Section A • Visual Fundamentals

1. Understanding Line Plots: Trends, Points & Continuity

Line plot data visualization ka sabse widely used chart type hai. Iska primary objective hota hai: Continuous sequence ya time-interval ke across data ka flow aur direction show karna.

Data Point
Observation
A specific measurement recorded at an exact X coordinate (e.g. Day 3 = 4.5 hours).
Connecting Line
Direction & Trend
Connects sequential points to reveal upward slope, downward drop, or flat plateau.
Ordering Rule
Sequential X
X-values MUST be ordered chronologically (time, dates, steps) to prevent criss-cross loops.

When to Use vs When NOT to Use Line Plots

  • When to Use: Continuous data over time (daily temperatures, weekly savings, hourly server load, monthly revenues, marathon split paces).
  • When NOT to Use: Unordered categorical data without logical sequence (e.g. Pizza toppings, City names, Car brands). Wahan Bar Chart use hota hai, kyunki unme continuity nahi hoti.

Example 1: Daily Study Hours Tracker (7 Days)

Aao 7 days ke study hours ko line plot par visualize karke trend observe karte hain:

🐍 weekly_study_hours.py Example 1 • Study Hours Trend 
import matplotlib.pyplot as plt

# 7 Days Study Hours Dataset
days = ['Mon', 'Tue', 'Wed', 'Thu', 'Fri', 'Sat', 'Sun']
study_hours = [2.0, 3.5, 3.0, 4.5, 4.0, 6.5, 5.0]

ax.axhline(3.5, color='#d97706', linestyle='--', linewidth=1.8, label='Weekly Target (3.5h)')

ax.set_title('Student Weekly Study Hours Trend', fontsize=13, fontweight='bold')
ax.set_xlabel('Day of the Week', fontsize=11, fontweight='bold')
ax.set_ylabel('Hours Studied', fontsize=11, fontweight='bold')
ax.set_ylim(0, 8)
ax.grid(True, linestyle='--', alpha=0.5)
ax.legend(loc='upper left')

# Numerical annotations above each point
for i, h in enumerate(study_hours):
    ax.annotate(f"{h}h", (days[i], h), textcoords="offset points", xytext=(0, 9), ha='center', fontweight='bold', color='#0284c7')

plt.show()
📈 Figure 4.1: Daily study hours trend line with circle markers. Note how weekend study hours surge to 6.5h, exceeding the 3.5h target baseline.

Section D • Line Styling

4. Customizing Line Appearance: Colors, Styles & Widths

Matplotlib lines ko customize karne ke 5 core parameters hote hain:

  • color: Hex codes (e.g. '#0284c7'), RGB, ya named colors ('green', 'crimson').
  • linestyle: Solid ('-'), Dashed ('--'), Dash-Dot ('-.'), ya Dotted (':').
  • linewidth: Line ki thickness points mein (default 1.5; enterprise charts mein 2.2–2.8 standard hai).
  • alpha: Transparency from 0.0 (fully invisible) to 1.0 (fully opaque).
  • label: Legend ke andar display hone wala descriptive name.
⚠️ Accessibility Rule: Never Rely on Color Alone
Colorblind users ke liye sirf red aur green color use karna misleading ho sakta hai! Hamesha Color + Line Style (e.g. Solid Green vs Dashed Red) combine karo taaki black-and-white printouts mein bhi graph 100% readable rahe.

Section I • Time Series & Missing Data

9. Working with Time-Based Data & Honest Gaps (NaN)

Real-life data collection mein IoT sensors fail ho sakte hain, internet drop ho sakta hai, ya maintenance break ho sakti hai. Data science ka golden principle hai: Missing data ko secretly connect mat karo!

❗ The Silent Interpolation Trap
Agar tum missing din ke data ko ignore karke simply doosre din se line join kar doge, toh viewer samjhega ki us din bhi normal traffic tha! Matplotlib mein missing values ko np.nan ya float('nan') assign karne se line plot wahan break ho jata hai, jo honest visual report banata hai.
🐍 nan_gap_handling.py Honest NaN Gap Visualization 
import matplotlib.pyplot as plt
import numpy as np

days = [f'Oct {i}' for i in range(1, 11)]
# Oct 5 has server outage: Assign np.nan
traffic = [4500, 4800, 5200, 4900, np.nan, 5600, 5900, 6400, 6800, 7100]

fig, ax = plt.subplots(figsize=(9.5, 4.8), dpi=150)
ax.plot(days, traffic, color='#0284c7', marker='o', markersize=8, linewidth=2.5, label='Daily Active Users')

ax.set_title('Honest Time-Series: Matplotlib Disconnects Across Missing (NaN) Values', fontsize=13, fontweight='bold')
ax.set_xlabel('Calendar Date', fontsize=11, fontweight='bold')
ax.set_ylabel('Active Users', fontsize=11, fontweight='bold')
ax.set_ylim(3500, 7800)
ax.grid(True, linestyle='--', alpha=0.5)

# Shaded span and annotation explaining the outage
ax.axvspan('Oct 4', 'Oct 6', color='#fef2f2', alpha=0.6)
ax.annotate('Oct 5: Server Outage\n(No data recorded)', xy=('Oct 5', 5200), xytext=('Oct 3', 6800),
            arrowprops=dict(arrowstyle='->', color='#dc2626', lw=1.5),
            fontsize=9.5, fontweight='bold', color='#dc2626',
            bbox=dict(boxstyle='round,pad=0.3', facecolor='#ffffff', edgecolor='#dc2626'))

ax.legend(loc='lower right')
plt.show()
🚨 Figure 4.17: Honest time-series handling: Matplotlib intentionally leaves a gap at Oct 5 where server outage occurred, avoiding false interpolation.
Section J • Troubleshooting

10. Common Mistakes & Debugging Checklist

Line charts aur markers use karte samay aane wale 12 most frequent errors aur unka exact fix:

# Mistake & Symptom Incorrect Code Correct Code & Why
1 Array Length Mismatch (ValueError) x = [1, 2, 3]
y = [10, 20]		 len(x) == len(y) ensure karo. Har X observation ke paas matching Y coordinate hona chahiye.
2 Unsorted X-values creating zigzag spiderweb x = [5, 1, 4, 2]
y = [10, 20, 30, 40]		 x, y = zip(*sorted(zip(x, y))) — Line plots connecting lines draw karte hain array order mein, isliye X sort hona zaroori hai.
3 Calling label=... but forgetting ax.legend() Line plots have labels, but no legend appears. Always call ax.legend() explicitly before plt.show().
4 Using identical line styles for all series 3 solid blue lines with no markers. Use distinct styles: solid ('-'), dashed ('--'), dotted (':') + unique markers.
5 Gigantic marker size obscuring the chart markersize=40 Keep markersize in the readable 6 to 10 range.
6 Too many points with markers (visual clutter) 10,000 hourly points with marker='o'. High-frequency data par markers off rakho ya markevery=100 use karo!
7 Clipped axis labels on export Labels cut off at canvas border. Always use fig.tight_layout() and plt.savefig(..., bbox_inches='tight').
8 Trunkating Y-axis to exaggerate minor fluctuations Y-axis limits set to 99.1 to 99.8. Provide zero-baseline or include contextual perspective so users are not misled.
9 Assuming Line Plot proves Causation "Study hours badhe toh weather acha hua." Line charts show correlation/trend over time, NOT automatic direct causation!
10 Silently joining lines across missing data days Skipping missing date without NaN. Use np.nan for missing records to render an honest gap.
11 Calling plt.show() before plt.savefig() Blank image file saved. Always call plt.savefig() before plt.show() because show() flushes memory.
12 Writing markersize='big' instead of numeric TypeError: must be a number Pass a float/integer like markersize=8.

# Left Axis: Running Pace

ax1.set_ylim(4.0, 6.0)
ax1.grid(True, linestyle='--', alpha=0.4)

# Right Twin Axis: Heart Rate

• Line plots show trends; markers show exact measurements.
