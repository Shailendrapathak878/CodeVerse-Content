Topic 06 • Core Charts

Scatter Plots

Master how to visualize relationships between two continuous numerical variables, detect positive and negative associations, spot natural clusters and outliers, encode 3rd and 4th dimensions via bubble size and colorbars, and avoid the correlation vs causation fallacy.

💡 Real-World Motivation: Why Scatter Plots?
“Suppose tumhare paas 30 students ke study hours aur exam marks ka data hai. Kaise pata chalega ki zyada padhne wale students ke marks generally zyada hain ya dono variables ka koi clear relationship nahi hai?” Bar chart se hum individual categories compare karte hain, line chart se time-series trend dekhte hain, lekin jab do continuous numbers ke beech connection ya pattern dhoondhna ho, toh Scatter Plot data scientist ka sabse powerful hathiyaar hota hai!
Section A • Core Principles

1. Understanding Scatter Plots: Points, Coordinates & Relationships

Scatter plot mein har observation ek single dot (point) ki tarah represent hota hai. Iska mental model ek Student Profile Sheet ki tarah hota hai jahan X-coordinate student ke daily study hours batata hai aur Y-coordinate usi student ke final exam marks.

Each Dot
One Observation
Single independent record (e.g. 1 student, 1 workout session, 1 IoT reading).
X & Y Coordinates
Two Continuous Metrics
Independent variable on X-axis; Dependent / Response metric on Y-axis.
Golden Rule
No Connecting Lines
Points are not connected sequentially because observations have no chronological order!

Scatter Plot vs Line Plot vs Bar Chart

Chart Type X-Axis Variable Type Y-Axis Variable Type Primary Objective
Scatter PlotContinuous NumericalContinuous NumericalCorrelation, relationships, clusters, outliers
Line PlotSequential / Chronological TimeContinuous NumericalTracking change over time (trends)
Bar ChartDiscrete Categorical GroupNumerical MetricComparing quantities across categories

Example 1: Study Hours vs Exam Marks (30 Students)

30 students ke reproducible dataset par study hours aur marks ka relationship observe karte hain:

🐍 study_hours_scatter.py Example 1 • 30-Student Relationship 
import matplotlib.pyplot as plt
import numpy as np

# 30 Students Reproducible Study Hours & Exam Marks
hours = np.array([1.5, 2.0, 2.2, 2.5, 2.8, 3.0, 3.2, 3.5, 3.8, 4.0,
                  4.2, 4.5, 4.8, 5.0, 5.2, 5.5, 5.8, 6.0, 6.2, 6.5,
                  6.8, 7.0, 7.2, 7.5, 7.8, 8.0, 8.2, 8.5, 8.8, 9.0])
noise = np.array([-3, 2, -1, 4, -2, 1, -4, 3, 0, -2,
                  3, -1, 2, -3, 4, 1, -2, 3, 0, -1,
                  2, -4, 1, 3, -2, 0, -1, 2, -3, 1])
marks = np.clip(42 + (hours * 5.8) + noise, 40, 98)

fig, ax = plt.subplots(figsize=(8.5, 4.8), dpi=150)
ax.scatter(hours, marks, color='#0284c7', s=70, edgecolor='#0369a1', linewidth=1.5, alpha=0.85, label='Student Record')

# Best-fit trendline
m, b = np.polyfit(hours, marks, 1)
ax.plot(hours, m*hours + b, color='#dc2626', linestyle='--', linewidth=2, label='Linear Trend (Positive Association)')

ax.set_title('30 Students: Daily Study Hours vs Exam Marks', fontsize=13, fontweight='bold')
ax.set_xlabel('Daily Study Hours', fontsize=11, fontweight='bold')
ax.set_ylabel('Exam Marks (out of 100)', fontsize=11, fontweight='bold')
ax.grid(True, linestyle='--', alpha=0.5)
ax.legend(loc='upper left')

fig.tight_layout()
plt.show()
📚 Figure 6.1: Scatter plot of 30 students showing a clear upward (positive) association between study hours and exam performance.

Section D • Point Styling

4. Customizing Point Colors, Marker Styles & Edges

Scatter points ko visually distinctive aur readable banane ke 6 key parameters:

  • color / c: Fill color hex code (e.g. '#0284c7').
  • s: Point ka physical area in points squared (standard: 60 to 120).
  • marker: Point shape ('o' circle, 's' square, '^' triangle, 'D' diamond, 'h' hexagon).
  • edgecolors: Outer boundary ring color (e.g. '#0f172a').
  • linewidths: Boundary ring ki thickness in points (standard: 1.2 to 2.0).
  • alpha: Point transparency level (0.0 to 1.0).

Section E • Bubble Charts

5. Marker Size as an Additional Variable (Bubble Charts)

Scatter plot mein X aur Y ke alawa ek 3rd numerical variable ko marker size (s) ke through encode kiya ja sakta hai. Isse hum Bubble Chart kehte hain.

❗ The Size vs Diameter Trap
Matplotlib mein parameter s point ke Area (points squared) ko represent karta hai, na ki diameter ya radius ko! Isliye agar data value 10 se 20 ho jaye (double), toh area double hota hai, jo visual perception ke liye mathematically accurate hai. Real values ko reasonable range (50 to 500 pt²) mein scale karna standard practice hai.

Example 2: IoT Telemetry — Temp vs Humidity (Continuous Color = AQI)

Continuous color scale ke liye c=aqi, cmap='viridis' aur fig.colorbar() use karna:

🐍 continuous_colorbar.py Continuous Color Mapping with Colorbar 
import matplotlib.pyplot as plt
import numpy as np

temp = np.array([21, 23, 24, 26, 27, 29, 31, 33, 35, 36, 28, 30, 32, 34])
humidity = np.array([75, 72, 68, 64, 60, 56, 52, 48, 44, 40, 58, 54, 50, 45])
aqi = np.array([45, 52, 68, 85, 95, 115, 135, 155, 175, 195, 105, 125, 145, 165])

fig, ax = plt.subplots(figsize=(9.5, 5), dpi=150)
scatter = ax.scatter(temp, humidity, c=aqi, cmap='viridis', s=90, edgecolors='#0f172a', linewidths=1.2, alpha=0.9)

cbar = fig.colorbar(scatter, ax=ax)
cbar.set_label('Air Quality Index (AQI Level)', fontsize=10.5, fontweight='bold')

ax.set_title('Continuous Color Mapping: Temp vs Humidity (Color = AQI)', fontsize=13, fontweight='bold')
ax.set_xlabel('Ambient Temperature (C)', fontsize=11, fontweight='bold')
ax.set_ylabel('Relative Humidity (%)', fontsize=11, fontweight='bold')
ax.grid(True, linestyle='--', alpha=0.5)

fig.tight_layout()
plt.show()
🌡️ Figure 6.14: Continuous colorbar: Yellow-green tones represent unhealthy high AQI, while dark purple tones indicate clean air quality.

Section K • Debugging Guide

11. 12 Common Scatter Plot Mistakes & How to Fix Them

Scatter plots implement karte samay aane wale 12 most frequent beginner errors:

# Common Mistake Incorrect Code Correct Code & Fix
1 Array dimension mismatch (ValueError) x = [1, 2, 3]
y = [10, 20]		 len(x) == len(y) ensure karo. Har observation ka matching coordinate hona mandatory hai.
2 Confusing s with marker diameter s = 100 assuming 100px diameter s marker ka area in points squared hota hai. 10pt diameter ke liye s=100 hota hai.
3 Passing continuous numbers to color instead of c ax.scatter(x, y, color=aqi_array) Continuous numbers ke liye hamesha c=aqi_array, cmap='viridis' use karo.
4 Forgetting the colorbar label fig.colorbar(scatter) without title Always call cbar.set_label('Metric Name (Units)') so viewers understand the scale.
5 Overplotting blindness with dense data 10,000 opaque points at alpha=1.0 Set alpha=0.1 to 0.3 and reduce marker size so overlapping density becomes visible.
6 Connecting scatter points with lines Calling plt.plot(x, y) on unordered scatter observations Use plt.scatter()! Only trendlines or regressions should be lines.
7 Assuming Correlation implies direct Causation "X badha toh Y isi ki wajah se badha." Correlation shows co-occurrence, NOT direct causality. Highlight external variables.
8 Deleting apparent outliers silently Filtering out unusual rows before analysis Investigate data collection context first. Outliers often carry the most valuable business insights!
9 Categorical colors without a legend Multiple colors used with no explanation Always provide label='...' and call ax.legend() for categorical groups.
10 Linear trendline on nonlinear data Fitting straight line on U-shaped curve Inspect scatter cloud visually; use polynomial regression for curvilinear patterns.
11 Hardcoded unscaled bubble sizes s = population (e.g. 5,000,000) Scale bubble metric into standard 40 to 400 pt² range.
12 Missing axis labels and physical units Axis labelled only "X" and "Y" Always specify clear metric name and units: e.g. "Ambient Temperature (°C)".

🐍 student_multidim_analysis.py Complete 4D Scatter Script 
import matplotlib.pyplot as plt
import numpy as np

hours = np.array([1.5, 2.0, 2.5, 3.0, 3.5, 4.0, 4.5, 5.0, 5.5, 6.0, 6.5, 7.0, 7.5, 8.0, 8.5])

⚡ Challenge Problem: 10K Marathon Pace vs Cardiac Load
Tumhe ek marathon runner ka biometrics scatter plot create karna hai:
  • X-Axis: Running Pace in min/km across 10 distance splits (Invert X-axis taaki faster pace right side par aaye!).
  • Y-Axis: Heart Rate in BPM (132 to 185 BPM).
  • Point Color: Segment Elevation Gain in meters (10m to 90m) mapped via `coolwarm` colormap with colorbar.
  • Points: Size `s=110`, dark boundary rings (`edgecolors='#0f172a'`).

Verified Challenge Solution:

🐍 marathon_scatter_challenge.py Verified Solution Code 
import matplotlib.pyplot as plt
import numpy as np

pace = np.array([6.2, 6.0, 5.8, 5.5, 5.3, 5.1, 4.9, 4.7, 4.5, 4.2])
heart_rate = np.array([132, 138, 144, 150, 155, 161, 166, 172, 178, 185])
elevation = np.array([10, 15, 20, 25, 30, 45, 50, 65, 75, 90])

fig, ax = plt.subplots(figsize=(9.5, 5), dpi=150)
scatter = ax.scatter(pace, heart_rate, c=elevation, cmap='coolwarm', s=110, edgecolors='#0f172a', linewidths=1.5)

cbar = fig.colorbar(scatter, ax=ax)
cbar.set_label('Segment Elevation Incline (Meters)', fontsize=10.5, fontweight='bold')

ax.invert_xaxis()  # Faster pace (smaller min/km) on right side!

ax.set_title('Mini Challenge Solution: 10K Marathon Pace vs Cardiac Load (Color = Elevation)', fontsize=13, fontweight='bold')
ax.set_xlabel('Running Pace (min/km — Inverted: Faster Speed on Right)', fontsize=11, fontweight='bold')
ax.set_ylabel('Heart Rate (BPM)', fontsize=11, fontweight='bold')
ax.set_xlim(6.5, 4.0)
ax.set_ylim(125, 195)
ax.grid(True, linestyle='--', alpha=0.5)

fig.tight_layout()
plt.show()
🏃 Figure 6.24: Verified Challenge Solution: Heart rate climbs towards 185 BPM as running pace reaches top speed (4.2 min/km) on steep hill climbs (90m elevation).

✔️ Golden Rules of Scatter Plots
• Never join points with lines: Scatter observations are independent, not chronological.
• Always check for overplotting: Set alpha=0.3 whenever plotting 200+ observations.
• Colorbar needs a label: Unlabeled continuous colorbars leave viewers guessing what the colors mean.
• Correlation is not causation: An apparent trend describes association, not root-cause proof.
