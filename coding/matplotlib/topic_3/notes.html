Section A • Core Anatomy

1. Understanding the Figure: The Overall Canvas

Matplotlib mein Figure sabse top-level container hota hai. Isko real life ke ek Wooden Notice Board ya Blank Painting Canvas ki tarah samjho. Canvas khud koi line ya bar graph draw nahi karta, balki yeh ek outer boundary provide karta hai jiske upar tum ek ya multiple graphs (Axes) paste kar sakte ho.

Top Container
Figure
Entire image canvas holding all plots, titles, legends, and colorbars.
Individual Plot
Axes
The actual plotting area with data points, ticks, grids, and boundaries.
Scale Ruler
Axis (X & Y)
Number-lines with tick marks that measure numeric or categorical scales.
📊 Figure 3.1: The 3-Tier Hierarchy: One Figure canvas holding two distinct Axes (Plotting Areas), each containing its own X and Y Axis rulers.

Controlling Figure Dimensions: figsize & dpi

plt.figure() call karke tum canvas ki physical width, height, background color aur resolution configure kar sakte ho:

  • figsize=(width, height): Canvas ka size inches mein define karta hai. E.g. (10, 5) means 10 inches wide aur 5 inches tall.
  • dpi=...: Dots Per Inch. Screen rendering ke liye 100–150 DPI best hota hai; high-res print publications ke liye 300 DPI use hota hai.
  • facecolor=...: Outer figure canvas ka background color set karta hai.
🐍 figure_intro.py Canvas Sizing & Facecolor 
import matplotlib.pyplot as plt

# Monthly Pocket Money Savings Scenario (6 Months)
months = ['Jan', 'Feb', 'Mar', 'Apr', 'May', 'Jun']
savings = [1200, 1500, 1800, 1400, 2200, 2600]

# 1. Canvas create karo: 9 inches wide x 4.5 inches tall with 150 DPI
plt.figure(figsize=(9, 4.5), dpi=150, facecolor='#f8fafc')

plt.plot(months, savings, color='#0284c7', marker='o', linewidth=2.5)
plt.title('Student Monthly Pocket Money Savings Trend', fontsize=13, fontweight='bold')
plt.xlabel('Month', fontsize=11)
plt.ylabel('Savings Amount (₹)', fontsize=11)
plt.grid(True, linestyle='--', alpha=0.5)
plt.show()

Section B • Coordinate Deep Dive

2. Understanding Axes vs Axis: Never Confuse Them Again

Beginners aksar Axes (plural spelling) aur Axis (singular) mein confuse ho jate hain. Dono mein zameen-aasmaan ka farq hai:

Feature Figure Axes (Plural) Axis (Singular)
Analogy Complete Notice Board Sheet of graph paper pinned on board The marked ruler measuring cm/inches
Contains All Axes, Suptitles, Canvas Lines, Bars, Ticks, Labels, Legend Tick marks, Tick labels, Min/Max limits
Code Object fig = plt.figure() ax = fig.add_subplot() ax.xaxis / ax.yaxis
Quantity 1 per image file 1, 2, 4, or 16 per Figure 2 (X and Y) per 2D Axes
✅ Golden Memory Rule
Axis = 1D number-line ruler (sirf X ya sirf Y).
Axes = 2D coordinate plotting region (jiske pass X-Axis + Y-Axis + Data Points + Title sab kuch hota hai).

Relatable Scenario 1: Daily Study Hours Tracking

Jab hum ax.set_title() aur ax.set_xlabel() call karte hain, toh hum directly usi specific Axes object ko customize kar rahe hote hain:

🐍 axes_study_hours.py Object-Oriented Axes Control 
import matplotlib.pyplot as plt

days = ['Mon', 'Tue', 'Wed', 'Thu', 'Fri', 'Sat', 'Sun']
hours = [2.5, 3.5, 2.0, 4.0, 4.5, 6.0, 5.0]

fig, ax = plt.subplots(figsize=(8.5, 4.5), dpi=150)

ax.plot(days, hours, color='#059669', marker='s', linewidth=2.5, label='Study Hours')
ax.axhline(3.5, color='#d97706', linestyle='--', label='Target (3.5h)')

ax.set_title('Weekly Student Study Hours vs Daily Target', fontsize=12, fontweight='bold')
ax.set_xlabel('Day of the Week', fontsize=10.5)
ax.set_ylabel('Hours Invested', fontsize=10.5)
ax.set_ylim(0, 7)
ax.grid(True, linestyle='--', alpha=0.5)
ax.legend(loc='upper left')
plt.show()

Section C • Industry Standard

3. The Object-Oriented (OO) Interface: plt.subplots()

Topic 2 mein humne plt.plot() aur plt.title() use kiya tha. Wo tha pyplot state-machine interface. Small exploratory scripts ke liye wo theek hai, lekin professional software engineering aur multi-plot dashboards mein Object-Oriented (OO) Interface use kiya jata hai.

Pyplot (State-based) vs Object-Oriented (Explicit)

Pyplot State-Machine (plt.xxx) Object-Oriented Approach (ax.xxx) Why OO is Superior?
plt.title('My Title') ax.set_title('My Title') Explicit pata hota hai kaunse subplot ka title set ho raha hai.
plt.xlabel('X Axis') ax.set_xlabel('X Axis') Multi-plot layout mein galat plot label hone ka risk 0 ho jata hai.
plt.xlim(0, 10) ax.set_xlim(0, 10) Har plot ki scaling completely independent rahti hai.
plt.grid(True) ax.grid(True) Ek plot par grid on aur doosre par off rakhna transparent hota hai.
⚖️ Figure 3.6: Side-by-side comparison: Pyplot implicit state vs Object-Oriented explicit references.
📝 The Magic Line: fig, ax = plt.subplots()
Yeh single line do objects return karti hai via Python tuple unpacking:
1. fig: Complete Figure window/canvas.
2. ax: Ek ready-to-use Axes plotting area.
Section D • Multi-Plot Layouts

4. Creating Multiple Subplots: Rows & Columns

Ek screen par multiple plots arrange karne ke liye hum plt.subplots(nrows, ncols) use karte hain. nrows batata hai kitni rows hongi, aur ncols batata hai kitne columns honge.

1. Horizontal Layout (1 Row × 2 Columns)

College marks aur study hours ko side-by-side compare karne ke liye nrows=1, ncols=2 sabse best choice hai:

🐍 two_panel_dashboard.py 1x2 Side-by-Side Dashboard 
import matplotlib.pyplot as plt

subjects = ['Python', 'SQL', 'ML', 'Web Dev']
marks = [88, 76, 92, 81]
study_hours = [25, 18, 32, 22]

# 1 row, 2 columns -> axes is a 1D NumPy array with 2 elements: [ax1, ax2]
fig, (ax1, ax2) = plt.subplots(nrows=1, ncols=2, figsize=(10, 4.5), dpi=150)

# Left Plot (Bar chart on ax1)
ax1.bar(subjects, marks, color='#0284c7', width=0.5)
ax1.set_title('Subject Marks (out of 100)', fontweight='bold')
ax1.set_ylabel('Marks')
ax1.set_ylim(0, 100)
ax1.grid(True, linestyle='--', alpha=0.5)

# Right Plot (Line chart on ax2)
ax2.plot(subjects, study_hours, color='#7c3aed', marker='o', linewidth=2.5)
ax2.set_title('Study Hours Invested', fontweight='bold')
ax2.set_ylabel('Total Hours')
ax2.grid(True, linestyle='--', alpha=0.5)

fig.suptitle('College Academic Performance: Marks vs Effort', fontsize=13, fontweight='bold')
fig.tight_layout()
plt.show()
🏫 Figure 3.7: 1x2 Subplot layout: Left panel shows exam marks (bar), right panel shows study hours (line).

3. Grid Matrix Layout (2 Rows × 2 Columns)

Enterprise applications mein 4 key metrics ko ek 2×2 grid matrix mein dikhaya jata hai. Dhyan rahe, is case mein axes ek 2D NumPy Array ban jata hai:

⚠️ 2D Array Subplot Indexing Rules
Jab nrows > 1 aur ncols > 1 ho, tab indexing coordinate system follow karti hai:
• axes[0, 0]: Top-Left plot (Row 0, Col 0)
• axes[0, 1]: Top-Right plot (Row 0, Col 1)
• axes[1, 0]: Bottom-Left plot (Row 1, Col 0)
• axes[1, 1]: Bottom-Right plot (Row 1, Col 1)
Agar tum loop lagana chahte ho, toh axes.flatten() use karke 1D array mein convert kar sakte ho!

Section F • Layout Perfection

6. Figure Titles, Spacing & Layout Management

Jab multiple subplots banaye jate hain, toh do major visual issues aate hain:

  1. Title Clashing: Subplot ke titles Figure ke main title se takra jate hain.
  2. Label Clipping: Ek subplot ka X-axis label doosre subplot ke title ke upar overlap ho jata hai.

1. fig.suptitle() vs ax.set_title()

  • fig.suptitle('Super Title', fontsize=14): Poore canvas ka overall high-level heading hota hai.
  • ax.set_title('Subplot Title', fontsize=11): Sirf us particular Axes ka individual heading hota hai.

2. fig.tight_layout() & fig.subplots_adjust()

fig.tight_layout() Matplotlib ka built-in layout engine hai jo automatic margins aur padding adjust karta hai taaki koi bhi text clip na ho:

👑 Figure 3.12: Clear hierarchy: Executive fig.suptitle() at the top, supported by clean individual ax.set_title() headings.
🔧 Figure 3.13: Before vs After: Left panel shows overlapping title labels without adjustment; Right panel shows clean auto-spaced layout via fig.tight_layout().
💡 Pro Tip for Suptitle Padding
Agar fig.suptitle() aur top subplots ke beech mein thoda extra room chahiye, toh fig.tight_layout(rect=[0, 0, 1, 0.95]) use karo! Yeh canvas ke top 5% space ko exclusively suptitle ke liye reserve kar deta hai.
Section G • Synchronized Scales

7. Shared Axes: sharex=True & sharey=True

Jab do subplots related data show kar rahe hon, toh unka axis scale share karna visual honesty aur clarity ke liye critical hota hai.

1. Shared X-Axis (sharex=True)

Agar dono graphs ka time scale same hai (jaise Daily Temperature aur Daily Humidity), toh X-axis labels ko repeat karne ki zaroorat nahi hoti. sharex=True lagane se sirf bottom plot par X tick labels aate hain aur dono zoom/pan synchronize ho jate hain:

🔗 Figure 3.14: Synchronized Time-Series with sharex=True: Top panel tracks server CPU load, bottom panel tracks RAM usage on identical timestamps.

2. Shared Y-Axis (sharey=True): Fair Comparisons

Agar do branches (Branch Alpha vs Branch Beta) ki monthly sales compare karni ho, aur dono ka Y-axis scale alag ho (jaise ek ka 0–100 aur doosre ka 0–500), toh viewer mislead ho sakta hai. sharey=True dono plots ka Y scale identical lock kar deta hai:

⚖️ Figure 3.15: Honest comparison with sharey=True: Branch Alpha vs Branch Beta have identical Y-scale (0 to 100 Lakhs), making visual comparison truthful.
🚫 When NOT to share axes?
Kabhi bhi different units wale metrics (jaise Exam Marks in % aur Study Hours in hours) par sharey=True mat lagao! Varna 6 hours ka graph 100 marks ke scale par flat line ban jayega.
Section H • Debugging Guide

8. 12 Common Plot-Structure Mistakes & How to Fix Them

Matplotlib beginner se intermediate level par aane ke dauran ye 12 mistakes sabse common hoti hain:

# Common Mistake Bad Code Example Correct Code & Why
1 Mixing plt and ax confusingly ax.plot(...)
plt.title('Title')		 ax.set_title('Title') — Pyplot functions active figure par affect karti hain; hamesha explicit ax methods use karo.
2 Unpacking 2D array incorrectly fig, (ax1, ax2, ax3, ax4) = plt.subplots(2, 2) — ValueError! fig, axes = plt.subplots(2, 2)
ax1 = axes[0, 0] ya axes.flatten() use karo.
3 Forgetting fig.tight_layout() Multiple plots banaye bina spacing adjustment ke. Call fig.tight_layout() before plt.show() taaki labels overlap na hon.
4 Suptitle clashing with plot titles fig.suptitle('...') without top margin. fig.tight_layout(rect=[0, 0, 1, 0.95]) — Top 5% space suptitle ke liye reserve karo.
5 Writing ax.title('...') instead of ax.set_title() ax.title('Title') — TypeError! Axes object par method ka naam ax.set_title() hota hai.
6 Writing ax.xlabel('...') instead of ax.set_xlabel() ax.xlabel('Month') — AttributeError! Always use setter methods: ax.set_xlabel(), ax.set_ylabel().
7 Sharing Y-axis for different units sharey=True for Marks (0-100) and Hours (0-5). Do not share Y-axis when physical data units are fundamentally different.
8 Calling plt.show() before plt.savefig() plt.show()
plt.savefig('my_plot.png')		 Always savefig() first! show() clears the active Figure buffer resulting in blank images.
9 Hardcoding tiny figsize for 4 subplots plt.subplots(2, 2, figsize=(4, 3)) Use adequate canvas size like figsize=(12, 8) for 2x2 grids so plots have room to breathe.
10 Overwriting ax variable in a loop for col in data: ax = ... Use indexed axes: for i, ax in enumerate(axes.flatten()): ax.plot(...).
11 Ignoring tick label rotation on crowded categorical axes 10 subject names horizontal and overlapping. Use ax.tick_params(axis='x', rotation=30) or ax.set_xticklabels(labels, rotation=30).
12 Missing bbox_inches='tight' during save plt.savefig('dashboard.png') Always use bbox_inches='tight' to prevent edge labels from being cut off in exports.

9. Mini Project 1: College Academic Performance Executive Dashboard

Aao ek complete, production-grade 3-panel academic dashboard banate hain jisme:

  • Panel A (Top-Left): 5 subjects ke Exam Marks (Bar Chart).
  • Panel B (Top-Right): 7 days ka Weekly Study Effort Curve with Target line (Line Chart).
  • Panel C (Bottom Full-Width): Subject-wise Attendance vs Exam Marks Correlation (Multi-Line Chart).
🐍 college_performance_dashboard.py Complete Runnable Script 
import matplotlib.pyplot as plt

# 1. Dataset Preparation
subjects = ['Data Struct', 'Databases', 'Python Viz', 'Networks', 'Maths']
exam_scores = [82, 76, 94, 71, 88]
attendance_pct = [90, 85, 98, 80, 92]

days = ['Mon', 'Tue', 'Wed', 'Thu', 'Fri', 'Sat', 'Sun']
daily_study_hours = [2.5, 3.2, 1.8, 4.5, 3.8, 6.0, 5.2]

# 2. Canvas & Grid Setup (2 rows x 2 cols layout)
fig = plt.figure(figsize=(10, 6.8), dpi=150)

# Subplot 1: Top-Left (Panel A)
ax1 = plt.subplot2grid((2, 2), (0, 0))
bars = ax1.bar(subjects, exam_scores, color='#0284c7', width=0.55)
ax1.set_title('Panel A: Subject Exam Scores', fontweight='bold')
ax1.set_ylabel('Score (out of 100)')
ax1.set_ylim(0, 110)
ax1.grid(True, linestyle='--', alpha=0.4)
ax1.tick_params(axis='x', rotation=25)
for b in bars:
    ax1.text(b.get_x() + b.get_width()/2, b.get_height() + 2, str(b.get_height()), ha='center', fontweight='bold')

# Subplot 2: Top-Right (Panel B)
ax2 = plt.subplot2grid((2, 2), (0, 1))
ax2.plot(days, daily_study_hours, color='#059669', marker='o', linewidth=2.5)
ax2.axhline(3.5, color='#d97706', linestyle='--', label='Target (3.5h)')
ax2.set_title('Panel B: Weekly Study Effort Curve', fontweight='bold')
ax2.set_ylabel('Daily Hours')
ax2.set_ylim(1, 7)
ax2.grid(True, linestyle='--', alpha=0.4)
ax2.legend(loc='upper left')

# Subplot 3: Bottom Full-Width (Panel C)
ax3 = plt.subplot2grid((2, 2), (1, 0), colspan=2)
ax3.plot(subjects, attendance_pct, color='#7c3aed', marker='s', linewidth=2.5, label='Attendance (%)')
ax3.plot(subjects, exam_scores, color='#0284c7', marker='o', linewidth=2.5, linestyle='--', label='Exam Marks (0-100)')
ax3.set_title('Panel C: Attendance Correlation Profile Across Curriculum', fontweight='bold')
ax3.set_ylabel('Percentage / Score')
ax3.set_ylim(60, 105)
ax3.grid(True, linestyle='--', alpha=0.4)
ax3.legend(loc='lower right')

fig.suptitle('Mini Project 1: College Academic Performance Executive Dashboard', fontsize=14, fontweight='bold')
fig.tight_layout(rect=[0, 0, 1, 0.96])
plt.savefig('college_dashboard.png', dpi=150, bbox_inches='tight')
plt.show()
