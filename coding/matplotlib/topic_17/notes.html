Statistical Plotting • Topic 17

Statistical & Scientific Visualization

Move beyond misleading averages. Master distribution shapes (symmetric, skewed, bimodal), box plots & 1.5×IQR outlier detection, violin plots, correlation heatmaps, scientific error bars, and 95% confidence intervals.

🔬 Section A — Introduction to Statistical & Scientific Visualization

Real-world data science aur scientific engineering mein sirf ek number — "Average" (Mean) — aksar sach ko chhipa deta hai! Statistical visualization ka maqsad raw data ke shape, spread, variability, aur uncertainty ko visible banana hai.

Sochiye ek college ke do sections (Class Alpha aur Class Beta) hain. Dono ka class average exact 72% hai! Lekin jab aap unka distribution graph dekhte hain, toh reality bilkul alag nikal kar aati hai:

Figure 17.1: The Flaw of Averages. Both classes have an identical mean score (72%), but Class Alpha is a tight normal curve, while Class Beta is polarized into failures and toppers!
The Lake Depth Analogy (तालाब की गहराई): Ek famous kahavat hai: "A mathematician drowned in a lake that was on average only 3 feet deep!" Average depth 3 feet thi, lekin beech mein 15 feet ka gehra gaddha tha! Data science mein bhi agar aap sirf mean dekhenge aur distribution nahi dekhenge, toh aapka model fail ho sakta hai!

When to Use Which Statistical Chart?

Plot Type Core Question It Answers Best Use Case
Histogram Data values kis frequency mein distributed hain? Single continuous variable ki shape & spread dekhna.
Box Plot Median, quartiles, aur extreme outliers kahan hain? Multiple groups ya departments ko side-by-side compare karna.
Violin Plot Kya distribution mein multiple peaks (multimodal) hain? Complex density distributions jahan box plot shape nahi dikha pata.
Scatter Plot Kya do variables ke beech koi mathematical relationship hai? Study hours vs. Marks, Price vs. Demand.
Correlation Heatmap Kaun-kaun se variables aapas mein strongly correlated hain? Multi-dimensional feature matrix analysis.
Error Bar Plot Lab measurements mein kitna uncertainty ya margin of error hai? Physical experiments, IoT sensor trials, machine benchmarks.

Code Example 1: Demonstrating the Mean Fallacy

import matplotlib.pyplot as plt
import numpy as np

np.random.seed(42)

# Class Alpha: Normal curve around 72
alpha = np.random.normal(loc=72, scale=6, size=500)

# Class Beta: Bimodal (polarized into 55 and 89)
beta = np.concatenate([np.random.normal(55, 5, 250), np.random.normal(89, 5, 250)])

fig, (ax1, ax2) = plt.subplots(1, 2, figsize=(10, 4))

ax1.hist(alpha, bins=25, color='#0284c7', edgecolor='white')
ax1.axvline(np.mean(alpha), color='#dc2626', linestyle='--', lw=2, label=f'Mean: {np.mean(alpha):.1f}%')
ax1.set_title("Class Alpha: Unimodal Normal")
ax1.legend()

ax2.hist(beta, bins=25, color='#7c3aed', edgecolor='white')
ax2.axvline(np.mean(beta), color='#dc2626', linestyle='--', lw=2, label=f'Mean: {np.mean(beta):.1f}%')
ax2.set_title("Class Beta: Polarized Bimodal")
ax2.legend()

plt.tight_layout()
plt.show()

📐 Section B — Understanding Data Distributions

Ek distribution humein batata hai ki data ke values number line par kis tarah spread hain. Teen core architectural shapes hoti hain:

Figure 17.2: Diagnostic Distribution Typologies: Symmetric (Mean ≈ Median), Right-Skewed (Mean > Median pulled by tail), and Bimodal (Dual operating regimes).

Key Statistical Properties

  • Symmetric (Bell Curve): Left aur right sides mirror images hoti hain. Yahan Mean ≈ Median hota hai.
  • Right-Skewed (Positive Skew): Long tail right side ki taraf hoti hai (jaise Software salaries, website latency). Yahan extreme high values mean ko upar kheench leti hain (Mean > Median).
  • Bimodal (Two Peaks): Do alag-alag clusters hote hain. Yahan mean ek aise khali point par hota hai jahan actual data bohot kam hota hai!

Code Example 2: Analyzing Skewness in Web Latency

import matplotlib.pyplot as plt
import numpy as np

# Log-normal distribution simulates API response times
latency = np.random.lognormal(mean=3.0, sigma=0.6, size=1000)

mean_val = np.mean(latency)
median_val = np.median(latency)

fig, ax = plt.subplots(figsize=(8, 4))
ax.hist(latency, bins=35, color='#d97706', edgecolor='white', alpha=0.85)

ax.axvline(mean_val, color='#dc2626', linestyle='--', lw=2, label=f'Mean ({mean_val:.1f}ms)')
ax.axvline(median_val, color='#059669', linestyle=':', lw=2.5, label=f'Median ({median_val:.1f}ms)')

ax.set_title("API Gateway Response Latency (Right-Skewed)", fontweight='bold')
ax.set_xlabel("Latency (ms)")
ax.set_ylabel("Request Count")
ax.grid(True, linestyle='--', alpha=0.3)
ax.legend()

plt.show()

📊 Section C — Histograms & Distribution Comparison

ax.hist() data ko discrete intervals (bins) mein baantkar har bucket ki count calculate karta hai. Lekin bin width select karna ek critical decision hai:

Figure 17.3: Bin Calibration (Left: Over-smoothed 5 bins vs. granular 25 bins) and Comparative Overlaid Histogram (Right: Express vs. Standard delivery with alpha=0.6).
The Bin Count Rule:
• Agar bins bohot kam (jaise bins=5) honge, toh distribution ka inner structure chhip jayega (Over-smoothing).
• Agar bins bohot zyada (jaise bins=100) honge, toh data spiky aur noisy ho jayega.
• Heuristic Rule: Sturges' rule (bins = int(1 + 3.322 * np.log10(N))) ya 20–30 bins general datasets ke liye best starting point hai.

📦 Section D — Box Plots & Quartiles (The 1.5×IQR Rule)

Box Plot (Box-and-Whisker plot) John Tukey dwara banaya gaya statistical summary plot hai jo 5 key numbers par aadharit hota hai:

Figure 17.4: Complete anatomical breakdown of a Box Plot across 3 engineering cohorts, illustrating Median, Q1, Q3, Whiskers, and flagged potential outliers.

Anatomy of a Box Plot

  • Median (Q2, 50th percentile): Box ke andar ki bold red line jo data ko do barabar hisso mein divide karti hai.
  • Interquartile Range (IQR): IQR = Q3 - Q1. Ye middle 50% data ka spread hota hai.
  • Whiskers: Box ke ends se nikli hui lines jo maximum 1.5 × IQR tak jaati hain.
  • Potential Outliers: Jo points Q3 + 1.5×IQR se oopar ya Q1 - 1.5×IQR se neeche girte hain, unhe isolated red dots se flag kiya jata hai!

Code Example 4: Creating Clean Multi-Group Box Plots

import matplotlib.pyplot as plt
import numpy as np

cs = np.concatenate([np.random.normal(82, 6, 80), [45, 48]]) # with outliers
ec = np.random.normal(74, 8, 80)
me = np.random.normal(68, 9, 80)

fig, ax = plt.subplots(figsize=(8, 5))

box = ax.boxplot([cs, ec, me], tick_labels=['Computer Science', 'Electronics', 'Mechanical'],
                 patch_artist=True, widths=0.5,
                 medianprops=dict(color='#dc2626', lw=2),
                 flierprops=dict(marker='o', markerfacecolor='#dc2626', markersize=7))

colors = ['#e0f2fe', '#d1fae5', '#fef3c7']
for patch, color in zip(box['boxes'], colors):
    patch.set_facecolor(color)

ax.set_title("Department Examination Score Distribution", fontweight='bold')
ax.set_ylabel("Marks (0-100)")
ax.grid(True, linestyle='--', alpha=0.35, axis='y')

plt.show()

🎻 Section E — Violin Plots & Distribution Shape

Box plots summarize toh achha karte hain, lekin ek bada limitation hai: Box plots internal shape nahi dikha sakte! Agar ek distribution mein do alag-alag peaks (bimodal) hain, toh box plot mein wo simple square box jaisa hi dikhega. Yahan kaam aata hai Violin Plot!

Figure 17.5: Box Plot vs. Violin Plot on identical data. Box plot (Left) obscures the dual peaks, while Violin Plot (Right) clearly captures the bimodal density waistline.
KDE Density Waistline:
Violin plot har side par Kernel Density Estimation (KDE) curve draw karta hai. Jahaan violin chauda (wide) hota hai, wahan data density sabse zyada hoti hai; jahan patla (narrow) hota hai, wahan data sparse hota hai.

Code Example 5: Implementing ax.violinplot()

import matplotlib.pyplot as plt
import numpy as np

# Bimodal cohort
cohort1 = np.concatenate([np.random.normal(40, 5, 200), np.random.normal(80, 6, 200)])
# Normal cohort
cohort2 = np.random.normal(60, 10, 400)

fig, ax = plt.subplots(figsize=(8, 4.8))

parts = ax.violinplot([cohort1, cohort2], positions=[1, 2], showmedians=True)

for pc in parts['bodies']:
    pc.set_facecolor('#0284c7')
    pc.set_edgecolor('#0369a1')
    pc.set_alpha(0.7)
parts['cmedians'].set_color('#dc2626')

ax.set_xticks([1, 2])
ax.set_xticklabels(['Cohort 1 (Bimodal)', 'Cohort 2 (Unimodal)'])
ax.set_title("Violin Plot Density Representation", fontweight='bold')
ax.set_ylabel("Exam Score")
ax.grid(True, linestyle='--', alpha=0.3, axis='y')

plt.show()

🌌 Section F — Scatter Plots & Relationships

Jab hum do continuous numerical variables ke beech ka correlation explore karte hain, toh Scatter Plot sabse pehla diagnostic tool hota hai.

Figure 17.6: The 4 Classic Bivariate Relationships: Strong Positive Linear, Strong Negative Linear, Non-Linear Inverted U-Curve, and Null Correlation.
Correlation Does NOT Imply Causation:
Agar do cheezon mein strong positive correlation hai (jaise Ice Cream Sales aur Drowning Incidents dono summer mein badhte hain), iska matlab ye nahi ki ek cheez doosri ko cause kar rahi hai! Yahan teesra lurking variable (Hot Summer Weather) dono ko drive kar raha hai.

Code Example 6: Study Hours vs. Examination Marks with Trendline

import matplotlib.pyplot as plt
import numpy as np

hours = np.random.uniform(5, 30, 120)
marks = 40 + 2.0 * hours + np.random.normal(0, 4, 120)

fig, ax = plt.subplots(figsize=(8, 4.5))

ax.scatter(hours, marks, color='#0284c7', alpha=0.75, s=40)

# Calculate linear regression trendline: y = mx + c
m, c = np.polyfit(hours, marks, 1)
h_sorted = np.sort(hours)
ax.plot(h_sorted, m * h_sorted + c, '--', color='#0369a1', lw=2, label=f'Trend: y={m:.1f}x+{c:.0f}')

ax.set_title("Study Hours vs. Examination Marks", fontweight='bold')
ax.set_xlabel("Weekly Study Hours")
ax.set_ylabel("Marks (0-100)")
ax.grid(True, linestyle='--', alpha=0.35)
ax.legend()

plt.show()

🔥 Section G — Correlation & Correlation Matrices (Heatmaps)

Pearson Correlation Coefficient (r) do variables ke beech linear relationship ki strength aur direction measure karta hai (-1.0 se +1.0 ke beech). Multiple features ke pairwise correlation ko summarize karne ke liye Matplotlib ka ax.imshow() use karke heatmap banaya jata hai.

Figure 17.7: Pearson Correlation Heatmap showing strong positive coupling between Study Hours, Midterms, and Final Scores.

Code Example 7: Building a Correlation Heatmap via imshow()

import matplotlib.pyplot as plt
import numpy as np

# Correlation matrix
corr = np.array([
    [1.00,  0.48,  0.81,  0.86],
    [0.48,  1.00,  0.55,  0.61],
    [0.81,  0.55,  1.00,  0.89],
    [0.86,  0.61,  0.89,  1.00]
])
labels = ['Hours', 'Attendance', 'Midterm', 'Final']

fig, ax = plt.subplots(figsize=(6, 5))
cax = ax.imshow(corr, cmap='Blues', vmin=-1.0, vmax=1.0)
fig.colorbar(cax, ax=ax)

ax.set_xticks(range(len(labels)))
ax.set_yticks(range(len(labels)))
ax.set_xticklabels(labels)
ax.set_yticklabels(labels)

# Print values inside matrix cells
for i in range(len(labels)):
    for j in range(len(labels)):
        val = corr[i, j]
        color = 'white' if val > 0.65 else '#0f172a'
        ax.text(j, i, f"{val:.2f}", ha='center', va='center', color=color, fontweight='bold')

ax.set_title("Feature Correlation Heatmap", fontweight='bold')
plt.tight_layout()
plt.show()

📏 Section H — Error Bars & Measurement Uncertainty

Scientific experiments aur physical sensor measurements mein kabhi bhi exact single value nahi aati; har reading ke sath uncertainty judi hoti hai. ax.errorbar() se hum har point ke aas-paas ka error range display karte hain.

Figure 17.8: Quantifying scientific uncertainty with ax.errorbar(). Symmetric ±1 SD bounds (Left) vs. Skewed asymmetric bounds (Right).

Key Parameters of ax.errorbar()

  • yerr=...: Vertical error bounds. Agar single array dein toh symmetric error banega; agar [lower, upper] dein toh asymmetric error banega.
  • capsize=5: Error bar ke ends par horizontal cross-bar add karta hai.
  • fmt='-o': Line aur marker format string (e.g. solid line with circle markers).
  • ecolor='#dc2626': Error bars ka color line se alag set karne ke liye.

Code Example 8: Reactor Temperature Yield with Error Bars

import matplotlib.pyplot as plt
import numpy as np

temp = np.array([100, 150, 200, 250, 300])
yield_mean = np.array([42.5, 58.2, 74.6, 82.1, 79.4])
yield_sd = np.array([3.2, 4.1, 2.8, 5.0, 6.2]) # Standard Deviation

fig, ax = plt.subplots(figsize=(8, 4.5))

ax.errorbar(temp, yield_mean, yerr=yield_sd, fmt='-o', color='#0284c7', ecolor='#dc2626',
            capsize=5, capthick=1.5, lw=2, label='Mean Yield ± 1 SD')

ax.set_title("Chemical Reactor Yield with Measurement Uncertainty", fontweight='bold')
ax.set_xlabel("Operating Temp (°C)")
ax.set_ylabel("Product Yield (%)")
ax.grid(True, linestyle='--', alpha=0.35)
ax.legend()

plt.show()

🎯 Section I — Confidence Intervals (Estimating Population Truth)

Jab aapke paas poore population ka data nahi hota (jaise sabhi 50,000 customers ka nahi, sirf 100 ka sample hai), toh Confidence Interval (CI) batata hai ki population ka asli mean kis range ke andar aane ki 95% probability hai.

Figure 17.9: 95% Confidence Interval shrinkage as sample size N expands from 10 to 2000 (Left), and comparing logistics delivery providers with CI error bars (Right).
The Law of Large Numbers (सैंपल साइज का जादू):
Jaise-jaise sample size $N$ badhta hai, Standard Error $SE = \sigma / \sqrt{N}$ chhota hota jaata hai. Nateeja? Confidence interval patla (narrow) ho jata hai aur hamara estimate bohot precise ban jata hai!

Code Example 9: Delivery Speed Comparison with 95% CI

import matplotlib.pyplot as plt

providers = ['FastDrop Logistics', 'ReliableCourier Ltd']
mean_times = [28.4, 34.2]
ci_95 = [1.8, 2.2] # 95% Confidence interval half-widths

fig, ax = plt.subplots(figsize=(7, 4.5))

ax.bar(providers, mean_times, yerr=ci_95, capsize=7, color=['#e0f2fe', '#d1fae5'],
       edgecolor=['#0284c7', '#059669'], lw=2, width=0.45)

ax.set_title("Delivery Speed with 95% Confidence Intervals", fontweight='bold')
ax.set_ylabel("Average Delivery Time (Hours)")
ax.set_ylim(0, 45)
ax.grid(True, linestyle='--', alpha=0.3, axis='y')

plt.show()

⏱️ Section J — Line Plots for Scientific Measurements

Scientific experiments mein jab X-axis ordered sequence (jaise continuous time ya pressure increments) hota hai, toh line plot ke sath model tolerance bands draw karna standard practice hai.

Figure 17.10: 24-hour scientific telemetry curve with shaded tolerance bands (fill_between) and operational alert ceiling.

Code Example 10: Shaded Confidence Bands via fill_between()

import matplotlib.pyplot as plt
import numpy as np

time_hrs = np.linspace(0, 24, 50)
nominal = 25.0 + 4.0 * np.sin(np.pi * time_hrs / 12)
lower = nominal - 0.8
upper = nominal + 0.8

fig, ax = plt.subplots(figsize=(8.5, 4.5))

ax.plot(time_hrs, nominal, color='#0284c7', lw=2, label='Nominal Model')
ax.fill_between(time_hrs, lower, upper, color='#bae6fd', alpha=0.5, label='95% Model Tolerance Band (±0.8°C)')

ax.set_title("Environmental Chamber Temperature Stability", fontweight='bold')
ax.set_xlabel("Elapsed Operating Hours")
ax.set_ylabel("Temperature (°C)")
ax.grid(True, linestyle='--', alpha=0.35)
ax.legend()

plt.show()

🪟 Section K — Scientific Comparison Using Subplots

Scientific reporting ka golden design pattern hai: Sequence plot + Marginal distribution side-by-side.

Figure 17.11: Multi-panel integration: Continuous process sequence on the left synchronized with a rotated marginal distribution on the right (sharey=ax1).

Code Example 11: Time Sequence with Rotated Marginal Histogram

import matplotlib.pyplot as plt
import matplotlib.gridspec as gridspec
import numpy as np

hours = np.linspace(1, 100, 100)
temp = 24.0 + 3.0 * np.sin(hours / 10) + np.random.normal(0, 0.7, 100)

ax2.hist(temp, bins=15, orientation='horizontal', color='#7c3aed', edgecolor='white')
ax2.set_title("Marginal Spread", fontweight='bold')

🚨 Section L — Outlier Detection & Robust Interpretation

Ek unusual reading dekhkar student aksar bolte hain: "Ye toh outlier hai, isko code se delete kar dete hain!" Warning: Kabhi bhi outliers ko bina investigate kiye delete mat karo! Anomaly detection (fraud, server crash, medical alert) hi aksar data science ka sabse valuable insight hota hai.

Figure 17.12: Identifying network spikes beyond the 1.5×IQR fence boundary on scatter and boxplot representations.

The 1.5×IQR Mathematical Threshold

q1 = np.percentile(data, 25)
q3 = np.percentile(data, 75)
iqr = q3 - q1
upper_fence = q3 + 1.5 * iqr
lower_fence = q1 - 1.5 * iqr

# Points beyond fences are flagged as potential outliers
outliers = data[(data > upper_fence) | (data < lower_fence)]

✨ Section M — Scientific Visualization Design Principles

Scientific data present karte waqt integrity aur clarity sabse badi priority honi chahiye. Deceptive practices se bachein:

Figure 17.13: Ethical design comparison. Deceptive truncated Y-axis exaggerates a 2% difference (Left) vs. Honest zero baseline with 95% CI error bars (Right).
Deceptive Practice (Avoid!) Kyun Galat Hai? Honest Scientific Practice
Truncated Y-Axis on Bar Charts 90% se shuru karke 2% difference ko 5 guna bada dikhana reader ko cheat karta hai. Bar charts must start at zero (ylim=(0, max)).
Missing Measurement Units Reader ko nahi pata ki '24' Celsius hai ya Fahrenheit ya Hours. Always label with units: Temperature (°C), Latency (ms).
Arbitrary Unlabeled Error Bars Reader ko pata nahi chalta ki error bar Standard Deviation hai ya CI. Always state in caption: "Error bars represent ±1 Standard Deviation".

⚠️ Section O — Common Mistakes & Debugging

Mistake / Error Kyun Hota Hai? (Root Cause) Instant Fix
Deceptive Truncated Y-Axis Y-axis ko 90 se start kar diya, jisse 2% difference 5 guna bada dikhta hai. Bar charts mein hamesha zero-baseline use karein: ylim=(0, max).
Confusing SD, SE & CI Standard Deviation (data spread), Standard Error (mean uncertainty), aur CI (confidence) ko mix kar diya. Always document clearly: "yerr represents 95% Confidence Interval".
Heatmap Without Colorbar imshow() call kiya lekin fig.colorbar() bhool gaye. Colors ka scale unreadable ho gaya. Always attach a labeled colorbar: fig.colorbar(im, ax=ax).
Blindly Deleting Outliers Jo data 1.5×IQR se bahar tha usse error maan kar delete kar diya. Outliers ko highlight karke investigate karein (often system anomalies/spikes).

10 Conceptual Multiple-Choice Questions (MCQs)

  1. Agar do classes ka average score 75% hai, toh kya dono ka performance identical hai?
    A) Haan, hamesha identical hota hai
    B) Nahi, distribution aur spread alag ho sakte hain (Flaw of averages)
    C) Sirf agar class size 10 ho
    D) Sirf private schools mein
    Answer: B (Identical mean can hide unimodal vs bimodal distributions).
  2. Right-skewed distribution mein mean aur median ke beech kya relation hota hai?
    A) Mean < Median
    B) Mean = Median
    C) Mean > Median
    D) Mean = 0
    Answer: C (Extreme high values pull the mean towards the right tail).
  3. Box plot mein middle 50% data ka range kya kehlata hai?
    A) Standard Deviation
    B) Interquartile Range (IQR = Q3 - Q1)
    C) Z-score
    D) Variance
    Answer: B (IQR represents Q3 minus Q1).
  4. Conventional boxplot mein potential outliers kis threshold ke bahar maane jaate hain?
    A) 1.0 × IQR
    B) 1.5 × IQR beyond Q1 or Q3
    C) 3.0 × Standard Deviation
    D) 100 points
    Answer: B (Tukey's 1.5 × IQR fence rule).
  5. Box plot ke muqable Violin plot ka sabse bada advantage kya hai?
    A) Wo kam memory leta hai
    B) Wo distribution ki internal shape (jaise bimodal dual peaks) ko reveal karta hai
    C) Usme numbers nahi hote
    D) Wo bina Matplotlib ke chalta hai
    Answer: B (Reveals KDE density shape).
  6. Pearson correlation coefficient (r) ki range kya hoti hai?
    A) 0 se 100
    B) 0 se 1
    C) -1.0 se +1.0
    D) -∞ se +∞
    Answer: C (-1.0 = perfect negative, +1.0 = perfect positive).
  7. Agar variable A aur variable B mein strong correlation (r = 0.90) hai, toh kya A ne B ko cause kiya hai?
    A) Haan, guaranteed causation hai
    B) Nahi, correlation does not establish causation
    C) Sirf agar dono integers hon
    D) Sirf physics experiments mein
    Answer: B (Correlation != Causation; lurking variables may exist).
  8. Error bar ke ends par horizontal cross-bar lagane ke liye kaunsa parameter use hota hai?
    A) barwidth
    B) capsize
    C) crossline
    D) fence
    Answer: B (e.g. capsize=5).
  9. Sample size N badhne par 95% Confidence Interval par kya asar padta hai?
    A) Interval chauda (wider) ho jata hai
    B) Interval patla (narrower/shrink) ho jata hai
    C) Interval gayab ho jata hai
    D) Koi farq nahi padta
    Answer: B (Standard error decreases as 1/sqrt(N)).
  10. Scientific bar chart banate waqt Y-axis ko zero se shuru karna kyun zaroori hai?
    A) Rule of thumb hai bina wajah
    B) Truncated axis bar heights ko distort karke chhota difference bohot bada dikha deta hai
    C) Python crash ho jata hai
    D) Matplotlib savefig fail ho jata hai
    Answer: B (Prevents visual deception).
