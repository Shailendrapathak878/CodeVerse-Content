Subplots & Multiple Axes

🪟 Section A — Introduction to Subplots: The Triad of Figure, Axes & Axis

Real-world data science mein ek single graph aksar poori story explain nahi kar sakta. Agar aap ek hi plot par student ke marks (0-100%), attendance (0-100%), aur weekly study hours (10-25 hrs) sab ek sath draw kar denge, toh reader confusing scales aur overlapping lines mein ulajh jayega.

Matplotlib ke architectural hierarchy ke teen core components samajhein:

  • Figure (पूरा कैनवास): Master canvas window ya physical sheet of paper jo sabhi charts, titles aur figure legends ko hold karta hai.
  • Axes (एक व्यक्तिगत प्लॉट): Figure ke andar ka ek specific plotting region jisme apna title, grid, lines, aur labels hote hain. Ek Figure mein multiple Axes ho sakte hain!
  • Axis (अक्ष रेखाएँ): Axes ke border par numerical scale lines (X-Axis aur Y-Axis) jo tick marks aur limits carry karti hain.
Analogy (अखबार का पन्ना): Figure ek newspaper ka poora front page hai. Har Axes ek alag news column ya photo story hai. Aur Axis us photo ke neeche scale ya caption line hai!

Figure 14.1: Left: cluttered single chart with 3 disparate metrics fighting for visual attention. Right: dedicated clean subplot providing focused, clear context.

🚀 Section B — Your First Subplot using plt.subplots()

Matplotlib mein subplots create karne ka standard, production-ready tareeqa hai plt.subplots(nrows, ncols):

import matplotlib.pyplot as plt

# 1. Single Axes
fig, ax = plt.subplots()

# 2. Side-by-side pair (1 row, 2 columns)
fig, (ax1, ax2) = plt.subplots(1, 2, figsize=(12, 4.5))

# 3. 2x2 Grid (2 rows, 2 columns)
fig, axes = plt.subplots(2, 2, figsize=(12, 8))

Dekhiye kaise 1 row aur 2 columns ka subplot pair revenue aur customer orders ko side-by-side cleanly correlate karta hai:

⚖️ Section E — Fair Comparisons: Sharing Axes with sharex & sharey

Jab aap do competing stores ya do student groups ka data side-by-side compare karte hain, toh agar unke Y-axes alag scale par honge, toh reader galat visual conclusion nikal lega!

Passing sharey=True ya sharex=True dono plots ke scale ko synchronize kar deta hai:

# Synchronize vertical heights for fair branch sales comparison
fig, (ax1, ax2) = plt.subplots(1, 2, figsize=(12, 4.5), sharey=True)

Figure 14.5: Fair comparison via sharey=True. Store A (Emerging) and Store B (Flagship) share an identical 0–50 Lakhs vertical scale, revealing the true performance gap honestly.

🏷️ Section F — Hierarchy of Titles, Labels & Legends

Multi-panel figures mein text labeling ka ek systematic structure hota hai:

  • fig.suptitle("Master Executive Title", fontsize=13): Poore dashboard ka master heading.
  • ax.set_title("Subplot Specific Title", fontsize=11): Individual chart ka context.
  • ax.set_ylabel(): Unit of measurement per panel.
  • ax.legend(): Local legend box for series disambiguation.

Figure 14.6: Coordinated dashboard with overarching fig.suptitle, dedicated panel titles, explicit Y-axis percentage units, and distinct legends.

📐 Section G — Controlling Spacing: tight_layout() & subplots_adjust()

Multi-chart layouts mein sabse common problem hoti hai: Subplot 1 ka X-axis label Subplot 2 ke title ke upar overlap ho jana!

Iska universal fix hai fig.tight_layout() jo subplots ke margins aur padding ko automatically calculate karta hai:

# Automatic padding calculation to prevent text collisions
fig.tight_layout(pad=2.0)

# Or manual fine-grained control of whitespace gaps:
fig.subplots_adjust(wspace=0.35, hspace=0.45)

Figure 14.7: Calibrated spacing via fig.tight_layout(pad=2.0). Both subplots breathe comfortably with zero label or title collision.

🔁 Section H — Automation: Looping Through Axes & Hiding Unused Ones

Agar aapke paas 5 products ka data hai aur aapne 2x3 grid (total 6 spots) create kiya hai, toh 6th spot par empty black box draw ho jayega! Production scripts mein hum loop chala kar data plot karte hain aur extra axes ko ax.set_visible(False) se chhipa dete hain:

fig, axes = plt.subplots(2, 3, figsize=(13, 7.5))
axes_flat = axes.flatten()

# Plot 5 products
for idx, (prod, vals) in enumerate(datasets.items()):
    axes_flat[idx].bar(quarters, vals)

# Hide the 6th unused subplot!
axes_flat[5].set_visible(False)
fig.tight_layout()

Figure 14.8: Automated loop over 5 product datasets in a 2x3 grid. The 6th unused subplot slot is cleanly hidden with ax.set_visible(False).

🧱 Section J — Advanced Irregular Layouts via GridSpec

Har dashboard regular uniform grid (jaise 2x2) me fit nahi hota. Kabhi-kabhi aapko ek Hero Master Chart chahiye hota hai jo poore top span par 2 columns cover kare, aur neeche do chote supporting charts hon. Yeh matplotlib.gridspec.GridSpec se banta hai:

import matplotlib.gridspec as gridspec

fig = plt.figure(figsize=(12, 7))
gs = gridspec.GridSpec(2, 2, height_ratios=[1.2, 1.0])

# Top master subplot spanning both columns: [0, :]
ax_top = fig.add_subplot(gs[0, :])

# Bottom-left: [1, 0]
ax_bl = fig.add_subplot(gs[1, 0])

# Bottom-right: [1, 1]
ax_br = fig.add_subplot(gs[1, 1])

Figure 14.10: Advanced GridSpec architecture. Top hero chart spans both columns showing executive revenue, supported below by regional bars and customer satisfaction curves.

🔀 Section K — Multiple Subplots vs. Secondary Y-Axis (ax.twinx())

Jab do metrics identical time horizon share karte hain lekin unke units completely alag hote hain—jaise Daily Traffic (Thousands) aur Checkout Conversion Rate (%)—tab hum ax.twinx() use karte hain:

Figure 14.11: Dual Y-Axis via ax.twinx(). Left axis (blue) measures visitor traffic in thousands, while right axis (green) tracks checkout conversion rate percentage with a unified legend.

Twin Axes Caveat: Secondary Y-axis sirf tab use karein jab dono variables ke beech direct correlation ho. Agar variables unrelated hain, toh do separate subplots create karna hamesha zyada honest aur readable hota hai!

⚠️ Section N — Common Subplot Mistakes & Debugging Guide

Figure 14.16: Left: unstandardized auto limits make minor changes appear as dramatic slopes. Right: standardized Y-axis limits (0 to 50) restore honest comparative context.

1. Indexing 1D as 2D

Mistake: plt.subplots(1, 2) me axes[0, 1] access karna.
Fix: 1 row layout 1D array hota hai: axes[0] aur axes[1].

2. Overlapping Subplot Labels

Mistake: Titles aur axis labels ka ek dusre par crash ho jana.
Fix: Always call fig.tight_layout(pad=2.0) before show/save.

3. Unhidden Unused Axes

Mistake: 5 charts ke liye 2x3 grid banana aur 6th spot par empty black frame chhodna.
Fix: Call axes_flat[5].set_visible(False).

4. Missing suptitle Breathing Room

Mistake: fig.suptitle ka top row charts ke labels par overlap ho jana.
Fix: Set y=1.02 and adjust rect=[0, 0, 1, 0.96] in tight_layout.

10 Conceptual Multiple-Choice Questions (MCQs)

1. Matplotlib me Figure aur Axes ke beech kya primary difference hai?
A) Figure ek line hoti hai, Axes pura page
B) Figure master canvas hai jo multiple individual subplots (Axes) ko contain kar sakta hai
C) Dono identical hote hain
D) Axes sirf 3D graphs ke liye hota hai
Answer: B • Figure is the overall canvas window; Axes is an individual plotting region inside it.
2. plt.subplots(1, 2) call karne par axes ka dimension kya hota hai?
A) 2D array of shape (1, 2)
B) 1D array of length 2: [ax1, ax2]
C) Single Axes object
D) Dictionary
Answer: B • By default, a single row or column produces a 1D array of Axes.
3. 2x2 grid me bottom-left subplot ko access karne ka correct index kaunsa hai?
A) axes[0, 1]
B) axes[1, 0]
C) axes[2, 1]
D) axes[1, 1]
Answer: B • Row index 1 (second row) and Column index 0 (first column) represents bottom-left.
4. Subplots ke titles aur labels ke beech collision ko automatically resolve karne ke liye kaunsa method call karte hain?
A) plt.autospace()
B) fig.tight_layout()
C) ax.clear_collision()
D) plt.spread()
Answer: B • fig.tight_layout() computes optimal margins and inter-subplot padding.
5. 2x3 grid me 5 charts plot karne ke baad 6th empty subplot ko chhipane ke liye kya use karenge?
A) ax.delete()
B) ax.set_visible(False)
C) plt.remove_axis(6)
D) ax.hide_frame()
Answer: B • ax.set_visible(False) hides the unused Axes completely.
6. Do branches ki sales ka fair vertical comparison karne ke liye subplots me kya pass karte hain?
A) equal_height=True
B) sharey=True
C) sync_scales=True
D) same_axis=True
Answer: B • sharey=True synchronizes vertical bounds and ticks across subplots.
7. Top master chart ko 2 columns span karane ke liye kaunsa Matplotlib module use hota hai?
A) matplotlib.spanner
B) matplotlib.gridspec.GridSpec
C) plt.supergrid()
D) ax.expand_columns()
Answer: B • GridSpec allows custom irregular row and column spanning.
8. Ek hi graph canvas par Daily Traffic aur Conversion Rate (%) ke liye secondary right Y-axis create karne ka method kaunsa hai?
A) ax.add_right_axis()
B) ax.twinx()
C) plt.secondary_y()
D) ax.split_y()
Answer: B • ax.twinx() creates a twin Axes sharing the X-axis with an independent Y-axis.
9. Poore multi-panel dashboard ka master figure title set karne ke liye kaunsa function use hota hai?
A) plt.master_title()
B) fig.suptitle()
C) ax.super_title()
D) plt.heading()
Answer: B • fig.suptitle() sets the figure-level overarching title.
10. Export karte waqt outside legends aur titles ko cut-off hone se bachane ke liye savefig me kya pass karte hain?
A) crop=False
B) bbox_inches="tight"
C) pad_all=True
D) full_view=True
Answer: B • bbox_inches='tight' computes the exact bounding box enclosing all text and legends.
