Annotations & Text

Transform raw charts into clear data stories: master ax.text(), targeted point callouts with ax.annotate(), arrow styles, coordinate transformations (transAxes), mathematical expressions with mathtext, and highlighted danger zones.

💡 Section A — Introduction: Graph Storytelling With Annotations

Ek graph bina annotations ke sirf numbers aur lines ka ek puzzle hota hai. Reader ko khud dhoondhna padta hai ki peak kahan hai, sudden drop kyu hua, ya critical threshold kahan cross hui.

Samjhein in text components ka core difference:

  • Title (शीर्षक): Graph ka overall subject batata hai (e.g. "Monthly E-Commerce Turnover (FY 2026)").
  • Axis Labels (अक्ष लेबल): Dimensions aur physical units explain karte hain (e.g. "Duration (Hours)", "Turnover (₹ Lakhs)").
  • Ordinary Text (ax.text): Canvas par kisi bhi location par generic notes, benchmarks ya summary stats print karta hai.
  • Annotation (ax.annotate): Ek specific data point ki taraf arrow point karke contextual story batata hai (e.g. "Diwali Festive Campaign Peak: ₹48 Lakhs").

Example 13.1: Raw Unannotated Plot vs. Annotated Storytelling

Dekhiye kaise ek single annotation chart ko guess-work se decision-making asset bana deti hai:

import matplotlib.pyplot as plt

months = ['Jan', 'Feb', 'Mar', 'Apr', 'May', 'Jun', 'Jul', 'Aug']
sales_lakhs = [22, 25, 24, 30, 48, 38, 35, 40]

fig, (ax1, ax2) = plt.subplots(1, 2, figsize=(13, 5), dpi=150)

# 1. Without Annotations (User has to search for peak)
ax1.plot(months, sales_lakhs, color='#64748b', marker='o', linewidth=2.2)
ax1.set_title("[Without Annotations] Raw Plot: Reader Must Guess Insights")
ax1.set_ylabel("Turnover (Lakhs ₹)")
ax1.grid(True, linestyle=':', alpha=0.4)

# 2. With Targeted Annotation and Callout Box
ax2.plot(months, sales_lakhs, color='#0284c7', marker='o', linewidth=2.5)
ax2.annotate(
    "Mid-Year Campaign Peak:\n₹48 Lakhs (Record High!)",
    xy=(4, 48), xytext=(4.3, 52),
    arrowprops=dict(facecolor='#dc2626', shrink=0.08, width=1.5, headwidth=7),
    fontsize=9, fontweight='bold', color='#991b1b',
    bbox=dict(boxstyle='round,pad=0.4', facecolor='#fef2f2', edgecolor='#f87171')
)
ax2.set_title("[With Annotations] Storytelling: Instant Clarity & Focus")
ax2.set_ylabel("Turnover (Lakhs ₹)")
ax2.set_ylim(15, 60)
ax2.grid(True, linestyle='--', alpha=0.45)

fig.tight_layout()
plt.show()

Figure 13.1: Left plot leaves the viewer searching for context. Right plot immediately focuses the eye on May's record-breaking campaign peak.

🏷️ Section B — Titles & Axis Labels: The Rule of Explicit Units

  • Separate Subplot Titles from Dashboard Super-Title: Har individual panel ka apna ax.set_title() hota hai, aur poore multi-panel dashboard ka master title fig.suptitle() se banta hai.

🎯 Section D — Precision Point Callouts with ax.annotate()

ax.annotate() Matplotlib ka sabse versatile function hai. Isme do distinct coordinate points hote hain jinko beginners aksar mix-up kar dete hain:

  • xy=(x, y): Wo point jisko arrow point kar raha hai (The actual target data point).
  • xytext=(x, y): Wo location jahan text callout box print hoga (The label position).
# The Anatomy of a Perfect Annotation
ax.annotate(
    "Viral Feature Launch Spike!\nVisitors: 58,000",
    xy=(5, 58),             # Target data point: Week 5, 58K users
    xytext=(5.6, 52),       # Text position offset away from point
    arrowprops=dict(
        facecolor='#0284c7',
        edgecolor='#0369a1',
        width=1.5,
        headwidth=8,
        shrink=0.08
    ),
    fontsize=9.5, fontweight='bold', color='#0c4a6e',
    bbox=dict(boxstyle='round4,pad=0.5', facecolor='#e0f2fe', edgecolor='#38bdf8')
)

Figure 13.4: Target point xy=(5, 58) highlighted with arrow originating from offset label box xytext=(5.6, 52).

🧭 Section F — Coordinate Systems: Data vs. Axes-Fraction (transAxes)

Aksar students jab graph ka viewing range (limits) change karte hain, toh unka status label screen se bahar gayab ho jata hai! Kyu? Kyunki unhone text ko Data Coordinates mein place kiya tha.

Axes-Fraction Coordinates (ax.transAxes):
(0, 0) bottom-left corner hota hai, aur (1, 1) top-right corner hota hai, chahe data range kuch bhi ho! Agar aapko "System Normal" ya watermark lagana hai jo hamesha top-right corner par fix rahe, toh transform=ax.transAxes use karein: 
# Fixed to the top-right corner regardless of data limits!
ax.text(
    0.98, 0.95,
    "SYSTEM HEALTH: OPTIMAL\nEngine: Node-04",
    transform=ax.transAxes,
    fontsize=9, fontweight='bold', color='#065f46',
    ha='right', va='top',
    bbox=dict(boxstyle='square,pad=0.5', facecolor='#ecfdf5', edgecolor='#10b981')
)

Figure 13.6: Comparison: Peak load label uses data coordinates (Day 11, 92%). The top-right System Health badge uses ax.transAxes (0.98, 0.95) and stays anchored even if data ranges shift.

🛡️ Section H — Highlighting Important Regions (Spans & Thresholds)

Single point ke bajaye jab poora range highlight karna ho—jaise "Unsafe Temperature Zone" ya "Festive Overclock Interval"—tab hum Span methods use karte hain:

  • ax.axhline(y, ...): Poore plot par horizontal benchmark line draw karta hai.
  • ax.axvline(x, ...): Vertical timestamp line draw karta hai.
  • ax.axhspan(ymin, ymax, ...): Horizontal shaded band create karta hai (e.g. danger zone above 35°C).
  • ax.axvspan(xmin, xmax, ...): Vertical shaded interval create karta hai (e.g. Days 8 to 11).

Figure 13.8: Combined region highlights: Horizontal red hazard zone (> 35°C) via ax.axhspan(), and vertical orange overclock window (Days 8-11) via ax.axvspan().

📊 Section I — Annotating Bar Charts via ax.bar_label()

Modern Matplotlib mein bars ke upar exact numerical values print karne ke liye manual loops ki zaroorat nahi hai. Standard method hai ax.bar_label():

# 1. Vertical Bars
bars = ax.bar(categories, values, color='#0284c7')
ax.bar_label(bars, padding=3, fmt='%d', fontweight='bold')

# 2. Horizontal Bars
bars_h = ax.barh(categories, values, color='#059669')
ax.bar_label(bars_h, padding=5, fmt='%d students', fontweight='bold')

⚠️ Section L — Debugging Text Placement & Clipping Defects

Figure 13.12: Left: setting xy == xytext directly places text over the data point and clips it against the top boundary. Right: properly offsetting xytext with an arrow and expanding Y-limits ensures 100% readability.

1. xy equals xytext Bug

Mistake: Text ko usi point par likh dena jahan marker hai.
Fix: Hamesha offset coordinates dein (e.g. xytext=(x+0.5, y+5)).

2. Border Clipping

Mistake: Annotation text chart canvas ke edge se bahar cut jana.
Fix: Expand limits: ax.set_ylim(0, max_y * 1.2).

3. Arrow Pointing to Nowhere

Mistake: xy aur xytext ke coordinates swap ho jana.
Fix: Remember: xy is the target; xytext is the box.

4. Disappearing Status Badges

Mistake: Status text data coordinates me likhna jo limits change hote hi gayab ho jaye.
Fix: Use transform=ax.transAxes for fixed corner badges.

10 Conceptual Multiple-Choice Questions (MCQs)

1. ax.annotate() me xy argument kya represent karta hai?
A) Text callout box ki position
B) Target data point jahan arrow point kar raha hai
C) Figure canvas ka center
D) Legend ki position
Answer: B • xy is the target data point; xytext is where the text box is placed.
2. Agar hum xy aur xytext dono ko identical coordinates de dein, toh kya hoga?
A) Error throw hoga
B) Text directly marker ke upar draw ho kar point ko chhipa dega
C) Arrow automatically gayab ho jayega
D) Graph blank ho jayega
Answer: B • Text will overlap and obscure the data point. Always offset xytext!
3. Graph ke top-right corner par watermark ya status badge lagane ke liye kaunsa transform use hota hai?
A) transform=ax.transData
B) transform=ax.transAxes
C) transform=plt.transWindow
D) transform=None
Answer: B • ax.transAxes uses relative 0 to 1 fractions, staying anchored regardless of data limits.
4. Text ke peeche colored background box draw karne ke liye kaunsa parameter use hota hai?
A) background='red'
B) box=True
C) bbox=dict(...)
D) fill='solid'
Answer: C • bbox dictionary controls boxstyle, facecolor, edgecolor, and padding.
5. Shaded hazard band (e.g. 35°C to 50°C) highlight karne ke liye kaunsa method use hota hai?
A) ax.axhspan(35, 50)
B) ax.axvline(35)
C) ax.shade(35, 50)
D) plt.band(35, 50)
Answer: A • ax.axhspan() creates horizontal shaded rectangular bands across the entire axis width.
6. Bars ke upar direct values print karne ke liye modern Matplotlib function kaunsa hai?
A) ax.print_bars()
B) ax.bar_label(bars)
C) plt.label_all()
D) ax.tag_bars()
Answer: B • ax.bar_label() automatically positions values above vertical or horizontal bars.
7. Curved arrow draw karne ke liye connectionstyle me kya specify karte hain?
A) connectionstyle='curve'
B) connectionstyle='arc3,rad=0.3'
C) connectionstyle='bend=30'
D) arrowstyle='round'
Answer: B • arc3 with a radian factor creates smooth curved arrows.
8. Matplotlib title me mathematical formula (jaise $\mu, \sigma$) display karne ke liye text ko kaise likhte hain?
A) Raw string inside dollar signs: r"$f(x) = \mu$"
B) latex.format("...")
C) math.formula("...")
D) HTML tags <math>
Answer: A • Mathtext parses LaTeX-like mathematical expressions inside dollar signs.
9. Arrowhead aur data point ke beech thoda gap chhodne ke liye kaunsa parameter use hota hai?
A) shrinkB
B) gap=10
C) arrow_padding=5
D) margin=2
Answer: A • shrinkB shrinks the arrow away from the target point xy.
10. Multi-panel figure ka master dashboard title set karne ke liye kaunsa function use hota hai?
A) plt.bigtitle()
B) fig.suptitle("...")
C) ax.super_title()
D) fig.set_master()
Answer: B • fig.suptitle() sets the figure-level overarching title across subplots.

5 Practical Coding Challenges (With Hints)

  1. Challenge 1 (Easy): Ek line graph me minimum value point ki taraf arrow point karein with label "Yearly Minimum".
    Hint: Find index of min(data) and pass to ax.annotate(..., xy=(min_x, min_y)).
  2. Challenge 2 (Easy): Bar chart banayein aur har bar par value ke sath '%' symbol add karein.
    Hint: Use ax.bar_label(bars, fmt='%d%%').
  3. Challenge 3 (Intermediate): Ek chart ke top-left corner par fixed timestamp lagayein jo data zoom hone par bhi hamesha wahi rahe.
    Hint: Use ax.text(0.02, 0.95, "Timestamp: ...", transform=ax.transAxes).
  4. Challenge 4 (Intermediate): Simulated sensor data me 30°C se 40°C ke beech safe operating zone ko green transparent color me highlight karein.
    Hint: Use ax.axhspan(30, 40, color='green', alpha=0.25).
  5. Challenge 5 (Advanced): Scatter plot me sirf top 5% revenue generating customers ko curved red arrows se spotlight karein bina baaki points ko label kiye.
    Hint: Loop over filtered points and call ax.annotate() with connectionstyle='arc3,rad=0.2'.
