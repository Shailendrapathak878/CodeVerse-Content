1. Introduction: Find the Records That Matter

Imagine kijiye ki aap ek University ke Examination Cell mein Head Data Analyst hain. Semester exams ke baad aapke paas 5,000 students ka master records table aata hai. University Chancellor aur Deans aapse 5 critical business questions puchte hain:

  1. "Poore college mein sabse highest marks kis student ke aaye hain?" → Sorting (Descending order)
  2. "Kaun se students exam dene ke ineligible hain kyunki unki attendance 75% se kam hai?" → Filtering (attendance < 75)
  3. "Scholarship ke liye eligible students kaun hain jinhone 85+ marks aur 80%+ attendance dono maintain ki hai?" → Compound Filtering (Condition A & Condition B)
  4. "Class mein 1st, 2nd, aur 3rd rank kiski aayi hai, aur agar do students ke 95 marks barabar hain toh tie kaise break hoga?" → Ranking with Tie-Breakers
  5. "Computer Science aur AI department ke sabhi students ka batch list dijiye." → Set Membership Filtering (isin(['CS', 'AI']))

Yeh sabhi questions data science ki teen foundational operations par depend karte hain: Sorting, Ranking, aur Filtering. In teeno ka difference samajhna bohot zaroori hai:

Figure 7.1: The Three Core Data Operations — Sorting (Reorder), Ranking (Position Metric), and Filtering (Subset Selection).
The Three Pillars Defined
  • Sorting: Table ki rows ke physical sequence ko badalta hai (jaise highest marks sabse upar, ya alphabetical A-Z order).
  • Ranking: Rows ki physical order ko badle bina har row ko ek official numeric position (1.0, 2.0, 3.0...) assign karta hai, aur equal values (ties) ko mathematically resolve karta hai.
  • Filtering: Sirf unhi records ko retain karta hai jo specific criteria ya business conditions ko satisfy karte hain, aur baki rows ko omit kar deta hai.

Chaliye in teeno pillars ko step by step practical python code, verified outputs, aur industrial mini-projects ke saath detail mein master karte hain!

2. Sorting with sort_values()

DataFrame ki rows ko kisi specific column ki values ke hisaab se reorder karne ke liye Pandas ka sabse common method DataFrame.sort_values() hai.

Figure 7.2: Visualizing sorting direction — ascending=True (lowest to highest) vs ascending=False (highest to lowest).

Core Parameters of sort_values()

  • by='column_name': Kis column ke aadhar par sort karna hai. Yeh single string ya list of strings ho sakta hai.
  • ascending=True: Default behavior. Numbers ko chote se bada (1 to 100) aur text ko alphabetical order (A to Z) mein arrange karta hai.
  • ascending=False: Reverse order. Numbers ko highest to lowest (100 to 1) aur text ko reverse alphabetical (Z to A) mein arrange karta hai.
  • inplace=False: Default behavior. Yeh ek naya sorted DataFrame return karta hai, original DataFrame ko modify nahi karta. Data science mein hamesha naya object return karna safe hota hai taaki original raw data intact rahe.

Example 1: Sorting Student Marks (Ascending vs Descending)

sort_students.py Python 3 • Pandas 
import pandas as pd

# 1. Create a synthetic student dataset
students_raw = {
    'student_id': ['S101', 'S102', 'S103', 'S104', 'S105', 'S106'],
    'name': ['Aarav', 'Diya', 'Rohan', 'Ananya', 'Kabir', 'Meera'],
    'department': ['CS', 'IT', 'CS', 'ECE', 'IT', 'CS'],
    'marks': [88, 94, 76, 85, 91, 68],
    'attendance': [92, 96, 85, 90, 88, 75]
}
df_students = pd.DataFrame(students_raw)

# 2. Sort by marks ascending (lowest first)
sort_asc = df_students.sort_values(by='marks', ascending=True)
print("--- Sorted by Marks Ascending (Lowest First) ---")
print(sort_asc[['student_id', 'name', 'marks']])

# 3. Sort by marks descending (highest first)
sort_desc = df_students.sort_values(by='marks', ascending=False)
print("\n--- Sorted by Marks Descending (Leaderboard) ---")
print(sort_desc[['student_id', 'name', 'marks']])
Verified Execution Output:
--- Sorted by Marks Ascending (Lowest First) --- student_id name marks 5 S106 Meera 68 2 S103 Rohan 76 3 S104 Ananya 85 0 S101 Aarav 88 4 S105 Kabir 91 1 S102 Diya 94 --- Sorted by Marks Descending (Leaderboard) --- student_id name marks 1 S102 Diya 94 4 S105 Kabir 91 0 S101 Aarav 88 3 S104 Ananya 85 2 S103 Rohan 76 5 S106 Meera 68

Notice Row Index Retention: Dhyan dijiye ki descending sort mein Diya ka row index 1 sabse upar chala gaya, aur Meera ka index 5 sabse niche. Pandas sorting ke baad original row index numbers ko preserve karta hai!

3. Sorting by Multiple Columns with Mixed Directions

Real-world datasets mein do records ki primary value aksar identical ho sakti hai (jaise do students ke 95 marks ya do products ki same price). Aise cases mein tie-break karne ke liye hum Multiple Column Sorting use karte hain.

Figure 7.3: Primary Key and Secondary Key Evaluation — Secondary column is evaluated only when the primary key produces a tie.

Evaluation Order & Mixed Directions

  • by=['col1', 'col2']: Pehle rows col1 ke hisaab se sort hongi. Agar col1 mein values distinct hain, toh col2 ko dekha bhi nahi jayega. col2 sirf tab evaluate hota hai jab col1 mein tie (equal values) ho!
  • ascending=[True, False]: Aap har column ke liye individual sorting direction specify kar sakte hain boolean list pass karke.

Example 1: Student Leaderboard with Attendance Tie-Breaker

Aarav, Diya, Kabir aur Rohan ke beech marks tie hone par attendance tie-breaker kaise kaam karta hai dekhiye:

sort_tiebreaker.py Python 3 • Pandas 
import pandas as pd

leaderboard_raw = {
    'student_id': ['S1', 'S2', 'S3', 'S4', 'S5', 'S6'],
    'name': ['Aarav', 'Diya', 'Rohan', 'Ananya', 'Kabir', 'Meera'],
    'marks': [90, 95, 90, 85, 95, 90],  # Ties at 95 and 90
    'attendance': [88, 92, 95, 90, 96, 82]
}
df_board = pd.DataFrame(leaderboard_raw)

# Primary: marks descending, Secondary: attendance descending
sorted_board = df_board.sort_values(by=['marks', 'attendance'], ascending=[False, False])
print("--- Leaderboard (Marks Desc, then Attendance Desc) ---")
print(sorted_board[['name', 'marks', 'attendance']])
Verified Execution Output:
--- Leaderboard (Marks Desc, then Attendance Desc) --- name marks attendance 4 Kabir 95 96 1 Diya 95 92 2 Rohan 90 95 0 Aarav 90 88 5 Meera 90 82 3 Ananya 85 90

Step-by-Step Tie Analysis:

  1. Diya aur Kabir dono ke 95 marks the. Secondary sorting attendance par hui: Kabir (96%) ne Diya (92%) ko beat kar diya aur Rank 1 position li!
  2. Rohan, Aarav, aur Meera teeno ke 90 marks the. Attendance ke hisaab se order bana: Rohan (95%) → Aarav (88%) → Meera (82%).

4. Sorting with sort_index()

Jab aap column values ke bajaye DataFrame ke Index labels ko arrange karna chahte hain, toh df.sort_index() use hota hai.

Figure 7.4: df.sort_values() (Content-based reordering) vs df.sort_index() (Label-based reordering).

When is sort_index() Useful?

  • Jab aapne sort_values() kiya tha aur rows ka index jumble ho gaya (e.g., 4, 1, 2, 0, 5), aur aap use wapas original sequential index order mein lana chahte hain.
  • Jab aapka index custom labels hai, jaise 'STU-101', 'STU-102', ya dates (Time-Series data).

Example 1: Sorting Custom Student IDs Index

sort_index_demo.py Python 3 • Pandas 
import pandas as pd

df_custom_idx = pd.DataFrame({
    'name': ['Diya', 'Aarav', 'Meera', 'Kabir'],
    'marks': [94, 88, 68, 91]
}, index=['STU-104', 'STU-101', 'STU-108', 'STU-102'])

print("--- Original Unsorted Index ---")
print(df_custom_idx)

# Sort by index ascending
sorted_idx = df_custom_idx.sort_index(ascending=True)
print("\n--- Sorted by Index (STU-101 to STU-108) ---")
print(sorted_idx)
Verified Execution Output:
--- Original Unsorted Index --- name marks STU-104 Diya 94 STU-101 Aarav 88 STU-108 Meera 68 STU-102 Kabir 91 --- Sorted by Index (STU-101 to STU-108) --- name marks STU-101 Aarav 88 STU-102 Kabir 91 STU-104 Diya 94 STU-108 Meera 68
Alphabetical vs Chronological Month Sorting
Agar aapke index par month names strings ke roop mein hain ('January', 'February', 'March', 'April'), aur aap sort_index() chalate hain, toh Pandas unhe alphabetically sort karega: April, February, January, March! Yeh calendar chronological order nahi hai! Chronological order ke liye hamesha proper datetime index (pd.to_datetime()) use karein.

5. Ranking with rank() and Tie-Breaking Methods

Aksar students sochte hain ki Sorting aur Ranking ek hi cheez hai. Lekin data science aur business reporting mein dono bilkul alag hain:

Figure 7.5: Sorting rearranges physical table rows; Ranking adds a numerical standing column while preserving row positions.

How rank() Works

Jab aap Series.rank(ascending=False) call karte hain, toh highest value ko rank 1 milta hai. Lekin jab do values equal hoti hain (ties), toh Pandas unhe kaise rank karega? Iske liye 5 distinct method options hain:

Figure 7.6: Step-by-step comparison of all 5 tie-breaking methods in Pandas rank().
Method Tie-Breaking Algorithm Scores: [95, 90, 90, 85, 80] Ranks Typical Real-World Use Case
average (Default) Tied positions ka mathematical average assign karta hai. [1.0, 2.5, 2.5, 4.0, 5.0] Statistical analysis & non-parametric tests (Spearman correlation).
min Tied positions mein se lowest rank number deta hai (Sports rank). [1, 2, 2, 4, 5] Olympic medals & competitive exams (Joint 2nd rank; next is 4th).
max Tied positions mein se highest rank number assign karta hai. [1, 3, 3, 4, 5] Worst-case qualification scenarios.
first Table mein jo row pehle aati hai use pehla rank milta hai. [1, 2, 3, 4, 5] Arbitrary single-winner tie-breaking without duplicates.
dense Ranks hamesha +1 se increment hoti hain, koi gap nahi chhodti! [1, 2, 2, 3, 4] Corporate sales tiers, performance bands (Gold, Silver, Bronze).

Example 1: Demonstrating All 5 Ranking Methods on Tied Scores

compare_rank_methods.py Python 3 • Pandas 
import pandas as pd

tie_data = pd.DataFrame({
    'student': ['Aarav', 'Diya', 'Rohan', 'Ananya', 'Kabir'],
    'score': [90, 85, 90, 95, 80]  # Aarav and Rohan tied at 90
})

s = tie_data['score']
tie_data['rank_avg'] = s.rank(ascending=False, method='average')
tie_data['rank_min'] = s.rank(ascending=False, method='min').astype(int)
tie_data['rank_dense'] = s.rank(ascending=False, method='dense').astype(int)

print("--- Ranking Comparison on Tied Scores ---")
print(tie_data)
Verified Execution Output:
--- Ranking Comparison on Tied Scores --- student score rank_avg rank_min rank_dense 0 Aarav 90 2.5 2 2 1 Diya 85 4.0 4 3 2 Rohan 90 2.5 2 2 3 Ananya 95 1.0 1 1 4 Kabir 80 5.0 5 4

Notice the Gap in 'min' vs No Gap in 'dense':

  • rank_min mein Aarav aur Rohan dono ko Rank 2 mila, lekin agli student Diya ko Rank 4 mila (Rank 3 skip ho gaya kyunki 2 students ne positions 2 aur 3 occupy kar li theen).
  • rank_dense mein Aarav aur Rohan ko Rank 2 mila, aur agli student Diya ko Rank 3 mila (koi gap nahi aaya)!

6. Filtering Using Comparison Operators & Boolean Masks

Data science mein 90% analysis dataset ke ek specific subset par ki jaati hai (jaise sirf specific department, sirf high-spending customers, ya sirf defacing errors). Pandas mein rows ko filter karne ka standard tareeqa Boolean Masking kehlata hai.

Figure 7.7: The Boolean Masking Pipeline — Source rows are matched against a condition to create a True/False series, retaining only True rows.

Comparison Operators in Pandas

Aap kisi bhi column par standard comparison operators use karke boolean series generate kar sakte hain:

  • == (Equal to): df['dept'] == 'CS'
  • != (Not equal to): df['dept'] != 'Mech'
  • > (Greater than): df['marks'] > 85
  • < (Less than): df['attendance'] < 75
  • >= (Greater than or equal to): df['marks'] >= 90
  • <= (Less than or equal to): df['price'] <= 1000
Figure 7.9: Single-condition filtering — Flagging students with attendance under 75%.

Example 1: Flagging Attendance Warning (< 75%)

filter_attendance.py Python 3 • Pandas 
import pandas as pd

# 1. Generate Boolean Mask
mask = df_students['attendance'] < 80
print("Boolean Mask Series:\n", mask)

# 2. Filter rows satisfying the mask
flagged = df_students[mask]
print("\n--- Flagged Students (Attendance < 80%) ---")
print(flagged[['student_id', 'name', 'attendance']])
Verified Execution Output:
Boolean Mask Series: 0 False 1 False 2 False 3 False 4 False 5 True Name: attendance, dtype: bool --- Flagged Students (Attendance < 80%) --- student_id name attendance 5 S106 Meera 75
Filtering is Non-Destructive!
Jab aap df[df['marks'] >= 85] likhte hain aur result display hota hai, toh iska matlab yeh nahi hai ki baaki rows original DataFrame se delete ho gayi hain! Original df_students bilkul intact rehta hai. Agar aapko filtered result save karna hai, toh use naye variable mein assign karein: honors_df = df[df['marks'] >= 85].

7. Combining Multiple Conditions: & (AND), | (OR), and ~ (NOT)

Real-life business rules aksar multiple conditions ko combine karke banti hain (jaise: "Marks ≥ 85 hona chahiye AUR attendance ≥ 90% hona chahiye"). Yahan Python ke built-in keywords (and, or, not) nahi chalte, balki Pandas ke bitwise element-wise operators use hote hain!

Figure 7.8: Truth-table mechanics of Bitwise & (AND), | (OR), and ~ (NOT) in Pandas.
Mandatory Syntax Rule: Wrap Each Condition in Parentheses!
Python mein bitwise operators (&, |) ki operator precedence comparison operators (>=, ==) se zyada hoti hai. Agar aap parentheses nahi lagayenge (e.g., df['marks'] >= 85 & df['att'] >= 90), toh Python crash ho jayega: TypeError: cannot compare a dtyped series with a scalar!
Hamesha aise likhein: (df['marks'] >= 85) & (df['att'] >= 90)
Figure 7.10: Eligibility evaluation matrix combining marks and attendance with AND (&).

Example 1: Scholarship Eligibility (marks ≥ 85 AND attendance ≥ 90)

filter_and_condition.py Python 3 • Pandas 
import pandas as pd

# Combine with & (Both must be True)
scholarship_mask = (df_students['marks'] >= 85) & (df_students['attendance'] >= 90)
eligible_students = df_students[scholarship_mask]

print("--- Scholarship Eligible Students (Marks >= 85 AND Att >= 90) ---")
print(eligible_students[['name', 'department', 'marks', 'attendance']])
Verified Execution Output:
--- Scholarship Eligible Students (Marks >= 85 AND Att >= 90) --- name department marks attendance 0 Aarav CS 88 92 1 Diya IT 94 96 3 Ananya ECE 85 90

Example 2: Combining with | (OR) and ~ (NOT)

filter_or_not.py Python 3 • Pandas 
import pandas as pd

# 1. OR condition: Either in ECE OR marks > 90
or_mask = (df_students['department'] == 'ECE') | (df_students['marks'] > 90)
print("--- ECE Students OR Marks > 90 ---")
print(df_students[or_mask][['name', 'department', 'marks']])

# 2. NOT condition: All students NOT in CS department
not_cs_mask = ~(df_students['department'] == 'CS')
print("\n--- Students NOT in CS Department ---")
print(df_students[not_cs_mask][['name', 'department']])
Verified Execution Output:
--- ECE Students OR Marks > 90 --- name department marks 1 Diya IT 94 3 Ananya ECE 85 4 Kabir IT 91 --- Students NOT in CS Department --- name department 1 Diya IT 3 Ananya ECE 4 Kabir IT

8. Filtering Using isin(): Clean Set Membership

Agar aapko kisi column ko multiple values ke against check karna ho (jaise: department 'CS' ho, ya 'IT' ho, ya 'AI' ho), toh baar-baar | lagana bohot messy ho jata hai: (df['dept'] == 'CS') | (df['dept'] == 'IT') | (df['dept'] == 'AI'). Iska elegant, fast, aur Pythonic solution Series.isin() hai!

Figure 7.11: Set membership filtering using df['col'].isin(['CS', 'IT']) and its negation with ~.

How isin() Works

  • df['col'].isin(['val1', 'val2', 'val3']): Agar cell ki value list ke kisi bhi item se match karti hai, toh True return karta hai.
  • ~df['col'].isin(['val1', 'val2']): Tilde operator ~ lagane se yeh exclusion filter ban jaata hai (selects everything EXCEPT those values)!

Example 1: Selecting Tech Cohort (CS & IT Departments)

filter_isin.py Python 3 • Pandas 
import pandas as pd

target_depts = ['CS', 'IT']

# Select students belonging to target departments
tech_students = df_students[df_students['department'].isin(target_depts)]
print("--- Students in CS or IT Departments ---")
print(tech_students[['name', 'department', 'marks']])

# Exclude CS and IT using ~
non_tech_students = df_students[~df_students['department'].isin(target_depts)]
print("\n--- Excluded Students (Neither CS nor IT) ---")
print(non_tech_students[['name', 'department', 'marks']])
Verified Execution Output:
--- Students in CS or IT Departments --- name department marks 0 Aarav CS 88 1 Diya IT 94 2 Rohan CS 76 4 Kabir IT 91 5 Meera CS 68 --- Excluded Students (Neither CS nor IT) --- name department marks 3 Ananya ECE 85

9. Filtering with between(): Numerical Range Slicing

Jab aapko numerical values ko kisi range ke andar check karna ho (jaise: "Marks 80 se 90 ke beech hone chahiye"), toh standard expression (df['marks'] >= 80) & (df['marks'] <= 90) likhne ke bajaye aap Series.between(left, right) use kar sakte hain.

Figure 7.12: Range filtering with df['marks'].between(80, 90) showing inclusive boundary evaluation.

The inclusive Parameter Explained

  • inclusive='both' (Default): Lower bound aur Upper bound dono included hote hain ($left \le x \le right$).
  • inclusive='neither': Dono boundaries excluded hoti hain ($left < x < right$).
  • inclusive='left': Sirf lower bound included hota hai ($left \le x < right$).
  • inclusive='right': Sirf upper bound included hota hai ($left < x \le right$).

Example 1: Filtering Scores in the 80–90 Interval

filter_between.py Python 3 • Pandas 
import pandas as pd

# Filter students whose marks are in [80, 90]
range_students = df_students[df_students['marks'].between(80, 90)]
print("--- Students with Marks Between 80 and 90 (Inclusive) ---")
print(range_students[['name', 'department', 'marks']])
Verified Execution Output:
--- Students with Marks Between 80 and 90 (Inclusive) --- name department marks 0 Aarav CS 88 3 Ananya ECE 85

10. Filtering Using query(): English-Like Readable Queries

Jab boolean filter conditions bohot lambi aur complex ho jaati hain, toh baar-baar df['...'] aur parentheses likhna tedious ho jaata hai. Pandas iska solution deta hai: DataFrame.query(). Yeh ek SQL-like string expression accept karta hai jo padhne mein natural English jaisa lagta hai.

Figure 7.13: Readability comparison: Standard Boolean Indexing vs df.query() syntax with @variable referencing.

Key Features of query()

  • Natural Keywords: Aap and, or, aur not seedhe string ke andar use kar sakte hain (bitwise & aur | ki zaroorat nahi hoti).
  • Referencing Python Variables with @: Agar aapko Python script ke kisi variable ko query string ke andar use karna hai, toh uske aage @ lagaya jaata hai (e.g., @min_marks).
  • Equivalence: df.query() aur standard boolean indexing 100% identical results return karte hain.

Example 1: Scholarship Filtering with @variable Syntax

filter_query_demo.py Python 3 • Pandas 
import pandas as pd

min_m = 85
min_att = 90

# Filter using query with @variable references
query_res = df_students.query("marks >= @min_m and attendance >= @min_att")
print("--- Query Result (marks >= 85 and attendance >= 90) ---")
print(query_res[['name', 'department', 'marks', 'attendance']])

# Verify equivalence with standard boolean masking
standard_res = df_students[(df_students['marks'] >= min_m) & (df_students['attendance'] >= min_att)]
print(f"\nAre both filtering methods completely identical? {query_res.equals(standard_res)}")
Verified Execution Output:
--- Query Result (marks >= 85 and attendance >= 90) --- name department marks attendance 0 Aarav CS 88 92 1 Diya IT 94 96 3 Ananya ECE 85 90 Are both filtering methods completely identical? True

11. Filtering Missing and Non-Missing Values

Topic 6 mein humne seekha tha ki missing values ko detect kaise karte hain. Ab hum dekhenge ki missing rows ko alag karke audit kaise kiya jaata hai aur valid rows ko downstream analysis ke liye kaise filter kiya jaata hai.

Figure 7.14: Filtering missing records with df.isna() vs valid records with df.notna().
The IEEE 754 Floating-Point NaN Trap
Python aur Pandas mein np.nan == np.nan hamesha False hota hai! Isliye agar aap likhte hain: df[df['attendance'] == np.nan], toh aapko ek empty DataFrame milega! Missing values filter karne ke liye sirf aur sirf .isna() ya .isnull() use karein!

Example 1: Isolating Records with Missing Attendance

filter_missing_values.py Python 3 • Pandas 
import numpy as np
import pandas as pd

df_nulls = pd.DataFrame({
    'student_id': ['S1', 'S2', 'S3', 'S4'],
    'name': ['Aarav', 'Diya', 'Rohan', 'Ananya'],
    'attendance': [90.0, np.nan, 85.0, np.nan],
    'marks': [88.0, 94.0, 76.0, 85.0]
})

# 1. Filter students missing attendance
missing_att = df_nulls[df_nulls['attendance'].isna()]
print("--- Students with Missing Attendance (Need Investigation) ---")
print(missing_att[['student_id', 'name', 'marks']])

# 2. Filter students with valid attendance AND marks >= 80
valid_cohort = df_nulls[df_nulls['attendance'].notna() & (df_nulls['marks'] >= 80)]
print("\n--- Verified Eligible Students ---")
print(valid_cohort[['student_id', 'name', 'attendance', 'marks']])
Verified Execution Output:
--- Students with Missing Attendance (Need Investigation) --- student_id name marks 1 S2 Diya 94.0 3 S4 Ananya 85.0 --- Verified Eligible Students --- student_id name attendance marks 0 S1 Aarav 90.0 88.0

12. Combining Sorting, Ranking, and Filtering: Practical Workflows

Asal enterprise workflows mein yeh teeno tools kabhi akele use nahi hote. Ek typical data analysis pipeline mein Filter → Sort → Rank ka ek strict sequence hota hai.

Figure 7.15: The Industrial 3-Stage Pipeline — Filter first to isolate the valid cohort, Sort to organize, and Rank to assign merit standings.
Why Order of Operations Matters!
Agar aap 5,000 students ko pehle rank() kar dete hain aur uske baad low attendance wale students ko filter karke remove karte hain, toh aapki ranks corrupt ho jayengi (jaise Rank 1 aur Rank 2 filter ho gaye, toh pehla bacha hua student Rank 3 dikhayega)! Isliye hamesha ineligible records ko pehle FILTER karein, aur sirf eligible cohort par RANK assign karein!

Example 1: End-to-End Merit Board Pipeline

combined_pipeline.py Python 3 • Full Pipeline 
import pandas as pd

df_all = pd.DataFrame({
    'student_id': ['S101', 'S102', 'S103', 'S104', 'S105', 'S106', 'S107'],
    'name': ['Aarav', 'Diya', 'Rohan', 'Ananya', 'Kabir', 'Meera', 'Aditya'],
    'department': ['CS', 'IT', 'CS', 'ECE', 'IT', 'CS', 'Mech'],
    'marks': [90, 95, 78, 88, 95, 92, 85],
    'attendance': [88, 92, 85, 75, 96, 70, 84]  # Ananya (75) and Meera (70) ineligible
})

# 1. STAGE 1: FILTER (Attendance >= 80% eligibility)
df_eligible = df_all[df_all['attendance'] >= 80].copy()

16. Top 12 Beginner Mistakes & Pro Debugging Tips

Sorting, ranking, aur filtering mein beginners aksar in 12 traps mein phans jaate hain:

# Common Junior Mistake Why It Breaks Your Workflow Correct Pro Practice
1 Using Python and / or in DataFrame filters Raises ValueError: The truth value of a Series is ambiguous. Always use bitwise operators: & for AND, | for OR.
2 Forgetting parentheses in compound filters Raises TypeError: cannot compare a dtyped series with a scalar due to operator precedence. Always wrap every condition in brackets: (cond1) & (cond2).
3 Testing for missing values with df['col'] == np.nan Always evaluates to False for every single row because IEEE 754 NaN != NaN. Always use df['col'].isna() or df['col'].isnull().
4 Confusing Sorting with Ranking Sorting changes physical table row sequence; Ranking assigns a position metric. Use sort_values() to reorder; use rank() to calculate medal standings.
5 Ranking before filtering in merit calculations Disqualified students occupy top ranks, leaving gaps in the final filtered report. Always FILTER disqualified records first, then apply rank() on the eligible subset!
6 Using inplace=True without saving backups Permanently mutates the DataFrame, making it impossible to recover raw data on mistake. Avoid inplace=True; assign sorted results to descriptive variable names.
7 Assuming rank(method='min') produces contiguous ranks Tied values skip subsequent rank numbers (e.g., 1, 2, 2, 4). Use method='dense' if you need contiguous ranks without gaps (1, 2, 2, 3).
8 Writing repetitive chained ORs instead of isin() (df['x'] == 'A') | (df['x'] == 'B') | (df['x'] == 'C') is slow and error-prone. Use clean, vectorized df['x'].isin(['A', 'B', 'C']).
9 Forgetting @ prefix when referencing variables in query() Raises UndefinedVariableError because Pandas searches for a column name. Always prefix Python variable names with @ inside query strings: @min_val.
10 Believing alphabetical month sorting is chronological sort_index() sorts strings alphabetically: April, February, January, March! Convert date strings to true datetime using pd.to_datetime() before sorting.
11 Forgetting inclusive='both' default in between() Beginners accidentally include boundary values when they wanted strictly between. Explicitly specify inclusive='neither', 'left', or 'right' when needed.
12 Forgetting reset_index(drop=True) after sorting/filtering Jumbled index labels (e.g., 4, 1, 0, 5) confuse downstream row lookups with .iloc. Call .reset_index(drop=True) when clean 0-indexed sequential rows are required.

Glossary of Essential Technical Terms

  • Sorting: Table ki physical rows ke sequence ko kisi column ya index ke values ke according re-arrange karna.
  • Ranking: Rows ki physical order ko badle bina har row ko ek numerical position metric (1.0, 2.0...) assign karna.
  • Boolean Mask: Ek True aur False values ki Series jo condition evaluate karke generate hoti hai.
  • Dense Ranking (method='dense'): Ek ranking algorithm jo tied values ke baad rank numbers mein koi gap nahi chhodti (1, 2, 2, 3).
  • Min Ranking (method='min'): Sports competition ranking jo tied values ko lowest rank assign karti hai aur gaps chhodti hai (1, 2, 2, 4).
  • Bitwise Operators (&, |, ~): Element-wise logical operators jo Pandas Series ke boolean masks ko combine karne ke liye mandatory hote hain.
  • Query Expression: Ek text string jo DataFrame columns par condition evaluate karti hai (e.g., "marks >= @cutoff").
  • Tie-Breaker: Ek secondary column jo sirf tab evaluate hota hai jab primary sorting key par do ya zyada rows identical hoti hain.
