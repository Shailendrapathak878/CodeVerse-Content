1. Introduction: Finding the Exact Information You Need

Imagine kijiye aap ek bade engineering college ke examination cell mein data analyst hain. Aapke database mein 1,000 students ke records hain: unke student_id, student_name, department, semester marks, attendance percentage, aur daily study_hours.

Aapke Principal aur Department HODs aapse roz alag-alag sawal puchte hain:

  • "Sirf Computer Science (CS) department ke students ke marks dikhaiye!"
  • "Aarav Sharma naamak student ki attendance kitni hai?"
  • "Un sabhi students ki list nikaliye jinke marks 80 se zyada hain aur attendance 85% se upar hai!"
  • "Top 5 highest scoring students kaun hain?"
  • "Student ID 'STU104' ke pure academic credentials fetch kijiye!"

Agar aapko pure 1,000 rows ko baar-baar print ya loop karke search karna pade, toh analysis bohot slow, error-prone aur exhausting ho jayegi. Yahi par Pandas ka Indexing and Selecting Engine hamara sabse shaktishaali tool banta hai!

Figure 4.1: The 4-stage data selection lifecycle from whole DataFrame to targeted insights.
The Fundamental Purpose of Selection:

Indexing aur Selecting ka maksad hota hai: pure bulky DataFrame mein se exact targeted rows aur columns ko isolate karna bina memory waste kiye, taaki aap specific calculations, filtering, visualizations, ya business reports bina kisi delay ke execute kar sakein.

The Three Selection Philosophies in Pandas:

Pandas data extraction ke liye teen mukhya tarike provide karta hai:

  1. Label-Based Selection (.loc[]): Row aur column ke explicit names ya labels ke zariye data dhundna (jaise phonebook mein naam se search karna).
  2. Integer-Position Selection (.iloc[]): Zero-based numerical offsets (0, 1, 2...) ke zariye data dhundna (jaise array ke memory index se access karna).
  3. Boolean Conditional Selection (df[condition]): Logical rules aur mathematical filters (jaise marks >= 80) ke zariye matching records extract karna.

2. Understanding Columns and Rows in a 2D DataFrame

Ek Pandas DataFrame do dimensions (axes) par kaam karta hai:

  • Axis 0 (Rows / Index): Horizontal records ko represent karta hai. Har row ka ek unique index label aur zero-based integer position hota hai.
  • Axis 1 (Columns): Vertical features ya attributes ko represent karta hai (jaise marks, department). Har column ka ek string ya integer header name hota hai.
Figure 4.2: Row selection paradigms — Label-based targeting (.loc) vs Position-based offsets (.iloc).

Column Selection vs Row Selection: The Output Shape Difference

Pandas mein selection karte waqt sabse pehli baat jo dhyan rakhni hoti hai woh hai Return Type:

  • Single Column Selection: Agar aap ek single column select karte hain (df['marks']), toh Pandas ek 1D pd.Series return karta hai.
  • Multiple Columns Selection: Agar aap columns ki list pass karte hain (df[['student_name', 'marks']]), toh Pandas ek 2D pd.DataFrame return karta hai (chahe list mein 1 hi column kyu na ho!).
  • Row Selection: Rows ko access karne ke liye normal brackets df[...] direct use nahi kiye jaate; balki explicit indexers .loc[] ya .iloc[] use kiye jaate hain.

3. Selecting Columns Using Square Brackets

Pandas DataFrame mein column selection ka standard tarika square brackets [] hota hai. Is syntax ko master karne ke liye do critical rules yaad rakhein:

Figure 4.3: The Single Bracket (Series) vs Double Bracket (DataFrame) architectural distinction.

1. Single Brackets vs Double Brackets

  • df['column_name']: Ek string pass karne par Series milti hai. Yeh tab use hota hai jab aapko kisi ek feature par mathematical operations (jaise .mean(), .sum()) run karne ho.
  • df[['col_a', 'col_b']]: Python list pass karne par DataFrame milta hai. Bahar wale brackets indexing syntax hain, aur andar wale brackets Python list literal hain!
  • df[['col_a']]: Agar list mein sirf ek column ho, tab bhi 2D DataFrame hi return hoga.

2. Changing Column Ordering on the Fly

Aap brackets mein columns ki list pass karke unka display aur export order instantly reorder kar sakte hain:

df[['marks', 'student_name', 'department']]

3. Why Dot Access (df.column) is Fragile & Dangerous!

Python mein bohot se beginners df.marks likhte hain. Halanki yeh valid hai, industry-standard code mein isse avoid kiya jaata hai kyuki:

  1. Spaces in Column Names: Agar column ka naam 'student name' hai, toh df.student name SyntaxError dega!
  2. Attribute Collisions: Agar column ka naam Pandas ke built-in attribute ya method se match karta hai (jaise shape, count, index, min), toh df.shape DataFrame ki actual dimensions return karega, na ki aapka column!
  3. Creating New Columns: Naya column assign karne ke liye dot access kaam nahi karta (df.new_col = [...] silent bug create karta hai). Hamesha bracket df['new_col'] = [...] use karna mandatory hai.
dot_access_caveat_demo.py Python 3 • Pandas 
import pandas as pd

df_demo = pd.DataFrame({
    'student name': ['Aarav', 'Diya'],
    'shape': [10, 20]  # Dangerous column name collision!
})

# Dot access fails on spaces: df_demo.student name -> SYNTAX ERROR
print("Safe bracket access with space:", df_demo['student name'].tolist())

# Dot access collides with built-in .shape attribute!
print("df_demo.shape (Returns DataFrame dimensions!):", df_demo.shape)
print("df_demo['shape'] (Returns the actual column values!):", df_demo['shape'].tolist())
VERIFIED EXECUTION OUTPUT:
Safe bracket access with space: ['Aarav', 'Diya'] df_demo.shape (Returns DataFrame dimensions!): (2, 2) df_demo['shape'] (Returns the actual column values!): [10, 20]

4. Understanding .loc[]: Label-Based Selection

Pandas mein .loc[] accessor label-based selection ke liye design kiya gaya hai. Iska matlab hai ki aap rows aur columns ko unke exact naam ya labels se target karte hain.

Figure 4.4: Visual breakdown of df.loc[row_labels, column_labels] coordinate targeting.

Core Syntax & Rules of .loc[]:

Standard syntax hota hai: df.loc[row_indexer, column_indexer]

  • Single Row by Label: df.loc['STU102'] → Returns a Series of that student's records.
  • Multiple Rows by Label List: df.loc[['STU101', 'STU103']] → Returns a DataFrame with matching rows.
  • Rows & Columns Together: df.loc[['STU101', 'STU102'], ['student_name', 'marks']] → Intersects specific rows with specific columns.
  • All Rows, Specific Columns: df.loc[:, ['student_name', 'marks']] (colon : indicates "all rows").
  • Label-Based Slicing (CRITICAL!): df.loc['STU101':'STU103', 'student_name':'marks'].
    Crucial Rule: Python ke normal slice ke vipreet, .loc[] label slices mein STOP endpoint STRICTLY INCLUDE hota hai!

Example 1: College Records with Custom Student IDs

Dekhiye kaise custom string index set karke .loc[] ke zariye direct student ID se data fetch kiya jaata hai:

5. Understanding .iloc[]: Integer Position-Based Selection

Agar aapko index labels ya column names nahi pata hain, ya aap data ko purely unki physical memory position (row number aur column number) ke hisab se extract karna chahte hain, toh aap .iloc[] (Integer Location) use karte hain.

Figure 4.5: Zero-based coordinate offsets in .iloc[row_pos, col_pos].

Core Syntax & Rules of .iloc[]:

Standard syntax: df.iloc[row_positions, column_positions]

  • Zero-Based Indexing: Pehli row hamesha position 0 hoti hai, doosri 1, teesri 2...
  • First Row: df.iloc[0] → Returns first record as Series.
  • Last Row (Negative Indexing): df.iloc[-1] → Returns last record.
  • Positional Slicing (CRITICAL!): df.iloc[0:3, 1:3].
    Python Standard Rule: .iloc[] standard Python slicing follow karta hai, jisme STOP index strictly EXCLUDE hota hai (0:3 ka matlab positions 0, 1, 2 hain; position 3 shamil nahi hoti!).
  • IndexError Warning: Agar aap DataFrame ki length se bada integer pass karenge (jaise 5 rows wale table mein df.iloc[10]), toh IndexError: single positional indexer is out-of-bounds raise hoga.

Example 1: Selecting Students by Position

iloc_student_selection.py Python 3 • Pandas

df_stu = pd.DataFrame({

--- POSITIONAL SLICE (0:3, 0:2) ---")
print(top3_sub)

# 3. Extract Single Cell: Diya's Marks (Row position 1, Col position 2)

print(f"
Single Cell at iloc[1, 2]: {cell_val}")

6. .loc[] vs .iloc[]: The Definitive Battle

Pandas seekhne wale 90% students ka sabse bada confusion hota hai: "Sir, kab .loc[] use karein aur kab .iloc[]?" Is section ko dhyan se samajh lijiye, aap kabhi confuse nahi honge!

Figure 4.6: The core distinction — .loc asks 'Where is the LABEL?' while .iloc asks 'What is the POSITION?'.

Comparison Matrix: .loc[] vs .iloc[]

Comparison Feature .loc[] (Label-Based) .iloc[] (Integer Position-Based)
Core Philosophy Data ko uske Name / Label se dhundna. Data ko uski Physical Offset / Position (0, 1...) se dhundna.
Accepted Inputs Index labels (strings, integers, dates), list of labels, boolean masks. Integers (0 to N-1), list of integers, integer slices, boolean masks.
Custom String Index Directly targets string IDs: df.loc['STU101']. String index ko ignore karke row position dekhta hai: df.iloc[0].
Slicing Stop Endpoint INCLUSIVE: Stop label slice ka hissa banta hai! EXCLUSIVE: Stop position standard Python slice ki tarah exclude hota hai!
Integer Labels (101, 205...) df.loc[101] label 101 wali row dhundega (chahe woh row 0 par ho). df.iloc[1] position 1 wali row dhundega (chahe uska label kuch bhi ho).
Negative Integers Tabhi kaam karta hai agar index mein actually negative number ho (jaise -1). Standard Python reverse indexing: df.iloc[-1] hamesha last row deta hai.
Error When Missing Raises KeyError if label not found. Raises IndexError if position out of range.
Mental Model Phonebook Lookup: Name se search karna. Array Memory Offset: Memory address/index se search karna.

The Non-Consecutive Integer Demonstration

Agar DataFrame ka index consecutive numbers (0, 1, 2...) nahi hai, balki roll numbers ya bus numbers (101, 205, 309, 412) hain, tab .loc aur .iloc ka difference visually clear ho jaata hai:

7. Selecting Individual Cells & High-Speed Access: .at and .iat

Jab aapko kisi table mein se sirf ek single value (scalar) extract karni ho ya modify karni ho, toh .loc aur .iloc use karna thoda heavy ho sakta hai kyuki woh internally indexing checks aur Series slicing perform karte hain. Pandas iske liye do lightweight aur fast accessors provide karta hai: .at[] aur .iat[].

Figure 4.7: High-speed scalar accessors — df.at (by label) vs df.iat (by position).

Comparison of the 4 Coordinate Accessors:

  • df.loc['STU102', 'marks']: General label-based accessor. Can return Series, DataFrame, or scalar.
  • df.iloc[1, 2]: General position-based accessor. Can return Series, DataFrame, or scalar.
  • df.at['STU102', 'marks']: Dedicated label-based scalar accessor. Returns ONLY one raw scalar value. Fast execution.
  • df.iat[1, 2]: Dedicated position-based scalar accessor. Returns ONLY one raw scalar value by integer offsets. Fastest execution.

Example: Inventory Price Lookup & In-Place Price Update

at_iat_scalar_demo.py Python 3 • Pandas 
import pandas as pd

df_inv = pd.DataFrame({
    'product': ['Laptop', 'Mouse', 'Keyboard'],
    'price': [55000, 600, 2500],
    'stock': [12, 45, 20]
}, index=['P01', 'P02', 'P03'])

print("--- ORIGINAL INVENTORY ---")
print(df_inv)

# 1. Fast scalar read with .at (by label) and .iat (by position)
mouse_price = df_inv.at['P02', 'price']
keyboard_stock = df_inv.iat[2, 2]
print(f"
Mouse Price (df.at['P02', 'price']): Rs {mouse_price}")
print(f"Keyboard Stock (df.iat[2, 2]): {keyboard_stock} units")

# 2. Fast in-place value update
df_inv.at['P02', 'price'] = 650       # Update price of Mouse
df_inv.iat[0, 2] = 15                  # Restock Laptop from 12 to 15

print("
--- UPDATED INVENTORY (AFTER IN-PLACE WRITES) ---")
print(df_inv)
VERIFIED EXECUTION OUTPUT:
--- ORIGINAL INVENTORY --- product price stock P01 Laptop 55000 12 P02 Mouse 600 45 P03 Keyboard 2500 20 Mouse Price (df.at['P02', 'price']): Rs 600 Keyboard Stock (df.iat[2, 2]): 20 units --- UPDATED INVENTORY (AFTER IN-PLACE WRITES) --- product price stock P01 Laptop 55000 15 P02 Mouse 650 45 P03 Keyboard 2500 20

8. Slicing Rows and Columns

Slicing ka matlab hota hai DataFrame ke andar se ek continuous ya stepped sub-matrix ko extract karna. Pandas mein row slicing aur column slicing dono ko ek sath combine kiya ja sakta hai.

Figure 4.8: Positional Slicing (Stop Excluded) vs Label Slicing (Stop Included).

Slicing Syntax Patterns:

  • df.iloc[start:stop]: Sirf rows slice karta hai (0 to stop-1).
  • df.iloc[row_slice, col_slice]: 2D rectangular grid slice (jaise df.iloc[0:3, 1:4]).
  • df.iloc[::2, :]: Har doosri row extract karta hai (step = 2).
  • df.iloc[::-1, :]: Pure DataFrame ko reverse order mein invert kar deta hai.
  • df.loc[start_lbl:stop_lbl, start_col:stop_col]: Label boundary slicing (both bounds included).
slicing_matrix_demo.py Python 3 • Pandas 
import pandas as pd

df_stu = pd.DataFrame({
    'name': ['Aarav', 'Diya', 'Rohan', 'Ananya', 'Kabir', 'Meera'],
    'dept': ['CS', 'IT', 'CS', 'ECE', 'IT', 'CS'],
    'marks': [88, 94, 76, 68, 91, 84],
    'attendance': [92, 96, 85, 78, 90, 88]
})

# 1. Positional 2D Grid Slice: First 3 rows, middle 2 columns
grid_view = df_stu.iloc[0:3, 1:3]
print("--- 2D POSITIONAL SLICE (df.iloc[0:3, 1:3]) ---")
print(grid_view)

# 2. Stepped Slicing: Alternate students (rows 0, 2, 4)
alternate_view = df_stu.iloc[::2, :]
print("
--- ALTERNATE ROWS (df.iloc[::2, :]) ---")
print(alternate_view[['name', 'marks']])
VERIFIED EXECUTION OUTPUT:
--- 2D POSITIONAL SLICE (df.iloc[0:3, 1:3]) --- dept marks 0 CS 88 1 IT 94 2 CS 76 --- ALTERNATE ROWS (df.iloc[::2, :]) --- name marks 0 Aarav 88 2 Rohan 76 4 Kabir 91

9. Boolean Indexing and Conditional Filtering

Data science aur real-world analytics mein sabse zyada use hone wala operation hai: Conditional Filtering. Jisme hum dataset par ek ya multiple conditions lagakar sirf wahi rows retain karte hain jo us condition ko satisfy karein.

Figure 4.9: The 4-stage lifecycle — Original data -> Condition evaluated -> Boolean Mask -> Filtered DataFrame.

What is a Boolean Mask?

Jab aap kisi column par comparison operator lagate hain (jaise df['marks'] >= 85), toh Pandas har element ko check karta hai aur ek boolean Series (True/False values) return karta hai. Is boolean Series ko Boolean Mask kehte hain.

Jab is mask ko square brackets df[mask] mein pass kiya jaata hai, toh Pandas sirf un rows ko retain karta hai jahan mask ki value True hoti hai!

Combining Conditions: The Strict Parentheses Rule

Real-world filtering mein aksar multiple conditions ko combine karna padta hai:

Figure 4.10: Logical bitwise operators (&, |, ~) and mandatory parentheses grouping.
The #1 Python Trap: Always Enclose Conditions in Parentheses!

Python mein bitwise operator & ki precedence comparison operators (>=, ==) se zyada hoti hai. Agar aap parentheses nahi lagayenge:

df[df['marks'] >= 80 & df['attendance'] >= 85] ← CRASHES with TypeError / ValueError!

Correct Syntax:

df[(df['marks'] >= 80) & (df['attendance'] >= 85)] ← WORKS FLAWLESSLY!

Example: Complex Filtering on Student Records

boolean_filtering_deepdive.py Python 3 • Pandas 
import pandas as pd

df_stu = pd.DataFrame({
    'name': ['Aarav', 'Diya', 'Rohan', 'Ananya', 'Kabir', 'Meera'],
    'dept': ['CS', 'IT', 'CS', 'ECE', 'IT', 'CS'],
    'marks': [88, 94, 76, 68, 91, 84],
    'attendance': [92, 96, 85, 78, 90, 88]
})

# 1. Inspect the raw boolean mask
mask_distinction = df_stu['marks'] >= 85
print("--- RAW BOOLEAN MASK (marks >= 85) ---")
print(mask_distinction)

# 2. Filter with AND (&): Distinction Marks (>=85) AND High Attendance (>=90)
mask_honors = (df_stu['marks'] >= 85) & (df_stu['attendance'] >= 90)
honors_students = df_stu[mask_honors]
print("

10. Useful Filtering Methods: isin(), between(), query(), isna() & notna()

Boolean conditions powerful hain, lekin complex criteria likhte waqt code lamba aur messy ho sakta hai. Pandas iske liye kuch highly optimized convenience filtering methods offer karta hai:

Figure 4.11: Categorical membership with .isin() vs Range checking with .between().

1. Categorical Selection with .isin()

Agar aapko kisi column ko multiple values ke sath match karna ho (jaise dept == 'CS' or dept == 'IT' or dept == 'ECE'), toh baar-baar | likhne ke bajaye aap list pass kar sakte hain:

df[df['department'].isin(['CS', 'IT'])]

Yeh method internally fast hash-table lookup use karta hai aur code ko clean banata hai.

2. Range Selection with .between()

Numeric ya date columns par range check karne ke liye: (col >= left) & (col <= right) likhne ke bajaye:

df[df['marks'].between(75, 90)]

By default, between() dono boundaries ko include karta hai (inclusive='both').

3. String Querying with .query()

Pandas SQL-like string queries support karta hai jo brackets ko hata kar natural language jaisa experience deti hain:

df.query("marks >= 80 and dept == 'CS'")

Caveat: query() column names mein spaces ya symbols hone par thoda rigid hota hai, aur external Python variables use karne ke liye @variable_name syntax lagana padta hai.

4. Detecting & Selecting Missing Data: .isna() & .notna()

Figure 4.12: Locating incomplete records with .isna() vs valid records with .notna().

Real-world datasets mein missing values (NaN ya None) common hote hain. Remember: Python mein np.nan == np.nan hamesha False return karta hai! Isliye direct equality check kabhi kaam nahi karega.

  • df[df['col'].isna()]: Sirf missing/incomplete rows ko isolate karta hai.
  • df[df['col'].notna()]: Sirf complete/valid records ko select karta hai.

11. Conditional Selection with where() and mask()

Aam taur par conditional filtering (jaise df[condition]) non-matching rows ko table se delete ya drop kar deta hai. Lekin kai scenarios mein humein pure table ka size aur row alignment maintain rakhna hota hai, bas specific values ko replace ya censor karna hota hai!

Figure 4.13: Shape-preserving value replacement — .where() vs .mask().

The Fundamental Rules:

  • df.where(condition, other=...):
    • Jahan condition True hai → Original value KEEP hoti hai.
    • Jahan condition False hai → Value other se REPLACE ho jaati hai (default is NaN).
  • df.mask(condition, other=...):
    • Jahan condition True hai → Value other se REPLACE ho jaati hai.
    • Jahan condition False hai → Original value KEEP hoti hai.
    • Yeh where() ka exact logical opposite hota hai!
where_mask_operations.py Python 3 • Pandas 
import numpy as np
import pandas as pd

marks_series = pd.Series([88, 64, 92, 55, 78], name='exam_marks')

# 1. where(): Keep passing marks (>= 70), replace failing with 'Needs Remedial'

print("--- .where() RESULT ---")
print(status)

# 2. mask(): Censor/Mask scores below 70 with 0
censored = marks_series.mask(marks_series < 70, other=0)
print("
--- .mask() RESULT ---")
print(censored)

valid_temps = raw_sensor_temps.where((raw_sensor_temps >= 20) & (raw_sensor_temps <= 40), other=np.nan)
print("
--- SENSOR READINGS FILTERED WITH .where() ---")
print(valid_temps)

12. Selecting Data from a Pandas Series

Pandas Series ek 1D labeled array hoti hai. Isme selection ke rules DataFrames se milte-julte hote hain lekin ek fundamental difference hota hai jise samajhna zaroori hai!

Figure 4.14: 1D Series indexing syntax — Labels vs Positions vs Boolean Masks.

The Crucial 1D vs 2D Indexing Rule:

Why s['key'] and df['key'] Behave Differently:

DataFrame mein 2 axes hoti hain, isliye df['name'] hamesha Column Header search karta hai.
Series mein sirf 1 axis hoti hai, isliye s['S102'] hamesha Row Label search karta hai!

Series Access Mechanisms:

  • Direct Label Access: s['S102'] → Returns scalar value 94.
  • Explicit Label Access: s.loc['S102'] → Safer, explicit label lookup.
  • Positional Access: s.iloc[1] → Returns value at offset 1.
  • Label Slicing: s.loc['S101':'S103'] → Includes endpoint 'S103'.
  • Positional Slicing: s.iloc[0:2] → Excludes endpoint 2.
  • Boolean Filtering: s[s >= 90] → Returns filtered Series of high scores.

16. Top 12 Beginner Mistakes & Indexing Traps

Indexing aur selection mein beginners aksar in 12 common traps mein phas jaate hain. Inhe padh kar aap ghanto ka debugging time bacha sakte hain:

Trap 1: Omitting Parentheses in Compound Conditions

Error: df[df['marks'] >= 80 & df['attendance'] >= 85]
Why: Python mein bitwise & ki priority >= se zyada hoti hai.
Fix: Hamesha har condition ko parentheses mein pack karein: df[(df['marks'] >= 80) & (df['attendance'] >= 85)].

Trap 2: Using Python's 'and' / 'or' Instead of Bitwise '&' / '|'

Error: df[(df['marks'] >= 80) and (df['att'] >= 85)] → ValueError: The truth value of a Series is ambiguous.
Why: Python ka and pure object ka single boolean mangta hai. Vectorized element-by-element operation ke liye bitwise & aur | hi required hain.

Trap 3: Slicing Endpoint Inconsistency (.loc vs .iloc)

Symptom: df.loc['A':'C'] 3 rows deta hai (C included), lekin df.iloc[0:2] sirf 2 rows deta hai (2 excluded).
Fix: Remember: .loc label slice includes stop label; .iloc integer slice strictly excludes stop index!

Trap 4: Chained Indexing and SettingWithCopyWarning

Error: df[df['dept'] == 'CS']['marks'] = 95
Why: Chained indexing ek temporary slice par write karne ki koshish karta hai, jisse original DataFrame update nahi hota.
Fix: Hamesha direct .loc use karein: df.loc[df['dept'] == 'CS', 'marks'] = 95.

Trap 5: Single Brackets for Multiple Columns

Error: df['name', 'marks'] → KeyError: ('name', 'marks')
Why: Pandas isse ek single tuple column name samajhta hai.
Fix: List pass karein double brackets ke sath: df[['name', 'marks']].

Trap 6: Accidental Spaces in Column Names

Symptom: df['marks '] ya df[' marks'] raises KeyError: 'marks'.
Fix: Ingestion ke baad columns clean karein: df.columns = df.columns.str.strip().

Trap 7: Comparing Missing Values with '== np.nan'

Error: df[df['rating'] == np.nan] → Returns an empty DataFrame 0 rows!
Why: IEEE 754 floating point standard ke hisab se nan == nan is False.
Fix: Hamesha df[df['rating'].isna()] use karein.

Trap 8: Forgetting That .set_index() Returns a New DataFrame

Error: df.set_index('student_id') run kiya lekin index change nahi hua.
Fix: Reassign karein: df = df.set_index('student_id') ya inplace=True use karein.

Trap 9: Looking Up Positional Integer with .loc on Integer Index

Error: Agar index [101, 205, 309] hai, toh df.loc[0] KeyError dega kyuki label 0 exist nahi karta.
Fix: Use df.iloc[0] to get the first row by offset.

Trap 10: Modifying a Filtered Slice Without .copy()

Symptom: sub_df = df[df['marks'] > 80]; sub_df['bonus'] = 5 raises SettingWithCopyWarning.
Fix: Explicit deep copy banayein: sub_df = df[df['marks'] > 80].copy().

Trap 11: Complex Variable Access in .query()

Error: df.query("marks > min_marks") → UndefinedVariableError.
Fix: Prefix Python local variables with @: df.query("marks > @min_marks").

Trap 12: Series Direct Slicing vs DataFrame Bracket Slicing

Confusion: s[0:2] rows slice karta hai, lekin df[0:2] bhi rows slice karta hai jabki df['col'] column select karta hai!
Best Practice: Ambiguity se bachne ke liye DataFrames par hamesha explicit .iloc[0:2] use karein.

Explanation: Passing single scalar integer coordinates to .iloc extracts the single cell at row 0, column 1.

Q24: What is the logical NOT operator used for negating boolean conditions in Pandas?

Laboratory Challenge: The Healthcare Emergency Department Triage Filter

Aapko ek city hospital ke Emergency Ward ka patient admission log diya gaya hai:

hospital_triage_lab.py Python 3 • Hands-on Lab 
import numpy as np
import pandas as pd

hospital_data = {
    'patient_id': ['P101', 'P102', 'P103', 'P104', 'P105', 'P106'],
    'name': ['Suresh Kumar', 'Pooja Roy', 'Amit Shah', 'Sunita Rao', 'Vikram Sen', 'Deepa Das'],
    'age': [68, 29, 74, 42, 81, 35],
    'blood_pressure': [165, 118, 172, 130, 158, np.nan], # P106 BP not yet recorded
    'oxygen_level': [89, 98, 87, 95, 91, 97],
    'department': ['Cardio', 'General', 'Cardio', 'General', 'Neuro', 'General']
}

df_hospital = pd.DataFrame(hospital_data).set_index('patient_id')

# LAB TASKS:
# 1. Filter critical patients: Oxygen Level < 90 OR Blood Pressure >= 160
# 2. Select patients in 'Cardio' department aged >= 70
# 3. Locate patients with missing Blood Pressure readings
# 4. Use .at to update Deepa Das (P106) Blood Pressure to 122

# Solution:
critical = df_hospital[(df_hospital['oxygen_level'] < 90) | (df_hospital['blood_pressure'] >= 160)]
print("--- 1. CRITICAL PATIENTS ---")
print(critical[['name', 'blood_pressure', 'oxygen_level']])

cardio_seniors = df_hospital[(df_hospital['department'] == 'Cardio') & (df_hospital['age'] >= 70)]
print("
--- 2. CARDIO SENIORS (Age >= 70) ---")
print(cardio_seniors[['name', 'age']])

missing_bp = df_hospital[df_hospital['blood_pressure'].isna()]
print("
--- 3. MISSING BP READINGS ---")
print(missing_bp[['name']])

df_hospital.at['P106', 'blood_pressure'] = 122
print(f"
--- 4. UPDATED P106 BP: {df_hospital.at['P106', 'blood_pressure']} ---")
