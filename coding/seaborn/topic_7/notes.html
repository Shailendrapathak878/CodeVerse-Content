01 Introduction: Why Mean & Standard Deviation Lie

Jab aap kisi numerical column ka distribution samajhne ki koshish karte hain, toh traditional statistics humein do metrics sikhata hai: Mean (μ) aur Standard Deviation (σ). Lekin real-world data science mein ek simple rule yaad rakhiye: Mean is an extreme-value magnet! Ek single billionaire pure neighborhood ki average income ko 100 guna distort kar sakta hai.

Real-Life Scenario: The Salary Trap

Maan lijiye ek startup mein 10 junior engineers kaam karte hain jinki monthly salary ≈ ₹40,000 hai. Ab company mein ek celebrity AI Architect join karta hai jiska compensation ₹25,00,000 per month hai! Agar HR report karegi: "Hamari company ka average salary ₹2,63,600 hai!", toh kya yeh sach batata hai junior engineers ki ground reality ka? Bilkul nahi! Mean complete distortion represent karta hai.

Isi problem ko solve karne ke liye 1977 mein legendary statistician John W. Tukey ne Box-and-Whisker Plot invent kiya tha. Box plot data ko summarize karne ke liye parametric statistics (mean/std) ke bajaye Non-Parametric Order Statistics (Ranked Quantiles) use karta hai.

Box Plot Ki Core Superpowers

  • Outlier Robustness: Extreme values median ko bilkul hilane nahi pati kyunki median middle rank par baitha hota hai.
  • 5-Number Summary at a Glance: Ek hi compact box mein minimum, lower quartile (Q1), median (Q2), upper quartile (Q3), aur maximum display ho jaata hai.
  • Multi-Category Comparison: Ek single plot canvas par aap 10 alag-alag departments, delivery partners, ya machine sensors ke distributions ko side-by-side compare kar sakte hain without clutter.
  • Skewness Detection: Median line box ke middle se kis taraf shift hai aur kaunsa whisker lamba hai, yeh distribution ki asymmetry (left-skew vs right-skew) instantly reveal kar deta hai.

First Code Example: Mean vs Median Sensitivity

Aaiye code run karke dekhte hain ki jab dataset mein ek outlier enter karta hai toh Mean aur Median kaise behave karte hain:

Python 3.13 • NumPy & Pandas 
import numpy as np
import pandas as pd

# 10 employees with normal salary + 1 executive outlier
clean_salaries = np.array([38000, 39000, 40000, 41000, 41500, 42000, 43000, 44000, 45000, 46000])
with_outlier = np.append(clean_salaries, [2500000])

print(f"Clean Data   -> Mean: ₹{clean_salaries.mean():,.2f} | Median: ₹{np.median(clean_salaries):,.2f}")
print(f"With Outlier -> Mean: ₹{with_outlier.mean():,.2f} | Median: ₹{np.median(with_outlier):,.2f}")

Notice the magic! Outlier add hote hi Mean ₹41,950 se jump karke ₹2,65,409 ho gaya (6.3× jump!), jabki Median sirf ₹41,750 se ₹42,000 hua (sirf ₹250 ka difference!). Box plots isiliye real-world analytics ka foundational pillar hain.

02 The 5-Number Summary & Tukey Fences Math

Box plot ka har ek graphic element kisi na kisi exact mathematical metric ko represent karta hai. Is mathematics ko bolte hain Five-Number Summary plus Tukey's Fences. Chaliye isko step-by-step calculate karte hain hamare foundational 11-number dataset ke saath:

Dataset: [12, 15, 18, 20, 22, 24, 26, 28, 30, 35, 80]  (n = 11)

Step 1: Finding the Median (Q2 / 50th Percentile)

Dataset ko pehle ascending order mein sort kiya jata hai. Kyunki n = 11 ek odd number hai, exact middle element position (n + 1) / 2 = 12 / 2 = 6th element hoga:

  • 1st: 12, 2nd: 15, 3rd: 18, 4th: 20, 5th: 22
  • 6th element = 24.0 → Median (Q2)
  • 7th: 26, 8th: 28, 9th: 30, 10th: 35, 11th: 80

Step 2: Calculating Quartiles Q1 and Q3

Dataset ko do equal halves mein divide kiya jata hai:

  • Lower Half: [12, 15, 18, 20, 22] → Median of lower half = 19.0 (Q1 / 25th percentile)
  • Upper Half: [26, 28, 30, 35, 80] → Median of upper half = 29.0 (Q3 / 75th percentile)

Step 3: Calculating IQR (Interquartile Range)

IQR = Q3 − Q1 = 29.0 − 19.0 = 10.0

IQR represent karta hai aapke dataset ke middle 50% population ka spread. Box plot ka rectangular box precisely Q1 se Q3 tak faila hota hai, aur box ki length exact IQR hoti hai.

Figure 7.2: Step-by-Step 5-Number Summary & Quartile Partitioning for n = 11.

Step 4: Tukey's 1.5 × IQR Fences (The Golden Rule)

John Tukey ne outlier identify karne ke liye boundary lines define ki jinko Fences kaha jaata hai:

Lower Fence = Q1 − 1.5 × IQR = 19.0 − (1.5 × 10.0) = 4.0
Upper Fence = Q3 + 1.5 × IQR = 29.0 + (1.5 × 10.0) = 44.0
The #1 Beginner Misconception: Whisker Length!

90% beginners yeh galat sochte hain ki whisker direct Upper Fence (44.0) tak extend hota hai! Yeh galat hai. Whisker kabhi theoretical fence tak draw nahi hota agar wahan data point hi na ho! Whisker fence ke andar ke sabse extreme actual observed data point par aakar ruk jaata hai!

Hamare dataset mein 44.0 se chhota sabse bada point 35.0 hai. Isiliye Upper Whisker 35.0 par rukega! Aur 80.0 kyunki fence (44.0) ke bahar chala gaya, isiliye usko whisker se alag karke ek standalone point (Flier) ke roop mein plot kiya jaata hai.

Figure 7.3: Tukey Fences vs Actual Observed Whisker Limits — Why Upper Whisker stops at 35.0 while 80.0 becomes an outlier marker.
Deep Dive: Why specifically 1.5 × IQR? Why not 1.0 or 2.0?

John Tukey ne 1.5 × IQR ko mathematically tune kiya tha. Normal distribution (Bell Curve) ke andar:

  • IQR ≈ 1.349 × σ hota hai.
  • Q1 − 1.5 × IQR ≈ μ − 2.698 × σ
  • Q3 + 1.5 × IQR ≈ μ + 2.698 × σ

Ek standard Gaussian distribution mein ±2.7σ ke bahar sirf 0.7% data points aate hain (p ≈ 0.007). Agar Tukey 1.0 × IQR rakhte, toh normal distribution ke lagbhag 5% valid data points bina wajah outlier flag ho jaate (False Positives). Agar 2.0 × IQR rakhte, toh genuine anomalous outliers pakad mein nahi aate. 1.5 is the mathematically balanced sweet spot!

Complete Code Example: Basic Single-Column Boxplot

Aaiye student exam scores ka simple univariate box plot banate hain:

Python 3.13 • Seaborn 0.13.2 
import matplotlib.pyplot as plt
import seaborn as sns
import pandas as pd

# Load verified college marks dataset
df = pd.read_csv("scratch/seaborn_topic7_data/college_exam_scores.csv")

fig, ax = plt.subplots(figsize=(7, 6))
sns.boxplot(y=df['exam_marks'], ax=ax, color='#0284c7', width=0.35,
            boxprops=dict(edgecolor='#38bdf8', linewidth=1.8),
            medianprops=dict(color='#f59e0b', linewidth=2.5),
            flierprops=dict(marker='o', markerfacecolor='#f43f5e', markeredgecolor='#ffffff', markersize=6))

ax.set_ylabel("Exam Marks (Out of 100)", fontsize=11, fontweight='bold')
ax.set_title("Distribution of Student Exam Marks (n=180)", fontsize=13, fontweight='bold')
plt.tight_layout()
plt.show()

04 Reading Every Component of a Box Plot

Jab koi stakeholder ya interviewer aapke saamne ek box plot rakhta hai, toh aapko usse ek story ki tarah padhna aana chahiye. Box plot ko read karne ka exact 4-step framework yeh hai:

The 4-Step Box Plot Decoding Framework
  1. Step 1: Check the Center (Median / Q2): Box ke andar ki median line dekhiye. Yeh distribution ka typical value batati hai.
  2. Step 2: Check the Spread (IQR / Box Height): Box kitna chhota ya bada hai? Chhota box matlab data consistent hai; bada box matlab high variance hai.
  3. Step 3: Check Symmetry & Skewness: Kya median line box ke ekdum center mein hai? Agar median niche (Q1 ke paas) hai aur upper whisker lamba hai, toh data Right-Skewed (Positive Skew) hai. Agar median upar (Q3 ke paas) hai, toh data Left-Skewed (Negative Skew) hai.
  4. Step 4: Audit Outlier Risk (Fliers): Box whiskers ke bahar kitne dots hain? Dots kis direction mein hain? Outliers high side par hain ya low side par?

05 Customizing Aesthetics & Orientation: Vertical vs Horizontal

Jab aapke categorical groups ke naam lambe hote hain (jaise "Junior Data Analyst", "Senior Machine Learning Scientist", "Lead Site Reliability Engineer"), toh standard vertical box plot mein x-axis par label collision ho jaata hai. Labels aapas mein overlap ho jaate hain ya unhe 45° rotate karna padta hai jo padhne mein mushkil hota hai.

The Horizontal Orientation Fix

Seaborn mein horizontal plot banana bahut simple hai: bas numerical variable ko x par aur categorical variable ko y par pass kar dijiye!

Python 3.13 • Seaborn 0.13.2 
import matplotlib.pyplot as plt
import seaborn as sns
import pandas as pd

df_salary = pd.read_csv("scratch/seaborn_topic7_data/tech_salaries_demo.csv")

fig, (ax1, ax2) = plt.subplots(1, 2, figsize=(13, 5.5))

# Vertical plot (requires x-tick rotation)
sns.boxplot(data=df_salary, x='role', y='monthly_salary_inr', hue='role', legend=False,
            ax=ax1, palette=['#0284c7', '#6366f1', '#10b981'],
            flierprops=dict(marker='o', markerfacecolor='#f43f5e', markeredgecolor='#ffffff', markersize=6))
ax1.set_xticklabels(ax1.get_xticklabels(), rotation=20, ha='right')
ax1.set_title("Vertical Box Plot (Rotated Labels)")

# Horizontal plot (effortless natural reading)
sns.boxplot(data=df_salary, y='role', x='monthly_salary_inr', hue='role', legend=False,
            ax=ax2, palette=['#0284c7', '#6366f1', '#10b981'],
            flierprops=dict(marker='o', markerfacecolor='#f43f5e', markeredgecolor='#ffffff', markersize=6))
ax2.set_title("Horizontal Box Plot (Effortless Reading)")

plt.tight_layout()
plt.show()
Figure 7.6: Side-by-side comparison — Vertical orientation with rotated labels vs clean horizontal orientation.

The showfliers=False Option: Truth vs Misunderstanding

Agar aapko executive presentation ke liye clean chart banana hai jisme extreme outlier dots se chart ka scale distort na ho, toh aap showfliers=False use kar sakte hain.

Critical Insight: Does showfliers=False delete data?

Absolutely NOT! Yeh bahut common misconception hai. Setting showfliers=False does NOT filter or remove rows from your DataFrame! Whisker lengths, median lines, aur quartile box boundaries 100% same rehte hain. Sirf un isolated dots ka visual rendering suppress hota hai.

# showfliers=True (default)
sns.boxplot(data=df_deliv, x='partner', y='delivery_time_mins', ax=ax1,
            palette='Blues_d', showfliers=True)
ax1.set_title("showfliers=True (Default)")

# showfliers=False (clean presentation)
sns.boxplot(data=df_deliv, x='partner', y='delivery_time_mins', ax=ax2,
            palette='Blues_d', showfliers=False)

plt.tight_layout()
plt.show()

08 Custom Whisker Rules: whis=1.5 vs 3.0 vs Percentiles

By default, sns.boxplot() John Tukey ke 1.5×IQR rule ko follow karta hai. Lekin kya aap jante hain ki whis parameter ko aap customize kar sakte hain different analytical use-cases ke liye?

The 3 Major Modes of whis

  1. Standard Tukey (whis=1.5): Fences = [Q1 − 1.5×IQR, Q3 + 1.5×IQR]. Flags mild and extreme outliers. Standard exploratory analysis ke liye ideal.
  2. Conservative Tukey (whis=3.0): Fences = [Q1 − 3.0×IQR, Q3 + 3.0×IQR]. Tukey ne ise "Far Outliers" ya "Extreme Outliers" kaha tha. Yeh setting normal variance ko ignore karke sirf severe anomalies ko isolate karti hai.
  3. Percentile Whiskers (whis=(5, 95)): Whiskers ko IQR fences ke bajaye direct 5th percentile aur 95th percentile par terminate karta hai. Financial risk modeling aur SLA tail analysis mein yeh standard technique hai.
Python 3.13 • whis Parameter In Depth 
sec_b = df_college[df_college['section'] == 'Section B']['exam_marks']

fig, (ax1, ax2, ax3) = plt.subplots(1, 3, figsize=(15, 5))

# Mode 1: whis=1.5
sns.boxplot(y=sec_b, ax=ax1, color='#0284c7', whis=1.5)
ax1.set_title("whis=1.5 (Standard: 5 outliers flagged)")

# Mode 2: whis=3.0
sns.boxplot(y=sec_b, ax=ax2, color='#6366f1', whis=3.0)
ax2.set_title("whis=3.0 (Conservative: Far Outliers only)")

# Mode 3: whis=(5, 95)
sns.boxplot(y=sec_b, ax=ax3, color='#10b981', whis=(5, 95))
ax3.set_title("whis=(5, 95) (Percentile Reach: 5% to 95%)")

plt.tight_layout()
plt.show()
Figure 7.12: Comparing Whisker Reach Rules — Standard 1.5×IQR vs Conservative 3.0×IQR vs Direct Percentile Reach (5, 95).

09 The Gold Standard: Box Plot Overlaid with Strip Plot

Box plots ki sabse badi weakness yeh hoti hai ki woh Sample Size (N) aur Data Point Density ko chupate hain. Chahe aapke group mein sirf 5 data points hon ya 5,000 data points hon, box plot dekhne mein bilkul ek jaisa lagta hai!

The Danger of the "Ghost Distribution"

Agar Section A mein 100 students hain aur Section B mein sirf 4 students hain, toh bina raw points dekhe aap dono ke boxes ko compare karke galat statistical conclusions nikaal sakte hain. 4 points ka box statistical fluke ho sakta hai!

The Solution: Overlaying sns.stripplot()

Professional data scientists box plot ke upar ek jittered sns.stripplot() overlay karte hain with transparency (alpha=0.6). Is combination ko bolte hain "The Best of Both Worlds" — summary quantiles bhi mil jaate hain aur underlying raw data density bhi transparently visible hoti hai!

Python 3.13 • Box + Strip Overlay 
import matplotlib.pyplot as plt
import seaborn as sns
import pandas as pd

df_college = pd.read_csv("scratch/seaborn_topic7_data/college_exam_scores.csv")

fig, ax = plt.subplots(figsize=(10, 5.5))

# Step 1: Draw clean base box plot with showfliers=False
# (Crucial: Hide fliers to avoid plotting outlier dots twice!)
sns.boxplot(data=df_college, x='section', y='exam_marks', ax=ax,
            palette=['#1e293b', '#1e293b', '#1e293b'],
            boxprops=dict(edgecolor='#94a3b8', linewidth=1.5),
            medianprops=dict(color='#38bdf8', linewidth=2.5),

10 Box Plot vs Histogram: When to Use Which & The Bimodal Trap

Histograms aur Box Plots dono continuous variables ke distributions study karne ke liye use hote hain. Lekin unka primary purpose alag hota hai, aur box plot ki ek bohot dangerous limitation hoti hai jise har data analyst ko jaan lena chahiye.

The Bimodal Blindspot (Dangerous Pitfall!)

Box plots multimodality ko completely chupate hain! Agar aapke data mein do alag-alag groups hain (e.g. customer groups jinka peak 30 aur 70 par hai), toh histogram do distinct pahad (peaks) dikhayega. Lekin box plot median ko theek unke beech ke khali gaddhe (50) par rakh dega, aur box ko chouda bana dega — giving you ZERO indication that there are two separate clusters!

11 Box Plot vs KDE Plot: Density Curves vs Quantile Anchors

Topic 5 mein humne Kernel Density Estimation (KDE) plots padhe the. KDE curve data ki smooth continuous probability density show karta hai, jabki Box Plot discrete summary quantiles draw karta hai.

When to Pair KDE with Box Plots

  • Use KDE when you need to understand skewness shape, tail decay rate, and probability mass.
  • Use Box Plot when you need executive-ready SLAs (e.g. "75% orders are delivered under 36.5 minutes").
  • Use Both during exploratory data analysis (EDA): KDE for shape discovery, Box Plot for outlier isolation.

12 Box Plot vs Violin Plot: Revealing Multimodal Secrets

Agar aapko Box Plot ka compact summary bhi chahiye aur Histogram/KDE ki peak-detection capability bhi chahiye, toh Seaborn ka sns.violinplot() perfect solution hai. Violin plot box plot aur mirrored KDE curve ka hybrid combination hota hai!

Figure 7.16: Box Plot vs Violin Plot on Normal, Skewed, and Bimodal distributions — Notice how the violin waist instantly catches the bimodal dip.
Decision Rule: When should you choose Violin Plot over Box Plot?

Choose Violin Plot if:

  • Aapko suspect hai ki data mein multi-modal distributions (multiple clusters) ho sakte hain.
  • Sample size sufficient hai (N > 100), taaki KDE curve reliably smooth ban sake.

Stick to Box Plot if:

  • Aapke non-technical business stakeholders standard box plots se familiar hain aur violin plots se confuse ho sakte hain.
  • Dataset small hai (N < 50), jahan KDE curve artificial bumps create kar deta hai.
  • Aapko exact Tukey outlier fences calculate karke flagging report karni hai.

17 12+ Common Pitfalls, Silent Bugs & How to Fix Them

Box plots generate karte waqt data analysts aksar chhoti-chhoti mistakes karte hain jo either code ko crash kar deti hain ya statistical interpretations ko completely invert kar deti hain. Yahan 12 most critical pitfalls ka complete field guide diya gaya hai:

# Pitfall & Silent Bug Scenario Danger / Incorrect Interpretation The Correct Code & Mental Fix
1 Believing Whiskers Reach Theoretical Fences Reporting that whiskers extend to Q3 + 1.5×IQR even when no data exists there. Whiskers stop at the most extreme observed data point inside fences. Do not assume fence equals whisker.
2 Thinking showfliers=False Cleans Data Believing that setting showfliers=False drops outliers from analysis or models. showfliers=False is purely cosmetic; DataFrame rows remain untouched. Filter rows with pandas if needed.
3 Double-Plotting Outliers with Stripplot Overlay Overlaying sns.stripplot() over default boxplot plots outlier dots twice! Always pass showfliers=False to sns.boxplot() when overlaying stripplot or swarmplot.
4 Missing Bimodal Distributions (The Twin Peaks Trap) Conflating a bimodal distribution with a wide unimodal spread. Always pair box plots with sns.histplot(kde=True) or use sns.violinplot() to verify peak count.
5 Passing Numerical Column to x When Grouping by y Accidental vertical orientation with cramped unreadable labels. For long categorical labels, always pass category column to y and continuous value to x.
6 Inverting order vs hue_order Visual chaos where sub-groups mismatch across legend entries. Use order for primary axis categories and hue_order strictly for the hue variable.
7 Unformatted Large Numbers on Axes Stakeholders struggle to read 1500000 vs 150000. Use Matplotlib ticker formatters: ax.yaxis.set_major_formatter('₹{x:,.0f}').
8 Assuming Small Samples are Normally Distributed Building box plots on N < 10 observations where quantiles are unstable. If sample size is small (N < 20), overlay raw points (sns.stripplot) and report N explicitly.
9 Ignoring NaN / Missing Values Pandas silently drops NaNs, which might distort category sample representation. Check missing values count with df.isnull().sum() before drawing box plots.
10 Hardcoding Colors Without hue Assignment in Seaborn 0.13+ Getting FutureWarning: Passing palette without assigning hue is deprecated. Pass hue=category_col, legend=False when applying a custom categorical palette to single-variable plots.
11 Overlapping Hue Boxes Due to Missing Gap Sub-group boxes touch each other and look cluttered. Use Seaborn 0.13+ gap=0.08 or gap=0.1 for modern breathe-in spacing between hue clusters.
12 Truncating Outlier Tail with Inappropriate ylim Cropping the y-axis cuts off high outliers, giving a false sense of safety. Always set ylim generously beyond the maximum outlier or use ax.autoscale().

19 21 Practice Questions, Exercises & Capstone Project

Apni understanding ko test karne ke liye niche diye gaye 21 curated questions solve kijiye. Har question mein real-world industry logic aur step-by-step verified explanations included hain.

Q1: Five-number summary mein kaunse 5 specific metrics calculate hote hain?

Answer: Minimum, First Quartile (Q1 / 25th percentile), Median (Q2 / 50th percentile), Third Quartile (Q3 / 75th percentile), and Maximum (ya whisker upper boundary).

Q2: Agar dataset [10, 20, 30, 40, 50, 60, 70] ho, toh median aur IQR calculate kijiye.

Answer:

  • n = 7 (odd). Middle element = 4th element = 40 (Median).
  • Lower half: [10, 20, 30] → Q1 = 20.
  • Upper half: [50, 60, 70] → Q3 = 60.
  • IQR = Q3 − Q1 = 60 − 20 = 40.
Q3: Tukey's 1.5 × IQR rule ke according Lower Fence aur Upper Fence ka exact formula kya hai?

Answer:

Lower Fence = Q1 − 1.5 × IQR
Upper Fence = Q3 + 1.5 × IQR
Q4: Kya whisker theoretical fence tak draw hota hai? Explain with example.

Answer: Nahi! Whisker theoretical fence tak tabhi draw hota hai jab exact fence value par koi data point exist karta ho. Otherwise, whisker fence ke andar ke sabse extreme actual observed data point par aakar ruk jaata hai.

Q5: showfliers=False pass karne par DataFrame ki rows delete hoti hain ya nahi?

Answer: Bilkul nahi. showfliers=False sirf Matplotlib canvas par outlier dots ki visual visibility ko hide karta hai. Data frame ki koi row remove nahi hoti aur whisker boundaries 100% same rehti hain.

Q6: Jab category names bohot lambe hon toh vertical plot ki jagah horizontal plot kaise banate hain?

Answer: Categorical column ko y variable par aur numerical column ko x variable par pass karke: sns.boxplot(data=df, y='job_title', x='monthly_salary').

Q7: Box plot ke upar sns.stripplot overlay karte waqt kaunsi critical mistake avoid karni chahiye?

Answer: Agar aap sns.boxplot mein showfliers=False set nahi karenge, toh box plot ke flier dots aur strip plot ke raw dots dono ek ke upar ek draw honge (double plotting), jisse points artificially dense aur darker dikhenge!

Q8: Box plot kis type ke data distribution ko detect karne mein fail ho jaata hai?

Answer: Bimodal aur Multimodal distributions. Box plot do alag-alag peaks ko ek wide continuous spread ki tarah summarize kar deta hai aur median ko dono peaks ke beech ke khali dip mein place kar deta hai.

Q9: whis=3.0 set karne par box plot kaisa behave karta hai?

Answer: Whisker reach 3.0×IQR tak extend ho jaati hai. Isse normal variance ke mild outliers flag nahi hote; sirf Extreme / Far Outliers hi visual dots ke roop mein appear hote hain.

Q10: Seaborn 0.13+ mein gap parameter ka kya role hota hai?

Answer: Jab hue variable use karke dodged sub-groups draw kiye jaate hain, toh gap=0.1 parameter adjacent hue boxes ke beech clean visual space add karta hai taaki bars aapas mein chipke na rahein.

Q11: Outlier markers ko red diamond shape dene ke liye kaunsa parameter use karenge?

Answer: flierprops=dict(marker='D', markerfacecolor='#f43f5e', markeredgecolor='#ffffff', markersize=8).

Q12: Agar box plot mein median line bottom quartile (Q1) ke bohot paas ho aur upper whisker bohot lamba ho, toh distribution ka skewness kya hai?

Answer: Right-Skewed (Positively Skewed) distribution. Data mein high values ki taraf lambi tail exist karti hai.

Q13: Agar median line upper quartile (Q3) ke paas ho aur lower whisker lamba ho, toh skewness kya hai?

Answer: Left-Skewed (Negatively Skewed) distribution. Majority values high hain, aur low values ki taraf lambi tail hai.

Q14: Categories ko unke median value ke according sort karke plot kaise karenge?

Answer: Groupby karke medians sort karein aur order pass karein:

sorted_order = df.groupby('category')['value'].median().sort_values().index
sns.boxplot(data=df, x='category', y='value', order=sorted_order)
Q15: Box plot ke andar Mean value kaise display ki jaati hai?

Answer: showmeans=True pass karein aur meanprops=dict(marker='^', markerfacecolor='green', markersize=8) ke zariye marker style customize karein.

Q16: Financial risk modeling mein standard 1.5×IQR fences ke bajaye percentile whiskers kaise set karte hain?

Answer: whis=(5, 95) ya whis=(1, 99) tuple pass karke.

Q17: Mean aur Standard Deviation ke comparison mein Median aur IQR ko "Robust Statistics" kyun kaha jaata hai?

Answer: Kyunki unka breakdown point 50% hota hai. Ek single massive outlier mean ko infinitely pull kar sakta hai, lekin median aur middle 50% IQR par single extreme value ka koi farak nahi padta.

Q18: Seaborn 0.13+ mein single-variable boxplot par palette pass karne se warning kyun aati hai aur uska clean fix kya hai?

Answer: Seaborn 0.13+ enforce karta hai ki agar palette use ho toh hue defined hona chahiye. Clean fix: hue='category_col', legend=False pass karein.

Q19: Box plot vs Violin plot: kab Violin plot prefer karna chahiye?

Answer: Jab dataset bada ho (N > 100) aur suspect ho ki distribution bimodal ya complex multi-peaked ho sakta hai.

Q20: Box plot width ko adjust karne ke liye kaunsa parameter use hota hai?

Answer: width=0.45 (default is 0.8).

Q21: Capstone Mini-Project: Automated Outlier Auditor & Boxplot Pipeline

Industry Pipeline Implementation: Yeh automated function kisi bhi DataFrame column ka 5-number summary calculate karta hai, outliers extract karta hai, aur polished boxplot generate karta hai:

import numpy as np
import pandas as pd
import seaborn as sns
import matplotlib.pyplot as plt

def audit_column_distribution(df, col_name, category_col=None):
    # Five-number summary calculations
    q1 = df[col_name].quantile(0.25)
    med = df[col_name].median()
    q3 = df[col_name].quantile(0.75)
    iqr = q3 - q1
    lf = q1 - 1.5 * iqr
    uf = q3 + 1.5 * iqr
    
    outliers = df[(df[col_name] < lf) | (df[col_name] > uf)][col_name]
    
    print(f"=== DISTRIBUTION AUDIT: {col_name} ===")
    print(f"Q1: {q1:.2f} | Median: {med:.2f} | Q3: {q3:.2f} | IQR: {iqr:.2f}")
    print(f"Fences: [{lf:.2f}, {uf:.2f}]")
    print(f"Outlier Count: {len(outliers)} ({len(outliers)/len(df)*100:.1f}%)")
    
    fig, ax = plt.subplots(figsize=(8, 5))
    if category_col:
        sns.boxplot(data=df, x=category_col, y=col_name, ax=ax, palette='Set2')
    else:
        sns.boxplot(y=df[col_name], ax=ax, color='#0284c7', width=0.4)
    ax.set_title(f"Box Plot Audit: {col_name}")
    plt.tight_layout()
    return fig
