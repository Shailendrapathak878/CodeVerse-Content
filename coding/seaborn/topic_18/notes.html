01 Section A • Introduction to Figure and Axes

Seaborn sikhne wale 90% students ka sabse bada confusion hota hai: "Jab main plt.title() likhta hoon toh title kahan lagta hai? Aur sns.scatterplot() me ax= kyu pass kar sakte hain jabki sns.relplot() me ax= likhne par error aa jata hai?"

Is confusion ko hamesha ke liye khatam karne ke liye hume Matplotlib ki underlying architecture samajhni hogi, kyunki Seaborn koi separate rendering engine nahi hai — Seaborn Matplotlib ke kandhon par khada ek sophisticated statistical wrapper hai!

1.1 The Painter's Canvas Analogy (Figure vs Axes)

Socho tum ek art gallery me khade ho:

  • Figure (The Wooden Frame & Canvas): Yeh overall picture window hai. Iska size (figsize=(width, height)), background color, DPI resolution, aur super-title (fig.suptitle()) hota hai. Figure akela data points draw nahi karta; yeh sirf ek container hai.
  • Axes (The Individual Painting on the Canvas): Figure ke andar jo coordinate boundary hoti hai — jisme X-axis aur Y-axis, ticks, labels, title, aur actual visual data marks (points, lines, bars) hote hain — us individual rectangular area ko Axes kehte hain. (Note: Axes plural nahi, singular box ke liye bhi yahi term use hoti hai).
  • One Figure, Multiple Axes: Ek single Figure frame ke andar 1, 2, 4 ya 10 alag-alag Axes (subplots) ho sakte hain!
Figure 18.1: Structural Anatomy of Matplotlib Figure vs Axes • Outer blue boundary represents the Figure object; inner white cards represent two distinct Axes objects hosting independent coordinate systems.

1.2 How Seaborn Renders on Matplotlib Objects

Jab bhi aap koi Seaborn chart draw karte hain, internally do baatein ho sakti hain:

  1. Direct Drawing (Axes-Level): Aap Seaborn ko batate hain ki "Bhai, yeh raha mera ax, iske andar scatter plot draw kar do." Function chupchap us ax par points plot kar deta hai aur wahi ax return karta hai.
  2. Canvas Takeover (Figure-Level): Aap Seaborn ko kehte hain ki "Mujhe department-wise 4 subplots chahiye." Yahan Seaborn khud ek naya Figure create karta hai, usme 4 Axes tile karta hai, data ko partition karta hai, aur pura Figure manage karne wala ek FacetGrid object return karta hai.
Figure 18.2: One Single Matplotlib Figure Containing Three Distinct Axes • Scatter plot (Axes 0), Box plot (Axes 1), aur Histogram (Axes 2) ek hi Figure window ke andar seamlessly coexist kar rahe hain.

Example 1: Creating a Figure with Single Axes Explicitly

Yeh Matplotlib ka standard object-oriented paradigm hai jo har data scientist ko aana chahiye:

Python • Example 1: Explicit Figure and Axes Creation 
import matplotlib.pyplot as plt
import seaborn as sns
import pandas as pd

# Load verified student performance dataset
df = pd.read_csv("scratch/seaborn_topic18_data/student_performance_dataset.csv")

# 2. Inspect the objects created

# 3. Use ax directly

ax.set_title("Study Hours vs Marks (Native Matplotlib on ax)", fontsize=11, weight="bold")
ax.set_xlabel("Daily Study Hours")
ax.set_ylabel("Marks (%)")
ax.grid(True, linestyle=":", alpha=0.5)

plt.show()

02 Section B • What Are Axes-Level Functions?

Axes-level functions Seaborn ke basic building blocks hain. Inka simple definition hai:

Core Definition • Axes-Level Function

Ek aisi function jo kisi ek particular coordinate space (Axes) par graph draw karti hai aur almost hamesha ek ax parameter accept karti hai. Yeh function khud koi naya figure structure invent nahi karti — jo ax aap ise doge, yeh usi ke borders ke andar plot draw karegi.

The Standard Axes-Level Roster in Seaborn

Neeche diye gaye sabhi functions purely axes-level hain:

Visual Category Axes-Level Function Accepts ax=? Return Type Typical Purpose
Relational sns.scatterplot(), sns.lineplot() Yes matplotlib.axes.Axes Two continuous variables ka relationship single coordinate frame me dekhna.
Distribution sns.histplot(), sns.kdeplot(), sns.ecdfplot(), sns.rugplot() Yes matplotlib.axes.Axes Single variable ka frequency distribution ya probability density plot karna.
Categorical sns.boxplot(), sns.violinplot(), sns.barplot(), sns.stripplot(), sns.swarmplot(), sns.pointplot() Yes matplotlib.axes.Axes Categories ke across values compare karna (quartiles, medians, aggregates).
Matrix sns.heatmap() Yes matplotlib.axes.Axes 2D correlation matrix ya grid heatmap draw karna.
Figure 18.3: Axes-Level sns.scatterplot(ax=ax) • Explicit user-supplied Axes par baseline threshold line aur custom legend ke sath render kiya gaya hai.

How an Axes-Level Function Uses the Provided ax

Jab aap likhte hain: 

fig, ax = plt.subplots(figsize=(8, 5))
sns.scatterplot(data=df, x="study_hours", y="marks", ax=ax)

Toh step-by-step kya hota hai?

  • Step 1: plt.subplots() ek naya Figure aur ek naya ax allocate karta hai.
  • Step 2: sns.scatterplot ko woh ax reference milta hai. Function us ax ke coordinate limits aur ticks ko data ke hisaab se adjust karta hai aur points plot karta hai.
  • Step 3: Function wahi ax object return karta hai, jisse aap chaining ya further customization (jaise ax.set_title(), ax.axhline()) kar sakte hain.
  • Step 4: Agar aap ax=ax pass NA karein, toh Seaborn automatically Matplotlib ka current active axes (plt.gca()) dhoond kar uspe plot draw kar deta hai.
Figure 18.4: Combining Two Axes-Level Functions (boxplot & histplot) • Ek hi figure ke andar ax=axes[0] aur ax=axes[1] pass karke do completely different chart types flawlessly integrate ho gaye.

Example 3: Direct Axes-Level Scatter Plot with Reference Threshold

Python • Example 3: Axes-Level Customization 
import matplotlib.pyplot as plt
import seaborn as sns
import pandas as pd

df = pd.read_csv("scratch/seaborn_topic18_data/student_performance_dataset.csv")

fig, ax = plt.subplots(figsize=(7.5, 4.8))

# Draw axes-level scatter plot directly on ax
res_ax = sns.scatterplot(
    data=df,
    x="study_hours",
    y="marks",
    hue="department",
    palette="tab10",
    s=65,
    alpha=0.85,
    ax=ax
)

# Verify return type
print("Returned object is ax:", res_ax is ax)  # True

# Customize via ax methods
ax.set_title("Axes-Level sns.scatterplot(ax=ax)", fontsize=11, weight="bold")
ax.set_xlabel("Daily Study Hours")
ax.set_ylabel("Final Marks (%)")
ax.axhline(50, color="#EF4444", linestyle="--", label="Pass Mark (50%)")
ax.legend(title="Department", loc="lower right")
ax.grid(True, linestyle=":", alpha=0.5)

plt.show()

03 Section C • What Are Figure-Level Functions?

Ab socho tumhe ek dataset ko 4 alag-alag departments ke hisaab se 4 separate panels me split karna hai. Agar tum axes-level function use karoge, toh tumhe manual for loop likhna padega, data filter karna padega, har subplot ka title set karna padega, aur shared y-limits sync karni padengi (8+ lines of tedious code).

Is problem ko solve karne ke liye Seaborn ne design kiye Figure-Level Functions!

Core Definition • Figure-Level Function

Ek aisi high-level function jo apna Figure aur pura layout khud manage karti hai. Yeh functions multi-panel faceting (col=..., row=...) ko first-class support karti hain aur legend ko automatically figure ke bahar organize kar deti hain. Golden Rule: Figure-level functions ax parameter accept NAHI karti!

The Big Three Figure-Level Families (+ Special Matrix Grids)

Modern Seaborn me har visualization category ka ek primary Figure-Level wrapper hota hai:

Figure-Level Function Supported Varieties (kind=...) Wraps Under the Hood Returned Object
sns.relplot() "scatter" (default), "line" FacetGrid + scatterplot / lineplot seaborn.axisgrid.FacetGrid
sns.displot() "hist" (default), "kde", "ecdf" FacetGrid + histplot / kdeplot / ecdfplot seaborn.axisgrid.FacetGrid
sns.catplot() "strip" (default), "box", "violin", "bar", "point", "count" FacetGrid + boxplot / violinplot, etc. seaborn.axisgrid.FacetGrid
sns.jointplot() Bivariate scatter/kde + marginal distributions JointGrid seaborn.axisgrid.JointGrid
sns.pairplot() All pairwise bivariate scatters + diagonal univariates PairGrid seaborn.axisgrid.PairGrid
Figure 18.5: Figure-Level sns.relplot() • 4 academic departments ko automatically horizontal subplots me split kiya gaya hai, synchronized Y-axis scale aur clean outside legend ke sath.

Why Figure-Level Functions Are So Powerful

  • Faceted Comparisons Made Trivial: Sirf col="department" ya row="segment" pass karne se Seaborn khud mathematical subplots matrix bana deta hai.
  • Unified Semantic Legend: Axes-level plots me legend often data points ke upar overlap ho jati hai. Figure-level functions legend ko automatically figure canvas ke right-side margin me place karti hain.
  • Consistent Shared Limits: Subplots me default sharex=True aur sharey=True hota hai, jisse visual comparisons mathematically honest rehte hain.
Figure 18.6: Figure-Level sns.displot(kind="kde", col_wrap=2) • 4 API routes ke latency profiles ko 2x2 grid me wrap kiya gaya hai built-in FacetGrid engine ke zariye.

Example 5: Faceted Relational Scatter Plot Using relplot()

Python • Example 5: Figure-Level relplot 
import seaborn as sns
import matplotlib.pyplot as plt
import pandas as pd

df = pd.read_csv("scratch/seaborn_topic18_data/student_performance_dataset.csv")

# Figure-level command manages its own figure & layout
g = sns.relplot(
    data=df,
    x="study_hours",
    y="marks",
    col="department",
    hue="pass_status",
    palette={"Pass": "#059669", "Fail": "#DC2626"},
    kind="scatter",
    s=65,
    height=3.4,
    aspect=0.95
)

# Verify return type
print("Returned object is FacetGrid:", type(g))

# Customize via FacetGrid methods
g.fig.subplots_adjust(top=0.85)
g.fig.suptitle("Faceted Student Marks by Faculty (sns.relplot)", fontsize=12, weight="bold")
g.set_axis_labels("Daily Study Hours", "Marks (%)")
g.set_titles(col_template="Faculty: {col_name}", weight="bold")

plt.show()

04 Section D • Axes-Level vs Figure-Level: Direct Comparison

Ab hum dono paradigms ko side-by-side compare karenge. Yeh distinction sirf theory nahi hai — yeh decide karta hai ki aapka Python code 2 lines ka hoga ya 20 lines ka, aur kya aapka visualization bina kisi bug ke render hoga!

Evaluation Dimension Axes-Level Functions (e.g. scatterplot) Figure-Level Functions (e.g. relplot)
Primary Purpose Pre-existing coordinate space (Axes) par specific statistical mark draw karna. Comprehensive multi-panel visualization create karna jisme layout aur faceting automated ho.
Figure & Axes Control User Figure aur Axes provide karta hai (via ax=ax). Function apna Figure aur multiple Axes khud allocate aur organize karti hai.
Supports ax= parameter? YES (Core feature) NO (Passing ax= raises error or warning and is ignored)
Faceting Support (col, row) NO (Aapko manual for loop aur data subsetting karni padti hai) YES (Built-in via col="category", row="category", col_wrap=K)
Return Object Type matplotlib.axes.Axes (or subclass AxesSubplot) seaborn.axisgrid.FacetGrid (or JointGrid / PairGrid)
Legend Management Axes ke andar place hoti hai; data points ke sath overlap hone ka risk rehta hai. Figure window ke right margin me bahar automatically dock hoti hai.
Custom Matplotlib Integration High (Native Matplotlib methods jaise ax.axhline(), ax.text() direct call hote hain). Moderate (Pehle g.axes array ya g.fig access karna padta hai).
Best Used When... Aap ek multi-plot custom dashboard (e.g. 2x2 grid with 4 different chart families) bana rahe hon. Aap categorical subsets ke beech relationship ya distribution comparison explore kar rahe hon.
Figure 18.7: Direct Visual Paradigm Comparison • [Left] Axes-level single frame me sabhi departments ka data overlap ho raha hai. [Right] Figure-level relplot() data ko 4 clean subplots me categorize karke visual clutter eliminate kar deta hai.

Function Pairs: Related by Family, Different by Architecture

Hamesha yaad rakhein ki Seaborn me functions pairs me aate hain. Inka data calculation logic same hota hai, lekin canvas management opposite hoti hai:

  • sns.scatterplot() (Axes-level) ↔ sns.relplot(kind="scatter") (Figure-level)
  • sns.lineplot() (Axes-level) ↔ sns.relplot(kind="line") (Figure-level)
  • sns.histplot() (Axes-level) ↔ sns.displot(kind="hist") (Figure-level)
  • sns.kdeplot() (Axes-level) ↔ sns.displot(kind="kde") (Figure-level)
  • sns.boxplot() (Axes-level) ↔ sns.catplot(kind="box") (Figure-level)
  • sns.barplot() (Axes-level) ↔ sns.catplot(kind="bar") (Figure-level)
Figure 18.8: Distribution Comparison • [Left] sns.histplot(ax=ax) layers overlapping density steps. [Right] sns.displot(kind="kde", col="dept") cleanly isolates each faculty into its own dedicated density frame.

import pandas as pd

05 Section E • Working With Matplotlib Subplots

Ab agar aapko ek heterogeneous dashboard banana ho — jahan Panel A me Scatterplot ho, Panel B me Boxplot ho, Panel C me Histogram ho, aur Panel D me Trendline ho — toh Figure-level function (jaise relplot) yeh nahi kar sakti, kyunki relplot sabhi subplots me same chart family draw karti hai!

Aise scenario me Matplotlib plt.subplots() + Axes-Level functions ka combination sabse powerful weapon ban jata hai.

5.1 Unpacking Subplot Grids (1D vs 2D Arrays)

Jab aap fig, axes = plt.subplots(nrows, ncols) likhte hain, toh axes ka structure dimensions ke sath badalta hai:

  • plt.subplots(1, 2) → axes ek 1D NumPy array hota hai: axes[0] aur axes[1].
  • plt.subplots(2, 2) → axes ek 2D NumPy array matrix hota hai: axes[row, col] (e.g. axes[0, 0], axes[0, 1], axes[1, 0], axes[1, 1]).
  • Pro-Tip: 2D array ko flatten karne ke liye axes.flat use karein: for ax in axes.flat: ax.grid(True).
Figure 18.9: Custom 2x2 Multi-Plot Dashboard • Matplotlib plt.subplots(2, 2) coordinate canvas par 4 completely diverse axes-level functions (Scatterplot, Boxplot, Histplot, Lineplot) integrate kiye gaye hain.

5.2 Shared Axes Limits (sharex & sharey)

Jab aap subplots me same metric compare kar rahe hon, toh sharex=True aur sharey=True pass karna zaroori hai. Isse Matplotlib sabhi axes ki boundaries ko identical scale par lock kar deta hai, jisse visual comparisons completely accurate rehte hain:

Figure 18.10: Matplotlib Subplots with Shared Axes • sharex=True, sharey=True enforces identical coordinate spans across all 4 departments for fair visual evaluation.

06 Section F • The Faceting Difference: Manual vs Automated

Multi-panel visualization banane ke do approaches hote hain:

  1. Manual Iteration Approach (Axes-Level): Python loop ke zariye har category ko filter karke individual axes[i] par plot karna.
  2. Declarative Faceting Approach (Figure-Level): Seaborn ko bolna: col="department", aur baki sara arrangement Seaborn ke haath chhod dena.
Figure 18.11: The Faceting Abstraction • Manual for-loop strategy gives deep surgical control over each individual subplot, while Figure-level relplot() achieves the same output in a single declarative statement.
When is Manual Loop Actually Superior?

Students aksar sochte hain ki "Jab relplot itna aasan hai toh manual loop kyu seekhe?"
Answer: Agar aapko har panel me alag custom logic lagana ho — jaise Panel 1 par average line draw karni ho, Panel 2 par outlier highlight karna ho, aur Panel 3 par text annotation likhna ho — toh relplot me yeh karna mushkil hota hai. Manual axes loop aapko 100% surgical freedom deta hai!

Example 11: Manual For-Loop Faceting with Per-Panel Thresholds

Python • Example 11: Granular Subplot Control 
import matplotlib.pyplot as plt
import seaborn as sns
import pandas as pd

df = pd.read_csv("scratch/seaborn_topic18_data/student_performance_dataset.csv")

depts = df["department"].unique()
fig, axes = plt.subplots(1, len(depts), figsize=(14, 3.8), sharey=True)

10 Section J • Return Objects & Customization Methods

Jab aap kisi plotting function ko call karte hain, toh woh Python me ek specific object return karti hai. Agar aapko yeh pata nahi hai ki kaunsa function kya return karta hai, toh aap titles, labels, ya limits customize karte waqt AttributeError ka shikar ho jayenge!

Figure 18.18: Object Hierarchy & Return Types in Seaborn 0.13+ • Axes-level functions return matplotlib.axes.Axes, whereas figure-level functions return seaborn.axisgrid.FacetGrid, JointGrid, or PairGrid.
Plotting Call Exact Return Type (Seaborn 0.13+) How to Set Title How to Set Labels How to Access Internal Axes
ax = sns.scatterplot(...) matplotlib.axes.Axes ax.set_title("...") ax.set_xlabel("..."), ax.set_ylabel("...") It is already the single Axes object!
ax = sns.boxplot(...) matplotlib.axes.Axes ax.set_title("...") ax.set_xlabel("..."), ax.set_ylabel("...") It is already the single Axes object!
g = sns.relplot(...) seaborn.axisgrid.FacetGrid g.set_titles("...") or g.fig.suptitle("...") g.set_axis_labels("x", "y") g.axes (NumPy array of sub-axes)
g = sns.displot(...) seaborn.axisgrid.FacetGrid g.set_titles("...") or g.fig.suptitle("...") g.set_axis_labels("x", "y") g.axes (NumPy array of sub-axes)
g = sns.catplot(...) seaborn.axisgrid.FacetGrid g.set_titles("...") or g.fig.suptitle("...") g.set_axis_labels("x", "y") g.axes (NumPy array of sub-axes)
g = sns.jointplot(...) seaborn.axisgrid.JointGrid g.fig.suptitle("...") g.set_axis_labels("x", "y") g.ax_joint, g.ax_marg_x, g.ax_marg_y
g = sns.pairplot(...) seaborn.axisgrid.PairGrid g.fig.suptitle("...") Automatic column headers g.axes (2D NumPy array matrix)
Figure 18.19: Customization Methods Cheat-Sheet • [Left] Direct Axes methods (ax.set_title, ax.axhline). [Right] FacetGrid wrapper methods (g.set_titles, g.fig.suptitle).
Why plt.title() Fails on Multi-Plot Layouts

Students aksar likhte hain: plt.title("My Title").
Danger: plt.title() sirf current active axes par title lagata hai. Agar aapne 4 subplots banaye hain, toh title sirf chauthe (last) subplot ke sar par baith jayega, jabki pure figure ka header khali reh jayega! Hamesha explicit methods use karein: Figure-level ke liye g.fig.suptitle() aur individual axes ke liye ax.set_title().

11 Section K • Common Mistakes & Troubleshooting Guide

Beginners ke codes me figure-level aur axes-level functions ko mix karte waqt kuch classic galtiyan hoti hain. Neeche diye gaye 14 critical pitfalls aur unke exact code solutions ko dhyan se study karein:

# Common Mistake / Antipattern What Happens (Symptom & Error) The Exact Code Solution
1 Passing ax= to a Figure-Level function TypeError: relplot() got an unexpected keyword argument 'ax', ya unused blank figure create ho jati hai. Figure-level functions me ax= kabhi na pass karein; unhe seedha call karein.
2 Using plt.figure(figsize=(...)) before relplot() Figure-level function apna naya figure kholti hai; aapka pehla figure khali window bankar reh jata hai. Figure-level plots ka size height=... aur aspect=... parameters se set karein.
3 Assuming all Figure-level functions return the same type Calling g.set_titles() on sns.jointplot() raises AttributeError. Remember: relplot/displot/catplot return FacetGrid; jointplot returns JointGrid.
4 Calling ax.suptitle() instead of fig.suptitle() AttributeError: 'Axes' object has no attribute 'suptitle'. Use ax.set_title() for individual subplots and fig.suptitle() for the entire canvas.
5 Calling fig.set_title() instead of fig.suptitle() AttributeError: 'Figure' object has no attribute 'set_title'. Use fig.suptitle("...") or ax.set_title("...").
6 Incorrect 2D Subplot Indexing (e.g. axes[1] on a 2x2 grid) IndexError: too many indices or unexpected row selection. Use 2D indexing axes[0, 1] or flatten with axes.flat[1].
7 Mixing plt.title() in a loop of subplots All titles overwrite each other on the last subplot. Use axes[i].set_title("...") explicitly inside the loop.
8 Using relplot() when you need an asymmetric dashboard Cannot put a barplot and scatterplot in the same relplot call. Use fig, axes = plt.subplots(1, 2) with individual axes-level functions.
9 Legend overlapping data points in axes-level plot Crowded points get hidden under the legend card. Move legend outside via ax.legend(bbox_to_anchor=(1.02, 1), loc='upper left').
10 Inconsistent Y-axis scales in manual subplot comparisons Viewer misinterprets a small variance as huge due to zoomed-in local axis. Pass sharey=True in plt.subplots() or manually set ax.set_ylim().
11 Memory leaks in batch plotting loops More than 20 figures have been opened warning, RAM spikes. Call plt.close(fig) or plt.close('all') at the end of each iteration.
12 Using deprecated ci=None parameter FutureWarning: The `ci` parameter is deprecated. Use `errorbar=None`. Replace ci=None with errorbar=None across all Seaborn 0.13+ code.
13 Passing palette without hue FutureWarning: Passing `palette` without assigning `hue` is deprecated. Assign hue="column_name" and set legend=False if a legend is not needed.
14 Suptitle colliding with facet headers The top super-title text overlaps with column titles. Add margin breathing room via g.fig.subplots_adjust(top=0.88) before suptitle.
Figure 18.20: Common Pitfalls Visual Guide • [Left] Anti-pattern of attempting to pass ax= to sns.relplot() leaves an empty phantom figure. [Right] Clean separation: use axes-level for subplots and figure-level for standalone faceting.

Core Parameters Cheat Sheet • What Goes Where?

Parameter Supported In Axes-Level? Supported In Figure-Level? Exact Role & Significance
ax YES NO Draws the visual mark directly on the designated Matplotlib Axes.
col, row NO YES Partitions dataset across horizontal columns or vertical rows of subplots.
col_wrap NO YES Wraps long horizontal column arrays across multiple grid rows.
height, aspect NO YES Controls vertical height and aspect ratio per subplot facet.
data, x, y YES YES Core data mapping parameters common across both families.
hue, style, size YES YES Semantic visual encodings available across both paradigms.
palette YES YES Custom color scheme mapping categories to distinct hues.
errorbar YES YES Statistical uncertainty calculation (replaces deprecated ci in 0.13+).

Example 27: Programmatic Figure Cleanup in Production Pipelines

Python • Example 27: Safe Memory Management with plt.close() 
import matplotlib.pyplot as plt
import seaborn as sns
import pandas as pd

df = pd.read_csv("scratch/seaborn_topic18_data/student_performance_dataset.csv")

# Clean memory loop in batch reporting pipelines
for d in df["department"].unique():
    fig, ax = plt.subplots(figsize=(6, 4))
    sub = df[df["department"] == d]
    sns.scatterplot(data=sub, x="study_hours", y="marks", ax=ax)
    ax.set_title(f"Report: {d}")
    # Export and immediately release memory
    fig.savefig(f"temp_report_{d}.png", bbox_inches="tight")
    plt.close(fig)  # Prevents RAM leaks!

print("Batch reporting executed cleanly without memory accumulation!")
