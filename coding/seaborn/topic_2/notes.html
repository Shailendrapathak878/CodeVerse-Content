🚀 01. What is Seaborn Setup & Figure Structure? (Kyu Zaroori Hai?)

Topic 1 mein humne dekha ki Seaborn ek high-level statistical library hai jisse hum raw Pandas DataFrames se 1 line of code mein beautiful charts bana sakte hain. Lekin jab aap industry mein kaam karte hain, toh aap sirf ek single isolated chart display nahi karte — aapko Multi-Panel Dashboards, Side-by-Side Comparisons, aur Custom Labeled Grids generate karne hote hain!

Yahin par aati hai Figure Structure ki understanding. Seaborn koi standalone graphics engine nahi hai; yeh Matplotlib ke upar build hua hai. Jab tak aapko yeh samajh nahi aayega ki Figure (outer canvas) kya hai aur Axes (plotting region) kya hai, tab tak aap charts ko control nahi kar payenge, titles aapas mein collide honge, aur multiple plots ek doosre ke upar overwrite ho jayenge.

🧠 Mental Model for Figure Structure

Sochiye ek Art Gallery Wall:
• Figure: Puri frame ya picture frame jo wall par hung hai (the canvas window).
• Axes: Us frame ke andar bani hui actual painting/chart jisme X-axis aur Y-axis ki boundaries hoti hain.
• Plot Elements: Us painting ke andar ke colors, dots (scatter), bars, lines, aur text labels.
Ek Figure ke andar 1, 2, 4 ya 9 alag-alag Axes (paintings) ho sakte hain!

🖊 04. Understanding Matplotlib's Figure and Axes (The Core Mental Model)

Seaborn ki mastering ka sabse critical concept hai: Figure aur Axes do bilkul alag cheezein hain! Dono ko aapas mein confuse karna beginners ki 90% layout mistakes ki wajah banta hai.

Figure 2.2: The Core Visual Hierarchy — Figure is the canvas frame, Axes is the coordinate plotting area, and Plot Elements are the points, bars, and lines.

Deep Dive: Figure vs. Axes vs. Axis

  • Figure (Canvas Window): Yeh pura image canvas ya outer container hai. Isme puri window ka background color (facecolor), master size (figsize), overall title (fig.suptitle()), aur overall DPI control hota hai. Figure ke andar ek ya multiple Axes ho sakte hain.
  • Axes (Plotting Region): Yeh ek individual graph ya plot area hai jisme X aur Y limits, ticks, tick labels, grid lines, data points, aur subplot title (ax.set_title()) hote hain. English me 'Axes' plural word lagta hai, lekin Matplotlib me 'an Axes' ek single 2D plotting box ka class object hai!
  • Axis (Single Coordinate Dimension): Yeh number line hai — ax.xaxis (horizontal) ya ax.yaxis (vertical) jo scale, tick marks aur axis labels ko control karti hai.

⚖ 05. plt.figure() versus plt.subplots() (Kaunsa Kab Use Karein?)

Matplotlib me canvas initialize karne ke do tareeqe hote hain: plt.figure() aur plt.subplots(). Dono ke beech functional difference samajhna zaroori hai:

Figure 2.6: plt.figure() vs. plt.subplots() — Comparing procedural canvas initialization with object-oriented grid generation.

Understanding Return Types of plt.subplots()

Jab aap plt.subplots(nrows, ncols) call karte hain, toh return hone wale ax / axes object ka shape change hota hai:

Call Signature Number of Plots Axes Return Type How to Access Individual Subplots
plt.subplots() ya (1, 1) 1 Plot Single matplotlib.axes.Axes object Direct: ax.set_title(...)
plt.subplots(1, 2) ya (2, 1) 2 Plots (1 Row ya 1 Col) 1D NumPy Array of Axes shape=(2,) Unpack: (ax1, ax2) = ... ya axes[0], axes[1]
plt.subplots(2, 2) ya (3, 3) 4 ya 9 Plots (2D Grid) 2D NumPy Array of Axes shape=(nrows, ncols) 2D Indexing: axes[0, 0], axes[0, 1] ya axes.flat[i]

Code Example A: Handling a 1D Subplot Tuple (1x2 Layout)

Python • 1x2 Subplot Unpacking Verified Execution 
import matplotlib.pyplot as plt
import seaborn as sns
import pandas as pd

df_college = pd.read_csv("scratch/seaborn_topic2_data/college_performance.csv")

# Tuple unpacking for clean 1x2 subplots
fig, (ax1, ax2) = plt.subplots(1, 2, figsize=(10, 4.5))

# Plot 1: Study hours vs marks
sns.scatterplot(data=df_college.sample(100, random_state=42),
                x="study_hours", y="exam_marks", ax=ax1, color="#3b82f6")
ax1.set_title("Weekly Study Hours vs Marks")

# Plot 2: Attendance vs marks
sns.scatterplot(data=df_college.sample(100, random_state=42),
                x="attendance_pct", y="exam_marks", ax=ax2, color="#10b981")
ax2.set_title("Attendance % vs Marks")

plt.tight_layout()
plt.show()
Executed Output

📊 06. Creating Multiple Charts with Subplots (Dashboard Thinking)

Real-world data science mein ek single metric se kabhi pura picture clear nahi hota. Agar aap college performance dekh rahe hain, toh aapko simultaneously Distribution of Marks, Study Hours Correlation, Attendance Spread, aur Departmental Differences ek sath dekhne padte hain. Isko kehte hain Dashboard Thinking.

Subplots create karne ke 3 golden rules hote hain:

  1. Rule 1 (1 Chart = 1 Question): Har subplot ek specific analytical question ka answer dena chahiye. E.g. Top-left: "Is the data skewed?", Top-right: "Is there correlation?", Bottom: "Which group is highest?".
  2. Rule 2 (Grid Aspect Ratio): Agar aap 2 rows aur 2 columns (4 plots) bana rahe hain, toh figsize ka width aur height proportional hona chahiye, jaise figsize=(12, 8). Agar aap 1 row aur 3 columns bana rahe hain, toh wide aspect ratio rakhein jaise figsize=(15, 4.5).
  3. Rule 3 (Layout Tightening): Hamesha subplots create karne ke baad plt.tight_layout() call karein taaki axes labels aur titles ek doosre ke sath collide na hon!

Complete Runnable Example: E-Commerce 1x2 Subplot Layout

Python • E-Commerce 1x2 Side-by-Side Analysis Verified Execution 
import matplotlib.pyplot as plt
import seaborn as sns
import pandas as pd

df_ecom = pd.read_csv("scratch/seaborn_topic2_data/ecommerce_sales.csv")

fig, (ax1, ax2) = plt.subplots(1, 2, figsize=(11, 4.5))

# Plot 1: Total Revenue by Category
cat_rev = df_ecom.groupby("category")["revenue"].sum().reset_index()
sns.barplot(data=cat_rev, x="category", y="revenue", hue="category", legend=False,
            palette="Blues_r", ax=ax1)
ax1.set_title("Total Revenue by Category (INR)")
ax1.tick_params(axis="x", rotation=25)

# Plot 2: Customer Rating Frequency
sns.countplot(data=df_ecom, x="customer_rating", hue="customer_rating", legend=False,
              palette="Greens", ax=ax2)
ax2.set_title("Order Volume by Rating (1 to 5 Stars)")

plt.tight_layout()
plt.show()
Executed Output
E-Commerce side-by-side plots rendered: Electronics generated highest revenue (INR 88.26 Lakhs), 4-star ratings had highest order volume (210 orders).

🎯 08. Passing Axes to Seaborn Using the ax= Parameter

Seaborn ke almost sabhi standard functions (jaise scatterplot, lineplot, barplot, histplot, boxplot) ek special parameter accept karte hain: ax=. Is parameter ka kaam hota hai Seaborn ko batana ki chart ko screen par kahan draw karna hai.

Figure 2.11: Injecting Plots into Axes via ax=ax — Combining scatterplot with reference mean threshold lines on the exact target plotting canvas.

Code Example: Layering Reference Elements onto an Existing Axes

Python • Explicit ax= Injection with Reference Lines Verified Execution 
import matplotlib.pyplot as plt
import seaborn as sns
import pandas as pd

df_college = pd.read_csv("scratch/seaborn_topic2_data/college_performance.csv")

# Step 1: Create explicit Figure and Axes
fig, ax = plt.subplots(figsize=(8, 4.5))

# Step 2: Inject Seaborn plot directly into 'ax'
sns.scatterplot(data=df_college.sample(120, random_state=42),
                x="study_hours", y="exam_marks",
                color="#3b82f6", s=45, alpha=0.85, ax=ax)

# Step 3: Layer custom Matplotlib benchmarks onto the SAME 'ax'
mean_marks = df_college["exam_marks"].mean() # 60.83
ax.axhline(mean_marks, color="#f59e0b", linestyle="--", lw=1.5, label=f"Cohort Mean ({mean_marks:.1f})")
ax.axvline(5.0, color="#ef4444", linestyle=":", lw=1.5, label="Min Study Target (5h)")

ax.set_title("Student Study Hours with Performance Benchmarks")
ax.legend()
plt.tight_layout()
plt.show()
Executed Output
Plot drawn directly on user-provided Axes. 2 reference lines layered on top of scatter dots.

🧩 09. Figure-Level versus Axes-Level Seaborn Functions (The Essential Duality)

Seaborn library do categories of functions mein divided hai: Axes-Level functions aur Figure-Level functions. Dono ka behavior bilkul alag hota hai aur beginners aksar dono ko galat tareeqe se mix karte hain.

Figure 2.12: The Fundamental Architectural Division — Axes-level functions draw on user-provided Axes, while Figure-level functions manage their own FacetGrid window.

API Mapping: Axes-Level vs. Figure-Level Equivalents

Plotting Goal Axes-Level Function (Takes ax=) Figure-Level Function (Manages FacetGrid) Key Behavioral Difference
Relational (Scatter, Line) sns.scatterplot()
sns.lineplot()		 sns.relplot(..., kind="scatter")
sns.relplot(..., kind="line")		 relplot supports col="category" and row="city" to auto-generate subplots.
Distribution (Hist, KDE) sns.histplot()
sns.kdeplot()		 sns.displot(..., kind="hist")
sns.displot(..., kind="kde")		 displot auto-manages margin subplots and facet wraps.
Categorical (Bar, Box) sns.barplot()
sns.boxplot()		 sns.catplot(..., kind="bar")
sns.catplot(..., kind="box")		 catplot handles multi-category grids seamlessly across columns.
⚠ The #1 Fatal Mistake in Seaborn

Kabhi bhi figure-level functions mein ax= pass mat karein!
E.g. sns.relplot(data=df, x="A", y="B", ax=ax) → TypeError: relplot() got an unexpected keyword argument 'ax'.
Figure-level functions khud apna Figure create karte hain, isliye woh kisi existing ax ke andar fit nahi ho sakte!

🔍 10. Figure Size, Resolution (DPI), and Exporting Visual Assets

Aapne kitna bhi achha chart banaya ho, agar usko mobile screen par open karne par labels dhundhle ya cut ho jayein, toh visualization fail ho jata hai. Figure sizing aur export parameters ko samajhna professional reporting ka core step hai.

Figure 2.13: Impact of Figure Size and DPI — 72 DPI (amateur screen preview) vs. 160+ DPI (crisp publication-ready rendering).

Understanding 'figsize' and 'dpi'

  • figsize=(width, height): Yeh dimensions inches mein specify hoti hain (e.g. figsize=(10, 6) = 10 inches wide, 6 inches tall).
  • DPI (Dots Per Inch): Yeh pixel density control karta hai. Agar figsize=(10, 6) hai aur DPI=100 hai, toh image 1000 × 600 pixels ki hogi. Agar DPI=160 hai, toh image 1600 × 960 pixels ki ultra-crisp image banegi.
Figure 2.18: Production Export Parameters — Utilizing bbox_inches='tight', dpi=160, and facecolor to prevent white border clipping.

Code Example: Exporting a Production Chart with Zero Clipped Labels

Python • Production Export via plt.savefig() Verified Execution 
import matplotlib.pyplot as plt
import seaborn as sns
import pandas as pd

df_college = pd.read_csv("scratch/seaborn_topic2_data/college_performance.csv")

fig, ax = plt.subplots(figsize=(8, 4.5), dpi=160)
sns.boxplot(data=df_college, x="department", y="exam_marks", hue="department",
            legend=False, palette="Blues", ax=ax)
ax.set_title("Departmental Performance Distribution")

# Production-grade save call
plt.savefig("scratch/production_chart.png",
            dpi=160,
            bbox_inches="tight",
            facecolor=fig.get_facecolor(),
            edgecolor="none")
plt.close(fig)
Executed Output
Saved crisp PNG at 160 DPI. Bounding box automatically expanded to include all axis labels and title.

🗖 12. Seaborn Grids: FacetGrid, PairGrid, and JointGrid

Matplotlib ke manual plt.subplots() ke alawa, Seaborn aapko 3 powerful high-level Grid Classes deta hai jo complex multi-panel analysis ko automatically handle karti hain:

Grid Class Primary Analytical Purpose How It Works Seaborn High-Level Wrapper
FacetGrid Subset analysis: Data ko category ke hisaab se split karke har category ka alag subplot banana. Initialize FacetGrid(df, col="cat") → call .map() or .map_dataframe(). sns.relplot(), sns.catplot(), sns.displot()
PairGrid Multivariate exploration: Sabhi numerical columns ke pairwise relationships matrix format mein dekhna. Diagonal par univariate (hist/kde) aur off-diagonal par bivariate scatter plots. sns.pairplot()
JointGrid Bivariate + Marginals: Central relationship plot ke sath top aur right margins par distributions dekhna. Central axes par scatter/kde aur marginal axes par histograms. sns.jointplot()

🚧 16. 14 Common Setup & Figure-Structure Mistakes & Fixes

# Common Mistake / Error Root Cause (Kyu Hota Hai?) Verified Solution (Kaise Theek Karein?)
1 ModuleNotFoundError: No module named 'seaborn' Pip ne package dusre global interpreter mein install kar diya. Hamesha python -m pip install seaborn use karein aur VS Code me active virtualenv select karein.
2 Passing ax= to sns.relplot() or sns.displot() Figure-level functions apna alag Figure manage karte hain aur ax= accept nahi karte. Figure-level ke bajaye axes-level function use karein (scatterplot ya histplot), ya col= use karein.
3 TypeError: 'numpy.ndarray' object has no attribute 'set_title' plt.subplots(2, 2) call karne par axes ek 2D array hota hai, single Axes nahi. Individual element ko index karein: axes[0, 0].set_title(...) ya for ax in axes.flat:.
4 IndexError: too many indices for array: array is 1-dimensional plt.subplots(1, 2) 1D array deta hai, lekin code axes[0, 1] likh raha hai. 1D array ke liye single index use karein: axes[0] aur axes[1].
5 Subplot titles and suptitle overlapping fig.suptitle() ko top margin nahi milta agar subplots_adjust na ho. plt.tight_layout() ke baad fig.subplots_adjust(top=0.88) call karein.
6 Calling plt.title() in a multi-subplot script plt.title() hamesha last active subplot ko modify karta hai. Hamesha explicit ax.set_title() use karein target Axes object par.
7 Forgetting ax=ax in Seaborn calls Plot naye default Matplotlib canvas par chala jata hai bajaye intended subplot cell ke. Function call mein explicitly ax=axes[row, col] pass karein.
8 Calling plt.savefig() AFTER plt.show() plt.show() canvas ko screen par draw karke clear/destroy kar deta hai. Hamesha plt.savefig() ko plt.show() se PEHLE call karein.
9 Clipped axis labels in saved PNGs Matplotlib ka default bounding box tight nahi hota. plt.savefig(..., bbox_inches="tight") pass karein.
10 White borders around dark theme figures Default savefig canvas background white hota hai. plt.savefig(..., facecolor=fig.get_facecolor()) pass karein.
11 Misleading scales on side-by-side charts Do comparative plots ke Y-axes alag range par auto-scale ho gaye. plt.subplots(..., sharey=True) use karein taaki vertical scale locked rahe.
12 Overcrowded FacetGrid / PairGrid Dataset mein 50 categories ya 20 numerical columns the jisse unreadable grid bani. Columns ko vars=[...] se filter karein aur categories ke liye col_wrap=3 use karein.
13 Duplicate legends on every single subplot Seaborn har subplot par apna local legend draw karta hai. Subplots mein legend=False pass karein aur ek single global figure legend banayein.
14 Distorted aspect ratio on mobile screens Width aur height ka ratio screen ke format ke opposite hai. Mobile-first cards ke liye compact aspect ratios jaise figsize=(8, 4.5) prefer karein.

Part 1: Beginner Conceptual Questions (Q1 to Q5)

❓ Q1: Matplotlib ke Figure aur Axes mein fundamental difference kya hai?

Answer: Figure outer canvas window ya picture frame hai jo entire image size (figsize), background color (facecolor), aur global title (suptitle) ko manage karta hai. Jabki Axes us canvas ke andar ka individual plotting region hai jisme X-Y coordinate systems, ticks, data points, aur subplot-specific title hote hain. Ek Figure mein multiple Axes ho sakte hain.

❓ Q2: Package install karte waqt 'python -m pip' likhna kyu behtar hai?

Answer: Plain pip chalane se PATH variable ka pehla pip run ho jata hai jo shayad kisi purane ya global Python ka ho. python -m pip ensure karta hai ki aapka active Python interpreter hi apne corresponding pip module ko run karega, jisse ModuleNotFoundError se bacha ja sakta hai.

❓ Q3: plt.subplots(1, 2) kya return karta hai?

Answer: Yeh ek tuple return karta hai: (fig, axes) jisme fig ek Figure object hota hai aur axes ek 1-dimensional NumPy array hota hai of length 2 (jisko aap fig, (ax1, ax2) = plt.subplots(1, 2) ke through unpack kar sakte hain).

❓ Q4: fig.suptitle() aur ax.set_title() mein kya farq hai?

Answer: fig.suptitle() pore dashboard ka main master title hota hai jo pure Figure canvas ke top par center hota hai. Jabki ax.set_title() sirf us specific individual subplot ke upar title display karta hai.

❓ Q5: Seaborn chart ko specific subplot mein draw karne ke liye kaunsa argument use hota hai?

Answer: ax= argument use hota hai (e.g. sns.scatterplot(..., ax=ax1)).

Part 2: Intermediate Analytical Questions (Q6 to Q10)

❓ Q6: plt.subplots(2, 2) mein returned axes object ko index kaise karte hain?

Answer: Yeh 2D array hota hai shape=(2, 2):
• Top-Left: axes[0, 0]
• Top-Right: axes[0, 1]
• Bottom-Left: axes[1, 0]
• Bottom-Right: axes[1, 1]
Ya sabhi par loop chalane ke liye axes.flat use karein.

❓ Q7: plt.subplots() mein sharey=True parameter ka kya role hai?

Answer: Yeh sabhi subplots ke Y-axis coordinate limits ko lock/synchronize kar deta hai taaki sabhi charts ka vertical scale exact same rahe, aur right side ke subplots ke duplicate Y-axis tick labels ko automatically hide kar deta hai.

❓ Q8: sns.relplot() mein ax= parameter pass karne par kya error aati hai aur kyu?

Answer: TypeError: relplot() got an unexpected keyword argument 'ax' aati hai. Wajah yeh hai ki relplot() ek Figure-level function hai jo khud apna naya FacetGrid window banata hai; woh kisi pehle se bane huye ax ke andar fit nahi ho sakta.

❓ Q9: plt.savefig() call karte waqt bbox_inches="tight" kyu lagana zaroori hai?

Answer: Bounding box ko tight calculate karne se image ke edges par jo rotated axis labels, titles, ya legends hote hain woh crop/cut hone se bach jaate hain.

❓ Q10: FacetGrid, PairGrid aur JointGrid mein primary difference kya hai?

Answer: FacetGrid category ke subsets ko subplots mein split karta hai; PairGrid sabhi numerical metrics ke pairwise scatter/histogram combinations matrix banata hai; aur JointGrid ek central bivariate relationship ke sath top aur right marginal distributions dikhata hai.

Part 5: Debugging Exercises (Q19 to Q20)

🐞 Q19: Debugging — IndexError: too many indices for array

Buggy Code:

fig, axes = plt.subplots(1, 2)
axes[0, 1].set_title("Second Plot") # Crash!

Diagnosis & Fix: plt.subplots(1, 2) returns a 1D array of shape (2,). Indexing it like a 2D array ([0, 1]) causes IndexError. Correct syntax is axes[1].set_title("Second Plot").

🐞 Q20: Debugging — TypeError: displot() got an unexpected keyword argument 'ax'

Buggy Code:

fig, ax = plt.subplots()
sns.displot(data=df, x="exam_marks", ax=ax) # Crash!

Diagnosis & Fix: displot ek Figure-level function hai jo ax= accept nahi karta. Agar aapko existing ax par histogram draw karna hai, toh iska axes-level equivalent sns.histplot(data=df, x="exam_marks", ax=ax) use karein!

import matplotlib.pyplot as plt
import seaborn as sns
import pandas as pd

# Load verified dataset
df = pd.read_csv("scratch/seaborn_topic2_data/college_performance.csv")
