1 Introduction to Exploratory Data Analysis (EDA) & Motivation

Data science aur analytics workflow me EDA (Exploratory Data Analysis) ka matlab hota hai data ko bina kisi bias ke visually aur statistically explore karna. Socho tumhare paas ek college ke 80 students ka dataset hai jisme unke Study_Hours, Attendance_Pct, Assignment_Score, aur Final_Marks recorded hain.

Aam beginner sirf ek simple plt.scatter() draw karta hai. Lekin standard scatter plot me do bohot badi limitations hoti hain:

  • No Marginal Insight: Scatter plot ye toh dikha deta hai ki X aur Y sath me upar ja rahe hain ya nahi, lekin wo ye nahi batata ki X akele kaisa distribute hai (kya study hours normal hain ya heavily skewed?) aur Y akele kaisa distribute hai (kya marks bimodal hain?).
  • Overplotting in Dense Data: Agar dataset me hazaron observations hon, toh scatter points aapas me collide karke ek solid black blob ban jate hain, jisse true frequency density completely conceal ho jati hai!
💡 Why Joint Plots & Pair Plots are Superpowers

Joint Plot (sns.jointplot): Ek hi graphic canvas par do continuous variables ka bivariate relationship (center me) aur dono variables ki apni-apni univariate marginal distributions (top aur right borders par) simultaneously render karta hai!
Pair Plot (sns.pairplot): Ek complete multi-feature dataset ke sabhi numerical columns ka pairwise combination matrix draw karta hai — off-diagonal par bivariate scatter plots aur diagonal par univariate histograms/KDE curves!

Figure 15.1: Exploratory Motivation — Left: Standard scatter plot (relationship only, missing marginal spread). Right: Joint plot combining central bivariate scatter with top & right marginal histograms.
Figure 15.2: Strategic Roles — Joint Plot focuses on deep 2-variable inspection with marginals; Pair Plot performs broad N-variable matrix discovery across an entire dataset.
Figure 15.3: The 3-Tier EDA Progression — From Univariate (single feature) to Bivariate Joint (2 features + marginals) to Multivariate Matrix (pairwise feature scanning).

2 Understanding Joint Plots: Anatomy of JointGrid

Seaborn me sns.jointplot() under-the-hood ek figure-level class JointGrid create karta hai. Ye grid canvas ko 3 coordinated subplots me divide karta hai:

Figure 15.4: Structural Anatomy of a Joint Plot — Central bivariate canvas (ax_joint), Top marginal X distribution (ax_marg_x), and Right marginal Y distribution (ax_marg_y).
Grid Subplot Region Matplotlib Axis Object What It Visualizes Analytical Insights Revealed
Central Joint Canvas g.ax_joint Bivariate relationship between X and Y (Scatter, KDE, Hex, Reg). Direction (positive/negative), slope, clustering, non-linearity, correlation strength.
Top Marginal Canvas g.ax_marg_x Univariate distribution of Independent Variable X (Aligned with X-axis). X-variable ka center, spread, skewness, outliers, aur sample density.
Right Marginal Canvas g.ax_marg_y Univariate distribution of Dependent Variable Y (Rotated, aligned with Y-axis). Y-variable ki modality (unimodal vs bimodal), ceiling effects, floor truncations.

Notice kijiye ki top plot ki horizontal axis central plot ki X-axis ke sath perfectly synchronized hoti hai, aur right plot ki vertical axis central plot ki Y-axis ke sath synchronized hoti hai!

3 Basic sns.jointplot() Syntax & Parameters

Seaborn me basic joint plot banana bohot clean aur readable hai:

Python Syntax
sns.jointplot(data=df, x="feature_x", y="feature_y", kind="scatter", **kwargs)

Supported Parameters in Seaborn 0.13.2

Parameter Default Description & Behavior
data None Tidy Pandas DataFrame containing input features.
x, y None Column names (strings) for horizontal and vertical variables.
kind "scatter" Kind of plot to draw: "scatter", "hist", "kde", "reg", "hex", "resid".
height 6 Size of the figure (since JointGrid is always a square canvas, height = width in inches).
ratio 5 Ratio of joint axes size to marginal axes size. ratio=5 means central plot is 5x larger than marginals.
space 0.2 Spacing buffer between central joint plot and marginal subplots.
hue None Categorical variable producing color-coded groups across both joint and marginal plots.
marginal_ticks False If True, shows numerical tick labels on marginal distribution axes.
joint_kws None Dictionary of keyword arguments passed directly to the central joint plotting function.
marginal_kws None Dictionary of keyword arguments passed directly to the marginal distribution plotting functions.
📏 Pro Tip: Controlling ratio and space

Agar aap chahte hain ki marginal histograms thode bade aur clear dikhein, toh ratio=3 ya ratio=4 use kijiye. Agar aap marginals ko bilkul central plot se sata kar chipkana chahte hain, toh space=0 set kar dijiye!

4 Joint Plot Type 1: Scatter (kind="scatter")

kind="scatter" Seaborn joint plot ka default mode hai. Ye central region me individual scatter points draw karta hai aur marginal regions par clean univariate histograms render karta hai.

Python • Scatter Joint Plot Implementation 
import seaborn as sns
import matplotlib.pyplot as plt
import pandas as pd

# Load student performance dataset
df = pd.read_csv("student_performance_dataset.csv")

# Create Scatter Joint Plot
g = sns.jointplot(
    data=df,
    x="Study_Hours",
    y="Final_Marks",
    kind="scatter",
    color="#2563EB",
    height=5.8,
    ratio=5,
    space=0.2,
    marginal_kws={"bins": 15, "fill": True, "color": "#3B82F6"}
)

g.set_axis_labels("Daily Study Hours", "Final Exam Marks (%)")
plt.show()
Figure 15.5: Scatter Joint Plot (kind='scatter') — Central dots show a strong positive correlation (r = 0.9638), while marginal histograms reveal that both study hours and marks are reasonably well-distributed across the 80 students.
👁️ When to Use kind="scatter"

Scatter joint plot tab sabse best hota hai jab dataset moderate size ka ho (e.g. 50 se 1,000 points). Yahan aap individual students ko clearly inspect kar sakte hain aur unke exact study duration aur exam marks ko visualize kar sakte hain.

5 Joint Plot Type 2: Binned Histograms (kind="hist")

Jab dataset me points densely pack hone lagte hain, toh scatter plot me individual dots overlap ho jate hain. Is situation me kind="hist" ek bohot powerful alternative ban jata hai.

kind="hist" central plot ko 2D Binned Heatmap me convert karta hai jahan canvas ko rectangular grids me divide kiya jata hai aur har grid box ka color shade us region me fall hone wale data points ke frequency count ko represent karta hai!

Python • 2D Histogram Joint Plot 
import seaborn as sns
import matplotlib.pyplot as plt
import pandas as pd

df = pd.read_csv("student_performance_dataset.csv")

# Create 2D Histogram Joint Plot with Colorbar
g = sns.jointplot(
    data=df,
    x="Study_Hours",
    y="Final_Marks",
    kind="hist",
    color="#059669",
    height=5.5,
    ratio=5,
    cbar=True, # Display colorbar indicating observation frequency
    cbar_kws={"shrink": 0.7, "label": "Student Frequency Count"}
)

g.set_axis_labels("Daily Study Hours", "Final Exam Marks (%)")
plt.show()
Figure 15.6: Binned Histogram Joint Plot (kind='hist') — Darker green tiles represent higher concentrations of students, while marginal histograms show the corresponding 1D frequencies on each axis.
💡 Why kind="hist" Solves Overplotting

Agar 20 students ne exactly 5 hours padhkar 70 marks score kiye hain, toh scatter plot par sirf 1 dot dikhega (baki 19 dots piche chhip jayenge!). Lekin kind="hist" us cell ko deep dark shade dega aur colorbar clearly batayega ki yahan 20 students concentrated hain!

6 Joint Plot Type 3: Density Contours (kind="kde")

Agar aap discrete points ya discrete boxes ke bajay smooth statistical probability landscape dekhna chahte hain, toh kind="kde" (Kernel Density Estimation) sabse visually appealing option hai.

Ye central plot par continuous Topographic Elevation Contours (contour rings) draw karta hai — jaise map par pahad ki unchai dikhai jati hai, waise hi yahan concentric rings data ki highest density peaks ko represent karti hain!

Python • 2D KDE Joint Plot 
import seaborn as sns
import matplotlib.pyplot as plt
import pandas as pd

df = pd.read_csv("student_performance_dataset.csv")

# Create Smooth 2D KDE Joint Plot
g = sns.jointplot(
    data=df,
    x="Study_Hours",
    y="Final_Marks",
    kind="kde",
    color="#7C3AED",
    height=5.5,
    ratio=5,
    fill=True, # Fill contours with gradient shading
    cmap="Purples"
)

g.set_axis_labels("Daily Study Hours", "Final Exam Marks (%)")
plt.show()
Figure 15.7: Kernel Density Estimation Joint Plot (kind='kde') — Concentric purple contour rings illuminate the dense center of mass around 5.5 hours and 74 marks, accompanied by smooth marginal bell curves.
⚠️ Critical Caution: KDE is an Approximation!

KDE plot actual discrete observations ko draw nahi karta, balki Gaussian mathematical kernels ke zariye ek continuous smoothed surface interpolate karta hai. Agar dataset bohot chhota ho (e.g. < 25 points), toh KDE artificial peaks fabricate kar sakta hai jo real data me maujood nahi hoteen!

8 Joint Plot Type 5: Hexbin (kind="hex")

Agar aapke paas 5,000 se lekar 500,000 data points ka massive dataset ho (jaise e-commerce clickstream ya ride-sharing GPS pings), toh kind="scatter" computer memory ko choke kar dega aur plot solid black blob ban jayega.

Iska ultimate data-science solution hai Hexagonal Binning (kind="hex"). Ye pure canvas par madhumakkhi ke chhatte (honeycomb) jaisi hexagonal cells draw karta hai:

Python • Hexagonal Binning Joint Plot 
import seaborn as sns
import matplotlib.pyplot as plt
import pandas as pd

df_ecom = pd.read_csv("ecommerce_customer_analytics.csv")

# Create Hexbin Joint Plot
g = sns.jointplot(
    data=df_ecom,
    x="Orders_Placed",
    y="Monthly_Spend_USD",
    kind="hex",
    color="#D97706",
    height=5.5,
    ratio=5,
    gridsize=18, # Number of hexagons in x-direction
    cmap="YlOrBr"
)

g.set_axis_labels("Monthly Orders Placed", "Monthly Spend ($ USD)")
plt.show()
Figure 15.9: Hexbin Joint Plot (kind='hex') — Honeycomb cells seamlessly aggregate dense data points into color-coded frequency hexagons, perfectly suited for large-scale customer transaction volumes.
⬢ Why are Hexagons Superior to Squares?

Geometry ka golden rule: Square cells ke diagonal neighbors side neighbors ke mukable zyada door hote hain (√2 ≈ 1.41× further). Lekin Regular Hexagons me center se sabhi 6 neighbors ka distance mathematically equidistant hota hai! Isliye hexbins natural radial clustering ko bina directional bias ke faithfully represent karte hain!

10 Advanced JointGrid Programming & Overlays

Kabhi-kabhi aapko predefined kind options ke beyond custom hybrid visualization create karni hoti hai — jaise central plot me scatter dots ke upar KDE contour rings overlay karna, aur top margin par histogram ke bajay Boxplot draw karna!

Iske liye hum directly sns.JointGrid class use karte hain:

Python • Custom JointGrid Hybrid Overlay 
import seaborn as sns
import matplotlib.pyplot as plt
import pandas as pd

df = pd.read_csv("student_performance_dataset.csv")

# 1. Initialize custom JointGrid
g = sns.JointGrid(data=df, x="Study_Hours", y="Final_Marks", height=5.8, ratio=5)

# 2. Central plot: Overlay Scatter dots + KDE contour lines
g.plot_joint(sns.scatterplot, color="#2563EB", s=50, alpha=0.75, edgecolors="#1E3A8A")
g.plot_joint(sns.kdeplot, color="#DC2626", levels=5, alpha=0.7, linewidths=1.5)

# 3. Marginals: Boxplot on Top X, KDE curve on Right Y
sns.boxplot(x=df["Study_Hours"], ax=g.ax_marg_x, color="#93C5FD")
sns.kdeplot(y=df["Final_Marks"], ax=g.ax_marg_y, color="#2563EB", fill=True, alpha=0.4)

g.set_axis_labels("Daily Study Hours", "Final Exam Marks (%)")
plt.show()
Figure 15.11: Advanced JointGrid Customization — Demonstrating ultimate programmatic flexibility by composing scatter dots, red KDE contour lines, a top marginal boxplot, and a right marginal density curve.

11 Understanding Pair Plots: Matrix of Multidimensional Visualizations

Ab socho ek real data-science project jisme tumhare paas 4 se lekar 8 numerical columns hain. Agar aap har pair ke liye alag-alag plt.scatter() ya sns.jointplot() banayenge, toh aapko N × (N - 1) / 2 alag-alag plots likhne padenge — 5 features ke liye 10 plots aur 8 features ke liye 28 plots!

Is manual frustration ko eliminate karne ke liye Seaborn deta hai Pair Plot (sns.pairplot). Ye ek hi line of code me ek complete N × N grid matrix render kar deta hai:

Figure 15.12: Structural Anatomy of a PairPlot Matrix — Main Diagonal cells visualize univariate distributions, while Off-Diagonal cells visualize pairwise bivariate relationships.

Pair Plot Matrix ke 2 Fundamental Components

  1. The Main Diagonal Cells (row == col): Yahan horizontal axis aur vertical axis dono par wahi same variable hota hai (e.g. Study_Hours vs Study_Hours). Ek variable ka apne hi sath scatter plot banana useless hoga (kyunki wo seedhi diagonal line ban jayegi), isliye Seaborn diagonal par automatically Univariate Distribution (Histogram ya KDE) draw karta hai!
  2. The Off-Diagonal Cells (row != col): Yahan do alag-alag variables intersect karte hain (e.g. Row = Marks, Col = Study Hours). Ye cells classic Bivariate Scatter Plots hote hain jo correlation aur clustering expose karte hain.

12 Basic sns.pairplot() Syntax & Customization

Seaborn me pair plot ka foundational syntax:

Python Syntax
sns.pairplot(data=df, vars=["col1", "col2", "col3"], hue="Category", **kwargs)

Supported Parameters in Seaborn 0.13.2

Parameter Default Description & Purpose
data Required Tidy Pandas DataFrame containing numerical and categorical features.
vars None List of specific numerical column names to plot. If omitted, plots all numerical columns in DataFrame!
x_vars, y_vars None Allows non-square rectangular matrices by specifying different variables for rows and columns.
hue None Categorical column name for color-coding observations across both diagonal and off-diagonal subplots.
palette None Color palette name or dictionary mapping for hue categories.
kind "scatter" Plot kind for off-diagonal subplots: "scatter", "kde", "hist", "reg".
diag_kind "auto" Plot kind for diagonal subplots: "auto", "hist", "kde", or None to leave blank.
corner False If True, renders only the lower triangle of the matrix, eliminating redundant duplicate cells!
height 2.5 Height (in inches) of each individual subplot panel in the grid.
aspect 1 Aspect ratio of each subplot (aspect * height = width of each panel).
plot_kws None Dictionary of keyword arguments passed to off-diagonal plotting functions (e.g. alpha, s).
diag_kws None Dictionary of keyword arguments passed to diagonal plotting functions.
⚠️ Golden Rule: Always Use the vars Parameter!

Agar aapke DataFrame me 40 columns hain aur aapne bina vars ke simply sns.pairplot(df) run kar diya, toh Seaborn 40 × 40 = 1,600 subplots draw karne ki koshish karega! Computer freeze ho jayega aur Jupyter kernel crash ho jayegi. Hamesha 3 se 6 meaningful numerical columns ko explicitly select kijiye!

14 Matrix Optimization with corner=True

Ek standard 4 × 4 pair plot me total 16 subplots bante hain. Notice kijiye ki diagonal ke upar wala hissa (Upper Triangle) aur diagonal ke niche wala hissa (Lower Triangle) exactly identical information contain karte hain — bas X aur Y axes aapas me swapped (transposed) hote hain!

Upper half ko render karna computational time ko double karta hai aur audience ko redundant visual clutter dikhata hai. Seaborn iska clean solution deta hai: corner=True:

Python • Lower Triangle Corner Optimization 
import seaborn as sns
import matplotlib.pyplot as plt
import pandas as pd

df = pd.read_csv("student_performance_dataset.csv")

# Corner=True renders only lower triangle of matrix
g = sns.pairplot(
    data=df,
    vars=["Study_Hours", "Assignment_Score", "Final_Marks"],
    corner=True, # Drops redundant upper triangle
    height=2.2,
    aspect=1.0,
    plot_kws={"s": 35, "alpha": 0.75, "color": "#059669"},
    diag_kws={"color": "#10B981", "fill": True}
)

plt.show()
Figure 15.14: Corner Optimization (corner=True) — Drops the redundant upper triangle, reducing visual cognitive load by 50% while cutting rendering time in half!

15 Case Study 1: College Student Performance

Real-World Scenario: Ek university academic committee 80 engineering students ke 4 critical performance metrics ka comprehensive multivariate audit conduct kar rahi hai:

  • Study_Hours: Average daily study hours (1.8 to 9.8 hrs, Mean = 5.53 hrs)
  • Attendance_Pct: Lecture attendance percentage (62% to 99%, Mean = 80.07%)
  • Assignment_Score: Cumulative lab & project assignments (40 to 98, Mean = 82.49)
  • Final_Marks: End-semester exam percentage (35 to 99%, Mean = 74.2%)
Python • Case Study 1 Multivariate Pair Plot 
import seaborn as sns
import matplotlib.pyplot as plt
import pandas as pd

df_students = pd.read_csv("student_performance_dataset.csv")

# Full 4-variable pair plot grouped by Academic Major
stu_vars = ["Study_Hours", "Attendance_Pct", "Assignment_Score", "Final_Marks"]

g = sns.pairplot(
    data=df_students,
    vars=stu_vars,
    hue="Academic_Major",
    palette={"Computer Science": "#2563EB", "Data Science": "#059669", "Electronics": "#D97706"},
    diag_kind="kde",
    height=2.0,
    aspect=1.0,
    plot_kws={"s": 35, "alpha": 0.75}
)

g.fig.subplots_adjust(top=0.92)
g.fig.suptitle("College Student Performance 4-Variable Pair Plot by Academic Major", fontweight="bold")
plt.show()
Figure 15.15: Case Study 1 Pair Plot — Notice that Study Hours and Assignment Score show near-perfect linear correlation with Final Marks (r = 0.9638 and r = 0.9269), while Attendance shows wide vertical dispersion (r = 0.1639), proving that mere physical presence in class without active study does not guarantee high marks!
🎯 Academic Analytics Takeaways

1. Study Hours vs Final Marks: Tight upward linear relationship — each daily hour studied contributes approx +6.04% to final marks.
2. Attendance vs Marks: Wide cloud (low correlation r = 0.1639). 95% attendance wale students ke marks bhi 45% se 95% ke beech spread hain — attendance is a prerequisite, not a sufficient condition for mastery!

17 Case Study 3: Fitness & Health Activity Analytics

Modern wearable fitness smartwatches (Apple Watch, Fitbit, Garmin) continuous biometric telemetry log karte hain. Is dataset me 100 users ke biometric signals analyze kiye gaye hain: Daily_Steps, Active_Minutes, Sleep_Hours, aur Calories_Burned, categorized by Fitness_Category (Sedentary, Moderate, Athlete).

Domain Insight: Wearable Biometrics Triangulation

Biomedical analytics me single feature isolated inspection deceptive hoti hai. For example, agar kisi user ke high calories burned record hue hain, to kya wo excessive physical workouts ki wajah se hai ya elevated baseline metabolic rate? Pair plot multidimensional matrix cross-comparison se in teeno user cohorts ke distinct biometric signatures instantly isolate ho jate hain.

Figure 15.17: Multivariate Pair Plot of Wearable Biometrics across Sedentary, Moderate, and Athlete Cohorts with diag_kind="kde" and corner=True. Notice the pristine non-overlapping density separation and positive linear trajectories.

Biometric Relationships & Verified Empirical Findings

  • Daily Steps vs Calories Burned (r = 0.9788): Steps aur Calories ke beech near-perfect linear correlation observe hota hai. Mean Daily Steps 8,596.6 aur Mean Calories 2,618.0 kcal hain. Athletes distinctly top-right quad (>12,000 steps, >3,000 kcal) occupy karte hain.
  • Active Minutes vs Calories Burned (r = 0.9434): Intense active movement energy expenditure ka direct driver hai. Sedentary users (<30 active mins) bottom-left quadrant me tightly clustered hain.
  • Sleep Hours vs Calories Burned (r = 0.6916): Moderate positive trend (Mean sleep: 6.97 hours). Lekin scatter inspect karne par clear plateau effect dikhta hai: 8.5 hours se zyada sleep calories burn ko further amplify nahi karti. Rest recovery phase hai, active expenditure nahi!

19 15+ Common Pitfalls, Anti-Patterns & Debugging Guide

Joint plots aur pair plots powerful figure-level visualizations hain, lekin beginner aur intermediate developers frequently inke execution me common traps me phas jate hain. Neeche 16 real-world pitfalls, unke underlying root causes, aur verified industry fixes diye gaye hain:

# Pitfall / Error Message Root Cause Industry Standard Solution
1 ValueError: Continuous hue not supported for hex kind="hex" underlying hexagonal binning algorithm multi-color overlay support nahi karta. Hex ke saath hue drop karein, ya categorical grouping ke liye kind="kde" ya kind="scatter" use karein.
2 Laggy browser / Out-of-memory crash during sns.pairplot(df) DataFrame me 15+ numerical columns hain, jisse 15 × 15 = 225 subplots render hone lagte hain. Hamesha vars=["col1", "col2", "col3", "col4"] specify karein to limit feature count to ≤ 5.
3 Cognitive clutter from redundant duplicate plots in pairplot Upper triangle lower triangle ka exact transpose hota hai, wasting 50% screen space and doubling render time. Set corner=True to automatically drop the duplicate upper triangle!
4 AttributeError: 'JointGrid' object has no attribute 'ax' sns.jointplot() returns a JointGrid object, not a single Matplotlib Axes. Use g.ax_joint for center plot, or g.ax_marg_x / g.ax_marg_y for marginals.
5 Marginal histogram labels or title chopped off in saved PNG Calling plt.tight_layout() disrupts JointGrid custom marginal axis geometry. Avoid plt.tight_layout() on JointGrid. Instead use g.figure.subplots_adjust(top=0.92).
6 KDE failure / Flat diagonal line: LinAlgError: singular matrix A feature has zero variance (all values identical or binary constant) causing zero covariance in KDE. Set diag_kind="hist" or remove zero-variance constant features before plotting.
7 Trying to embed jointplot() inside plt.subplots(1, 2) jointplot is a figure-level function that creates its own standalone canvas and ignores ax=.... Use individual sns.scatterplot(..., ax=ax1) or manage sub-canvases independently.
8 Continuous float passed to hue creating 500+ color legend Float variable passed to categorical hue argument forces continuous color binning. Discretize continuous column using pd.qcut(df['col'], q=3, labels=['Low', 'Med', 'High']) first.
9 Points completely invisible in dense scatter jointplot Default solid opacity causes thousands of points to overlap identically without depth. Pass joint_kws={"alpha": 0.3, "s": 20} or switch to kind="hex".
10 TypeError: Got both 'linewidth' and 'linewidths' Matplotlib scatter kwarg alias collision when passing linewidth inside plot_kws. Explicitly use linewidths=0.5 (plural) in Matplotlib scatter dictionary arguments.
11 Misaligned diagonal histogram bins across hue groups Each group calculates independent bin edges leading to visually mismatched bars. Pass diag_kws=dict(common_norm=False, bins=15) to align bin calculations.
12 Hexagonal bins stretched into thin ellipses X-axis and Y-axis have wildly different numeric magnitudes (e.g., 0-1 GPA vs 0-50,000 Salary). Tune joint_kws=dict(gridsize=25) or normalize features with standard scaling prior to plotting.
13 Super-title overlaps top marginal plot in JointGrid plt.title() places title on the last active axis (usually right marginal). Use g.figure.suptitle("Main Title", y=1.03) to anchor title on the overarching figure.
14 Entire rows missing due to NaN in unselected columns Passing raw DataFrame with NaNs to pairplot() causes aggressive row dropping. Clean subset explicitly: df.dropna(subset=selected_vars) before passing to Seaborn.
15 Palette color mismatch across categorical groups Custom dictionary keys don't match exact string cases of DataFrame category levels. Verify df['cat'].unique() and map exact string keys in palette={"CatA": "#color"}.
16 Saved figure truncated or edges cut off Using default plt.savefig('plot.png') without bounding box optimization. Always pass bbox_inches="tight" and high resolution dpi=160 (or 300 for print).
