1 Section A — Introduction to Multi-Plot Analysis

Suppose tumhare paas ek college ke 120 students ka data hai. Data me 4 alag-alag departments hain: Computer Science (CS), Engineering, Business, aur Arts. Sath hi har student ek study group (Group A, Group B, Group C) me partitioned hai. Agar tum ek hi single scatter plot par sabhi 12 groups ko alag-alag colors aur markers se draw karne ki koshish karoge, toh kya hoga?

Woh graph ek unreadable dense "ink blob" ban jayega! Har group ke dots ek dusre ke upar overlap ho jayenge, aur yeh pehchanna impossible ho jayega ki CS students ka study pattern Arts students se kitna alag hai. Is visual overcrowding ko solve karne ke liye data science me Multi-Plot Analysis (ya Trellis / Lattice Graphics) use kiya jata hai.

Core Concept: What is Faceting?

Faceting ka matlab hota hai ek bade complex dataset ko categorical variable ke values ke aadhar par chote-chote subsets me split karna, aur har subset ke liye ek separate mini-graph (subplot) create karna, sabhi ko ek structured row-and-column grid canvas par align karke.

Figure 17.1: The Power of Multi-Plot Analysis — [Left] Overcrowded single plot with 12 overlapping cohorts creates cognitive chaos. [Right] Clean 1 × 4 Faceted grid separates each department into its own dedicated panel with uniform axes scales for effortless side-by-side comparison!

Why Multiple Small Graphs Are Superior in Exploratory Data Analysis (EDA)

  • Reduced Cognitive Load: Human brain ek time par 2 se 3 color shades ko hi accurately compare kar sakta hai. 12 colors dekhkar user confuse ho jata hai. Faceting har category ko isolated room deta hai.
  • Shared Visual Scales: Sabhi faceted subplots default me identical X aur Y axis limits share karte hain. Iska matlab hai ki height aur slopes directly visual intuition se compare kiye ja sakte hain!
  • Spotting Sub-Group Anomalies: Agar kisi specific department (e.g. Arts) me study hours ka marks par slope gentle hai jabki Engineering me steep hai, toh faceting me yeh interaction effect instantly identify ho jata hai.
Figure 17.2: Structural Anatomy of a FacetGrid Canvas — The grid orchestrates rows (e.g. row="study_group") and columns (e.g. col="department") with synchronized axes coordinates.

Example 1: Single Crowded Plot vs Clean FacetGrid Concept

Demonstrating how a single function call partitions a dataset into separate department panels:

Python • Example 1: Basic FacetGrid Initialization 
import seaborn as sns
import matplotlib.pyplot as plt
import pandas as pd

# Load verified student performance dataset
df_student = pd.read_csv("scratch/seaborn_topic17_data/student_academic_dataset.csv")

plt.show()

2 Section B — Understanding FacetGrid

Seaborn me FacetGrid ek figure-level object-oriented class hai jo multi-panel visualizations ki foundation banati hai. Yeh do-step execution pattern follow karti hai:

  1. Grid Initialization: g = sns.FacetGrid(data, col="...", row="...") call karke figure aur subplots structure initialize hota hai (empty canvas).
  2. Function Mapping: g.map() ya g.map_dataframe() use karke plotting function ko har subplot cell par execute kiya jata hai.
Figure 17.3: Basic FacetGrid with col="department" — 4 subplots aligned side-by-side, sharing a uniform Y-axis range (40% to 100%).

Core Parameters of FacetGrid

Parameter Type / Default Description & Behavioral Function
data pandas.DataFrame Tidy (long-form) DataFrame jisme categorical columns aur numerical measurements hon.
col str (column name) Categorical variable jo horizontal columns of subplots define karta hai.
row str (column name) Categorical variable jo vertical rows of subplots define karta hai.
hue str (column name) Categorical variable jo har facet ke andar points ko color-code karta hai.
col_wrap int (Default: None) Columns ki maximum limit. Agar categories zyada hon (e.g. 8), toh yeh unhe multiple rows me wrap kar deta hai (cannot be used with row).
height float (Default: 3.0) Har individual subplot ki height in inches.
aspect float (Default: 1.0) Aspect ratio (width = height × aspect). aspect=1.5 makes facets wider.
sharex, sharey bool (Default: True) Whether all subplots share the same X and Y axis limits and tick marks.
margin_titles bool (Default: False) When True and using both row and col, places row titles on the right margin instead of repeating on each panel.

The Critical Importance of Axis Sharing (sharex & sharey)

By default, FacetGrid me sharex=True aur sharey=True hota hai. Yeh ek scientific best practice hai. Agar subplots different scales use karenge, toh reader visually deceive ho sakta hai:

Figure 17.4: Shared Axes vs Independent Axes — [Top Row] sharey=True reveals true absolute differences across departments. [Bottom Row] sharey=False stretches local coordinates, making low-performing cohorts appear artificially inflated!
When is sharey=False Acceptable?

Agar alag-alag facets me completely different scale ke measurements plot kiye ja rahe hon (e.g. ek facet me Server Requests 0-5000 aur dusre me Error Rate 0-10), tab sharey=False zaroori hota hai. Lekin jab same metric compare ho rahi ho, hamesha sharey=True rakhein!

3 Section C — Mapping Plotting Functions

FacetGrid create karne ke baad, magic function mapping ke through hota hai. Seaborn do primary mapping methods provide karta hai: g.map() aur g.map_dataframe().

Method Arguments Pattern How It Operates Recommended Use Case
g.map(func, *args, **kwargs) g.map(plt.hist, "marks", bins=10) Positional column arrays pass karta hai function ko. Useful for classic Matplotlib functions. Simple univariate histograms (plt.hist), scatter plots (plt.scatter).
g.map_dataframe(func, *args, **kwargs) g.map_dataframe(sns.scatterplot, x="hours", y="marks") Passes the subsetted DataFrame directly as keyword arguments. Preserves column names and metadata. Modern Seaborn functions (sns.scatterplot, sns.regplot, sns.kdeplot).

Figure 17.6: Mapping Matplotlib's plt.hist using g.map() — Demonstrates how native Matplotlib plotting calls integrate seamlessly with FacetGrid.

Example 5: Layering Scatter and Regression Lines with map_dataframe()

Python • Example 5: Layered Multi-Plot Mapping 
import seaborn as sns
import matplotlib.pyplot as plt
import pandas as pd

df = pd.read_csv("scratch/seaborn_topic17_data/student_academic_dataset.csv")

Section 4: Faceting Dimensions • row, col, and hue

Jab hum real-world complex datasets analyze karte hain, toh data me multiple categorical attributes hote hain. For example, humare student dataset me department (4 categories), study_group (3 categories), aur attendance_rate jaise factors hain. Seaborn ka FacetGrid humein 3 distinct visual dimensions deta hai jinhe combine karke hum ek hi visualization me 4 ya 5 variables simultaneously explore kar sakte hain:

Dimension Parameter Spatial / Visual Mapping Cognitive Purpose Ideal Number of Categories
col="column_name" Horizontal Panels (Left to Right) Primary category comparison along a shared horizontal axis. 2 to 5 categories (e.g., 4 Departments).
row="column_name" Vertical Panels (Top to Bottom) Secondary category split creating stacked visual baselines. 2 to 4 categories (e.g., 3 Study Groups).
hue="column_name" Color Palette within each panel Sub-segmentation inside the same Cartesian axes. 2 to 4 high-contrast classes (e.g., Attendance High/Low).
style="column_name" Marker shapes or dash styles Additional visual encoding accessible for grayscale or colorblind viewers. 2 to 3 distinct glyphs.

05 • LAYOUT & GEOMETRY TUNING

Section 5: Customizing FacetGrid Geometry & Layout

Default grid settings har dataset ke liye ideal nahi hote. Agar aapke paas 8 categories hain, toh 8 columns ek single horizontal line me squish ho jayenge, jisse text unreadable ho jayega. Is section me hum sikhenge ki subplot geometry, column wrapping, axis scale independence, aur titles ko professionally kaise polish kiya jata hai.

5.1 Subplot Sizing with height and aspect

Matplotlib ke standard figsize=(width, height) ke opposite, Seaborn ka FacetGrid sizing ko per-facet basis par calculate karta hai:

  • height: Har individual subplot ki vertical height in inches (e.g., height=3.5).
  • aspect: Har subplot ka aspect ratio, defined as width / height. So individual facet width = height * aspect.
  • Total Figure Width = height * aspect * n_columns. Total Figure Height = height * n_rows.

5.2 Axis Sharing: sharex and sharey

By default, FacetGrid assumes karta hai ki sabhi subplots me x aur y axes ka scale same hona chahiye (sharex=True, sharey=True). Yeh visual comparison ko fair banata hai kyunki same physical height ka matlab same numerical value hota hai. Lekin real-world me, kuch categories ke scale me 10x ka difference ho sakta hai (jaise lightweight microservice vs heavy checkout transaction). Aise case me shared axis set karne se choti values flat ho jati hain!

Figure 17.11: FacetGrid Aesthetics & Layout Tuning • [Top Row] Unstyled raw default with default column labels and spines. [Bottom Row] Polished publication-grade layout with clean titles, unified limits, and despined frames.
⚠ Critical Trade-off • Fair Comparison vs Detail Zoom

Jab aap sharey=False karte hain, toh har subplot apne data ke [min, max] par zoom-in kar leta hai. Caution: Isse viewer confuse ho sakta hai agar do plots ki visual line same height par ho lekin left plot par 50 ho aur right plot par 500! Always add clear tick labels jab axes unshared hon.

5.3 Column Wrapping with col_wrap

Jab aapke categorical variable me 5 se zyada unique levels hote hain (e.g., 10 US States, 12 Months of the year), toh horizontal row screen se bahar chali jayegi. Is situation ko solve karne ke liye Seaborn deta hai col_wrap=K:

Configuration Grid Dimensions Output Key Constraint
col="month", col_wrap=4 12 categories → 3 Rows × 4 Columns col_wrap cannot be combined with row parameter.
col="region", col_wrap=2 4 regions → 2 Rows × 2 Columns (compact square) Preserves readability on mobile and dashboard layouts.

5.4 Advanced Title and Axis Label Formatting

Default title format department = CS kafi technical aur robotic lagti hai. Seaborn allows templated string customization via g.set_titles():

  • g.set_titles(template="Cohort: {col_name}") → Displays "Cohort: CS", "Cohort: Engineering".
  • g.set_titles(row_template="Group: {row_name}", col_template="Dept: {col_name}") → Customizes both row and column headers in 2D grids.
  • g.set_axis_labels("Study Hours", "Final Exam Score") → Sets outer edge labels while suppressing redundant inner axes labels automatically.
  • g.despine(left=True) → Removes top, right, and optionally left spines for modern, clean visual aesthetics.

Example 9: Professional Layout Formatting with Custom Templates

Python • Example 9: Templated Titles and Clean Despined Facets 
import seaborn as sns
import matplotlib.pyplot as plt
import pandas as pd

df = pd.read_csv("scratch/seaborn_topic17_data/student_academic_dataset.csv")

06 • MODERN SEABORN ARCHITECTURE

Section 6: High-Level Visual Faceting with relplot(), displot(), and catplot()

Beginners aksar puchte hain: "Sir, jab hume FacetGrid initialize karke manually g.map() likhna hi padta hai, toh kya koi aisi function nahi hai jo yeh do-step process ek hi line me kar de?"
Answer is YES! Modern Seaborn (v0.9+) me author Michael Waskom ne figure-level convenience wrappers introduce kiye: sns.relplot(), sns.displot(), aur sns.catplot().

Figure-Level Function Chart Families Supported (kind=...) Underlying Engine Primary Benefit
sns.relplot() "scatter" (default), "line" FacetGrid + scatterplot / lineplot Zero boilerplate faceting with automatic legend placement outside the grid.
sns.displot() "hist" (default), "kde", "ecdf" FacetGrid + histplot / kdeplot / ecdfplot Seamless multi-panel distribution comparisons with shared bins and normalization.
sns.catplot() "strip" (default), "box", "violin", "bar", "point", "count" FacetGrid + boxplot / violinplot, etc. Categorical aggregation across subplots without manual subset filtering loops.

6.1 sns.relplot() for Relational Multi-Panel Visuals

relplot() relational variables (two continuous metrics) ke relationship ko study karne ke liye best hai. Isme aap direct col=..., row=..., hue=..., style=..., aur size=... arguments pass kar sakte hain:

Figure 17.12: sns.relplot(kind="scatter", col="department") mapping study hours to marks with automated cohort hues.

Agar data sequential ya time-series nature ka ho, toh simply kind="line" pass karein:

Figure 17.13: sns.relplot(kind="line", col="region") showing spend trajectory across order frequencies.

6.2 sns.displot() for Distribution Multi-Panel Visuals

Jab aapko multiple groups ke underlying statistical distributions (skewness, modality, tails) compare karne hon, toh sns.displot() standard FacetGrid + map(sns.histplot) se 10x zyada convenient hai:

Figure 17.14: sns.displot(kind="kde", col="endpoint", col_wrap=2) showing kernel density estimates of latency distributions.

6.3 sns.catplot() for Categorical Aggregations

Categorical data visualization (boxplots, violins, point plots, bar plots) ke liye sns.catplot() ultimate Swiss Army knife hai:

Figure 17.15: sns.catplot(kind="box", col="region", x="customer_segment", y="spend_usd") comparing median customer spending.
💡 Architecture Rule of Thumb • When to use Figure-Level vs FacetGrid

Always use Figure-Level functions (relplot, displot, catplot) first! Kyunki yeh cleaner hain, 1 line me execute hote hain, aur inme standard figure-level conveniences built-in hain.
Switch to raw FacetGrid ONLY when: (1) Aapko multiple unrelated plotting layers add karni hon (jaise panel 1 par scatter + panel 2 par custom KDE + panel 3 par threshold line), ya (2) Aap native Matplotlib function (plt.scatter, plt.fill_between) map karna chahte hon.

10 • ARCHITECTURAL SELECTION GUIDE

Section 10: Choosing the Right Multi-Plot Tool • Comprehensive Architecture Comparison

Python data visualization ecosystem me multiple multi-plot tools available hain: FacetGrid, sns.relplot(), sns.displot(), sns.catplot(), sns.PairGrid (Topic 15), aur native Matplotlib ka plt.subplots(). Students aksar confuse hote hain ki "Konsa tool kab use karna chahiye?"

Tool / Function Object Returned Primary Chart Types Data Format Required Legend & Titles Best Used When...
sns.FacetGrid FacetGrid Any Matplotlib or custom Python plotting function Tidy / Long-form DataFrame Manual (g.add_legend(), g.set_titles()) Custom hybrid plots banani hon (e.g. overlaying custom regression models or KDE over scatter).
sns.relplot() FacetGrid Scatter, Line Tidy / Long-form DataFrame Automatic (external margin legend) Two continuous variables ka relationship across categories visualize karna ho (zero boilerplate).
sns.displot() FacetGrid Hist, KDE, ECDF, Rug Tidy / Long-form DataFrame Automatic (shared bins & density) Subgroups ke statistical distributions aur spread compare karne hon.
sns.catplot() FacetGrid Box, Violin, Bar, Strip, Swarm, Point, Count Tidy / Long-form DataFrame Automatic Categorical summaries, medians, aur quartiles across dimensions compare karne hon.
sns.PairGrid PairGrid Pairwise scatter, histograms, KDE matrix Numeric columns of DataFrame Diagonal / Off-diagonal split All pairs of numeric variables ka pairwise interaction dekhna ho (Topic 15).
plt.subplots() (Figure, ndarray of Axes) Arbitrary Matplotlib primitives Any Python list, NumPy array, or Series Fully Manual Heterogeneous dashboard banani ho jahan panel 1 pie chart ho, panel 2 line chart ho, aur panel 3 3D surface ho.

Key Architectural Differences: FacetGrid vs PairGrid

Aspect FacetGrid PairGrid (Topic 15)
Core Splitting Logic Same variables plotted across different categorical subsets (e.g., Study Hours vs Marks for CS, Eng, Arts). Different numeric variables plotted against each other pairwise (e.g., Hours vs Marks, Hours vs Attendance, Marks vs Attendance).
Grid Dimensions Number of rows/cols depends on categorical levels (e.g., 3 Groups × 4 Departments = 12 panels). Square matrix of size N × N where N is the number of numerical columns.
Diagonal Treatment All panels contain the same plot type. Diagonals typically show univariate distributions (histplot), off-diagonals show bivariate relationships (scatterplot).
ⓘ The "Golden Rule" of Multi-Plot Selection

Rule 1: Agar aap standard scatter, line, distribution, ya boxplot bana rahe hain → Use figure-level wrappers (relplot, displot, catplot). Yeh aapke 10 lines of code ko 1 line me shrink kar dete hain.
Rule 2: Agar aapko multiple custom plot types ek hi panel me layer karni hain ya non-Seaborn plotting call karni hai → Use raw FacetGrid.
Rule 3: Agar aapko har panel me completely different geometry chahiye (e.g. Panel 1: Gauge chart, Panel 2: Table, Panel 3: Area chart) → Use Matplotlib plt.subplots().

11 • DEFECT PREVENTION & DEBUGGING

Section 11: Common Mistakes, Pitfalls & Debugging Masterclass

Jab students FacetGrid aur multi-plot workflows implement karte hain, toh kuch subtle syntax errors, layout collisions, aur visual anti-patterns frequently occur karte hain. Neeche 14 critical pitfalls aur unke exact code-level solutions diye gaye hain:

# Common Mistake / Antipattern Root Cause The Exact Fix
1 Using col_wrap together with row ValueError: Cannot use `row` and `col_wrap` together. Wrapping applies only to 1D column arrays. Omit row when using col_wrap, or use row + col for a fixed 2D matrix.
2 Calling g.map() with keyword-only arguments g.map() passes columns positionally: func(df[col1], df[col2]). Use g.map_dataframe() instead, which passes named kwargs (x=..., y=...).
3 Overriding figure size via plt.figure(figsize=(12, 6)) FacetGrid internally instantiates its own plt.figure(), ignoring previous figure calls. Configure height and aspect parameters directly in FacetGrid(height=3.5, aspect=1.2).
4 Using deprecated ci=None parameter Seaborn 0.13+ has replaced ci with errorbar=None. Use errorbar=None in catplot, relplot, and barplot.
5 Passing palette without assigning hue Triggers FutureWarning: Passing `palette` without assigning `hue` is deprecated. Assign hue="column_name" and set legend=False if a legend is not needed.
6 Passing wide-form (unmelted) DataFrame FacetGrid requires categorical columns to partition data subsets. Use pd.melt(df, id_vars=[...]) to convert wide data to tidy long-form before plotting.
7 High-cardinality category explosion (e.g., 50 States) FacetGrid tries to render 50 separate axes, crashing memory and producing microscopic plots. Filter top categories with df[df['col'].isin(top_k)] or aggregate small groups into "Other".
8 Misleading comparison with unshared axes Setting sharey=False causes subplots with small variations to visually look identical to large ones. Keep sharey=True unless category scales differ by orders of magnitude (e.g. 10x+ difference).
9 Missing margin_titles=True on 2D grids Default headers print full title "group = A | dept = CS" in every cell, cluttering the view. Set margin_titles=True so row names appear only on the far right and col names on top.
10 Suptitle overlapping facet titles g.fig.suptitle() collides with top row headers. Call g.fig.subplots_adjust(top=0.90) before adding the suptitle.
11 Legend cut off on exported images Figure bounding box excludes external legend placed by g.add_legend(). Use plt.savefig('output.png', bbox_inches='tight') to capture the external legend.
12 Annotating single panel instead of all subplots Calling plt.axhline() applies only to the last active axis. Loop through all axes: for ax in g.axes.flat: ax.axhline(...).
13 Categorical sorting disorder Categories appear in arbitrary order of first appearance in data. Specify explicit ordering using col_order=['CS', 'Engineering', 'Business', 'Arts'].
14 Unwanted scientific notation on axes ticks Matplotlib automatically adds 1e6 multiplier on large financial values. Format ticks with matplotlib.ticker.FuncFormatter(lambda x, p: f'${{x*1e-3:.0f}}k').
Figure 17.22: Left: Anti-pattern with overlapping titles, cluttered legends, and squished columns. Right: Polished best practice with column wrapping and clean margins.

FacetGrid & Multi-Plot Parameter Reference

Parameter Supported In Data Type / Values Practical Utility
data All functions pandas DataFrame Input dataset (must be tidy long-form format).
col FacetGrid, relplot, displot, catplot String (Column name) Horizontal panel partitioning across categories.
row FacetGrid, relplot, displot, catplot String (Column name) Vertical panel partitioning (creates 2D matrix when paired with col).
hue All functions String (Column name) Color mapping within each panel; preserves spatial coordinates.
col_wrap All functions Integer (> 0) Wraps horizontal column faceting across multiple rows (cannot be used with row).
height All functions Float (Inches) Vertical height of each individual subplot.
aspect All functions Float (Width / Height) Controls aspect ratio of each facet. Individual width = height * aspect.
sharex, sharey FacetGrid, relplot, catplot Boolean or "col", "row" Enforces global axis limits across panels (default True).
margin_titles FacetGrid Boolean (default False) When True on 2D grids, places row titles only on the far-right margin.
palette All functions String, dict, or list Color mapping scheme applied across categories.
despine FacetGrid Boolean (default True) Removes top and right axis spines for clean visual polish.
col_order, row_order All functions List of Strings Explicit custom ordering of categorical levels across panels.
