Section 1 What is EDA and Why Do We Need It?

Socho ek college aapko 200 students ka academic record deta hai jisme attendance, assignment marks, internal scores, study hours aur final marks stored hain. Agar aap bina data ko dekhe seedha Machine Learning model me feed kar denge ya Dean ko report bana kar de denge, toh kya hoga?

  • Agar data me missing values hain, toh model crash ho jayega.
  • Agar koi student duplicate ho kar 2 baar enter ho gaya hai, toh aggregate statistics skew ho jayengi.
  • Agar kisi student ka score typing mistake ki wajah se 995 enter ho gaya hai, toh standard deviation aur mean bilkul galat picture dikhayenge.

Yahi reason hai ki har Data Scientist aur Data Analyst machine learning model train karne se pehle Exploratory Data Analysis (EDA) perform karta hai. EDA humein data ki real-world anatomy aur limitations ko discover karne me help karta hai.

Figure 20.1: The 12-Step Disciplined EDA Framework: Phase 1 (Ingestion & Inspection) → Phase 2 (Visual Exploration) → Phase 3 (Anomaly Triage & Evidence Synthesis).

Why Visualizations Reveal What Summary Tables Hide (Anscombe's Lesson)

Sirf df.mean() ya summary numbers dekhna kaafi nahi hota. Famous Anscombe's Quartet dikhata hai ki 4 completely alag datasets ka mean, variance aur linear correlation exact same (correlation r = 0.816) ho sakta hai, lekin jab hum unka Seaborn scatter plot banate hain toh ek linear line hoti hai, ek curved parabola hoti hai, ek vertical line hoti hai aur ek me massive outlier hota hai!

Isliye EDA ek iterative detective process hai: hum question poochhte hain → code execute karte hain → graph inspect karte hain → nayi hypothesis form karte hain!

Role How EDA Transforms Their Daily Work
Data Analyst Raw SQL extracts ko business metrics (churn, retention, margin) me translate karta hai aur unexpected drops discover karta hai.
Data Scientist & ML Engineer Feature distributions, multicollinearity, skewness, aur data leakage detect karta hai before model training.
Business & Product Analyst A/B experiment test results aur user cohort behaviour ko visualize karke feature roadmap decide karta hai.
Software / DevOps Engineer API latency distribution, error rate spikes, aur microservice SLA breaches ko isolate karta hai.

Section 3 Data Quality Checks Before Visualization: Triage & Cleaning

"Garbage in, garbage out" — data science ka sabse bada truth hai. Agar aapne missing values aur dirty duplicates ko bina audit kiye direct Seaborn heatmap ya regression plot me bhej diya, toh calculations misleading hongi.

Figure 20.3: Data Quality Audit: Visualizing missingness locations across student records (Left) and accounting for duplicates and nulls before cleaning (Right).

Handling Missing Values: The 3 Core Strategies

  • 1. Deletion (dropna()): Sirf tab use karein jab missingness completely random ho (MCAR) aur missing rows total dataset ka bohot chhota hissa hon (< 2%). Agar 20% rows delete kar di, toh sample bias create ho jayega!
  • 2. Imputation with Summary Statistics (fillna(median)): Numeric variables me median use karna safest hota hai kyunki median outliers se affect nahi hota.
  • 3. Contextual / Domain Imputation: E.g., customer rating null hone ka matlab ho sakta hai user ne abhi review nahi diya. Use separate category "Unrated" dekar preserve karein.

Handling Duplicate Records

Real-world databases me network retry ya accidental form submission ki wajah se exact duplicate rows create ho jaati hain. Seaborn me duplicate rows data points ko artificially dense bana deti hain:

  • df.duplicated().sum() → Check duplicate count.
  • df.drop_duplicates(inplace=True) → Remove exact identical rows, retaining the first occurrence.

Example 5: Auditing and Cleaning College Student Records

Student dataset me 1 duplicate row aur missing values hain. Dekhiye kaise hum audit note record karke clean karte hain:

example5_clean_student_records.py 
import pandas as pd
import numpy as np

df = pd.read_csv("scratch/seaborn_topic20_data/student_eda_dataset.csv")

# 1. Inspect Duplicates
dupe_count = df.duplicated().sum()
print(f"Audit Finding: Found {dupe_count} duplicate row.")
df_clean = df.drop_duplicates().copy()
print(f"Action: Removed duplicate. New row count: {len(df_clean)}")

# 2. Inspect Missing Values
print("\nMissing values before imputation:")
print(df_clean[["internal_marks", "attendance_pct"]].isnull().sum())

# 3. Contextual Median Imputation
int_median = df_clean["internal_marks"].median()
att_median = df_clean["attendance_pct"].median()

df_clean["internal_marks"] = df_clean["internal_marks"].fillna(int_median)
df_clean["attendance_pct"] = df_clean["attendance_pct"].fillna(att_median)

print(f"\nAction: Imputed internal_marks with median ({int_median})")
print(f"Action: Imputed attendance_pct with median ({att_median})")
print("Verification: Remaining nulls in dataset:", df_clean.isnull().sum().sum())

Example 6: E-Commerce Cleaning & Date Parsing

String dates ko real datetime me convert karna taaki time-based EDA possible ho:

example6_clean_ecommerce.py 
import pandas as pd

df_ecom = pd.read_csv("scratch/seaborn_topic20_data/ecommerce_eda_dataset.csv")

# 1. Drop duplicates
df_ecom_clean = df_ecom.drop_duplicates().copy()

# 2. Parse dates explicitly
df_ecom_clean["order_date"] = pd.to_datetime(df_ecom_clean["order_date"])
df_ecom_clean["order_month"] = df_ecom_clean["order_date"].dt.month_name()
df_ecom_clean["order_quarter"] = df_ecom_clean["order_date"].dt.quarter

# 3. Impute missing customer ratings with neutral median (4.0)
df_ecom_clean["customer_rating"] = df_ecom_clean["customer_rating"].fillna(df_ecom_clean["customer_rating"].median())

print("E-Commerce Cleaned Dataset Summary:")
print(f"Valid orders: {len(df_ecom_clean)}")
print(f"Date span: from {df_ecom_clean['order_date'].min().date()} to {df_ecom_clean['order_date'].max().date()}")
print(f"Cleaned columns: {list(df_ecom_clean.columns)}")
✖ Never Blindly Delete Missing Data

Agar kisi column me 40% data missing hai, toh dropna() karne se aadha dataset delete ho jayega! Hamesha document kijiye: What issue was found? What action was taken? What information might be lost? How was the result verified?

Section 4 Univariate Analysis: Understanding Individual Variables

Univariate analysis EDA ka pehla visual step hota hai. Iska primary objective hota hai: "Ek single variable ka distribution kaisa hai?" Hum numerical variables me unki central tendency, spread, skewness, aur outliers inspect karte hain; jabki categorical variables me class frequency aur category imbalance audit karte hain.

Figure 20.4: Univariate Numerical Exploration: Histogram with KDE overlay (Left), Empirical Cumulative Distribution Function ECDF (Center), and Boxplot (Right).

The 4 Numerical Distribution Tools in Seaborn

Seaborn Function What It Shows Best Analyst Interpretation Guide
sns.histplot(kde=True) Data frequency across discrete bins with density curve. Bimodal peaks (two clusters) ya bell-curve normal distribution spot karne ke liye ideal. Bin size badalne se visual appearance change hota hai.
sns.kdeplot() Continuous Probability Density Estimate (smoothed curve). Data ke probability mass ko estimate karta hai. Remember: KDE ek mathematical estimate hai, exact distribution nahi!
sns.ecdfplot() Empirical Cumulative Distribution Function (0% to 100%). Zero bin-bias! Aap direct dekh sakte hain: "Kitne % students 50 marks se kam score kar rahe hain?" ya "80th percentile kahan par hai?"
sns.boxplot() Tukey's Five-Number Summary (Min, Q1, Median, Q3, Max). Median position aur interquartile spread dekh kar skewness aur potential outlier points immediately reveal hote hain.

Section 7 Correlation Analysis & Heatmaps: Measuring Linear Strength

Jab dataset me kai numerical variables hote hain, toh hum yeh samajhna chahte hain ki kaun se variables aapas me co-move karte hain. Pearson Correlation Coefficient (r) do variables ke beech linear relationship ki strength aur direction ko measure karta hai:

  • r = +1.0: Perfect Positive Linear Correlation (Ek badhta hai, toh dusra proportionally badhta hai).
  • r = 0.0: Zero Linear Correlation (Dono ke beech koi straight-line pattern nahi hai).
  • r = -1.0: Perfect Negative Linear Correlation (Ek badhta hai, toh dusra proportionally ghat-ta hai).
Figure 20.10: Student Correlation Matrix Heatmap rendered with a zero-centered diverging colormap (vlag) highlighting the strongest linear link (study_hours vs final_score, r = 0.732).
Figure 20.11: The Golden EDA Rule: Correlation Measures Co-Movement, Not Causation. Distinguishing statistical association from controlled real-world causality.
⚠ CRITICAL WARNING: Correlation ≠ Causation!

Agar study hours aur final marks me r = 0.732 hai, iska matlab statistical association hai, koi absolute guarantee nahi! Kisi student ki prior foundation, teacher quality, aur exam-day health confounding variables hote hain. EDA hypotheses generate karta hai, policy decisions nahi!

import seaborn as sns

    annot=True,
    fmt=".3f",
    cmap="vlag",
    vmin=-1,
    vmax=1,
    center=0,
    linewidths=1.2,
    linecolor="white",
    cbar_kws={"label": "Pearson r"}
)

Section 8 Outliers and Unusual Patterns: Contextual Triage vs Blind Removal

Outlier ek aisa observation hota hai jo baaki data cluster se abnormally door situated hota hai. Beginner analysts ki sabse common mistake hoti hai: "Outlier dikha nahi ki foran drop kar diya!"

Real-world EDA me outliers 3 categories me split hote hain:

  1. Data Entry Typo: E.g., student attendance 850% instead of 85%. (Fix: Correct or drop if irrecoverable).
  2. Genuine High-Value Event: E.g., corporate wholesale customer placing a $4,850 order with quantity 45. (Fix: Retain! Yeh company ka most profitable customer segment hai!).
  3. Exceptional Phenomenon: E.g., student STU-1043 studying 8.9 hrs but scoring only 44.0% due to illness during the exam. (Fix: Flag with context).

Example 21: Programmatic IQR Outlier Detection

example21_iqr_detection.py 
import pandas as pd
import numpy as np

df_ecom = pd.read_csv("scratch/seaborn_topic20_data/ecommerce_eda_dataset.csv").drop_duplicates()

q1 = df_ecom["sales_amount"].quantile(0.25)
q3 = df_ecom["sales_amount"].quantile(0.75)
iqr = q3 - q1

lower_fence = q1 - 1.5 * iqr
upper_fence = q3 + 1.5 * iqr

outliers = df_ecom[(df_ecom["sales_amount"] < lower_fence) | (df_ecom["sales_amount"] > upper_fence)]

print(f"IQR: ${iqr:.2f} | Upper Fence: ${upper_fence:.2f}")
print(f"Identified {len(outliers)} statistical outliers out of {len(df_ecom)} orders.")
print("\nTop Outlier Record:")
print(outliers.sort_values(by="sales_amount", ascending=False).head(1)[["order_id", "category", "quantity", "sales_amount"]])

Section 10 Choosing the Right Seaborn Chart Guide: Question-Driven Mapping

Bohot se students is baat me confuse ho jaate hain ki "Mujhe kaun sa plot choose karna chahiye?". Solution simple hai: Chart type kabhi bhi random visual preference se choose nahi hota, balki aapke Analytical Question ke data type se decide hota hai!

Figure 20.16: Seaborn Visual Selection Matrix: Mapping analytical question types to appropriate Seaborn functions.
Analytical Question Suitable Visualization Common Seaborn Function Important Caution / Limitation
How is one numerical variable distributed? Histogram or KDE curve sns.histplot(), sns.kdeplot() KDE is a mathematical density estimate, not exact distribution. Always test multiple bin widths.
How do two numerical variables relate? Scatter plot with optional regression fit sns.scatterplot(), sns.regplot() Statistical association does not equal real-world causation. Check for extreme leverage outliers.
How do categories differ in numerical spread? Box plot or Violin plot sns.boxplot(), sns.violinplot() Boxplots hide multimodal peaks. Overlay with sns.stripplot() for sample size transparency.
How many observations are in each category? Count plot sns.countplot() Always sort categories by frequency (order=...) to highlight imbalance.
How do numerical values change over time? Line plot sns.lineplot() Ensure timestamps are chronologically sorted; line plots imply continuity across missing intervals.
Which pairs of numerical variables correlate? Correlation Heatmap sns.heatmap() Pearson r only captures linear links. Exclude identifier columns before matrix calculation.
How do multiple numerical variables interact? Pair plot matrix sns.pairplot() Limit to 3–5 core features. Plotting > 8 variables creates unreadable, slow-rendering matrices.
How do multi-category groups compare? Faceted small multiples sns.relplot(), sns.catplot() Too many facet columns reduce individual readability. Keep col_wrap between 2 and 4.

def recommend_plot(var1_type, var2_type=None, is_temporal=False):
    """Recommends the best Seaborn chart based on variable types."""
    if is_temporal:
        return "sns.lineplot(x=time_col, y=num_col) -> Temporal trend exploration"
    if var2_type is None:
        if var1_type == "numeric":
            return "sns.histplot(kde=True) or sns.ecdfplot() -> Univariate numerical"
        else:
            return "sns.countplot(order=...) -> Univariate category frequency"
    if var1_type == "numeric" and var2_type == "numeric":
        return "sns.regplot() or sns.scatterplot() -> Bivariate numerical relationship"
    if (var1_type == "categorical" and var2_type == "numeric") or (var1_type == "numeric" and var2_type == "categorical"):
        return "sns.boxplot() overlaid with sns.stripplot() -> Group distribution comparison"
    return "pd.crosstab() + sns.heatmap() -> Categorical contingency analysis"

print("Recommendation for Study Hours vs Score:", recommend_plot("numeric", "numeric"))
print("Recommendation for Department vs Score:", recommend_plot("categorical", "numeric"))
print("Recommendation for Monthly Revenue:", recommend_plot("numeric", is_temporal=True))

Section 13 Common Beginner Mistakes & Debugging in EDA

Exploratory Data Analysis me statistical aur visual traps bohot common hote hain. Chaliye dekhte hain ki top 15 pitfalls kaun se hain aur unhe code me kaise avoid karein:

Figure 20.19: Top 4 EDA Pitfalls: Plotting before checking data, calculating stats on IDs, confusing correlation with causation, and blind outlier deletion.
Figure 20.20: Data Cleaning Transparency: Comparing raw distribution with missing values and duplicates (Left) vs deduplicated, median-imputed clean distribution (Right).
# Common EDA Mistake Root Cause Immediate Professional Fix
1 Plotting Before Inspecting Direct sns.scatterplot() run karne par missing values ya wrong dtypes chart ko distort kar dete hain. Hamesha pehle df.info(), df.shape aur df.isnull().sum() run karein.
2 Ignoring Missing Values Seaborn silently NaNs drop kar deta hai, jisse analyst ko pata hi nahi chalta ki 20% sample gayab ho chuka hai. Missingness count report karein aur documented imputation (median/mode) use karein.
3 Treating IDs as Numbers student_id ya order_id par mean, median ya correlation heatmap calculate karna meaningless hai. ID columns ko numerical analysis se explicitly filter out karein.
4 Using Wrong Chart for Question Categories compare karne ke liye scatter plot ya time trend ke liye pie chart use karna. Section 10 ka decision matrix follow karke question type ke according plot choose karein.
5 Drawing Conclusions from Tiny Samples Agar kisi department me sirf 3 students hain, toh unke 95% average ko general fact maan lena invalid hai. Count plots aur stripplot jitter se sample size hamesha transparent rakhein.
6 Assuming Correlation = Causation High Pearson r dekh kar yeh assume kar lena ki X direct Y ko cause kar raha hai. Hamesha confounders aur unobserved drivers acknowledge karke hypothesis formulate karein.
7 Blind Outlier Deletion Tukey's fence se bahar ke points ko error samajh kar drop kar dena. Investigate karein: kya yeh bulk customer ya system incident hai? Contextual triage karein.
8 Too Many Colors in One Chart 12 categories ko 12 different rainbow colors me plot karna. Top 4 categories ko distinct colors dein, baaki sab ko 'Other' grey shade me bundle karein.
9 Misinterpreting KDE Smoothing KDE curve ko exact physical distribution maan lena. Remember: KDE ek mathematical estimate hai jo negative values me bhi bleed ho sakta hai.
10 Unsorted Timestamps in Line Plots Date strings ko bina pd.to_datetime() aur sort_values() ke lineplot me pass karna jisse zigzag lines ban jaati hain. Dates ko real datetime me parse karke chronologically sort karein.
11 Unreadable Pair Plots 15 features par pairplot chala dena jo 15x15 = 225 tiny unreadable subplots create karta hai. Sirf 3 se 4 meaningful core features par curated pairplot banayein.
12 Ignoring Duplicate Records Duplicate rows aggregate sum aur percentages ko duplicate weight de kar double count karti hain. df.drop_duplicates() run karke deduplicate karein.
13 Reporting Synthetic Data as Real-World Truth Educational synthetic dataset ke trend ko universal real-world biology ya business truth claim karna. Hamesha transparent disclaimer dein: "Observed in synthetic educational dataset".
14 Bar Plot Y-Axis Truncation Bar plots me Y-axis ko zero se shuru na karke 90 se shuru karna jisse chhoti differences massive lagti hain. Bar plots ka baseline hamesha 0 hona chahiye!
15 Hardcoding Annotation Coordinates Window resize hone par text box ke data points ke upar chadh jana. Hamesha textcoords='offset points' use karein.
