01 Section A: Violin Plot Kya Hota Hai?

Relatable Opening Question

"Section A aur Section B ke students ke marks ka median lagbhag similar hai (71.3 vs 72.4). Kya dono sections mein marks ka distribution bhi same hai?"

Agar aap sirf Mean aur Median dekhkar faisla le lenge, toh aapka answer hoga: "Haan, dono sections ki performance lagbhag barabar hai!" Lekin real-world data science mein yeh sabse bada dhokha ho sakta hai.

Jab aap unhi marks ka Violin Plot dekhenge, toh aapke hosh udd jayenge! Section A mein students ka score ek single concentrated cluster mein hai (lagbhag sabhi 68–75 ke beech hain). Lekin Section B mein classroom do tukdo mein polarized hai: 50% students struggle kar rahe hain 55 ke aas-paas (Peak 1), aur 50% top students 85 ke aas-paas hain (Peak 2)! Dono ka median same 72 hai, lekin dono classrooms ki teaching requirement 100% alag hai!

Violin Plot Ki Definition Aur Shape

Ek Violin Plot do classical statistical charts ka perfect hybrid combination hota hai:

  1. Kernel Density Estimation (KDE): Data ke probability density curve ko vertically draw karke horizontally mirror kar diya jaata hai (creating the outer curvy violin body).
  2. Box Plot Core: Violin ke center spine par ek miniature box plot baitha hota hai jisme thick black bar Interquartile Range (IQR) batata hai, white center dot Median batata hai, aur thin black lines extreme whisker values batati hain.
Figure 8.1: Complete Anatomy of a Violin Plot — Mirrored KDE density contours, wide mode bulges, narrow density waists, and central miniature box plot anchors.

Violin Ki Width Kya Batati Hai?

Violin plot ka sabse important rule yaad rakhiye: Violin ki horizontal width kisi value range ki Estimated Probability Density represent karti hai, exact observation count nahi!

  • Wide Region (Bulge): Jis point par violin sabse zyada chouda (wide) hota hai, wahan data values sabse zyada concentrated hoti hain (Distribution ka Mode / Peak).
  • Narrow Region (Waist): Jahan violin patla ho jata hai, wahan data points bohot rare ya absent hote hain.
  • Tapering Tails: Upar aur niche ke patle edges distribution ke extreme tail ranges show karte hain.

Two Relatable Real-World Questions a Violin Plot Answers

  • E-Commerce Delivery Operations: "Kya delivery partner QuickDrop ke orders ek consistent time (~30 mins) par deliver hote hain, ya highway traffic ke waqt do alag peaks ban jaate hain (25 mins vs 55 mins)?"
  • FinTech Customer Spending: "Regular aur VIP customers ke order amounts mein kya sirf median ka fark hai, ya VIP customers mein ek second luxury purchase peak exist karta hai?"

02 Section B: Understanding KDE Statistics & The "Smooth Bump" Analogy

Violin plot padhne se pehle students ko lagta hai ki yeh curved shape kahan se aayi. Iske peeche jo core statistical algorithm kaam karta hai use kehte hain Kernel Density Estimation (KDE).

The Smooth Bump Analogy (Intuitive Explanation)

Imagine kijiye aapke paas 9 students ke test marks hain: [22, 25, 27, 30, 31, 33, 48, 50, 52]. Agar aap har student ke score par ek ret ka chhota sa smooth dher (Gaussian bump / Kernel) rakh dein:

  • Jahan 4–5 students ke marks ek doosre ke bohot paas hain (30, 31, 33), wahan ret ke saare chhote bumps aapas mein judkar ek bada pahad (prominent peak) bana lenge!
  • Jahan 35 se 45 ke beech koi student nahi hai, wahan zameen flat rahegi (dip / waist).
  • Aur jahan 48, 50, 52 par agla group hai, wahan ek doosra pahad ban jayega!

Jab in saare bumps ko mathematically add (sum) kar diya jaata hai, toh humein ek continuous smooth density curve milta hai. Phir Seaborn is curve ko dono taraf mirror kar deta hai, aur ban jaata hai aapka Violin Plot!

Figure 8.2: The Smooth Bump Analogy — Dotted Gaussian kernels over raw observations sum into the blue continuous KDE curve, which is mirrored vertically to forge the violin body.

The 4 Essential Distribution Archetypes

Real-life datasets mein aapko violin plots 4 primary shapes mein dikhenge:

Figure 8.3: The Four Classic Distribution Archetypes — Symmetric Bell Curve, Right-Skewed Long Tail, Left-Skewed Cap, and Bimodal Twin Peaks.
Archetype Visual Violin Anatomy Statistical Meaning Real-World Example
Symmetric Normal Equal width on both sides of center; median sits in the exact middle bulge. Mean ≈ Median; variance is evenly distributed without skew. Calibrated factory machinery, adult heights, standardized IQ tests.
Right-Skewed (Positive) Bulbous base at low values; long thin neck tapering upwards. Mean > Median; majority values low, few extreme high outliers pull the tail. Customer order spending, website API latencies, software engineer salaries.
Left-Skewed (Negative) Bulbous top at high values; long thin stem tapering downwards. Mean < Median; majority perform well, few severe failures pull the lower tail. Easy college exam marks, airline on-time arrival scores, product satisfaction ratings.
Bimodal (Two Peaks) Hourglass waist; two distinct wide bulges with a narrow bridge in between. Data contains two distinct hidden sub-populations with different means! Rush hour vs non-rush hour delivery times, mixed junior/senior developer salaries.
Deep Dive: Individual Observations vs Underlying Distribution vs Estimated Density

Yeh teen terms beginner data scientists aksar aapas mein mix kar dete hain:

  1. Individual Observations: Aapka raw data (e.g. 100 students ke exact exam marks).
  2. Underlying Population Distribution: Woh theoretical true probability distribution jahan se data generate hua hai (jo humein directly kabhi 100% pata nahi hota).
  3. Estimated Density (The Violin): KDE algorithm dwara banayi gayi smooth approximation! Yeh sample data aur chosen smoothing bandwidth par depend karti hai. Isiliye violin shape ko divine truth nahi, balki ek intelligent mathematical estimation samjhein.

03 Section C: sns.violinplot() Syntax & Master Parameter Guide

Seaborn mein violin plot generate karne ke liye standard function sns.violinplot() hota hai. Seaborn 0.13+ architecture mein is function ne kai legacy parameters ko modernize kiya hai (jaise scale ko density_norm se replace karna aur modern gap support add karna).

Master Parameter Reference Table (Seaborn 0.13.2 Verified)

Parameter Type Default Data Science Purpose & Hinglish Explanation
data DataFrame / Array None Input dataset (Tidy long-form ya Wide-form tabular data).
x, y str / Series None Variables mapping. Agar categorical variable x par hai toh vertical plot banega; agar y par hai toh horizontal.
hue str None Sub-grouping variable jo violins ko subgroups mein divide ya split karta hai.
inner 'box' | 'quart' | 'point' | 'stick' | None 'box' Violin ke center spine par internal indicators draw karta hai: miniature box plot, dashed quartile lines, individual points, ya clean blank.
split bool False Game-Changer: Jab hue mein exactly 2 levels hote hain, toh split=True unhe ek single violin ke left aur right halves mein merge kar deta hai!

04 Section D: How to Read the Violin Shape & Decode Its Anatomy

Violin plot dekhne mein khoobsurat lagta hai, lekin ek professional data analyst ki nazar uske geometry mein छिपे statistical signals ko dhundti hai. Yahan 4 critical components diye gaye hain:

The 4-Step Violin Decoding Framework
  1. Peak Count (Modality): Violin mein kitne bulges (choude pet) hain? Ek bulge ka matlab Unimodal (single homogeneous group); do bulges ka matlab Bimodal (two hidden sub-groups with different averages); teen ya zyada ka matlab Multimodal.
  2. Waist Tightness (Density Dip): Do bulges ke beech ka waist kitna patla hai? Jitna zyada patla hoga, utna hi strong segregation hai dono groups ke beech.
  3. Symmetry vs Skew: Kya median line ke upar aur niche violin ka shape mirror image hai? Agar upar lamba stem hai, toh right-skewed tail hai.
  4. Internal Box Summary: White center dot median batata hai. Thick black bar middle 50% data (IQR) ki exact physical limits batata hai.
Crucial Reminder: Density vs Frequency

Violin plot ki width relative probability density batati hai, exact student count nahi! Agar Section A mein 1,000 students hain aur Section B mein sirf 50 students hain, default setting (density_norm='area') mein dono violins ki total width barabar dikhegi kyunki har violin ka area 1.0 par normalize hota hai. Kabhi yeh mat samajhiye ki chouda violin matlab zyada data points!

05 Section E: Understanding KDE Bandwidth (bw_adjust) & The cut Parameter

Violin plot ka sabse sensitive hissa hota hai Bandwidth Smoothing. KDE curve kitna smooth hoga, yeh bandwidth parameter decide karta hai. Seaborn 0.13+ mein hum ise bw_adjust parameter ke zariye fine-tune karte hain.

1. The bw_adjust Parameter (Smoothing Multiplier)

  • bw_adjust=1.0 (Default): Balanced automatic Scott's rule bandwidth.
  • bw_adjust < 1.0 (e.g. 0.35): Under-smoothed. Bumps bohot patle ho jaate hain jisse random sampling noise bhi artificial peaks ke roop mein appear ho sakti hai.
  • bw_adjust > 1.0 (e.g. 2.5): Over-smoothed. Excessive smoothing do genuine peaks ke beech ke dip ko mita deti hai, making bimodal data falsely appear unimodal!
Python 3.13 • Bandwidth Sensitivity Demonstration 
sec_b = df_college[df_college['section'] == 'Section B']['exam_marks']

fig, (ax1, ax2, ax3) = plt.subplots(1, 3, figsize=(15, 5))

# 1. Under-smoothed
sns.violinplot(y=sec_b, ax=ax1, color='#38bdf8', bw_adjust=0.35)
ax1.set_title("bw_adjust = 0.35 (Under-Smoothed)
Noisy & Distracting Jaggies")

# 2. Balanced
sns.violinplot(y=sec_b, ax=ax2, color='#10b981', bw_adjust=1.0)
ax2.set_title("bw_adjust = 1.0 (Balanced Default)
Accurately reveals both modes (55 & 85)")

# 3. Over-smoothed
sns.violinplot(y=sec_b, ax=ax3, color='#f43f5e', bw_adjust=2.5)
ax3.set_title("bw_adjust = 2.5 (Over-Smoothed)
Masks the dip; falsely appears unimodal!")

plt.tight_layout()
plt.show()
Figure 8.6: The Bandwidth Dilemma — Comparing under-smoothed noise (0.35) vs balanced ground-truth bimodality (1.0) vs over-smoothed mode masking (2.5).

2. The cut Parameter: Bounded Variables Alert

By default, Seaborn ka cut=2 setting KDE tails ko extreme observed values ke 2 bandwidth units aage tak extend kar deta hai. Iska side-effect yeh hota hai ki agar exam marks 0 se 100 ke beech hain, toh violin −5 ya +105 tak reach karta hua dikhayi de sakta hai!

The Bounded Variable Trap

Exam marks, ages, ya positive delivery times jaise physical variables ke liye KDE tails impossible negative values ya >100% values dikha sakti hain. Is problem ka clean solution hai: cut=0 set karein! Yeh violin ko strictly dataset ke observed minimum aur maximum par terminate kar deta hai.

Figure 8.7: The cut Parameter — cut=0 strictly binds the violin within observed data limits, whereas cut=2 extrapolates smooth tails past actual min/max boundaries.

06 Section F: Customizing Aesthetics, Orientation & Inner Indicators

Professional dashboards aur client reports ke liye default violin plots ko customize karna zaroori hota hai. Yahan do major customization techniques di gayi hain: Orientation Control aur Inner Indicator Selection.

1. Horizontal vs Vertical Orientation

Jab aapke categories ke naam lambe hote hain (jaise customer membership tiers: "Regular Member", "Gold Tier", "VIP Corporate"), toh horizontal violin plot banana best practice hai:

Python 3.13 • Horizontal vs Vertical 
import matplotlib.pyplot as plt
import seaborn as sns
import pandas as pd

df_spend = pd.read_csv("scratch/seaborn_topic8_data/customer_spending_tiers.csv")

fig, (ax1, ax2) = plt.subplots(1, 2, figsize=(13, 5.5))

# Vertical plot
sns.violinplot(data=df_spend, x='tier', y='spend_inr', hue='tier', legend=False,
               ax=ax1, palette=['#0284c7', '#6366f1', '#f43f5e'], width=0.55)
ax1.set_title("Vertical Violin Plot (X = Category)")
ax1.yaxis.set_major_formatter('₹{x:,.0f}')

# Horizontal plot (natural readability)
sns.violinplot(data=df_spend, y='tier', x='spend_inr', hue='tier', legend=False,
               ax=ax2, palette=['#0284c7', '#6366f1', '#f43f5e'], width=0.55)
ax2.set_title("Horizontal Violin Plot (Y = Category)")
ax2.xaxis.set_major_formatter('₹{x:,.0f}')

plt.tight_layout()
plt.show()
Figure 8.8: Vertical vs Horizontal Layout — Clean horizontal orientation eliminates text rotation on category axes.

2. The Four Modes of the inner Parameter

Violin plot ke center spine par kya draw hoga, yeh inner parameter decide karta hai:

  • inner='box' (Default): Miniature box plot with white median dot and thick IQR bar.
  • inner='quart': Three dashed lines representing Q1 (25%), Median (50%), and Q3 (75%). Bohot clean aur modern look deta hai!
  • inner='point': Saare individual raw observations ko scatter dots ke roop mein center spine par plot karta hai. Small datasets ke liye ideal.
  • inner=None: Koi internal lines ya box nahi hote; violin hollow dikhta hai, focusing purely on continuous density shape.
Figure 8.9: Comparing all 4 inner modes — 'box' (default) vs 'quart' (dashed lines) vs 'point' (scatter dots) vs None (pure density envelope).

08 Section H: Split Violins for Binary Groups (split=True)

Agar aapke hue variable mein exactly 2 categories hain (jaise Lunch vs Dinner, Male vs Female, Treatment vs Control), toh do alag-alag violins draw karne ki bajaye Seaborn unhe ek hi violin ke Left Half aur Right Half mein split kar sakta hai!

The Superpower of split=True
  • 50% Space Saving: Chart ka width half ho jaata hai, making it compact and clean.
  • Direct Side-by-Side Comparison: Dono groups ki density curves ek hi center axis par chipki hoti hain, jisse peaks aur tails ka difference instantly notice hota hai.

Technical Gotcha: What happens if hue has 3 or more levels when split=True?

Seaborn ValueError: split=True can only be used with a hue variable that has exactly two levels! throw kar dega. Ek violin sirf do sides (Left and Right) afford kar sakta hai. Agar 3 levels hain (e.g. Morning, Afternoon, Evening), toh standard grouped violins (split=False) use karein.

09 Section I: Violin Plots vs Box Plots & The Bimodal Revelation

Topic 7 mein humne Box Plots padhe the. Box plots 5-number summary (Min, Q1, Median, Q3, Max) ke liye best hote hain, lekin unki sabse badi kamzori yeh hai ki woh multimodality ko completely mita dete hain.

The Bimodal Secret Revealed!

Agar aap Section B ke marks ka Box Plot banayenge, toh aapko ek wide box dikhega jiska median center mein 72.4 par baitha hoga. Box plot ko dekhkar koi bhi insaan yeh nahi bata sakta ki 70 par koi student hi nahi hai — wahan ek khali dip hai! Lekin Violin Plot dekhte hi hourglass waist aur dono modes (55 aur 85) instantly clear ho jaate hain.

Figure 8.14: The Bimodal Revelation — Box plot on the left places the median line in the empty dip (72.4) with zero indication of clustering, whereas the Violin plot on the right clearly separates the twin peaks at 55 and 85!
Analytical Requirement Box Plot (sns.boxplot) Violin Plot (sns.violinplot)
Revealing Multimodal Peaks Fails completely (masks dips and modes). Winner! Hourglass bulges expose clusters clearly.
Compact Group Comparison (15+ categories) Winner! Clean, narrow rectangular boxes. Can become crowded and visually heavy.
Outlier Detection via Tukey Fences Winner! Explicit flier dots beyond 1.5×IQR. Shows smooth tapering tails (no explicit fence markers).
Small Datasets (N < 30) Winner! Quantiles are stable and safe. KDE may create false artificial bumps!
Executive Audience Familiarity Winner! Universally understood by managers. Requires a 30-second explanation of width = density.

10 Violin Plot vs Histogram & KDE Curves

Histograms aur KDE curves distribution ke shape ko x-axis par count ya vertical density ke roop mein show karte hain. Violin Plot usi KDE curve ko 90° rotate karke horizontally mirror kar deta hai:

Figure 8.15: Direct Comparison — Histogram + KDE curve along the horizontal axis vs Mirrored Violin Plot along the vertical axis on identical bimodal data.

When to Choose Which

  • Use Histogram + KDE (sns.histplot) jab aapko single variable ka exact bin counts aur probability curve dekhna ho.
  • Use Violin Plot (sns.violinplot) jab aapko 3 se 8 categories ke distributions ko side-by-side compare karna ho bina kisi visual clutter ke.

11 Violin Plot vs ECDF Cumulative Curves

Topic 6 mein humne Empirical Cumulative Distribution Functions (ECDF) padhe the. ECDF aur Violin plots ek doosre ke perfect complementary partners hote hain:

Figure 8.16: Complementary Insights — Violin Plot highlights density peaks and clusters, while ECDF directly answers threshold questions like "What percentage of deliveries meet the 45-minute SLA?"

  • ECDF Plot answer karta hai: "What exact fraction of data falls below threshold X?" (SLA compliance & percentile auditing).

12 The Small-Sample Safeguard: Violin Overlaid with Strip Plot

Jab aapke dataset mein observations kam hoti hain (N < 30), toh KDE smoothing par blindly trust karna dangerous ho sakta hai. KDE chhota sample hone par bhi ek smooth elegant curve draw kar deta hai, jisse misleading illusion create hota hai.

The Small-Sample Remedy

Hollow violin (inner=None) ke upar ek jittered sns.stripplot(alpha=0.6) overlay karein. Isse students aur stakeholders ko summary shape bhi milta hai aur underlying data points ki exact sample strength bhi transparently dikhti hai!

Python 3.13 • Violin + Strip Overlay 
import matplotlib.pyplot as plt
import seaborn as sns
import pandas as pd

df = pd.read_csv("scratch/seaborn_topic8_data/college_exam_multimodal.csv")

fig, ax = plt.subplots(figsize=(10, 5.5))

# 1. Base hollow violin
sns.violinplot(data=df, x='section', y='exam_marks', ax=ax,
               palette=['#1e293b', '#1e293b', '#1e293b'],
               linewidth=1.5, linecolor='#64748b', inner=None)

# 2. Overlay jittered points
sns.stripplot(data=df, x='section', y='exam_marks', ax=ax,
              palette=['#34d399', '#38bdf8', '#fbbf24'],
              jitter=0.25, size=5, alpha=0.6, edgecolor='#0f172a', linewidth=0.5)

ax.set_title("Violin Plot Overlaid with Strip Plot (Density + Raw Sample Transparency)")
plt.tight_layout()
plt.show()

14 Section J • Case Study 1: College Exam Multimodal Performance

1. The Real-Life Question

17 Section K: 12+ Common Pitfalls, Silent Bugs & Debugging Guide

Violin plots interpret karte waqt data scientists aur students aksar fatal mistakes karte hain. Yahan 12 most frequent pitfalls aur unka verified resolution guide diya gaya hai:

# Pitfall & Silent Bug Scenario Danger / Incorrect Statistical Interpretation The Correct Code & Mental Fix
1 Assuming Width Equals Observation Count Believing a wider violin means more data points collected. Width represents relative probability density, not count. A group with N=20 can have the same width as N=2,000!
2 Treating Every Small Bump as a Sub-population Over-interpreting random sampling noise as distinct customer clusters. Check sample size. If N < 50, increase bw_adjust=1.2 or overlay sns.stripplot to verify sample support.
3 Ignoring cut on Bounded Variables Exam marks showing negative percentages (−5%) or ages reaching 130! Pass cut=0 to strictly terminate the violin tails at observed data min and max bounds.
4 Passing 3+ Hue Levels to split=True Code crashes with ValueError: split=True can only be used with a hue variable that has exactly two levels. Split violins only have left and right halves. If you have 3+ categories, set split=False.
5 Over-smoothing Bimodal Data with High Bandwidth Setting bw_adjust=2.5 masks true bimodal twin peaks into a fake bell curve. Keep bw_adjust=1.0 as default. Only adjust slightly (0.8 to 1.2) after verifying with a histogram.
6 Using Obsolete Parameter scale Instead of density_norm Getting deprecation warnings in Seaborn 0.13+: FutureWarning: The `scale` parameter is deprecated. Use `density_norm` instead. Use modern Seaborn 0.13 syntax: density_norm='area', 'count', or 'width'.
7 Using Obsolete Parameter bw Instead of bw_adjust Deprecation warning or broken custom bandwidth scaling. Pass bw_adjust=1.0 for relative multiplier or bw_method='scott' for calculation rule.
8 Passing palette Without hue in Seaborn 0.13+ Getting FutureWarning: Passing palette without assigning hue is deprecated. Pass hue=category_col, legend=False when applying custom categorical palettes.
9 Assuming Outlier Flags Exist in Violin Plots Searching for individual outlier dots that are visible in box plots. Default violins show continuous tapering tails, not isolated fliers. Use inner='point' or overlay sns.stripplot.
10 Comparing Groups with Incompatible Scale Units Plotting salary in INR next to salary in USD without currency normalization. Always normalize currencies and scales into identical units before feeding into a single axes.
11 Overlapping Grouped Hue Violins Adjacent hue violins look crowded and visually collide. Use Seaborn 0.13+ gap=0.08 to introduce clean modern spacing between sub-category violins.
12 Treating Synthetic Demonstration Data as Real Measurements Publishing algorithmic case study findings as genuine corporate statistics. Always clearly label synthetic datasets as demonstration examples with explicit random seeds.

Q1: Violin plot ki horizontal width kya represent karti hai?

A) Total number of observations collected
B) Estimated relative probability density at that value
C) The standard deviation of the category
D) The sample variance

Answer: B. Violin width indicates estimated relative probability density according to KDE, not absolute observation count.

Q2: Default Seaborn violin plot ke center spine par white dot kya represent karta hai?

A) Arithmetic Mean
B) Median (50th percentile)
C) Mode
D) Standard Error

Answer: B. The central white marker inside inner='box' represents the median.

Q3: Bimodal distribution ko reveal karne ke liye kaunsa plot sabse zyada effective hai?

A) Standard Box Plot
B) Violin Plot
C) Bar Plot with mean
D) Pie Chart

Answer: B. Box plots hide bimodality in a single wide box, while Violin plots clearly show the hourglass shape with twin bulges.

Q4: split=True parameter use karne ke liye hue variable mein kitne levels hone chahiye?

A) Exactly 1
B) Exactly 2
C) 3 or more
D) Any number of levels

Answer: B. split=True merges two groups into left and right halves of a single violin; it requires exactly 2 hue levels.

Q5: Bounded variables (jaise exam marks 0-100) par violin tails ko bahar extend hone se rokne ke liye kaunsa parameter use hota hai?

A) cut=0
B) limit=True
C) clip=True
D) bound=0

Answer: A. Setting cut=0 terminates the KDE curve strictly at observed minimum and maximum data values.

Q6: Bandwidth smoothing ko double karne ke liye kaunsa parameter pass karenge?

A) bw_adjust=2.0
B) smooth=2.0
C) bandwidth=2.0
D) kernel_size=2.0

Answer: A. In Seaborn 0.13+, bw_adjust acts as the multiplicative factor for KDE bandwidth.

Q7: Seaborn 0.13+ mein deprecated scale parameter ko kis parameter se replace kiya gaya hai?

A) size_norm
B) density_norm
C) width_scale
D) area_norm

Answer: B. density_norm ('area', 'count', 'width') is the modern replacement for scale.

Q8: Miniature box plot ke bajaye dashed quartile lines draw karne ke liye kaunsa parameter use hota hai?

A) inner='quart'
B) inner='lines'
C) inner='dashed'
D) inner='percentile'

Answer: A. inner='quart' draws clean dashed horizontal lines for Q1, Median, and Q3.

Q9: Small datasets (N < 25) par violin plots ka primary risk kya hota hai?

A) Code runtime error throw kar deta hai
B) KDE curve artificial noisy peaks create kar sakta hai jo population mein exist nahi karti
C) Violin plot automatically box plot ban jaata hai
D) Medians calculate nahi ho paate

A) spacing=0.1

Q21: Capstone Project: Automated Multimodal Distribution Diagnostic Pipeline

Problem Statement: Ek reusable Python diagnostic function banayein jo kisi bhi continuous numerical column ka modality test kare, skewness calculate kare, aur polished Box vs Violin multi-panel visual comparison generate kare:

import numpy as np
import pandas as pd
import seaborn as sns
import matplotlib.pyplot as plt
import scipy.stats as stats

def run_distribution_diagnostic(df, col_name, category_col=None):
    # Statistical calculations
    median_val = df[col_name].median()
    mean_val = df[col_name].mean()
    skew_val = stats.skew(df[col_name].dropna())
    
    print(f"=== DISTRIBUTION DIAGNOSTIC REPORT: {col_name} ===")
    print(f"Median: {median_val:.2f} | Mean: {mean_val:.2f}")
    print(f"Skewness: {skew_val:.2f} ({'Right-Skewed' if skew_val > 0.5 else 'Left-Skewed' if skew_val < -0.5 else 'Roughly Symmetric'})")
    
    fig, (ax1, ax2) = plt.subplots(1, 2, figsize=(12, 5))
    
    # Left: Box Plot
    if category_col:
        sns.boxplot(data=df, x=category_col, y=col_name, ax=ax1, palette='Set2')
        sns.violinplot(data=df, x=category_col, y=col_name, ax=ax2, palette='Set2', inner='quart', cut=0)
    else:
        sns.boxplot(y=df[col_name], ax=ax1, color='#f59e0b', width=0.35)
        sns.violinplot(y=df[col_name], ax=ax2, color='#38bdf8', inner='box', cut=0, width=0.45)
        
    ax1.set_title("Box Plot: 5-Number Quantile Summary")
    ax2.set_title("Violin Plot: Density Envelope & Multimodality")
    plt.tight_layout()
    return fig
