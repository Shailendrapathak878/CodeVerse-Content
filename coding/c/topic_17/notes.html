Foundations

01. Why Do We Need Structures, Unions & Enums?

In basic C programming, primitive variables (such as int, float, and char) store isolated individual pieces of data. Arrays allow you to store multiple elements, but an array requires every single element to be of the exact same data type (homogeneous).

1.1 The Problem: Modeling Real-World Entities

Real-world entities are inherently heterogeneous (made of multiple different data types). Consider representing a student in a university registry:

  • Roll Number: Integer (int)
  • Full Name: Text string (char[50])
  • Age: Integer (int)
  • Grade Point Average (GPA): Floating-point (float)
  • Enrollment Status: Active, Suspended, or Graduated

Without user-defined types, you are forced to manage isolated parallel variables:

The Flawed "Parallel Variables" Approach
int student1_id = 101;
char student1_name[50] = "Aman";
float student1_gpa = 3.85f;

int student2_id = 102;
char student2_name[50] = "Priya";
float student2_gpa = 3.92f;
Why Loose Parallel Variables Break Down
  1. No Cohesion: The compiler has no idea that student1_id and student1_gpa belong to the same person. Passing student details to a function requires 5+ separate parameters.
  2. Sorting Nightmare: If you sort student names alphabetically, you must manually write code to swap the corresponding roll numbers, ages, GPAs, and statuses simultaneously. A single missed swap scrambles the entire database.
  3. Zero Scalability: Managing 500 students requires 2,500 loose variables or 5 separate parallel arrays that easily fall out of synchronization.

1.2 The Three User-Defined Solutions

C provides three distinct constructs to solve these architectural problems:

Construct Core Concept Memory Organization Primary Use Case
struct Bundle of related heterogeneous fields Members have distinct, independent storage locations side-by-side Representing records (Student, Employee, Bank Account, Point in 3D space)
union Shared overlapping storage for alternative data forms All members share the exact same starting memory address Memory conservation, hardware register mapping, variant types (e.g. sensor readings)
enum User-defined type of named integer constants Stores an integer value from a set of human-readable symbols State machines, status codes, flags, removing ambiguous "magic numbers"
Architectural Distinction

These three features solve completely different problems: struct holds multiple pieces of data together at once; union holds one of several alternative values in shared memory; enum defines a readable vocabulary of discrete states.

Data Aggregation

02. Structures in C: Definition & Anatomy

What Is a Structure?

A structure is a user-defined aggregate data type that bundles multiple named variables (called members or fields), which can be of different data types, into a single cohesive unit of memory.

Real-Life Analogy: Physical Admission Form

Think of a printed university admission form. The form contains separate blank boxes for Roll Number, Student Name, and Percentage. Although each box holds a different kind of information, all boxes belong to the same physical sheet of paper representing one student.

2.1 Structure Syntax Breakdown

A structure is introduced using the struct keyword:

Structure Declaration Syntax
struct Student
{
    int id;          /* Member 1: Integer identifier */
    char name[50];   /* Member 2: String array */
    float marks;     /* Member 3: Floating-point score */
}; /* Notice the mandatory terminating semicolon! */
  • struct is the C keyword initiating the type declaration.
  • Student is the structure tag (the name of this newly created type).
  • id, name, and marks are the members of the structure.
  • The trailing semicolon ; is mandatory; omitting it causes a compiler syntax error.
Declaration vs. Object Creation

Declaring struct Student { ... }; creates a type blueprint; it does NOT allocate any memory in RAM! Memory is only allocated when you instantiate a variable of that structure type.

2.2 Instantiating Structure Variables

Once declared, you create concrete structure objects using the tag name prefixed by struct: 

struct Student s1; /* Allocates independent memory for s1 */
struct Student s2; /* Allocates independent memory for s2 */

s1 and s2 are completely separate objects in memory. Changing s1.id has zero effect on s2.id.

Member Access

03. Accessing Structure Members: The Dot (.) Operator

To access, read, or assign a value to an individual member of a structure object, C uses the Member Access Operator, commonly called the Dot Operator (.).

Dot Operator Syntax
structure_variable_name.member_name

3.1 Complete Starter Program

This beginner-friendly program initializes a student record and displays each member using the dot operator:

structure_starter.c 
#include <stdio.h>

struct Student
{
    int id;
    char name[50];
    float marks;
};

int main(void)
{
    /* Initialize structure members in declaration order */
    struct Student s1 = {101, "Aman", 87.5f};

    /* Access and print individual members using the dot operator */
    printf("ID: %d\n", s1.id);
    printf("Name: %s\n", s1.name);
    printf("Marks: %.1f\n", s1.marks);

    return 0;
}
Exact Expected Output
ID: 101
Name: Aman
Marks: 87.5

3.2 Step-by-Step Program Walkthrough

  1. struct Student s1 = {101, "Aman", 87.5f}; allocates contiguous memory for s1 on the stack and populates id = 101, copies the string "Aman" into name, and sets marks = 87.5.
  2. s1.id evaluates to the int value 101.
  3. s1.name yields the base address of the character array name inside s1, printed with %s.
  4. s1.marks evaluates to the float value 87.5, printed with %.1f.
Initialization

04. Declaration, Initialization & Assignment

C provides multiple methods for initializing and updating structure variables:

4.1 Sequential Initialization vs. C99 Designated Initializers

  • Sequential Initialization: Values are assigned strictly in the order members were declared in the structure template.
  • Designated Initializers (C99+): Members are explicitly named with a leading dot (.member = value). Order does not matter, and unmentioned members are automatically initialized to zero!
Point Structure Example
struct Point {
    int x;
    int y;
};

/* Sequential: x gets 10, y gets 20 */
struct Point p1 = {10, 20};

/* Designated (C99): explicit names; order can be reversed */
struct Point p2 = {.y = 15, .x = 5};

4.2 Updating Structure Members

Members behave like ordinary variables of their type: 

p1.x = 42;          /* Direct assignment for scalar types */
p1.y += 10;         /* Arithmetic update */

/* For string arrays, use strcpy: you cannot assign to an array directly! */
#include <string.h>
strcpy(s1.name, "Rahul"); /* Correct */
/* s1.name = "Rahul";    -- ERROR: Array type is not assignable */

4.3 Structure Assignment & Shallow Copy Warning

C allows you to assign one structure directly to another of the exact same type: 

struct Point a = {100, 200};
struct Point b;
b = a; /* Copies all member values from 'a' into 'b' */
The Shallow Copy Trap with Pointer Members

Structure assignment performs a bitwise copy of member values (shallow copy). If your structure contains a pointer member pointing to heap memory (e.g. char *notes;), assignment copies only the memory address, NOT the data on the heap!

Both structures will now point to the exact same heap memory block. If one structure frees that memory, the second structure is left with a fatal dangling pointer. To duplicate heap-allocated data, you must manually perform a deep copy.

Low-Level Architecture

05. Structure Memory Layout, Padding & Alignment

A beginner often assumes that the size of a structure is simply the sum of the sizes of its individual members. In real-world C, this is frequently FALSE!

The Padding Puzzle
struct Example {
    char c;    /* 1 byte */
    int n;     /* 4 bytes */
    char flag; /* 1 byte */
};

Expected size: \(1 + 4 + 1 = 6\) bytes.
Actual size on typical 32-bit and 64-bit systems: 12 bytes!

5.1 Why Does the Compiler Insert Padding?

Modern CPU architectures access memory much faster when data is aligned to natural hardware boundaries:

  • A 4-byte int must typically start at a memory address evenly divisible by 4.
  • An 8-byte double must typically start at an address evenly divisible by 8.
  • If an int were placed at odd address 0x1001, the CPU would have to execute multiple memory bus cycles to read it (unaligned access penalty), or on some RISC processors (ARM/SPARC), crash with a bus error.

To prevent this, the compiler automatically inserts unused padding bytes between members and at the tail end of the structure so that arrays of the structure remain properly aligned.

5.2 Inspecting Structure Size with sizeof (%zu)

struct_padding_demo.c 
#include <stdio.h>

struct Unoptimized {
    char c;    /* 1 byte + 3 padding bytes */
    int n;     /* 4 bytes */
    char flag; /* 1 byte + 3 padding bytes */
};

struct Optimized {
    int n;     /* 4 bytes */
    char c;    /* 1 byte */
    char flag; /* 1 byte + 2 padding bytes */
};

int main(void) {
    printf("Unoptimized struct size: %zu bytes\n", sizeof(struct Unoptimized));
    printf("Optimized struct size:   %zu bytes\n", sizeof(struct Optimized));
    return 0;
}
Typical 64-bit / 32-bit Output (Illustrative ABI)
Unoptimized struct size: 12 bytes
Optimized struct size:   8 bytes
Optimization Tip: Order Members by Decreasing Size

By declaring larger members first (such as double, then int, then char), you minimize internal gaps and save significant RAM when managing large arrays of structures.

Record Collections

06. Arrays of Structures (Record Collections)

In practical software, you rarely store just one record. A university manages thousands of students; an inventory system tracks thousands of products. An Array of Structures combines the power of array indexing with the heterogeneous fields of a structure.

Array of Structures Declaration
struct Student {
    int id;
    char name[30];
    float marks;
};

/* Declares a contiguous array of 3 complete Student records */
struct Student classroom[3];

6.1 Initializing and Accessing Array Elements

To access a member of a specific record in the array, combine the bracket index [i] with the dot operator .:

  • classroom[0].name — Accesses the name member of the first student record.
  • classroom[1].marks — Accesses the marks member of the second student record.
array_of_structures.c 
#include <stdio.h>

struct Student {
    int id;
    char name[30];
    float marks;
};

int main(void) {
    /* Initialize an array of 3 student records */
    struct Student students[3] = {
        {101, "Aman Sharma", 88.5f},
        {102, "Priya Patel", 94.0f},
        {103, "Rohan Verma", 76.5f}
    };

    printf("%-6s %-16s %-8s\n", "ID", "Student Name", "Marks");
    printf("------------------------------------\n");

    /* Loop through and print every record */
    for (int i = 0; i < 3; i++) {
        printf("%-6d %-16s %-8.1f\n", 
               students[i].id, 
               students[i].name, 
               students[i].marks);
    }

    return 0;
}
Exact Expected Output
ID     Student Name     Marks   
------------------------------------
101    Aman Sharma      88.5    
102    Priya Patel      94.0    
103    Rohan Verma      76.5

6.2 Three Crucial Distinctions

Pattern Syntax Example What It Represents
Array of Structures struct Student s[3]; 3 full, independent student records stored contiguously in memory.
Structure with an Array struct Course { char code[10]; int marks[5]; }; A single course record containing an internal list of 5 test marks.
Array of Structure Pointers struct Student *ptrs[3]; An array of 3 pointer addresses pointing to student records located elsewhere.
Hierarchical Models

07. Nested Structures (Hierarchical Models)

Just as an integer or character array can be a member of a structure, another structure can also be a member! This is called a Nested Structure.

Real-Life Analogy: Employee and Joining Date

An employee profile contains an employee ID, a name, and a joining date. But a "Date" itself consists of three distinct parts: day, month, and year. Rather than flattening everything into emp_day, emp_month, emp_year, we create a reusable struct Date and embed it inside struct Employee.

7.1 Defining and Accessing Nested Members

Nested members are accessed using chained dot operators: 

struct Date {
    int day;
    int month;
    int year;
};

struct Employee {
    int id;
    char name[40];
    struct Date joiningDate; /* Nested structure member */
};

/* Chained access: */
emp.joiningDate.year = 2024;
nested_structures.c 
#include <stdio.h>

struct Date {
    int day;
    int month;
    int year;
};

struct Employee {
    int id;
    char name[40];
    struct Date joiningDate;
};

int main(void) {
    /* Initialize employee with nested date */
    struct Employee emp = {
        5001,
        "Vikram Seth",
        {15, 8, 2022} /* Initializer for joiningDate */
    };

    printf("--- Employee Record ---\n");
    printf("ID:           %d\n", emp.id);
    printf("Name:         %s\n", emp.name);
    printf("Joining Date: %02d/%02d/%04d\n", 
           emp.joiningDate.day, 
           emp.joiningDate.month, 
           emp.joiningDate.year);

    return 0;
}
Exact Expected Output
--- Employee Record ---
ID:           5001
Name:         Vikram Seth
Joining Date: 15/08/2022
Pointers & References

08. Structure Pointers & The Arrow (->) Operator

Just like primitive variables, structures live in memory and have addresses. A pointer variable can store the starting memory address of a structure object: 

struct Student s1 = {101, "Aman", 87.5f};
struct Student *ptr = &s1; /* ptr points to s1 */

8.1 The Precedence Dilemma: Why (*ptr).marks Is Clunky

If you try to write *ptr.marks to access the marks member through the pointer, the compiler produces an error!

  • In C's operator precedence table, the dot operator (.) has higher precedence than the dereference operator (*).
  • Therefore, *ptr.marks is parsed as *(ptr.marks) — attempting to access a member named marks on the pointer variable itself, which is illegal.
  • To fix this, you must explicitly group the dereference with parentheses: (*ptr).marks.

8.2 The Arrow Operator (->): Elegant Syntactic Sugar

Because writing (*ptr).member everywhere is clumsy and prone to syntax errors, C provides the Arrow Operator (->) as a direct, readable shorthand:

Golden Equivalence Rule
ptr->marks   ≡   (*ptr).marks
structure_pointer_demo.c 
#include <stdio.h>

struct Student {
    int id;
    char name[30];
    float marks;
};

int main(void) {
    struct Student s1 = {101, "Aman", 87.5f};
    struct Student *ptr = &s1;

    printf("Original marks via dot:   %.1f\n", s1.marks);

    /* Update marks through the pointer using the arrow operator */
    ptr->marks = 93.5f;

    /* Read back using both styles */
    printf("Updated marks via (*ptr): %.1f\n", (*ptr).marks);
    printf("Updated marks via arrow:  %.1f\n", ptr->marks);

    return 0;
}
Exact Expected Output
Original marks via dot:   87.5
Updated marks via (*ptr): 93.5
Updated marks via arrow:  93.5
Defensive Programming: Never Dereference NULL

Always ensure a structure pointer is valid and non-null before using ->. Writing ptr->id when ptr == NULL will cause an instant operating system Segmentation Fault.

Function Integration

09. Passing Structures to Functions

In C, functions can interact with structures in two fundamental ways:

9.1 Method A: Passing by Value (Copying)

When a structure variable is passed to a function by value, the compiler creates a complete, byte-for-byte duplicate copy of the entire structure in the function's stack frame.

  • Safety: Any changes made inside the function affect only the local copy; the caller's original record remains untouched.
  • Performance Cost: If the structure contains large arrays or many fields (e.g. 500 bytes), copying that data on every function call degrades performance.

9.2 Method B: Passing by Pointer (Address)

Instead of copying the entire structure, you pass the memory address (pointer) of the structure:

  • High Performance: Passing a pointer copies only 4 or 8 bytes, regardless of whether the structure is 10 bytes or 10,000 bytes.
  • Modifiability: The function can directly modify the caller's original record.
  • Read-Only Protection: If the function only needs to read the structure, use const struct Student *ptr to guarantee the compiler forbids any accidental modifications.
passing_structures.c 
#include <stdio.h>

struct Student {
    int id;
    char name[30];
    float marks;
};

/* Method A: Pass by value (Read-only copy) */
void printStudentValue(struct Student s) {
    printf("[Value Copy] ID: %d | Name: %s | Marks: %.1f\n", s.id, s.name, s.marks);
    s.marks = 0.0f; /* Modifies ONLY the local copy */
}

/* Method B: Pass by pointer (Efficient + can modify caller's data) */
void updateMarksPointer(struct Student *s, float newMarks) {
    if (s != NULL) {
        s->marks = newMarks; /* Modifies caller's original record */
    }
}

int main(void) {
    struct Student s1 = {101, "Aman", 80.0f};

    printf("Initial marks: %.1f\n", s1.marks);

    /* Pass by value */
    printStudentValue(s1);
    printf("After value function call (unchanged): %.1f\n", s1.marks);

    /* Pass by pointer */
    updateMarksPointer(&s1, 95.5f);
    printf("After pointer function call (updated):   %.1f\n", s1.marks);

    return 0;
}
Exact Expected Output
Initial marks: 80.0
[Value Copy] ID: 101 | Name: Aman | Marks: 80.0
After value function call (unchanged): 80.0
After pointer function call (updated):   95.5
Evaluation Metric Pass by Value (struct Type s) Pass by Pointer (const struct Type *s)
Memory Overhead Copies entire object (can be heavy) Copies only 4 or 8 byte memory address
Caller Modification Impossible (immune to changes) Possible (preventable with const)
Best Used For Small structures (e.g. struct Point { int x, y; }) Medium to large structures, data processing, modifying data
Memory Sharing

10. Unions in C: Shared Storage Architecture

What Is a Union?

A union is a user-defined data type in which all declared members share the exact same physical memory storage location. Unlike a structure (where each member has its own dedicated slot), a union can hold a value for only one member at a time.

Real-Life Analogy: A Multipurpose Storage Locker

Imagine a single storage locker at a gym. It can store a bowling ball, or a tennis racket, or a duffel bag. But it cannot store all three at the exact same moment. Putting in the bowling ball requires taking out the tennis racket.

10.1 Union Declaration & Size Calculation

Union Syntax
union Data {
    int number;     /* 4 bytes */
    float decimal;  /* 4 bytes */
    char letter;    /* 1 byte */
};

How large is union Data?

  • In a structure, the size would be at least \(4 + 4 + 1 = 9\) bytes (plus alignment padding).
  • In a union, the size is equal to the size of its largest member (plus any necessary alignment padding). Here, int and float are 4 bytes; thus, sizeof(union Data) is typically 4 bytes!

10.2 Complete Demonstrative Program

Notice what happens when you write to one member and then write to another:

union_lifecycle.c 
#include <stdio.h>

union Data {
    int number;
    float decimal;
    char letter;
};

int main(void) {
    union Data d;

    printf("Size of union Data: %zu bytes\n\n", sizeof(union Data));

    /* 1. Store and read integer */
    d.number = 1984;
    printf("d.number set:  %d\n", d.number);

    /* 2. Store and read float in the same shared bytes */
    d.decimal = 3.14159f;
    printf("d.decimal set: %.5f\n", d.decimal);

    /* 3. Store and read character */
    d.letter = 'Z';
    printf("d.letter set:  %c\n", d.letter);

    /* 4. Demonstrate overwriting: what happened to d.number? */
    printf("\nAfter setting d.letter, d.number is now: %d (corrupted by 'Z' bits!)\n", d.number);

    return 0;
}
Exact Expected Output
Size of union Data: 4 bytes

d.number set:  1984
d.decimal set: 3.14159
d.letter set:  Z

After setting d.letter, d.number is now: 1078530138 (corrupted by 'Z' bits!)
Type-Punning Caution

Writing to d.letter overwrote the first byte of the shared memory storage. Attempting to read d.number or d.decimal afterwards interprets those raw character bits through an integer or floating-point lens. In standard C, accessing a union member other than the one most recently written to is generally non-portable. Always read only the currently active member.

Comparison

11. Structure vs. Union: Comprehensive Comparison

The following table provides an exhaustive side-by-side comparison between structures and unions:

Feature Structure (struct) Union (union)
Memory Allocation Each member gets its own distinct, separate memory address. All members share the exact same starting memory address.
Concurrent Values All members hold independent valid values simultaneously. Only ONE member holds a valid value at any given time.
Total Size Greater than or equal to the sum of all member sizes (plus padding). Equal to the size of the largest member (plus alignment padding).
Altering a Member Modifying one member leaves all other members completely untouched. Modifying one member overwrites the shared bytes of all other members.
Keywords struct union
Primary Purpose Grouping diverse attributes together to model a single record. Conserving RAM when a value can take one of several mutually exclusive forms.
Real-World Example Student profile (Roll No, Name, Marks). Hardware packet or Sensor measurement (Integer count OR Double voltage).
Tagged Union Pattern

12. Practical Union Example: Sensor Data with Tagged Union

Because a union does not intrinsically record which of its members was written to, professional systems programmers use the Tagged Union (Discriminated Union) Pattern.

What Is a Tagged Union?

A tagged union combines an enum tag (which records which data type is currently active) with a union (which stores the actual value) inside a single wrapping struct.

tagged_union_sensor.c 
#include <stdio.h>

/* Step 1: Enum to identify which union variant is active */
enum ReadingType {
    READING_COUNT,
    READING_TEMPERATURE,
    READING_STATUS
};

/* Step 2: Union holding the alternative values */
union ReadingValue {
    int count;
    double temperature;
    char status;
};

/* Step 3: Enclosing struct coupling the tag with the value */
struct SensorReading {
    enum ReadingType type;
    union ReadingValue value;
};

void printReading(const struct SensorReading *r) {
    if (r == NULL) return;

    /* Always check the tag before accessing the union member! */
    switch (r->type) {
        case READING_COUNT:
            printf("[Digital Counter] Pulse Count: %d\n", r->value.count);
            break;
        case READING_TEMPERATURE:
            printf("[Analog Thermometer] Temp: %.2f deg C\n", r->value.temperature);
            break;
        case READING_STATUS:
            printf("[System Monitor] Status Code: '%c'\n", r->value.status);
            break;
        default:
            printf("Error: Unknown sensor type!\n");
            break;
    }
}

int main(void) {
    /* Create three readings using the same tagged structure */
    struct SensorReading r1 = {READING_COUNT, {.count = 1420}};
    struct SensorReading r2 = {READING_TEMPERATURE, {.temperature = 36.65}};
    struct SensorReading r3 = {READING_STATUS, {.status = 'K'}}; /* 'K' for OK */

    printReading(&r1);
    printReading(&r2);
    printReading(&r3);

    return 0;
}
Exact Expected Output
[Digital Counter] Pulse Count: 1420
[Analog Thermometer] Temp: 36.65 deg C
[System Monitor] Status Code: 'K'
Named Constants

13. Enumerations (enum) in C: Named Constants

What Is an Enumeration?

An enumeration (enum) is a user-defined data type consisting of a set of named integer constants (called enumerators). It replaces cryptic "magic numbers" (like 0, 1, 2) with human-readable semantic names.

13.1 Default Enumerator Numbering

By default, the C compiler assigns integer values starting from 0 and increments by 1 for each subsequent name:

Day Enumeration
enum Day {
    SUNDAY,    /* 0 */
    MONDAY,    /* 1 */
    TUESDAY,   /* 2 */
    WEDNESDAY, /* 3 */
    THURSDAY,  /* 4 */
    FRIDAY,    /* 5 */
    SATURDAY   /* 6 */
};
enum_starter.c 
#include <stdio.h>

enum Day {
    SUNDAY,
    MONDAY,
    TUESDAY,
    WEDNESDAY,
    THURSDAY,
    FRIDAY,
    SATURDAY
};

int main(void) {
    enum Day today = WEDNESDAY;

    /* Enumerators are integers under the hood */
    printf("The integer value of WEDNESDAY is: %d\n", today);

    if (today == WEDNESDAY) {
        printf("Midweek reached!\n");
    }

    return 0;
}
Exact Expected Output
The integer value of WEDNESDAY is: 3
Midweek reached!
Enumerators Are Numbers, Not Strings!

Writing printf("%s", today); will crash your program! today holds the integer number 3, not the text string "WEDNESDAY". If you wish to print an enum name as text, you must use a helper function or string array lookup.

State Machines

14. Custom Enumeration Values & Switch Integration

You are not restricted to default 0-based counting. You can assign explicit integer values, including negative numbers and custom seeds:

Explicit Enumerator Values
enum Status {
    FAILED  = -1, /* Explicit -1 */
    PENDING =  0, /* Explicit  0 */
    SUCCESS =  1  /* Explicit  1 */
};

14.1 Automatic Progression from a Seed

If you only assign some values, the unassigned enumerators automatically increment from the previous value: 

enum HTTPStatusCode {
    HTTP_OK = 200,      /* 200 */
    HTTP_CREATED,       /* 201 (200 + 1) */
    HTTP_ACCEPTED,      /* 202 (201 + 1) */
    HTTP_BAD_REQUEST = 400, /* 400 */
    HTTP_UNAUTHORIZED   /* 401 (400 + 1) */
};

14.2 Enums in Switch Statements & typedef Aliases

Combining typedef enum with a switch statement forms the backbone of finite state machines, parser tokens, and network protocol decoders in C:

enum_switch_traffic.c 
#include <stdio.h>

typedef enum {
    LIGHT_RED,
    LIGHT_YELLOW,
    LIGHT_GREEN
} TrafficLight;

void renderSignal(TrafficLight light) {
    switch (light) {
        case LIGHT_RED:
            printf("[RED LIGHT] Stop! Do not proceed.\n");
            break;
        case LIGHT_YELLOW:
            printf("[YELLOW LIGHT] Caution! Prepare to stop.\n");
            break;
        case LIGHT_GREEN:
            printf("[GREEN LIGHT] Go! Clear to proceed.\n");
            break;
        default:
            printf("[MALFUNCTION] Blinking hazard mode.\n");
            break;
    }
}

int main(void) {
    TrafficLight current = LIGHT_RED;
    renderSignal(current);

    current = LIGHT_GREEN;
    renderSignal(current);

    return 0;
}
Exact Expected Output
[RED LIGHT] Stop! Do not proceed.
[GREEN LIGHT] Go! Clear to proceed.
Integration Architecture

15. Combining Structures, Unions & Enums Together

Real-world industrial systems combine all three tools into a clean, cohesive data model. Consider an e-commerce catalog tracking physical books, digital software downloads, and fresh groceries:

combined_catalog.c 
#include <stdio.h>

/* 1. Enum: Category */
typedef enum {
    CAT_BOOK,
    CAT_SOFTWARE,

Q1: What is a structure in C, and why is it described as a "heterogeneous" data type?
ANSWER

A structure is a user-defined aggregate data type that bundles multiple named variables (called members) into a single cohesive unit. It is called heterogeneous because its members can be of completely different data types (e.g. an int, a float, and a char[] array in the same record), unlike an array which must be homogeneous.

Q3: How do you access and modify the price member of a structure variable named myBook?
ANSWER

Using the dot operator (.):

myBook.price = 29.99f;
Q4: What is the core difference between a struct and a union regarding memory allocation?
ANSWER

In a struct, each member has its own distinct, separate memory address, allowing all members to hold valid values simultaneously. In a union, all members share the exact same starting memory address; only the most recently written member holds a valid value.

Q5: What is an enum in C, and what is the default integer value assigned to its first enumerator?
ANSWER

An enum is a user-defined type consisting of a list of named integer constants. By default, the first enumerator is assigned the integer value 0, and each subsequent name increments by 1.

EXACT OUTPUT

Explanation: p.x was initialized to 10 and incremented by 5 to become 15. p.y was untouched and remains 20.

Q7: Distinguish between the dot operator (.) and the arrow operator (->).
ANSWER
  • The dot operator (.) is used when accessing a member directly on a structure variable: s1.id.
  • The arrow operator (->) is used when accessing a member through a pointer to a structure: ptr->id. It is shorthand for (*ptr).id.

Q3: Why does passing a structure by value prevent a function from modifying the caller's record?
ANSWER

In C, arguments are passed strictly by value. When a structure is passed by value, the compiler copies all of its bytes into a brand-new parameter object inside the callee's stack frame. Any modifications change only this local temporary copy; the caller's original object in its own stack frame is left untouched.

Q5: If struct S { int a; double b; }; and union U { int a; double b; }; are declared on a 64-bit system, what are their typical sizes?
ANSWER & ANALYSIS

  • sizeof(union U): Exactly 8 bytes (the size of its largest member, double, which satisfies 8-byte alignment).

Q8: Why is a Tagged Union considered superior to a raw union?
ANSWER

A raw union contains no metadata indicating which member is currently active. Attempting to read a floating-point member when an integer was written reads garbage bits. A Tagged Union bundles an enum tag with the union, enabling code to programmatically verify the active type before accessing the shared storage.

21.2 Problem 2: Shallow Copy vs. Deep Copy Hazard

Demonstrating why structure assignment with pointer members causes a double-free hazard if not deep-copied:

deep_copy_demo.c 
#include <stdio.h>
#include <stdlib.h>
#include <string.h>

struct Document {
    int id;
    char *text; /* Heap pointer */
};

/* Safe Deep Copy Function */
struct Document cloneDocument(const struct Document *src) {
    struct Document dest;
    dest.id = src->id;
    dest.text = malloc(strlen(src->text) + 1);
    if (dest.text != NULL) {
        strcpy(dest.text, src->text);
    }
    return dest;
}

int main(void) {
    struct Document doc1;
    doc1.id = 1;
    doc1.text = malloc(32);
    strcpy(doc1.text, "Original Secret");

    /* Deep copy creates an independent heap buffer */
    struct Document doc2 = cloneDocument(&doc1);

    /* Modify doc2 text independently */
    strcpy(doc2.text, "Modified Copy");

    printf("Doc 1: %s\n", doc1.text);
    printf("Doc 2: %s\n", doc2.text);

    free(doc1.text);
    free(doc2.text);
    return 0;
}

Doc 2: Modified Copy

22. Capstone Mini-Project: Student Record Manager

This complete, professional mini-project demonstrates the synthesis of structures, enums, dynamic memory allocation, and functions:

  • Uses a struct Student with an ID, name, marks, and result status.
  • Uses an enum ResultStatus (STATUS_PASS and STATUS_FAIL).
  • Allocates student records dynamically based on class size.
  • Checks for multiplication overflow and allocation failure.
  • Validates marks (0 to 100).
  • Calculates class average and identifies the top-performing student.
  • Releases all allocated memory cleanly before program exit.
student_record_manager.c 
#include <stdio.h>
#include <stdlib.h>
#include <string.h>
#include <stdint.h>

typedef enum {
    STATUS_FAIL,
    STATUS_PASS
} ResultStatus;

typedef struct {
    int id;
    char name[40];
    float marks;
    ResultStatus status;
} Student;

void displayStudents(const Student *records, size_t count) {
    printf("\n%-6s %-20s %-8s %-8s\n", "ID", "Student Name", "Marks", "Status");
    printf("----------------------------------------------------\n");
    for (size_t i = 0; i < count; i++) {
        printf("#%-5d %-20s %-8.1f %-8s\n", 
               records[i].id, 
               records[i].name, 
               records[i].marks, 
               (records[i].status == STATUS_PASS) ? "PASS" : "FAIL");
    }
    printf("----------------------------------------------------\n");
}

int main(void) {
    printf("====================================================\n");
    printf("          CODEVERSE STUDENT RECORD MANAGER          \n");
    printf("====================================================\n\n");

    /* Deterministic demonstration with 3 students */
    size_t count = 3;

    /* Check for multiplication overflow */
    if (count > SIZE_MAX / sizeof(Student)) {
        fprintf(stderr, "Error: Requested size exceeds addressable memory.\n");
        return 1;
    }

    /* Allocate dynamic array of structures */
    Student *classroom = malloc(count * sizeof *classroom);
    if (classroom == NULL) {
        fprintf(stderr, "Error: Memory allocation failed!\n");
        return 1;
    }

    /* Populate student 1 */
    classroom[0].id = 101;
    strcpy(classroom[0].name, "Aman Sharma");
    classroom[0].marks = 88.5f;
    classroom[0].status = (classroom[0].marks >= 50.0f) ? STATUS_PASS : STATUS_FAIL;

    /* Populate student 2 */
    classroom[1].id = 102;
    strcpy(classroom[1].name, "Priya Patel");
    classroom[1].marks = 94.0f;
    classroom[1].status = (classroom[1].marks >= 50.0f) ? STATUS_PASS : STATUS_FAIL;

    /* Populate student 3 */
    classroom[2].id = 103;
    strcpy(classroom[2].name, "Rohan Verma");
    classroom[2].marks = 42.0f;
    classroom[2].status = (classroom[2].marks >= 50.0f) ? STATUS_PASS : STATUS_FAIL;

    /* Display formatted table */
    displayStudents(classroom, count);

    /* Compute Statistics */
    float total = 0.0f;
    size_t topIndex = 0;

    for (size_t i = 0; i < count; i++) {
        total += classroom[i].marks;
        if (classroom[i].marks > classroom[topIndex].marks) {
            topIndex = i;
        }
    }

    float classAverage = total / (float)count;

    printf("CLASS METRICS:\n");
    printf("Total Enrolled: %zu\n", count);
    printf("Class Average:  %.2f\n", classAverage);
    printf("Top Performer:  %s (ID #%d) with %.1f marks\n", 
           classroom[topIndex].name, 
           classroom[topIndex].id, 
           classroom[topIndex].marks);

    /* Clean up all heap memory */
    free(classroom);
    classroom = NULL;
    printf("\nMemory successfully released.\n");

    return 0;
}

12 High-Yield Technical Viva Questions

1. What is the fundamental difference between a structure and an array?
VIVA ANSWER

An array is a homogeneous collection of elements of the exact same data type. A structure is a heterogeneous collection of named members that can be of completely different data types.

2. What is structure padding, and why does the compiler insert it?
VIVA ANSWER

Structure padding refers to unused bytes inserted by the compiler between members or at the end of a structure to ensure all data types align to their natural hardware memory address boundaries, maximizing CPU memory access performance.

3. What does the arrow operator (->) do?
VIVA ANSWER

The arrow operator dereferences a structure pointer and accesses a member in one step. ptr->member is 100% equivalent to (*ptr).member.

4. How is the size of a union determined?
VIVA ANSWER

The size of a union is equal to the size of its largest member, plus any necessary trailing padding required to satisfy the strictest alignment requirement among its members.

5. Can you store values in all members of a union at the same time?
VIVA ANSWER

No. All members of a union share the exact same physical memory address. Writing to one member overwrites the bytes of all other members.

6. What is a Tagged Union?
VIVA ANSWER

A tagged (discriminated) union wraps an enum tag and a union inside a struct. The tag identifies which union variant is currently active, allowing safe access via conditional or switch statements.

7. What happens if you assign one structure to another using s2 = s1;?
VIVA ANSWER

The compiler performs a shallow bitwise copy of all member values. If a member is a pointer to heap memory, only the address is copied, not the heap data.

8. Are enum names strings in C?
VIVA ANSWER

No. In C, enum names are named integer constants. Attempting to print an enum directly with %s causes undefined behavior or a segmentation fault.

9. Why is passing a structure pointer to a function preferred over passing by value?
VIVA ANSWER

Passing a structure pointer copies only 4 or 8 bytes of address data, eliminating the performance and stack memory overhead of duplicating large structures. It also allows the function to modify the caller's record if needed.

10. How can you protect a structure from being modified when passed via pointer?
VIVA ANSWER

By declaring the function parameter with the const qualifier: void display(const struct Student *s);.

11. What is a self-referential structure?
VIVA ANSWER

A structure that contains a pointer member pointing to another instance of the exact same structure type (e.g., struct Node { int val; struct Node *next; };), forming the basis for linked lists and trees.

12. What is the role of typedef with structures?
VIVA ANSWER

typedef creates a type alias, allowing programmers to declare variables using just Student s1; instead of repeatedly writing struct Student s1;.
