A Simple Problem to Start

Before any definitions, look at this small program. Read it slowly.

C
int result = 10 + 5 * 2;
🤔 Think for a moment

What do you think result will contain?

Many beginners say 30, because they read left to right: 10 + 5 = 15, then 15 × 2 = 30. Take a guess before you read on.

Now let us run it and print the value.

Code
C
#include <stdio.h>

int main() {
    int result = 10 + 5 * 2;

    printf("%d\n", result);
    return 0;
}
Output
20
What happened?
  • C does not always go left to right.
  • The * operator is stronger than +, so C does 5 * 2 = 10 first.
  • Then it does 10 + 10 = 20.
🎯 Why this chapter exists

Every calculation, comparison and decision in a C program is built from operators and expressions. By the end of this chapter you will know what each operator does, and exactly why the answer above is 20 and not 30.

🔑 Key Idea
Operators are the action symbols of C. The order in which C applies them decides the final result.
02

Operator, Operand and Expression

Three small words appear in every line of calculation: operator, operand and expression. Let us meet them one by one.

What is an Operator?

OPERATOR
An operator is a special symbol that tells C to perform a specific action on one or more values. The action can be a calculation, a comparison, a decision or storing a value. Each operator has its own job, such as + for adding or > for comparing.
Examples: +   -   *   >   ==   &&   =
🗣️ In Simple Words

An operator is an action button. When C sees the symbol, it knows what to do with the values around it.

🧮 Real-Life Example

On a calculator you press 8, then +, then 2. The + key is the operator. It tells the calculator to add. Without it, the calculator would just have two numbers and no idea what to do with them.

What is an Operand?

OPERAND
An operand is a value that an operator works on. It can be a number, a variable, or even a smaller expression. An operator needs its operands to do its job, just like a cook needs ingredients.
In 8 + 2, the operands are 8 and 2. In price * qty, the operands are price and qty.
🗣️ In Simple Words

The operator is what to do. The operands are what to do it to.

What is an Expression?

EXPRESSION
An expression is a combination of operands and operators that C can work out to get a single value. When C works it out, we say it evaluates the expression. Even one number or one variable on its own is a valid expression.
Examples: a + b   marks >= 40   price * qty   10
🗣️ In Simple Words

An expression is a small question that C answers with one value. "What is 8 + 2?" The answer, 10, is the value of the expression.

Diagram 1: Operator, Operands and Expression
Operands are the values. The operator is the action. Together they form an expression.
Code
C
#include <stdio.h>

int main() {
    int price = 40;
    int qty = 3;

    int total = price * qty;

    printf("%d\n", total);
    return 0;
}
Output
120
Step-by-Step
  1. price and qty are the operands.
  2. * is the operator (multiply).
  3. price * qty is the expression. C evaluates it: 40 × 3 = 120.
  4. The value 120 is stored in total.

More Expressions

10 + 5
Arithmetic expressionvalue is 15
age >= 18
Relational expressionvalue is 1 (true) or 0 (false)
x
A single variablevalue is whatever x holds
total = a + b
Assignment expressionvalue is the value stored
ℹ️ Expression vs Statement

An expression produces a value: a + b.

A statement is a complete instruction that ends with a semicolon: c = a + b;. A statement usually contains an expression.

🔑 Key Idea
Operator = the action. Operand = the value it acts on. Expression = operands + operators that give one value.

04

Arithmetic Operators

ARITHMETIC OPERATORS
Arithmetic operators perform the basic mathematical calculations in C. They work on numbers and give back a number as the result. C has five of them: addition, subtraction, multiplication, division and modulus (remainder).
Operators: +   -   *   /   %
🗣️ In Simple Words

These are the same operations you use in maths class. The only new ones for most students are * (multiply, instead of ×) and % (remainder).

🛒 Real-Life Example

At a shop, the billing machine adds the prices, multiplies the price by the quantity, subtracts the discount and finds the change to return. Every one of those steps is an arithmetic operator.

+
Addition17 + 5 = 22
-
Subtraction17 - 5 = 12
*
Multiplication17 * 5 = 85
/
Division (quotient)17 / 5 = 3 (for ints)
%
Modulus (remainder)17 % 5 = 2
Code
C
#include <stdio.h>

int main() {
    int a = 17, b = 5;

    printf("a + b = %d\n", a + b);
    printf("a - b = %d\n", a - b);
    printf("a * b = %d\n", a * b);
    printf("a / b = %d\n", a / b);
    printf("a %% b = %d\n", a % b);
    return 0;
}
Output
a + b = 22
a - b = 12
a * b = 85
a / b = 3
a % b = 2
What happened?
  • The first three are the same as normal maths: 22, 12 and 85.
  • 17 / 5 gives 3, not 3.4. Both numbers are ints, so the decimal part is dropped.
  • 17 % 5 gives 2, the remainder left after dividing.
  • %% inside printf prints a single % sign.

Shopping Bill Example

Code
C
#include <stdio.h>

int main() {
    int price = 40;       // price of one notebook
    int qty = 5;          // notebooks bought
    int paid = 500;       // money given

    int total = price * qty;
    int change = paid - total;

    printf("Total: %d\n", total);
    printf("Change: %d\n", change);
    return 0;
}
Output
Total: 200
Change: 300
Step-by-Step
  1. price * qty = 40 × 5 = 200.
  2. paid - total = 500 - 200 = 300.
  3. The shopkeeper returns ₹300.
⚠️ Remember

% works only with integers. Writing 5.5 % 2 gives a compile error. Also, never divide by zero: x / 0 and x % 0 are errors in a program.

🔑 Key Idea
Arithmetic operators calculate. With two ints, / gives the whole-number quotient and % gives the remainder.
05

Integer Division

INTEGER DIVISION
Integer division happens when both numbers in a division are integers. C divides them and keeps only the whole-number part of the answer. The decimal part is thrown away, not rounded.
Examples: 7 / 2 is 3   9 / 10 is 0   20 / 6 is 3
🗣️ In Simple Words

Integer division asks: "How many complete times does the second number fit into the first?" Leftovers are ignored.

🍫 Real-Life Example

You have 17 chocolates and share them equally among 5 students. Each student gets 3 whole chocolates. 2 are left over. You cannot give someone 3.4 chocolates, so C also gives 3.

Diagram 3: 17 shared among 5
The / operator gives the quotient. The % operator gives the remainder.
Code
C
#include <stdio.h>

int main() {
    int chocolates = 17;
    int students = 5;

    printf("Each student gets: %d\n", chocolates / students);
    printf("Chocolates left: %d\n", chocolates % students);
    printf("Exact answer: %.1f\n", (float)chocolates / students);
    return 0;
}
Output
Each student gets: 3
Chocolates left: 2
Exact answer: 3.4
Step-by-Step
  1. chocolates / students is int ÷ int, so it is an integer division: 17 ÷ 5 = 3 (the .4 is dropped).
  2. chocolates % students is the remainder: 17 - (5 × 3) = 2.
  3. (float)chocolates makes 17.0 before dividing, so C does a decimal division: 17.0 ÷ 5 = 3.4.
Why?

The type of the numbers decides the type of the division. Int ÷ int gives an int. We studied this in the Type Casting chapter.

Quick Examples

7 / 2
int ÷ int= 3
9 / 10
int ÷ int (smaller ÷ larger)= 0
7 / 2.0
int ÷ double= 3.5
7.0 / 2
double ÷ int= 3.5
💡 Tip

If at least one operand has a decimal point (or is a float or double), C does a decimal division and keeps the fraction.

🔑 Key Idea
Int ÷ int = int. To keep decimals, make at least one side a float or double before the division.
06

Modulus Operator

MODULUS OPERATOR (%)
The modulus operator % gives the remainder left after one integer is divided by another. It works only on integer values. It is one of the most useful operators for checking even or odd numbers, finding digits and grouping items.
Examples: 17 % 5 is 2   10 % 2 is 0   7 % 2 is 1
🗣️ In Simple Words

a % b asks: "After dividing a by b, what is left over?"

📦 Real-Life Example

A shop has 47 pens and packs 10 pens in each box. It fills 47 / 10 = 4 full boxes. The loose pens left over are 47 % 10 = 7.

Code
C
#include <stdio.h>

int main() {
    int pens = 47;
    int n = 7342;

    printf("Full boxes: %d\n", pens / 10);
    printf("Loose pens: %d\n", pens % 10);
    printf("Last digit of %d: %d\n", n, n % 10);
    printf("10 %% 2 = %d\n", 10 % 2);
    printf("7 %% 2 = %d\n", 7 % 2);
    return 0;
}
Output
Full boxes: 4
Loose pens: 7
Last digit of 7342: 2
10 % 2 = 0
7 % 2 = 1
Step-by-Step
  1. 47 / 10 = 4 (integer division), and 47 % 10 = 47 - 40 = 7.
  2. 7342 % 10 is the remainder after dividing by 10, which is always the last digit: 2.
  3. 10 % 2 is 0, because 10 divides by 2 exactly. A number is even when n % 2 is 0.
  4. 7 % 2 is 1, so 7 is odd.

Where is % used?

n % 2
Even or odd check0 means even, 1 means odd
n % 10
Last digit of a number7342 % 10 = 2
a % b == 0
Is a divisible by b?20 % 5 == 0 is true
(9 + 8) % 12
Clock arithmetic8 hours after 9 o'clock = 5
⚠️ Careful

% is not the percentage symbol. 10 % 3 is 1 (the remainder), not 0.3 and not 3.33. To find a percentage you use multiplication and division.

🔑 Key Idea
/ tells you how many times it fits. % tells you what is left.
07

Relational Operators

RELATIONAL OPERATORS
Relational operators compare two values and tell you how they are related. The result is always either true or false. In C, true is represented by the number 1 and false is represented by the number 0.
Operators: ==   !=   >   <   >=   <=
🗣️ In Simple Words

A relational operator asks a yes or no question about two values. C answers 1 for yes and 0 for no.

🎓 Real-Life Example

The pass mark of an exam is 40. A student has 45 marks. The question "Is 45 at least 40?" has the answer yes. In C, marks >= 40 gives 1.

==
Equal to5 == 5 → 1
!=
Not equal to5 != 3 → 1
>
Greater than5 > 8 → 0
<
Less than5 < 8 → 1
>=
Greater than or equal to5 >= 5 → 1
<=
Less than or equal to5 <= 3 → 0
Code
C
#include <stdio.h>

int main() {
    int age = 20;
    int marks = 45;

    printf("%d\n", age >= 18);
    printf("%d\n", age < 18);
    printf("%d\n", marks == 50);
    printf("%d\n", marks != 50);
    printf("%d\n", marks > 40);
    printf("%d\n", marks <= 45);
    return 0;
}
Output
1
0
0
1
1
1
Step-by-Step
  1. 20 >= 18 is true → 1.
  2. 20 < 18 is false → 0.
  3. 45 == 50 is false → 0.
  4. 45 != 50 is true → 1.
  5. 45 > 40 is true → 1.
  6. 45 <= 45 is true (45 is equal to 45) → 1.
⚠️ = is not ==

== compares two values. A single = stores a value. They look similar but do completely different jobs.

🔑 Key Idea
A relational expression gives 1 (true) or 0 (false). Use == to compare, never =.
08

Logical Operators

LOGICAL OPERATORS
Logical operators combine two or more conditions into one bigger condition. They look at whether each condition is true or false, and then decide if the whole thing is true or false. The result is always 1 or 0.
Operators: && (AND)   || (OR)   ! (NOT)
🗣️ In Simple Words

Logical operators are the "and", "or" and "not" of programming. You use them in everyday sentences without noticing.

📝 Real-Life Example

"A student can write the exam if attendance is at least 75% AND marks in the internal test are at least 40." Both conditions must be true. That is the && operator.

Diagram 4: The Three Logical Operators
AND needs both. OR needs at least one. NOT flips true and false.

Truth Table

Here 1 means true and 0 means false.

ABA && BA || B
1111
1001
0101
0000
A!A
10
01
Code
C
#include <stdio.h>

int main() {
    int attendance = 70;
    int marks = 55;

    printf("%d\n", attendance >= 75 && marks >= 40);
    printf("%d\n", attendance >= 75 || marks >= 40);
    printf("%d\n", !(marks >= 40));
    return 0;
}
Output
0
1
0
Step-by-Step
  1. Line 1: 70 >= 75 is 0 (false). 55 >= 40 is 1 (true). Then 0 && 1 = 0, because AND needs both to be true.
  2. Line 2: The same two answers, 0 and 1. Then 0 || 1 = 1, because OR needs only one true.
  3. Line 3: 55 >= 40 is 1. Then !1 flips it to 0.
Why?

The student has enough marks but not enough attendance. So "both" fails, "either" passes, and the "not" of a pass is a fail.

💡 Good to know

C treats any non-zero value as true and 0 as false. But the result of &&, || and ! is always exactly 1 or 0.

⚡ C stops early

With &&, if the left side is false, C already knows the answer and does not check the right side. With ||, if the left side is true, C skips the right side. This is called short-circuiting.

🔑 Key Idea
&& = both true. || = at least one true. ! = opposite. Results are always 1 or 0.
09

Assignment Operators

ASSIGNMENT OPERATORS
Assignment operators store a value into a variable. The basic one is =, which takes the value on its right and puts it into the variable on its left. Compound assignment operators such as += combine a calculation and an assignment in one short step.
Operators: =   +=   -=   *=   /=   %=
🗣️ In Simple Words

= does not mean "equal" like in maths. It means "store this value in this box". A compound operator means "update the box using its own old value".

📦 Real-Life Example

A shop has 100 items in stock. After selling 20, the stock is updated to 80. In C, that is stock -= 20;. The new value depends on the old value, which is exactly what compound assignment is for.

Normal vs Compound

Normal assignment

You write the variable twice.

stock = stock - 20;

Compound assignment

Shorter, and it means exactly the same.

stock -= 20;
=
Simple assignmentx = 10
+=
Add and assignx += 5 means x = x + 5
-=
Subtract and assignx -= 5 means x = x - 5
*=
Multiply and assignx *= 5 means x = x * 5
/=
Divide and assignx /= 5 means x = x / 5
%=
Remainder and assignx %= 5 means x = x % 5
Code
C
#include <stdio.h>

int main() {
    int stock = 100;

    stock -= 20;
    printf("%d\n", stock);

    stock += 5;
    printf("%d\n", stock);

    stock *= 2;
    printf("%d\n", stock);

    stock /= 5;
    printf("%d\n", stock);

    stock %= 10;
    printf("%d\n", stock);
    return 0;
}
Output
80
85
170
34
4
Step-by-Step
  1. stock -= 20 → 100 - 20 = 80.
  2. stock += 5 → 80 + 5 = 85.
  3. stock *= 2 → 85 × 2 = 170.
  4. stock /= 5 → 170 ÷ 5 = 34.
  5. stock %= 10 → remainder of 34 ÷ 10 = 4.
💡 Tip

The same integer division rules apply. If x is an int, then x /= 2 drops any decimal part.

🔑 Key Idea
= stores. +=, -= and the others update a variable using its own old value.
10

Increment and Decrement Operators

INCREMENT AND DECREMENT OPERATORS
The increment operator ++ increases a variable by 1, and the decrement operator -- decreases it by 1. Each can be written before the variable (prefix) or after it (postfix). On its own they do the same thing, but inside a bigger expression the position changes the result.
Forms: ++x (pre-increment)   x++ (post-increment)   --x (pre-decrement)   x-- (post-decrement)
🗣️ In Simple Words

x++ is a shortcut for x = x + 1. Think of a tally counter that goes up by one every time you click it.

🎟️ Real-Life Example

A cinema has a counter for tickets sold. Each sale does tickets++. Each cancellation does tickets--. Only one is added or removed at a time.

FormNameWhat happens
++xPre-incrementFirst add 1, then use the value
x++Post-incrementFirst use the value, then add 1
--xPre-decrementFirst subtract 1, then use the value
x--Post-decrementFirst use the value, then subtract 1

On a line by itself, x++; and ++x; do exactly the same thing. The difference only shows up when the result is used, for example stored in another variable or printed.

Diagram 5: Pre-increment vs Post-increment
Pre = change first, then use. Post = use first, then change.

Pre-Increment

Code
C
int x = 5;
int y = ++x;

printf("x = %d, y = %d", x, y);
Output
x = 6, y = 6
Step-by-Step
  1. x starts as 5.
  2. ++x is a pre-increment: x is increased first, so x becomes 6.
  3. The new value 6 is then stored in y.

Post-Increment

Code
C
int x = 5;
int y = x++;

printf("x = %d, y = %d", x, y);
Output
x = 6, y = 5
Step-by-Step
  1. x starts as 5.
  2. x++ is a post-increment: the old value 5 is used first, so y gets 5.
  3. After that, x is increased and becomes 6.

Pre and Post Decrement

Code
C
int a = 10;

printf("%d\n", a--);
printf("%d\n", a);
printf("%d\n", --a);
printf("%d\n", a);
Output
10
9
8
8
Step-by-Step
  1. a-- (post): prints the old value 10, then a becomes 9.
  2. Printing a now shows 9.
  3. --a (pre): a becomes 8 first, then 8 is printed.
  4. Printing a again shows 8.
🔑 Key Idea
Pre (++x) = change, then use. Post (x++) = use, then change. Alone on a line, they are identical.
11

Conditional (Ternary) Operator

CONDITIONAL (TERNARY) OPERATOR
The conditional operator ?: chooses between two values based on a condition. If the condition is true, it gives the first value. If the condition is false, it gives the second value. It is called ternary because it works on three parts.
Syntax: condition ? expression1 : expression2
🗣️ In Simple Words

It is a one-line choice: "If this is true, take that. Otherwise, take this other thing."

🌡️ Real-Life Example

"If the temperature is above 30, call it a hot day. Otherwise, call it a pleasant day." One condition, two possible answers.

Diagram 6: How ? : Decides
Condition true → first value. Condition false → second value.
Code
C
#include <stdio.h>

int main() {
    int marks = 62;
    int a = 12, b = 20;
    int total = 1200;

    printf("Result: %s\n", marks >= 40 ? "Pass" : "Fail");

    int max = (a > b) ? a : b;
    printf("Bigger number: %d\n", max);

    int discount = (total >= 1000) ? 100 : 0;
    printf("Discount: %d\n", discount);
    return 0;
}
Output
Result: Pass
Bigger number: 20
Discount: 100
Step-by-Step
  1. marks >= 40 is 62 ≥ 40, which is true, so the first value "Pass" is chosen.
  2. a > b is 12 > 20, which is false, so the second value b (20) is chosen.
  3. total >= 1000 is true, so the discount is 100. For a smaller total it would be 0.

Note: %s prints text. We will study text (strings) properly in a later topic. For now, treat "Pass" as a word to print.

💡 Tip

Use ?: for short, simple choices. If the choice needs many lines or more than two options, there are better tools, which come in a later topic.

🔑 Key Idea
condition ? A : B gives A when the condition is true, and B when it is false.
12

Bitwise Operators: Basic Introduction

BITWISE OPERATORS
Bitwise operators work on the individual bits (the 0s and 1s) of a number. A computer stores every number in binary form, and these operators let you work directly on that binary form. This is only a basic introduction, because bitwise operations are used mostly in advanced topics.
Operators: & (AND)   | (OR)   ^ (XOR)   ~ (NOT)   << (left shift)   >> (right shift)
🗣️ In Simple Words

Imagine a row of light switches. Each switch is a bit: ON is 1 and OFF is 0. Bitwise operators compare or flip these switches one by one.

🔢 Binary in 10 seconds

Binary uses only 0 and 1. With 4 bits: 0101 is 5 (4 + 1) and 0011 is 3 (2 + 1). We use only 4 bits here to keep the pictures small. Real ints have 32 bits, with extra 0s on the left.

Diagram 7: Bit by Bit (4-bit view)
& = 1 only if both bits are 1. | = 1 if any bit is 1. ^ = 1 if the bits are different.
&
AND1 only when both bits are 1
|
OR1 when at least one bit is 1
^
XOR1 when the two bits are different
~
NOTflips every bit
<<
Left shiftmoves bits left (5 << 1 = 10)
>>
Right shiftmoves bits right (5 >> 1 = 2)
Code
C
#include <stdio.h>

int main() {
    int a = 5, b = 3;

    printf("a & b  = %d\n", a & b);
    printf("a | b  = %d\n", a | b);
    printf("a ^ b  = %d\n", a ^ b);
    printf("~a     = %d\n", ~a);
    printf("a << 1 = %d\n", a << 1);
    printf("a >> 1 = %d\n", a >> 1);
    return 0;
}
Output
a & b  = 1
a | b  = 7
a ^ b  = 6
~a     = -6
a << 1 = 10
a >> 1 = 2
Step-by-Step
  1. 0101 & 0011 = 0001 = 1.
  2. 0101 | 0011 = 0111 = 7.
  3. 0101 ^ 0011 = 0110 = 6.
  4. ~5 flips every bit. On most computers the result is -6. A handy rule: ~n equals -(n + 1).
  5. 5 << 1 moves 0101 to 1010 = 10. Shifting left by 1 doubles the number.
  6. 5 >> 1 moves 0101 to 0010 = 2. Shifting right by 1 halves the number (dropping any remainder).
⚠️ Do not mix these up

& is bitwise AND (works on bits). && is logical AND (works on true and false). They are different operators.

🔑 Key Idea
Bitwise operators work on the bits of a number. For now, understand the idea of AND, OR, XOR, NOT and shifting. Details come later.
13

sizeof Operator

SIZEOF OPERATOR
The sizeof operator tells you how much memory a data type or a variable uses, measured in bytes. It is an operator, not a function, even though it is often written with brackets. It is useful when you want to know how much space your data takes.
Syntax: sizeof(type) or sizeof(variable)
🗣️ In Simple Words

sizeof answers the question "How many bytes of memory does this need?"

🧳 Real-Life Example

Before packing a bag, you check how much space each item takes. A jacket takes more space than a handkerchief. In the same way, a double takes more memory than a char.

Diagram 8: Typical Sizes in Bytes
Typical sizes on most modern systems. Each unit of width = 1 byte.
Code
C
#include <stdio.h>

int main() {
    int age = 20;
    double price = 99.5;

    printf("char: %zu\n", sizeof(char));
    printf("int: %zu\n", sizeof(int));
    printf("float: %zu\n", sizeof(float));
    printf("double: %zu\n", sizeof(double));
    printf("age: %zu\n", sizeof(age));
    printf("price: %zu\n", sizeof(price));
    return 0;
}
Output (on most systems)
char: 1
int: 4
float: 4
double: 8
age: 4
price: 8
What happened?
  • sizeof(char) is always 1 byte in C.
  • sizeof(age) gives the size of the variable's type. age is an int, so 4.
  • sizeof(price) is 8 because price is a double.
  • %zu is the format specifier used to print the result of sizeof.
⚠️ Remember

Sizes can be different on different computers. The numbers 4 and 8 are the most common, but only sizeof(char) is guaranteed to be 1.

🔑 Key Idea
sizeof gives the memory size in bytes. It works on types and on variables.
14

Unary, Binary and Ternary Operators

Another way to group operators is by how many operands they need. This gives three groups: unary, binary and ternary.

UNARY, BINARY AND TERNARY
A unary operator works on one operand. A binary operator works on two operands. A ternary operator works on three operands, and C has only one of those: ?:.
Unary: -x   Binary: a + b   Ternary: c ? x : y
Diagram 9: Operators by Number of Operands
Count the operands to find the kind of operator.
KindOperandsExamples
Unary1-x, !x, ++x, x--, ~x, sizeof x
Binary2+ - * / %, < > ==, && ||, =, & | ^
Ternary3? : (the only one)
Code
C
int x = 5;

int y = -x;               // unary: one operand
int z = x - 3;            // binary: two operands
int m = (x > 3) ? 1 : 0;  // ternary: three parts

printf("%d %d %d", y, z, m);
Output
-5 2 1
Step-by-Step
  1. -x has one operand (x). It flips the sign: -5.
  2. x - 3 has two operands (x and 3): 5 - 3 = 2.
  3. (x > 3) ? 1 : 0 has three parts: the condition, 1 and 0. The condition is true, so the result is 1.
ℹ️ One symbol, two jobs

The symbol - can be unary (-x, making a number negative) or binary (a - b, subtracting). C decides by counting the operands.

🔑 Key Idea
Count the operands: one = unary, two = binary, three = ternary.

Operator Precedence

OPERATOR PRECEDENCE
Operator precedence is the rule that decides which operator C works out first when an expression contains more than one operator. Operators with higher precedence are worked out before operators with lower precedence. Parentheses ( ) have the highest priority of all, so they let you take control.
Example: in 10 + 5 * 2, * has higher precedence than +, so 5 * 2 is done first.
🗣️ In Simple Words

Precedence is "who goes first". It is like the BODMAS rule from maths, but with more operators in the rulebook.

🛒 Real-Life Example

You buy one pen for ₹10 and 2 notebooks at ₹40 each. The bill is 10 + 40 * 2. The quantity 2 belongs only to the notebooks, so you multiply first (40 × 2 = 80) and then add the pen (80 + 10 = 90). C does the same.

Diagram 10: Precedence Ladder (1 = worked out first)
Dashed rows are bitwise and shift operators, shown for completeness. You will use the other rows most of the time.
💡 Easy way to remember
  1. Brackets first.
  2. Unary operators like !, -x, ++x.
  3. Multiply, divide, remainder (* / %).
  4. Add, subtract (+ -).
  5. Compare (< > == !=).
  6. Logical: && before ||.
  7. Ternary ?:, then assignment last.

Precedence Changes the Result

Code
C
#include <stdio.h>

int main() {
    int a = 1, b = 0, c = 0;

    printf("%d\n", 10 + 5 * 2);
    printf("%d\n", (10 + 5) * 2);
    printf("%d\n", 100 - 20 / 4);
    printf("%d\n", (100 - 20) / 4);
    printf("%d\n", a || b && c);
    printf("%d\n", (a || b) && c);
    return 0;
}
Output
20
30
95
20
1
0
Step-by-Step
  1. 10 + 5 * 2: * first → 10 + 10 = 20.
  2. (10 + 5) * 2: brackets first → 15 * 2 = 30.
  3. 100 - 20 / 4: / first → 100 - 5 = 95.
  4. (100 - 20) / 4: brackets first → 80 / 4 = 20.
  5. a || b && c: && beats ||, so it is a || (b && c) = 1 || (0 && 0) = 1 || 0 = 1.
  6. (a || b) && c: brackets first → (1 || 0) && 0 = 1 && 0 = 0.
Why?

The same numbers and operators gave different answers. Only the order changed. This is why precedence matters.

A Classic Trap with !

Code
C
int marks = 30;

printf("%d\n", !marks >= 40);
printf("%d\n", !(marks >= 40));
Output
0
1
Step-by-Step
  1. Line 1: ! has higher precedence than >=. So C does (!marks) >= 40. Since marks is 30 (non-zero, true), !marks is 0. Then 0 >= 40 is 0.
  2. Line 2: The brackets force the comparison first: 30 >= 40 is 0, and !0 is 1.
Why?

The student failed (30 < 40), so "not passed" should be true (1). Only the second line says so. Brackets saved the day.

🔑 Rule of Thumb

If you are not sure about the order, add brackets. Brackets never hurt, and they make your intention clear to anyone who reads the code.

🔑 Key Idea
Precedence decides which operator goes first. Brackets beat everything. Multiply before add. Compare before &&. && before ||. Assignment last.

Associativity

ASSOCIATIVITY
Associativity decides the order of evaluation when two operators have the same precedence. It tells C whether to start from the left or from the right. Precedence is checked first, and associativity is used only to break a tie.
Left to right: 10 - 4 - 3   Right to left: a = b = 5
🗣️ In Simple Words

Precedence says which kind of operator goes first. Associativity says which one in a row goes first, when they are equals.

🚶 Real-Life Example

People in a queue are all equal. The one standing at the front is served first. Left-to-right associativity means C serves the leftmost operator first. Right-to-left means it serves the rightmost one first.

Diagram 11: Two Directions
Most operators go left to right. Assignment and unary operators go right to left.
OperatorsAssociativity
( )   x++   x--Left to right
!   -x   ++x   --x   sizeof   (type)Right to left

<   <=   >   >=Left to right

&&Left to right

=   +=   -=   *=   /=   %=Right to left
Code
C
#include <stdio.h>

int main() {
    int a, b;

    printf("%d\n", 10 - 4 - 3);
    printf("%d\n", 100 / 10 * 2);
    printf("%d\n", 100 / (10 * 2));

    a = b = 5;
    printf("%d %d\n", a, b);
    return 0;
}
Output
3
20
5
5 5
Step-by-Step
  1. 10 - 4 - 3: both - have the same rank. Left to right: (10 - 4) - 3 = 6 - 3 = 3. If it went right to left, it would give 10 - (4 - 3) = 9, which is wrong.
  2. 100 / 10 * 2: / and * have the same rank. Left to right: (100 / 10) * 2 = 10 * 2 = 20.
  3. 100 / (10 * 2): the brackets change the order: 100 / 20 = 5.
  4. a = b = 5: assignment goes right to left. First b = 5. That gives the value 5, so a = 5 next. Both are 5.
⚠️ Common slip

100 / 10 * 2 is not 100 / 20. C does not multiply first just because it is written second. Both have equal rank, so left to right applies.

🔑 Key Idea
Same precedence? Check associativity. Most operators go left to right. Assignment, unary operators and ?: go right to left.
17

Expression Evaluation

EXPRESSION EVALUATION
Expression evaluation is the process C follows to turn an expression into one final value. C works out one operator at a time, in an order decided by brackets, precedence and associativity. The final value can then be stored, printed or used in a comparison.
Example: 10 + 20 / 4 * 3 - 2 evaluates to 23.
🗣️ In Simple Words

C solves an expression one small step at a time, replacing each finished piece with its value, until only one value is left.

The 5 Steps C Follows

  1. Look for parentheses. Work out the innermost ones first.
  2. Among the remaining operators, work out the highest precedence first.
  3. If operators have the same precedence, use associativity (mostly left to right).
  4. At each step, the types of the operands decide the type of the result (int ÷ int gives an int).
  5. When one value remains, that is the value of the expression.
Diagram 12: Evaluating 10 + 20 / 4 * 3 - 2
Each step solves one operator and rewrites the expression shorter.
Code
C
#include <stdio.h>

int main() {
    int result = 10 + 20 / 4 * 3 - 2;

    printf("%d\n", result);
    return 0;
}
Output
23
Step-by-Step
  1. / and * beat + and -. Among / and *, go left to right: first 20 / 4 = 5.
  2. The expression is now 10 + 5 * 3 - 2. Next 5 * 3 = 15.
  3. Now 10 + 15 - 2. Both are rank 4, so left to right: 10 + 15 = 25.
  4. Finally 25 - 2 = 23, stored in result.

Mixing Comparison and Logic

Code
C
int age = 20, marks = 38;

int ok = age >= 18 && marks + 5 >= 40;
printf("%d\n", ok);
Output
1
Step-by-Step
  1. + first: marks + 5 = 43.
  2. Then the comparisons: 20 >= 18 is 1, and 43 >= 40 is 1.
  3. Then &&: 1 && 1 = 1.
  4. Last, assignment: 1 is stored in ok.
Why?

The order was: arithmetic, then comparison, then logical, then assignment. That follows the precedence ladder from top to bottom.

Types Matter Too

Code
C
int m1 = 85, m2 = 90, m3 = 82;

printf("%d\n", (m1 + m2 + m3) / 3);
printf("%.2f\n", (m1 + m2 + m3) / 3.0);
Output
85
85.67
Step-by-Step
  1. Brackets first: 85 + 90 + 82 = 257 (an int).
  2. Line 1: 257 / 3 is int ÷ int, an integer division: 85.
  3. Line 2: 257 / 3.0 is int ÷ double, so C divides as decimals: 85.666..., printed as 85.67.

Use Parentheses to Be Clear

❌ Hard to read

int ok = age >= 18 && marks + 5 >= 40 || attendance > 90;

You have to remember the precedence ladder to understand it.

✅ Easy to read

int ok = ((age >= 18) && (marks + 5 >= 40)) || (attendance > 90);

Same meaning. Every group is visible at a glance.

💡 Tip

Extra brackets cost nothing. Write the expression so that a classmate can understand it without checking the precedence table.

🔑 Key Idea
C evaluates one operator at a time: brackets, then precedence, then associativity. Types decide whether a division keeps its decimals.

Real-Life Examples

Now let us combine several operators in realistic programs.

Example 1: Shopping Bill with Discount

A customer buys 4 items at ₹250 each. If the bill is ₹1000 or more, a discount of ₹100 is given.

Code
C
#include <stdio.h>

int main() {
    int price = 250, qty = 4;

    int subtotal = price * qty;
    int discount = (subtotal >= 1000) ? 100 : 0;
    int payable = subtotal - discount;

    printf("Subtotal: %d\n", subtotal);
    printf("Discount: %d\n", discount);
    printf("Payable: %d\n", payable);
    return 0;
}
Output
Subtotal: 1000
Discount: 100
Payable: 900
Step-by-Step
  1. price * qty = 250 × 4 = 1000.
  2. subtotal >= 1000 is true, so the ternary gives 100.
  3. subtotal - discount = 1000 - 100 = 900.

Operators used: *, >=, ?:, -, =.

Example 2: Exam Eligibility

A student can sit the exam if attendance is at least 75% and marks plus 5 grace marks reach at least 40.

Code
C
#include <stdio.h>

int main() {
    int attendance = 82, marks = 38, grace = 5;

    int eligible = (attendance >= 75) && (marks + grace >= 40);

    printf("Eligible: %s\n", eligible ? "Yes" : "No");
    return 0;
}
Output
Eligible: Yes
Step-by-Step
  1. attendance >= 75 → 82 ≥ 75 → 1.
  2. marks + grace = 43, then 43 >= 40 → 1.
  3. 1 && 1 → 1, which is stored in eligible.
  4. The ternary sees 1 (true) and prints "Yes".

Operators used: >=, +, &&, =, ?:.

Example 3: Shop Stock and Boxes

A shop has 120 items. It sells 45 and then receives a delivery of 50. Items are packed in boxes of 12.

Code
C
#include <stdio.h>

int main() {
    int stock = 120, sold = 45, delivered = 50;

    stock -= sold;
    printf("After sales: %d\n", stock);

    stock += delivered;
    printf("After delivery: %d\n", stock);

    printf("Full boxes of 12: %d\n", stock / 12);
    printf("Loose items: %d\n", stock % 12);
    return 0;
}
Output
After sales: 75
After delivery: 125
Full boxes of 12: 10
Loose items: 5
Step-by-Step
  1. stock -= sold → 120 - 45 = 75.
  2. stock += delivered → 75 + 50 = 125.
  3. 125 / 12 = 10 (integer division).
  4. 125 % 12 = 125 - 120 = 5.

Operators used: -=, +=, /, %.

🔑 Key Idea
Real programs use many operators together: arithmetic to calculate, relational and logical to decide, assignment to store.

Common Mistakes

❌ Mistake 1: Using = instead of ==
int x = 3;
printf("%d\n", x == 5);
printf("%d\n", x = 5);
printf("%d\n", x);
⚠️ Problem: x was changed
Output
0
5
5
✅ Correct: use == to compare
printf("%d\n", x == 5);   // 0 (just a question)
Why: A single = stores a value. It changed x from 3 to 5, and the value 5 (non-zero) counts as true. == only asks whether the two sides are equal. Mixing them up causes bugs that are hard to spot, so read compiler warnings carefully.
❌ Mistake 2: Misunderstanding %
float t = 7.5;
int r = t % 2;
⚠️ Problem: compile error
Compiler message
error: invalid operands to binary % (have 'float' and 'int')
✅ Correct: use % with integers
int n = 7;
int r = n % 2;       // 1
Why: % works only with integers. Also remember it gives the remainder, not a percentage and not a decimal: 10 % 3 is 1, not 3.33.
❌ Mistake 3: Confusing integer division with decimal division
int m1 = 85, m2 = 90, m3 = 82;
float avg = (m1 + m2 + m3) / 3;
printf("%.2f", avg);
⚠️ Problem: expected 85.67
Output
85.00
✅ Correct: make one side a decimal
float avg = (m1 + m2 + m3) / 3.0;   // 85.67
Why: 257 / 3 is int ÷ int, so C gives 85 and the .67 is lost before it reaches the float variable. Using 3.0 makes it a decimal division.
❌ Mistake 4: Confusing pre-increment and post-increment
int a = 5;
int b = a++ + 10;
printf("a = %d, b = %d", a, b);
⚠️ Problem: expected b = 16
Output
a = 6, b = 15
✅ Correct: use pre-increment, or split the lines
int a = 5;
int b = ++a + 10;    // a = 6, b = 16
Why: a++ uses the old value 5 first (5 + 10 = 15), and only afterwards does a become 6. ++a increases first, so it uses 6 (6 + 10 = 16). Also avoid using the same variable twice in one expression with ++, such as a + a++, because the result is unpredictable.
❌ Mistake 5: Ignoring operator precedence
int a = 80, b = 90;
int avg = a + b / 2;
printf("%d", avg);
⚠️ Problem: expected 85
Output
125
✅ Correct: use brackets
int avg = (a + b) / 2;   // 85
Why: / goes before +. So C does 90 / 2 = 45 first, then 80 + 45 = 125. Brackets make the addition happen first.
❌ Mistake 6: Writing unnecessarily complicated expressions

❌ Confusing

int ok = !(age < 18) && !(marks < 40);

✅ Clear

int ok = (age >= 18) && (marks >= 40);

❌ Everything in one line

int payable = price * qty - (price * qty >= 1000 ? 100 : 0) + price * qty * 5 / 100;

✅ Small named steps

int subtotal = price * qty;
int discount = (subtotal >= 1000) ? 100 : 0;
int tax = subtotal * 5 / 100;
int payable = subtotal - discount + tax;
Why: Both versions give the same answer, but the clear ones are easier to read, test and fix. Avoid double negatives, and break long calculations into steps with meaningful names.
❌ Mistake 7: Misunderstanding logical operators
int x = 15;
printf("%d", 0 < x < 10);
⚠️ Problem: 15 is not between 0 and 10
Output
1
✅ Correct: join two comparisons with &&
printf("%d", x > 0 && x < 10);   // 0
Why: C reads 0 < x < 10 as (0 < x) < 10. First 0 < 15 is 1. Then 1 < 10 is 1, so the answer is always true. Also remember: && is logical AND (not &), || is logical OR (not |), and ! binds tightly, so use !(a > b) with brackets.

Think Before You Code

🧠 Think Before You Code

Before writing an expression, ask yourself:

  1. What values (operands) do I have, and what are their types?
  2. What kind of result do I need: a whole number, a decimal, a true/false (1 or 0), or one of two choices?
  3. Which group of operator fits: arithmetic, relational, logical, assignment, or ternary?
  4. Could integer division or % change my answer?
  5. Does the order matter? Do I need brackets?
  6. Is ++ or -- inside a bigger expression? Pre or post?
  7. Can a friend read this expression easily, or should I split it?
Worked example: average of three marks and a pass check

Marks are int m1 = 85, m2 = 90, m3 = 82. We want the average with decimals, and we want to know if the student passed (average at least 40).

  1. Values and types? Three ints.
  2. Result needed? A decimal average, then a 1 or 0 for pass.
  3. Operators? + and / (arithmetic), >= (relational).
  4. Integer division? Yes, it would drop .67. So divide by 3.0.
  5. Order and brackets? The sum must be added before dividing, so it needs brackets.
  6. ++ or --? Not needed.
  7. Readable? Two short lines, with clear names.
C
#include <stdio.h>

int main() {
    int m1 = 85, m2 = 90, m3 = 82;

    float average = (m1 + m2 + m3) / 3.0;
    int passed = average >= 40;

    printf("Average: %.2f\n", average);
    printf("Passed: %d\n", passed);
    return 0;
}
Output
Average: 85.67
Passed: 1

🎓 Challenge: Packing Pens

A shop has 250 pens. Each box holds 12 pens. Write a C program to find:

  • how many full boxes can be packed,
  • how many loose pens are left over,
  • whether the pens fit into boxes exactly (print Yes or No).

Show Suggested Solution

int main() {
    int pens = 250;
    int perBox = 12;

    int boxes = pens / perBox;
    int loose = pens % perBox;

    printf("Remaining seats: %d\n", seats);
    printf("Status: %s\n", seats > 0 ? "Seats available" : "House full");
    return 0;
}
