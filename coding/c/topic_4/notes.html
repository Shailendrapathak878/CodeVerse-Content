01

What is Data?

DATA
Data means the pieces of information that a program works with. It can be a number, a word, a single letter, a price, a temperature or anything else we want the computer to remember and use. A program is only useful when it can store data, read it, change it and show it again.
Examples: a name, an age, marks, a price, a temperature, a grade.
🗣️ In Simple Words

Data is simply facts about something. When you say "Riya is 20 years old and got 82.5%", you have just spoken four pieces of data: a name, an age and a percentage. A program needs the same kind of facts to do any job.

🏫 Real-Life Example

A school keeps a record for every student. It does not store one big blob of text. It keeps separate, clearly named pieces of information.

One student, many pieces of data
Every piece of information has a name and a value.
More everyday data
  • Name: "Riya" (text)
  • Age: 20 (whole number)
  • Marks: 85 (whole number)
  • Price: 499.99 (decimal number)
  • Temperature: 36.5 (decimal number)
  • Grade: A (a single letter)

Notice that data comes in different kinds. Some is a whole number, some has decimals, some is a letter. C needs to know the kind so it can store it correctly. That is why data types exist.

🔑 Key Idea
Data = information. A program needs a place to keep that information and a way to name it. That place is a variable.
02

What is a Variable?

VARIABLE
A variable is a named memory location used to store a value while a program is running. The value inside the variable can change whenever the program needs to update it. We give the variable a name so that we can easily find, read and modify the data without remembering any memory address.
Example: age can hold 20 today and 21 next year.
🗣️ In Simple Words

Think of a variable as a labeled box. The label on the outside is the name (like age). The thing inside the box is the value (like 20). You can open the box, look at the value, or throw it away and put a new value in.

🌍 Real-Life Example

A student's age is 19 this year and will be 20 next year. Because it can change, a program should keep it in a variable named age.

A variable is a labeled storage box
A variable has a name, a value and a data type.

Every variable in C has these parts:

  • Name: the label we use in code, such as age.
  • Value: the data stored right now, such as 20.
  • Data type: the kind of data allowed, such as int for whole numbers.
⚠️ Important

The box picture is only a simple way to imagine memory. Real computer memory is a long row of tiny numbered cells, and the compiler decides where each variable lives. You do not need to know the exact layout to use variables.

Code Example
C
#include <stdio.h>

int main() {
    int age = 20;          // a box named age holding 20
    printf("%d\n", age);
    return 0;
}
Output
20
Easy Explanation
  • int age = 20; creates a box called age and puts 20 inside.
  • printf reads the box and shows the value on the screen.
🔑 Key Idea
A variable = name + value + type. The value may change. The name stays the same.
03

Variable Declaration

DECLARATION
A declaration is the statement where you tell C that a variable exists, what it is called and what type of data it will hold. When C sees a declaration it sets aside a suitable amount of memory for that variable. After this, you can use the variable's name in the rest of the function.
Example: int age;
🗣️ In Simple Words

Declaration means "buy an empty box and stick a label on it". You decide the label (age) and what the box is allowed to hold (int, whole numbers). Nothing useful is inside yet.

📦 Real-Life Example

Before a new student joins, the school prepares an empty locker and writes the student's name on it. The locker exists and has a label, but it is not filled yet. Declaration is that step.

Anatomy of a declaration
Three parts: type, name and a semicolon.
Syntax 
data_type variable_name;
Code Example
C
int age;               // whole number
float price;           // decimal number
char grade;            // single character

int a, b, c;           // several variables of the same type
Easy Explanation
  • Each line creates an empty, labeled box of a specific type.
  • You can declare several variables of the same type in one line by separating names with commas.
  • The variable must be declared before you use it.
⚠️ Important

A variable that is only declared and never given a value contains unknown leftover data (called a garbage value). Do not read it before you store something in it.

🔑 Key Idea
Declaration = type + name + ;. It creates the box. It does not fill it.
04

Variable Initialization

INITIALIZATION
Initialization means giving a variable its first value at the same moment it is declared. It combines two steps in one line: creating the box and putting a starting value inside. Initializing is a good habit because it makes sure the variable never contains random leftover data.
Example: int age = 20;
🗣️ In Simple Words

Initialization means "get the box and fill it right away". You do not leave the box empty even for a moment.

🎒 Real-Life Example

When a student joins school, the locker is prepared and a starting set of books is placed inside on day one. The locker is not left empty. That first filling is initialization.

Syntax 
data_type variable_name = value;
Code Example
C
#include <stdio.h>

int main() {
    int age = 20;
    float percentage = 82.5;
    char grade = 'A';

    printf("%d %.1f %c\n", age, percentage, grade);
    return 0;
}
Output
20 82.5 A
Easy Explanation
  • Each variable is created and filled in a single line.
  • The = here stores the starting value in the box.
Declaration → Initialization
Initialization is declaration with a starting value.
💡 Tip
Initialize variables when you declare them. It avoids garbage-value bugs.
🔑 Key Idea
Initialization = declaration + first value in one statement.
05

Assignment

ASSIGNMENT
Assignment means storing a value in a variable that already exists. It is done with the assignment operator =. C takes the value on the right side and places it into the variable on the left side, replacing whatever was stored there before.
Example: age = 21;
🗣️ In Simple Words

In C, = does not mean "is equal to" like in maths. It means "put the right-hand value into the left-hand box". Read age = 21; as "store 21 in age".

🎂 Real-Life Example

On a student's birthday, the school crosses out the old age on the record and writes the new age. The record (the box) stays the same, only the value is replaced.

Code Example
C
#include <stdio.h>

int main() {
    int age = 20;

    age = 21;

    printf("%d", age);
    return 0;
}
Output
21
Why was the old value replaced?
  • A variable box can hold only one value at a time.
  • When age = 21; runs, C puts 21 in the box. The old value 20 is overwritten and lost.
  • So when we print, only the latest value 21 is shown.
Using the old value to make a new one
C
int marks = 80;
marks = marks + 5;        // right side is calculated first: 80 + 5 = 85
printf("%d", marks);   // 85
  • C first works out the right side (80 + 5 = 85), then stores the answer in marks.
  • This is only possible because = means "store", not "equals".
🔑 Key Idea
Assignment = store the right side into the left side. It replaces the old value.
06

Declaration vs Initialization vs Assignment

These three words sound similar, so beginners often mix them up. Here they are side by side.

📦 Declaration

int age;

Creates the variable (type + name). No value is given.

🎁 Initialization

int age = 20;

Creates the variable and gives it its first value.

✏️ Assignment

age = 21;

Changes the value of a variable that already exists. No type is written.

The life of a variable: three steps
Create the box, fill it, then change what is inside.
All three in one program
C
int a;            // declaration
a = 10;             // assignment (first value given later)

int b = 20;       // initialization
b = 25;             // assignment (value replaced)
  • You can declare first and assign later, or initialize straight away. Both are valid.
  • Writing int again for the same variable would try to declare it a second time, which is an error.
🔑 Key Idea
Declare = make the box. Initialize = make it and fill it. Assign = change what is in an existing box.
07

Variables in Real Life

Let us look at how real situations turn into variables. For each one, notice why the type was chosen.

🎓 Student
C
int age = 20;
float percentage = 82.5;
char grade = 'A';
  • age is a whole number, so int.
  • percentage can have a decimal part, so float.
  • grade is a single letter, so char.
🛒 Shopping
C
float price = 499.99;
int quantity = 2;
  • A price has paise or cents, so it needs decimals: float.
  • You cannot buy 2.5 pens, so quantity is counted in whole items: int.
🌡️ Temperature
C
float temperature = 36.5;
  • Body temperature is rarely a perfect whole number, so a decimal type float fits.
🔑 Key Idea
Look at the real-world data first. Whole count → int. Measurement with decimals → float. One letter → char.
08

Variable Naming Rules

IDENTIFIER
An identifier is the name you choose for something in your program, such as a variable, a function or a constant. In C, identifiers must follow a few strict rules so the compiler can understand them. If a rule is broken, the program will not compile.
Example: age, studentAge, total_marks
🗣️ In Simple Words

An identifier is just a name you invent. C is like a strict teacher: names must follow certain rules, otherwise they are rejected.

The rules

  1. Use only letters (A–Z, a–z), digits (0–9) and the underscore _.
  2. The name cannot start with a digit. It must start with a letter or an underscore.
  3. No spaces are allowed inside a name.
  4. No special symbols such as -, @, #, $, %.
  5. You cannot use a keyword (a reserved word like int, float, return, if).
  6. C is case-sensitive: age, Age and AGE are three different names.

✅ Valid names

age
studentAge
student_age
marks1
_total

❌ Invalid names

2age
student age
student-age
int

Why are those invalid?

2age
Starts with a digitNames must begin with a letter or _
student age
Contains a spaceC reads it as two separate words
student-age
Contains a hyphenC reads - as minus: student minus age
int
It is a keywordReserved by C for its own use
Case sensitivity
C
int age = 20;
int Age = 30;      // a different variable!
printf("%d %d", age, Age);
Output
20 30
  • age and Age are two completely separate boxes.
  • This is legal, but confusing. Avoid names that differ only by capital letters.
📚 Some C keywords you cannot use as names

int float double char void const if else for while return break

🔑 Key Idea
Letters, digits, underscore. Do not start with a digit. No spaces. No keywords. Capital letters matter.
09

Good Variable Names

Following the rules makes a name legal. A good name also makes the code easy to understand. Compare these two:

😵 Unclear

int x = 20;
float y = 499.99;

What is 20? What is 499.99? You must guess.

😊 Clear

int studentAge = 20;
float productPrice = 499.99;

The names tell you what the data means. No guessing.

🏷️ Real-Life Example

Imagine a shop where every jar is labeled "A", "B", "C". You would have to open each one to learn what is inside. Labels like "Sugar" and "Salt" save time. Variable names are the labels on your jars.

Good examples

totalMarks
studentAge
productPrice
numberOfStudents

Poor examples

a
x1
temp2
⚠️ Context matters

Short names are not always wrong. In a tiny maths program, a and b for two numbers, or i for a loop counter, are perfectly normal. The problem begins when a short name hides the meaning in a bigger program.

💡 Tip: Naming styles
  • camelCase: studentAge
  • snake_case: student_age

Both are fine. Pick one style and use it everywhere in your program.

🔑 Key Idea
Code is read far more often than it is written. Choose names that explain themselves.
10

Constants

CONSTANT
A constant is a value that is meant to stay the same for the whole program. Once it is set, it should not be changed. We use constants for fixed facts, so that nobody changes them by mistake and so the number has a meaningful name instead of appearing as a mysterious value in many places.
Example: π (3.14159), 7 days in a week, a fixed tax rate.
🗣️ In Simple Words

A constant is a locked box. You put a value in once, and then the lock is closed. C will refuse to let you change it later.

📅 Real-Life Example

A week always has 7 days. This will not change while your calendar program runs, so DAYS_IN_WEEK is a perfect constant. Likewise π is always about 3.14159.

Syntax 
const data_type NAME = value;
Code Example
C
#include <stdio.h>

int main() {
    const float PI = 3.14159;
    printf("PI = %.5f\n", PI);
    return 0;
}
Output
PI = 3.14159
Breaking down a constant
The value must be given right where the constant is declared.
  • const: the keyword that makes the variable read-only.
  • data type: the kind of value, such as float.
  • constant name: by convention written in CAPITAL LETTERS, like PI or MAX_MARKS.
  • value: must be given immediately, because you cannot assign it later.
🔑 Key Idea
A constant is a named value that is set once and never changed. In C we write const before the type.
11

Variable vs Constant

🔁 Variable

int age = 20;
age = 21;       // allowed

The value can change when needed.

🔒 Constant

const int DAYS_IN_WEEK = 7;

The value is fixed. C will not allow you to change it.

Variable vs Constant
Variables change. Constants stay fixed.
What happens if you try to change a constant?
C
const int DAYS_IN_WEEK = 7;
DAYS_IN_WEEK = 8;      // not allowed
Compiler error
Error
error: assignment of read-only variable 'DAYS_IN_WEEK'
  • The word const told the compiler that this box is read-only.
  • When your code tries to put a new value in, the compiler stops and reports an error. The exact wording differs between compilers, but the program will not build.
  • This protects your program from accidental changes.
🔑 Key Idea
Use a variable when the value may change. Use a constant when it must stay the same.
12

#define Constants

There is a second way to create a constant in C. It uses a preprocessor directive called #define.

#define
#define gives a name to a fixed value. Before your program is compiled, a helper step called the preprocessor goes through the code and replaces every use of that name with the value. So #define works like an automatic find-and-replace, not like a real variable stored in memory.
Example: #define PI 3.14159
🗣️ In Simple Words

#define is a nickname. You tell C: "wherever I write PI, treat it as 3.14159."

📇 Real-Life Example

On your phone you save a contact named "Home" instead of typing the full number every time. "Home" is a nickname that gets replaced by the real number when you call.

Code Example
C
#include <stdio.h>
#define PI 3.14159

int main() {
    printf("%.5f\n", PI);
    return 0;
}
Output
3.14159
  • Notice: no data type, no = sign and no semicolon at the end.
  • It is usually written near the top of the file, below #include.

const vs #define

🔒 const

const float PI = 3.14159;
  • Has a data type
  • Is a real variable that is read-only
  • Ends with a semicolon

📇 #define

#define PI 3.14159
  • Has no data type
  • Is a text replacement done before compiling
  • Has no = and no semicolon
⚠️ Common Mistake

Do not write #define PI 3.14159; with a semicolon. The semicolon becomes part of the replacement text and can cause strange errors wherever PI is used.

ℹ️ Remember

These are two different mechanisms. We will not go deeper into the preprocessor here. For now, prefer const when you want a typed, read-only value, and know that you will often see #define in real C code.

What is a Data Type?

DATA TYPE
A data type tells C what kind of value a variable is expected to store, such as a whole number, a decimal number or a single character. Based on the type, C decides how much memory to reserve and how to understand the bits stored there. It also decides which operations make sense for that data.
Examples: int, float, double, char
🗣️ In Simple Words

A data type is the "kind of thing" a box is meant for. A whole-number box is built for whole numbers. A character box is built for one letter.

🧳 Real-Life Example

Different containers are designed for different things. A water bottle stores liquid, while a pencil box stores stationery. You would not pour water into a pencil box. In the same way, a data type tells C what kind of data a variable is meant to hold.

Why does C need data types?

  • Memory: a single letter needs less space than a large decimal number. C reserves the right amount.
  • Meaning: the same bits can mean a number or a letter. The type tells C which one to use.
  • Safety: the compiler can warn you when you use data in the wrong way.
Code Example
C
int   studentCount = 60;     // whole number
float height = 5.8;          // decimal number
char  section = 'B';        // one character
  • The type comes first, before the variable name, so C knows what the box is for.
🔑 Key Idea
The data type decides what kind of data a variable holds and how much memory it needs. C is a typed language, so every variable must have a type.

15

int

int
int is the data type for whole numbers: numbers with no decimal point. It can hold positive numbers, negative numbers and zero. It is the most commonly used type in C, because many things in programs are counted in whole units.
Examples: 20, 60, 0, -15
🗣️ In Simple Words

If you can count it on your fingers, use int. No fractions, no decimal point.

🧮 Real-Life Examples
  • Age: 20
  • Number of students in a class: 60
  • Number of products in a cart: 3
  • Count of items: 12
Code Example
C
#include <stdio.h>

int main() {
    int age = 20;
    int students = 60;
    int marks = 85;

    printf("%d %d %d\n", age, students, marks);
    return 0;
}
Output
20 60 85
Easy Explanation
  • All three values are whole numbers, so int is the right choice.
  • %d in printf prints an int.
⚠️ Important

An int has a limited range. A very large number may not fit. For now, remember that int is for ordinary whole numbers like ages, counts and marks.

🔑 Key Idea
int = whole numbers, positive or negative, without decimals.
16

float

float
float is the data type for numbers with a decimal point. These are called floating-point numbers because the decimal point can "float" to different positions. Use it when the value is not always a whole number, such as a measurement, a price or a percentage.
Examples: 36.5, 82.5, 499.99, 5.8
🗣️ In Simple Words

If the value can be in between two whole numbers, like 36.5 between 36 and 37, use float.

📏 Real-Life Examples
  • Temperature: 36.5
  • Percentage: 82.5
  • Product price: 499.99
  • Height: 5.8 feet
Code Example
C
#include <stdio.h>

int main() {
    float temperature = 36.5;
    printf("%.1f\n", temperature);
    return 0;
}
Output
36.5
Easy Explanation
  • 36.5 has a decimal part, so it cannot be stored as an int.
  • %.1f prints a float with one digit after the decimal point. Plain %f would print 36.500000.
ℹ️ Why decimals need special types

Computers store whole numbers and decimal numbers in different ways. A decimal type can hold fractional values, but it stores them only to a limited number of digits, so very long decimals may be slightly rounded.

🔑 Key Idea
float = decimal numbers with a moderate amount of precision.
17

double

double
double is also used for decimal numbers, just like float, but it can store them with more precision. "Precision" means how many digits of the number are kept accurately. It also uses more memory than float.
Example: 3.14159265359
🗣️ In Simple Words

double is a bigger, more careful version of float. It remembers more decimal digits correctly.

🔬 Real-Life Example

A kitchen scale showing 250.5 grams is fine with a normal measure. A science lab weighing a chemical needs a scale that shows many more decimal places. float is the kitchen scale. double is the lab scale.

Code Example
C
#include <stdio.h>

int main() {
    double pi = 3.14159265359;
    printf("%.11lf\n", pi);
    return 0;
}
Output
3.14159265359
Easy Explanation
  • We ask printf for 11 digits after the decimal point.
  • A double keeps all of them correctly. A float would start to show small errors after about 6 or 7 digits.
💡 Tip
When you are unsure and the number has decimals, double is a safe choice for accuracy. Use float when you are fine with fewer digits or want to save memory.
🔑 Key Idea
double = decimal numbers with more precision than float.
18

char

char
char is the data type for a single character: one letter, one digit symbol or one special symbol. A character value is written inside single quotes. Internally, C stores each character as a small number code, but you do not need to worry about that yet.
Examples: 'A', 'z', '7', '#'
🗣️ In Simple Words

char holds exactly one character. Not a word, not a sentence. Just one symbol.

🏅 Real-Life Example

A student's grade is a single letter: A, B or C. Marks sheets, seat rows ('A', 'B') and menu choices ('Y' for yes, 'N' for no) are also single characters.

Code Example
C
#include <stdio.h>

int main() {
    char grade = 'A';
    printf("%c\n", grade);
    return 0;
}
Output
A

'A' vs "A": a very important difference

✅ 'A' (single quotes)

A character constant. One character. This is what a char variable stores.

⚠️ "A" (double quotes)

A string literal. It is text, even when it holds only one letter. It is stored differently, with a hidden end marker, and it cannot be stored directly in a char.

C
char grade = 'A';     // correct
char grade = "A";     // wrong: double quotes make a string
ℹ️ Strings come later

To store a whole word like "Riya", C uses a group of characters (a character array). That is a later topic. For now, one char = one character.

🔑 Key Idea
char = one character in single quotes. Double quotes mean a string, not a char.
19

void

void
void means "no value" or "no type". You cannot create a normal variable of type void, because a box with no type cannot hold anything. Its most common use at this stage is with functions: a function declared with void as its return type does its job but does not send any value back.
Example: void display(void)
🗣️ In Simple Words

void says "nothing here". A void function just does something (like printing) and gives back nothing.

🔔 Real-Life Example

Pressing a doorbell makes a sound, but it does not hand you any object back. It performs an action and returns nothing. A void function works like that doorbell.

Code Example
C
#include <stdio.h>

void display(void) {
    printf("Hello\n");
}

int main() {
    display();
    return 0;
}
Output
Hello
Easy Explanation
  • void display(void): the first void means "returns nothing". The void in brackets means "takes no inputs".
  • Writing void display() also works in many programs, but putting void in the brackets is the clearer, safer habit.
  • Functions are covered fully in a later topic. This is just a first look.
🔑 Key Idea
void = no value. Used for functions that return nothing. You cannot store data in a plain void variable.

Size of Data Types: sizeof

sizeof
sizeof is an operator that tells you how many bytes of memory a data type or a variable uses. A byte is a small unit of computer memory. Different types need different amounts of memory, and sizeof lets you check the exact amount on your own computer.
Example: sizeof(int)
🗣️ In Simple Words

sizeof asks: "How big is this box?" The answer is given in bytes.

🧳 Real-Life Example

A small pouch holds a coin and a big suitcase holds clothes. sizeof tells you whether you are holding the pouch or the suitcase.

Code Example
C
#include <stdio.h>

int main() {
    printf("char   : %zu\n",  sizeof(char));
    printf("int    : %zu\n",  sizeof(int));
    printf("float  : %zu\n",  sizeof(float));
    printf("double : %zu\n",  sizeof(double));
    return 0;
}
Typical output on many modern computers
char   : 1
int    : 4
float  : 4
double : 8
Easy Explanation
  • sizeof gives the size in bytes.
  • %zu is the format specifier used to print a sizeof result.
  • You can also use it on a variable: sizeof(age) gives the size of age's type.
⚠️ Important: sizes are not the same everywhere

The values 4 and 8 above are typical examples, not universal rules. The size of int, float and double can depend on the compiler and the computer (the platform). The one exception: sizeof(char) is always 1 by definition. If you need to know the size on your system, run sizeof yourself.

🔑 Key Idea
sizeof shows how many bytes a type or variable uses. Do not assume the numbers are the same on every system.
23

Format Specifiers: Basic Introduction

FORMAT SPECIFIER
A format specifier is a short code that starts with % and tells printf what type of value to print in that spot. When printf runs, it replaces each specifier with the matching variable's value. Using the wrong specifier can print wrong or strange output.
Example: %d for an int
🗣️ In Simple Words

A format specifier is a blank space in a sentence with a note saying what kind of word goes there: "My age is ___ (number)". %d is that note for a whole number.

%d
intprintf("%d", age);
%f
floatprintf("%f", price);
%lf
doubleprintf("%lf", pi);
%c
charprintf("%c", grade);
Code Example
C
#include <stdio.h>

int main() {
    int age = 20;
    float price = 99.5;
    double pi = 3.14159265359;
    char grade = 'A';

    printf("Age   : %d\n", age);
    printf("Price : %f\n", price);
    printf("Pi    : %lf\n", pi);
    printf("Grade : %c\n", grade);
    return 0;
}
Output
Age   : 20
Price : 99.500000
Pi    : 3.141593
Grade : A
Easy Explanation
  • %f and %lf print six digits after the decimal point by default, so 99.5 appears as 99.500000.
  • To control the digits, write a number: %.1f prints one decimal place, %.2f prints two.
  • In printf, %f also works for a double. When we later read a double with scanf, %lf is required.
⚠️ Common Mistake

Using a specifier that does not match the type, like printf("%d", 3.5);, gives wrong output. Always match: int → %d, float → %f, char → %c.

Basic Type Conversion

TYPE CONVERSION
Type conversion means changing a value from one data type to another. Sometimes C does it automatically when you mix types, and sometimes you ask for it yourself. Conversion can be harmless, or it can lose information, so it is important to know what is happening.
Examples: int → float, float → int
🗣️ In Simple Words

Pouring water from a big jug into a small glass may spill. Moving a value from a "bigger" type into a "smaller" one can also lose some of it.

1. int → float (safe)

C
int count = 5;
float f = count;
printf("%.1f", f);     // 5.0

The whole number 5 becomes 5.0. Nothing is lost.

2. float → int (the decimal part is cut off)

C
int x = 9.8;
printf("%d", x);       // 9

C truncates the value: it throws away the .8. It does not round to 10.

3. Integer division surprise

Code Example
C
#include <stdio.h>

int main() {
    int a = 7, b = 2;

    printf("%d\n", a / b);            // both int
    printf("%.1f\n", (float)a / b);   // type cast
    return 0;
}
Output
3
3.5
Easy Explanation
  • When both sides are int, C gives an int answer. 7 / 2 becomes 3, and the .5 is dropped.
  • (float)a is a type cast: you tell C to treat a as a float for this calculation. Now the division is done with decimals, so you get 3.5.
⚠️ Important

Putting a decimal value into an int variable silently drops the decimal part. Choose float or double if you need to keep it.

🔑 Key Idea
Small to big types is safe. Big to small can lose data. To get decimals from dividing two ints, cast one of them to float.

Common Mistakes

❌ Wrong: Wrong data type
int price = 99.99;
printf("%d", price);
⚠️ Problem
Output (data is lost)
99
✅ Correct
float price = 99.99;
printf("%.2f", price);
Why: An int cannot hold decimals, so C throws away .99 and keeps only 99. Money should use a decimal type.
❌ Wrong: Wrong quotes for a character
char grade = "A";
⚠️ Problem
Compiler warning or error (depends on compiler)
warning: initialization of 'char' from 'char *' makes integer from pointer without a cast
✅ Correct
char grade = 'A';
Why: Double quotes create a string, not a single character. A char needs single quotes.
❌ Wrong: Trying to modify a constant
const int DAYS = 7;
DAYS = 8;
⚠️ Problem
Error
error: assignment of read-only variable 'DAYS'
✅ Correct: remove the second line. If the value really must change, do not make it const
Why: const locks the value. Changing it defeats the purpose of a constant.
❌ Wrong: Invalid variable name
int 2age = 20;
⚠️ Problem
Error
error: invalid suffix "age" on integer constant
✅ Correct
int age2 = 20;      // or: int studentAge = 20;
Why: A name cannot start with a digit. C thinks 2age is a badly written number.
❌ Wrong: Ignoring case sensitivity
int age = 20;
printf("%d", Age);
⚠️ Problem
Error
error: 'Age' undeclared (first use in this function)
✅ Correct
printf("%d", age);
Why: C is case-sensitive. Age and age are different names, and Age was never declared.
❌ Wrong: Using a variable before giving it a value
int marks;
printf("%d", marks);
⚠️ Problem
Unpredictable output
some random garbage value (not a reliable result)
✅ Correct
int marks = 0;
printf("%d", marks);
Why: A local variable that is only declared contains leftover data. Always initialize before reading.
❌ Wrong: Mismatched format specifier
float price = 99.5;
printf("%d", price);
⚠️ Problem
Wrong output
a meaningless number, not 99.5
✅ Correct
printf("%.1f", price);
Why: %d expects an int. A float needs %f.

Think Before You Code

🧠 Think Before You Code

Every time you create a variable, ask yourself these six questions:

  1. What information am I storing?
  2. Can the value change while the program runs?
  3. What type of data is it: whole number, decimal, character?
  4. What is a meaningful name for it?
  5. Do I need a variable or a constant?
  6. How will I display or use the value?
Worked example: number of seats in a bus
  1. Information: total seats in a bus.
  2. Can it change? Not during the program. For one bus it is fixed.
  3. Type: you cannot have half a seat, so a whole number: int.
  4. Name: totalSeats or TOTAL_SEATS.
  5. Variable or constant? Constant.
  6. Display: with %d.
C
const int TOTAL_SEATS = 40;
printf("Seats: %d", TOTAL_SEATS);

Quick Revision

Key Definitions

Variable→A named memory location that stores a value which can change
Constant→A named value that is set once and should not change
Data type→The kind of value a variable can store
Declaration→Creating a variable: int age;
Initialization→Declaring and giving the first value: int age = 20;
Assignment→Storing a new value in an existing variable: age = 21;
Identifier→The name you give to a variable, constant or function

Important Types

int      whole numbers
float    decimal numbers
double   decimal numbers, more precision
char     one character
void     no value

Important Syntax

C
int age = 20;
float price = 99.5;
char grade = 'A';
const int DAYS = 7;
#define PI 3.14159

Key Points to Remember

  • A variable has a name, a value and a type.
  • = in C means assign, not "equals".
  • Initialize variables to avoid garbage values.
  • Names: letters, digits, underscore; no leading digit, no spaces, no keywords.
  • C is case-sensitive.
  • const makes a value read-only. #define is a separate text-replacement mechanism.
  • 'A' is a char. "A" is a string.
  • Match format specifiers to types: %d %f %lf %c.
  • Type sizes can differ between systems. Use sizeof to check.
  • Putting a decimal into an int drops the decimal part.
