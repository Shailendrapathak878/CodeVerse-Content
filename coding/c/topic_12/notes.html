📌 Section 01

Introduction: What Is a String in C?

In everyday life, we read and write words, sentences, and paragraphs: names, passwords, email addresses, and messages. But how does a computer programming language like C represent human text?

Unlike newer languages such as Python or Java, C does not have a built-in primitive "string" data type. There is no keyword called string in standard C.

📚 Formal Definition of a C String In C, a string is a sequence of characters stored in a one-dimensional character array, terminated by a special invisible marker called the null character ('\0').

Deconstructing the 5 Pillars of a C String

  1. A Character: The smallest unit of text in C (type char), typically occupying 1 byte of memory and storing an ASCII numeric code (such as 'A' = 65).
  2. A Character Array: A continuous row of char boxes placed side-by-side in computer memory.
  3. A Sequence of Characters: Letters and symbols placed in order to spell out human words (e.g., 'C', 'o', 'd', 'e').
  4. The Null Terminator ('\0'): A special byte with an exact value of 0 placed immediately after the last visible letter to mark the boundary where the string ends.
  5. Character vs String: A character is a single isolated letter enclosed in single quotes ('A'), whereas a string is an array of characters enclosed in double quotes ("A").

The Classic Student Name Example: "Aman"

Suppose you declare a string to hold a student's name:

string_declaration.c
char name[] = "Aman";

Count the letters in the word "Aman": there are 4 letters. However, the C compiler allocates 5 character positions in memory!

📌 Section 02

Character vs String: The Fundamental Difference

Beginners often confuse a single character with a one-letter string. In C, these two concepts are completely different in syntax, memory footprint, and behavior:

📝 Single Character: 'A'
char grade = 'A';
  • Enclosed in single quotes (' ').
  • Occupies exactly 1 byte of memory.
  • Stores the single integer ASCII value 65.
  • Contains no null terminator.
  • Printed with the %c format specifier.
📖 String Literal: "A"
char gradeText[] = "A";
  • Enclosed in double quotes (" ").
  • Occupies 2 bytes of memory: 'A' and '\0'.
  • Stores an array of characters ending with zero.
  • Must be terminated by '\0'.
  • Printed with the %s format specifier.

Common Beginner Pitfalls: Quotes and Assignments

❌ Pitfall A: Assigning a String Literal to a char Variable 
char ch = "A";  /* COMPILE WARNING / ERROR! */
Why it fails: "A" is a string literal (an array address in memory), not a single character. A char variable can only store a single byte, not a memory address! The correct syntax is: 
char ch = 'A';  /* Correct */
❌ Pitfall B: Trying to Reassign an Array Name Directly 
char name[10];
name = "Rahul";  /* COMPILE ERROR: Array type is not assignable */
Why it fails: In C, an array name is a constant pointer to the allocated memory buffer. You cannot reassign an array with = after declaration! You must copy text using strcpy(name, "Rahul"); or initialize it at declaration time.
📌 Section 03

Declaring and Initializing Strings

In C, there are four standard ways to declare and initialize character arrays. Understanding how memory is sized for each form is critical:

1. The 4 Declaration Forms

Style A: String Literal with Automatic Sizing

style_a.c
char city[] = "Lucknow";

"Lucknow" has 7 characters. The compiler automatically adds '\0' at the end and allocates an array of size 8 bytes.

Style B: Explicit Fixed Buffer Size

style_b.c
char name[20] = "Aman";

Allocates 20 bytes on the stack. The first 4 bytes store 'A', 'm', 'a', 'n', the 5th byte stores '\0', and the remaining 15 bytes are automatically zeroed.

Style C: Single Character Literal in Sized Array

style_c.c
char language[4] = "C";

Allocates 4 bytes. Index 0 holds 'C', index 1 holds '\0', and indices 2 and 3 are zero-filled.

Style D: Explicit Character-by-Character Initializer List

style_d.c
char word[] = {'C', 'o', 'd', 'e', '\0'};

When initializing with curly braces, you must explicitly write '\0'! If you omit '\0', the compiler creates an ordinary 4-element char array that is not a valid C string.

The Deadly Missing Terminator Trap

☠ Fatal Bug: char word[4] = "Code"; What happens if you write: 
char word[4] = "Code";  /* LACKS ROOM FOR '\0'! */
The string literal "Code" contains 4 letters plus '\0' (5 bytes total). Because you restricted the array size to 4, C squeezes in 'C', 'o', 'd', 'e' and drops the null terminator!

word is now a raw character array with no ending marker. If you pass word to printf("%s", word) or strlen(word), the function will continue reading past the 4th byte into adjacent RAM until it accidentally stumbles upon a random 0 byte. This causes buffer overread and undefined behavior!

📌 Section 04

The Null Character '\0': The Essential Concept

The null character '\0' is the single most important concept in C string manipulation. Without it, string processing in C cannot function.

5 Vital Truths About '\0'

  • Exact Value Zero: In computer memory, '\0' is represented by an 8-bit byte with all bits cleared: 00000000. Its numerical integer value is exactly 0.
  • It Differs from the Character '0': The character '0' (the numeral zero) has an ASCII value of 48 (00110000). '\0' is ASCII 0. They are completely different!
  • It Differs from the NULL Pointer: '\0' is a 1-byte character constant with value 0. NULL is an address pointer constant representing a null memory reference (typically ((void *)0)).
  • The Universal Sentinel: Because C arrays do not record their own length, every standard string function (strlen, strcpy, printf, strcmp) scans character-by-character until it hits '\0' to know when to stop.

Comparison Table: Three Similar Looking Declarations

Declaration Bytes Allocated Characters Stored in Memory String Length (strlen)
char a[] = "0"; 2 bytes '0' (ASCII 48), '\0' (ASCII 0) 1
char b[] = "A"; 2 bytes 'A' (ASCII 65), '\0' (ASCII 0) 1
char c[] = {'A', 'B', '\0'}; 3 bytes 'A' (ASCII 65), 'B' (ASCII 66), '\0' (ASCII 0) 2
💡 Why Not Store an Array Length Counter? When C was created at Bell Labs in the 1970s, computer memory was tiny (measured in kilobytes). Dennis Ritchie chose the null-terminator convention because it eliminated the need for extra integer header bytes storing string lengths. A single byte with value 0 serves as a lightweight, zero-overhead end-of-string sentinel!
📌 Section 05

Printing Strings in C

In C, strings are printed to the console using the standard library function printf() with the %s format specifier.

print_string.c 
#include <stdio.h>

int main(void)
{
    char name[] = "Aman";

    /* Print entire string */
    printf("Full string: %s\n", name);

    /* Print individual characters at specific indices */
    printf("First letter (index 0): %c\n", name[0]);
    printf("Third letter (index 2): %c\n", name[2]);

    return 0;
}
Terminal Output
Full string: Aman First letter (index 0): A Third letter (index 2): a

How Does printf("%s", name) Work Internally?

When you pass name to printf("%s", name):

  1. C passes the memory address of index 0 (the base address of the array).
  2. printf reads the byte at index 0 and sends it to your screen.
  3. It increments its internal memory pointer to index 1, index 2, and so on.
  4. The moment it encounters '\0', it immediately stops reading and returns.
👁 %s vs %c Specifiers
  • %s: Expects the base address of a null-terminated string. Prints all characters until '\0'.
  • %c: Expects a single char value (e.g., name[0]). Prints exactly one character.
📌 Section 06

Taking String Input Safely: scanf vs fgets

Reading text input from users is one of the most common sources of security vulnerabilities (buffer overflows) in C programs. Let's compare the methods:

Method 1: Using scanf("%s", ...)

You can read a single word using scanf:

scanf_single_word.c
char username[20];
printf("Enter your username: ");
if (scanf("%19s", username) == 1) {
    printf("Hello, %s!\n", username);
}

Crucial Rules for scanf("%s"):

  • No & Operator Needed: Because an array name in C naturally evaluates to the address of its first element, you pass username, NOT &username.
  • Stops at Whitespace: scanf("%s") reads characters until it hits a space, tab, or newline. If a user enters "Aman Sharma", only "Aman" is read!
  • Always Use Width Limit: Writing plain scanf("%s", username) on a 20-byte array allows a malicious user to type 100 characters, smashing your program's call stack! Writing %19s guarantees that at most 19 characters are stored, leaving slot 20 safely for '\0'.

Method 2: Using fgets() for Full Lines with Spaces (Recommended)

When you need to read a full name, address, or complete sentence that may contain spaces, fgets() is the gold standard in modern C.

safe_fgets_input.c 
#include <stdio.h>
#include <string.h>

#define MAX_LEN 50

int main(void)
{
    char fullName[MAX_LEN];

    printf("Enter your full name: ");

    /* fgets(buffer, buffer_size, input_stream) */
    if (fgets(fullName, sizeof(fullName), stdin) != NULL)
    {
        /* Remove trailing newline character if captured by fgets */
        size_t len = strlen(fullName);
        if (len > 0 && fullName[len - 1] == '\n')
        {
            fullName[len - 1] = '\0';
        }

        printf("Welcome to CodeVerse, %s!\n", fullName);
    }
    else
    {
        printf("Error reading input.\n");
    }

    return 0;
}
Sample Terminal Session
Enter your full name: Aman Kumar Sharma Welcome to CodeVerse, Aman Kumar Sharma!

Why fgets() is Secure and Reliable

  • Guaranteed Buffer Boundary: sizeof(fullName) ensures fgets never reads more bytes than your array can hold.
  • Guaranteed Null-Termination: When input is successfully read, fgets always appends '\0' at the end.
  • Trailing Newline Handling: If there is room in the buffer, fgets preserves the user's Enter key (' '). The two lines of code above strip it safely by replacing ' ' with '\0'.
☠ Strictly Banned Function: NEVER USE gets()! Older textbooks frequently teach the function gets(str).

DO NOT USE gets()! gets() does not know the size of the destination array and continues writing until the user presses Enter. It is responsible for some of the most famous security hacks in computing history. It was officially removed from the C Standard in C11 and modern compilers will refuse to compile it or issue severe security warnings.

Traversing a String with a Loop

In Data Structures & Algorithms, strings are processed character-by-character. Because strings are arrays, we can iterate through them using a loop.

However, notice a fundamental difference from numerical arrays: you do not need to know the size of the array ahead of time! You simply stop when you encounter '\0'.

Complete C Program: Character Traversal

traverse_string.c 
#include <stdio.h>

int main(void)
{
    char text[] = "CODE";

    printf("Traversing string character by character:\n");

    for (int i = 0; text[i] != '\0'; i++)
    {
        printf("Index [%d] = '%c' (ASCII %d)\n", i, text[i], text[i]);
    }

    return 0;
}
Terminal Output

Finding String Length: strlen() vs Capacity

The standard library header <string.h> provides strlen() to determine how many visible characters a string contains.

string_length.c 
#include <stdio.h>
#include <string.h>

int main(void)

📌 Section 09

Standard String Functions: <string.h>

The C Standard Library provides a rich set of string manipulation functions declared in the <string.h> header file. Every function assumes strings are properly null-terminated.

1. strcpy(dest, src): String Copy

Copies the source string (including its terminating '\0') into the destination character array:

strcpy_example.c
char source[] = "Hello";
char destination[20];
strcpy(destination, source);
/* destination now holds: "Hello" with '\0' at index 5 */
⚠ Capacity Rule for strcpy(): The destination array must be large enough to store all characters of the source string plus the terminating '\0'. If destination is too small, strcpy overflows the buffer, causing Undefined Behavior!

2. strncpy(dest, src, n): Bounded Copy

Copies at most n characters from src to dest:

strncpy_safe.c
char src[] = "Programming";
char dest[10];

strncpy(dest, src, sizeof(dest) - 1);
dest[sizeof(dest) - 1] = '\0';  /* CRUCIAL: Manually guarantee null termination! */
👁 Important Warning on strncpy(): strncpy() does NOT always append a null terminator! If strlen(src) >= n, strncpy fills all n slots with characters and leaves the destination unterminated. Always set dest[n - 1] = '\0' explicitly!

3. strcat(dest, src): String Concatenation

Appends a copy of the source string to the end of the destination string. It overwrites the original '\0' of dest and adds a new '\0' at the very end.

strcat_example.c
char greeting[30] = "Hello, ";
char name[] = "Aman!";
strcat(greeting, name);
/* greeting is now: "Hello, Aman!" */

4. strcmp(s1, s2): Lexicographical Comparison

Compares two strings character-by-character according to their ASCII numerical values:

Return Value Mathematical Meaning ASCII Explanation
0 s1 == s2 Both strings have identical characters in identical order.
< 0 (Negative) s1 < s2 At the first differing character, s1 has a smaller ASCII value.
> 0 (Positive) s1 > s2 At the first differing character, s1 has a larger ASCII value.
⚠ Do NOT Use "==" to Compare String Contents! Writing if (str1 == str2) in C compares the memory addresses of the two arrays, NOT their text contents! Always use if (strcmp(str1, str2) == 0).

5. strchr(str, ch) & strstr(str, sub): Searching

  • strchr(str, 'a'): Locates the first occurrence of character 'a' in str. Returns a pointer to the character, or NULL if not found.
  • strstr(text, "code"): Locates the first occurrence of the substring "code" within text. Returns a pointer to the match, or NULL.

Master Program: Demonstrating string.h Functions

demo_string_h.c 
#include <stdio.h>
#include <string.h>

int main(void)
{
    char str1[50] = "Code";
    char str2[] = "Verse";
    char copy[50];

    /* 1. strcpy */
    strcpy(copy, str1);
    printf("Copied string: %s\n", copy);

    /* 2. strcat */
    strcat(str1, str2);
    printf("Concatenated: %s (Length: %zu)\n", str1, strlen(str1));

    /* 3. strcmp */
    int cmp = strcmp("Apple", "Banana");
    if (cmp < 0)
    {
        printf(""Apple" comes before "Banana" alphabetically (cmp = %d)\n", cmp);
    }

    /* 4. strchr */
    if (strchr(str1, 'V') != NULL)
    {
        printf("Character 'V' found in %s!\n", str1);
    }

    /* 5. strstr */
    if (strstr(str1, "Verse") != NULL)
    {
        printf("Substring "Verse" found inside %s!\n", str1);
    }

    return 0;
}

Common String Functions vs Manual Implementation

In Data Structures & Algorithms (DSA) interviews, examiners will frequently say: "Calculate string length or copy a string without using <string.h>."

Understanding how library functions work internally builds algorithmic intuition and mastery over pointers and loops:

Library Function Manual Algorithmic Logic Stopping Condition
strlen(s) Count characters one-by-one with a counter variable s[i] == '\0'
strcpy(dest, src) Copy dest[i] = src[i] sequentially Copy until src[i] == '\0', then copy '\0'
strcmp(s1, s2) Compare s1[i] == s2[i] at each offset Until mismatch or either hits '\0'
strcat(dest, src) Find end of dest, then append src Until src[j] == '\0', then append '\0'

Complete C Program: Manual Implementations

manual_string_ops.c 
#include <stdio.h>

/* 1. Manual String Length */
size_t my_strlen(const char str[])
{
    size_t length = 0;
    while (str[length] != '\0')
    {
        length++;
    }
    return length;
}

/* 2. Manual String Copy */
void my_strcpy(char dest[], const char src[])
{
    int i = 0;
    while (src[i] != '\0')
    {
        dest[i] = src[i];
        i++;
    }
    dest[i] = '\0';  /* Manually seal with null terminator */
}

/* 3. Manual String Compare */
int my_strcmp(const char s1[], const char s2[])
{
    int i = 0;
    while (s1[i] != '\0' && s1[i] == s2[i])
    {
        i++;
    }
    return (unsigned char)s1[i] - (unsigned char)s2[i];
}

/* 4. Manual String Concatenate */
void my_strcat(char dest[], const char src[])
{
    int i = 0;
    /* Step 1: Find end of destination string */
    while (dest[i] != '\0')
    {
        i++;
    }

    /* Step 2: Append source characters */
    int j = 0;
    while (src[j] != '\0')
    {
        dest[i] = src[j];
        i++;
        j++;
    }
    dest[i] = '\0';  /* Seal result with null terminator */
}

int main(void)
{
    char text[] = "CodeVerse";
    char copy[30];
    char combo[40] = "Super ";

    printf("my_strlen("%s") = %zu\n", text, my_strlen(text));

    my_strcpy(copy, text);
    printf("my_strcpy result     = %s\n", copy);

    my_strcat(combo, "Coding");
    printf("my_strcat result     = %s\n", combo);

    int cmpResult = my_strcmp("cat", "car");
    printf("my_strcmp("cat", "car") = %d ('t' > 'r')\n", cmpResult);

    return 0;
}

Reversing a String: Two Approaches

String reversal is a classic interview question. It can be performed in two distinct ways:

Approach 1: Displaying in Reverse (Non-Destructive)

If you only need to print the string backward without modifying memory, calculate len = strlen(str) and iterate backward from len - 1 down to 0:

print_reverse_snippet.c
char word[] = "HELLO";
int len = strlen(word);
for (int i = len - 1; i >= 0; i--) {
    printf("%c", word[i]);
}
/* Prints: OLLEH (word in memory remains "HELLO") */

Approach 2: In-Place Reversal (Two-Pointer Technique)

In DSA, we frequently need to permanently mutate the array in-place using $O(1)$ auxiliary memory:

  1. Initialize left = 0 and right = length - 1.
  2. Swap the characters at str[left] and str[right] using a temporary char temp.
  3. Move left++ forward and right-- backward.
  4. Repeat until left >= right.

Complete C Program: In-Place String Reversal

reverse_string_inplace.c 
#include <stdio.h>
#include <string.h>

void reverseString(char str[])
{
    int left = 0;
    int right = strlen(str) - 1;

    while (left < right)
    {
        /* Swap characters */
        char temp = str[left];
        str[left] = str[right];
        str[right] = temp;

        /* Move pointers inward */
        left++;
        right--;
    }
}

int main(void)
{
    char message[] = "CodeVerse";

    printf("Original string: %s\n", message);
    reverseString(message);
    printf("Reversed string: %s\n", message);

    return 0;
}
Terminal Output
Original string: CodeVerse Reversed string: esreVedoC

Dry-Run Table: In-Place Reversal of "HELLO"

Step Pointers Characters Swapped Array State Next Pointer Values
Init left = 0, right = 4 - H E L L O left < right (True)
1 left = 0, right = 4 Swap 'H' ↔ 'O' O E L L H left = 1, right = 3
2 left = 1, right = 3 Swap 'E' ↔ 'L' O L L E H left = 2, right = 2
End left = 2, right = 2 - O L L E H left < right (False) → Exit!
📌 Section 12

String Palindrome: Important DSA Problem

A palindrome is a word or phrase that reads the exact same forward and backward. Famous examples include "radar", "level", "madam", and "racecar".

The Two-Pointer Palindrome Algorithm

  1. Set left = 0 and right = strlen(str) - 1.
  2. Compare str[left] with str[right].
  3. If they do not match, return 0 (Not a palindrome).
  4. If they match, increment left++ and decrement right--.
  5. If left >= right, every symmetric pair matched! Return 1 (Is a palindrome).

Complete C Program: Palindrome Checker

palindrome_checker.c 
#include <stdio.h>
#include <string.h>

int isPalindrome(const char str[])
{
    int left = 0;
    int right = strlen(str) - 1;

    while (left < right)
    {
        if (str[left] != str[right])
        {
            return 0;  /* Mismatch: Not a palindrome */
        }
        left++;
        right--;
    }

    return 1;  /* All symmetric pairs matched */
}

int main(void)
{
    char word1[] = "level";
    char word2[] = "hello";

    printf(""%s" is %s\n", word1, isPalindrome(word1) ? "a PALINDROME" : "NOT a palindrome");
    printf(""%s" is %s\n", word2, isPalindrome(word2) ? "a PALINDROME" : "NOT a palindrome");

    return 0;
}
Terminal Output
"level" is a PALINDROME "hello" is NOT a palindrome

Dry-Run Comparison: "level" vs "hello"

Target String Pointers Characters Compared Match? Outcome
"level" left=0, right=4 str[0] = 'l', str[4] = 'l' Yes Move inward
left=1, right=3 str[1] = 'e', str[3] = 'e' Yes left >= right → Palindrome!
"hello" left=0, right=4 str[0] = 'h', str[4] = 'o' NO Immediate mismatch → Not Palindrome
👁 Case Sensitivity Note This standard implementation is case-sensitive: "Madam" would fail because 'M' (ASCII 77) != 'm' (ASCII 109). For case-insensitive checking, use tolower((unsigned char)str[left]) from <ctype.h> before comparing.

Anagram Checking: Essential DSA Problem

Two words are anagrams of each other if they contain the exact same characters with the exact same frequencies, rearranged in a different order.

🧩 Classic Anagram Pairs
  • "listen" and "silent"
  • "triangle" and "integral"
  • "earth" and "heart"

The Optimal O(N) Frequency Bucket Algorithm

  1. If strlen(s1) != strlen(s2), they cannot be anagrams. Return 0 immediately.
  2. Allocate a small frequency array of 26 integers initialized to 0 (for lowercase 'a' to 'z').
  3. Iterate through both strings simultaneously in a single loop:
    • Increment the bucket for s1[i] - 'a'.
    • Decrement the bucket for s2[i] - 'a'.
  4. Inspect the 26 buckets. If every bucket is exactly 0, the words are anagrams!
anagram_checker.c 
#include <stdio.h>
#include <string.h>

int isAnagram(const char s1[], const char s2[])
{
    /* Step 1: Length check */
    if (strlen(s1) != strlen(s2))
    {
        return 0;
    }

    /* Step 2: 26 lowercase English letter buckets */
    int counts[26] = {0};

    /* Step 3: Increment for s1, decrement for s2 */
    for (int i = 0; s1[i] != '\0'; i++)
    {
        counts[s1[i] - 'a']++;
        counts[s2[i] - 'a']--;
    }

    /* Step 4: Verify all buckets balanced out to zero */
    for (int i = 0; i < 26; i++)
    {
        if (counts[i] != 0)
        {
            return 0;
        }
    }

    return 1;
}

int main(void)
{
    printf(""listen" & "silent" : %s\n", isAnagram("listen", "silent") ? "ANAGRAMS" : "NOT anagrams");
    printf(""apple" & "apply"   : %s\n", isAnagram("apple", "apply") ? "ANAGRAMS" : "NOT anagrams");

    return 0;
}
Terminal Output
"listen" & "silent" : ANAGRAMS "apple" & "apply" : NOT anagrams

Substring Search: Naive Pattern Matching

Searching for a specific keyword or pattern inside a body of text is the core problem solved by search engines, code editors (Ctrl+F), and DNA sequence analyzers.

The Naive Sliding Window Algorithm

Given text of length $N$ and pattern of length $M$:

  1. Slide the pattern along the text from index i = 0 up to N - M.
  2. For each starting position i, check character-by-character if text[i + j] == pattern[j].
  3. If all $M$ characters match, report the match starting index i.
  4. If a mismatch occurs, advance i++ by 1 and try the next window.
naive_pattern_search.c 
#include <stdio.h>
#include <string.h>

int findSubstring(const char text[], const char pattern[])
{
    int n = strlen(text);
    int m = strlen(pattern);

    if (m > n) return -1;

    for (int i = 0; i <= n - m; i++)
    {
        int j;
        for (j = 0; j < m; j++)
        {
            if (text[i + j] != pattern[j])
            {
                break;  /* Mismatch: break inner loop */
            }
        }
        if (j == m)
        {
            return i;  /* All m characters matched! */
        }
    }

    return -1;  /* Pattern not found */
}

int main(void)
{
    char text[] = "Welcome to CodeVerse programming";
    char pattern[] = "CodeVerse";

    int index = findSubstring(text, pattern);

    if (index != -1)
    {
        printf("Pattern "%s" found at index %d in text.\n", pattern, index);
    }
    else
    {
        printf("Pattern not found.\n");
    }

    return 0;
}
Terminal Output
Pattern "CodeVerse" found at index 11 in text.

16 Common String Pitfalls and How to Fix Them

Because strings in C are raw character arrays with no runtime guard rails, string bugs account for a huge portion of security exploits and crashes. Here are the 16 most common mistakes:

❌ 1. Forgetting Room for Null Terminator

Wrong:

char str[4] = "Code"; /* Lacks '\0' */

Why: "Code" needs 4 bytes + 1 byte for '\0' = 5 bytes.

Fix: char str[5] = "Code"; or char str[] = "Code";

❌ 2. Using == to Compare Strings

Wrong:

if (str1 == str2) /* Compares pointers! */

Why: == tests if both strings share the exact same RAM memory address, not identical text.

Fix: if (strcmp(str1, str2) == 0)

❌ 3. Using Banned gets()

Wrong:

char buf[20];
gets(buf); /* DANGEROUS! Removed in C11 */

Why: Cannot bound input; easily causes buffer overflow.

Fix: fgets(buf, sizeof(buf), stdin);

❌ 4. Unbounded scanf("%s")

Wrong:

char name[10];
scanf("%s", name); /* Can overflow! */

Why: User typing 50 chars will smash the call stack.

Fix: scanf("%9s", name);

❌ 5. Passing & to scanf("%s")

Wrong:

scanf("%s", &name); /* Redundant & */

Why: Array name name already decays to the address of element 0.

Fix: scanf("%19s", name);

❌ 6. Confusing 'A' with "A"

Wrong:

char c = "A"; /* Assigns pointer to char! */

Why: Double quotes create a 2-byte array address; single quotes create a 1-byte char.

Fix: char c = 'A';

❌ 7. Assuming strncpy Appends '\0'

Wrong:

char d[5];
strncpy(d, "SuperLong", 5); /* No '\0'! */

Why: strncpy does not null-terminate if source is $\ge$ bound.

Fix: d[4] = '\0'; explicitly.

❌ 8. Insufficient strcat Capacity

Wrong:

char a[6] = "Hi ";
strcat(a, "There!"); /* Overflow! */

Why: Total string length is 9 + 1 = 10, but array capacity is only 6.

Fix: Declare destination with sufficient headroom: char a[30];

❌ 9. Missing #include <string.h>

Wrong: Calling strlen without header.

Why: Causes implicit declaration warnings and mismatched return type conversions.

Fix: Always include #include <string.h>.

❌ 10. Trying to Reassign String Array

Wrong:

char s[20];
s = "Hello"; /* Compile error! */

Why: Array name is a non-modifiable lvalue.

Fix: strcpy(s, "Hello");

❌ 11. Overwriting '\0' in a Loop

Wrong:

for (int i = 0; i <= len; i++) {
    s[i] = 'X'; /* Erases '\0' at s[len]! */
}

Why: Overwriting index len destroys the string sentinel.

Fix: Loop up to i < len.

❌ 12. Confusing strlen() with sizeof()

Wrong:

char s[50] = "Hi";
/* Assuming strlen is 50 or sizeof is 2 */

Why: strlen(s) == 2; sizeof(s) == 50 bytes.

Fix: Use strlen for text length, sizeof for buffer capacity.

❌ 13. Unchecked fgets Return

Wrong:

fgets(buf, 20, stdin);
len = strlen(buf); /* Crash if EOF! */

Why: If input hits EOF or fails, fgets returns NULL.

Fix: if (fgets(...) != NULL) { ... }

❌ 14. Forgetting Trailing Newline from fgets

Wrong: Comparing strcmp(input, "admin") after fgets.

Why: input actually contains "admin ", so comparison fails!

Fix: Strip ' ' before comparing.

❌ 15. Assuming strcmp Returns Exactly -1 or 1

Wrong: if (strcmp(a, b) == -1)

Why: The C standard only guarantees negative ($< 0$) or positive ($> 0$), not strictly $-1$ or $1$.

Fix: if (strcmp(a, b) < 0)

❌ 16. Assuming Strings Ignore Case

Wrong: Expecting strcmp("apple", "Apple") == 0.

Why: 'A' is 65; 'a' is 97. C string comparisons are strictly case-sensitive.

Fix: Convert characters to lowercase or write a custom case-insensitive comparison.

Time and Space Complexity for String DSA

In string-based algorithmic challenges, performance analysis is evaluated against string length $N$ (and pattern length $M$):

String Operation Time Complexity Auxiliary Space Algorithmic Explanation
Access character by index O(1) O(1) Direct base address + byte offset lookup. Instantaneous.
String Length (strlen) O(N) O(1) Must inspect every byte sequentially until encountering '\0'.
String Copy (strcpy) O(N) O(1) Copies each of the $N$ characters plus null terminator.
String Concatenation (strcat) O(N + M) O(1) Scans $N$ chars to find end of dest, then appends $M$ chars from src.
Lexicographical Comparison (strcmp) O(N) worst case O(1) $O(1)$ if first letters differ; $O(N)$ if strings are identical.
In-Place String Reversal O(N) O(1) Two-pointer approach visits $N / 2$ pairs with a single temporary variable.
Palindrome Verification O(N) worst case O(1) Compares symmetric pairs from both ends toward middle.
Character Frequency Count O(N) O(1) Single linear pass through text. Fixed 256-bucket array is $O(1)$ space.
Anagram Verification O(N) O(1) Single-pass increment/decrement over 26 lowercase buckets.
Naive Substring Search O(N × M) worst O(1) Slides window of size $M$ over $N - M + 1$ positions.

#include <string.h>
#include <ctype.h>

int isSentencePalindrome(const char *s)
{
    int left = 0;
    int right = strlen(s) - 1;

    while (left < right)
    {
        /* Skip non-alphanumeric characters */

        while (left < right && !isalnum((unsigned char)s[right])) right--;

        if (tolower((unsigned char)s[left]) != tolower((unsigned char)s[right]))
        {
            return 0;
        }
        left++;
        right--;
    }
    return 1;
}

Reasoning: 'M' (77) != 'm' (109). "Madam" will fail a strict palindrome check unless converted with tolower().

Q17: In "char roster[5][30];", what do 5 and 30 represent?
Answer: 5 strings, each with a maximum capacity of 30 bytes

Reasoning: The first dimension is rows (number of names); the second dimension is columns (maximum characters per name including '\0').

Q18: Why should characters be cast to (unsigned char) with <ctype.h>?
Answer: To prevent negative index undefined behavior

Reasoning: On platforms where char is signed, characters with values > 127 become negative integers, causing array index errors in ctype.h lookup tables.

Q19: What happens if you call strcpy() into a buffer that is too small?
Answer: Buffer overflow & undefined behavior

Reasoning: strcpy does not perform bounds checks; it continues writing past the end of the destination array, corrupting memory.

Q20: How can character frequency be counted in O(N) time?
Answer: Using a fixed 256-element integer frequency array

Reasoning: A single pass through the string increments freq[(unsigned char)str[i]]++ directly by ASCII index in $O(1)$ time per character.

DSA Challenge 1: Find the First Non-Repeating Character

Problem: Given a string, find the first non-repeating character in a single pass of extra state. Return '\0' if none exists.

Sample Input: "swiss" → Output: 'w' (since 's' repeats 3 times).

first_unique_char.c
char firstNonRepeating(const char *s) {
    int freq[256] = {0};
    for (int i = 0; s[i] != '\0'; i++) freq[(unsigned char)s[i]]++;
    for (int i = 0; s[i] != '\0'; i++) {
        if (freq[(unsigned char)s[i]] == 1) return s[i];
    }
    return '\0';
}

C String Syntax Cheat Sheet

Operation C Syntax Template Golden Engineering Rule
Declaration char str[20]; Ensure buffer capacity has room for $N$ characters + 1 byte for '\0'.
Safe Full-Line Input fgets(buf, sizeof(buf), stdin); Guarantees bounds safety; strip trailing '\n' if present.
Safe Word Input scanf("%19s", buf); Always specify field width limit %[size - 1]s.
Traversal Condition for (int i = 0; str[i] != '\0'; i++) Stops precisely at the null terminator sentinel.
Length Check size_t len = strlen(str); Counts characters before '\0'; print with %zu.
Copy String strcpy(dest, src); Destination must have capacity $\ge ext{strlen}(src) + 1$.
Compare Strings if (strcmp(s1, s2) == 0) Never use ==; strcmp returns 0 for identical text.
Append Strings strcat(dest, src); Appends src to dest; destination must have room.

15 High-Yield Viva / Interview Questions

1. What is a string in C? A one-dimensional character array terminated by the null character '\0'.
2. What is the ASCII value of '\0'? Exactly 0.
3. What is the difference between '\0' and '0'? '\0' has integer value 0 and marks string endings. '0' is the numeral zero with ASCII value 48.
4. How much memory does "Hello" occupy? 6 bytes (5 letters + 1 byte for '\0').
5. What happens if a string lacks a null terminator? Functions like printf and strlen read past the array boundary into unowned RAM, causing buffer overreads and Undefined Behavior.
6. Why is gets() banned in C? Because it cannot check destination buffer capacity, easily causing buffer overflow vulnerabilities.
7. Why does fgets() include the newline character? fgets reads until a newline or EOF and preserves '\n' in the buffer if space permits.
8. Why does strlen() have O(N) complexity? Because C strings do not store length metadata, requiring a sequential scan until '\0'.
9. What does strcmp() return if two strings are equal? Exactly 0.
10. Why is strncpy() not completely safe? It does not append '\0' if the source string length equals or exceeds the specified limit $n$.
11. How does in-place string reversal work? Using two pointers at index 0 and index $N - 1$, swapping symmetric characters and stepping inward until they meet in $O(N)$ time and $O(1)$ space.
12. What is a palindrome? A string that reads identical forward and backward (e.g., "radar").
13. How do you check for anagrams in O(N) time? Using a 26-element integer frequency array, incrementing counts for string 1 and decrementing for string 2.
14. What does char names[5][20]; declare? A 2D character array capable of storing 5 separate strings of up to 19 characters each plus '\0'.
15. Can you reassign a string array with = after declaration? No, because an array name in C is a non-modifiable constant address pointer. You must use strcpy().
