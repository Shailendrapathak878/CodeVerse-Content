01

A Simple Problem to Start

Before any definitions, look at this small program. Read it slowly.

C
int a = 10;
int b = 3;

float result = a / b;
🤔 Think for a moment

What do you think result will contain?

Most beginners say 3.333333, because 10 divided by 3 is 3.333 on a calculator. Take a guess before you read on.

Now let us run it and print the value.

Code
C
#include <stdio.h>

int main() {
    int a = 10;
    int b = 3;

    float result = a / b;

    printf("%.2f\n", result);
    return 0;
}
Output
3.00
What happened?
  • The answer is 3.00, not 3.33. Surprising, right?
  • Even though result is a float, the damage was done before the value reached it.
  • Both a and b are int, so C did an integer division: 10 ÷ 3 = 3 (the .333 part is thrown away). That 3 was then converted into the float 3.0 and stored.
🎯 Why this chapter exists

This one small surprise is the reason we study type conversion (C changing a value's type) and type casting (you telling C which type to use). By the end you will know exactly why the result was 3.00 and how to get 3.33.

🔑 Key Idea
The type of the variable on the left does not decide how the calculation on the right is done. The types of the values in the calculation decide that.
02

What is Type Conversion?

TYPE CONVERSION
Type conversion means changing a value from one data type to another data type. For example, the whole number 10 (an int) can be turned into the decimal number 10.0 (a float). C often does this for you when you mix different types in one statement, and you can also ask for it yourself.
Examples: int → float, float → int, char → int, int → double
🗣️ In Simple Words

Every value in C wears a type label: int, float, char and so on. Type conversion is swapping that label (and the way the value is stored) so that the value fits the place where it is going to be used.

🏪 Real-Life Example

A shop records the quantity of notebooks as a whole number: 3. But it calculates the price using decimals: ₹99.50. To multiply them, the billing system must treat the quantity in a decimal form too. The amount of notebooks has not changed. Only the way it is written for the calculation has changed. That is the heart of type conversion.

int → float
Whole number becomes decimal10 → 10.0
float → int
Decimal becomes whole number10.75 → 10
char → int
Character becomes its code'A' → 65
int → double
Whole number becomes a precise decimal25 → 25.0
C Example
C
int quantity = 3;
float q = quantity;      // int → float
printf("%.1f", q);
Output
3.0
What happened?
  • quantity holds the int 3.
  • When it is stored in a float variable, C converts it to the float 3.0.
🔑 Key Idea
Type conversion = changing a value from one data type to another so that it fits where it is being used.
03

Why Do We Need Type Conversion?

C is strict about types. Real programs constantly mix types, so conversion is needed in many everyday situations.

🔀
Working with different data typesint quantity × float price
🧮
Performing calculationsmixing whole and decimal numbers
📥
Assigning valuesstoring a double into an int variable
✅
Getting the expected result10 / 3 should give 3.33, not 3
📤
Passing values to functionsfunction expects a double, you give an int
🎚️
Controlling precisionkeep decimals, or deliberately drop them
Simple examples
C
int quantity = 3;
float price = 99.50;
float total = quantity * price;   // mixing int and float

double area = 78.54;
int wholeArea = (int)area;        // we only want the whole part
  • In the first example, the calculation needs both numbers in a compatible decimal form.
  • In the second, we deliberately drop the decimals because the program only needs a whole number.
🔑 Key Idea
Programs mix types all the time. Conversion lets C combine them. Casting lets you control how.

05

Implicit Type Conversion

IMPLICIT CONVERSION
Implicit conversion happens automatically when C converts a value from one type to another without the programmer writing a cast. C does this when a value of one type is used somewhere that needs another type, such as storing an int into a float variable. It is also called automatic or implicit type conversion.
Example: float result = num; where num is an int.
🗣️ In Simple Words

You do not say anything. C notices that the types do not match and quietly fixes it for you, like an auto-correct on a phone.

What C does behind the scenes
Code
C
#include <stdio.h>

int main() {
    int num = 10;
    float result = num;

    printf("%.2f", result);

    return 0;
}
Output
10.00
Step-by-Step
  1. num is created and holds the int value 10.
  2. C sees a float variable on the left and an int on the right.
  3. C automatically converts 10 into the float 10.0.
  4. 10.0 is stored in result.
  5. %.2f prints it with two decimal places: 10.00.
Why?

A float variable can only hold a floating-point value. So C changes the value into the right form before storing it. The number is the same, only its type changed.

🔑 Key Idea
Implicit conversion = C converts automatically, without a cast.
06

Real-Life Analogy for Implicit Conversion

💰 The ₹10 vs ₹10.00 analogy

Imagine you have ₹10 as a whole amount. A shop's billing system needs decimal currency, so it writes the same amount as ₹10.00. The value is the same amount of money. Only the representation (the way it is written) has changed.

When C converts 10 to 10.0, it does the same kind of thing.

Same value, different form
⚠️ Important

This is only an analogy. Inside the computer, an int and a float are stored in very different ways. Conversion creates a new value in the new type. It is not just adding ".00" to the text.

07

Widening Conversion

WIDENING CONVERSION
A widening conversion changes a value from a type that holds a narrower range or less precision into a type that can generally hold a wider range or more precision. Common examples are int → float, int → double and float → double. Because the destination is usually "roomier", this kind of conversion is often safer, but the exact behavior depends on the types involved.
Examples: int → double, float → double
🗣️ In Simple Words

You are moving something from a smaller container to a bigger one. It almost always fits.

🫙 Real-Life Example

Pouring water from a small glass into a big jug. Nothing spills, because the jug is larger than the glass.

Code
C
int number = 25;
double value = number;

printf("%.1f", value);
Output
25.0
What happened?
  • The int 25 was converted into the double 25.0.
  • The whole value 25 is still there. No digits were thrown away.
Why is there usually no loss?

A whole number like 25 has no fractional part, and a double can represent it exactly. Nothing needs to be cut off, unlike converting a decimal value into an integer (see the next section).

⚠️ Not every widening is perfect

Be careful with the word "safe". A float keeps only a limited number of accurate digits, so a very large int converted to float can lose precision. For example, the int 16777217 becomes 16777216.0 as a float. For ordinary beginner values like 25 or 1000, there is no problem. This is why we say widening is often safer, not always perfect.

🔑 Key Idea
Widening = moving to a roomier type. Usually fine for normal values, but extremely large values can still lose precision.
08

Narrowing Conversion

NARROWING CONVERSION
A narrowing conversion goes in the opposite direction: a value is converted into a type that may hold less information, such as double → int or float → int. When a decimal value is converted to an integer, C discards the fractional part (everything after the decimal point). This is why narrowing conversions need more care.
Examples: double → int, float → int
🗣️ In Simple Words

You are moving something from a bigger container to a smaller one. Some of it may not fit.

🫗 Real-Life Example

Pouring a full jug into a small glass. The glass can hold only part of the water, and the rest is lost. Similarly, an int has no place for the ".99" part, so it is cut off.

Code
C
double price = 99.99;
int value = price;

printf("%d", value);
Output
99
Step-by-Step
  1. price holds the double 99.99.
  2. The destination value is an int, which can only hold whole numbers.
  3. C converts 99.99 to an int by dropping the .99.
  4. 99 is stored in value.
⚠️ Very Important

This does NOT round 99.99 to 100. It becomes 99. C simply cuts off the decimal part. This is called truncation.

🔑 Key Idea
Narrowing = moving to a smaller type. Converting a float or double to an int truncates: it removes the fractional part and never rounds.
09

Data Loss

DATA LOSS
Data loss means some information from the original value is missing after the conversion. It happens when the new type cannot represent everything that the old value contained. The most common beginner example is losing the fractional part when converting a decimal number to an integer.
Example: 82.75 → int → 82
🗣️ In Simple Words

After the conversion, you can no longer get back what was cut off. Converting 82.75 to 82 and then back to a float gives 82.0, not 82.75.

📏 Real-Life Example

A tailor measures you as 82.75 cm, but writes only "82" on the form. The extra 0.75 cm is gone from the record. That is data loss.

Diagram 4: Data Loss
Once the .75 is dropped, it cannot be recovered.
Code
C
float marks = 82.75;
int result = marks;

printf("%d", result);
Output
82
What was lost?
  • The .75 is gone. Only the whole part 82 survives.
  • If these were exam marks, three quarters of a mark has silently vanished. C did not warn you by default.

Other kinds of loss

Fractions are not the only thing that can be lost. A conversion may also cause range or precision problems when the destination type cannot represent the original value adequately. For example, a very large decimal number may not fit into an int at all, and the result is then unreliable. A very large int may lose small digits when it becomes a float.

ℹ️ Do not over-simplify

It is not correct to say "widening is always safe and narrowing is always unsafe". Think of it as: always ask whether the destination type can hold everything the source value contains.

🔑 Key Idea
Data loss = information missing after conversion. Always ask: "Can the new type hold everything the old value had?"
10

Explicit Type Casting

TYPE CASTING
Type casting is when the programmer explicitly tells C to treat or convert a value as another type, using the cast operator. You write the target type in round brackets just before the value or expression. This gives you control, so you do not have to depend on what C would do automatically.
Example: (float)10
🗣️ In Simple Words

Type casting is you telling C: "Please treat this value as this type." You give the order instead of waiting for C to decide.

🥤 Real-Life Example

A cashier says, "Please give me this amount in coins." You are not leaving it to chance. You are clearly asking for a specific form. A cast is the same kind of clear request.

Syntax 
(type) expression
Example 
(float)10
Every part explained
  • ( ): the round brackets that mark this as a cast.
  • type: the type you want, such as float, int or double.
  • expression: the value or calculation to be converted. It can be a number, a variable or an expression.
Diagram 5: The Cast Operator
The type in brackets goes first, then the thing you are converting.
Code
C
int x = 9;
float y = (float)x;

printf("%.1f %d", y, x);
Output
9.0 9
What happened?
  • (float)x produced a float copy of the value 9: that is 9.0.
  • The original variable x is not changed. It is still the int 9.
💡 Tip
A cast converts the value at that moment, in that expression. It never changes the declared type of the variable.
🔑 Key Idea
Cast operator: (type) expression. It converts a value on request, and leaves the original variable alone.
11

Basic Type Casting Example

Now let us fix the problem from the very beginning. This is one of the most important examples in the whole chapter.

Code
C
#include <stdio.h>

int main() {
    int a = 10;
    int b = 3;

    float result = (float)a / b;

    printf("%f", result);
    return 0;
}
Output
3.333333
Step-by-Step 
a = 10
b = 3

(float)a
   ↓
10.0

10.0 / 3
   ↓
3.333333...
  1. (float)a turns the int 10 into the float 10.0.
  2. Now the division is float ÷ int. C automatically converts the 3 into 3.0 (implicit conversion).
  3. So C does a floating-point division: 10.0 / 3.0 = 3.333333...
  4. The result is stored in result.
Why?

Division in C looks at the types of both sides. When one side is a float, the whole division becomes a decimal division. Casting just one operand is enough.

ℹ️ Why only a was cast

You need to cast only one of the two numbers. C converts the other one automatically to match. Writing (float)a / (float)b also works, but it is not necessary.

🔑 Remember
(float)a / b gives a decimal answer, because a becomes a float before the division happens.
12

Integer Division vs Floating-Point Division

INTEGER DIVISION
Integer division happens when both numbers in a division are integers. The result is also an integer, so the fractional part is cut off. For example, 10 / 3 is 3 and 7 / 2 is 3. C does not round the answer. It simply drops everything after the decimal point.
Both sides int → integer division
FLOATING-POINT DIVISION
Floating-point division happens when at least one of the numbers is a float or double. C then divides using decimals and keeps the fractional part. For example, 10.0 / 3 gives 3.333333.
At least one side float or double → decimal division
🍕 Real-Life Example

Share 10 pizzas among 3 friends. Integer division asks "how many whole pizzas does each friend get?" Answer: 3. Floating-point division asks "how much does each friend get, including parts of pizzas?" Answer: 3.33.

Diagram 2: Integer vs Floating-Point Division
Same numbers. Different answer, because of the types.

Without casting

Code
C
int a = 10;
int b = 3;

float result = a / b;
printf("%f", result);
Output
3.000000
Step-by-Step
  1. a and b are both int.
  2. C divides two ints, so it uses integer division: 10 / 3 = 3.
  3. The int 3 is then implicitly converted to the float 3.0.
  4. 3.0 is stored in result. Printed with %f, it shows 3.000000.
Why?

The decimal part was already lost during the division. Converting 3 to 3.0 afterwards cannot bring .333 back.

With casting

Code
C
int a = 10;
int b = 3;

float result = (float)a / b;
printf("%f", result);
Output
3.333333
Step-by-Step
  1. (float)a makes 10.0.
  2. Division is now float ÷ int, so C converts b to 3.0 automatically.
  3. C does a floating-point division: 10.0 / 3.0 = 3.333333.
Why?

The cast happened before the division, so the decimals were kept.

💡 Tip: a shortcut with decimal literals

Writing a number with a decimal point already makes it a floating-point value. 10 / 3.0 and 10.0 / 3 both give 3.333333, without any cast. Casting is mainly needed when the numbers are variables.

🔑 Remember
Int ÷ int = int. If you want decimals, make at least one side a float or double before the division.
13

Casting Different Types

The cast operator works between many types. Here are the most common beginner cases.

Integer → Float

C
int x = 10;
float y = (float)x;
printf("%.1f", y);     // 10.0

The whole number 10 becomes the decimal 10.0. Nothing is lost.

Float → Integer

C
float x = 10.75;
int y = (int)x;
printf("%d", y);        // 10

The .75 is dropped. The result is 10, not 11. (Truncation, not rounding.)

Double → Integer

C
double x = 99.99;
int y = (int)x;
printf("%d", y);        // 99

Again the decimal part is cut off. 99.99 becomes 99.

Character → Integer

Code
C
char ch = 'A';
int value = (int)ch;

printf("%d", value);
Output (on systems using ASCII)
65
What happened?
  • Inside the computer, every character is stored as a number code.
  • On most systems the code for 'A' is 65, for 'B' it is 66, and so on.
  • Casting the char to int shows that number.
ℹ️ Real-Life Example

Think of a library where every book has a shelf number. The letter 'A' is like the book, and 65 is its shelf number. We will look at character codes properly in a later topic. For now, just remember that a char is really a small number.

🔑 Key Idea
Int → float keeps the value. Float or double → int cuts the decimals. Char → int shows the character's code.
14

Conversion During Assignment

ASSIGNMENT CONVERSION
When you assign a value to a variable using =, C first calculates the value on the right side. If its type is different from the type of the variable on the left side, C automatically converts the value into the variable's type before storing it. This is the most common place where implicit conversion happens.
The variable's type always wins.
🗣️ In Simple Words

Whatever you put into a box, C reshapes it to fit the box's type.

🔌 Real-Life Example

A foreign phone charger plug does not fit your wall socket, so you use an adapter. The socket (the variable's type) stays the same. The plug (the value) is adapted to fit.

Diagram 6: Assignment Conversion
Right-side value → conversion → left-side variable's type.
Case 1: int → double
C
int x = 10;
double y = x;
printf("%.1f", y);
Output
10.0
  • Widening. The int 10 becomes the double 10.0. Nothing lost.
Case 2: double → int
C
double x = 10.75;
int y = x;
printf("%d", y);
Output
10
  • Narrowing. The int variable cannot hold .75, so it is cut off. No cast was written, but the conversion still happened automatically.
⚠️ Important

Assignment conversion happens silently. C will usually not stop you from storing a decimal into an int. Some compilers can give a warning if you turn warnings on. If you really intend to drop the decimals, write the cast (int)x to show that it is on purpose.

🔑 Key Idea
On assignment, the value is converted to the type of the variable on the left.
15

Conversion in Expressions

CONVERSION IN EXPRESSIONS
An expression is a calculation such as a + b. When the values in one expression have different types, C converts them to a common, compatible type before doing the calculation. In general, a whole number is converted into a floating-point form when it is combined with a decimal value, so no decimal part gets lost.
Example: int + float
🗣️ In Simple Words

C does not mix apples and oranges. Before calculating, it makes both numbers the same kind.

⚖️ Real-Life Example

You cannot add 2 kg and 500 grams directly. You first write both in the same unit (2000 g + 500 g). C does a similar thing: it brings both numbers to one common type.

Code
C
int a = 10;
float b = 2.5;

float result = a + b;
printf("%.1f", result);
Output
12.5
Step-by-Step
  1. a is an int (10) and b is a float (2.5).
  2. Before adding, C converts a into the float 10.0.
  3. C adds 10.0 + 2.5 = 12.5.
  4. The float result is stored in result.
Why?

If C had turned 2.5 into an int instead, it would have become 2 and the answer would be wrong. So C converts in the direction that keeps the decimals.

ℹ️ Keeping it simple

The full rules of C for choosing the common type have more details. For now, remember this rule of thumb: when whole and decimal numbers are mixed, the whole number becomes a decimal number.

🔑 Key Idea
In mixed expressions, C converts the "smaller" kind (int) to the "bigger" kind (float or double) before calculating.

Type Casting vs Type Conversion

These two terms are closely related, so beginners often use them as if they were the same. They are not exactly the same.

Type ConversionType Casting
The general process of changing one type into anotherAn explicit conversion written by the programmer
Can happen automaticallyThe programmer requests it
May be implicit or explicitAlways explicit
Example: int to float during assignmentExample: (float)x
🧠 How they relate

Type conversion is the big umbrella. Type casting is one kind of type conversion, the explicit kind.

So: every cast is a conversion, but not every conversion is a cast.

Casting lives inside conversion
🔑 Key Idea
Conversion = the general idea (automatic or not). Casting = the explicit kind that you write with (type).
17

Widening vs Narrowing

Diagram 3: Widening vs Narrowing
Small to big: usually safe. Big to small: information may be lost.

⬆ Widening

  • Typical purpose: combine different types in a calculation, or store a whole number in a decimal variable.
  • Information loss: usually none for ordinary values.
  • Example: int number = 25; double value = number; → 25.0

⬇ Narrowing

  • Typical purpose: when you really need only the whole part, or a smaller type.
  • Information loss: possible. The fractional part is cut off.
  • Example: double price = 99.99; int value = (int)price; → 99
⚠️ Important

Do not memorize "widening is perfectly lossless". As you saw earlier, a huge int converted to a float can still lose small digits. The accurate idea is: widening is generally safer, narrowing is more likely to lose information.

18

Real-Life Examples

Example 1: Shopping

Code
C
#include <stdio.h>

int main() {
    int quantity = 3;
    float price = 99.50;

    float total = quantity * price;

    printf("Total: %.2f\n", total);
    return 0;
}
Output
Total: 298.50
Step-by-Step
  1. quantity is an int (3), price is a float (99.50).
  2. In the multiplication, C implicitly converts 3 to 3.0.
  3. 3.0 × 99.50 = 298.50, stored in total.
Why?

The price has decimals, so the calculation must also be a decimal calculation. C converted the quantity for us. No cast was needed.

Example 2: Student percentage

Code
C
int obtained = 425;
int total = 500;

float percentage = (float)obtained / total * 100;
printf("%.2f", percentage);
Output
85.00
Step-by-Step
  1. (float)obtained becomes 425.0.
  2. 425.0 / 500 = 0.85 (a floating-point division).
  3. 0.85 × 100 = 85.0.
Why is the cast important here?

Without it, obtained / total would be 425 / 500 = 0 in integer division, because 425 is smaller than 500. Then 0 × 100 = 0, and the percentage would wrongly be 0.00.

Example 3: Temperature

Converting Celsius to Fahrenheit uses the formula F = C × 9 / 5 + 32. The fraction 9/5 is where integer division can ruin the answer.

Code
C
#include <stdio.h>

int main() {
    int celsius = 37;

    float wrong = celsius * (9 / 5) + 32;
    float right = celsius * 9.0 / 5 + 32;

    printf("Wrong: %.1f\n", wrong);
    printf("Right: %.1f\n", right);
    return 0;
}
Output
Wrong: 69.0
Right: 98.6
Step-by-Step
  1. Wrong: 9 / 5 is an integer division, so it equals 1. Then 37 × 1 + 32 = 69.
  2. Right: 9.0 is a decimal value, so celsius * 9.0 is 333.0, then / 5 = 66.6, then + 32 = 98.6.
Why?

Body temperature 37 °C is 98.6 °F. The wrong version gave 69, which is a big error caused by one hidden integer division.

🔑 Key Idea
Whenever a calculation involves a fraction like 9/5 or 425/500, check whether integer division could sneak in.
19

Common Mistakes

❌ Mistake 1: Expecting a decimal result
int result = 10 / 3;
printf("%d", result);
⚠️ Problem
Output
3
✅ Correct
float result = 10.0 / 3;     // 3.333333
Why: 10 and 3 are both integers, so it is an integer division. The answer is 3, with the .333 dropped. Also the variable on the left is an int, which cannot hold decimals anyway.
❌ Mistake 2: Casting too late
int a = 10, b = 3;

float r1 = (float)(a / b);
float r2 = (float)a / b;

printf("%f\n%f", r1, r2);
⚠️ Problem: they are NOT the same
Output
3.000000
3.333333
Step by step, (float)(a / b):
1. Brackets first: a / b = 10 / 3 = 3 (integer division, the decimals are already gone).
2. Then the cast changes 3 into 3.0.
Result: 3.000000. The cast came too late.
Step by step, (float)a / b:
1. The cast applies to a only: 10 becomes 10.0.
2. Then 10.0 / 3 is a floating-point division: 3.333333.
The cast came before the division.
✅ Correct: cast the operand, not the finished result
float r = (float)a / b;
Remember: a cast only converts what is directly next to it. If you cast the result of an integer division, the damage is already done.
Where you place the cast matters
Cast early to keep the decimals. Cast late and they are already gone.
❌ Mistake 3: Expecting casting to round
int x = (int)9.99;
printf("%d", x);
⚠️ Problem
Output
9
✅ If you want rounding (positive numbers), add 0.5 first
int x = (int)(9.99 + 0.5);   // 10
Why: A cast to int only cuts off the decimal part. It never rounds up. 9.99 becomes 9, not 10. (There are proper rounding functions in C, which come in a later topic.)
❌ Mistake 4: Ignoring data loss
int x = (int)82.75;
printf("%d", x);
⚠️ Problem
Output
82
✅ Correct: keep the decimal type if the decimals matter
float x = 82.75;
printf("%.2f", x);     // 82.75
Why: The .75 was discarded and cannot be recovered. Before casting to int, ask yourself whether you can really live without the fractional part.
❌ Mistake 5: Mixing up = and ==
int x = 5;
x = 10;       // assignment: store 10 in x
x == 10;      // comparison: is x equal to 10?
Brief note: = stores a value (this is where assignment conversion happens). == compares two values. Beginners mix them up, so keep them apart in your mind. We will study comparison properly in the Operators chapter.

Think Before You Code

🧠 Think Before You Code

Before converting or casting a value, ask yourself:

  1. What is the original data type?
  2. What type do I need?
  3. Is C converting it automatically already?
  4. Do I need an explicit cast?
  5. Could I lose information?
  6. Will integer division affect my result?
Worked example: average of two marks

Marks are int math = 85 and int science = 90. We want the average (87.5).

  1. Original type? Both are int.
  2. Needed type? A decimal, because 87.5 has a fraction.
  3. Automatic? Not enough. (85 + 90) / 2 is int ÷ int.
  4. Cast needed? Yes, or write 2.0.
  5. Loss? Without a cast, the .5 would be lost.
  6. Integer division? Yes, it would affect the result.
C
float average = (float)(math + science) / 2;     // 87.5
  • Notice the cast is applied to the sum (inside brackets) before dividing. The sum 175 is an exact whole number, so nothing is lost by taking its float form first.

Quick Revision

Type conversion→Changing a value from one data type to another
Implicit conversion→Automatic. C does it without a cast
Explicit conversion→Requested by the programmer
Type casting→Explicit conversion using the cast operator
Cast operator→(type) expression
Widening→To a roomier type (int → double). Generally safer
Narrowing→To a smaller type (double → int). May lose information
Data loss→Information missing after conversion (e.g. 82.75 → 82)
Integer division→int ÷ int gives an int. Decimals are cut off
Floating-point division→At least one float or double. Decimals are kept

Remember These

(type) expression
C
(float)a / b
  • 10 / 3 with ints gives 3, not 3.33.
  • (float)a / b casts before dividing. (float)(a / b) casts after.
  • Casting to int truncates. It never rounds.
  • On assignment, the value is converted to the variable's type.
  • A cast does not change the variable. It converts the value for that expression.
  • Widening is generally safe. Narrowing may lose data.
