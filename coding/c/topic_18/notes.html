DSA Foundations

01. Introduction: What Is a Linked List?

In Computer Science, a data structure is a specialized format for organizing, processing, retrieving, and storing data in computer memory. Among all data structures, the Linked List is the foundational gateway into dynamic, non-contiguous data representations.

What Is a Linked List?

A Linked List is a linear data structure consisting of a sequence of dynamically allocated elements called nodes. Unlike arrays, nodes are not stored in contiguous (neighboring) memory locations. Instead, each node contains two distinct parts:

  1. Data Field: The actual information being stored (such as an integer, string, or record).
  2. Link (Pointer) Field: A pointer variable storing the memory address of the next node in the sequence.
Real-Life Analogy: The Treasure Hunt

Imagine participating in an outdoor treasure hunt:

  • Clue 1 does not contain all the clues. It contains a puzzle, plus a written note saying: "The next clue is hidden under the oak tree by the library."
  • You walk over to the oak tree to find Clue 2. Clue 2 has its own puzzle, plus an address: "Next clue is behind the sports stadium fountain."
  • You cannot jump directly to Clue 5 because you do not know where it is hidden until you visit Clues 1, 2, 3, and 4 in sequence.
  • The final clue contains a message: "Congratulations! There are no more clues." (Represented in C by the NULL pointer).

1.1 Fundamental Visual Representation

A standard singly linked list with three integer nodes is conceptually visualized as follows: 

HEAD → [ 10 | • ] → [ 20 | • ] → [ 30 | NULL ]
  • HEAD: A pointer variable that stores the memory address of the very first node. It serves as the single entry point to the entire list.
  • The Bullet (•): Represents the next pointer holding the heap address of the succeeding node.
  • NULL: A macro representing address 0x0. It terminates the list, indicating that the third node has no successor.
  • Empty List: If a linked list contains zero nodes, it is represented simply as head == NULL.
Crucial Insight: Arrows Are Pointers, Not Physical Wires!

The arrows drawn in linked list diagrams are conceptual abstractions. In physical RAM, Node 1 might live at address 0x1040, Node 2 at address 0x9800, and Node 3 at address 0x2210. The nodes are scattered across the heap, connected solely because Node 1 explicitly stores 0x9800 inside its next member!

Arrays vs. Linked Lists

02. Why Do We Need Linked Lists? (Arrays vs. Lists)

Before writing code, every engineer must understand why linked lists exist when we already have arrays.

2.1 The Limitations of Arrays

  1. Fixed Capacity Ceiling: Standard arrays declared as int arr[100]; have an immutable size locked at compile time. If you only store 3 items, 97 slots are wasted. If you need 101 items, the array overflows.
  2. Expensive Reallocation: Dynamically resizable arrays (like C++ std::vector or custom realloc() arrays) must frequently allocate a larger block and copy all existing elements to the new location when full.
  3. Costly Element Shifting: Inserting or deleting an item at the beginning (index 0) of an array of \(n\) elements requires shifting all \(n\) existing elements one slot over, resulting in an expensive \(O(n)\) time penalty.

2.2 The Strengths & Trade-offs of Linked Lists

  • Dynamic Sizing: Nodes are allocated one by one via malloc() precisely when needed and freed with free() when deleted. Memory consumption grows and shrinks perfectly with the workload.
  • Instant \(O(1)\) Insertion/Deletion: Prepending a new node to the front of a linked list takes instant \(O(1)\) time because no other nodes need to move in memory; only two pointer addresses are updated.
  • No Contiguity Requirement: If system memory is fragmented, an array allocation of 1,000 contiguous integers might fail, while a linked list can easily scatter those 1,000 nodes across scattered free memory chunks.

Node Anatomy

03. Understanding a Node in C: Anatomy & Allocation

In C, a linked-list node is constructed using a Self-Referential Structure:

Node Structure Definition
struct Node
{
    int data;           /* Data field: Stores the payload */
    struct Node *next;  /* Link field: Pointer to another node of the exact same type */
};

3.1 Why Is It Called "Self-Referential"?

The member next is declared as struct Node *. It does not contain an entire node inside itself (which would cause an infinite recursive sizing error). Instead, it stores a pointer address (4 bytes on 32-bit systems, 8 bytes on 64-bit systems) capable of pointing to any object of type struct Node.

3.2 Complete Single-Node Program

The following complete, runnable program demonstrates how to allocate a node on the heap using malloc(), check for allocation failure, assign its values, print its payload, and cleanly release its memory:

single_node_demo.c 
#include <stdio.h>
#include <stdlib.h>

struct Node
{
    int data;
    struct Node *next;
};

int main(void)
{
    /* Step 1: Request heap memory for one node */
    struct Node *first = malloc(sizeof *first);

    /* Step 2: Always verify allocation success */
    if (first == NULL)
    {
        fprintf(stderr, "Fatal Error: Memory allocation failed!\n");
        return 1;
    }

    /* Step 3: Initialize data and set next to NULL */
    first->data = 42;
    first->next = NULL;

    /* Step 4: Access and display node data */
    printf("Node successfully created!\n");
    printf("Stored Data: %d\n", first->data);
    printf("Next Pointer: %p (NULL indicates end of list)\n", (void *)first->next);

    /* Step 5: Clean up memory */
    free(first);
    first = NULL;

    return 0;
}

Pointer Mechanics

04. The head Pointer: The Anchor of the List

The head pointer is the single most important variable in linked-list programming.

The Role of Head

head is not a node. It is an ordinary pointer variable (residing on the stack or in global scope) whose entire job is to hold the memory address of the first node in the list.

4.1 The Three Cardinal States of a Linked List

  1. Empty List: 
    struct Node *head = NULL;
    When head is NULL, the list has zero elements. Every linked list begins in this state.
  2. Single-Node List: 
    head → [ 10 | NULL ]
    head points to Node 10, and Node 10's next pointer is NULL.
  3. Multi-Node List: 
    head → [ 10 | • ] → [ 20 | • ] → [ 30 | NULL ]
    head points to Node 10. Node 10 points to Node 20. Node 20 points to Node 30. Node 30 points to NULL.
The "Severed Head" Disaster

If you accidentally reassign head = NULL; without freeing the nodes, or if you overwrite head = head->next; without saving the old address, the detached nodes are stranded in heap memory with no pointer left in the entire program to reach them. This produces an immediate, unfixable Memory Leak!

05. Creating a Singly Linked List (createNode Helper)

In professional DSA implementations, we never write raw malloc() calls repeatedly in main(). Instead, we encapsulate allocation, validation, and initialization inside a reusable helper function:

The Standard createNode() Helper
struct Node *createNode(int value)
{
    struct Node *newNode = malloc(sizeof *newNode);
    if (newNode == NULL)
    {
        return NULL; /* Caller must handle allocation failure */
    }
    newNode->data = value;
    newNode->next = NULL;
    return newNode;
}

5.1 Connecting Three Nodes Sequentially

The following complete program builds a 3-node list (10 → 20 → 30), handles partial allocation failures, displays the chain, and cleanly frees every node:

create_three_nodes.c 
#include <stdio.h>
#include <stdlib.h>

struct Node {
    int data;
    struct Node *next;
};

struct Node *createNode(int value) {
    struct Node *newNode = malloc(sizeof *newNode);
    if (newNode == NULL) return NULL;
    newNode->data = value;
    newNode->next = NULL;
    return newNode;
}

int main(void) {
    /* 1. Allocate Node 1 */
    struct Node *head = createNode(10);
    if (head == NULL) return 1;

    /* 2. Allocate Node 2 and link Node 1 to Node 2 */
    head->next = createNode(20);
    if (head->next == NULL) {
        free(head);
        return 1;
    }

    /* 3. Allocate Node 3 and link Node 2 to Node 3 */
    head->next->next = createNode(30);
    if (head->next->next == NULL) {
        free(head->next);
        free(head);
        return 1;
    }

    /* Display the chain */
    printf("List created: %d → %d → %d → NULL\n", 
           head->data, 
           head->next->data, 
           head->next->next->data);

    /* Clean up all allocated nodes in reverse or sequential order */
    free(head->next->next);
    free(head->next);
    free(head);
    head = NULL;

    return 0;
}

Traversal Engine

06. Traversing and Displaying a Linked List

Traversal means visiting every node in the linked list sequentially, starting from head and continuing until the terminating NULL pointer is encountered.

The Universal Traversal Pattern
struct Node *current = head; /* Start at head */

while (current != NULL)      /* Continue until reaching the end */
{
    printf("%d ", current->data); /* Process node */
    current = current->next;      /* Advance to next node */
}

6.1 Why We Must Use a current Pointer

DO NOT ADVANCE HEAD DIRECTLY!
/* CATASTROPHIC BUG: */
while (head != NULL) {
    printf("%d ", head->data);
    head = head->next; /* HEAD IS LOST FOREVER! */
}

If you advance head directly in a display loop, head ends up pointing to NULL when the loop finishes. You have completely lost the reference to the start of your list and leaked every single node in memory! Always declare a temporary iterator pointer (usually named current or temp).

6.2 Complete Runnable Traversal Program

traversal_demo.c 
#include <stdio.h>
#include <stdlib.h>

struct Node {
    int data;
    struct Node *next;
};

struct Node *createNode(int value) {
    struct Node *n = malloc(sizeof *n);
    if (n) { n->data = value; n->next = NULL; }
    return n;
}

void displayList(const struct Node *head) {
    const struct Node *current = head;
    printf("List elements: ");
    while (current != NULL) {
        printf("%d ", current->data);
        current = current->next;
    }
    printf("\n");
}

void freeList(struct Node *head) {
    struct Node *current = head;
    while (current != NULL) {
        struct Node *temp = current->next;
        free(current);
        current = temp;
    }
}

int main(void) {
    struct Node *head = createNode(10);
    head->next = createNode(20);
    head->next->next = createNode(30);

    displayList(head);
    freeList(head);
    head = NULL;

    return 0;
}

07. Insertion Operations (Beginning, End, Position)

Inserting a new node into a linked list requires splicing memory pointers. Unlike arrays, no elements need to be shifted in memory.

7.1 Operation A: Insert at the Beginning (Prepend)

Inserting at the beginning creates a new head for the list.

Prepend Algorithm (Strict Order of Operations)
/* 1. Point new node's next to the CURRENT head */
newNode->next = head;

/* 2. Update head to point to the new node */
head = newNode;
CRITICAL ORDER OF ASSIGNMENT

You must set newNode->next = head; BEFORE setting head = newNode;! If you set head = newNode; first, you overwrite the only pointer to the rest of the list, permanently detaching and leaking all existing nodes.

insert_beginning_demo.c 
#include <stdio.h>
#include <stdlib.h>

struct Node {
    int data;
    struct Node *next;
};

struct Node *createNode(int val) {
    struct Node *n = malloc(sizeof *n);
    if (n) { n->data = val; n->next = NULL; }
    return n;
}

struct Node *insertAtBeginning(struct Node *head, int value) {
    struct Node *newNode = createNode(value);
    if (newNode == NULL) return head; /* Allocation failed */
    newNode->next = head;
    head = newNode;
    return head;
}

void printList(const struct Node *head) {
    while (head != NULL) {
        printf("%d ", head->data);
        head = head->next;
    }
    printf("\n");
}

int main(void) {
    struct Node *head = NULL;

    /* Build initial list: 20 -> 30 */
    head = insertAtBeginning(head, 30);
    head = insertAtBeginning(head, 20);

    printf("Before: ");
    printList(head);

    /* Insert 10 at the beginning */
    head = insertAtBeginning(head, 10);

    printf("After:  ");
    printList(head);

    /* Clean up */
    while (head) {
        struct Node *temp = head->next;
        free(head);
        head = temp;
    }
    return 0;
}

Before: 20 30 
After:  10 20 30

7.2 Operation B: Insert at the End (Append)

To insert at the end of a singly linked list without a maintained tail pointer:

  1. Allocate the new node and set its next = NULL.
  2. If the list is empty (head == NULL), the new node becomes the head.
  3. Otherwise, declare an iterator pointer and walk until current->next == NULL (the current last node).
  4. Set current->next = newNode;.
Append Code Pattern
struct Node *insertAtEnd(struct Node *head, int value) {
    struct Node *newNode = createNode(value);
    if (newNode == NULL) return head;
    if (head == NULL) return newNode;

    struct Node *current = head;
    while (current->next != NULL) {
        current = current->next;
    }
    current->next = newNode;
    return head;
}

7.3 Operation C: Insert at a Given Zero-Based Position

Positions are 0-indexed. For a list of length \(n\), valid insertion positions range from 0 (prepend) up to n (append). A position greater than \(n\) is invalid.

Position Insertion Logic
struct Node *insertAtPosition(struct Node *head, int value, int position) {
    if (position < 0) return head; /* Invalid */
    if (position == 0) return insertAtBeginning(head, value);

    struct Node *current = head;
    for (int i = 0; i < position - 1 && current != NULL; i++) {
        current = current->next;
    }

    if (current == NULL) return head; /* Position exceeds list length */

    struct Node *newNode = createNode(value);
    if (newNode == NULL) return head;

    newNode->next = current->next;
    current->next = newNode;
    return head;
}
Memory Release

08. Deletion Operations (Beginning, End, Value, Pos)

Deleting a node involves two critical steps: updating pointer links around the node and freeing the node's heap memory.

8.1 Operation A: Delete from Beginning

struct Node *deleteFromBeginning(struct Node *head) {
    if (head == NULL) return NULL; /* List already empty */

    struct Node *temp = head; /* Save current head */
    head = head->next;        /* Move head to second node */
    free(temp);               /* Free old first node */
    return head;
}

8.2 Operation B: Delete from End

Requires finding the second-to-last node so its next pointer can be set to NULL: 

struct Node *deleteFromEnd(struct Node *head) {
    if (head == NULL) return NULL;
    if (head->next == NULL) { /* Single-node list */
        free(head);
        return NULL;
    }

    struct Node *current = head;
    while (current->next->next != NULL) {
        current = current->next;
    }

    free(current->next);   /* Free last node */
    current->next = NULL;  /* Second-to-last node is now tail */
    return head;
}

8.3 Operation C: Delete by Value (First Occurrence)

Searches for a specific value. When found, bypasses the node and frees it:

delete_by_value.c 
#include <stdio.h>
#include <stdlib.h>

struct Node {
    int data;
    struct Node *next;
};

struct Node *createNode(int val) {
    struct Node *n = malloc(sizeof *n);
    if (n) { n->data = val; n->next = NULL; }
    return n;
}

struct Node *deleteByValue(struct Node *head, int target) {
    if (head == NULL) return NULL;

    /* Case 1: Target is at the head node */
    if (head->data == target) {
        struct Node *temp = head;
        head = head->next;
        free(temp);
        return head;
    }

    /* Case 2: Target is in the middle or end */
    struct Node *current = head;
    while (current->next != NULL && current->next->data != target) {
        current = current->next;
    }

    if (current->next != NULL) {
        struct Node *temp = current->next;
        current->next = current->next->next; /* Bypass node */
        free(temp);                          /* Release memory */
    }

    return head;
}

void printList(const struct Node *head) {
    while (head != NULL) {
        printf("%d ", head->data);
        head = head->next;
    }
    printf("\n");
}

int main(void) {
    struct Node *head = createNode(10);
    head->next = createNode(20);
    head->next->next = createNode(30);
    head->next->next->next = createNode(40);

    printf("Original: ");
    printList(head);

    head = deleteByValue(head, 20); /* Delete middle node */
    printf("After deleting 20: ");
    printList(head);

    /* Clean up */
    while (head) {
        struct Node *t = head->next;
        free(head);
        head = t;
    }
    return 0;
}

8.4 Operation D: Delete at Given Zero-Based Position

Valid positions are \(0 \le pos < length\): 

struct Node *deleteAtPosition(struct Node *head, int position) {
    if (head == NULL || position < 0) return head;
    if (position == 0) return deleteFromBeginning(head);

    struct Node *current = head;
    for (int i = 0; i < position - 1 && current != NULL; i++) {

09. Searching in a Linked List (Linear Search)

Because linked-list nodes are not stored in contiguous memory and lack indexed addressing, binary search is impossible on a standard singly linked list. We must perform Linear Search:

search_demo.c 
#include <stdio.h>
#include <stdlib.h>

struct Node {
    int data;
    struct Node *next;
};

struct Node *createNode(int val) {
    struct Node *n = malloc(sizeof *n);
    if (n) { n->data = val; n->next = NULL; }
    return n;
}

/* Returns 0-based index if found, or -1 if target not present */
int searchNode(const struct Node *head, int target) {
    int index = 0;
    const struct Node *current = head;

    while (current != NULL) {
        if (current->data == target) {
            return index; /* Target found! */
        }
        current = current->next;
        index++;
    }

    return -1; /* Not found */
}

int main(void) {
    struct Node *head = createNode(10);
    head->next = createNode(20);
    head->next->next = createNode(30);
    head->next->next->next = createNode(40);

    int target1 = 30;
    int pos1 = searchNode(head, target1);
    if (pos1 != -1) printf("Target %d found at position %d\n", target1, pos1);
    else printf("Target %d not found\n", target1);

    int target2 = 99;
    int pos2 = searchNode(head, target2);
    if (pos2 != -1) printf("Target %d found at position %d\n", target2, pos2);
    else printf("Target %d not found\n", target2);

    /* Clean up */
    while (head) {
        struct Node *t = head->next;
        free(head);
        head = t;
    }
    return 0;
}

10. Counting Nodes & Calculating Metrics

Traversal can compute a multitude of statistics. Notice how findMin and findMax initialize their candidates directly from head->data rather than hardcoding arbitrary numbers:

metrics_demo.c 
#include <stdio.h>
#include <stdlib.h>

struct Node {
    int data;
    struct Node *next;
};

struct Node *createNode(int val) {
    struct Node *n = malloc(sizeof *n);
    if (n) { n->data = val; n->next = NULL; }
    return n;
}

int countNodes(const struct Node *head) {
    int count = 0;
    while (head) { count++; head = head->next; }
    return count;
}

long long calculateSum(const struct Node *head) {
    long long sum = 0;
    while (head) { sum += head->data; head = head->next; }
    return sum;
}

int findMin(const struct Node *head) {
    if (head == NULL) return 0;
    int minVal = head->data;
    head = head->next;
    while (head) {
        if (head->data < minVal) minVal = head->data;
        head = head->next;
    }
    return minVal;
}

int findMax(const struct Node *head) {
    if (head == NULL) return 0;
    int maxVal = head->data;
    head = head->next;
    while (head) {
        if (head->data > maxVal) maxVal = head->data;
        head = head->next;
    }
    return maxVal;
}

int countOccurrences(const struct Node *head, int target) {
    int occurrences = 0;
    while (head) {
        if (head->data == target) occurrences++;
        head = head->next;
    }
    return occurrences;
}

Classic DSA Algorithm

11. Reversing a Linked List (Three-Pointer Algorithm)

Reversing a singly linked list is one of the most famous and essential technical interview questions in Computer Science. The task is to invert the direction of all next pointers so that the tail becomes the new head.

11.1 The Golden Three-Pointer Technique

To reverse the list in a single pass without extra memory allocation, we maintain three pointers:

  • prev: Points to the node preceding current (initialized to NULL).
  • current: Points to the node whose link is currently being reversed (initialized to head).
  • nextNode: Temporarily saves the remainder of the list before reversing the link.
The In-Place Iterative Reversal Algorithm
struct Node *reverseList(struct Node *head) {
    struct Node *prev = NULL;
    struct Node *current = head;
    struct Node *nextNode = NULL;

    while (current != NULL) {
        nextNode = current->next; /* Step 1: Stash next node address */
        current->next = prev;     /* Step 2: Invert current node's pointer */
        prev = current;           /* Step 3: Advance prev to current */
        current = nextNode;       /* Step 4: Advance current to stashed next */
    }

    head = prev; /* Step 5: prev is now pointing to the new head! */
    return head;
}
reverse_linked_list.c 
#include <stdio.h>
#include <stdlib.h>

struct Node {

Ring Topology

14. Circular Linked List (CLL: Loop & Termination)

What Is a Circular Linked List?

A Circular Linked List (CLL) is a variation where the last node does not point to NULL; instead, its next pointer points directly back to the head node, forming a closed ring. 

head → [ 10 | • ] → [ 20 | • ] → [ 30 | • ] └
         ↑                                    ┐
         └───────────────────────────────┐

14.1 The Infinite Loop Hazard

NEVER USE `while (current != NULL)` ON A CIRCULAR LIST!

Because there is no NULL in a circular list, writing while (current != NULL) causes an infinite loop that locks up your application!

14.2 The Safe do-while Traversal Pattern

Always use a do ... while (current != head); loop to ensure you visit each node exactly once and stop when you loop back to the start:

circular_linked_list_demo.c 
#include <stdio.h>
#include <stdlib.h>

struct CNode {
    int data;
    struct CNode *next;
};

struct CNode *createCNode(int val) {
    struct CNode *n = malloc(sizeof *n);
    if (n) { n->data = val; n->next = NULL; }
    return n;
}

void printCircularList(const struct CNode *head) {
    if (head == NULL) {
        printf("List is empty.\n");
        return;
    }

    const struct CNode *curr = head;
    printf("Circular Ring: ");
    do {
        printf("%d → ", curr->data);
        curr = curr->next;
    } while (curr != head);
    printf("(head)\n");
}

    /* Manually link 3 nodes in a circle */
    struct CNode *head = createCNode(10);
    head->next = createCNode(20);

    head->next->next->next = head; /* Circular link back to head */

    /* Safe deallocation */
    struct CNode *curr = head->next;
    while (curr != head) {
        struct CNode *temp = curr->next;
        free(curr);
        curr = temp;
    }
    free(head);
    head = NULL;

    return 0;
}

15. Real-Life Applications of Linked Lists

Linked lists are not mere academic exercises; they form the operational backbone of modern operating systems, multimedia players, and system runtimes:

15.1 Real-World Application Portfolio

  • A. Music Playlist Engines: Songs are nodes. In a Doubly Linked List, pressing "Next" follows next, pressing "Previous" follows prev, and enabling "Repeat All" links the tail to the head as a Circular DLL.
  • B. Web Browser History (Back/Forward Buttons): Visiting a new URL creates a node. Pressing the Back button traverses prev; pressing Forward traverses next. Navigating to a new URL prunes the forward branch.
  • C. Round-Robin CPU Task Scheduling: The operating system kernel maintains a Circular Linked List of active process threads. The CPU executes Process A for 10ms, follows the next link to Process B for 10ms, and continuously cycles without ever hitting a NULL end.
  • D. Undo / Redo Stacks in Text Editors: Keystrokes or edit commands are stored as linked nodes. Undoing walks backward along the history chain; redoing walks forward.
  • E. Dynamic Heap Memory Allocators (free-lists): The C standard library's malloc() implementation uses internal circular doubly linked lists (bins) to track free chunks of memory in RAM.

18. DSA Problem 1: Middle Node (Fast & Slow Pointers)

Problem Statement

Given the head of a singly linked list, find and return the middle node in a single traversal pass. If there are two middle nodes (even length), return the second middle node.

18.1 The Tortoise and the Hare Algorithm

Instead of counting nodes in a first pass and walking to \(\lfloor n/2 \rfloor\) in a second pass, we use two pointers running at different speeds:

  • slow (Tortoise): Advances 1 node per step.
  • fast (Hare): Advances 2 nodes per step.

When fast reaches the end of the list (or NULL), slow is guaranteed to be positioned precisely at the middle node!

middle_node.c 
#include <stdio.h>
#include <stdlib.h>

struct Node {
    int data;
    struct Node *next;
};

struct Node *createNode(int val) {
    struct Node *n = malloc(sizeof *n);
    if (n) { n->data = val; n->next = NULL; }
    return n;
}

struct Node *findMiddle(struct Node *head) {
    if (head == NULL) return NULL;

    struct Node *slow = head;
    struct Node *fast = head;

    while (fast != NULL && fast->next != NULL) {
        slow = slow->next;       /* 1 step */
        fast = fast->next->next; /* 2 steps */
    }

    return slow;
}

int main(void) {
    /* Build list: 10 -> 20 -> 30 -> 40 -> 50 */
    struct Node *head = createNode(10);
    head->next = createNode(20);
    head->next->next = createNode(30);
    head->next->next->next = createNode(40);
    head->next->next->next->next = createNode(50);

    struct Node *mid = findMiddle(head);
    if (mid) {
        printf("Middle Node Data: %d\n", mid->data);
    }

    /* Clean up */
    while (head) {
        struct Node *t = head->next;
        free(head);
        head = t;
    }
    return 0;
}

19. DSA Problem 2: Cycle Detection & Removal (Floyd's Algorithm)

Problem Statement

Determine if a linked list contains a cycle (loop). If a cycle exists, identify the starting node of the cycle and break the loop safely so the list terminates with NULL.

19.1 Floyd's Cycle-Finding Algorithm

Advance slow by 1 step and fast by 2 steps.

  1. Detection: If fast == slow at any point, a cycle exists. If fast reaches NULL, no cycle exists.
  2. Find Loop Start: Keep fast at the meeting point. Reset slow = head. Move both slow and fast by 1 step simultaneously. The node where they meet again is the exact starting node of the cycle!
  3. Break Cycle: Find the node whose next points to the loop start, and set its next = NULL.
cycle_detection.c 
#include <stdio.h>
#include <stdlib.h>

struct Node {
    int data;
    struct Node *next;
};

struct Node *createNode(int val) {
    struct Node *n = malloc(sizeof *n);
    if (n) { n->data = val; n->next = NULL; }
    return n;
}

int detectAndRemoveCycle(struct Node *head) {
    if (head == NULL || head->next == NULL) return 0;

    struct Node *slow = head;
    struct Node *fast = head;

    /* Step 1: Detect cycle */
    while (fast && fast->next) {
        slow = slow->next;
        fast = fast->next->next;
        if (slow == fast) break;
    }

    if (slow != fast) return 0; /* No cycle */

    /* Step 2: Find start of cycle */
    slow = head;
    if (slow == fast) {
        /* Edge case: loop starts at head */
        while (fast->next != slow) fast = fast->next;
    } else {
        while (slow->next != fast->next) {
            slow = slow->next;
            fast = fast->next;
        }
    }

    /* Step 3: Break the cycle */
    printf("Cycle detected at node %d! Breaking cycle...\n", fast->next->data);
    fast->next = NULL;
    return 1;
}

int main(void) {
    /* Build list: 1 -> 2 -> 3 -> 4 -> 5 -> loop back to 3 */
    struct Node *head = createNode(1);
    head->next = createNode(2);
    head->next->next = createNode(3);
    head->next->next->next = createNode(4);
    head->next->next->next->next = createNode(5);

    /* Create cycle: 5 -> 3 */
    head->next->next->next->next->next = head->next->next;

    int hadCycle = detectAndRemoveCycle(head);
    printf("Had cycle: %s\n", hadCycle ? "YES" : "NO");

    /* Verify list now terminates cleanly */
    printf("List after removal: ");
    struct Node *curr = head;
    while (curr) {
        printf("%d ", curr->data);
        curr = curr->next;
    }
    printf("NULL\n");

    /* Clean up */
    while (head) {
        struct Node *t = head->next;
        free(head);
        head = t;
    }
    return 0;
}

20. DSA Problem 3: N-th Node from End (Two-Pointer Gap)

Problem Statement

Find the \(N\)-th node from the end of a singly linked list in a single pass. For example, in 10 → 20 → 30 → 40 → 50, the 2nd node from the end is 40.

20.1 The Constant-Gap Two-Pointer Strategy

  1. Advance a pointer first by \(N\) steps from the head. If first hits NULL before \(N\) steps, the list has fewer than \(N\) nodes.
  2. Place a second pointer second at the head.
  3. Move both first and second forward 1 step at a time until first reaches NULL.
  4. second is now pointing directly to the \(N\)-th node from the end!
nth_from_end.c 
#include <stdio.h>
#include <stdlib.h>

struct Node {
    int data;
    struct Node *next;
};

struct Node *createNode(int val) {
    struct Node *n = malloc(sizeof *n);
    if (n) { n->data = val; n->next = NULL; }
    return n;
}

struct Node *findNthFromEnd(struct Node *head, int n) {
    if (head == NULL || n <= 0) return NULL;

    struct Node *first = head;
    struct Node *second = head;

    /* Move first pointer n steps ahead */
    for (int i = 0; i < n; i++) {
        if (first == NULL) return NULL; /* List too short */
        first = first->next;
    }

    /* Move both together until first reaches NULL */
    while (first != NULL) {
        first = first->next;
        second = second->next;
    }

    return second;
}

int main(void) {
    struct Node *head = createNode(10);
    head->next = createNode(20);
    head->next->next = createNode(30);
    head->next->next->next = createNode(40);
    head->next->next->next->next = createNode(50);

    int n = 2;
    struct Node *res = findNthFromEnd(head, n);
    if (res) printf("%dnd node from end is: %d\n", n, res->data);

    /* Clean up */
    while (head) {
        struct Node *t = head->next;
        free(head);
        head = t;
    }
    return 0;
}

21.1 Problem 4: Merge Two Sorted Linked Lists

Splice two sorted lists into one sorted list in-place in \(O(n + m)\) time and \(O(1)\) space: 

struct Node *mergeSorted(struct Node *l1, struct Node *l2) {
    if (!l1) return l2;
    if (!l2) return l1;

    struct Node dummy;
    struct Node *tail = &dummy;
    dummy.next = NULL;

    while (l1 && l2) {
        if (l1->data <= l2->data) {
            tail->next = l1;
            l1 = l1->next;
        } else {
            tail->next = l2;
            l2 = l2->next;
        }
        tail = tail->next;
    }
    tail->next = l1 ? l1 : l2;
    return dummy.next;
}

22. DSA Problem 9: Merge Sort on Linked List

Why is Merge Sort the gold standard for sorting linked lists?

  • QuickSort requires random access and suffers cache penalties on linked lists.
  • Merge Sort requires \(O(1)\) auxiliary memory on linked lists because merging nodes only requires rewiring pointers — no temporary auxiliary array is needed!
  • Guaranteed \(O(n \log n)\) time complexity in all cases.
merge_sort_list.c 
#include <stdio.h>
#include <stdlib.h>

struct Node {
    int data;
    struct Node *next;
};

struct Node *createNode(int val) {
    struct Node *n = malloc(sizeof *n);
    if (n) { n->data = val; n->next = NULL; }
    return n;
}

struct Node *merge(struct Node *a, struct Node *b) {
    if (!a) return b;
    if (!b) return a;
    struct Node *result = NULL;
    if (a->data <= b->data) {
        result = a;
        result->next = merge(a->next, b);
    } else {
        result = b;
        result->next = merge(a, b->next);
    }
    return result;
}

void splitList(struct Node *source, struct Node **frontRef, struct Node **backRef) {
    struct Node *fast = source->next;
    struct Node *slow = source;
    while (fast && fast->next) {
        slow = slow->next;
        fast = fast->next->next;
    }
    *frontRef = source;
    *backRef = slow->next;
    slow->next = NULL;
}

void mergeSort(struct Node **headRef) {
    struct Node *head = *headRef;
    if (!head || !head->next) return;

    struct Node *a = NULL;
    struct Node *b = NULL;

    splitList(head, &a, &b);
    mergeSort(&a);
    mergeSort(&b);

    *headRef = merge(a, b);
}

void printList(const struct Node *n) {
    while (n) { printf("%d ", n->data); n = n->next; }
    printf("\n");
}

int main(void) {
    /* Unsorted list: 42 -> 15 -> 88 -> 7 -> 23 */
    struct Node *head = createNode(42);
    head->next = createNode(15);
    head->next->next = createNode(88);
    head->next->next->next = createNode(7);
    head->next->next->next->next = createNode(23);

    printf("Unsorted: ");
    printList(head);

    mergeSort(&head);

    printf("Sorted:   ");
    printList(head);

Level 1: Beginner Fundamentals (8 Questions)

Q1: Define a linked list and describe its two primary components.
ANSWER

A linked list is a linear dynamic data structure composed of nodes. Each node contains a data field (stores value) and a link/pointer field (stores memory address of the next node).

Q2: Draw the conceptual pointer representation of a three-node list storing values 10, 20, and 30.
ANSWER 
head → [ 10 | • ] → [ 20 | • ] → [ 30 | NULL ]
Q3: What is the exact role of the head pointer?
ANSWER

head is a pointer variable storing the memory address of the first node. It serves as the single entry point for all traversal, insertion, and deletion operations.

Q4: Why does the last node of a singly linked list point to NULL?
ANSWER

NULL marks the termination of the list, signaling to traversal loops that there are no further nodes.

Q5: Predict the output of this traversal snippet:
while (curr != NULL) { printf("%d ", curr->data * 2); curr = curr->next; } on list [5 → 10 → 15].
OUTPUT 
10 20 30
Q6: Write a concise function to count the total number of nodes in a singly linked list.
CODE 
int countNodes(const struct Node *head) {
    int count = 0;
    while (head) { count++; head = head->next; }
    return count;
}
Q7: Why is prepending to a linked list \(O(1)\), but prepending to an array \(O(n)\)?
ANSWER

Prepending to a linked list only rewires two pointer addresses without moving existing nodes. An array must shift all \(n\) existing elements one memory slot to the right.

Q8: What happens if you forget to check if (newNode == NULL) after malloc()?
ANSWER

If the system runs out of memory, malloc() returns NULL. Dereferencing NULL->data causes an immediate, fatal Segmentation Fault crash.

Level 2: Intermediate Concepts (8 Questions)

Q9: Explain why the assignment order matters when prepending: newNode->next = head; head = newNode;.
ANSWER

Setting head = newNode; first overwrites the address of the existing list before saving it, stranding and leaking the entire list in memory.

Q10: Write the code to delete the first occurrence of a target value from a singly linked list.
CODE 
struct Node *deleteVal(struct Node *head, int target) {
    if (!head) return NULL;
    if (head->data == target) {
        struct Node *temp = head;
        head = head->next;
        free(temp);
        return head;
    }
    struct Node *curr = head;
    while (curr->next && curr->next->data != target) curr = curr->next;
    if (curr->next) {
        struct Node *temp = curr->next;
        curr->next = curr->next->next;
        free(temp);
    }
    return head;
}
Q11: What is the time complexity of searching an unsorted linked list vs. a sorted array?
ANSWER

Unsorted linked list search is \(O(n)\) (linear walk). Sorted array search is \(O(\log n)\) using binary search (which is impossible on a standard singly linked list due to lack of random access).

Q12: Trace the 3 pointers (prev, curr, nxt) during iterative reversal of a 2-node list 10 → 20.
TRACE

Init: prev=NULL, curr=10. Iter 1: nxt=20, 10->next=NULL, prev=10, curr=20. Iter 2: nxt=NULL, 20->next=10, prev=20, curr=NULL. Return prev (20). Result: 20 → 10 → NULL.

Q13: How does the Fast and Slow pointer algorithm locate the middle node in one pass?
ANSWER

Since the fast pointer advances twice as fast as the slow pointer, when the fast pointer reaches the end (\(n\)), the slow pointer is at \(\lfloor n/2 \rfloor\).

Q14: Compare Singly and Doubly Linked Lists regarding memory and deletion of a known node.
ANSWER

DLL uses an extra pointer per node. However, deleting a known node in a DLL is \(O(1)\) (using node->prev), whereas in a singly linked list it is \(O(n)\) to locate the predecessor.

Q15: Why does while (curr != NULL) cause an infinite loop on a circular linked list?
ANSWER

A circular list has no NULL pointer; the tail points back to the head. Traversal must stop when curr == head after the first iteration using a do-while loop.

Q16: Explain why single-node lists require special guards during tail deletion.
ANSWER

Because accessing curr->next->next when curr->next == NULL causes a fatal null-pointer dereference crash.

Level 3: Advanced & DSA Challenges (8 Questions)

Q17: Prove mathematically why Floyd's algorithm finds the start of a cycle when resetting one pointer to head.
PROOF

Let distance to cycle start be \(k\), meeting point inside cycle be \(m\), cycle length \(L\). Distance traveled: \(D_{slow} = k + m\), \(D_{fast} = k + m + nL\). Since fast travels twice slow: \(2(k+m) = k + m + nL \Rightarrow k = nL - m\). Moving slow from head (\(k\) steps) and fast from meeting point (\(k\) steps) meets exactly at cycle entrance!

Q18: How do you find the \(N\)-th node from the end in a single pass without extra memory?
ANSWER

Advance first by \(N\) nodes. Then advance first and second (from head) together until first == NULL. second is at the \(N\)-th node from end.

Q19: How do you merge two sorted linked lists in \(O(1)\) space?
ANSWER

Use a dummy head node. Compare l1->data and l2->data, attach the smaller node to tail->next, advance that list's pointer, and repeat.

Q20: How can you delete a node in \(O(1)\) time given only a pointer to that node (not tail)?
ANSWER

Copy the data from node->next into node, bypass node->next, and free node->next. This cannot delete the tail node because there is no successor data to copy.

Q21: Describe the optimal algorithm to check if a singly linked list is a palindrome in \(O(n)\) time and \(O(1)\) space.
ALGORITHM

1. Find middle node using fast/slow pointers. 2. Reverse the second half in-place. 3. Compare values of first half and reversed second half. 4. Restore original list order.

Q22: Why is Merge Sort preferred over QuickSort for linked lists?
ANSWER

Merge sort does not require random indexed access, merges in-place in \(O(1)\) auxiliary memory on lists, and guarantees \(O(n \log n)\) worst-case time.

Q23: How do you find the intersection node of two lists without hashing?
ANSWER

Count lengths \(L_1\) and \(L_2\). Advance the longer list's pointer by \(|L_1 - L_2|\). Then advance both pointers in lockstep until p1 == p2.

Q24: What is cache locality, and why do linked lists suffer compared to arrays?
ANSWER

Modern CPUs load contiguous 64-byte chunks (cache lines). Arrays allow the CPU to prefetch consecutive elements into L1/L2 cache. Linked-list nodes reside at scattered heap addresses, causing frequent CPU cache misses and RAM stalls.

playlist_manager.c 
#include <stdio.h>
#include <stdlib.h>
#include <string.h>

typedef struct Song {
    int id;
    char title[64];
    struct Song *prev;
    struct Song *next;
} Song;

typedef struct {
    Song *head;
    Song *tail;
    Song *currentSong;
    int songCount;
} Playlist;

Song *createSong(int id, const char *title) {
    Song *s = malloc(sizeof *s);
    if (!s) return NULL;
    s->id = id;
    strncpy(s->title, title, sizeof(s->title) - 1);
    s->title[sizeof(s->title) - 1] = '\0';
    s->prev = NULL;
    s->next = NULL;
    return s;
}

void addSong(Playlist *pl, int id, const char *title) {
    Song *s = createSong(id, title);
    if (!s) return;

    if (pl->head == NULL) {
        pl->head = s;
        pl->tail = s;
        pl->currentSong = s;
    } else {
        pl->tail->next = s;
        s->prev = pl->tail;
        pl->tail = s;
    }
    pl->songCount++;
    printf("Added: #%d - %s\n", id, title);
}

void displayPlaylist(const Playlist *pl) {
    printf("\n=== Current Playlist (%d Tracks) ===\n", pl->songCount);
    Song *curr = pl->head;
    while (curr) {
        if (curr == pl->currentSong) {
            printf(" → [PLAYING] #%d: %s\n", curr->id, curr->title);
        } else {
            printf("   #%d: %s\n", curr->id, curr->title);
        }
        curr = curr->next;
    }
    printf("=====================================\n");
}

void playNext(Playlist *pl) {
    if (pl->currentSong && pl->currentSong->next) {
        pl->currentSong = pl->currentSong->next;
        printf("Track Advanced → Now Playing: %s\n", pl->currentSong->title);
    } else {
        printf("Already at the last track!\n");
    }
}

void playPrevious(Playlist *pl) {
    if (pl->currentSong && pl->currentSong->prev) {
        pl->currentSong = pl->currentSong->prev;
        printf("Track Rewound ← Now Playing: %s\n", pl->currentSong->title);
    } else {
        printf("Already at the first track!\n");
    }
}

void freePlaylist(Playlist *pl) {
    Song *curr = pl->head;
    while (curr) {
        Song *temp = curr->next;
        free(curr);
        curr = temp;
    }
    pl->head = NULL;
    pl->tail = NULL;
    pl->currentSong = NULL;
    pl->songCount = 0;
}

int main(void) {
    Playlist myPlaylist = {NULL, NULL, NULL, 0};

    printf("==========================================\n");
    printf("       CODEVERSE MUSIC PLAYLIST ENGINE    \n");
    printf("==========================================\n");

    addSong(&myPlaylist, 101, "Bohemian Rhapsody");
    addSong(&myPlaylist, 102, "Stairway to Heaven");
    addSong(&myPlaylist, 103, "Hotel California");

    displayPlaylist(&myPlaylist);

    playNext(&myPlaylist);
    playNext(&myPlaylist);
    playPrevious(&myPlaylist);

    displayPlaylist(&myPlaylist);

    freePlaylist(&myPlaylist);
    printf("\nPlaylist memory cleanly released.\n");

    return 0;
}

12 High-Yield Technical Viva Questions

1. Why is a linked-list node called a self-referential structure?
VIVA ANSWER

Because it contains a pointer member that points to another instance of the exact same structure type (e.g. struct Node *next; inside struct Node).

2. What is the fundamental difference between an array and a linked list in RAM?
VIVA ANSWER

Array elements reside in contiguous, consecutive memory addresses. Linked-list nodes reside at scattered heap addresses connected solely by pointer references.

3. What happens if you reassign head = head->next; without a temporary pointer?
VIVA ANSWER

You lose the only reference to the original first node without freeing it, creating an instant memory leak.

4. Why is binary search impossible on a singly linked list?
VIVA ANSWER

Binary search requires constant-time \(O(1)\) random indexed access to evaluate the middle element, whereas accessing any index in a linked list requires linear \(O(n)\) traversal.

5. Explain the three-pointer reversal algorithm.
VIVA ANSWER

We maintain prev, curr, and nxt. Before inverting curr->next = prev, we save nxt = curr->next. We then advance prev = curr and curr = nxt until curr == NULL, returning prev as the new head.

6. What is the purpose of Floyd's Cycle Detection algorithm?
VIVA ANSWER

It uses slow (1 step) and fast (2 steps) pointers to detect whether a linked list contains an infinite cycle in \(O(n)\) time and \(O(1)\) memory.

7. Why is Merge Sort preferred over QuickSort for linked lists?
VIVA ANSWER

Merge sort does not require random access, merges lists in-place in \(O(1)\) auxiliary memory by rewiring pointers, and guarantees \(O(n \log n)\) time.

8. How does a Doubly Linked List simplify node deletion?
VIVA ANSWER

Given a pointer to a node in a DLL, we can access its predecessor immediately via node->prev, allowing \(O(1)\) deletion without searching from the head.

9. What loop structure is mandatory for traversing a circular linked list?
VIVA ANSWER

A do ... while (curr != head); loop is used so that the loop executes the first node and terminates when it loops back to the start.

10. What is the space complexity of reversing a linked list recursively?
VIVA ANSWER

\(O(n)\) auxiliary space due to the \(n\) call-stack frames required by the recursion.

11. Why do linked lists have poorer cache performance than arrays?
VIVA ANSWER

Because nodes are scattered non-contiguously in heap memory, causing frequent CPU cache line misses during sequential traversal.

12. Can you delete the tail node in \(O(1)\) time using only a pointer to that node in a singly linked list?
VIVA ANSWER

No. The data-copy trick requires copying data from the next node. Because the tail node has no next node, its predecessor's link cannot be set to NULL without traversal.
