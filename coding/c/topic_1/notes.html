01

What is C?

C LANGUAGE
In simple words: C is a general-purpose programming language used to write fast programs that talk closely to the computer.
Think of it as learning to drive a manual car: harder at first, but you understand how the machine really works.
  • Used to build operating systems, embedded software and system tools.
  • Teaches memory, data types and logic, the base of every language.
  • Languages like C++, Java and Python are influenced by C.
02

History of C

  • Dennis Ritchie created C at Bell Labs (USA).
  • Developed around 1969–1973, based on the earlier language B (Ken Thompson).
  • Used to rewrite the UNIX operating system, proving C could build an OS.
  • Standardised later as ANSI C (1989), then C99, C11 and C17.
Family line
BCPL → B → C → C++, Java, C#...
03

Why Was C Created?

Before C, system software was written in assembly: fast but hard to write and tied to one machine.

  • System programming: write an OS in a readable language.
  • Efficiency: run close to hardware speed.
  • Portability: same code works on many machines after recompiling.
  • Memory control: work directly with addresses and bytes.
💡 Real-life analogy

Assembly is like giving a driver every turn of the steering wheel. C is like saying "go to the station" while still letting you grab the wheel when needed.

04

Features of C

Format: Feature → Meaning → Where it helps

  • Simple: small set of keywords and clear syntax → easy to start.
  • Fast: compiles to machine code → games, OS kernels.
  • Efficient: uses little memory and CPU → embedded chips.
  • Portable: recompile on another system → one program, many platforms.
  • Structured: code is split into functions → easy to read and fix.
  • Procedural: programs run as steps and function calls → logic-first thinking.
  • Middle-level: mixes high-level and low-level power (next section).
  • Rich operators: arithmetic, logical, bitwise, etc. → powerful expressions.
  • Pointers: variables that store addresses → direct memory access, arrays, data structures.
  • Dynamic memory: malloc() and free() → size decided while running.
  • Recursion: a function can call itself → factorial, trees.
  • Extensible: add your own functions and libraries → reuse code.
  • Standard library: ready functions like printf(), strlen() → no need to rewrite basics.
05

Why is C a Middle-Level Language?

Position of C
High-Level Concepts
(functions, loops, arrays)
        ↑
        │
        C
        │
        ↓
Low-Level / System Concepts
(memory addresses, bits)
  • High-level side: readable English-like keywords, loops, functions.
  • Low-level side: pointers, bitwise operators, direct memory access.

So C is easier than assembly, yet gives more control than languages like Python.

06

Where is C Used?

  • Operating systems: Linux and Windows kernels are largely C.
  • Embedded systems and firmware: washing machines, routers, car ECUs.
  • Compilers: many compilers and interpreters are written in C.
  • Device drivers: connect hardware such as printers to the OS.
  • System software and networking: databases, servers, network tools.
  • Game engines/components: speed-critical parts.
  • IoT: small low-memory devices.
  • Performance-critical software: where every millisecond counts.
07

Advantages of C

  • Fast execution because it compiles to machine code.
  • Portable across systems.
  • Efficient memory use with full control.
  • Flexible: from tiny devices to large systems.
  • Hardware-level control via pointers and bits.
  • Huge ecosystem: libraries, tools, books, community.
  • Great foundation for learning C++, Java and more.
08

Limitations of C

  • Manual memory management: forgetting free() causes leaks.
  • No built-in OOP: no classes or objects.
  • Pointer complexity: powerful but confusing for beginners.
  • Less safety: no automatic array bounds checking.
  • More responsibility: the programmer handles details.
⚖️ Balanced view

C is not "bad" or "hard". It trades convenience for speed and control.

09

Your First C Program

C
#include <stdio.h>

int main() {
    printf("Hello, World!");
    return 0;
}
Output
Hello, World!

Line by line

  • #include: tells the preprocessor to bring in a header file.
  • <stdio.h>: standard input/output header; it contains printf().
  • int main(): starting point. Execution always begins here.
  • { }: braces mark the start and end of the function body.
  • printf(): prints text on the screen.
  • ;: ends a statement.
  • return 0;: tells the system the program ended successfully.
10

Basic Structure of a C Program

Structure
C Program
│
├── Preprocessor Directives
├── main() Function
├── Declarations
├── Statements
└── return statement
C
#include <stdio.h>        // preprocessor directive

int main() {              // main function
    int a = 10, b = 20;   // declarations
    int sum = a + b;      // statement
    printf("Sum = %d", sum);
    return 0;             // return statement
}
Output
Sum = 30
  • Preprocessor directives: lines starting with #.
  • main(): where execution starts.
  • Declarations: create variables.
  • Statements: instructions, each ending with ;.
  • return: sends a result back to the system.

How a C Program Runs

Compilation flow
C Source Code (.c)
      ↓
Preprocessor
      ↓
Compiler
      ↓
Object Code (.o)
      ↓
Linker
      ↓
Executable Program
      ↓
Output
  • Preprocessor: handles #include and similar lines.
  • Compiler: converts C into machine-level object code and reports errors.
  • Linker: joins your object code with library code like printf().
  • Executable: the final file you run.

Try it: gcc hello.c -o hello then run ./hello.

12

C vs Python (Basics)

❌ C

  • Syntax: braces, semicolons
  • Compiled before running
  • Static typing: int x = 5;
  • Manual memory control
  • Very fast
  • Steeper learning curve
  • Used for OS, embedded, drivers

✅ Python

  • Syntax: indentation, no semicolons
  • Interpreted line by line
  • Dynamic typing: x = 5
  • Automatic memory management
  • Slower, but quick to write
  • Gentle learning curve
  • Used for AI, web, scripting

Same task, two languages:

C
#include <stdio.h>
int main() {
    int x = 5;
    printf("%d", x * 2);
    return 0;
}
Output
10

Python: x = 5 then print(x * 2). Same result, fewer lines, less control.

Common Beginner Mistakes

❌ Wrong: Missing semicolon
C
#include <stdio.h>
int main() {
    printf("Hi")
    return 0;
}
✅ Correct: add ; after printf("Hi").

Problem: the compiler cannot see where the statement ends.

C
#include <stdio.h>
int main() {
    printf("Hi")
    return 0;
}
Expected Compiler Error
a.c:3:17: error: expected ‘;’ before ‘return’
❌ Wrong: Header missing or wrong
C
int main() {
    printf("Hi");
    return 0;
}
✅ Correct: write #include <stdio.h> at the top.

Problem: the compiler does not know printf.

❌ Wrong: Wrong main and missing braces
C
int main
    printf("Hi");
✅ Correct: int main() { ... } with matching braces.
❌ Wrong: Wrong printf syntax
C
printf(Hello);
✅ Correct: printf("Hello");

Text must be inside double quotes.

❌ Wrong: Forgetting return 0
C
int main() {
    printf("Hi");
}
✅ Correct: add return 0; at the end.

Modern compilers often allow it, but writing it is good practice.

14

Think Before You Code

  1. What problem am I solving?
  2. What input do I need?
  3. What output should appear?
  4. What steps are required?
  5. How will C represent this (variables, printf, operators)?
💡 Example

Problem: add two numbers. Input: 10, 20. Output: 30. Steps: store both, add, print. C: two int variables and one printf.

15

Key Takeaways

  • C is a general-purpose, middle-level, procedural language.
  • Created by Dennis Ritchie at Bell Labs in the early 1970s.
  • Strengths: speed, portability, memory control.
  • Weaknesses: manual memory, no OOP, less safety.
  • Execution starts at main().
  • Flow: source → preprocessor → compiler → linker → executable.
