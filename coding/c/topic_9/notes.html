01

Introduction to Functions

FUNCTION
A function is a named block of code that does one specific job. You write it once and can use it as many times as you want, just by calling its name. Every C program already has one function: main().
In simple words: a small machine. You give it input, it does the work, and may give back a result.
🍹 Real-life example

A mixer grinder: you put in fruits (input), press a button (call), and get juice (output). You do not rebuild the machine every time you want juice. A function is that machine.

Function concept
Inputvalues you give
↓
Functiondoes one job
↓
Outputresult you get
Write once, use many times.

Why do we need functions?

  • Reusability: write once, call many times.
  • Modular programming: split a big problem into small parts.
  • Easy to read and fix: each function has one clear job.

Without a function, we repeat code:

C
#include <stdio.h>

void welcome() {
    printf("Welcome to CodeVerse\n");
}

int main() {
    welcome();
    welcome();
    welcome();
    return 0;
}
Output
Welcome to CodeVerse
Welcome to CodeVerse
Welcome to CodeVerse
Key Idea

Functions make programs reusable and modular.

02

Function Structure

Working with a function has three parts:

Declaration → Definition → Call
1. Declarationtells C it exists
↓
2. Definitionthe actual code
↓
3. Calluse the function
Declare it, define it, then call it.
C
#include <stdio.h>

int add(int a, int b);        // 1. declaration (prototype)

int main() {
    int r = add(2, 3);        // 3. call
    printf("Sum = %d", r);
    return 0;
}

int add(int a, int b) {       // 2. definition
    return a + b;
}
Output
Sum = 5
  • Declaration: only the heading, ending with ;.
  • Definition: heading plus body { }.
  • Call: using the function inside main() or another function.

Function Syntax

C
return_type function_name(parameters) {
    // body
    return value;
}
Function anatomy
int add(int a, int b) {← return type, name, parameters
  int sum = a + b;← body
  return sum;← return statement
}← end of body
int = return typeadd = function name(int a, int b) = parameters{ } = body
The return type must match the value you return.
  • Return type: the kind of value the function gives back (int, float, or void for nothing).
  • Name: follows identifier rules.
  • Parameters: inputs written inside ( ).
  • Body: the code that runs.
  • return: sends a value back and ends the function.

Creating and Calling a Function

C
#include <stdio.h>

void greet() {
    printf("Hello from greet()\n");
}

int main() {
    printf("Start\n");
    greet();
    printf("End");
    return 0;
}
Output
Start
Hello from greet()
End
Call and return flow
1. main() startsprints Start
2. greet() calledcontrol jumps
3. Body runsprints Hello...
4. Return to main()continues after the call

Step by step

  1. Program starts in main() and prints "Start".
  2. greet(); is the call. Control jumps into greet().
  3. The body prints the greeting.
  4. The function ends, control returns to the line after the call.
  5. main() prints "End".
05

Parameters and Arguments

PARAMETER
A parameter is a variable written in the function definition. It receives the value sent to the function.
Like the empty slot in a form.
ARGUMENT
An argument is the actual value you pass when you call the function.
Like the data you write into that slot.
C
#include <stdio.h>

void showMarks(int marks) {      // marks = parameter
    printf("Marks: %d\n", marks);
}

int main() {
    showMarks(85);                // 85 = argument
    showMarks(72);
    return 0;
}
Output
Marks: 85
Marks: 72
Parameter vs argument
Parameterin the definition: int marks
Argumentin the call: showMarks(85)
  1. showMarks(85) is called with argument 85.
  2. 85 is copied into the parameter marks.
  3. The body prints it.
  4. Second call repeats with 72.
06

Return Values

RETURN VALUE
A return value is the result a function sends back to the place where it was called. The return statement sends the value and ends the function.
Like a shopkeeper handing you the item you asked for.
C
#include <stdio.h>

int square(int n) {
    return n * n;
}

int main() {
    int r = square(5);
    printf("%d\n", r);
    printf("%d", square(3) + 1);   // use inside an expression
    return 0;
}
Output
25
10
  • square(5) becomes 25 where it was called.
  • The returned value can be stored or used directly.

❌ void function

Returns nothing. Just does a job, like printing.

✅ Value-returning function

Returns a result you can store or use in calculations.

Practical: average of marks

C
#include <stdio.h>

float average(int a, int b, int c) {
    return (a + b + c) / 3.0;
}

int main() {
    printf("Average = %.2f", average(80, 70, 90));
    return 0;
}
Output
Average = 80.00

void Functions

VOID
void means "nothing". A void function does not give back any value.
Like a person who rings the bell and leaves without bringing anything back.
  • Use void for tasks like printing, showing a menu or displaying a bill.
  • You cannot store its result: int x = hello(); is wrong.
C
#include <stdio.h>

void printLine() {
    printf("--------\n");
}

int main() {
    printLine();
    printf("Report\n");
    printLine();
    return 0;
}
Output
--------
Report
--------

Function Prototype

FUNCTION PROTOTYPE
A prototype is a declaration placed before main(). It tells the compiler the function name, parameter types and return type, so the function can be called before its full definition appears.
Like a menu card that lists the dish before the kitchen cooks it.
C
int add(int a, int b);
C
#include <stdio.h>

int add(int a, int b);   // prototype

int main() {
    printf("%d", add(7, 8));
    return 0;
}

int add(int a, int b) {
    return a + b;
}
Output
15
  • Without it, calling a function defined later in the file can cause a warning or error.
  • Parameter names in a prototype are optional: int add(int, int);.
10

Declaration vs Definition vs Call

Three different things
Declarationint add(int a, int b);
Definitionint add(...) { return a+b; }
Calladd(2, 3);
  • Declaration: "this function exists" (no body, ends with ;).
  • Definition: "this is what it does" (has a body).
  • Call: "run it now" (uses arguments).
Key Idea

Declare it, define it once, call it as many times as needed.

11

Local Variables and Function Scope

LOCAL VARIABLE
A local variable is declared inside a function. It exists only while that function runs and can be used only inside it.
Like a note written inside your own notebook: other students cannot read it.
Local scope
main()int a = 10;
show()int b = 20;
a belongs only to main(), b only to show().
C
#include <stdio.h>

void show() {
    int b = 20;
    printf("b = %d\n", b);
}

int main() {
    int a = 10;
    show();
    printf("a = %d", a);
    return 0;
}
Output
b = 20
a = 10

Using b inside main() fails:

C
#include <stdio.h>

void show() {
    int b = 20;
}

int main() {
    show();
    printf("%d", b);
    return 0;
}
Expected Compiler Error
a.c:9:18: error: ‘b’ undeclared (first use in this function)

Each function has its own space. To share values, use parameters and return values.

12

Passing Values to Functions

PASS BY VALUE
In C, when you pass an argument, a copy of its value goes into the parameter. Changing the parameter inside the function does not change the original variable.
Like giving someone a photocopy of your notes: they can scribble on it, your original is safe.
C
#include <stdio.h>

void change(int x) {
    x = 50;
    printf("Inside: %d\n", x);
}

int main() {
    int a = 10;
    change(a);
    printf("Outside: %d", a);
    return 0;
}
Output
Inside: 50
Outside: 10
Copy, not original
a = 10original in main()
x = 10copy made in change()
x = 50only the copy changes
a is still 10original is safe
Key Idea

Functions work on copies of the values you pass.

13

Multiple Parameters

Separate parameters with commas. Arguments must come in the same order and same count.

C
#include <stdio.h>

int area(int length, int width) {
    return length * width;
}

int isPass(int marks, int passMark) {
    if (marks >= passMark) {
        return 1;
    }
    return 0;
}

int main() {
    printf("Area = %d\n", area(5, 4));
    printf("Pass? %d", isPass(62, 40));
    return 0;
}
Output
Area = 20
Pass? 1
  • area(5, 4): length = 5, width = 4.
  • isPass returns 1 for pass and 0 for fail.
14

Functions Calling Other Functions

CALLING A FUNCTION FROM A FUNCTION
One function can call another. The first one waits until the second finishes, then continues.
Like a manager asking an assistant to finish a part before continuing.
C
#include <stdio.h>

int tax(int amount) {
    return amount / 10;
}

int finalBill(int amount) {
    return amount + tax(amount);
}

int main() {
    printf("Bill = %d", finalBill(500));
    return 0;
}
Output
Bill = 550
Flow of execution
main()calls finalBill(500)
↓
finalBill()calls tax(500)
↓
tax()returns 50
↓
finalBill()returns 550
↓
main()prints 550
Each function returns to the one that called it.
  • Break big work into small functions.
  • Each function is easy to test and reuse.
15

Recursion: Basic Introduction

RECURSION
Recursion is when a function calls itself to solve a smaller version of the same problem. It must have a base condition, a case where it stops calling itself.
Like Russian nesting dolls: open one, find a smaller one, until the last doll.
C
#include <stdio.h>

int factorial(int n) {
    if (n == 0 || n == 1) {      // base condition
        return 1;
    }
    return n * factorial(n - 1); // recursive call
}

int main() {
    printf("%d", factorial(4));
    return 0;
}
Output
24
factorial(3) going down and coming back
factorial(3)3 × factorial(2)
factorial(2)2 × factorial(1)
factorial(1)base: returns 1
Answer1 → 2 → 6
  • Base condition stops the calls.
  • Each call works on a smaller number.
  • Without a base condition, calls never stop and the program crashes.
C
#include <stdio.h>

void countdown(int n) {
    if (n == 0) {
        return;
    }
    printf("%d ", n);
    countdown(n - 1);
}

int main() {
    countdown(3);
    return 0;
}
Output
3 2 1

Common Mistakes

1. Wrong number of arguments

C
#include <stdio.h>
int add(int a, int b) { return a + b; }
int main() {
    printf("%d", add(1, 2, 3));
    return 0;
}
Expected Compiler Error
a.c:4:18: error: too many arguments to function ‘add’

Fix: pass exactly as many arguments as parameters.

  • Missing prototype: call a later-defined function without declaring it first.
  • Wrong argument type: passing text to an int parameter.
  • Parameters vs arguments: parameters are in the definition, arguments in the call.
  • Forgot return: an int function with no return gives an unpredictable value.
  • Wrong return type: returning a decimal from an int function drops the decimal part.
  • void misuse: trying to store the result of a void function.
  • Definition vs call: writing int add(2, 3); instead of add(2, 3);.
  • Local variable access: using another function's variable directly.
  • No base condition: recursion that never stops.

Think Before You Code

  1. Can this code be reused as a function?
  2. What should the function do?
  3. Does it need parameters?
  4. Should it return a value?
  5. What should the return type be?
  6. What arguments should I pass?
  7. Where should the function be called?
  8. If using recursion, what is the base condition?

Key Takeaways

  • A function is a named, reusable block of code.
  • Declaration, definition and call are three different things.
  • Parameters are in the definition; arguments are in the call.
  • return sends a value back; void returns nothing.
  • Local variables live only inside their function.
  • C passes arguments by value (copies).
  • Recursion needs a base condition.

Definition→heading + body
Call→add(2, 3)
Parameter→variable in definition
Argument→value in call
Return→sends value back
void→returns nothing
Scope→local to the function
