🛠️ Section 03

Requirements for C Programming (Editor vs. Compiler)

To build and execute C programs on any computer, you need four core components working together. Beginners often confuse them, so let us distinguish each one clearly.

1. A Text Editor or IDE

Where you type human-readable C code. Examples include VS Code, Notepad++, Sublime Text, or dedicated IDEs like Code::Blocks or CLion. An editor is essentially a specialized text writing tool with syntax highlighting.

2. A C Compiler Toolchain

The engine that translates your text file into executable machine instructions. Examples include GCC (GNU Compiler Collection), Clang, or Microsoft's MSVC.

3. A Terminal or Command Prompt

A text-based command interface where you invoke the compiler and run your compiled application (e.g., Windows Command Prompt / PowerShell, or macOS/Linux Terminal).

4. A Host Computer Operating System

Windows, Linux, or macOS provides the memory, CPU execution environment, and standard C system libraries (libc) that your program interacts with.

The Most Common Beginner Misunderstanding: Editor ≠ Compiler!
Installing a code editor like Visual Studio Code does not automatically install a C compiler! VS Code is simply a text editor. If you install VS Code without configuring an underlying compiler like GCC, attempting to run C code will result in an error stating that no C compiler can be found. You must ensure a compiler toolchain is installed and accessible on your computer.

Toolchain Comparison Summary

ComponentRole in DevelopmentWhat It Does NOT DoExamples
Text Editor Editing source code text Cannot compile or run programs on its own VS Code, Notepad++, Sublime Text
C Compiler Translating .c code into CPU opcodes Has no graphical text editing window GCC (gcc), Clang (clang)
Command Terminal Running shell commands and launch binaries Does not write code or compile without tools PowerShell, Command Prompt, Bash
💻 Section 04

Setting Up C on Windows, Linux, and macOS

Follow these practical instructions to ensure you have a working C compiler available from your command line.

Windows Setup

1. Install MinGW-w64 (or MSYS2) which provides GCC for Windows.
2. Add the MinGW bin directory (e.g., C:\mingw64\bin) to your Windows System PATH environment variable.
3. Open Command Prompt or PowerShell and verify:

Command
gcc --version
Linux Setup

Linux distributions come developer-ready. Open your terminal and install the development toolchain:
Ubuntu / Debian:
sudo apt install build-essential
Fedora:
sudo dnf groupinstall "Development Tools"
Verify with:

Command
gcc --version
macOS Setup

On macOS, Clang is the standard C compiler provided directly by Apple.
1. Open Terminal and trigger the installation:
xcode-select --install
2. Follow the on-screen prompt to download the tools.
3. Verify with:

Command
clang --version

What a Successful Check Looks Like

When your compiler is properly installed and registered in your system PATH, typing gcc --version or clang --version prints details similar to this:

Terminal Verification Output
gcc (Rev2, Built by MSYS2 project) 13.2.0
Copyright (C) 2023 Free Software Foundation, Inc.
This is free software; see the source for copying conditions.  There is NO
warranty; not even for MERCHANTABILITY or FITNESS FOR A PARTICULAR PURPOSE.
What if you see "command not found"?
If your terminal outputs 'gcc' is not recognized as an internal or external command, it means either:
  • MinGW/GCC is not installed on your machine yet.
  • The compiler was installed, but its bin folder was not added to your operating system's PATH variable.
  • You added it to PATH, but have not restarted your terminal window for the change to take effect.

Creating Your First C Program (Hello World)

Now that you know what tools are required, let us inspect the complete source code of the classic Hello World program.

C Source Code • hello.c 
#include <stdio.h>

int main(void)
{
    printf("Hello, World!\n");
    return 0;
}
Expected Terminal Output
Hello, World!

Concise Line-by-Line Breakdown

LineCode SnippetWhat It Means
1 #include <stdio.h> Tells the preprocessor to include standard input/output declarations, enabling printf().
3 int main(void) The starting entry point of the program. int means it returns an integer; void means it takes no parameters.
4, 7 { and } Curly braces define the beginning and end of the function body.
5 printf("Hello, World!\n"); Calls the library function to display text. \n inserts a newline; ; terminates the statement.
6 return 0; Returns exit status code 0 to the operating system, confirming successful execution.
💾 Section 06

Saving the Source File & Directory Workflow

A program cannot be compiled until it is saved properly on your disk. Follow these exact steps to avoid the classic beginner pitfalls:

Step-by-Step Saving Guide
  1. Create a dedicated folder: Make a clean folder on your computer, such as C:\c_projects or ~/c_projects.
  2. Open your text editor: Open VS Code or your preferred editor and create a new empty file.
  3. Type the code: Enter the exact Hello World code from Section 5.
  4. Save as hello.c: Choose "Save As", navigate to your projects folder, and name the file strictly hello.c.
  5. Open terminal in that folder: Ensure your terminal’s current working directory matches where hello.c is saved.
Beware the Hidden ".txt" Extension Trap!

On Windows, text editors like Notepad often automatically append .txt to files. Your file might look like hello.c, but its real name on disk is hello.c.txt!

If you try to run gcc hello.c -o hello, GCC will report: fatal error: hello.c: No such file or directory. Always verify that the file extension is strictly .c.

⚙️ Section 07

Compiling and Running the Program (GCC & Clang)

With your source file saved, you are ready to command the compiler to transform your text into a runnable program.

1. Compiling with GCC

In your terminal, navigate to your folder and execute the compilation command:

Compilation Command (GCC)
gcc hello.c -o hello
Anatomy of the Compile Command:
  • gcc — Calls the GNU C Compiler.
  • hello.c — Specifies the input source file to be translated.
  • -o hello — Tells the compiler to name the resulting output executable hello (or hello.exe on Windows).

2. Running the Compiled Program

Once compilation completes with no errors, execute the binary depending on your operating system:

On Windows (Command Prompt / PowerShell):
Run Command
hello.exe
# OR:
.\hello.exe
On Linux or macOS (Terminal):
Run Command
./hello

Note: The ./ explicitly tells Unix-like shells to run the executable from the current directory.

3. Compiling with Clang (macOS / Linux alternative)

If you are using Clang on macOS or Linux, the syntax is identical:

Compilation Command (Clang)
clang hello.c -o hello
./hello
What happens if you omit -o hello?
If you simply type gcc hello.c without the -o flag, the compiler will still compile your program, but it will use a default output name:
  • On Windows: a.exe (run via .\a.exe)
  • On Linux/macOS: a.out (run via ./a.out)
Using -o name is always recommended so your executable has a clear, recognizable name.

🚧 Section 09

Common Errors and Troubleshooting Quick-Guide

When learning to compile C, errors are completely normal. Study this reference table to quickly identify the cause of an error and apply the exact fix.

Observed Problem / MessageRoot CausePractical Solution
'gcc' is not recognized or command not found Compiler is not installed or its directory is missing from the system PATH environment variable. Install MinGW-w64 (Windows) or build-essential (Linux) and add its bin folder to PATH; restart terminal.
fatal error: hello.c: No such file or directory Terminal is in a different directory, or the file was saved with an unintended name (like hello.c.txt). Use cd to navigate to the exact folder where the file is stored; verify the filename ends strictly in .c.
error: expected ';' before 'return' A statement is missing its mandatory semicolon terminator. Add a semicolon (;) at the end of the preceding line (e.g., after printf(...)).
error: expected '}' at end of input Mismatched or missing closing curly brace in the function body. Ensure every opening brace { has an exactly matching closing brace }.
undefined reference to 'Printf' Misspelled printf with a capital 'P'. C is case-sensitive. Change Printf to lowercase printf.
hello: command not found (on Linux/macOS) Running hello instead of ./hello. Prepend ./ to instruct the shell to run the executable from the current directory: ./hello.
Output appears on the same line without spacing Forgot to include the \n escape sequence. Add \n inside the string literal: printf("Hello!\n");.
Compilation Error vs. Execution Command Error:
Always distinguish between an error during compilation (the compiler rejects your C code syntax) and an error running the executable (the compiler succeeded, but you typed the wrong command or path in your terminal). If gcc finishes silently with no output messages, compilation succeeded!

5 Quick Self-Assessment Questions

Q1: Does installing Visual Studio Code give you a working C compiler?

Answer: No. VS Code is a text editor, not a compiler. You must install a compiler toolchain like MinGW-w64 (GCC) or Clang separately and configure your system PATH.

Q2: What is the purpose of the -o flag in gcc hello.c -o hello?

Answer: The -o flag specifies the custom output filename for the generated executable binary (e.g. hello or hello.exe) instead of the default a.out or a.exe.

Q3: Why do Linux and macOS terminals require ./ before running an executable?

Answer: For security reasons, Unix-like operating systems do not include the current working directory in the system search PATH by default. Prepending ./ explicitly tells the shell to execute the binary located in the current folder.

Q4: What does \n do when placed inside a printf() string?

Answer: \n is an escape sequence that prints a newline (line feed), moving the terminal output cursor to the beginning of the next row.

Q5: What happens if you forget to include a semicolon at the end of a statement?

Answer: The compiler will fail with a syntax error (e.g. expected ';' before '...'), and no executable program will be generated.
