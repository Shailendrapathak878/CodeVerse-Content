What Do We Need to Write C Programs?

  • Source code: the C program you type, saved in a file.
  • Compiler: a tool that converts your code into something the computer can run.
  • Code editor / IDE: the app where you type the code.
  • Terminal / Command Prompt: a text window where you type commands.
💡 Analogy

You write a recipe in English (source code). A translator (compiler) converts it into the chef's language (machine code). The chef (computer) then cooks it (runs it).

02

The C Compiler

COMPILER
A compiler converts your C code into a form the computer can execute.
Like a translator turning English into machine language.
  • A computer cannot read C directly. It only understands machine code (0s and 1s).
  • The compiler also finds mistakes and shows error messages.

Popular C compilers

  • GCC: free, very popular, works on Linux, macOS and Windows.
  • Clang: modern compiler with clear error messages.
  • MSVC: Microsoft's compiler, comes with Visual Studio.
03

Code Editor vs IDE vs Compiler

  • Code editor: only for typing and editing code. Example: VS Code.
  • IDE: editor + compiler + run button + debugger in one app. Examples: Code::Blocks, Visual Studio.
  • Compiler: the translator. It is a separate tool (an IDE just includes one).
⚠️ Important

Installing VS Code alone does not let you run C. VS Code is an editor; you must still install a compiler like GCC.

Your First C Program

C
#include <stdio.h>

int main() {
    printf("Hello, World!");
    return 0;
}
Output
Hello, World!
Remember

Every C program starts running from main().

07

First Program: Line by Line

First program, annotated
#include <stdio.h>← Header file
int main() {← main() function
  printf("Hello, World!");← Statement
  return 0;← Return
}← Closing brace
{ } = body of main()"Hello, World!" = stringprintf() = print; = end of statement
Read it top to bottom: include → main → print → return.
  • #include <stdio.h>: brings in the standard input/output header file. It contains the code for printf(). Without it, the compiler will not know printf.
  • int main(): the starting point. The computer always begins here. int means main gives back a whole number when it finishes.
  • { }: braces hold everything that belongs to main().
  • printf(): prints text on the screen. "f" stands for "formatted".
  • "Hello, World!": a string, meaning text inside double quotes.
  • ;: ends a statement, like a full stop in English.
  • return 0;: tells the system "everything went fine".
⚠️ Common Mistake

Using single quotes 'Hello' for text. Strings need double quotes.

What Happens When You Compile?

Compilation flow

↓
Preprocessorhandles #include
↓
Compilerconverts C code
↓
Object Codehello.o
↓
Linkerjoins library code
↓

GCC does all these stages for you in one command.
  • Preprocessor: pastes in the header file you included.
  • Compiler: checks your code and makes object code.
  • Linker: adds the ready-made printf() code.
  • Result: one runnable file, the executable.
11

Compiling with GCC

Terminal
gcc hello.c -o hello
  • gcc: the compiler.
  • hello.c: your source file.
  • -o hello: name the output (executable) hello.

Now run the executable:

Terminal
./hello
Output
Hello, World!
  • ./ means "in this folder" (Linux/macOS).
  • On Windows, the executable ends with .exe: run hello.exe or .\hello.
Remember

Source file (hello.c) → compile → executable (hello) → run → output.

12

Common Setup Problems

  • "gcc is not recognized" / "command not found": the compiler is not installed, or its folder is not in PATH. Reinstall and restart the terminal.
  • Compiler not installed: gcc --version shows an error instead of a version.
  • Wrong extension: hello.txt instead of hello.c. Rename it.
  • Wrong folder: run the command in the folder where hello.c is saved.

Compilation error vs runtime problem

❌ Compilation error

Found before running, by the compiler. Example: missing semicolon. No executable is created.

✅ Runtime problem

Happens while the program runs. The program compiled but behaves wrongly or crashes.

13

Common First-Program Mistakes

C is case-sensitive: printf and Printf are different.

❌ Wrong: Missing semicolon
C
printf("Hello")
✅ Correct: printf("Hello");

Problem: the compiler cannot see where the statement ends.

C
#include <stdio.h>
int main() {
    printf("Hello")
    return 0;
}
Expected Compiler Error
a.c:3:20: error: expected ‘;’ before ‘return’
❌ Wrong: Wrong case: Printf
C
Printf("Hello");
✅ Correct: printf("Hello");

Why: C treats uppercase and lowercase as different names.

C
#include <stdio.h>
int main() {
    Printf("Hello");
    return 0;
}
Expected Compiler Error
a.c:(.text+0x18): undefined reference to `Printf'
❌ Wrong: Wrong main or missing braces
C
int main
    printf("Hello");
✅ Correct: int main() { ... }

Why: main needs () and a body between { }.

❌ Wrong: Incorrect include
C
#include stdio.h
#include <stdio>
✅ Correct: #include <stdio.h>

Why: the header name is stdio.h and needs angle brackets.

15

A Simple Debugging Mindset

  1. Read the error message.
  2. Find the line number.
  3. Check spelling and case.
  4. Check semicolons.
  5. Check braces { }.
  6. Check the header files.
  7. Compile again.
Sample compiler message
hello.c:4:19: error: expected ';' before 'return'
  • hello.c:4 means file hello.c, line 4.
  • The real mistake is often on the line before the one reported.
🌱 Tip

Don't panic at errors. Every programmer sees them every day. Errors are how the compiler helps you.
