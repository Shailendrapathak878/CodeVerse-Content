01

Introduction to Loops

LOOP
A loop is a statement that repeats a block of code again and again, as long as a condition stays true. It saves us from writing the same lines many times. Each repetition is called an iteration.
In simple words: "keep doing this until I say stop".
🏫 Real-life example

A teacher calls out the roll number of every student in class: 1, 2, 3, ... until the last one. The same action (calling a name) repeats, only the number changes. A loop does exactly this.

Without a loop, printing 1 to 5 needs five lines:

C
#include <stdio.h>

int main() {
    printf("1 ");
    printf("2 ");
    printf("3 ");
    printf("4 ");
    printf("5 ");
    return 0;
}
Output
1 2 3 4 5

Imagine doing that for 1000 numbers! A loop does it in a few lines.

Basic loop flow
Initializationstart value
↓
Conditiontrue or false?
↓
Bodywork to repeat
↓
Updatechange the counter
Initialization once, then Condition → Body → Update repeat until the condition is false.
Key Idea

A loop needs a start, a condition to continue, and a change that eventually makes the condition false.

02

The for Loop

FOR LOOP
A for loop repeats code a known number of times. It keeps initialization, condition and update together in one line, which makes it neat and easy to read.
In simple words: "start here, continue while this is true, and move forward like this".
🪜 Real-life example

Climbing stairs: start at step 1, keep going while you are below step 10, and move up one step each time.

C
for (initialization; condition; update) {
    // body
}
C
#include <stdio.h>

int main() {
    int i;
    for (i = 1; i <= 5; i++) {
        printf("%d ", i);
    }
    return 0;
}
Output
1 2 3 4 5
for loop execution
i = 1initialization (once)
↓
i <= 5 ?condition
True ↓
Bodyprintf("%d ", i)
↓
i++update
↺ back to the condition check
False ↓
Exit loopgo to next statement

Step by step

  1. i = 1 runs once.
  2. Check i <= 5: true, so print 1.
  3. i++ makes i = 2. Check again: print 2.
  4. This continues until i becomes 6.
  5. 6 <= 5 is false, so the loop stops.

Practical: bill for 5 products

C
#include <stdio.h>

int main() {
    int i, total = 0;
    for (i = 1; i <= 5; i++) {
        total = total + 100;   // each product costs 100
    }
    printf("Total bill = %d", total);
    return 0;
}
Output
Total bill = 500

Practical: table of 5

C
#include <stdio.h>

int main() {
    int i;
    for (i = 1; i <= 5; i++) {
        printf("5 x %d = %d\n", i, 5 * i);
    }
    return 0;
}
Output
5 x 1 = 5
5 x 2 = 10
5 x 3 = 15
5 x 4 = 20
5 x 5 = 25
Key Idea

Use for when you know how many times to repeat.

03

The while Loop

WHILE LOOP
A while loop checks the condition first. If it is true, the body runs, and then the condition is checked again. If it is false from the start, the body never runs.
In simple words: "while this is true, keep doing it".
🚰 Real-life example

Keep filling a bucket while it is not full. You check first, then pour.

C
while (condition) {
    // body
}
C
#include <stdio.h>

int main() {
    int n = 5;
    while (n >= 1) {
        printf("%d ", n);
        n--;
    }
    printf("Liftoff!");
    return 0;
}
Output
5 4 3 2 1 Liftoff!
while loop flow
n >= 1 ?checked first
True ↓
Bodyprint n
↓
n--update inside body
↺ back to the condition check
False ↓
Exit loopLiftoff!

Practical: count digits of 4521

C
#include <stdio.h>

int main() {
    int num = 4521, count = 0;
    while (num > 0) {
        num = num / 10;   // remove last digit
        count++;
    }
    printf("Digits = %d", count);
    return 0;
}
Output
Digits = 4
  • Use while when you do not know in advance how many repetitions are needed.
  • Remember to update the variable inside the body.
04

The do-while Loop

DO-WHILE LOOP
A do-while loop runs the body first and checks the condition afterwards. So the body always executes at least once, even if the condition is false.
In simple words: "do it once, then check if I should do it again".
🍽️ Real-life example

You taste a dish first, then decide if you want more. You always take at least one bite.

C
do {
    // body
} while (condition);   // note the semicolon
C
#include <stdio.h>

int main() {
    int i = 1;
    do {
        printf("%d ", i);
        i++;
    } while (i <= 3);
    return 0;
}
Output
1 2 3
do-while flow
Initializationi = 1
↓
Body + Updateprintf(...); i++
↓
Condition true?checked AFTER the body
True ↓
Repeat↺ back to Body
False ↓
Exit loopcontinue after loop
Body runs first, so it always executes at least once.

Condition is false from the start

C
#include <stdio.h>

int main() {
    int x = 10;
    do {
        printf("Runs once");
    } while (x < 5);
    return 0;
}
Output
Runs once
Key Idea

Use do-while when the task must happen at least once, like showing a menu.

05

for vs while vs do-while

❌ while / for

Condition is checked before the body. May run zero times.

✅ do-while

Condition is checked after the body. Runs at least once.

Same condition, different result:

C
#include <stdio.h>

int main() {
    int x = 10;
    while (x < 5) {
        printf("while ");
    }
    do {
        printf("do-while");
    } while (x < 5);
    return 0;
}
Output
do-while
  • for: known count (print 1 to 100).
  • while: repeat until something happens (digits of a number).
  • do-while: must run once (a menu, or a first attempt).

07

Nested Loops

NESTED LOOP
A nested loop is a loop placed inside another loop. For every single round of the outer loop, the inner loop runs completely from start to end.
In simple words: a loop inside a loop.
🕒 Real-life example

A clock: for each hour (outer), the minutes go from 0 to 59 (inner). The minute hand completes a full lap for every hour.

C
#include <stdio.h>

int main() {
    int i, j;
    for (i = 1; i <= 3; i++) {
        for (j = 1; j <= 2; j++) {
            printf("i=%d j=%d\n", i, j);
        }
    }
    return 0;
}
Output
i=1 j=1
i=1 j=2
i=2 j=1
i=2 j=2
i=3 j=1
i=3 j=2
Nested structure
Outer loop (i = 1..3)
Inner loop (j = 1..2)runs fully for every i
3 outer rounds × 2 inner rounds = 6 prints

Pattern: right triangle of stars

C
#include <stdio.h>

int main() {
    int i, j;
    for (i = 1; i <= 4; i++) {
        for (j = 1; j <= i; j++) {
            printf("* ");
        }
        printf("\n");
    }
    return 0;
}
Output
* 
* * 
* * * 
* * * *

Pattern: number triangle

C
#include <stdio.h>

int main() {
    int i, j;
    for (i = 1; i <= 4; i++) {
        for (j = 1; j <= i; j++) {
            printf("%d", j);
        }
        printf("\n");
    }
    return 0;
}
Output
1
12
123
1234
  • Outer loop controls the rows.
  • Inner loop controls what is printed in each row.
  • printf("\n") after the inner loop moves to the next row.

Multiple students: pass or fail

Marks of students 1 to 5 are 40, 50, 60, 70, 80 (calculated as 30 + 10 × student number). Pass mark is 50.

C
#include <stdio.h>

int main() {
    int s, marks, passed = 0;
    for (s = 1; s <= 5; s++) {
        marks = 30 + 10 * s;
        if (marks >= 50) {
            printf("Student %d: %d Pass\n", s, marks);
            passed++;
        } else {
            printf("Student %d: %d Fail\n", s, marks);
        }
    }
    printf("Passed = %d", passed);
    return 0;
}
Output
Student 1: 40 Fail
Student 2: 50 Pass
Student 3: 60 Pass
Student 4: 70 Pass
Student 5: 80 Pass
Passed = 4
Key Idea

Loop = repeat. if = decide. A counter variable = remember how many.

09

The break Statement

BREAK
The break statement stops the loop immediately and jumps to the first statement after it. The remaining iterations are skipped.
In simple words: "stop right now and leave the loop".
🔍 Real-life example

Searching for your keys in the house. Once you find them, you stop searching.

C
#include <stdio.h>

int main() {
    int i;
    for (i = 1; i <= 10; i++) {
        if (i == 4) {
            break;
        }
        printf("%d ", i);
    }
    printf("\nLoop ended at i = %d", i);
    return 0;
}
Output
1 2 3 
Loop ended at i = 4
break flow
Condition ok?normal check
True ↓
Body runscheck if(i == 4)
↓
break?if true, leave loop
↺ back to the condition check
False ↓
Exit loopnormal end

Practical: first multiple of 7 above 20

C
#include <stdio.h>

int main() {
    int i;
    for (i = 21; i <= 100; i++) {
        if (i % 7 == 0) {
            printf("First: %d", i);
            break;
        }
    }
    return 0;
}
Output
First: 21
  • Normal end: condition becomes false.
  • With break: loop ends early, even if the condition is still true.
10

The continue Statement

CONTINUE
The continue statement skips the rest of the current iteration and moves on to the next one. The loop itself does not stop.
In simple words: "skip this one, go to the next".
📋 Real-life example

Checking a list of students and skipping the absent ones, then going on to the next name.

C
#include <stdio.h>

int main() {
    int i;
    for (i = 1; i <= 5; i++) {
        if (i == 3) {
            continue;
        }
        printf("%d ", i);
    }
    return 0;
}
Output
1 2 4 5
break vs continue
breakstops the whole loop
continueskips only this round

Practical: print odd numbers only

C
#include <stdio.h>

int main() {
    int i;
    for (i = 1; i <= 9; i++) {
        if (i % 2 == 0) {
            continue;
        }
        printf("%d ", i);
    }
    return 0;
}
Output
1 3 5 7 9
  • break: exit the loop.
  • continue: jump to the update (for) or condition (while) and keep looping.
11

Infinite Loops

INFINITE LOOP
An infinite loop is a loop whose condition never becomes false, so it never stops by itself. The program keeps running until you force it to close.
In simple words: a loop with no exit.
C
int i = 1;
while (i <= 5) {
    printf("%d ", i);
    // i is never updated: loop never ends!
}
Common causes
No updatei never changes
Wrong conditionalways true, like while(1)
Wrong directioni-- when it should be i++

Sometimes an infinite loop is intentional, with a break to leave it:

C
#include <stdio.h>

int main() {
    int count = 0;
    while (1) {
        count++;
        printf("%d ", count);
        if (count == 3) {
            break;
        }
    }
    return 0;
}
Output
1 2 3
  • Always update the loop variable.
  • Check that the condition can become false.
  • If a program hangs, press Ctrl + C in the terminal.

Loop Conditions and Common Patterns

Counting and reverse counting

C
#include <stdio.h>

int main() {
    int i;
    for (i = 1; i <= 5; i++) printf("%d ", i);
    printf("\n");
    for (i = 5; i >= 1; i--) printf("%d ", i);
    return 0;
}
Output
1 2 3 4 5 
5 4 3 2 1

Sum of numbers 1 to 10

C
#include <stdio.h>

int main() {
    int i, sum = 0;
    for (i = 1; i <= 10; i++) {
        sum = sum + i;
    }
    printf("Sum = %d", sum);
    return 0;
}
Output
Sum = 55

Counting occurrences: even numbers from 1 to 20

C
#include <stdio.h>

int main() {
    int i, count = 0;
    for (i = 1; i <= 20; i++) {
        if (i % 2 == 0) count++;
    }
    printf("Even numbers = %d", count);
    return 0;
}
Output
Even numbers = 10

Maximum and minimum

Values are calculated as (i * 7) % 10 for i = 1 to 5, giving 7, 4, 1, 8, 5.

C
#include <stdio.h>

int main() {
    int i, v, max, min;
    max = min = 7;     // first value
    for (i = 1; i <= 5; i++) {
        v = (i * 7) % 10;
        if (v > max) max = v;
        if (v < min) min = v;
    }
    printf("Max = %d, Min = %d", max, min);
    return 0;
}
Output
Max = 8, Min = 1
Pattern Tip

Sum/count: set the variable to 0 before the loop, then update it inside the loop.

Example: process 10 items and decide for each.

C
#include <stdio.h>

int main() {
    int i, big = 0, small = 0;
    for (i = 1; i <= 10; i++) {
        if (i > 5) {
            big++;
        } else {
            small++;
        }
    }
    printf("Big = %d, Small = %d", big, small);
    return 0;
}
Output
Big = 5, Small = 5

Example: eligible students. Age of student n is 15 + n, and voting age is 18.

C
#include <stdio.h>

int main() {
    int n, eligible = 0;
    for (n = 1; n <= 6; n++) {
        if (15 + n >= 18) {
            eligible++;
        }
    }
    printf("Eligible = %d", eligible);
    return 0;
}
Output
Eligible = 4

Common Mistakes

1. Semicolon after the loop

C
#include <stdio.h>

int main() {
    int i;
    for (i = 0; i < 3; i++);
    {
        printf("Hi ");
    }
    return 0;
}
Output
Hi

The ; makes the loop body empty. The block runs only once. Fix: remove the semicolon.

2. Off-by-one error

C
#include <stdio.h>

int main() {
    int i;
    for (i = 1; i < 5; i++) printf("%d ", i);   // wanted 1 to 5
    return 0;
}
Output
1 2 3 4

< stops before 5. Fix: use <=.

  • Forgot to update: while (i <= 5) without i++ never ends.
  • Wrong start value: starting at 0 when you wanted 1.
  • Wrong condition: i > 5 when you meant i <= 5: loop never runs.
  • break vs continue: break exits, continue skips.
  • do-while: it always runs once, even when the condition is false.
  • Nested loops: using the same variable i in both loops.
  • Condition in the wrong place: checking if outside the loop when it must be inside.

Key Takeaways

  • A loop repeats code while a condition is true.
  • for = known count, while = repeat until, do-while = at least once.
  • Every loop needs a start, a condition and an update.
  • break exits the loop, continue skips one round.
  • Nested loop: the inner loop completes for every outer round.
  • Watch out for infinite loops and off-by-one errors.
for→init; condition; update
while→check first
do-while→run first, check later
break→leave loop
continue→skip this round
Nested→loop inside loop
