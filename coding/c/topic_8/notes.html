01. Start from Zero: What Is a Loop?

Imagine you are asked to write your name on a sheet of paper 100 times. You would not invent 100 different ways to write your name; you would perform the exact same action over and over again until your count reached 100, and then you would put your pen down and stop.

📖 Formal Definition

In computer programming, a loop is a control-flow statement that allows a sequence of instructions to be executed repeatedly as long as a specified condition remains true (non-zero).

Computers excel at high-speed repetition. A human gets tired or makes clerical mistakes when repeating a task thousands of times, but a computer processor can repeat an arithmetic operation billions of times per second with absolute accuracy. Loops are the programmatic steering wheel that harness this immense computational power.

Repetition in Programming: Key Concepts

  • Repetition (Iteration): Executing the same block of code multiple times with potentially different input or state values.
  • Loop: The programming construct (such as while, for, or do-while) that controls and manages the repetitive execution.
  • Condition: The relational or logical test evaluated to decide whether the loop should continue running or terminate.
  • Iteration: A single, complete pass through the body of the loop. If a loop prints numbers from 1 to 5, it performs exactly 5 iterations.
💡 Real-Life Analogy 1: Roll-Call Attendance

Suppose a teacher stands in front of a classroom with 50 students to record morning attendance:

  • Initialization: The teacher starts at Roll Number 1.
  • Condition Check: Has the teacher reached past student number 50? If not, continue.
  • Loop Body (Action): Call the current student's name out loud and mark attendance.
  • Update: Move forward to the next roll number (roll = roll + 1).
  • Termination: Once Roll Number 50 is finished, the teacher stops calling names.

Note: This real-life process maps directly to how a computer evaluates a loop.

💡 Real-Life Analogy 2: Automatic Water Bottle Filling

An automated sensor-driven water dispenser places a nozzle inside a bottle and starts pumping water:

  • Condition: is_bottle_full == FALSE.
  • Loop Body: Keep pouring water into the bottle.
  • Update: The water level rises with every passing millisecond.
  • Termination: As soon as the optical sensor detects water touching the rim, the condition becomes false and the valve snaps shut immediately.

This is an example of an event-driven or condition-controlled loop where the exact number of seconds depends on how empty the bottle was initially.

💡 Real-Life Analogy 3: Daily Savings Piggy Bank

A student decides to save ₹50 every single day until their piggy bank reaches ₹1,000 for a new book:

  • Starting Balance: ₹0.
  • Condition: current_savings < 1000.
  • Action: Deposit ₹50 into the bank.
  • Update: current_savings += 50.
  • Termination: On Day 20, the balance hits ₹1,000. The saving goal is achieved, and the loop stops.

02. Why Do We Need Loops? (Manual vs. Loop Comparison)

To understand why loops are essential, let us look at what happens when we try to solve a repetitive problem without them.

Task: Print the Numbers 1 to 5 on Separate Lines

Approach A: Without a Loop (Repeated Statements)

manual_print.c
#include <stdio.h>

int main(void)
{
    printf("1\n");
    printf("2\n");
    printf("3\n");
    printf("4\n");
    printf("5\n");

    return 0;
}
Exact Expected Output:
1 2 3 4 5

Now imagine if your boss, client, or teacher asked you to print numbers from 1 to 1,000 or from 1 to 1,000,000. Writing 1,000 lines of printf statements would:

  • Take hours of tedious typing and clutter your source code.
  • Bloat the compiled executable size significantly.
  • Make updating requirements (e.g., printing comma-separated or printing only evens) a maintenance nightmare.
  • Be completely impossible if the upper limit is decided by the user at runtime!

Approach B: With a Loop

Here is the exact same task solved elegantly using a C for loop:

loop_print.c
#include <stdio.h>

int main(void)
{
    for (int i = 1; i <= 5; i++)
    {
        printf("%d\n", i);
    }

    return 0;
}
Exact Expected Output:
1 2 3 4 5
✨ The Power of Scalability

If you need to change this program to print numbers from 1 to 1,000, you only modify a single character: change i <= 5 to i <= 1000. That is the beauty of automated repetition!

Summary of Loop Advantages

Dimension Without Loops With Loops
Lines of Code Grows proportionally with repetition count ($O(N)$ lines). Constant size ($O(1)$ lines), typically 3 to 5 lines.
Maintainability Editing a format requires modifying every individual line. Change the format once inside the loop body.
Flexibility Fixed strictly at compile-time. Cannot handle dynamic user limits. Can repeat based on variables, user inputs, or database queries.
Data Processing Cannot iterate through arrays, strings, or file buffers. Natural mechanism for processing arrays, strings, and data streams.

03. Understand the Main Parts of a Loop

👉 Visual Anatomy: The 4 Core Parts of Every C Loop
Figure 8.2: Tokenized decomposition of a C loop header and body.

Every correctly functioning loop in C relies on five conceptual milestones. Understanding these five pieces will prevent 99% of loop-related bugs:

  1. 1. Initialization: Setting up the initial starting state before the loop begins. Typically, this assigns an initial starting value to a loop control variable (counter).
  2. 2. Condition Check: A boolean expression evaluated to determine if the iteration should take place. In C, if this expression evaluates to non-zero (true), the loop body executes; if it evaluates to zero (false), the loop terminates.
  3. 3. Loop Body: The block of C statements enclosed within braces { ... } that performs the actual useful work during each iteration.
  4. 4. State Update (Increment / Decrement): Modifying the loop control variable after each pass. This brings the loop one step closer to making the condition false.
  5. 5. Termination: The exact moment when the condition evaluates to 0 (false), allowing control to exit the loop and move on to subsequent statements.

Code Trace of the 5 Components

Examine how these five components interact in a basic while loop:

anatomy_of_loop.c
#include <stdio.h>

int main(void)
{
    // 1. INITIALIZATION: Start counter at 1
    int i = 1;

    // 2. CONDITION: Keep looping as long as i <= 3 is true
    while (i <= 3)
    {
        // 3. LOOP BODY: The repetitive work
        printf("Current value of i: %d\n", i);

        // 4. UPDATE: Increment counter by 1
        i++;
    }

    // 5. TERMINATION REACHED: i is now 4 (4 <= 3 is false)
    printf("Loop finished! Final value of i is: %d\n", i);

    return 0;
}
Exact Expected Output:
Current value of i: 1 Current value of i: 2 Current value of i: 3 Loop finished! Final value of i is: 4
⚠️ Essential Architectural Concept

These 5 parts represent a mental model, not a rigid rigid syntax requirement. For instance, in a while loop, the update statement is placed explicitly inside the body block. In a for loop, initialization, condition, and update are declared neatly together in the header parentheses. In a do-while loop, the body executes first before the condition is ever checked.

04. The while Loop — Detailed Explanation

👉 Flowchart: The while Loop (Entry-Controlled)
Figure 8.3: Execution flowchart for pre-test while loop.

The while loop is an entry-controlled loop (also called a pre-test loop). This means C tests the condition before allowing execution of the loop body. If the condition is false right from the start, the loop body will not execute even once.

Syntax

while_syntax.c
while (condition)
{
    // Statements executed repeatedly as long as condition is true (non-zero)
    // Update statement (e.g., counter increment) MUST be included here!
}

How Execution Proceeds Step-by-Step

  1. The expression inside parentheses (condition) is evaluated.
  2. If the result is non-zero (true), program control enters the curly braces { ... } and executes all statements inside sequentially.
  3. When the closing brace } is reached, control immediately jumps back to the top and re-evaluates the condition.
  4. If the condition is zero (false), the entire loop body is skipped, and execution continues with the statement immediately following the closing brace.
⚠️ Zero-Execution Possibility

Because the condition is evaluated at the entry point, if the condition is initially false (e.g., int x = 10; while (x < 5)), the body is executed zero times.

while_print_1_to_5.c

{
    int i = 1;

    while (i <= 5)
    {

05. The for Loop — Detailed Explanation

👉 Flowchart: The for Loop (1-2-3-4 Sequence)
Figure 8.4: Four-phase execution sequence of a standard for loop.

The for loop is the most commonly used loop in C when the exact number of repetitions is known in advance or when managing counter-controlled sequences.

Syntax

for_syntax.c
for (initialization; condition; update)
{
    // Statements executed while condition is true
}

The 3 Header Expressions Explained

  • 1. Initialization (int i = 1;): Executed only once when the loop is first entered. Used to declare and set up the starting value of the counter.
  • 2. Condition (i <= 5;): Evaluated before every iteration. If non-zero (true), the loop body executes. If zero (false), the loop terminates immediately.
  • 3. Update (i++): Executed after the loop body completes, right before control jumps back to check the condition again.
💡 Roll-Call Exam Analogy for the 3 Header Parts

Think of a proctor in an examination hall:

  1. Initialization: Pick up test paper for Roll #1 (done only once at the start).
  2. Condition: Is Roll #1 $\le$ 30? Yes.
  3. Body: Hand the question paper to the student.
  4. Update: Move forward to the next desk (Roll #2). Check condition again.

{

    long long fact = 1; // 0! and 1! start at 1

    {
        fact *= i;
    }

    printf("Factorial of %d is: %lld\n", n, fact);

}

Factorial of 5 is: 120

06. The do-while Loop — Detailed Explanation

👉 Flowchart: The do-while Loop (Exit-Controlled)
Figure 8.5: Post-test do-while loop guaranteeing at least one execution.

The do-while loop is an exit-controlled loop (also called a post-test loop). In this construct, C executes the statements inside the body first and only evaluates the condition afterward.

🔑 Guaranteed At-Least-Once Execution

Because the test condition appears at the bottom of the loop body, a do-while loop is guaranteed to execute at least once, even if the condition evaluates to false on the very first evaluation!

Syntax

do_while_syntax.c
do
{
    // Statements executed at least once
    // Update statement must be present here
}
while (condition); // CRITICAL: Semicolon is mandatory here!
🚨 Mandatory Semicolon Warning

Notice the semicolon ; immediately following while (condition);. In standard C syntax, omitting this trailing semicolon results in a compile-time syntax error. Neither for nor while loops have a semicolon after their closing parentheses!

Example 1: Print 1 to 5 Using do-while

dowhile_1_to_5.c
#include <stdio.h>

int main(void)
{
    int i = 1;

    do
    {
        printf("%d\n", i);
        i++;
    }
    while (i <= 5);

    return 0;
}
Exact Expected Output:
1 2 3 4 5

Example 2: Demonstrating the At-Least-Once Execution Guarantee

Notice what happens when the starting variable is deliberately initialized so that the condition is false immediately:

dowhile_at_least_once.c
#include <stdio.h>

int main(void)
{
    int i = 10; // Note: 10 is already strictly greater than 5!

    do
    {
        printf("Body executed! Value of i is: %d\n", i);
        i++;
    }
    while (i <= 5); // 11 <= 5 evaluates to 0 (false)

    printf("Execution finished! Final value of i is: %d\n", i);

    return 0;
}
Exact Expected Output:
Body executed! Value of i is: 10 Execution finished! Final value of i is: 11

Step-by-step Trace: The body executed first without checking any condition, printing 10 and incrementing i to 11. Next, C tested 11 <= 5, found it to be 0 (false), and terminated the loop. In an ordinary while loop, this program would have printed nothing!

07. Comparing while, for, and do-while

👉 Architectural Comparison: while vs. for vs. do-while
Figure 8.6: Core behavioral differences between C iteration constructs.

Every problem that can be solved with a loop can theoretically be written using any of the three constructs. However, choosing the most appropriate loop makes your source code cleaner, more readable, and less error-prone.

Feature while Loop for Loop do-while Loop
Type Entry-controlled (Pre-test) Entry-controlled (Pre-test) Exit-controlled (Post-test)
Condition Checked At the very beginning, before each iteration At the beginning, after initialization or update At the very end, after body executes
Minimum Iterations 0 times (can be skipped completely) 0 times (can be skipped completely) 1 time (guaranteed execution)

🧭 The Golden Rule of Loop Selection
  • Know the exact repetition count? → Use a for loop.
  • Repeating until a condition changes dynamically? → Use a while loop.
  • Code must execute at least once before checking? → Use a do-while loop.

08. Increment and Decrement Inside Loops

The update step dictates how the loop progresses towards termination. In C, developers use a variety of update operators to control counter velocity and direction.

Common Update Expressions

  • i++ or ++i: Increments counter by 1 each iteration.
  • i-- or --i: Decrements counter by 1 each iteration.
  • i += 2: Steps forward by 2 (e.g., generating even or odd numbers).
  • i -= 5: Steps downward by 5 (e.g., countdowns).
  • i *= 2: Multiplies counter by 2 (e.g., powers of two: 1, 2, 4, 8, 16...).
  • i /= 10: Strips off the last decimal digit (e.g., digit-processing algorithms).

Ascending vs. Descending Loops

Direction C Code Pattern Condition Direction Sample Output
Ascending (Counting Up) for (int i = 1; i <= 5; i++) Uses <= or < 1 2 3 4 5
Descending (Counting Down) for (int i = 5; i >= 1; i--) Uses >= or > 5 4 3 2 1

Prefix vs. Postfix in Loop Headers: Clearing the Confusion

Beginners often wonder whether they should write i++ or ++i inside a for loop header.

💡 The Truth About i++ vs ++i in Loop Headers

In a standalone expression like the third part of a for loop header:

for (int i = 0; i < 5; i++)  vs  for (int i = 0; i < 5; ++i)

Both produce the exact same outcome! Because the return value of the increment expression is discarded in a standalone statement, C simply increments the variable i by 1 in both cases before the next condition check.

09. Infinite Loops, Traps & Off-by-One Bugs

An infinite loop occurs when a loop's terminating condition never becomes false (zero). When this happens, the program gets stuck repeating the loop body endlessly until the operating system runs out of resources, freezes, or the process is manually killed.

🚨 The Classic Infinite Loop Trap
// INTENTIONALLY INCORRECT CODE - DO NOT RUN
int i = 1;
while (i <= 5)
{
    printf("%d\n", i);
    // BUG: Missing i++; i remains 1 forever!
}

Why it fails: Because i is never incremented, 1 <= 5 remains true for all eternity. The console floods with infinite 1s and the CPU cores spike to 100%.

The Fix: Always ensure the loop body updates the variable controlling the condition: 

int i = 1;
while (i <= 5)
{
    printf("%d\n", i);
    i++; // Fixed: i advances towards termination
}

8 Common Loop Traps Beginners Face

# Bug / Trap Name Incorrect Code Example Beginner Expectation vs Reality Corrected Fix
1 Missing Update while (i <= 5) { printf("%d", i); } Expects 1 to 5. In reality, prints 1 infinitely. Add i++; inside the loop body.
2 Updating Wrong Variable for (int i=1; i<=5; j++) Expects i to increase. In reality, i stays 1 and j grows. Change j++ to i++ in header.
3 Off-by-One Error for (int i=1; i<5; i++) (wants 1 to 5) Expects 5 iterations. In reality, stops at 4 (4 < 5 is true, but 5 < 5 is false). Use i <= 5 or start from 0 with i < 5.
4 Wrong Starting Index int count = 0; while (count <= 10) Expects 10 iterations. In reality, executes 11 times (0 through 10). Start at 1 for 1 to 10, or use count < 10.
5 Premature Increment while (i <= 5) { i++; printf("%d", i); } Expects 1, 2, 3, 4, 5. In reality, prints 2, 3, 4, 5, 6. Place i++; after the printf call.
6 Stray Semicolon Trap while (i <= 5); { printf("%d", i); i++; } Expects normal loop. In reality, semicolon creates an empty body; spins infinitely on condition! Remove the stray semicolon ; after while(...).
7 Unsigned Underflow for (unsigned int i=5; i>=0; i--) Expects countdown to 0. In reality, when 0 decrements, unsigned wraps to 4,294,967,295! Use signed int i for countdowns to 0.
8 Accidental Empty for for (int i=1; i<=5; i++); { printf("*"); } Expects 5 stars. In reality, loop spins 5 times doing nothing, then prints a single star once! Remove the semicolon immediately after the closing paren.

10. Flow Control: break and continue

👉 Visual Flow: break vs. continue Jump Execution
Figure 8.7: Execution divergence: break terminates loop; continue advances to next iteration.

C provides two jump statements that give you precise control over the natural iteration sequence of any loop.

1. The break Statement: Immediate Loop Termination

When C encounters a break statement inside a loop, it immediately abandons the loop and transfers control to the statement directly following the loop's closing brace.

Program: Print 1 to 10 but Stop Prematurely at 5

break_demo.c
#include <stdio.h>

int main(void)
{
    for (int i = 1; i <= 10; i++)
    {
        if (i == 5)
        {
            printf("Found 5! Breaking out of loop.\n");
            break; // Abort loop immediately
        }
        printf("%d ", i);
    }
    printf("\nLoop ended cleanly.\n");

    return 0;
}
Exact Expected Output:
1 2 3 4 Found 5! Breaking out of loop. Loop ended cleanly.

2. The continue Statement: Skip to the Next Iteration

The continue statement does not terminate the loop. Instead, it skips the remaining statements in the current iteration and jumps directly to the beginning of the next cycle.

Program: Print 1 to 10 but Skip Number 5

continue_demo.c
#include <stdio.h>

int main(void)
{
    for (int i = 1; i <= 10; i++)
    {
        if (i == 5)
        {
            continue; // Skip printing 5, jump to update (i++)
        }
        printf("%d ", i);
    }
    printf("\n");

    return 0;
}
Exact Expected Output:
1 2 3 4 6 7 8 9 10
⚠️ The Critical Difference: continue in for vs while

This is one of the most frequently asked C exam and interview questions:

  • In a for loop: continue jumps directly to the update expression (i++). Therefore, i increases safely before checking the condition.
  • In a while loop: continue jumps directly to the condition check! If your update statement (i++) was written after the continue, it will be skipped entirely, creating an infinite loop! 
// BUGGY WHILE LOOP: Jumps over i++ into infinite loop!
int i = 1;
while (i <= 10)
{
    if (i == 5)
    {
        continue; // DANGER: i remains 5 forever!
    }
    printf("%d ", i);
    i++;
}

// CORRECT WHILE LOOP: Increment before continuing!
int i = 1;
while (i <= 10)
{
    if (i == 5)
    {
        i++; // Increment manually before jumping!
        continue;
    }
    printf("%d ", i);
    i++;
}

13. How to Dry-Run a Loop Manually (3 Solved Tables)

A dry-run (or manual code tracing) is the superpower that separates top engineers from confused beginners. It involves tracking the values of variables on a sheet of paper or spreadsheet line-by-line exactly as the CPU executes them.

The 8-Step Repeatable Tracing Methodology

  1. Step 1: List all variables involved (counters, accumulators, flags) and note their starting values.
  2. Step 2: Evaluate the loop condition with current variable values. Record whether it is True or False.
  3. Step 3: If False, skip the body and terminate the loop immediately.
  4. Step 4: If True, enter the loop body and execute statements line by line.
  5. Step 5: Write down any output printed to the screen.
  6. Step 6: Apply arithmetic updates (increment, decrement, summation).
  7. Step 7: Trace control moving back to the condition check.
  8. Step 8: Repeat steps 2 through 7 until the condition fails.

4 4 4 <= 4 → TRUE 4 4 + 1 = 5 5

14. Choosing the Right Loop & Problem-Solving Guide

How do seasoned software engineers instantly know whether to reach for a for, while, or do-while loop? They use this simple decision flowchart:

👉 The Loop Selection Decision Flowchart
Figure 8.9: Decision flowchart to choose the right loop construct for any programming problem.

How to Think Before Writing a Loop: The 6-Question Checklist

  1. What should repeat? Identify the exact statements that need to run multiple times.
  2. What variable changes? Identify the counter or state variable that tracks progress.
  3. What condition keeps it running? Determine the boundary condition (e.g., i <= n or num != 0).
  4. What ensures it stops? Verify that the update statement (i++, n /= 10) moves toward the exit boundary.
  5. What is the very first output? Verify output on iteration 1 (did you start at 0 or 1?).
  6. What is the very last output? Verify output on final iteration (did you stop one step early or late?).

16. Practice Questions and Exercises (3 Difficulty Levels)

Test your understanding by attempting these exercises. Click on any question to reveal the verified answer, dry run, and step-by-step reasoning.

Level 1: Beginner Fundamentals (10 Questions)

Q01: What is the exact output of: for (int i = 0; i < 3; i++) printf("%d ", i); ?
Output: 0 1 2

Reasoning: The loop starts at i = 0. It runs while i < 3. The printed values are 0, 1, and 2. When i becomes 3, 3 < 3 evaluates to false, and the loop stops immediately.

Q02: Which C loop is guaranteed to execute its body at least once?
Answer: The do-while loop

Reasoning: Because do-while is an exit-controlled loop, the condition is evaluated at the bottom after the body has already executed once.

Q03: How many times does this loop execute: int x = 5; while (x < 5) { x++; } ?
Answer: Exactly 0 times

Reasoning: Since x is initialized to 5, the condition 5 < 5 is false right from the start. As an entry-controlled loop, the body is completely bypassed.

Q04: What is the bug in: int c = 1; while (c <= 5); { printf("%d", c); c++; } ?
Bug: Stray semicolon after while header

Reasoning: The semicolon immediately following while (c <= 5); creates an empty loop body. Since c never increments inside the empty loop, the program hangs in an infinite loop evaluating 1 <= 5.

Q05: In a standard for (init; cond; update) loop, when does the update step execute?
Answer: At the end of each iteration, after the body statements run

Reasoning: The update occurs after the body statements finish normally, right before control jumps back to re-evaluate the condition.

Q06: What is the output of: int a = 1; while (a <= 3) { a++; printf("%d ", a); } ?
Output: 2 3 4

Reasoning: Because a++ occurs before printf, when a is initially 1, it becomes 2 and prints 2. On the 3rd iteration, a is 3, increments to 4, and prints 4.

Q07: What does the break statement do inside a loop?
Answer: Terminates the loop immediately

Reasoning: Control jumps out of the innermost enclosing loop to the first statement following the loop's closing brace.

Q08: What does the continue statement do inside a loop?
Answer: Skips the remaining statements in current iteration

Reasoning: It abandons the rest of the current body and moves directly to the update step (in for) or condition test (in while).

Q09: What is an off-by-one error?
Answer: A boundary mistake causing a loop to run 1 time too many or 1 time too few

Reasoning: Commonly caused by confusing < with <=, or starting a counter at 0 instead of 1.

Q10: Is a semicolon required after the condition in a do-while loop?
Answer: Yes, mandatory

Reasoning: The syntax strictly requires: do { ... } while (condition);. Omitting it causes a compiler syntax error.

Level 2: Intermediate Challenges (10 Questions)

Q11: What is the output of: for (int i = 1; i <= 5; i++) { if (i == 3) continue; printf("%d ", i); } ?
Output: 1 2 4 5

Reasoning: When i == 3, continue triggers, skipping the printf statement and jumping directly to i++.

Q12: What happens if you run: int i = 1; while (i <= 5) { if (i == 3) continue; printf("%d ", i); i++; } ?
Result: Prints 1 2 and then freezes in an infinite loop!

Reasoning: In a while loop, continue jumps directly to the condition. When i == 3, it skips i++! Thus i remains 3 forever, creating an infinite loop.

Q13: How many total stars does this print: for (int r = 1; r <= 3; r++) for (int c = 1; c <= 4; c++) printf("*"); ?
Answer: Exactly 12 stars

Reasoning: Outer loop runs 3 times. For each outer run, inner loop runs 4 times. Total = $3 imes 4 = 12$.

Q14: What is the output of: for (int i = 10; i > 0; i -= 3) printf("%d ", i); ?
Output: 10 7 4 1

Reasoning: Values of i: 10 (valid), 7 (valid), 4 (valid), 1 (valid). Next is $1 - 3 = -2$, which fails -2 > 0.

Q15: What is the final value of sum: int sum = 0; for (int i = 1; i <= 4; i++) sum += i * 2; ?
Answer: 20

Reasoning: Sums $2 + 4 + 6 + 8 = 20$.

Q16: Can a for loop header omit all three expressions like for (;;)?
Answer: Yes, it creates an intentional infinite loop

Reasoning: In C, omitting the condition in for (;;) defaults to non-zero (true). It requires an internal break or return to terminate.

Q17: What is the output of: int x = 1; do { printf("%d ", x); } while (x-- > 1); ?
Output: 1

Reasoning: Body executes once, printing 1 . Condition tests x-- > 1 with old value 1 ($1 > 1$ is false). Loop terminates.

Q18: What is the value of count after: int n = 456, count = 0; while (n > 0) { count++; n /= 10; } ?
Answer: 3

Reasoning: Iteration 1: $n = 45, count = 1$. Iteration 2: $n = 4, count = 2$. Iteration 3: $n = 0, count = 3$. Loop exits.

Q19: What is the output of: for (int i = 0; i < 5; i++) { if (i > 2) break; printf("%d ", i); } ?
Output: 0 1 2

Reasoning: Prints 0, 1, 2. When i = 3, 3 > 2 is true, and break terminates the loop immediately.

Q20: Why is for (unsigned int i = 5; i >= 0; i--) dangerous?
Answer: It creates an infinite loop due to unsigned underflow

Reasoning: An unsigned int can never be negative. When i is 0 and decrements, it wraps around to the maximum unsigned integer ($4,294,967,295$), which is always $\ge 0$.

Top 5 Viva & Interview Questions

🎤 1. What is the fundamental difference between while and do-while?

A while loop evaluates its condition before executing the body, so it may execute 0 times. A do-while loop evaluates its condition after the body executes, guaranteeing at least 1 iteration.

🎤 2. What happens if you place a semicolon directly after a while loop header?

It creates an unintended empty loop body. The loop repeatedly tests the condition without executing the intended block, typically causing an infinite freeze if the condition was true.

🎤 3. How does continue behave differently in for vs while loops?

In a for loop, continue jumps directly to the update expression (e.g., i++). In a while loop, continue jumps directly to the condition, potentially skipping the counter update and triggering an infinite loop.

🎤 4. What is an iteration?

An iteration is a single, complete pass through the statements contained within the loop body.

🎤 5. Can a for loop have multiple initialization or update expressions?

Yes, C allows multiple comma-separated expressions in the initialization and update clauses: for (int i = 0, j = 10; i < j; i++, j--).

🌟 Final Beginner Takeaway

"A loop becomes easy when you track three things: the current state, the condition, and the update."
