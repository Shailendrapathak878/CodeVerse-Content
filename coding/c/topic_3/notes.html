What is the Structure of a C Program?

A C program is built from a few simple parts, always in a similar order.

C
#include <stdio.h>

int main() {
    printf("Hello, World!");
    return 0;
}
Output
Hello, World!
Program structure
Header#include <stdio.h>
↓
main() functionstarting point
↓
Statementsprintf(...);
↓
return statementreturn 0;
Header first, then main(), then statements, then return.
Remember

The computer reads from the top and starts running at main().

Look at the colours: each colour is one kind of part.
03

Basic C Program Structure

1. Preprocessor directive

C
#include <stdio.h>

A line starting with #. It tells C to bring in a ready-made header file before compiling.

2. Main function

C
int main()

The place where the program starts. Every C program needs exactly one main().

3. Function body

C
{
    ...
}

Braces hold everything that belongs to the function.

4. Statements

C
printf("Hello");

One instruction for the computer.

5. Return statement

C
return 0;

Ends main() and says the program finished fine.

04

What Does Syntax Mean?

SYNTAX
The rules for writing valid C code.
Like grammar in English: "I am going home" is correct; "going am home I" is not.

Correct:

C
printf("Hello");

Incorrect (missing semicolon):

C
printf("Hello")

The compiler cannot tell where the instruction ends, so it shows an error.

05

Statements

STATEMENT
One complete instruction in C.
int age = 20; or printf("Hello");
C
#include <stdio.h>
int main() {
    int age = 20;
    printf("Hello");
    return 0;
}
Output
Hello
  • Many statements end with ;.
  • Not every line needs one: #include lines and the int main() header do not end with a semicolon.
06

Semicolon ;

;
The statement terminator. It marks the end of a statement.
Like a full stop at the end of a sentence.

✅ Correct

C
#include <stdio.h>
int main() {
    int age = 20;
    return 0;
}

❌ Incorrect

C
#include <stdio.h>
int main() {
    int age = 20
    return 0;
}
Expected Compiler Error
a.c:4:5: error: expected ‘,’ or ‘;’ before ‘return’

The compiler says it expected ; before the next line. The mistake is on the line before the one it points to.

07

Blocks and Curly Braces { }

A block
int main() {
printf(...);statement 1
return 0;statement 2
}everything inside belongs to main()
  • { starts the block.
  • } ends the block.
  • Statements inside belong to that block.
  • Every { needs a matching }.
08

Comments in C

COMMENT
Notes for humans. The compiler ignores them.
// this adds numbers
C
#include <stdio.h>
int main() {
    // single-line comment
    /*
       multi-line
       comment
    */
    printf("Comments are ignored");   // prints a message
    return 0;
}
Output
Comments are ignored
  • Use // for one line, /* ... */ for many lines.
  • Programmers use comments to explain why code does something.
09

Identifiers

IDENTIFIER
A name we give to something in our program, such as a variable or function.
age, totalMarks, studentName, calculateSum
  • Can contain letters, digits and _.
  • Cannot start with a digit.
  • Cannot contain spaces.
  • Cannot be a keyword.
  • C is case-sensitive.
10

Valid and Invalid Identifiers

❌ Invalid

  • 2age: starts with digit
  • student name: has a space
  • total-marks: "-" not allowed
  • int: it is a keyword

✅ Valid

  • age
  • student_name
  • totalMarks
  • _marks
C
int main() {
    int 2age = 5;
    return 0;
}
Expected Compiler Error
a.c:2:9: error: invalid suffix "age" on integer constant

Keywords

KEYWORD
A reserved word with a special meaning in C.
int, char, if, else, for, while, return, void
Some keywords
intcharifelseforwhilereturnvoid
Reserved: you cannot use them as variable names.
C
int main() {
    int int = 5;
    return 0;
}
Expected Compiler Error
a.c:2:9: error: two or more data types in declaration specifiers
12

Case Sensitivity

C treats uppercase and lowercase letters as different.

C
#include <stdio.h>
int main() {
    int age = 20;
    int Age = 30;
    int AGE = 40;
    printf("%d %d %d", age, Age, AGE);
    return 0;
}
Output
20 30 40

age, Age and AGE are three different names. Likewise printf works but Printf does not.

C
#include <stdio.h>
int main() {
    Printf("Hi");
    return 0;
}
Expected Compiler Error
a.c:(.text+0x18): undefined reference to `Printf'

Functions: Basic Structure

C
return_type function_name(parameters) {
    // body
}
Function anatomy
Return typeint
↓
Function namemain
↓
Parameters() none here
↓
Body{ ... }
int main() { ... } follows exactly this shape.
  • Return type: what kind of value comes back.
  • Name: what we call the function.
  • Parameters: inputs inside ( ). Empty here.
  • Body: the code that runs.

main() is just a special function: the one that runs first.

16

Common Syntax Mistakes

❌ Wrong: Missing ;
C
printf("Hi")
✅ Correct: printf("Hi");

Problem: the compiler cannot find the end.

❌ Wrong: Missing { }
C
int main()
    return 0;
✅ Correct: int main() { return 0; }

Problem: function body must be inside braces.

❌ Wrong: Wrong capitalization
C
Printf("Hi");
✅ Correct: printf("Hi");

Problem: C is case-sensitive.

❌ Wrong: Keyword as variable name
C
int return = 5;
✅ Correct: int result = 5;

Problem: return is reserved.

❌ Wrong: Missing quotes
C
printf(Hello);
✅ Correct: printf("Hello");

Problem: text must be a string in double quotes.

❌ Wrong: Wrong include
C
#include stdio.h
✅ Correct: #include <stdio.h>

Problem: the header needs angle brackets.

❌ Wrong: Wrong main
C
int main
{ }
✅ Correct: int main() { }

Problem: main needs ( ).

17

A Complete Small Example

C
#include <stdio.h>

int main() {
    int age = 20;

    printf("Age: %d\n", age);

    return 0;
}
Output
Age: 20
Parts of this program
#include <stdio.h>← Header
int main() {← Main function
  int age = 20;← Declaration + assignment
  printf("Age: %d\n", age);← Function call
  return 0;← Return
}← Block ends
"Age: %d\n" = string%d = format specifier (prints an int); after each statement{ } = braces
%d is replaced by the value of age.

\n moves to a new line. More on format specifiers in a later chapter.
