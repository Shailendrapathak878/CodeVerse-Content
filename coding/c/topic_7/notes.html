01

A Simple Problem to Start

Before any definitions, look at this small program. Read it slowly.

C
int marks = 35;
printf("Result: Pass\n");
🤔 Think for a moment

What will this print if marks is 35? What if it is 85? What if it is 10?

It prints "Result: Pass" every single time. The program has no way to decide. A student with 35 marks would be told they passed, which is wrong.

Now let us give the program the power to decide.

Code
C
#include <stdio.h>

int main() {
    int marks = 35;

    if (marks >= 40) {
        printf("Result: Pass\n");
    } else {
        printf("Result: Fail\n");
    }
    return 0;
}
Output
Result: Fail
What happened?
  1. C checks the condition marks >= 40.
  2. 35 is not greater than or equal to 40, so the condition is false (0).
  3. Because it is false, C skips the if block and runs the else block instead.
  4. The program prints Result: Fail. Change marks to 85 and it prints Pass.
🎯 Why this chapter exists

Almost every useful program needs to make decisions: is the password correct, is the student eligible, is the bill big enough for a discount. In this chapter you will learn every tool C gives you for this: if, if-else, else if, nested if and switch.

🔑 Key Idea
A program without decisions does the same thing every time. Conditional statements let it choose what to do.
02

Introduction to Conditional Statements

CONDITIONAL STATEMENT
A conditional statement lets a program choose which instructions to run, based on a condition. The condition is an expression that is either true or false. If it is true, one set of instructions runs. If it is false, a different set runs, or nothing runs at all.
Also called: decision-making statements, selection statements. In C: if, if-else, else if, switch
🗣️ In Simple Words

A conditional statement is a fork in the road. The program looks at a condition, and then takes the path that matches the answer.

☔ Real-Life Example

"If it is raining, take an umbrella. Otherwise, wear sunglasses." You check one condition (raining?) and take one of two actions. You make this kind of decision many times a day, and a C program does it the same way.

Why do programs need decisions?

🔐
Login checkif the password is correct, allow entry
🎓
Exam resultif marks are 40 or more, the student passes
🛒
Discountif the bill is 1000 or more, give a discount
🏧
ATMif the balance is enough, give the cash
🚦
Traffic lightif the light is red, stop

How a condition gives true or false

A condition is usually a relational or logical expression from Topic 6. C represents true as 1 and false as 0. In a decision, C treats any non-zero value as true and 0 as false.

Diagram 1: Condition → Decision → Result
The condition gives true or false. The program follows the matching path.
Code
C
#include <stdio.h>

int main() {
    int age = 20;

    printf("%d\n", age >= 18);
    printf("%d\n", age < 18);
    return 0;
}
Output
1
0
What happened?
  • 20 >= 18 is true, so it gives 1.
  • 20 < 18 is false, so it gives 0.
  • A conditional statement uses exactly this 1 or 0 to choose a path.

The Conditional Statements in C

if
One-way decisiondo something, or do nothing
if-else
Two-way decisiondo one of two things
else if
Many-way decisionchoose one from several
nested if
Decision inside a decisioncheck a second condition after the first
switch
Menu-style decisionmatch one value against many cases
🔑 Key Idea
A condition is true (1) or false (0). The conditional statement uses it to choose which code runs.
03

if Statement

IF STATEMENT
The if statement runs a block of code only when a condition is true. If the condition is false, C skips the block and moves on to the next line after it. It is the simplest decision in C: do something, or do nothing.
Syntax: if (condition) { statements }
🗣️ In Simple Words

"If this is true, then do that." If it is not true, just carry on with the rest of the program.

🗳️ Real-Life Example

At a polling booth, if your age is 18 or more, you are allowed to vote. If not, nothing happens, and the next person in the queue is checked.

Syntax
if (condition) {
    // statements that run when the condition is true
}
Diagram 2: if Statement Flow
If the condition is false, the if block is skipped completely.
Code
C
#include <stdio.h>

int main() {
    int age = 20;

    if (age >= 18) {
        printf("You can vote.\n");
    }

    printf("Program ends.\n");
    return 0;
}
Output
You can vote.
Program ends.
Step-by-Step
  1. age is 20.
  2. C checks age >= 18. 20 ≥ 18 is true.
  3. So the block inside the braces runs and prints You can vote.
  4. After the block, the program continues and prints Program ends.

Now the same program with age = 15.

Code
C
int age = 15;

if (age >= 18) {
    printf("You can vote.\n");
}

printf("Program ends.\n");
Output
Program ends.
Step-by-Step
  1. 15 >= 18 is false.
  2. The if block is skipped. Nothing is printed for it.
  3. The program continues after the block and prints Program ends.
💡 Always use braces { }

Braces group the statements that belong to the if. If you leave them out, only the first single statement after the if belongs to it. Beginners should always write braces, even for one statement.

🔑 Key Idea
if runs its block only when the condition is true. When it is false, C skips the block and continues.
04

if-else Statement

IF-ELSE STATEMENT
The if-else statement chooses between two paths. If the condition is true, the if block runs. If the condition is false, the else block runs instead. Exactly one of the two blocks always runs, never both and never neither.
Syntax: if (condition) { ... } else { ... }
🗣️ In Simple Words

"If this is true, do A. Otherwise, do B." It is a two-way fork where you must take one road.

🎓 Real-Life Example

Result day at school: if marks are 40 or more, the result says Pass. Otherwise, it says Fail. Every student gets one of the two results.

Syntax
if (condition) {
    // runs when the condition is true
} else {
    // runs when the condition is false
}
Diagram 3: if-else Flow
Exactly one block runs. Then both paths meet and the program continues.
Code
C
#include <stdio.h>

int main() {
    int number = 7;

    if (number % 2 == 0) {
        printf("%d is Even\n", number);
    } else {
        printf("%d is Odd\n", number);
    }
    return 0;
}
Output
7 is Odd
Step-by-Step
  1. number % 2 is 7 % 2 = 1.
  2. 1 == 0 is false.
  3. The if block is skipped, and the else block runs.
  4. The program prints 7 is Odd.

Difference between if and if-else

if

Runs a block when the condition is true. When false, nothing happens.

int age = 15;
if (age >= 18) {
    printf("Eligible\n");
}
// prints nothing for age 15

if-else

Always does one of two things. When false, the else block runs.

int age = 15;
if (age >= 18) {
    printf("Eligible\n");
} else {
    printf("Not eligible\n");
}
// prints: Not eligible
Another example: discount eligibility
C
#include <stdio.h>

int main() {
    int bill = 1200;

    if (bill >= 1000) {
        printf("Discount applied.\n");
    } else {
        printf("No discount.\n");
    }
    return 0;
}
Output
Discount applied.
Step-by-Step
  1. 1200 >= 1000 is true.
  2. The if block runs. The else block is skipped.
🔑 Key Idea
if = do something or nothing. if-else = do one of two things. Only one block ever runs.
05

if-else if-else Ladder

IF-ELSE IF-ELSE LADDER
The else-if ladder is used when there are more than two possible outcomes. C checks the conditions one by one from the top. As soon as one condition is true, its block runs and all the remaining conditions are skipped. The final else catches everything that matched nothing above.
Syntax: if (...) { } else if (...) { } else if (...) { } else { }
🗣️ In Simple Words

It is a ladder of questions. C climbs down from the top, asks each question in turn, and stops at the first "yes".

🎓 Real-Life Example

A report card gives a grade from marks: 90 or more is A, 75 or more is B, 60 or more is C, and so on. One student gets exactly one grade, even though several ranges might seem to fit.

Syntax
if (condition1) {
    // runs if condition1 is true
} else if (condition2) {
    // runs if condition1 is false and condition2 is true
} else if (condition3) {
    // runs if the ones above are false and condition3 is true
} else {
    // runs if none of the conditions is true
}
Diagram 4: The else-if Ladder
Checked from the top. The first true condition wins and the rest are skipped.
Code: grades
C
#include <stdio.h>

int main() {
    int marks = 82;

    if (marks >= 90) {
        printf("Grade: A\n");
    } else if (marks >= 75) {
        printf("Grade: B\n");
    } else if (marks >= 60) {
        printf("Grade: C\n");
    } else if (marks >= 40) {
        printf("Grade: D\n");
    } else {
        printf("Grade: Fail\n");
    }
    return 0;
}
Output
Grade: B
Step-by-Step
  1. marks >= 90: 82 ≥ 90 is false. Go to the next condition.
  2. marks >= 75: 82 ≥ 75 is true. Print Grade: B.
  3. The rest of the ladder (>= 60, >= 40 and else) is skipped, even though 82 is also ≥ 60.
Why?

Only the first true condition runs. That is why the order matters: you must check the highest range first.

Code: electricity bill category
C
#include <stdio.h>

int main() {
    int units = 230;

    if (units <= 100) {
        printf("Low usage\n");
    } else if (units <= 300) {
        printf("Medium usage\n");
    } else {
        printf("High usage\n");
    }
    return 0;
}
Output
Medium usage
Step-by-Step
  1. 230 <= 100 is false.
  2. 230 <= 300 is true. Print Medium usage.
  3. The else is skipped.

Here we check the smallest range first, because the conditions use <=. The direction of the comparison decides which order is right.

⚠️ Ladder vs separate ifs

In a ladder, only one block ever runs. If you write separate if statements instead of else if, C checks every one, and several blocks can run.

🔑 Key Idea
An else-if ladder picks exactly one outcome from many. The first true condition wins, so put the conditions in the right order.
06

Nested if

NESTED IF
A nested if is an if statement placed inside another if or else block. The inner condition is checked only if the outer condition allows it. It is used when a second decision depends on the result of the first.
Syntax: if (outer) { if (inner) { ... } }
🗣️ In Simple Words

It is a decision inside a decision, like passing through two gates. You reach the second gate only after you pass the first.

🏧 Real-Life Example

At an ATM: first the machine checks whether the card is valid. Only then does it ask for your PIN. If the card is invalid, the PIN question is never asked.

Syntax
if (outer_condition) {
    if (inner_condition) {
        // both conditions are true
    } else {
        // outer is true, inner is false
    }
} else {
    // outer condition is false
}
Diagram 5: Nested if Structure
The inner box is reached only when the outer condition is true.
Code: voting with ID
C
#include <stdio.h>

int main() {
    int age = 20;
    int hasId = 0;

    if (age >= 18) {
        if (hasId == 1) {
            printf("You can vote.\n");
        } else {
            printf("Please bring your voter ID.\n");
        }
    } else {
        printf("You are too young to vote.\n");
    }
    return 0;
}
Output
Please bring your voter ID.
Step-by-Step
  1. Outer check: age >= 18 is 20 ≥ 18, which is true. Enter the outer block.
  2. Inner check: hasId == 1 is 0 == 1, which is false.
  3. The inner else runs and prints Please bring your voter ID.
  4. The outer else is skipped completely.
Why?

The person is old enough but has no ID. The outer condition passed, so the inner decision was needed.

Nested if vs else-if ladder

Nested if

A second question that is asked only after the first one is true. Used for dependent decisions.

else-if ladder

A list of alternatives for the same value. C picks exactly one. Used for ranges and categories.

💡 Keep it shallow

If both conditions must be true and nothing else happens, you can often replace a nested if with one &&. For example, if (age >= 18 && hasId == 1). Deeply nested code is hard to read.

🔑 Key Idea
Nested if = a decision inside another decision. The inner one is checked only when the outer condition is true.
07

Multiple Conditions

MULTIPLE CONDITIONS
Real decisions often depend on more than one condition. We combine conditions using the logical operators && (AND), || (OR) and ! (NOT). Each smaller condition is usually a relational expression such as age >= 18.
Examples: age >= 18 && age <= 65   day == 6 || day == 7   !(marks >= 40)
🗣️ In Simple Words

Use && when all conditions must be true. Use || when at least one must be true. Use ! to flip a condition.

🚗 Real-Life Example

To get a driving licence you must be at least 18 AND at most 65. Both rules must hold. To get a free weekend ticket, the day must be Saturday OR Sunday. Either one is enough.

&&
AND: all must be trueage >= 18 && marks >= 40
||
OR: at least one trueday == 6 || day == 7
!
NOT: flips the result!(age >= 18) means age < 18
Diagram 6: Two Conditions Joined by &&
AND is true only when both sides are true.
Code: range check with &&
C
#include <stdio.h>

int main() {
    int age = 70;

    if (age >= 18 && age <= 65) {
        printf("Eligible for a licence.\n");
    } else {
        printf("Not eligible for a licence.\n");
    }
    return 0;
}
Output
Not eligible for a licence.
Step-by-Step
  1. age >= 18: 70 ≥ 18 is true (1).
  2. age <= 65: 70 ≤ 65 is false (0).
  3. 1 && 0 is 0, because AND needs both to be true.
  4. The condition is false, so the else block runs.
Code: either condition with ||
C
#include <stdio.h>

int main() {
    int day = 6;       // 1 = Monday ... 7 = Sunday

    if (day == 6 || day == 7) {
        printf("Weekend\n");
    } else {
        printf("Weekday\n");
    }
    return 0;
}
Output
Weekend
Step-by-Step
  1. day == 6: 6 == 6 is true (1).
  2. Since OR needs only one true side, the whole condition is true. C does not even need to check day == 7.
  3. The if block runs and prints Weekend.
Code: combining && and ||
C
#include <stdio.h>

int main() {
    int total = 800;
    int isMember = 1;

    if (total >= 1000 || (isMember == 1 && total >= 500)) {
        printf("Discount applied.\n");
    } else {
        printf("No discount.\n");
    }
    return 0;
}
Output
Discount applied.
Step-by-Step
  1. Brackets first: isMember == 1 && total >= 500 is 1 && (800 ≥ 500) = 1 && 1 = 1.
  2. total >= 1000: 800 ≥ 1000 is 0.
  3. Now 0 || 1 is 1, so the condition is true.
  4. The shop gives a discount: either the bill is big, or the customer is a member with a bill of at least 500.
Why?

The brackets make the rule clear. Remember from Topic 6 that && is worked out before ||, so brackets also protect you from precedence surprises.

⚠️ Write each comparison in full

Mathematics lets you write 18 <= age <= 65. In C that does not work as you expect. Always write two comparisons joined by &&: age >= 18 && age <= 65.

🔑 Key Idea
Join conditions with && (all true), || (any true) and ! (flip). Use brackets to make the grouping clear.
08

Conditions with Characters

CHARACTER CONDITIONS
A char variable holds a single character such as 'A', 'e' or '7'. Characters are written in single quotes. Because every character is stored as a number code (you saw 'A' = 65 in Topic 5), you can compare characters with == and with >= or <=, just like numbers.
Examples: ch == 'y'   ch >= 'A' && ch <= 'Z'
🗣️ In Simple Words

You can ask questions about letters in the same way as about numbers: "Is it the letter e?" or "Is it between A and Z?"

🔤 Real-Life Example

A form asks "Continue? (y/n)". The program checks whether the character typed is 'y' or 'n' and then decides what to do.

Code: vowel check
C
#include <stdio.h>

int main() {
    char ch = 'e';

    if (ch == 'a' || ch == 'e' || ch == 'i' || ch == 'o' || ch == 'u') {
        printf("%c is a vowel.\n", ch);
    } else {
        printf("%c is not a vowel.\n", ch);
    }
    return 0;
}
Output
e is a vowel.
Step-by-Step
  1. ch holds the character 'e'.
  2. ch == 'a' is false. C moves to the next part of the OR.
  3. ch == 'e' is true, so the whole OR condition is true.
  4. %c prints a character. The program prints e is a vowel.

This simple version checks lowercase vowels only.

Code: kind of character
C
#include <stdio.h>

int main() {
    char ch = 'G';

    if (ch >= 'A' && ch <= 'Z') {
        printf("%c is an uppercase letter.\n", ch);
    } else if (ch >= 'a' && ch <= 'z') {
        printf("%c is a lowercase letter.\n", ch);
    } else if (ch >= '0' && ch <= '9') {
        printf("%c is a digit.\n", ch);
    } else {
        printf("%c is a special character.\n", ch);
    }
    return 0;
}
Output
G is an uppercase letter.
Step-by-Step
  1. 'G' has code 71. The letters 'A' to 'Z' have codes 65 to 90 (on ASCII systems).
  2. ch >= 'A' is true and ch <= 'Z' is true, so the first condition is true.
  3. The program prints G is an uppercase letter. The rest of the ladder is skipped.
⚠️ Single quotes vs double quotes

'a' is one character. "a" is text (a string). Use single quotes when you compare a char. Comparing whole words such as "Pass" with == does not work in C. Comparing text comes in a later topic, so for now keep your conditions on numbers and single characters.

🔑 Key Idea
A char can be compared like a number. Write characters in single quotes: ch == 'y'.
09

switch Statement

SWITCH STATEMENT
The switch statement compares one value against a list of fixed choices called cases. When a case matches, C runs the code of that case. It is a neat alternative to a long else-if ladder when you are checking one variable against exact values, like a menu choice or a day number.
Syntax: switch (expression) { case value: ... break; default: ... }
🗣️ In Simple Words

A switch is like a menu board. You say your choice, and C jumps straight to the matching line.

🥤 Real-Life Example

A vending machine: press 1 for tea, 2 for coffee, 3 for milk. Each button number leads to one drink. Any other button gives an error message.

Syntax
switch (expression) {
    case value1:
        // statements
        break;
    case value2:
        // statements
        break;
    default:
        // statements when no case matches
}

The four parts

switch
The value to checkswitch (day) looks at day
case
One possible matchcase 3: runs if day is 3
break
Leave the switchstops C from running the next case
default
Nothing matchedlike the final else
Diagram 7: How switch Chooses
C compares day with each case and jumps to the matching one.
Code: day of the week
C
#include <stdio.h>

int main() {
    int day = 3;

    switch (day) {
        case 1: printf("Monday\n");    break;
        case 2: printf("Tuesday\n");   break;
        case 3: printf("Wednesday\n"); break;
        case 4: printf("Thursday\n");  break;
        case 5: printf("Friday\n");    break;
        case 6: printf("Saturday\n");  break;
        case 7: printf("Sunday\n");    break;
        default: printf("Invalid day\n");
    }
    return 0;
}
Output
Wednesday
Step-by-Step
  1. C looks at the value of day, which is 3.
  2. It compares 3 with case 1 and case 2. No match.
  3. case 3 matches, so C runs printf("Wednesday\n");
  4. The break makes C leave the switch. The program continues after the closing brace.
Code: simple calculator menu
C
#include <stdio.h>

int main() {
    int a = 12, b = 4;
    char op = '*';

    switch (op) {
        case '+':
            printf("%d\n", a + b);
            break;
        case '-':
            printf("%d\n", a - b);
            break;
        case '*':
            printf("%d\n", a * b);
            break;
        case '/':
            printf("%d\n", a / b);
            break;
        default:
            printf("Invalid operator\n");
    }
    return 0;
}
Output
48
Step-by-Step
  1. op holds the character '*'.
  2. C skips '+' and '-', and matches case '*'.
  3. It prints 12 * 4 = 48 and then break leaves the switch.
📏 Rules of switch
  • The expression must be an integer or a character (not a decimal such as 2.5).
  • Each case must be a fixed constant like 3 or 'A', not a variable.
  • Every case ends with a colon :
  • A case can only test equality. It cannot test ranges like marks >= 40.
  • No two cases can have the same value.
🔑 Key Idea
switch jumps to the case that matches the value. Use break to leave, and default for no match.
10

break in switch

BREAK IN SWITCH
The break statement inside a switch tells C to leave the switch immediately. Without it, C does not stop at the end of the matching case. It keeps running the code of the next cases one after another, until it reaches a break or the end of the switch. This behaviour is called fall-through.
Syntax: break;
🗣️ In Simple Words

break means "I am done here, get out of the switch." If you forget it, C keeps walking into the next case.

🚪 Real-Life Example

Think of a row of connected rooms with open doors. Once you enter room 2, you can walk straight into room 3, room 4 and so on. A break is a closed door at the end of each room.

With break

Code
C
#include <stdio.h>

int main() {
    int day = 2;

    switch (day) {
        case 2:
            printf("Tuesday\n");
            break;
        case 3:
            printf("Wednesday\n");
            break;
        default:
            printf("Invalid\n");
    }
    return 0;
}
Output
Tuesday
Step-by-Step
  1. day is 2, so case 2 matches.
  2. It prints Tuesday.
  3. break sends C out of the switch. Case 3 and default never run.

Without break: fall-through

Code
C
#include <stdio.h>

int main() {
    int day = 2;

    switch (day) {
        case 2:
            printf("Tuesday\n");
        case 3:
            printf("Wednesday\n");
        default:
            printf("Invalid\n");
    }
    return 0;
}
Output
Tuesday
Wednesday
Invalid
Step-by-Step
  1. case 2 matches and prints Tuesday.
  2. There is no break, so C falls through into case 3 and prints Wednesday.
  3. Still no break, so it falls into default and prints Invalid.
  4. The switch ends only because there is nothing left.
Why?

Once a case matches, C runs everything from that point down, until a break or the closing brace. A case label is only an entry point, not a wall.

Diagram 8: break vs Fall-Through
Without break, C keeps running into the next cases.

Fall-through used on purpose

Sometimes you want several cases to share the same code. Leaving out break between them is a neat trick for that.

Code: days in a month
C
#include <stdio.h>

int main() {
    int month = 4;

    switch (month) {
        case 1: case 3: case 5: case 7:
        case 8: case 10: case 12:
            printf("31 days\n");
            break;
        case 4: case 6: case 9: case 11:
            printf("30 days\n");
            break;
        case 2:
            printf("28 or 29 days\n");
            break;
        default:
            printf("Invalid month\n");
    }
    return 0;
}
Output
30 days
Step-by-Step
  1. month is 4. C jumps to case 4.
  2. Cases 4, 6, 9 and 11 are stacked together with no code between them, so they share one block.
  3. It prints 30 days, and then break leaves the switch.
⚠️ Accidental fall-through is a bug

Using fall-through on purpose, like the month example, is fine. Forgetting a break by mistake is one of the most common bugs in switch statements.

🔑 Key Idea
break ends a case. Without it, C falls through and runs the next cases too. End every case with break unless you want to share code.
11

default Case

DEFAULT CASE
The default case runs when none of the case values match the switch expression. It works like the final else in an if-else ladder. It is optional, but it is good practice to include it, so that unexpected values are handled.
Syntax: default: statements
🗣️ In Simple Words

default means "if nothing else matched, do this." It is the safety net of the switch.

🥤 Real-Life Example

A vending machine has buttons 1 to 3. If someone presses 9, the machine does not stay silent. It shows "Invalid choice". That message is the default case.

Code: menu with default
C
#include <stdio.h>

int main() {
    int choice = 9;

    switch (choice) {
        case 1:
            printf("Tea\n");
            break;
        case 2:
            printf("Coffee\n");
            break;
        case 3:
            printf("Milk\n");
            break;
        default:
            printf("Invalid choice\n");
    }
    return 0;
}
Output
Invalid choice
Step-by-Step
  1. choice is 9.
  2. It does not match case 1, 2 or 3.
  3. C jumps to default and prints Invalid choice.
  4. With choice = 2, default would be skipped and the output would be Coffee.
💡 Good to know
  • Put default at the end, where it is easiest to read.
  • A break is not needed after the last default, because the switch ends anyway.
  • If there is no default and nothing matches, the switch simply does nothing.
🔑 Key Idea
default handles every value that no case matched. Use it to catch invalid input.
12

switch vs if-else

Both switch and if-else make decisions. The skill is choosing the right one for the job.

✅ Use switch when

  • You compare one variable with exact values.
  • The values are whole numbers or characters.
  • It is a menu, a day number, a month or a choice.
switch (choice) {
    case 1: ... break;
    case 2: ... break;
}

✅ Use if-else when

  • You check ranges, such as marks >= 40.
  • You combine conditions with && and ||.
  • You compare decimals or different variables.
if (marks >= 75 && attendance >= 80) {
    ...
}
Which one fits?
switch
ATM menu: 1 balance, 2 deposit, 3 withdrawexact choices
switch
Day number 1 to 7 → day nameexact values
if-else
Marks → grade (90+, 75+, 60+ ...)ranges
if-else
Age between 18 and 65range with &&
if-else
Bill ≥ 1000 and membercombined conditions
💡 Simple Rule

Exact matches → switch. Ranges and combined conditions → if-else. When in doubt, if-else is always allowed. A switch is only a tidier way for exact values.

🔑 Key Idea
switch is for exact values of one variable. if-else can do everything else.

Conditional Operator Connection

In Topic 6 you met the conditional operator ?:. It is a one-line way of doing a simple if-else that picks between two values.

🗣️ In Simple Words

condition ? A : B means "if the condition is true, use A, otherwise use B." It is a mini if-else that gives back a value.

if-else (several lines)

int max;
if (a > b) {
    max = a;
} else {
    max = b;
}

Ternary (one line)

int max = (a > b) ? a : b;
Code
C
#include <stdio.h>

int main() {
    int a = 12, b = 20;

    int max1;
    if (a > b) {
        max1 = a;
    } else {
        max1 = b;
    }

    int max2 = (a > b) ? a : b;

    printf("if-else: %d\n", max1);
    printf("ternary: %d\n", max2);
    return 0;
}
Output
if-else: 20
ternary: 20
What happened?
  • a > b is 12 > 20, which is false.
  • Both versions choose b, which is 20.
  • The ternary gives the same result in a single line.

When is the ternary useful?

✅
Choosing one of two valuesdiscount = (bill >= 1000) ? 100 : 0
✅
A short message inside printfok ? "Pass" : "Fail"
❌
Many statements in each branchuse if-else
❌
Three or more outcomesuse an else-if ladder or switch
⚠️ Keep it simple

Avoid putting one ternary inside another. It becomes very hard to read. If the decision needs more than two outcomes, an else-if ladder is clearer.

🔑 Key Idea
The ternary operator is a short if-else for choosing between two values. For anything bigger, use if-else.

Real-Life Examples

Let us put the tools together in four realistic programs.

Example 1: Largest of Three Numbers

Code
C
#include <stdio.h>

int main() {
    int a = 15, b = 42, c = 27;

    if (a >= b && a >= c) {
        printf("Largest: %d\n", a);
    } else if (b >= a && b >= c) {
        printf("Largest: %d\n", b);
    } else {
        printf("Largest: %d\n", c);
    }
    return 0;
}
Output
Largest: 42
Step-by-Step
  1. a >= b is 15 ≥ 42, which is false. So a is not the largest.
  2. b >= a is true and b >= c is 42 ≥ 27, which is true. Both are true, so the condition is true.
  3. The program prints Largest: 42. The else is skipped.

Example 2: Discount Slabs

A shop gives 20% off on bills of 2000 or more, 10% off on bills of 1000 or more, and no discount otherwise.

Code
C
#include <stdio.h>

int main() {
    int total = 1500;
    int percent;

    if (total >= 2000) {
        percent = 20;
    } else if (total >= 1000) {
        percent = 10;
    } else {
        percent = 0;
    }

    int discount = total * percent / 100;

    printf("Discount: %d%%\n", percent);
    printf("You pay: %d\n", total - discount);
    return 0;
}
Output
Discount: 10%
You pay: 1350
Step-by-Step
  1. 1500 >= 2000 is false.
  2. 1500 >= 1000 is true, so percent becomes 10.
  3. discount = 1500 × 10 / 100 = 150.
  4. The customer pays 1500 - 150 = 1350.

Example 3: Leap Year

A year is a leap year if it is divisible by 4 and not by 100, or if it is divisible by 400.

Code
C
#include <stdio.h>

int main() {
    int year = 2024;

    if ((year % 4 == 0 && year % 100 != 0) || year % 400 == 0) {
        printf("%d is a leap year.\n", year);
    } else {
        printf("%d is not a leap year.\n", year);
    }
    return 0;
}
Output
2024 is a leap year.
Step-by-Step
  1. year % 4 == 0: 2024 % 4 = 0, so true.
  2. year % 100 != 0: 2024 % 100 = 24, so true.
  3. The bracket is true && true = true.
  4. An OR with a true side is true, so the year is a leap year.

Example 4: ATM Menu

Code
C
#include <stdio.h>

int main() {
    int choice = 2;

    printf("1. Check balance\n");
    printf("2. Deposit\n");
    printf("3. Withdraw\n");

    switch (choice) {
        case 1:
            printf("Your balance is shown here.\n");
            break;
        case 2:
            printf("Enter the amount to deposit.\n");
            break;
        case 3:
            printf("Enter the amount to withdraw.\n");
            break;
        default:
            printf("Invalid choice.\n");
    }
    return 0;
}
Output
1. Check balance
2. Deposit
3. Withdraw
Enter the amount to deposit.
Step-by-Step
  1. The menu is printed first.
  2. choice is 2, so case 2 matches.
  3. It prints the deposit message, and break leaves the switch.
  4. For choice = 7, the default case would print Invalid choice.
🔑 Key Idea
Real programs mix the tools: else-if for slabs, && and || for rules, and switch for menus.

Common Mistakes

❌ Mistake 1: Using = instead of ==
int x = 5;
if (x = 10) {
    printf("x is ten\n");
}
⚠️ Problem: x was 5, but the message prints
Output
x is ten
✅ Correct: use == to compare
if (x == 10) {
    printf("x is ten\n");   // not printed, because x is 5
}
Why: x = 10 stores 10 in x, and the value 10 is non-zero, so it counts as true. x == 10 only compares. Always use == inside conditions.
❌ Mistake 2: Forgetting braces for multiple statements
int marks = 30;
if (marks >= 40)
    printf("Pass\n");
    printf("Congratulations!\n");
⚠️ Problem: a failing student is congratulated
Output
Congratulations!
✅ Correct: use braces
if (marks >= 40) {
    printf("Pass\n");
    printf("Congratulations!\n");
}
Why: Without braces, only the first statement belongs to the if. The second line always runs. The indentation fools your eyes, but not the compiler.
❌ Mistake 3: Incorrect condition logic (wrong order in a ladder)
int marks = 92;
if (marks >= 40) {
    printf("Grade: D\n");
} else if (marks >= 90) {
    printf("Grade: A\n");
}
⚠️ Problem: a top student gets grade D
Output
Grade: D
✅ Correct: check the highest range first
if (marks >= 90) {
    printf("Grade: A\n");
} else if (marks >= 40) {
    printf("Grade: D\n");
}
Why: 92 is also at least 40, so the first condition wins and the ladder stops. Order your conditions so that the most specific or highest one comes first.
❌ Mistake 4: Using the wrong logical operator
int age = 10;
if (age < 12 && age > 60) {
    printf("Free ticket\n");
} else {
    printf("Full price\n");
}
⚠️ Problem: a child should get a free ticket
Output
Full price
✅ Correct: use || for "either"
if (age < 12 || age > 60) {
    printf("Free ticket\n");   // children or seniors
}
Why: No age can be below 12 and above 60 at the same time, so && is never true. When the rule says "this or that", use ||.
❌ Mistake 5: Forgetting break in switch
int day = 1;
switch (day) {
    case 1:
        printf("Monday\n");
    case 2:
        printf("Tuesday\n");
    default:
        printf("Invalid\n");
}
⚠️ Problem: three lines print instead of one
Output
Monday
Tuesday
Invalid
✅ Correct: end each case with break
case 1:
    printf("Monday\n");
    break;
Why: Without break, C falls through into the next cases. Make it a habit to write break; as soon as you write a case.
❌ Mistake 6: Incorrect case syntax

❌ Wrong

case 1;
case >= 40:
case marks:
case "A":
case 2:   // written twice

✅ Right

case 1:
// ranges: use if-else instead
case 5:         // constants only
case 'A':       // char in single quotes
case 2:         // each value once
Why: A case needs a colon, a fixed constant (a number or a single character), and a unique value. Ranges, variables and strings are not allowed. These mistakes cause compile errors.
❌ Mistake 7: Forgetting default when it is useful
int choice = 9;
switch (choice) {
    case 1: printf("Tea\n");    break;
    case 2: printf("Coffee\n"); break;
}
⚠️ Problem: the program is silent for a wrong choice
Output
(nothing is printed)
✅ Correct: add a default
    default: printf("Invalid choice\n");
Why: With no default, an unexpected value does nothing, and the user is left confused. A default message makes the program friendlier and easier to debug.
❌ Mistake 8: Confusing nested if and if-else if (misplaced else)
int x = 5, y = 0;
if (x > 3)
    if (y > 3)
        printf("Both are big\n");
else
    printf("x is small\n");
⚠️ Problem: x is 5, yet it says "x is small"
Output
x is small
✅ Correct: use braces to show which if the else belongs to
if (x > 3) {
    if (y > 3) {
        printf("Both are big\n");
    }
} else {
    printf("x is small\n");
}
Why: An else belongs to the nearest if. The indentation suggested otherwise, but the else attached to y > 3. Braces remove the doubt. Also remember: use nested if for a second question, and else if for alternatives.
❌ Mistake 9: Writing unnecessarily complicated conditions

❌ Confusing

if ((age >= 18) == 1 && !(marks < 40)) {
    printf("Eligible\n");
}

✅ Clear

if (age >= 18 && marks >= 40) {
    printf("Eligible\n");
}

❌ Needless nesting

if (age >= 18) {
    if (marks >= 40) {
        printf("Eligible\n");
    }
}

✅ One condition

if (age >= 18 && marks >= 40) {
    printf("Eligible\n");
}
Why: A condition is already true or false, so == 1 adds nothing. Prefer marks >= 40 over !(marks < 40). Short, direct conditions are easier to read and to get right.
❌ Mistake 10: Using switch where if-else is more appropriate

❌ Awkward

switch (age >= 18) {
    case 1: printf("Adult\n"); break;
    case 0: printf("Minor\n"); break;
}

✅ Natural

if (age >= 18) {
    printf("Adult\n");
} else {
    printf("Minor\n");
}
Why: A switch needs exact values. For a true/false condition or a range, if-else is simpler and clearer. Use switch for menus and fixed choices.
❌ Mistake 11: A stray semicolon after the if
int marks = 30;
if (marks >= 40);
{
    printf("Pass\n");
}
⚠️ Problem: marks is 30, yet it prints Pass
Output
Pass
✅ Correct: no semicolon after the condition
if (marks >= 40) {
    printf("Pass\n");
}
Why: The ; ends the if statement right there, as an empty action. The block below is then a separate block that always runs.

Think Before You Code

🧠 Think Before You Code

Before writing a decision, ask yourself:

  1. What is the decision? What should I check first?
  2. What should happen if the condition is true?
  3. What should happen if it is false? Is nothing OK, or do I need an else?
  4. Are there more than two outcomes? Then I need an else-if ladder or a switch.
  5. Do I need multiple conditions? Should I join them with && or ||?
  6. Does the order of my conditions matter?
  7. Should I use if-else or switch? Ranges mean if-else. Exact choices mean switch.
  8. Have I used == (not =), braces, break and default where needed?
Worked example: movie ticket price

A cinema gives free entry to children under 5 and to seniors above 60. Everyone else pays Rs. 100. Check a person aged 65.

  1. Decision? Is the ticket free or paid?
  2. If true? Print "Free ticket".
  3. If false? Print "Ticket: Rs. 100". So I need an else.
  4. More than two outcomes? No, only two. if-else is enough.
  5. Multiple conditions? Yes. Under 5 or above 60, so I use ||.
  6. Order? Not important here.
  7. if-else or switch? These are ranges, so if-else.
C
#include <stdio.h>

int main() {
    int age = 65;

    if (age < 5 || age > 60) {
        printf("Free ticket\n");
    } else {
        printf("Ticket: Rs. 100\n");
    }
    return 0;
}
Output
Free ticket

Mini Challenge

🎓 Challenge: Movie Ticket with Weekend Charge

The ticket price depends on age: below 12 pays 80, 12 to 59 pays 150, and 60 or above pays 100. On a weekend (day 6 or 7), add 20 to the price. Write a program for age 34 on day 6.

Stop here and think first. Which statements will you need? Then check the solution below.

Show Suggested Solution
C
#include <stdio.h>

int main() {
    int age = 34;
    int day = 6;
    int price;

    if (age < 12) {
        price = 80;
    } else if (age < 60) {
        price = 150;
    } else {
        price = 100;
    }

    if (day == 6 || day == 7) {
        price += 20;
    }

    printf("Ticket price: %d\n", price);
    return 0;
}
Expected output
Ticket price: 170

How it works: The ladder gives 150 for age 34 (34 < 12 is false, 34 < 60 is true). The second, separate if checks the day. Day 6 is a weekend, so 20 is added: 150 + 20 = 170.

Quick Revision

Conditional statement→Chooses which code runs, based on a condition
Condition→An expression that is true (non-zero) or false (0)
if→Runs a block only when the condition is true
if-else→Runs one of two blocks. Exactly one always runs
else if ladder→Many outcomes. The first true condition wins
Nested if→A decision inside another decision
&& || !→Join or flip conditions
char condition→Compare single characters like ch == 'y'
switch→Match one value against exact cases
case→One possible value. Ends with a colon
break→Leaves the switch. Missing break causes fall-through
default→Runs when no case matches
?:→Short if-else for choosing between two values

Remember These

C
if (condition) {
    ...
} else if (condition2) {
    ...
} else {
    ...
}

switch (value) {
    case 1:
        ...
        break;
    default:
        ...
}
  • Use == to compare. A single = stores a value.
  • Always use braces around if and else blocks.
  • In an else-if ladder, only one block runs. Put the highest or most specific condition first.
  • Nested if asks a second question only when the first is true.
  • && needs all true. || needs one true.
  • switch is for exact values (int or char). Ranges need if-else.
  • End each case with break, or C falls through. Add a default.
  • Use ?: only for a simple choice between two values.
