Computer Vision • OpenCV Topic 9 of 25 ⏱ ~6-8 min read

Morphological Operations

Master shape and structure transformations on binary masks: Structuring elements (RECT, ELLIPSE, CROSS), boundary shrinking via Erosion, gap bridging via Dilation, compound noise removal with Opening & Closing, and outline extraction via Morphological Gradient.

01

What Are Morphological Operations?

Topic 8 mein humne image ko binarize (0 aur 255) karna seekha. Lekin thresholding ke baad binary mask mein aksar do tarah ki problems aati hain:

  1. Background mein chote-chote white noise dots (salt noise) reh jaate hain.
  2. Main object ke andar chote-chote black holes, gaps ya toote hue text strokes reh jaate hain.

In problems ko theek karne ke liye hum Morphological Operations use karte hain. Yeh geometric operations hote hain jo binary image ke Foreground (White Shapes) ke size aur structure ko modify karte hain.

⚠ Fundamental Assumption: White is Foreground!
OpenCV ke sabhi morphological algorithms assume karte hain ki White (255) aapka target foreground object hai aur Black (0) background hai! Agar aap white paper par black text process kar rahe hain, to pehle use invert (THRESH_BINARY_INV) karna padega.
02

Structuring Element (The Morphological Kernel)

Morphological operations ek choti binary matrix (jise Structuring Element ya Kernel kehte hain) ke zariye perform hote hain. Yeh kernel sliding window ki tarah poori image par traverse karta hai.

OpenCV kernel generate karne ke liye cv2.getStructuringElement() provide karta hai:

PYTHON • KERNELS.PY STRUCTURING ELEMENTS 
import cv2

# 1. Rectangular Kernel (standard box)
kernel_rect = cv2.getStructuringElement(cv2.MORPH_RECT, (5, 5))

# 2. Elliptical / Circular Kernel (smooth organic boundaries)
kernel_ellipse = cv2.getStructuringElement(cv2.MORPH_ELLIPSE, (5, 5))

# 3. Cross-shaped Kernel (+ symbol, strict 4-connectivity)
kernel_cross = cv2.getStructuringElement(cv2.MORPH_CROSS, (5, 5))
Figure 9.1: Microscopic view of OpenCV structuring elements (9x9 grid): RECT (all 1s), ELLIPSE (rounded circular footprint), and CROSS (+ sign 4-connectivity).
03

1. Erosion: cv2.erode() (Shrinking Foreground)

Erosion ka kaam foreground (white regions) ke boundaries ko strip (erode) karna hai. Jaise samundar ki lehren pathar ko ghis deti hain, waise hi erosion white pixels ki kinariyon ko chota kar deta hai.

Rule: Output pixel sirf tab 255 banta hai jab kernel window ke niche aane wale sabhi pixels 255 hon. Agar ek bhi neighbor black 0 hai, to center pixel ko 0 bana diya jata hai!

PYTHON • EROSION.PY SHRINKING FOREGROUND 
import cv2

# Apply Erosion
# iterations: Number of times erosion is applied sequentially (default=1)
eroded_img = cv2.erode(binary_img, kernel=kernel_rect, iterations=1)
✔ Best Uses of Erosion
  • Background ke chote-mote isolated white noise dots ko delete karna.
  • Do aapas mein jude hue (touching) objects ko alag-alag karna.
⚠ Caution

Agar kernel bohot bada ho ya iterations zyada hon, to patli lines aur delicate text letters poori tarah dissolve ho sakte hain!

04

2. Dilation: cv2.dilate() (Expanding Foreground)

Dilation erosion ka theek ulta hota hai. Yeh foreground (white regions) ke boundaries ko chaaron taraf expand (mota) kar deta hai.

Rule: Output pixel 255 ban jata hai agar kernel window ke niche kam se kam ek pixel bhi 255 ho!

PYTHON • DILATION.PY EXPANDING FOREGROUND 
import cv2

# Apply Dilation
dilated_img = cv2.dilate(binary_img, kernel=kernel_rect, iterations=1)
✔ Best Uses of Dilation
  • Toote hue text strokes aur hairline cracks ko jodna.
  • Weak/faint object silhouettes ko solid aur thik banana.
⚠ Caution

Zyada dilation pass-pass baithe alag-alag objects ko aapas mein chipka kar ek single blob bana deti hai!

Figure 9.2: Erosion vs Dilation on benchmark shape: Notice how erosion shrinks the perimeter and enlarges internal holes, while dilation expands the perimeter and fills the holes.
05

3. Opening: cv2.MORPH_OPEN (Noise Removal)

Agar aap sirf Erosion karte hain, to noise to chali jaati hai lekin main object bhi chota ho jata hai. Iska perfect solution hai Opening:

Opening = Erosion Followed by Dilation   ( Erode → Dilate )

Yeh kaise kaam karta hai?

  • Step 1 (Erode): Chote-chote isolated white specks poori tarah dissolve ho kar khatam ho jaate hain. Bada main object thoda shrink hota hai.
  • Step 2 (Dilate): Bada main object wapas expand hokar apne original size par aa jata hai! Lekin jo chote specks Step 1 mein mar chuke the, wo wapas nahi aate!
PYTHON • OPENING.PY SALT NOISE REMOVAL 
import cv2

# MorphologyEx syntax for Opening
k = cv2.getStructuringElement(cv2.MORPH_RECT, (5, 5))
cleaned_mask = cv2.morphologyEx(noisy_mask, cv2.MORPH_OPEN, kernel=k)
06

4. Closing: cv2.MORPH_CLOSE (Gap & Hole Filling)

Opening ka theek opposite Closing hota hai:

Closing = Dilation Followed by Erosion   ( Dilate → Erode )

Yeh kaise kaam karta hai?

  • Step 1 (Dilate): Foreground expand hota hai, jisse object ke andar ke chote black holes aur gaps aapas mein judkar fill ho jaate hain.
  • Step 2 (Erode): Foreground wapas shrink hokar apne original size par aa jata hai, lekin jo holes Step 1 mein seal ho chuke the wo band hi rehte hain!
PYTHON • CLOSING.PY GAP & HOLE FILLING 
import cv2

# MorphologyEx syntax for Closing
k = cv2.getStructuringElement(cv2.MORPH_RECT, (7, 7))
healed_mask = cv2.morphologyEx(defective_mask, cv2.MORPH_CLOSE, kernel=k)
Figure 9.3: Opening vs Closing: Opening eliminates external white noise specks without distorting the circle, while Closing seals internal holes and bridges cracks.
07

5. Morphological Gradient: cv2.MORPH_GRADIENT

Morphological Gradient ek solid binary shape me se uski Perimeter Boundary (Outline) nikaalne ka sabse aasan tareeka hai:

Gradient = Dilation − Erosion

Kyunki Dilation object ki outer kinari ko expand karta hai aur Erosion inner core ko shrink karta hai, dono ka difference nikaalne par beech ka hollow border outline ban jata hai!

PYTHON • GRADIENT.PY OUTLINE BOUNDARY EXTRACTION 
import cv2

# Morphological Gradient
k = cv2.getStructuringElement(cv2.MORPH_RECT, (5, 5))
outline = cv2.morphologyEx(solid_shape, cv2.MORPH_GRADIENT, kernel=k)
Figure 9.4: Morphological Gradient: Subtracting the eroded core from the dilated shell leaves a clean perimeter outline.
08

Morphology Operations Decision Matrix

Operation Sequence Primary Effect on White Foreground Standard Use-Case
Erosion Single step Shrinks boundaries, removes tiny noise Separating touching blood cells / coins.
Dilation Single step Expands boundaries, bridges cracks Repairing faint handwritten text strokes.
Opening Erode → Dilate Removes isolated white noise dots Cleaning thresholded background noise.
Closing Dilate → Erode Fills internal black holes & bridges gaps Closing holes inside segmented object masks.
Gradient Dilate − Erode Extracts hollow perimeter outline Fast boundary detection without heavy Sobel math.

4 Practical Code Recipes (Copy & Run)

📋 Recipe 1: Erosion & Dilation Explorer

RECIPE_1_EROSION_DILATION.PY BASIC OPERATIONS 
import cv2

# Load binary mask
mask = cv2.imread("binary_mask.png", cv2.IMREAD_GRAYSCALE)

# Create 5x5 rectangular structuring element
kernel = cv2.getStructuringElement(cv2.MORPH_RECT, (5, 5))

# Apply operations
eroded = cv2.erode(mask, kernel, iterations=1)
dilated = cv2.dilate(mask, kernel, iterations=1)

cv2.imwrite("eroded.png", eroded)
cv2.imwrite("dilated.png", dilated)

📋 Recipe 2: Cleaning White Noise with Opening

RECIPE_2_OPENING.PY NOISE REMOVAL 
import cv2

# Load binary image with background salt noise
noisy_img = cv2.imread("noisy_barcode.png", cv2.IMREAD_GRAYSCALE)

# 3x3 or 5x5 kernel depending on noise dot size
kernel = cv2.getStructuringElement(cv2.MORPH_RECT, (5, 5))

# Opening wipes out small specks while keeping barcode intact
cleaned_img = cv2.morphologyEx(noisy_img, cv2.MORPH_OPEN, kernel)

cv2.imwrite("cleaned_barcode.png", cleaned_img)

📋 Recipe 3: Sealing Cracks & Holes with Closing

RECIPE_3_CLOSING.PY GAP REPAIR 
import cv2

# Load binary mask with internal holes
broken_letters = cv2.imread("broken_ocr.png", cv2.IMREAD_GRAYSCALE)

# 7x7 kernel bridges hairline gaps
kernel = cv2.getStructuringElement(cv2.MORPH_RECT, (7, 7))

# Closing fills internal cracks seamlessly
repaired_img = cv2.morphologyEx(broken_letters, cv2.MORPH_CLOSE, kernel)

cv2.imwrite("repaired_ocr.png", repaired_img)

📋 Recipe 4: Extracting Boundary Outlines

RECIPE_4_GRADIENT.PY OBJECT OUTLINE 
import cv2

# Load solid binary silhouette
silhouette = cv2.imread("person_mask.png", cv2.IMREAD_GRAYSCALE)

# 3x3 kernel produces a sharp 2-pixel wide perimeter
kernel = cv2.getStructuringElement(cv2.MORPH_RECT, (3, 3))

# Morphological gradient extracts object outline
outline = cv2.morphologyEx(silhouette, cv2.MORPH_GRADIENT, kernel)

cv2.imwrite("outline_boundary.png", outline)

Common Beginner Mistakes & Fixes

❌ Mistake 1: Processing Black Foreground on White Paper
Problem: Scanned text black hota hai aur paper white hota hai. Agar aap direct erosion laga denge, to text mota (dilate) ho jayega aur paper shrink ho jayega!
Fix: Morphology lagane se pehle image polarity invert karein taaki text White 255 ban sake: binary = cv2.bitwise_not(gray_thresh).
❌ Mistake 2: Using Kernel Bigger than Feature Thickness
Problem: Agar text letter ka stroke 3 pixels ka hai aur aapne (9, 9) kernel se Opening laga di, to poora letter hi gayab ho jayega!
Fix: Kernel size hamesha us noise ya gap ke size se match hona chahiye jise aap target kar rahe hain.
❌ Mistake 3: Confusing Opening vs Closing Sequence
Memory Trick:
• OPENing = Erosion pehle (Noise Bahut Door bhaga do)
• CLOSEing = Dilation pehle (Holes ko Band kar do).
11

Quick Summary & Cheat Sheet

  • Morphological Operations binary images (White Foreground = 255) ki shapes aur structures ko manipulate karte hain.
  • Structuring Element: Kernel matrix jo cv2.getStructuringElement() se RECT, ELLIPSE, ya CROSS footprint mein generate hoti hai.
  • cv2.erode(): White regions ko shrink karta hai; noise dots hatata hai aur touching objects separate karta hai.
  • cv2.dilate(): White regions ko expand karta hai; toote hue strokes jodta hai.
  • cv2.MORPH_OPEN: Erode → Dilate; external white noise specks hatata hai bina main object ka size badle.
  • cv2.MORPH_CLOSE: Dilate → Erode; internal black holes aur cracks seal karta hai.
  • cv2.MORPH_GRADIENT: Dilate − Erode; object ki crisp perimeter outline banata hai.

Mini Knowledge Check

❓ Q1: Ek binary mask mein main object ke chaaron taraf chote-chote white noise specks hain. Main object ka size badle bina noise hatane ke liye kya use karenge?
  • A) cv2.dilate()
  • B) cv2.morphologyEx() with cv2.MORPH_OPEN
  • C) cv2.morphologyEx() with cv2.MORPH_CLOSE
  • D) cv2.resize()
✅ Correct Answer: B) cv2.MORPH_OPEN
Explanation: Opening pehle erode karke chote specks ko eliminate karta hai aur fir dilate karke main object ko uske original size par restore kar deta hai!
❓ Q2: Microscope image mein do touching cells aapas mein jude hue hain. Unhe separate karne ke liye kaunsa operation suitable hai?
  • A) Erosion (cv2.erode)
  • B) Dilation (cv2.dilate)
  • C) Closing (cv2.MORPH_CLOSE)
  • D) Gaussian Blur
✅ Correct Answer: A) Erosion (cv2.erode)
Explanation: Erosion white foreground boundaries ko shrink karta hai, jisse unke beech ka patla joining bridge toot jata hai aur dono cells alag ho jate hain.
❓ Q3: Morphological Gradient mathematically kya calculate karta hai?
  • A) Erosion + Dilation
  • B) Dilation − Erosion
  • C) Opening − Closing
  • D) Mean × Standard Deviation
✅ Correct Answer: B) Dilation − Erosion
Explanation: Dilation object ko thoda bada karta hai aur erosion thoda chota karta hai. Dono ka difference nikaalne par sirf object ka hollow boundary perimeter bachta hai!
