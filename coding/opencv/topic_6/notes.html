Image Resizing: The (Width, Height) Gotcha

OpenCV mein image resize karne ke liye cv2.resize() function use hota hai. Lekin yahan OpenCV ka ek bohot bada gotcha hai jo har beginner ko confuse karta hai:

⚠ CRITICAL OPENCV GOTCHA: (W, H) vs (H, W)!
  • NumPy array shape: h, w, c = img.shape → Height-First!
  • cv2.resize() target size: cv2.resize(img, dsize=(width, height)) → Width-First!
Agar aapki image ka shape (200, 300) hai aur aap use aadha karna chahte hain, to aapko dsize=(150, 100) pass karna hoga, na ki (100, 150)!

Resizing karne ke 2 methods:

  1. Explicit Output Dimensions: Direct pixel size batana — cv2.resize(img, (width, height)).
  2. Scale Factors (fx, fy): Proportional scaling — cv2.resize(img, None, fx=0.5, fy=0.5) (50% chota karna).

Interpolation Methods: How Pixels are Calculated

Aspect Ratio: Preventing Stretched & Squashed Photos

Aapne kai bar websites par aisi photos dekhi hongi jahan insaan ka chehra ajeeb sa pichka (squashed) ya lamba khincha (stretched) hua lagta hai. Yeh tab hota hai jab Aspect Ratio ignore kar diya jaye.

💡 Definition: Aspect Ratio
Aspect Ratio image ki Width aur Height ka proportional ratio hota hai:
Aspect Ratio = Width / Height (e.g., 16:9, 4:3, ya 1:1 square).

Proportional Resizing ka Simple Formula:
Agar aapko nayi Width (target_w) pata hai, to nayi Height aise calculate karein:

python • aspect_ratio_formula.py Proportional Calculation 
# Calculate new height while preserving original aspect ratio
h, w = img.shape[:2]
target_w = 150
ratio = target_w / float(w)
target_h = int(h * ratio)

# Resize proportionally
resized_clean = cv2.resize(img, (target_w, target_h), interpolation=cv2.INTER_AREA)

Image Cropping: Selecting Region of Interest (ROI)

OpenCV mein image crop karne ke liye koi alag cv2.crop() function nahi hota. Kyunki OpenCV image ek NumPy array hai, hum direct Array Slicing use karte hain:

🔢 Cropping Syntax: img[y1:y2, x1:x2].copy()
  • y1 : y2 — Rows range (Vertical Height)
  • x1 : x2 — Columns range (Horizontal Width)
  • Rule: Ending indices (y2, x2) hamesha excluded hote hain!
  • Memory Safety: Hamesha .copy() lagayein taaki original image accidental mutation se surakshit rahe!

Image Rotation: 90° Flips & Arbitrary Angles

OpenCV mein rotation do tarike se ki ja sakti hai: built-in fast 90°/180° rotations ya custom angle affine warping.

Method 1: Built-in 90° & 180° Rotations (cv2.rotate)

Yeh functions direct matrix transpose aur flip use karte hain, isliye yeh ultra-fast aur lossless hote hain:

  • cv2.rotate(img, cv2.ROTATE_90_CLOCKWISE) — 90° right turn (Width aur Height swap ho jaate hain!).
  • cv2.rotate(img, cv2.ROTATE_180) — Poori image upside-down ulati ho jaati hai.
  • cv2.rotate(img, cv2.ROTATE_90_COUNTERCLOCKWISE) — 90° left turn.

Method 2: Arbitrary Angle Rotation (cv2.warpAffine)

Agar aapko image ko kisi custom angle (jaise 30°, 45°, ya 60°) par ghumana ho, to hum Rotation Matrix banate hain:

python • arbitrary_rotation.py Affine Transformation 
# 1. Find center of the image
h, w = img.shape[:2]
center = (w // 2, h // 2)

# 2. Build 2D rotation matrix (center, angle_degrees, scale)
M = cv2.getRotationMatrix2D(center, 45, 1.0)

# 3. Apply affine warping
rotated_45 = cv2.warpAffine(img, M, (w, h), borderValue=(255, 255, 255))
Figure 6.5: Rotation operations: 90° clockwise, 180° inversion, and 45° affine warping around the center.

Example 1: Resize Explorer (Explicit Dimensions vs Scale Factors)

Yeh script image ko smaller aur larger dimensions mein resize karti hai aur unke shapes verify karti hai.

import cv2
import numpy as np

# 1. Create a 200x300 synthetic test image
img = np.full((200, 300, 3), 200, dtype=np.uint8)
cv2.circle(img, (150, 100), 50, (0, 0, 255), -1)

# 2. Method A: Explicit output size dsize=(width, height)
shrunk = cv2.resize(img, (150, 100), interpolation=cv2.INTER_AREA)
enlarged = cv2.resize(img, (450, 300), interpolation=cv2.INTER_CUBIC)

# 3. Method B: Using scale factors fx, fy
shrunk_scale = cv2.resize(img, None, fx=0.5, fy=0.5, interpolation=cv2.INTER_AREA)

print("Original Shape:      ", img.shape)
print("Shrunk (150x100):    ", shrunk.shape)
print("Enlarged (450x300):  ", enlarged.shape)
print("Shrunk (fx=0.5):     ", shrunk_scale.shape)

Example 2: Aspect Ratio Preserving Resizer Function

A reusable professional helper function jo image ko resize karte waqt aspect ratio hamesha preserve rakhti hai.

python • example2_aspect_ratio_resizer.py Production Helper 
import cv2
import numpy as np

def resize_proportional(image, target_width=None, target_height=None, inter=cv2.INTER_AREA):
    h, w = image.shape[:2]
    if target_width is None and target_height is None:
        return image
    if target_width is None:
        r = target_height / float(h)
        dim = (int(w * r), target_height)
    else:
        r = target_width / float(w)
        dim = (target_width, int(h * r))
    return cv2.resize(image, dim, interpolation=inter)

# Test with 200x300 image (Aspect Ratio = 1.5)
test_img = np.zeros((200, 300, 3), dtype=np.uint8)

# Target width 150 -> Height should automatically become 100
clean_resize = resize_proportional(test_img, target_width=150)
print(f"Original: {test_img.shape} -> Proportional: {clean_resize.shape}")
print(f"Aspect Ratio Preserved: {clean_resize.shape[1] / clean_resize.shape[0]:.2f}")
Actual Executed Output
Original: (200, 300, 3) -> Proportional: (100, 150, 3)
Aspect Ratio Preserved: 1.50

Example 3: Cropping a Region of Interest (ROI) with .copy()

Target rectangular region ko crop karna aur uspar independent operations perform karna.

python • example3_crop_roi.py Independent Crop 
import cv2
import numpy as np

img = np.full((200, 300, 3), 100, dtype=np.uint8)

# Define crop boundaries
y1, y2 = 50, 150
x1, x2 = 100, 200

# Crop with .copy()
roi = img[y1:y2, x1:x2].copy()

print(f"Original Image Shape: {img.shape}")
print(f"Cropped ROI Shape:    {roi.shape} (Height={y2-y1}, Width={x2-x1})")

# Save cropped result
cv2.imwrite("cropped_face.png", roi)

Example 4: Rotation Explorer (90°, 180° & 45° Affine)

Image orientation fix karna aur arbitrary rotation matrix apply karna.

python • example4_rotation_explorer.py Cardinal & Arbitrary Rotation 
import cv2
import numpy as np

img = np.zeros((200, 300, 3), dtype=np.uint8)
h, w = img.shape[:2]

# 1. 90 Degrees Clockwise
rot_90 = cv2.rotate(img, cv2.ROTATE_90_CLOCKWISE)

# 2. 180 Degrees Flip
rot_180 = cv2.rotate(img, cv2.ROTATE_180)

# 3. Arbitrary 45 Degrees around center
center = (w // 2, h // 2)
M = cv2.getRotationMatrix2D(center, 45, 1.0)
rot_45 = cv2.warpAffine(img, M, (w, h))

print(f"Original Shape: (H={h}, W={w})")
print(f"90° CW Shape:   {rot_90.shape} (Width & Height Swapped!)")
print(f"180° Shape:     {rot_180.shape}")
print(f"45° Affine:     {rot_45.shape}")
Actual Executed Output
Original Shape: (H=200, W=300)
90° CW Shape: (300, 200, 3) (Width & Height Swapped!)
180° Shape: (200, 300, 3)
45° Affine: (200, 300, 3)

Common Beginner Traps & Troubleshooting

❌ The (W, H) in resize() Trap

cv2.resize() mein pehla argument Width aur doosra Height hota hai. Agar aap img.shape ke hisaab se (h, w) pass kar denge to image ulati stretch ho jayegi!

❌ Inverted Crop Coordinates

Agar aap likhenge img[150:50, 200:100] jahan start index end index se bada hai, to NumPy empty array (0, 0, 3) return karega bina error diye!

⚠ Arbitrary Rotation Corner Clipping

cv2.warpAffine() usi canvas size (w, h) par rotate karta hai. Isliye 45° rotation par image ke chaaron kone cut (clip) ho jaate hain.

✔ Right Interpolation for Downsampling

Image shrink karte waqt hamesha cv2.INTER_AREA use karein. Yeh moire patterns aur aliasing artifacts ko eliminate karta hai.

Quick Revision & Self-Assessment Quiz

Q1: Ek image ka shape (400, 600, 3) hai. cv2.resize() mein use 50% chota karne ke liye dsize kya hona chahiye?
Sahi Jawab: dsize=(300, 200)
Shape (400, 600) ka matlab hai Height=400, Width=600. Kyunki cv2.resize() Width-first (W, H) format leta hai, isliye aadha karne par (300, 200) hoga.
Q2: Image ko chota (downsample) karte waqt kaun sa interpolation method best maana jata hai?
Sahi Jawab: cv2.INTER_AREA
INTER_AREA pixel area relation use karta hai jo image shrink hone par moire artifacts aur jagged lines ko rokk kar smooth result deta hai.
Q3: Jab hum kisi rectangular image ko cv2.ROTATE_90_CLOCKWISE rotate karte hain, to uske dimensions par kya asar padta hai?
Sahi Jawab: Width aur Height aapas mein swap ho jaate hain.
For example, agar image (200, 300) thi, to 90° rotate hone ke baad wo (300, 200) ban jayegi.
