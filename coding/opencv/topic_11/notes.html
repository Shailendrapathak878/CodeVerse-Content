Contours & Shape Detection

Image processing mein edges sirf scattered boundary pixels hote hain, jabki Contours unhi pixels ko jodkar ek continuous closed vector curve banate hain. Seekhein kaise objects ko count karein, area calculate karein, bounding box banayein aur geometric shapes detect karein!

⏱ ~6-8 min read 🎯 Target: OpenCV 4.x + Python 📊 Difficulty: Beginner to Intermediate 🔗 Requires: Topics 8 & 10
01

What is a Contour? (Edges vs Contours)

Bahut se beginners Edges aur Contours mein confuse hote hain:

Feature Edge (Kinaara) Contour (Ghera / Vector Curve)
Definition Pixels jahan color ya intensity mein sudden jump hota hai (Gradient peaks). Ek hi intensity ya color ke boundary points ko jodti hui continuous boundary curve.
Output Format Raster binary image (0 aur 255 pixels ki grid). Python List of NumPy point arrays [(x1, y1), (x2, y2), ...].
Object Awareness Nahi hoti. Edges tooti-phooti ya disconnected ho sakti hain. Hoti hai! Har distinct object ka apna alag discrete contour curve hota hai.
Calculations Direct Area ya Perimeter nikaalna mushkil hai. Direct contourArea(), arcLength(), centroid aur shape match possible hai.
⚠ The Golden Rule of OpenCV Contours:
OpenCV mein cv2.findContours() hamesha Black Background (0) par White Object (255) dhoondhta hai. Agar aapki image mein object black hai aur background white, to pehle use cv2.bitwise_not() ya binary inverted thresholding se invert karna zaroori hai!

Finding & Drawing Contours: The Core APIs

OpenCV mein contours extract karne ke liye do primary functions use hote hain:

🔍 1. cv2.findContours(image, mode, method)

Ye function binary image ko scan karke discrete point arrays nikaalta hai:

contours, hierarchy = cv2.findContours(binary_img, cv2.RETR_EXTERNAL, cv2.CHAIN_APPROX_SIMPLE)
💡 OpenCV 3 vs OpenCV 4+ Notice:
OpenCV 3.x mein cv2.findContours() 3 values return karta tha (image, contours, hierarchy). Par modern OpenCV 4.x mein ye sirf 2 values return karta hai: (contours, hierarchy). 3 values unpack karne par ValueError: too many values to unpack exception aayegi!

🖌 2. cv2.drawContours(image, contours, contourIdx, color, thickness)

  • image: Destination image jispar boundary draw karni hai (usually original 3-channel color image).
  • contours: findContours se aayi hui contour points ki Python list.
  • contourIdx: Kaunsa contour draw karna hai? -1 pass karne par sabhi contours ek saath draw ho jate hain. Specific shape ke liye index pass karein (jaise 0 ya 1).
  • color: BGR tuple (jaise green ke liye (0, 255, 0)).
  • thickness: Line ki motai in pixels. Agar -1 ya cv2.FILLED pass karenge to poora shape solid fill ho jayega!

⚗ Memory Optimization: CHAIN_APPROX_NONE vs CHAIN_APPROX_SIMPLE

Contour nikaalte waqt points store karne ke do main methods hain:

cv2.CHAIN_APPROX_NONE

Boundary ke har ek pixel coordinate ko list mein save karta hai. Agar ek rectangle 200×200 pixels ka hai, to ye approx 800 discrete points store karega. High memory consumption!

cv2.CHAIN_APPROX_SIMPLE ★

Horizontal, vertical aur diagonal segments ko compress kar deta hai aur sirf corners / endpoints store karta hai. 200×200 rectangle ke liye sirf 4 points store hote hain! Highly optimized!

Hands-on Code: Detect and Draw Shapes

import cv2 import numpy as np # 1. Grayscale image load karein img = cv2.imread('shapes.png') gray = cv2.cvtColor(img, cv2.COLOR_BGR2GRAY) # 2. Binary thresholding (foreground white 255, background black 0) _, binary = cv2.threshold(gray, 127, 255, cv2.THRESH_BINARY) # 3. Contours extract karein (OpenCV 4+ style) contours, hierarchy = cv2.findContours(binary, cv2.RETR_EXTERNAL, cv2.CHAIN_APPROX_SIMPLE) print(f"Kul mile {len(contours)} alag-alag objects!") # 4. Saare contours ko Green color (0, 255, 0) mein draw karein output = img.copy() cv2.drawContours(output, contours, -1, (0, 255, 0), 2) cv2.imshow('Contours Detected', output) cv2.waitKey(0) cv2.destroyAllWindows()
✔ Output Console: Kul mile 2 alag-alag objects!

Contour Properties & Geometric Measurements

Ek baar contour array mil jane ke baad hum uski physical properties calculate kar sakte hain:

📏 1. Contour Area

cv2.contourArea(cnt): Shape ke andar kitne square pixels hain. Tiny noise specks ko filter out karne ke liye useful hai (e.g. if area > 100: ...).

⚖ 2. Perimeter (Arc Length)

cv2.arcLength(cnt, closed=True): Boundary ki total linear length. Closed curve ke liye closed=True pass karein.

🎯 3. Centroid (Center of Mass)

M = cv2.moments(cnt) se spatial moments milte hain:
cx = int(M['m10'] / M['m00'])
cy = int(M['m01'] / M['m00'])

📦 4. Bounding Box

x, y, w, h = cv2.boundingRect(cnt): Object ke around upright straight bounding box ka top-left corner aur width-height nikaalta hai.

Figure 11.2: OpenCV geometric measurements: Cyan bounding boxes, Red centroid dots, and calculated Area & Perimeter values.

Hands-on Code: Calculate Properties & Annotate

for i, cnt in enumerate(contours): # Area aur Perimeter calculate karein area = cv2.contourArea(cnt) perimeter = cv2.arcLength(cnt, True) # Spatial moments se centroid nikaalein M = cv2.moments(cnt) if M['m00'] != 0: cx = int(M['m10'] / M['m00']) cy = int(M['m01'] / M['m00']) # Centroid par red dot banayein cv2.circle(output, (cx, cy), 4, (0, 0, 255), -1) # Straight bounding rectangle nikaalein x, y, w, h = cv2.boundingRect(cnt) cv2.rectangle(output, (x, y), (x + w, y + h), (255, 255, 0), 2) print(f"Shape #{i}: Area={area:.1f}, Peri={perimeter:.1f}, Center=({cx}, {cy})")
✔ Output Console:
Shape #0: Area=5000.0, Peri=300.0, Center=(100, 100)
Shape #1: Area=11310.0, Peri=376.8, Center=(280, 150)
04

Contour Retrieval Modes & Hierarchy (Nested Holes)

Real-world images mein objects ke andar holes ho sakte hain (jaise coin ke beech ka hole, donut, washer, ya alphabets 'O', 'B', 'P'). OpenCV mein parent-child relations ko handle karne ke liye Retrieval Modes hote hain:

Mode Flag Hierarchy Behavior Best Use Case
cv2.RETR_EXTERNAL Sirf sabse bahar ke extreme outer contours dhoondhta hai. Holes ko ignore karta hai! Object counting, boundary outline, document border detection.
cv2.RETR_TREE Poora complete hierarchical tree reconstruct karta hai (parents, children, grandchildren). Complex shapes with inner cutouts, nested text OCR, washer hole inspection.
cv2.RETR_LIST Saare contours extract karta hai bina kisi parent-child relationship ke (flat list). Jab nested hierarchy ka structure matter nahi karta par har boundary chahiye.
cv2.RETR_CCOMP 2-level hierarchy banata hai: Outer boundaries (level 1) aur Holes (level 2). Simple hole-vs-outer separation bina deeply nested levels ke.
Figure 11.3: cv2.RETR_EXTERNAL ignores interior cutouts (2 outer shapes), whereas cv2.RETR_TREE detects all 3 boundaries including the inner hole.
👁 Understanding the Hierarchy Array:
Hierarchy array ka shape (1, N, 4) hota hai, jisme har contour ke liye 4 values hoti hain:
[Next, Previous, First_Child, Parent]
Agar koi child ya parent nahi hai, to wahan value -1 hoti hai!
05

Polygon Approximation (Douglas-Peucker Algorithm)

Jab camera se koi shape capture hota hai, to pixels ki rough edges ki wajah se contour curve mein hazaron points ho sakte hain. cv2.approxPolyDP() Douglas-Peucker algorithm use karke is curve ko smooth straight lines wale simple polygon mein convert karta hai!

approx = cv2.approxPolyDP(curve=cnt, epsilon=0.035 * peri, closed=True)

🔴 Epsilon (ε) Parameter Tuning:

Epsilon maximum distance threshold define karta hai. Curve ka jo point approximated segment se ε se zyada door hoga, use naye vertex ke roop mein add kiya jayega:

  • Too Small (ε < 0.01 * Perimeter): Curve lagbhag simplify nahi hoga, noise points bache rahenge.
  • Optimal (ε ≈ 0.02 to 0.04 * Perimeter): Clean geometric vertices milenge (Triangles = 3, Rectangles = 4, Pentagons = 5).
  • Too Large (ε > 0.10 * Perimeter): Over-simplification ho jayega! Ek 10-point star shape bhi katkar sirf 3-point triangle ban jayega!
Figure 11.4: Star contour simplified with increasing epsilon. Notice how 1.5% preserves all 10 vertices, 5.0% drops inner tips, and 12.0% distorts into a 3-point triangle!

Automatic Shape Classification in OpenCV

Contour approximation ke baad hum len(approx) (number of vertices) se shapes detect aur classify kar sakte hain:

Vertices Count Identified Shape Classification Logic & Checks
3 Vertices Triangle (Tribhuj) len(approx) == 3
4 Vertices Square ya Rectangle aspect_ratio = float(w) / h
Agar 0.95 <= aspect_ratio <= 1.05 to Square, warna Rectangle.
5 Vertices Pentagon (Panchbhuj) len(approx) == 5
> 6 Vertices Circle / Oval Circularity Formula: 4 * π * Area / (Perimeter2)
Agar Circularity > 0.75 hai, to shape Circle hai!
Figure 11.5: Automatic shape detection in action! Shapes classified accurately by counting Douglas-Peucker approximated vertices.

Hands-on Code: Production Shape Classifier

import cv2 import numpy as np def classify_shapes(image_path): img = cv2.imread(image_path) gray = cv2.cvtColor(img, cv2.COLOR_BGR2GRAY) _, thresh = cv2.threshold(gray, 127, 255, cv2.THRESH_BINARY) contours, _ = cv2.findContours(thresh, cv2.RETR_EXTERNAL, cv2.CHAIN_APPROX_SIMPLE) for cnt in contours: # Ignore noise if cv2.contourArea(cnt) < 100: continue peri = cv2.arcLength(cnt, True) approx = cv2.approxPolyDP(cnt, 0.035 * peri, True) num_vertices = len(approx) x, y, w, h = cv2.boundingRect(cnt) shape_name = "Unknown" if num_vertices == 3: shape_name = "Triangle" elif num_vertices == 4: aspect_ratio = float(w) / h shape_name = "Square" if 0.95 <= aspect_ratio <= 1.05 else "Rectangle" elif num_vertices == 5: shape_name = "Pentagon" else: shape_name = "Circle" # Draw outline and label cv2.drawContours(img, [cnt], -1, (0, 255, 0), 2) cv2.putText(img, shape_name, (x, y - 10), cv2.FONT_HERSHEY_SIMPLEX, 0.6, (255, 0, 0), 2) return img

Real-World Industry Applications

Contours computer vision pipelines ka backbone hain. Ye practical applications dekhein:

📄 1. Document Scanner Apps

CamScanner jaise apps table par rakhe document ke 4 corners detect karne ke liye findContours + approxPolyDP (vertices == 4) use karte hain, aur fir perspective transform se seedha scan generate karte hain!

🪙 2. Coin & Currency Counter

Bank sorting machines har coin ka area (contourArea) measure karke instant pata laga leti hain ki coin ₹1, ₹2, ₹5 ya ₹10 ka hai aur total cash count karti hain!

🐦 3. Industrial Defect Detection

Manufacturing lines par bottles ke caps ya metal washers ke holes ka area aur circularity check ki jaati hai. Agar circularity < 0.70 hai to defective part reject ho jata hai.

✋ 4. Hand Gesture Recognition

Hand contours nikaalkar Convex Hull aur Convexity Defects calculate kiye jaate hain, jisse uthi hui ungliyon ki ginti hoti hai (Thumbs up, Victory sign, Fist)!

Common Beginner Mistakes & Fixes

❌ Mistake 1: Original BGR/Color image ko findContours mein pass karna
Problem: cv2.error: (-210:Unsupported format or combination of formats) crash aayega.
Solution: Pehle image ko cv2.cvtColor(img, cv2.COLOR_BGR2GRAY) karein aur fir cv2.threshold() ya cv2.Canny() se 8-bit single-channel binary image banayein!
⚠ Mistake 2: Black object on white background ko bina invert kiye pass karna
Problem: OpenCV border par background ka ek bada sa single contour pakad lega aur actual objects gayab ho jayenge.
Solution: Agar document white hai aur text/shapes black hain, to cv2.bitwise_not() ya cv2.THRESH_BINARY_INV se black foreground ko white banayein!
💡 Mistake 3: Zero area contours se division by zero crash
Problem: Spatial moments calculate karte waqt cx = int(M['m10'] / M['m00']) mein jab M['m00'] == 0 ho to ZeroDivisionError aayega.
Solution: Hamesha check karein: if M['m00'] != 0: ...

Mini Knowledge Check

❓ Q1: OpenCV 4.x mein cv2.findContours() kitni values return karta hai?
  • A) 1 value (sirf contours)
  • B) 2 values (contours, hierarchy)
  • C) 3 values (image, contours, hierarchy)
  • D) 4 values (x, y, w, h)
✅ Correct Answer: B) 2 values (contours, hierarchy)
Explanation: OpenCV 3 mein 3 values aati thi, lekin modern OpenCV 4+ mein source image ko modify kiye bina seedhe (contours, hierarchy) return kiya jata hai!
❓ Q2: Agar hamein kisi shape ke andar ke holes ignore karke sirf bahar ki boundary chahiye, to kaunsa retrieval mode use karenge?
  • A) cv2.RETR_TREE
  • B) cv2.RETR_LIST
  • C) cv2.RETR_EXTERNAL
  • D) cv2.RETR_CCOMP
✅ Correct Answer: C) cv2.RETR_EXTERNAL
Explanation: RETR_EXTERNAL sirf outermost parent boundaries return karta hai aur internal child cutouts/holes ko discard kar deta hai!
❓ Q3: cv2.drawContours(img, contours, -1, (0, 255, 0), 2) mein -1 ka kya matlab hai?
  • A) Sirf aakhiri contour draw karo
  • B) Sabhi (all) detected contours ko ek saath draw karo
  • C) Inverse colors mein draw karo
  • D) Error raise karo
✅ Correct Answer: B) Sabhi (all) detected contours ko ek saath draw karo
Explanation: contourIdx = -1 OpenCV ka special flag hai jo list ke sabhi contours ko ek loop ke bina canvas par draw kar deta hai!
