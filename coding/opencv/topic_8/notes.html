Thresholding & Binary Images

Learn how to binarize grayscale images into pure black and white: Simple global thresholding, inverse polarity, handling harsh document shadows with Adaptive thresholding, and automated bimodal cutoff using Otsu's method.

01

What Is Thresholding?

Computer Vision mein kisi image se main subject (Foreground) ko background se alag karne ka sabse direct aur fundamental tareeka Thresholding kehlata hai.

Yeh ek pixel classification technique hai jisme hum ek benchmark number (jise Threshold Value kehte hain, jaise 127) set karte hain:

  • Agar kisi pixel ki brightness threshold se zyada hai, to use ek category (jaise White 255) assign ki jaati hai.
  • Agar brightness threshold se kam ya barabar hai, to use dusri category (jaise Black 0) assign ki jaati hai.
💡 Real-Life Analogy: CamScanner / Document Scanner
Jab aap mobile scanner app se kisi printed page ki photo lete hain, to app page ke grayish paper ko pure white 255 bana deta hai aur likhe hue text ko deep black 0 bana deta hai. Is operation ko Image Binarization ya Document Thresholding kehte hain!
⚠ Golden Rule: Hamesha Grayscale Input Use Karein!
Thresholding brightness (intensity) par kaam karti hai. Isliye thresholding apply karne se pehle RGB/BGR image ko cv2.cvtColor(img, cv2.COLOR_BGR2GRAY) se single-channel grayscale mein convert karna anivarya (mandatory) hai.
02

What Is a Binary Image?

Ek standard 8-bit grayscale image mein 256 possible intensity levels (0 se 255) hote hain jisme shadows, smooth gradients aur midtones shamil hote hain.

Lekin ek Binary Image mein sirf aur sirf do values hoti hain:

⚫ Value 0 (Pure Black)

Standard conventions mein 0 background ya dark text ko darshata hai.

⚪ Value 255 (Pure White)

Standard object segmentation mein 255 foreground object ya paper background ko darshata hai.

Binary images computer vision ke downstream tasks (jaise OCR text extraction, finding object contours, counting items, aur shape detection) ke liye perfect input hoti hain kyunki isme koi confusing lighting variations nahi bachte.

03

Simple Global Thresholding: cv2.threshold()

OpenCV mein simple thresholding ke liye hum cv2.threshold() function use karte hain. Yeh function poori image par ek single fixed cutoff value lagata hai:

PYTHON • SIMPLE_THRESHOLD.PY GLOBAL CUTOFF 
import cv2

# 1. Load image in grayscale
gray = cv2.imread("coin.jpg", cv2.IMREAD_GRAYSCALE)

# 2. Apply Simple Binary Thresholding
# Syntax: retval, dst = cv2.threshold(src, thresh, maxval, type)
ret, binary = cv2.threshold(gray, thresh=127, maxval=255, type=cv2.THRESH_BINARY)

# 3. Apply Inverted Binary Thresholding
ret_inv, binary_inv = cv2.threshold(gray, 127, 255, cv2.THRESH_BINARY_INV)

Parameters Breakdown:

  • src: Input single-channel grayscale image array.
  • thresh: Threshold cutoff value (e.g., 127).
  • maxval: Value jo assign hogi agar pixel condition pass kare (standard 255).
  • type: Thresholding algorithm flag (e.g., cv2.THRESH_BINARY).

Return Values: Yeh function hamesha ek tuple (ret, dst) return karta hai:

  • ret: Used threshold value (simple thresholding mein wahi value jo aapne pass ki, jaise 127.0).
  • dst: Resulting binary output image array.

🔢 Numeric Pixel Classification (Cutoff = 127):

Input Pixel Value Condition (vs 127) THRESH_BINARY Output THRESH_BINARY_INV Output
40 (Dark shadow) 40 ≤ 127 0 (Black) 255 (White)
127 (Boundary) 127 ≤ 127 0 (Black) 255 (White)
185 (Bright coin) 185 > 127 255 (White) 0 (Black)

Other Useful OpenCV Thresholding Flags

OpenCV binary cutoff ke alawa 3 aur useful non-binary threshold types deta hai jo pixel values ko truncate ya zero kar sakte hain:

Flag Mathematical Logic Visible Effect
cv2.THRESH_TRUNC dst(x,y) = thresh if src(x,y) > thresh else src(x,y) Bright pixels threshold value par freeze (clip) ho jaate hain. Low values waise hi rehti hain.
cv2.THRESH_TOZERO dst(x,y) = src(x,y) if src(x,y) > thresh else 0 Threshold se bright pixels waise hi rehte hain, baaki sab 0 (black) ban jaate hain.
cv2.THRESH_TOZERO_INV dst(x,y) = 0 if src(x,y) > thresh else src(x,y) Threshold se bright pixels black ho jaate hain, dark pixels unaltered rehte hain.

Adaptive Thresholding: Handling Shadows & Uneven Lighting

Global thresholding tab bilkul fail ho jati hai jab image mein uneven lighting ya partial shadows hon (jaise mobile se book ki photo lete waqt haath ki shadow padna).

Global thresholding poori image par ek hi cutoff lagati hai, jisse shadow wala poora hissa black blotch ban jata hai aur text gayab ho jata hai!

Adaptive Thresholding iska solution hai: Yeh poori image par ek cutoff nahi lagati, balki har pixel ke aas-paas ek chota neighborhood window (blockSize) leti hai aur local threshold calculate karti hai!

PYTHON • ADAPTIVE_THRESHOLD.PY LOCAL NEIGHBORHOOD CUTOFF 
import cv2

# Adaptive Thresholding syntax
# blockSize: Neighborhood size (must be odd integer > 1, e.g. 11, 15)
# C: Constant subtracted from the calculated mean/gaussian (fine-tuning)

# Method 1: Adaptive Mean
adapt_mean = cv2.adaptiveThreshold(
    gray, 255, cv2.ADAPTIVE_THRESH_MEAN_C, cv2.THRESH_BINARY, blockSize=15, C=8
)

# Method 2: Adaptive Gaussian (smoother, cleaner results)
adapt_gauss = cv2.adaptiveThreshold(
    gray, 255, cv2.ADAPTIVE_THRESH_GAUSSIAN_C, cv2.THRESH_BINARY, blockSize=15, C=8
)

Key Parameters Explained:

  • adaptiveMethod:
    • ADAPTIVE_THRESH_MEAN_C: Neighborhood pixels ka arithmetic average.
    • ADAPTIVE_THRESH_GAUSSIAN_C: Gaussian bell curve ke weighted weights se average. (Industry standard for documents).
  • blockSize: Area of pixel neighborhood. Yeh hamesha odd number > 1 (jaise 11, 15, 21) hona chahiye.
  • C: Calculated mean/gaussian se subtract kiya jane wala constant offset number. Yeh background noise speckles ko control karta hai (typical values: 2 se 10).
Figure 8.3: Global thresholding completely fails under shadow (black wedge), while Adaptive Gaussian recovers all text lines and stamp details cleanly.

Otsu's Thresholding: Automated Optimal Cutoff

Simple thresholding mein sabse bada sawaal yeh hota hai: "Mujhe threshold value 100 rakhni chahiye ya 150 ya 180?" Manual guessing time-wasting hoti hai.

Otsu's Binarization ek statistical algorithm hai jo image ke intensity histogram ko analyze karta hai aur automatically optimum threshold calculate karta hai jo background aur foreground clusters ke beech ki variance ko maximize karta hai!

PYTHON • OTSU_THRESHOLD.PY AUTOMATIC HISTOGRAM BINARIZATION 
import cv2

# Pass thresh=0, and combine THRESH_BINARY with THRESH_OTSU
# OpenCV calculates the optimal threshold and returns it in 'optimal_thresh'
optimal_thresh, binary_otsu = cv2.threshold(
    gray, 0, 255, cv2.THRESH_BINARY + cv2.THRESH_OTSU
)

print(f"Otsu automatically calculated optimal threshold: {optimal_thresh}")
💡 Why pass thresh=0?
Kyunki Otsu algorithm khud optimum cutoff find karta hai, isliye input thresh parameter ignore ho jata hai. Convention ke hisaab se hum 0 pass karte hain, aur calculated cutoff function ke pehle return value (optimal_thresh) mein mil jata hai!
Figure 8.4: Otsu's method on a bimodal distribution: The algorithm locates the exact valley between the background peak (~45) and foreground peak (~205) at T=124.
⚠ When does Otsu work best?
Otsu tab sabse effective hota hai jab image ka histogram Bimodal ho (yaani do clear peaks hon — ek dark background ka aur ek bright foreground ka). Agar image mein harsh lighting gradients hon, to Adaptive thresholding better choice hoti hai.

Thresholding Decision Matrix

Kab kaunsa thresholding method use karna chahiye? Yeh compact guide aapko sahi decision lene mein help karegi:

Method Speed Cutoff Selection Best Use-Case
Simple Global Threshold Ultra Fast Manual Fixed Value (e.g. 127) Uniformly lit lab images, controlled camera environments.
Inverse Binary Threshold Ultra Fast Manual Fixed Value Jab dark text ko white foreground aur light paper ko black background banana ho.
Adaptive Threshold (Gaussian) Fast Local Window Mean/Gaussian Real-world document scans, paper under shadows, uneven outdoor lighting.
Otsu's Thresholding Fast Automated from Histogram Bimodal contrast images, coins/cells on dark microscope backgrounds without guesswork.

Common Beginner Mistakes & Fixes

❌ Mistake 1: Passing 3-Channel Color BGR Image
cv2.threshold(color_bgr, 127, 255, cv2.THRESH_BINARY)
Error: Output mein teeno channels alag-alag binarize ho kar distorted color blotches banate hain.
Fix: Thresholding se pehle hamesha grayscale conversion karein: gray = cv2.cvtColor(img, cv2.COLOR_BGR2GRAY).
❌ Mistake 2: Even blockSize in adaptiveThreshold
cv2.adaptiveThreshold(gray, 255, ..., blockSize=16, C=5)
Error: cv2.error: blockSize % 2 == 1 && blockSize > 1.
Fix: Blurring kernels ki tarah blockSize hamesha odd number (11, 15, 21) hona chahiye!
❌ Mistake 3: Unpacking Single Variable from cv2.threshold
binary = cv2.threshold(gray, 127, 255, cv2.THRESH_BINARY)
Problem: binary ek tuple ban jata hai (127.0, <ndarray>). Agar aap cv2.imshow("Win", binary) karenge to crash hoga.
Fix: Hamesha do variables unpack karein: ret, binary = cv2.threshold(...).

Quick Summary & Cheat Sheet

  • Thresholding: Pixel intensity values ko cutoff ke basis par classify karne ki technique.
  • Binary Image: Discrete 2-state image jisme sirf do values hoti hain: 0 (Black) aur 255 (White).
  • cv2.threshold(gray, thresh, maxval, type): Global threshold function jo tuple (ret, dst) return karta hai.
  • THRESH_BINARY vs THRESH_BINARY_INV: Above threshold pixels ko 255 ya 0 set karta hai.
  • cv2.adaptiveThreshold(): Local window (odd blockSize) ke basis par alag-alag thresholds compute karta hai — shadows aur documents ke liye best.
  • Otsu's Method (THRESH_OTSU): Bimodal histogram analyze karke optimal cutoff value automatically find karta hai bina kisi manual guessing ke.

Mini Knowledge Check

❓ Q1: Kisi book page par haath ki harsh shadow pad rahi hai. Text ko saaf read karne ke liye kaunsa thresholding method best rahega?
  • A) cv2.threshold() with THRESH_BINARY
  • B) cv2.adaptiveThreshold() with ADAPTIVE_THRESH_GAUSSIAN_C
  • C) cv2.resize()
  • D) cv2.blur() with (25, 25)
✅ Correct Answer: B
Explanation: Adaptive thresholding har local neighborhood ke hisaab se threshold calculate karta hai, isliye shadow wale dark hisse mein bhi text white paper se alag ho jata hai!
❓ Q2: Otsu's thresholding call karte waqt thresh argument ko 0 kyun set kiya jata hai?
  • A) Kyunki Otsu method image ko pure black kar deta hai.
  • B) Kyunki Otsu algorithm khud histogram se optimum threshold calculate karta hai, isliye manual threshold ignore ho jata hai.
  • C) Kyunki 0 pass karne se image invert ho jaati hai.
  • D) Kyunki Otsu sirf 0-value pixels count karta hai.
✅ Correct Answer: B
Explanation: Otsu's algorithm automatically bimodal variance analyze karke optimum cutoff choose karta hai aur use pehle return value (ret) mein return kar deta hai.
❓ Q3: ret, binary = cv2.threshold(gray, 150, 255, cv2.THRESH_BINARY) mein agar input pixel value 170 hai, to output pixel value kya hogi?
  • A) 0
  • B) 150
  • C) 255
  • D) 170
✅ Correct Answer: C) 255
Explanation: In THRESH_BINARY, agar pixel value threshold (150) se badi hai (170 > 150), to use maxval (255) assign kiya jata hai.
