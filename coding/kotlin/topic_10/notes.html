1 Introduction to Lambda Expressions

A lambda expression (or simply a lambda) is an anonymous function—a concise block of code that is not declared with a formal function name. Lambdas can be stored in variables, passed directly into other functions as arguments, or returned from functions.

📝 Real-Life Analogy: The Sticky Note Instruction

A normal function is like a heavy recipe book with an index. A lambda is like a quick sticky note with a single instruction written on it: "Double this number". You can hand this note to anyone to execute!

Visual 1: Formal Function vs. Lightweight Lambda Equivalent
LambdaIntro.kt
KOTLIN Script
KOTLIN 
fun main() {
    // 1. A lambda stored in a variable
    val sum = { a: Int, b: Int -> a + b }

    // 2. Calling the lambda
    val result = sum(10, 20)
    println("Result of lambda: $result")
}
Output:
Result of lambda: 30

💡 Implicit Return Value
Notice there is no return keyword inside a lambda! In Kotlin, the last expression inside the lambda body is automatically returned as its result.
KOTLIN Script
KOTLIN 
val greet = { name: String ->
    "Hello, $name!" // Automatically returned
}

fun main() {
    println(greet("Aman"))
}
Output:
Hello, Aman!

3 Lambda Stored in a Variable

In Kotlin, functions are first-class citizens. This means you can assign a lambda to a variable, pass it around, and execute it later by appending parentheses ().

5 Lambda with One Parameter: The it Keyword

If a lambda has exactly one parameter, Kotlin lets you omit the parameter declaration entirely! Kotlin supplies the implicit name it to refer to that parameter:

}
Output:
Square of 5 = 25

6 Higher-Order Functions & Trailing Lambdas

A higher-order function is a function that does at least one of the following:

  • Takes another function/lambda as a parameter, OR
  • Returns another function as its result.
🍴 Restaurant Manager Analogy

A restaurant kitchen manager receives an order along with preparation instructions. The manager provides the kitchen station and ingredients, while the supplied instruction decides whether the dish is grilled or fried!

Visual 6: Injecting Behavior via Function Parameters
Visual 8: Kotlin's Signature Trailing Lambda Syntax
KOTLIN Script
KOTLIN 
fun compute(a: Int, b: Int, op: (Int, Int) -> Int): Int {
    return op(a, b)
}

fun main() {
    // Passing addition lambda
    val sum = compute(10, 5) { x, y -> x + y }

    // Passing multiplication lambda to same function!
    val product = compute(10, 5) { x, y -> x * y }

    println("Sum: $sum | Product: $product")
}
Output:
Sum: 15 | Product: 50

7 Standard Higher-Order Collection Functions

Kotlin's collection standard library is built entirely on higher-order functions:

Visual 7: Collection Pipeline Triad: map vs. filter vs. forEach
KOTLIN Script
KOTLIN 
fun main() {
    val numbers = listOf(1, 2, 3, 4, 5)

    // A. filter: select even numbers
    val evens = numbers.filter { it % 2 == 0 }
    println("Evens: $evens")

    // B. map: double each number
    val doubled = numbers.map { it * 2 }
    println("Doubled: $doubled")

    // C. sumOf: calculate total
    val total = numbers.sumOf { it }
    println("Sum: $total")
}
Output:
Evens: [2, 4]
Doubled: [2, 4, 6, 8, 10]
Sum: 15

8 Function Returning Another Function

fun getMultiplier(factor: Int): (Int) -> Int {
    return { number -> number * factor }
}

fun main() {
    val triple = getMultiplier(3)
    println("Triple of 7 = ${triple(7)}")
}
Output:
Triple of 7 = 21

10 Common Beginner Mistakes & Fixes

❌ 1. Missing Arrow ->

Writing { a: Int, b: Int a + b } fails to separate params from body.

Fix: Separate params with ->.

❌ 2. Using it in Multi-Param Lambdas

it is valid only for single-parameter lambdas.

Fix: Use explicit names { a, b -> ... }.

❌ 3. Confusing map & filter

filter tests conditions; map transforms items.

Fix: Use filter to keep items, map to change values.

❌ 4. Using return Inside Lambda

Writing bare return inside a lambda attempts to return from enclosing fun.

Fix: Let the last expression be the returned value.

❌ 5. Forgetting to Invoke Stored Lambda

Writing val fn = { ... }; fn without () does not execute.

Fix: Add parentheses: fn().

❌ 6. Using forEach to Transform List

forEach returns Unit and cannot construct a new list.

Fix: Use map when you need the transformed list.

11 Quick Revision

  • Lambda: Anonymous function literal enclosed in { p1, p2 -> body }.
  • Function Type: Signature written as (ParamTypes) -> ReturnType.
  • it: Automatic implicit parameter name for single-parameter lambdas.
  • Higher-Order Function: Function that takes functions as parameters or returns functions.
  • Trailing Lambda: When the last argument is a lambda, it can be written outside ().
  • filter vs map: filter selects items by predicate; map transforms items into new values.

12 Practice & Assessment

MCQ 1
1. In Kotlin, how is the return value of a lambda expression determined?
Answer: The value of the last expression in the lambda body is automatically returned.
MCQ 2
2. When can the implicit parameter name `it` be used in a lambda?
Answer: Only when the lambda has exactly one parameter and its type can be inferred.
MCQ 3
3. What is a higher-order function?
Answer: A function that takes another function as an argument, returns a function, or both.
MCQ 4
4. What is trailing lambda syntax in Kotlin?
Answer: Placing a lambda outside the function call parentheses if it is the last parameter.
MCQ 5
5. What does the collection function `map` do?
Answer: Transforms each element of a collection using the provided lambda, returning a new list.
