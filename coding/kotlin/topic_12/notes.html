Strings & String Templates in Kotlin

Master textual data processing in Kotlin. Learn character indexing, immutability, safe queries, powerful string transformations, and clean string interpolation using $variable and ${expression}.

1 Introduction to Strings in Kotlin

In programming, a String is an ordered sequence of characters used to store, manipulate, and display human-readable text. Whether it is a student's name, a college address, or a chat message, textual information is represented as a String.

In Kotlin, a Char holds exactly one single character enclosed in single quotes ('A'), whereas a String represents an ordered series of characters enclosed in double quotes ("Aman").

3 String Immutability (Unchangeable Content)

In Kotlin, Strings are immutable. Once a String object is allocated in memory, its characters can never be directly edited, lengthened, or shortened in-place.

Real-Life Analogy: Think of a printed physical document. If you spot an error on a printed paper certificate, you don't magically erase the ink on that paper; you reprint a brand-new page with the updated text. Similarly, any String function in Kotlin (like uppercase() or replace()) leaves the original String untouched and returns a newly allocated String.

Visual 4: Reassigning a var Points to a New Memory Object
Kotlin ImmutabilityDemo.kt
KOTLIN Script
KOTLIN 
fun main() {
    var student = "Aman"
    student = "Rahul"    // student now references a new String; "Aman" was not modified
    println(student)     // Rahul

    val original = "kotlin"
    val upper = original.uppercase()
    println(original)    // kotlin (Original remains completely lowercase!)
    println(upper)       // KOTLIN (New string returned by uppercase)
}
Execution Output: Rahul

4 Accessing Characters in a String (Zero-Based Indexing)

Every character in a Kotlin String has an index (position). Like most modern languages, Kotlin uses zero-based indexing, meaning the very first character is located at index 0, and the last character is at index length - 1.

Visual 5: Zero-Based Character Indexing — "Kotlin" (Length = 6)
Visual 6: Safe Index Access — text[10] vs text.getOrNull(10)
Kotlin IndexingDemo.kt
KOTLIN Script
KOTLIN 
fun main() {
    val language = "Kotlin"

    println(language[0])               // K (first character at index 0)
    println(language[1])               // o (second character)
    println(language.first())          // K
    println(language.last())           // n
    println(language.length)           // 6

    // Safe indexing
    val safeChar = language.getOrNull(10)
    println(safeChar)                  // null (Does not crash!)
}

5 String Templates with $variable

In older languages, building sentences from variables required tedious concatenation using + signs (e.g. "My name is " + name + " and I am " + age). Kotlin introduces String Templates: you simply place a $ directly in front of the variable name inside the double quotes!

KOTLIN Script

    val studentName = "Aman"
    val marks = 85
    val city = "Lucknow"

    // Effortless insertion using $variableName
    println("Student Name : $studentName")
    println("Score        : $marks / 100")
    println("City         : $city")
}

Score : 85 / 100
City : Lucknow

6 Expression Templates with ${expression}

What if you want to compute a math calculation, access an object property (like .length), or call a function inside your String? When you have anything more than a plain variable name, wrap it in curly braces: ${...}.

Visual 8: Expression Evaluation Flowchart — ${a + b} and ${name.length}
Kotlin ExpressionTemplates.kt
KOTLIN Script
KOTLIN 
fun main() {
    val price = 40
    val quantity = 3
    val title = "kotlin programming"

    // 1. Calculation inside ${}
    println("Total Bill: \$${price * quantity}")

    // 2. Property access inside ${}
    println("Title characters: ${title.length}")

    // 3. Function call inside ${}
    println("Capitalized: ${title.uppercase()}")
}
Execution Output: Total Bill: $120
Title characters: 18
Capitalized: KOTLIN PROGRAMMING
&info;
Pro Tip: $title.length without braces will print the string "kotlin programming.length"! Always wrap dotted property calls in braces: ${title.length}.

7 String Concatenation (+) vs String Templates

You can also join strings together using the plus operator (+). While concatenation is valid and commonly used for small joins, Kotlin's String Templates are preferred because they are cleaner, eliminate quote clutters, and execute faster.

9 Comparing Strings (== vs equals(ignoreCase = true))

In Kotlin, the equality operator == checks for value equality (whether the content inside both strings is identical). Unlike in Java, you do not have to write str1.equals(str2) for regular comparisons!

Because strings are case-sensitive by default, "Kotlin" == "kotlin" evaluates to false. To perform a case-insensitive check, pass ignoreCase = true to equals().

Visual 11: Case-Sensitive (==) vs Case-Insensitive Comparison
Kotlin StringComparison.kt
KOTLIN Script
KOTLIN 
fun main() {
    val enteredPassword = "secret123"
    val actualPassword = "secret123"
    println(enteredPassword == actualPassword)  // true

    val city1 = "Lucknow"
    val city2 = "lucknow"
    println(city1 == city2)                    // false
    println(city1.equals(city2, ignoreCase = true))  // true
}
Execution Output: true
false
true

11 Multiline Strings (Triple Quotes """ & trimIndent())

When drafting long messages, emails, or JSON payloads spanning multiple lines, writing endless \n characters is exhausting. Kotlin solves this with Raw Multiline Strings wrapped in triple quotes: """ ... """.

By default, your code indents inside the function. Adding trimIndent() strips away common leading indent spaces while preserving your intentional multi-line formatting!

13 Common Beginner Mistakes & How to Fix Them

✗ Mistake 1: Single quotes for Strings

val name = 'Aman' // Compile Error!

Fix: Single quotes are exclusively for single Char. Always use double quotes for strings: "Aman".

✗ Mistake 2: Missing braces for expressions

println("Length: $name.length")

Fix: Wrap dotted properties in braces: println("Length: ${name.length}").

✗ Mistake 3: Off-by-one index crash

val last = text[text.length] // Crashes!

Fix: Indexing starts at 0. Last index is text[text.length - 1] or simply text.last().

✗ Mistake 4: Expecting in-place modification

str.uppercase(); println(str) // Still lowercase!

Fix: Strings are immutable. Assign the result: val upper = str.uppercase().

✗ Mistake 5: Case-sensitive comparison trap

if (role == "admin") // Fails on "Admin"

Fix: Use role.equals("admin", ignoreCase = true) or role.lowercase() == "admin".

✗ Mistake 6: Unescaped dollar sign

println("Price: $50") // Expects variable '50'

Fix: Escape the dollar sign with a backslash: println("Price: \$50").

14 Quick Revision & Takeaways

  • String is an ordered sequence of characters: Enclosed in double quotes "...".
  • Strings are immutable: Character content cannot be changed in place; functions return new String objects.
  • Zero-based indexing: First character is at [0]; safe index lookup uses getOrNull(index).
  • Simple templates: Use $variableName to embed variables cleanly into strings.
  • Expression templates: Use ${expression} for math, calculations, and property/method calls.
  • Structural Equality: Use == to check text value equality; use equals(..., ignoreCase = true) for case-insensitive checks.
  • Escape Characters: \n (newline), \t (tab), \" (quote), \$ (literal dollar).
  • Multiline Strings: Use triple quotes """ ... """ with trimIndent() for clean block formatting.
