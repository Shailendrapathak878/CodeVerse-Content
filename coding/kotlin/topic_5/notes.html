Kotlin Data Types & Type Conversion

Explore how Kotlin represents information in memory — master numeric types, characters, strings, booleans, unsigned numbers, and explicit safe type conversions.

1 Introduction to Data Types

In everyday life, you wouldn't pour milk into a wicker basket or store shoes in an envelope. Different kinds of physical items require specific, appropriately sized containers.

📦 The Storage Container Analogy

A data type tells the computer what kind of value a variable is holding, how much RAM it occupies, and what operations can legally be performed on it:
• Numbers (`Int`, `Double`): Can be added, multiplied, and rounded.
• Text (`String`): Can be searched, capitalized, and concatenated.
• Truth Values (`Boolean`): Can be checked for decision-making (yes/no).

BasicDataTypes.kt
KOTLIN Script
KOTLIN 
fun main() {
    val age: Int = 21
    val temperature: Double = 98.6
    val section: Char = 'A'
    val studentName: String = "Pooja"
    val isRegistered: Boolean = true

    println("$studentName (Section $section): Age $age, Temp $temperature°F, Active: $isRegistered")
}
Output:
Pooja (Section A): Age 21, Temp 98.6°F, Active: true

2 Kotlin's Type System

Kotlin is a statically typed language. This means:

  • Every variable and expression has a type verified by the compiler before your program runs.
  • Bugs like multiplying a word by a true/false value are caught instantly during development, not after shipping to users.
  • Kotlin treats primitive types (like Int and Double) as objects with helpful methods (e.g. 25.toDouble()), while the compiler automatically optimizes them down to high-speed JVM primitives behind the scenes!

3 Main Kotlin Basic Data Types

A. Integer Types (Whole Numbers)

Kotlin provides four signed integer types that vary by bit width and memory capacity:

Type Bit Size Range Example / Literal Typical Real-World Use
Byte 8 bits -128 to 127 val b: Byte = 100 Binary streaming, image raw pixels
Short 16 bits -32,768 to 32,767 val s: Short = 25000 Memory-constrained IoT devices
Int 32 bits ~ -2.14 Billion to +2.14 Billion val count = 500 Standard default for integer numbers
Long 64 bits ~ -9.22 Quintillion to +9.22 Quintillion val stars = 9000000000L (Suffix 'L') Database primary IDs, epoch timestamps

B. Floating-Point Types (Decimals)

For numbers with decimal places, Kotlin offers two types:

Float (32 bits)

Single precision with 6–7 decimal digits. Must be explicitly tagged with an f or F suffix.

KOTLIN Script
KOTLIN 
val pi: Float = 3.14159f

Double (64 bits)

Double precision with 15–16 decimal digits. The default inferred type for decimal numbers.

KOTLIN Script
KOTLIN 
val taxRate = 18.75  // Inferred Double

C. Character Type (`Char`)

Represents a single 16-bit Unicode character enclosed in single quotes (' '):

KOTLIN Script
KOTLIN 
val grade: Char = 'A'
val currencySymbol: Char = '₹'
val newlineChar: Char = '\n'  // Escape character

D. String Type (`String`)

Represents an ordered sequence of characters enclosed in double quotes (" "). Supports indexing and string templates:

StringDemo.kt
KOTLIN Script
KOTLIN 
fun main() {
    val title = "Kotlin"
    println("First letter: ${title[0]}")  // Indexing (0-based)
    println("Total characters: ${title.length}")
}
Output:
First letter: K
Total characters: 6

E. Boolean Type (`Boolean`)

Stores binary truth values: either true or false. Used extensively in decision-making and logic conditions.

F. Unsigned Integer Types

Kotlin also provides unsigned integers: UByte, UShort, UInt, and ULong. Because they do not store negative numbers, their positive capacity is doubled (e.g. UByte stores 0 to 255). Marked with a u or U suffix (e.g. val port: UInt = 8080u).

4 Explicit Type Conversion in Kotlin

In some programming languages like Java or C++, smaller numbers are automatically and silently converted into larger numbers (called implicit widening). Kotlin does NOT do implicit numeric conversions!

⚠️ Why Kotlin Requires Explicit Conversion

Silent automatic conversion often causes subtle arithmetic bugs and unexpected equality failures. In Kotlin, if you want to turn an Int into a Double, you must explicitly call a conversion method!

NumericConversion.kt
KOTLIN Script
KOTLIN 
fun main() {
    val intVal: Int = 25

    // THIS FAILS: val d: Double = intVal (Type Mismatch)
    // CORRECT: Explicitly call .toDouble()
    val doubleVal: Double = intVal.toDouble()
    val longVal: Long = intVal.toLong()

    println("Int: $intVal | Double: $doubleVal | Long: $longVal")
}
Output:
Int: 25 | Double: 25.0 | Long: 25

5 String to Number Conversion & Safe Parsing

When reading user input from text fields or network APIs, numbers arrive as String text (e.g. "25"). You must parse them into numeric types before performing mathematical operations:

StringParsing.kt
KOTLIN Script
KOTLIN 
fun main() {
    val ageString = "20"
    val ageNumber = ageString.toInt()
    println("Age in 5 years: ${ageNumber + 5}")

    // DANGER: If input is invalid (e.g. "abc"), .toInt() crashes with NumberFormatException!
}
Output:
Age in 5 years: 25

Safe Parsing with `toIntOrNull()`

To prevent app crashes when user input is invalid, Kotlin provides toIntOrNull() and toDoubleOrNull(). If parsing succeeds, it returns the number; if parsing fails, it safely returns null instead of crashing:

SafeConversion.kt
KOTLIN Script
KOTLIN 
fun main() {
    val goodInput = "45"
    val badInput = "hello"

    val num1 = goodInput.toIntOrNull()
    val num2 = badInput.toIntOrNull()

    println("Parsed '45': $num1")
    println("Parsed 'hello': $num2")

    // Safe verification
    if (num1 != null) {
        println("Valid calculation: ${num1 * 2}")
    }
}
Output:
Parsed '45': 45
Parsed 'hello': null
Valid calculation: 90

6 Type Conversion vs. Type Casting

Type Conversion (Data Transformation)

Takes an existing value and transforms it into a completely new representation (e.g. 25.toDouble() produces 25.0). Uses dedicated toX() functions.

Type Casting (Object Re-labeling)

Tells the compiler to treat an existing object reference as a more specific subtype (e.g. obj as String). `as` cannot convert numbers (e.g. num as Double fails at runtime with ClassCastException).

7 Common Beginner Mistakes & Fixes

Mistake 1 • Implicit Conversion
Expecting automatic widening

val x: Int = 10; val y: Double = x

Fix: Explicitly convert: val y: Double = x.toDouble().
Mistake 2 • Quotes Confusion
Double quotes for Char

val grade: Char = "A"

Fix: Use single quotes for Char: val grade: Char = 'A'.
Mistake 3 • Unsafe String Parsing
Crashing on non-numeric input

val n = "N/A".toInt() // Crash!

Fix: Use safe parsing: val n = "N/A".toIntOrNull().
Mistake 4 • Missing Float Suffix
Assigning double literal to Float

val rate: Float = 3.14

Fix: Append f suffix: val rate: Float = 3.14f.

8 Real-World Mini Project: Student Report Card

A complete, working Kotlin program calculating student totals and averages using appropriate data types:

ReportCard.kt
KOTLIN Script
KOTLIN 
fun main() {
    val studentName: String = "Karan Malhotra"
    
    // Whole subject marks stored as Int
    val mathScore: Int = 88
    val scienceScore: Int = 92
    val englishScore: Int = 85

    // Calculate total
    val totalMarks: Int = mathScore + scienceScore + englishScore

    // Convert Int to Double before division to preserve decimal precision!
    val averagePercentage: Double = totalMarks.toDouble() / 3.0
    val isPassed: Boolean = averagePercentage >= 50.0
    val gradeLetter: Char = if (averagePercentage >= 90.0) 'A' else 'B'

    println("==================================")
    println("STUDENT ACADEMIC REPORT")
    println("Name: $studentName")
    println("Total Marks: $totalMarks / 300")
    println("Average: ${averagePercentage}%")
    println("Grade: $gradeLetter | Passed: $isPassed")
    println("==================================")
}
Output:
==================================
STUDENT ACADEMIC REPORT
Name: Karan Malhotra
Total Marks: 265 / 300
Average: 88.33333333333333%
Grade: B | Passed: true
==================================

9 Quick Revision

  • Basic Types: Byte, Short, Int, Long, Float, Double, Char, String, Boolean.
  • Default Inferences: Whole numbers infer as Int; decimal numbers infer as Double.
  • Literals: Longs end in L; Floats end in f or F; Chars use single quotes ' '.
  • No Implicit Widening: Kotlin requires explicit conversion methods like .toDouble() and .toLong().
  • Safe Parsing: Always prefer toIntOrNull() to prevent app crashes when converting external strings.
  • Conversion vs. Casting: Conversion transforms data using toX(); casting re-labels object references using as.

10 Practice & Assessment

Test your understanding of data types and conversion:

Concept Q1
1. Why does Kotlin disallow implicit numeric conversion (like assigning Int directly to Double)?
Answer: Implicit conversion causes subtle bugs, precision losses, and unexpected equality failures. Kotlin requires explicit calls like .toDouble() to ensure code intent is clear.
Type Identification Q2
2. Identify the inferred data type for each of the following literals:
Answers:
• 42 → Int
• 42L → Long
• 3.14 → Double
• 3.14f → Float
• 'Z' → Char
• "Z" → String
Conversion Q3
3. What is the difference between `toInt()` and `toIntOrNull()` on a String?
Answer: toInt() throws a NumberFormatException crash if the string is not a valid number. toIntOrNull() returns null safely without crashing.
Output Prediction Q4
4. What will be printed by this code?
KOTLIN Script
KOTLIN 
fun main() {
    val a: Int = 5
    val b: Int = 2
    println(a / b)
}
Answer: 2. Integer division truncates the decimal portion. To get 2.5, at least one operand must be converted to Double: a.toDouble() / b.

fun main() {

}
Answer: Type mismatch! "X" is a String (in double quotes). Char values must use single quotes: 'X'.
Practical Coding Task
Task: Write a Kotlin program that takes a string representation of an item price ("199") and quantity ("3"), safely parses them into numbers, and prints the total payable amount.
Solution:
KOTLIN Script
KOTLIN 
fun main() {
    val priceInput = "199"
    val qtyInput = "3"

    val price = priceInput.toIntOrNull() ?: 0
    val qty = qtyInput.toIntOrNull() ?: 0

    println("Total Bill: ₹${price * qty}")
}
