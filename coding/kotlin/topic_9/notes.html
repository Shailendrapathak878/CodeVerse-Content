1 Introduction to Functions

A function is a self-contained, named block of reusable code designed to perform a specific task. Instead of duplicating the same 10 lines of code across your project, you write a function once and call it whenever needed.

🛠 Real-Life Analogy: The Washing Machine Button

A washing machine has a "Start Wash" button. You do not manually wash, rinse, and spin by hand every single day; you simply press the button, and the machine executes that predefined set of actions.

KOTLIN Script

// 1. Declaring the function
fun sayHello() {
    println("Hello, welcome to CodeVerse!")
}

fun main() {
    // 2. Calling the function
    sayHello()
}

Hello, welcome to CodeVerse!

4 Parameters & Arguments

Beginners often confuse parameters with arguments:

  • Parameter: The variable declared in the function definition (e.g., name: String).
  • Argument: The actual real value passed into the function when calling it (e.g., "Rahul").

    println("Total Bill: ₹$total")
}

fun main() {
    calculateBill(150, 3)
}
Output:
Total Bill: ₹450

5 Return Values & Return Type

Functions can pass results back to the caller using the return keyword. The type of data returned must match the declared return type:

6 The Unit Return Type

If a function does not return any meaningful value, its return type is Unit (analogous to void in Java/C). Specifying : Unit is optional:

KOTLIN Script
KOTLIN 
// Both declarations are 100% identical in Kotlin
fun greetA(): Unit {
    println("Explicit Unit")
}

fun greetB() {
    println("Implicit Unit (preferred clean style)")
}

8 Single-Expression Functions

When a function body consists of a single expression, you can remove the curly braces and return keyword, replacing them with =:

    println("Max of 15 and 28 = ${maxVal(15, 28)}")

Max of 15 and 28 = 28

9 Variable Arguments (vararg)

The vararg modifier lets a function accept a variable number of arguments (zero or more), which are treated as an array inside the function:

Visual 11: Flexible Multi-Argument Packing
KOTLIN Script
KOTLIN 
fun sumAll(vararg numbers: Int): Int {
    var total = 0
    for (n in numbers) {
        total += n
    }
    return total
}

fun main() {
    println("Sum 2 items: ${sumAll(5, 10)}")
    println("Sum 4 items: ${sumAll(1, 2, 3, 4)}")
}
Output:
Sum 2 items: 15
Sum 4 items: 10

fun calculateDiscountedTotal(price: Double, qty: Int, discountPercent: Double = 10.0): Double {

12 Common Beginner Mistakes & Fixes

❌ 1. Declared But Never Called

Writing a function definition but forgetting to call it in main().

Fix: Remember functions execute only when invoked.

❌ 2. Confusing println & return

Using println instead of return loses output data.

Fix: Use return to send results back to callers.

❌ 3. Missing Return in Block Body

Functions declaring non-Unit return types must have an explicit return.

Fix: Write return value before closing }.

❌ 4. Wrong Argument Types

Passing "25" (String) to an Int parameter causes compile error.

Fix: Match parameter types strictly.

❌ 5. Confusing Parameter vs Argument

Parameter is variable in header; Argument is value in call.

Fix: Understand declaration vs call-site.

❌ 6. Typos in Named Arguments

Writing greet(user = "Aman") when parameter is name.

Fix: Named arguments must match parameter names exactly.

13 Quick Revision

  • Function: Reusable block declared with fun functionName() { ... }.
  • Parameters vs. Arguments: Parameters are definitions; Arguments are passed values.
  • Return Types: Specifies output type (e.g. : Int); defaults to Unit if omitted.
  • Default Parameters: Assigned via param: Type = defaultVal to prevent excessive overloads.
  • Named Arguments: Callers can supply arguments out-of-order by specifying name = value.
  • Single-Expression Functions: Concise syntax: fun double(x: Int) = x * 2.
  • vararg: Accepts zero or more values as a packed array.

Answer: fun • Functions in Kotlin always start with the fun keyword.
MCQ 2
2. What is the default return type of a function that does not return a value?
Answer: Unit • Unit represents the absence of a meaningful return value.
MCQ 3
3. What is the benefit of default parameter values in Kotlin?
Answer: Allows omitting arguments when calling and reduces the need for multiple overloaded functions.
MCQ 4
4. Which syntax represents a single-expression function?
Answer: fun triple(n: Int) = n * 3.
MCQ 5
5. How does a function receive multiple arguments passed via `vararg`?
Answer: Inside the function, the parameter is treated as an array of that type.
