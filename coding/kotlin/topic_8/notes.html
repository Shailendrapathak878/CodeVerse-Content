1 Introduction to Loops

A loop is a programming structure that repeats a block of code multiple times until a specific condition becomes false. In real applications, loops process lists of users, compute totals, animate graphics, and automate repetitive tasks.

📝 Real-Life Analogy: Writing Lines

Imagine a teacher asking a student to write "I will complete my homework" 10 times. Instead of writing 10 separate print statements by hand, a loop executes a single instruction 10 times automatically.

2 The for Loop

The for loop iterates over anything that provides an iterator, such as ranges, arrays, or collections. In Kotlin, you do not write traditional C-style index loops like for (int i=0; i<n; i++). Instead, Kotlin uses the much cleaner for (item in range) syntax.

3 The while Loop

A while loop repeats its block of code as long as its condition remains true. The condition is verified before each iteration. If the condition is false initially, the loop body executes zero times!

💧 Filling a Water Bottle
While the bottle is not full, you keep pouring water. If the bottle is already full at the start, you pour zero drops.
Visual 4: while Loop Entry Condition Flowchart
WhileLoop.kt
KOTLIN Script
KOTLIN 
fun main() {
    var cupsPoured = 0

    while (cupsPoured < 3) {
        println("Poured cup #$cupsPoured")
        cupsPoured++ // Increment condition variable!
    }
    println("Bottle is full!")
}
Output:
Poured cup #0
Poured cup #1
Poured cup #2
Bottle is full!

4 The do-while Loop

The do-while loop is an exit-controlled loop. It executes the code block first, and then tests the condition. As a result, a do-while loop is guaranteed to execute at least once, even if the condition is false from the beginning!

🍴 Restaurant Menu Prompt
The restaurant displays the dessert menu at least once. Afterwards, it asks: "Would you like to order another item?" If you say No, it stops.
Visual 5: do-while Guaranteed First Execution Flowchart
DoWhileLoop.kt
KOTLIN Script
KOTLIN 
fun main() {
    var number = 100

    do {
        println("Printed at least once! Value = $number")
    } while (number < 5) // Condition is immediately false
}
Output:
Printed at least once! Value = 100

7 Looping Through Ranges

Combining range expressions with for loops enables clean, readable iteration:

KOTLIN Script
KOTLIN 
fun main() {
    // 1. Counting backwards
    for (i in 3 downTo 1) print("$i ")
    println()

    // 2. Even numbers using step
    for (i in 2..8 step 2) print("$i ")
    println()

    // 3. Character range
    for (ch in 'A'..'D') print("$ch ")
}
Output:
3 2 1
2 4 6 8
A B C D

9 break and continue Statements

Visual 11: break (Terminate) vs. continue (Skip Step)
KOTLIN Script
KOTLIN 
fun main() {
    // break: stops when finding target 3
    for (n in 1..5) {
        if (n == 3) break
        print("$n ")
    }
    println()

    // continue: skips even number 2
    for (n in 1..4) {
        if (n % 2 == 0) continue
        print("$n ")
    }
}
Output:
1 2
1 3

10 Nested Loops

A nested loop is a loop inside another loop. For every single iteration of the outer loop, the inner loop completes its full cycle.

11 Common Beginner Mistakes & Fixes

❌ 1. Forgetting Variable Update

In while loops, forgetting i++ causes infinite looping.

Fix: Always update loop counter in the body.

❌ 2. Inverted Range without downTo

for (i in 5..1) produces an empty range that never runs.

Fix: Use for (i in 5 downTo 1).

❌ 3. Invalid Step Value

step 0 or negative steps throw IllegalArgumentException.

Fix: Step must always be positive (e.g. step 2).

❌ 4. Off-by-One Range Confusion

Using 1..n when 0-based indexing is needed causes out-of-bounds.

Fix: Use 0 until array.size or array.indices.

❌ 5. Confusing break & continue

Using break terminates everything; continue only skips 1 step.

Fix: Select continue when processing further items.

❌ 6. False Initial while Condition

If condition is false before start, while body runs 0 times.

Fix: Use do-while if 1 run is required.

13 Quick Revision

  • for Loop: Used for ranges and collections; syntax: for (item in range).
  • while Loop: Tests condition before running; runs 0 or more times.
  • do-while Loop: Tests condition after running; guaranteed ≥ 1 execution.
  • Ranges: 1..5 (inclusive), 1 until 5 (excludes 5), downTo (backwards), step (custom delta).
  • break: Exits the entire loop structure immediately.
  • continue: Skips remainder of current step and moves to next iteration.

14 Practice & Assessment

MCQ 1
1. Which loop construct is guaranteed to execute its code block at least once?
Answer: do-while • It evaluates the condition after executing the body.
MCQ 2
2. What numbers are generated by the range expression `1..5`?
Answer: 1, 2, 3, 4, 5 • The `..` operator is closed and includes both ends.
MCQ 3
3. What is the output of `for (i in 5..1) print(i)` in Kotlin?
Answer: Prints nothing • `5..1` produces an empty progression. Use `5 downTo 1` to count backwards.
MCQ 4
4. What does the `continue` statement do when reached inside a loop?
Answer: It immediately skips the rest of the current iteration and jumps to the next iteration.
MCQ 5
5. What happens if a `step` argument of 0 or negative is passed to a range?
Answer: Throws IllegalArgumentException • Step values must be strictly positive.
