1 Introduction to Operators & Operands

An operator is a special symbol (like +, -, *, ==) that tells the compiler to perform a specific mathematical, logical, or relational action. The values or variables that the operator acts upon are called operands.

🧮 The Pocket Calculator Analogy

Think of a standard pocket calculator:
• You type 10 (First Operand)
• You press + (The Operator: tells the machine what action to perform)
• You type 5 (Second Operand)
• The screen outputs 15 (The Evaluated Expression Result)

BasicOperation.kt
KOTLIN Script
KOTLIN 
fun main() {
    val apples = 10
    val oranges = 5
    val totalFruit = apples + oranges  // '+' is operator; apples & oranges are operands

    println("Total Fruits: $totalFruit")
}
Output:
Total Fruits: 15

2 Arithmetic Operators

Arithmetic operators perform standard mathematical calculations:

Operator Name Example Result Description
+ Addition 12 + 8 20 Calculates the sum of numbers or joins strings.
- Subtraction 25 - 7 18 Subtracts the right operand from the left.
* Multiplication 6 * 4 24 Multiplies both operands.
/ Division 20 / 4 5 Divides numerator by denominator.
% Modulus (Remainder) 17 % 5 2 Returns the remainder after integer division.

Critical Concept: Integer vs. Decimal Division

When both operands are integers, Kotlin performs Integer Division and discards any fractional remainder:

KOTLIN Script
KOTLIN 
val intDivision = 10 / 3          // Result: 3 (truncated, not 3.33!)
val decimalDivision = 10.0 / 3.0  // Result: 3.3333333333333335 (Double division)
val mixedDivision = 10.toDouble() / 3  // Result: 3.3333333333333335

The Modulus Operator (`%`) & Even/Odd Checking

The % operator yields the remainder left over after division. It is the universal developer tool for checking whether a number is even or odd:

KOTLIN Script
KOTLIN 
val number = 14
val isEven = (number % 2 == 0)  // True if remainder is 0
println("Is $number even? $isEven") // Output: Is 14 even? true

3 Assignment Operators

The basic assignment operator = stores a value into a variable. Kotlin also provides compound assignment operators (+=, -=, *=, /=, %=) which perform the math and reassign in one step:

WalletTracker.kt
KOTLIN Script
KOTLIN 
fun main() {
    var walletBalance = 500  // Must be mutable (var) to reassign!

    walletBalance += 200     // Equivalent to: walletBalance = walletBalance + 200
    println("After Salary Bonus: ₹$walletBalance")

    walletBalance -= 150     // Equivalent to: walletBalance = walletBalance - 150
    println("After Grocery Bill: ₹$walletBalance")
}
Output:
After Salary Bonus: ₹700
After Grocery Bill: ₹550

4 Comparison Operators (Relational)

Comparison operators test the relationship between two values and always return a Boolean: either true or false.

Operator Meaning Example (`a = 10`, `b = 20`) Result
== Equal to (Structural equality) a == b false
!= Not equal to a != b true
> Greater than a > b false
< Less than a < b true
>= Greater than or equal to a >= 10 true
<= Less than or equal to b <= 15 false
⚠️ `=` vs. `==` vs. `===`

• = is for Assignment: val x = 10 (stores 10 into x).
• == is for Structural Equality: x == 10 (checks if the contents are equal).
• === is for Referential Equality: checks if both variables point to the exact same object reference in memory.

5 Logical Operators & Truth Tables

Logical operators combine multiple boolean conditions together:

&& (Logical AND)

Returns true only if BOTH conditions are true.

|| (Logical OR)

Returns true if AT LEAST ONE condition is true.

! (Logical NOT)

Inverts the boolean value (!true becomes false).

Truth Table Reference

A B A && B (AND) A || B (OR) !A (NOT)
true true true true false
true false false true false
false true false true true
false false false false true
⚡ Short-Circuit Evaluation

Kotlin optimizes logical expressions:
• In false && conditionB, Kotlin skips checking conditionB because the result is already guaranteed to be false.
• In true || conditionB, Kotlin skips conditionB because the result is already guaranteed to be true.

6 Increment (`++`) & Decrement (`--`) Operators

The increment operator increases an integer by 1; decrement decreases it by 1. Kotlin distinguishes between Prefix and Postfix:

Prefix: ++x / --x

Increments first, then uses the updated value in the expression.

Postfix: x++ / x--

Uses the original value first, then increments the variable afterwards.

IncrementDemo.kt
KOTLIN Script
KOTLIN 
fun main() {
    var a = 5
    var b = 5

    println(++a)  // Prefix: Increments to 6 FIRST, then prints: 6
    println(b++)  // Postfix: Prints original 5 FIRST, then b becomes 6 in memory!
    println(b)    // Now prints: 6
}
Output:
6
5
6

7 Range & Membership Operators (`in`, `!in`, `..`)

Kotlin features native range syntax for testing whether numbers or characters fall within an interval:

Operator Syntax Meaning Example
.. start..end Closed range (includes both start and end) 1..5 contains 1, 2, 3, 4, 5
in x in range Tests if value belongs to range 3 in 1..5 → true
!in x !in range Tests if value is outside range 10 !in 1..5 → true
KOTLIN Script
KOTLIN 
val examScore = 82
val isValidScore = examScore in 0..100
println("Is score in legal 0-100 range? $isValidScore") // Output: true

8 Type Checking (`is`) & Elvis Operator (`?:`)

Type Checking: is and !is

Verifies whether an object belongs to a given type at runtime:

KOTLIN Script
KOTLIN 
val obj: Any = "Kotlin"
println(obj is String) // true

Elvis Operator: ?: (Fallback)

Provides a safe fallback value if a nullable variable contains null:

KOTLIN Script
KOTLIN 
val inputName: String? = null
val user = inputName ?: "Guest"
println(user) // Output: Guest

9 Kotlin as an Expression-Oriented Language

In Kotlin, constructs like if-else and when can be used as expressions that evaluate to a value:

ExpressionsDemo.kt
KOTLIN Script
KOTLIN 
fun main() {
    val marks = 75

    // 1. 'if' as an Expression
    val result = if (marks >= 40) "Pass" else "Fail"

    // 2. 'when' as an Expression
    val gradeLetter = when {
        marks >= 90 -> 'A'
        marks >= 75 -> 'B'
        else -> 'C'
    }

    println("Result: $result | Grade: $gradeLetter")
}
Output:
Result: Pass | Grade: B

10 Operator Precedence & Parentheses

When multiple operators appear in a single line, Kotlin follows precedence rules (multiplication & division happen before addition & subtraction). Always use parentheses () to guarantee clear evaluation order:

KOTLIN Script
KOTLIN 
val a = 10 + 5 * 2    // 10 + 10 = 20 (* evaluated before +)
val b = (10 + 5) * 2  // 15 * 2 = 30 (Parentheses evaluate first!)

12 Common Beginner Mistakes & Fixes

Mistake 1 • `=` vs `==`
Using assignment in conditions

if (marks = 100) // Error!

Fix: Use == for comparison: if (marks == 100).
Mistake 2 • Truncated Division
Expecting 5/2 to equal 2.5

val avg = 5 / 2 // Gives 2!

Fix: Convert to Double: val avg = 5.0 / 2.
Mistake 3 • Postfix Confusion
Expecting immediate update from x++

println(x++) // Prints old x!

Fix: Use prefix ++x if you need the incremented value immediately.
Mistake 4 • Operator Precedence
Omitting grouping parentheses

val total = a + b * 2

Fix: Use parentheses for clarity: val total = (a + b) * 2.

13 Quick Revision

  • Arithmetic: +, -, *, /, % (Remember: Int division truncates decimals).
  • Comparison: ==, !=, >, <, >=, <= return Boolean.
  • Logical: && (AND), || (OR), ! (NOT) with short-circuit evaluation.
  • Prefix vs. Postfix: ++x increments first; x++ returns current value then increments.
  • Ranges: 1..5 includes both ends; check membership with in and !in.
  • Elvis Operator: nullable ?: fallback supplies default values safely.
  • Expressions: In Kotlin, if and when return values and can be assigned to variables directly.

14 Practice & Assessment

Test your understanding of operators and expressions:

Concept Q1
1. What is the result of `19 % 4` and what does it represent?
Answer: 3. The modulus operator calculates the remainder left over when 19 is divided by 4 (4 × 4 = 16, remainder = 3).
Logic Q2
2. How does short-circuit evaluation work with `&&`?
Answer: If the left condition of an && expression is false, Kotlin does not evaluate the right condition because the final result is already guaranteed to be false.
Output Prediction Q3
3. What will be printed by this code snippet?
KOTLIN Script
KOTLIN 
fun main() {
    var count = 10
    val res = count++ + 2
    println("res: $res, count: $count")
}
Answer: res: 12, count: 11.
Explanation: count++ uses original value 10 in the addition (10 + 2 = 12), and then increments count to 11.
Output Prediction Q4
4. What is the value of `val grade = 8 in 1..10`?
Answer: true. The in operator tests if 8 is within the closed interval [1, 10].
Find the Error Q5
5. Why will this code fail to compile?
KOTLIN Script
KOTLIN 
fun main() {
    val x = 10
    x += 5
    println(x)
}
Answer: x was declared with val (read-only). Compound assignment += reassigns the variable, which requires var.
Practical Coding Task
Task: Write a program that checks whether a user's age is between 18 and 60 (inclusive) AND whether they have a driver's license, printing "Eligible to Drive" or "Not Eligible" using an `if` expression.
Solution:
KOTLIN Script
KOTLIN 
fun main() {
    val age = 24
    val hasLicense = true

    val status = if ((age in 18..60) && hasLicense) {
        "Eligible to Drive"
    } else {
        "Not Eligible"
    }

    println(status)
}
