Pseudorandom Numbers: Computer Randomness Kaise Banata Hai?

Pure physical randomness (jaise atmospheric noise ya radioactive decay) computers ke CPU mein naturally available nahi hoti. Isliye computers Pseudorandom Number Generators (PRNG) use karte hain. PRNG ek deterministic mathematical algorithm hota hai jo numbers ki aisi sequence calculate karta hai jo statistically pure random numbers jaisi behave karti hai.

⚠️ Security Clarification: NumPy ke standard random functions mathematical experiments, machine learning aur simulations ke liye design kiye gaye hain. Inhe kabhi bhi cryptographic secrets, user passwords, ya security tokens generate karne ke liye use mat kijiye (uske liye Python ka built-in secrets module use hota hai).

⚙️ A. Understanding NumPy's Modern Random Generator

NumPy 1.17 se pehle pura world legacy functions use karta tha jaise np.random.randint() ya np.random.seed(). Yeh legacy functions ek shared global state par depend karte the jisse code race conditions aur statistical flaws se suffer karta tha.

Modern NumPy mein standard aur best practice hai Generator Object create karna:

modern_rng_syntax.py Core Concept 
rng = np.random.default_rng(seed=None)  # Modern PCG64 BitGenerator
  • np.random.default_rng(): NumPy ka official constructor function jo ek dedicated Generator instance banata hai.
  • rng: Yeh koi Python keyword nahi hai! Yeh sirf ek convenient variable name hai jiska matlab Random Number Generator hai. Aap chahein to gen = np.random.default_rng() bhi likh sakte hain.
  • PCG64 Engine: Under the hood, modern NumPy PCG64 (Permuted Congruential Generator) bit-generator use karta hai jo legacy Mersenne Twister se vastly faster aur statistically superior hai.
  • Best Practice: Ek application ya script mein sirf ek generator initialize karke usko reuse karna sabse clean aur performant approach hoti hai.

🌱 C. Seeds, State Advancement & Reproducibility

Data science aur machine learning mein Reproducibility (results ko dobara recreate kar pana) ek fundamental requirement hoti hai. Agar aapka research paper ya machine learning model kisi aur ke computer par alag accuracy de, to use peer review mein reject kar diya jata hai.

Seed Kya Hota Hai?

Ek Seed PRNG algorithm ke mathematical formula ka initial starting input hota hai.

  • Jab aap generator ko ek fixed seed (e.g. 42 ya 123) dete hain, to algorithm hamesha usi exact initial internal state se calculate karna start karta hai.
  • Har baar jab aap random draw karte hain (e.g., rng.integers()), to generator ka internal state mathematically aage badh jata hai (State Advance). Agli call naya random number deti hai.
  • Agar aap do separate generators ko bilkul same seed denge, to unka first draw, second draw, aur hundredth draw 100% exact match karega!

Example 1: Same Seed, Same Sequence Verification

reproducible_seeds.py Python 3 
import numpy as np

# Do independent generators initialized with same seed 123
rng1 = np.random.default_rng(123)
rng2 = np.random.default_rng(123)

values1 = rng1.integers(0, 100, size=10)
values2 = rng2.integers(0, 100, size=10)

print("Generator 1 Sequence:", values1)
print("Generator 2 Sequence:", values2)
print("Are both sequences identical?:", np.array_equal(values1, values2))
Verified Execution Output:
Generator 1 Sequence: [ 1 68 59 5 90 22 25 18 33 17] Generator 2 Sequence: [ 1 68 59 5 90 22 25 18 33 17] Are both sequences identical?: True

📏 D. Continuous Uniform Distribution

Ek Continuous Uniform Distribution mein kisi specified interval [low, high) ke andar har sub-interval of equal length ki occur hone ki probability density barabar hoti hai.

💡 Mathematical Meaning: Continuous model mein individual single point ki probability zero hoti hai (kyunki infinite real numbers hote hain), lekin Probability Density Function flat horizontal line hoti hai:
f(x) = 1 / (high - low) for low ≤ x < high
Iska theoretical mean interval ka exact midpoint hota hai: (low + high) / 2.

print("Sample Min:", round(float(wait_times.min()), 3))

🔔 E. Normal (Gaussian) Distribution

Normal Distribution (Bell Curve) statistics aur machine learning ki sabse famous aur widely-used continuous distribution hai. Central Limit Theorem ke anusaar, jab bahut saare independent random factors combine hote hain, to unka sum ya average normal curve jaisa ban jata hai.

normal_syntax.py Syntax 
data = rng.normal(loc=mean, scale=standard_deviation, size=sample_size)
  • loc: Distribution ka center ya Mean (μ). Bell curve ka peak is point par hota hai.
  • scale: Distribution ki spread ya Standard Deviation (σ). Badi scale ka matlab curve wider aur flatter hoga, chhoti scale ka matlab curve tall aur narrow hoga.
  • 68-95-99.7 Empirical Rule: Lagbhag 68.3% data [μ - σ, μ + σ] mein aata hai, 95.4% data [μ - 2σ, μ + 2σ] mein aata hai, aur 99.7% data [μ - 3σ, μ + 3σ] mein aata hai.
  • Important Reality Check: Normal distribution mathematically unbounded hoti hai (interval -∞ to +∞). Iska matlab hai ki theoretical normal sample mein arbitrarily extreme values aa sakti hain. Real world scores (0-100) ko model karte waqt clipping ya bounded model use kiya jata hai.

🍿 F. Sampling with rng.choice() & Weighted Selection

Data science mein aksar hume kisi collection ya array mein se randomly items pick karne hote hain. NumPy ka modern function rng.choice() dono scenarios handle karta hai: Equal Probability aur Weighted Probability.

choice_syntax.py Syntax 
selected = rng.choice(a, size=None, replace=True, p=None)
  • a: Input 1D array ya sequence jisme se pick karna hai. Agar a ek integer N hai, to selection np.arange(N) se hoti hai.
  • size: Kitne items pick karne hain (scalar integer ya tuple shape).
  • replace=True (Default): Sampling With Replacement. Ek item dobara select ho sakta hai (jaise lottery draw jisme ball wapas dabba mein daali jaye).
  • replace=False: Sampling Without Replacement. Ek baar select hone ke baad item dobara pick nahi hoga (jaise card deck se 5 cards deal karna).
  • p: Probability distribution weights ka array jo 1.0 ke barabar sum hona chahiye (sum(p) == 1.0).
⚠️ Golden Rule of Sampling Without Replacement: Jab replace=False ho, to aap population ke size se zyada items select nahi kar sakte! Agar pool mein 10 questions hain aur aap size=12, replace=False mangenge, to NumPy turant ValueError: Cannot take a larger sample than population when 'replace=False' raise karega.

🔀 G. Shuffling, Permutations & ML Dataset Alignment

Data science mein machine learning models train karne se pehle dataset rows ko shuffle karna zaroori hota hai taaki gradient descent kisi particular class order se bias na ho. NumPy do methods provide karta hai:

Method Behavior Return Value Original Array Status
rng.shuffle(arr) In-Place Modification None Original array permanently mutate hota hai
rng.permutation(arr) Safe Copy Creation Fresh permuted array Original array 100% untouched rehta hai

Example 1: Safe Permutation vs In-Place Shuffling

shuffle_vs_permutation.py Python 3 
import numpy as np

rng = np.random.default_rng(42)
original_questions = np.array([101, 102, 103, 104, 105])

# Method 1: permutation() returns a new randomized copy
permuted = rng.permutation(original_questions)
print("Original after permutation():", original_questions)
print("Permuted copy:", permuted)

# Method 2: shuffle() mutates the array in-place
to_mutate = original_questions.copy()
rng.shuffle(to_mutate)
print("After in-place rng.shuffle():", to_mutate)
Verified Execution Output:
Original after permutation(): [101 102 103 104 105] Permuted copy: [102 105 103 101 104] After in-place rng.shuffle(): [102 105 103 101 104]
🚨 CRITICAL MACHINE LEARNING MISTAKE: Independent Shuffling! Kabhi bhi feature matrix X aur label vector y ko independently shuffle mat kijiye:
rng.shuffle(X) # WRONG!
rng.shuffle(y) # WRONG!
Aisa karne se row 0 ke features kisi aur row ke label ke saath connect ho jayenge aur pura dataset corrupt ho jayega!

Correct Solution (Index Permutation): 
indices = rng.permutation(len(X))
X_shuffled = X[indices]
y_shuffled = y[indices]

🪙 H. Binomial Distribution • Repeated Trials

Binomial Distribution ek discrete probability distribution hai jo n independent Bernoulli trials (jisme har trial ke sirf do outcomes hote hain: Success ya Failure) mein successful outcomes ki count ko model karti hai.

binomial_syntax.py Syntax 
counts = rng.binomial(n=trials_per_experiment, p=success_probability, size=num_experiments)
  • n: Har experiment mein total kitne trials hain (e.g. 10 coin tosses).
  • p: Har trial mein success ki probability (e.g. fair coin ke liye 0.5).
  • size: Pura experiment kitni baar repeat karna hai (e.g. 50,000 experiments).
  • Theoretical Properties:
    Expected Mean $= n \times p$ (10 coin flips ke liye $= 10 \times 0.5 = 5.0$)
    Variance $= n \times p \times (1 - p)$ ($= 10 \times 0.5 \times 0.5 = 2.5$)

Example 1: Simulating 10 Coin Flips Across 50,000 Experiments

binomial_coin_flips.py Python 3 
import numpy as np

rng = np.random.default_rng(42)

# n=10 coin tosses per experiment, p=0.5, 50,000 repeated experiments
heads_counts = rng.binomial(n=10, p=0.5, size=50000)

print("Theoretical Expected Mean Heads:", 10 * 0.5)
print("Observed Empirical Mean Heads:", round(float(heads_counts.mean()), 3))
print("Theoretical Variance:", 10 * 0.5 * 0.5)
print("Observed Empirical Variance:", round(float(heads_counts.var()), 3))
print("Probability of getting exactly 5 heads:",
      round(float((heads_counts == 5).mean() * 100), 2), "%")
Verified Execution Output:
Theoretical Expected Mean Heads: 5.0 Observed Empirical Mean Heads: 5.003 Theoretical Variance: 2.5 Observed Empirical Variance: 2.502 Probability of getting exactly 5 heads: 24.59 %

💡 Empirical Probability Formula:
P(Event) ≈ (Number of successful simulated trials) / (Total trials N)

Law of Large Numbers ke anusaar, jaise-jaise sample size N badhta hai (100 → 1,000 → 10,000 → 100,000), simulated empirical probability true theoretical probability ke behad kareeb pahunch jati hai.

🚨 M. 15 Common Traps & 8 Code Debugging Scenarios

15 Common Traps Every Beginner Should Avoid

  1. Legacy Global Seed Trap: np.random.seed(42) use karna jo global state corrupt karta hai. Modern np.random.default_rng(42) use karein.
  2. Upper Bound Exclusion Trap: rng.integers(1, 6) se kabhi 6 nahi aayega! Upper bound 7 de ya endpoint=True set karein.
  3. Re-creating Generators in Loops: Loop ke andar bar-bar np.random.default_rng(42) call karne se har iteration mein wahi first number repeat ho jata hai!
  4. Assuming Cryptographic Security: NumPy random functions passwords ya security tokens ke liye nahi hain.
  5. Independent Feature-Label Shuffling: X aur y ko alag-alag shuffle karne se dataset corrupt ho jata hai. Shared index permutation use karein.
  6. Sampling Without Replacement Overflow: Population size se zyada items bina replacement ke mangne par ValueError aata hai.
  7. Invalid Probability Sum in Choice: p array ka sum strictly 1.0 hona chahiye (numerical tolerance ke andar).
  8. In-place shuffle() Return Value Trap: result = rng.shuffle(arr) likhne se result mein None chala jata hai!
  9. Small Sample Overconfidence: 10 tosses mein 7 heads dekh kar coin ko biased declare karna. Law of large numbers requires large samples.
  10. Assuming Normal Values Are Bounded: Normal distribution unbounded hoti hai; marks ya prices simulate karte waqt extremes aa sakte hain.
  11. Mistaking Synthetic Data for Ground Truth: Model assumptions ke mutabiq synthetic data banta hai; yeh real human behavior ka substitute nahi hai.
  12. Ignoring Poisson Variance Equality: Agar data ka variance uske mean se bahut zyada hai (overdispersion), to Poisson model fail ho jata hai.
  13. Assuming Exact Match Across Major Library Versions: Different NumPy versions ya algorithms bit-for-bit identical streams guarantee nahi karte.
  14. Forgetting rng Advances State: Ek hi generator par do consecutive random calls alag-alag values dengi.
  15. Forgetting Seed in Debugging: Fixed seed na dene par bugs non-reproducible (heisenbugs) ban jate hain.
