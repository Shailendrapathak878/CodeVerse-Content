A. Scalars, Vectors, and Matrices

Linear algebra me data ko unke dimensions ke basis par 3 fundamental structures me classify kiya jata hai:

  • Scalar (0D): Ek single numerical value (jaise 5 ya 3.14). Iska koi direction ya dimension nahi hota. NumPy me ndim == 0, shape ().
  • Vector (1D): Numbers ki ek 1D list/sequence. Iska ek length (magnitude) aur orientation hota hai. NumPy me ndim == 1, shape (n,).
  • Matrix (2D): Rows aur Columns ka ek 2D rectangular grid. Data tables, images, aur multivariable datasets matrix hote hain. NumPy me ndim == 2, shape (m, n).

D. Matrix Multiplication: @, np.matmul(), and np.dot()

Matrix multiplication linear algebra ka sabse critical aur powerful concept hai. Yeh element-wise product se bilkul alag hota hai kyunki isme Row of A aur Column of B ka dot product liya jata hai!

The Dimension Compatibility Rule

Do matrices \(A\) aur \(B\) tabhi multiply ho sakte hain jab \(A\) ke Columns aur \(B\) ki Rows exactly equal hon:

The Golden Dimension Rule:
\[ (m \times \mathbf{n}) \ @ \ (\mathbf{n} \times p) \ \longrightarrow \ (m \times p) \]
  • Inner Dimensions: Dono ka n barabar hona chahiye! (Columns of A == Rows of B).
  • Outer Dimensions: Resulting matrix ka shape (m x p) banega!
Figure 15.5: Dimension Compatibility: Valid inner match (3 == 3) vs Invalid mismatch raising ValueError.

B = np.array([[5, 6, 7], [8, 9, 10]])   # Shape: (2, 3)

print("B.T @ A (Shape 3x2):\n", transposed_prod)

G. Determinants with np.linalg.det()

Determinant kisi Square Matrix (n x n) se juda ek special scalar number hota hai. Yeh hume batata hai ki matrix coordinate space ko kitna expand, compress, ya flip karta hai.

2x2 Determinant Formula:
Agar matrix \(A = \begin{bmatrix} a & b \\ c & d \end{bmatrix}\) hai, toh iska determinant hota hai:
\[ \det(A) = ad - bc \] Diagonal entries ka product minus anti-diagonal entries ka product!
Figure 15.8: Geometric Meaning of Determinant: Matrix A transforms the unit square (area 1) into a parallelogram of area |det(A)| = 3.

J. Solving Systems of Linear Equations with np.linalg.solve()

Linear algebra ka sabse common real-world application hota hai simultaneous linear equations ko solve karna:

The Matrix Equation: Ax = b
\[ \begin{bmatrix} a_{11} & a_{12} \\ a_{21} & a_{22} \end{bmatrix} \begin{bmatrix} x_1 \\ x_2 \end{bmatrix} = \begin{bmatrix} b_1 \\ b_2 \end{bmatrix} \]
  • \(A\): Coefficient Matrix (known coefficients)
  • \(x\): Vector of Unknowns (variables to find)
  • \(b\): Right-Hand-Side Vector (known targets)
Figure 15.11: Solving Ax = b graphically: The unique solution (x=3, y=2) is the exact intersection point of both equations.

L. Eigenvalues and Eigenvectors (Introductory Level)

Data science, Machine Learning (PCA), Google PageRank, aur Computer Vision ka sabse powerful concept hai Eigenvalues and Eigenvectors. Pehli baar sunne me ye name intimidating lag sakta hai, lekin iska visual meaning behad intuitive aur beautiful hai.

The Core Intuition: Jab hum kisi matrix \(A\) se kisi vector \(\mathbf{v}\) ko multiply karte hain, toh mostly vector ka magnitude (length) bhi change hota hai aur uski direction bhi rotate (turn) ho jati hai. Lekin kuch special vectors aise hote hain jinki direction bilkul change nahi hoti—wo sirf usi line par stretch (lamba), shrink (chhota), ya flip (reverse) hote hain! Inhi special vectors ko Eigenvectors kehte hain, aur unke stretch factor ko Eigenvalue (\(\lambda\)) kehte hain.
Figure 15.13: Geometric Transformation: Ordinary vectors rotate when transformed by A, but Eigenvectors maintain their exact directional line, scaling by eigenvalue λ.

1. The Fundamental Eigen Equation

Mathematics me ise is tarah likha jata hai:

\[ A \mathbf{v} = \lambda \mathbf{v} \]
Yahan \(A\) ek \(n \times n\) square matrix hai, \(\mathbf{v}\) non-zero eigenvector hai, aur \(\lambda\) scalar eigenvalue hai.

NumPy me eigenvalues aur eigenvectors calculate karne ke liye np.linalg.eig(A) function use kiya jata hai:

Example 1 — Diagonal Matrix ke Eigenvalues

Ek diagonal matrix me diagonal elements hi uske eigenvalues hote hain aur standard basis vectors \([1, 0]^T\) and \([0, 1]^T\) uske eigenvectors hote hain:

Python 3 • Diagonal Matrix Eigen-decomposition Executable 
import numpy as np

# Diagonal scaling matrix
A_diag = np.array([
    [3.0, 0.0],
    [0.0, 7.0]
])

eigenvals, eigenvecs = np.linalg.eig(A_diag)

print("Eigenvalues:", eigenvals)
print("Eigenvectors (Columns):\n", eigenvecs)
Verified Output
Eigenvalues: [3. 7.] Eigenvectors (Columns): [[1. 0.] [0. 1.]]
CRITICAL GOTCHA — Column-Wise Eigenvectors:
np.linalg.eig() jo 2D array return karta hai, usme eigenvectors columns me store hote hain, rows me nahi! Matlab pehla eigenvector eigenvecs[:, 0] hai jo eigenvals[0] ke sath match karta hai, aur doosra eigenvector eigenvecs[:, 1] hai jo eigenvals[1] ke sath match karta hai.

Example 2 — Symmetric 2x2 Matrix & Numerical Verification

Aayein ek non-trivial symmetric matrix \(A = \begin{bmatrix} 4 & 1 \\ 1 & 4 \end{bmatrix}\) ka eigen-decomposition calculate karein aur verify karein ki kya \(A\mathbf{v} = \lambda\mathbf{v}\) sach me satisfy hota hai:

Python 3 • Symmetric Matrix Eigenvalues & Verification Executable 
import numpy as np

A = np.array([
    [4.0, 1.0],
    [1.0, 4.0]
])

evals, evecs = np.linalg.eig(A)

print("Computed Eigenvalues:", np.round(evals, 4))

# Verification for each eigenvalue/eigenvector pair
for i in range(len(evals)):
    lam = evals[i]
    v = evecs[:, i]  # Column vector!
    
    LHS = A @ v
    RHS = lam * v
    
    is_valid = np.allclose(LHS, RHS)
    print(f"Pair {i+1}: lambda={lam:.1f}, Av == lambda*v? {is_valid}")
Verified Output
Computed Eigenvalues: [5. 3.] Pair 1: lambda=5.0, Av == lambda*v? True Pair 2: lambda=3.0, Av == lambda*v? True

  • PCA (Principal Component Analysis): Covariance matrix ke largest eigenvalues wale eigenvectors hi data ka primary variance (main trend) capture karte hain.
  • Google PageRank: Web graph matrix ke principal eigenvector se websites ki authority rank decide hoti hai.
  • Structural Engineering: Bridges aur buildings ke natural vibrational frequencies eigenvalues se nikali jati hain taaki earthquake me collapse na ho.

M. Matrix Shapes & 8 Common Debugging Scenarios

Linear algebra me 90% bugs dimension mismatch aur floating-point precision traps se aate hain. Niche diye gaye 8 scenarios ko dhyan se samjhein:

Figure 15.14: Dimension compatibility rule: Inner dimensions must match exactly (n == n), and outer dimensions form the resulting matrix shape (m × p).

Trap 1: Shape Mismatch in Matrix Multiplication (@)

❌ Incorrect Code
import numpy as np
A = np.ones((2, 2))  # shape (2, 2)
B = np.ones((1, 3))  # shape (1, 3)
C = A @ B             # ERROR! Inner dims (2 != 1)
Actual Exception
ValueError: matmul: Input operand 1 has a mismatch in its core dimension 0, with gufunc signature (n?,k),(k,m?)->(n?,m?) (size 2 is different from 1)

Kyun Hua? Matrix \(A\) ke columns (\(2\)) matrix \(B\) ke rows (\(1\)) ke barabar nahi hain.

✔ Corrected Code
B_correct = np.ones((2, 3))  # Inner dims now match: 2 == 2
C = A @ B_correct
print("Result Shape:", C.shape)  # Output: (2, 3)

Trap 2: Accidentally Using `*` Instead of `@`

Jab aap do matrices ko matrix-multiply karna chahte the lekin galti se * likh diya, toh NumPy element-wise multiply karega (ya broadcast karega), jisse mathematical disaster ho jayega:

⚠ Comparison
import numpy as np
A = np.array([[1, 2], [3, 4]])
B = np.array([[5, 6], [7, 8]])

print("Element-wise (*):\n", A * B)
print("Matrix Mult (@):\n", A @ B)
Verified Output
Element-wise (*): [[ 5 12] [21 32]] Matrix Mult (@): [[19 22] [43 50]]

Trap 3: Inverting a Singular Matrix (LinAlgError)

❌ Incorrect Code
import numpy as np
A = np.array([[2.0, 4.0], [1.0, 2.0]])  # Row 1 is 2 * Row 2 (Rank 1, det=0)
inv_A = np.linalg.inv(A)
Actual Exception
numpy.linalg.LinAlgError: Singular matrix

Correction: Hamesha rank ya determinant check karein, ya safe try...except LinAlgError block use karein.

Trap 4: Taking Determinant of a Non-Square Matrix

❌ Incorrect Code
import numpy as np
A = np.array([[1, 2, 3], [4, 5, 6]])  # Shape (2, 3)
det_val = np.linalg.det(A)
Actual Exception
numpy.linalg.LinAlgError: Last 2 dimensions of the array must be square

Rule: Determinant sirf aur sirf Square Matrix (\(n \times n\)) ke liye hi mathematically defined hota hai!

Trap 5: Exact Equality `== 0.0` with Floating-Point Determinant

Computers me floating-point rounding errors ke karan determinant exact 0.0 aane ke bajaye 1e-16 ya -2e-17 aa sakta hai:

✔ Correct Method: np.isclose
import numpy as np

det = np.linalg.det(singular)

print("det == 0.0:", det == 0.0)                      # Unsafe! might be False
print("np.isclose(det, 0.0):", np.isclose(det, 0.0))  # Reliable & Safe!
Verified Output
det == 0.0: True np.isclose(det, 0.0): True

Trap 6: 1D Array Transpose `.T` Does Not Create a Column Vector

Beginners sochte hain ki v = np.array([1, 2, 3]) par v.T lagane se wo \((3, 1)\) column matrix ban jayega. Nahi banta! 1D array ka shape (3,) hi rehta hai:

✔ Correct Method for Column Vector

print("v.shape:", v.shape, "v.T.shape:", v.T.shape)

Verified Output
v.shape: (3,) v.T.shape: (3,) col_v shape: (3, 1)

Trap 7: Misunderstanding `np.dot` vs `np.matmul` on 3D Arrays

2D matrices ke liye np.dot(A, B) aur np.matmul(A, B) same output dete hain. Lekin jab arrays 3D ya batch tensors hote hain (jaise Deep Learning me batches of images):

  • np.matmul(A, B) (aur @ operator) batch-wise 2D matrix multiplication perform karta hai (batches ko independently multiply karta hai).
  • np.dot(A, B) last axis of A aur second-to-last axis of B par sum over karta hai, creating a higher-rank tensor.

Trap 8: Using `np.linalg.solve()` with Non-Square Matrix

np.linalg.solve(A, b) tabhi kaam karta hai jab \(A\) square matrix (\(n \times n\)) ho aur full-rank ho. Agar rectangular system ho (\(m \neq n\)), toh np.linalg.lstsq(A, b) (least-squares solver) use karna hota hai.

Vector Magnitude np.linalg.norm(v) Euclidean distance / length of vector from origin.
Eigen Decomposition evals, evecs = np.linalg.eig(A) Special directional axes where transformation only stretches without turning (\(A\mathbf{v} = \lambda\mathbf{v}\)).
