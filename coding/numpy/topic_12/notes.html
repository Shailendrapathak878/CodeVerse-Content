01. Opening — Ask NumPy to Find the Right Students

Suppose tum ek school teacher ya university mentor ho aur tumhare paas class test ke student marks hain. Ab tumhe sirf un meritorious students ki list nikalni hai jinhone 75 ya usse zyada marks score kiye hain:

find_top_students.pyPython (NumPy)
import numpy as np

marks = np.array([45, 78, 92, 61, 85, 70])

# Step 1: Create a Boolean condition mask
mask = marks >= 75

# Step 2: Use mask inside square brackets to filter elements
filtered_marks = marks[mask]

print("Boolean Mask:", mask)
print("Filtered High Scorers:", filtered_marks)
Terminal Output
Boolean Mask: [False True True False True False] Filtered High Scorers: [78 92 85]
Figure 12.1: Step 1 comparison se True/False mask banta hai; Step 2 mein sirf True positions ke elements extract hote hain.

Ye two-step process kaam kaise karta hai?

  1. Step 1 — Vectorized Comparison: marks >= 75 har element ko individually 75 se compare karta hai. Jo numbers 75 ya bade hain (78, 92, 85) unke index par True place hota hai, aur baaki par False. Resulting array ek Boolean Mask kehlata hai.
  2. Step 2 — Boolean Indexing Extraction: Jab tum is mask ko marks[mask] ke roop mein square brackets mein pass karte ho, toh NumPy sirf un positions ki values uthata hai jahan mask True hai. False wali values discard ho jaati hain.
Why this matters
Standard Python mein ye karne ke liye tumhe for loop chalana padta, if condition lagani padti, aur append() karna padta. NumPy ka Boolean indexing C-level speed par bina kisi manual loop ke pure millions of records ko fraction of a millisecond mein filter kar deta hai!

02. Section A — Boolean Values & Comparison Operators

Python mein do Boolean primitive values hoti hain: True aur False. NumPy mein jab hum kisi numerical array ko kisi scalar value ya doosre array ke saath compare karte hain, toh output humesha Boolean array (`dtype=bool`) banta hai.

Operator Meaning Example Expression Resulting Boolean Value
> Strictly Greater than np.array([20, 50]) > 30 [False, True]
< Strictly Less than np.array([20, 50]) < 30 [True, False]
>= Greater than or equal to np.array([30, 50]) >= 30 [True, True]
<= Less than or equal to np.array([30, 50]) <= 30 [True, False]
== Exact Equality np.array([25, 40]) == 40 [False, True]
!= Not equal to np.array([25, 40]) != 40 [True, False]
Figure 12.2: Array element aur scalar threshold ke beech har position par comparison evaluate hota hai.

# Passing benchmark is 40
passed_mask = marks >= 40
print("Passed Mask:", passed_mask)
print("Data Type:", passed_mask.dtype)
Terminal Output
Passed Mask: [False True True True True] Data Type: bool

Example 2: E-Commerce Store Price Filtering

price_filter.pyPython
import numpy as np

prices = np.array([99, 150, 250, 499, 799])

# Check which products are under budget (< 300)

Watch Out: Floating-Point Equality & np.isclose()
Computer memory mein floating-point numbers binary fractions mein store hote hain. Isliye 0.1 + 0.2 == 0.3 evaluate karne par False milta hai (kyunki internal value 0.30000000000000004 hoti hai)! Floating-point arrays mein exact equality == ke bajay humesha np.isclose(a, b) ya np.allclose(a, b) use karein: 
f_arr = np.array([0.1 + 0.2, 0.3])
np.isclose(f_arr, 0.3)  # Returns: array([True, True])

03. Section B — Understanding Boolean Masks & Shape Rules

Boolean Mask kya hota hai? Ek aisa array jisme sirf True aur False values hoti hain aur jiska shape target array ke barabar hota hai. Ye ek photo stencil ya sieve (chalni) ki tarah kaam karta hai: jahan hole (True) hai wahan ka element bahar nikal aata hai, jahan solid (False) hai wo block ho jata hai.

Boolean Indexing vs Integer Indexing & Slicing

  • Integer Indexing (Topic 5): Tum specific position number dete ho (jaise arr[2] ya arr[[0, 3]]).
  • Slicing (Topic 5): Tum range dete ho (jaise arr[1:4]).
  • Boolean Indexing (Topic 12): Tum position nahi dete, balki criteria / condition dete ho. NumPy automatically dhoondhta hai ki kaunsi values condition satisfy karti hain!

Example 1: Temperature Sensor Filtering

temperature_filter.pyPython
import numpy as np

temperatures = np.array([22, 27, 31, 19, 35, 29])

# Identify hot days (> 28°C)
hot_mask = temperatures > 28
hot_days = temperatures[hot_mask]

print("Hot Mask:", hot_mask)
print("Extracted Hot Temperatures:", hot_days)
Terminal Output
Hot Mask: [False False True False True True] Extracted Hot Temperatures: [31 35 29]

Example 2: Affordable Product Filtering

affordable_products.pyPython
import numpy as np

prices = np.array([120, 450, 250, 800, 300])

affordable_mask = prices <= 300
affordable_items = prices[affordable_mask]

print("Affordable Prices (≤ 300):", affordable_items)
Terminal Output
Affordable Prices (≤ 300): [120 250 300]

Shape Mismatch Error: Kyu Mask ka Shape Match Hona Zaroori Hai?

Agar tum kisi 6-element array ko sirf 2-element Boolean array se index karne ki koshish karoge:

shape_mismatch_error.pyPython (Expected Exception)
import numpy as np

temps = np.array([22, 27, 31, 19, 35, 29])  # length = 6
short_mask = np.array([True, False])           # length = 2 (Mismatch!)

try:
    res = temps[short_mask]
except IndexError as e:
    print("IndexError Caught:", e)
Terminal Output

The Fix: Hamesha ensure karein ki mask usi array ke comparison se generate hua ho (temps > 25) taaki length aur dimension exact match karein.

04. Section C — Combining Multiple Conditions (&, |, ~)

Real-life filtering mein hume aksar multiple conditions combine karni padti hain (jaise: "Marks 40 se zyada hon AND 80 se kam hon").

NumPy mein standard Python ke and, or, aur not keywords kaam nahi karte. NumPy array ke elements par element-wise logical operations ke liye bitwise operators use kiye jaate hain:

  • & : Logical AND — Dono conditions True honi chahiye.
  • | : Logical OR — Kam se kam ek condition True honi chahiye.
  • ~ : Logical NOT (Invert) — True ko False aur False ko True bana deta hai.
Figure 12.3: Bitwise logical truth table aur multiple conditions ka mask intersection.

Parentheses Rule: Sabse Badi Beginner Galti!

Python operator precedence mein & aur | ka precedence comparison operators (>=, <=) se zyada high hota hai! Agar tum parentheses nahi lagaoge: 

marks >= 40 & marks <= 80  # SyntaxError / TypeError!
# Python tries to evaluate (40 & marks) first!

Golden Rule: Hamesha har individual comparison ko parentheses () ke andar wrap karein: 

(marks >= 40) & (marks <= 80)  # Correct!

Example 1: Marks within a Specific Range (AND: &)

and_condition.pyPython
import numpy as np

marks = np.array([25, 45, 60, 75, 90])

# Select marks between 40 and 80 inclusive
mask = (marks >= 40) & (marks <= 80)

print("Mask:", mask)
print("Filtered Marks:", marks[mask])
Terminal Output
Mask: [False True True True False] Filtered Marks: [45 60 75]

Example 2: Discount Eligibility (OR: |)

Store discount de raha hai un products par jo ya toh budget clearance mein hain (< 300) ya luxury premium hain (≥ 700):

or_condition.pyPython
import numpy as np

prices = np.array([150, 450, 700, 250, 900])

# Budget (< 300) OR Premium (>= 700)
disc_mask = (prices < 300) | (prices >= 700)

print("Discount Eligible Products:", prices[disc_mask])
Terminal Output
Discount Eligible Products: [150 700 250 900]

Example 3: Inverting Selection with NOT (~)

not_condition.pyPython
import numpy as np

marks = np.array([25, 45, 60, 75, 90])

mid_range_mask = (marks >= 40) & (marks <= 80)
# Select marks OUTSIDE the 40-80 range
outliers_mask = ~mid_range_mask

print("Outside Range Marks:", marks[outliers_mask])
Terminal Output
Outside Range Marks: [25 90]
Why Python's "and" and "or" Fail on Arrays
Python ke built-in and aur or operators kisi object ka single boolean truth value maangte hain (jaise bool(obj)). Lekin ek 5-element array mein kuch elements True ho sakte hain aur kuch False! Python confuse ho jata hai aur error raise karta hai: ValueError: The truth value of an array with more than one element is ambiguous. Use a.any() or a.all(). Isliye arrays ke liye humesha & aur | use karein!

05. Section D — Conditional Selection with np.where()

Boolean indexing elements ko array se bahar extract kar leti hai (shape choti ho sakti hai). Lekin kya ho agar tum original array ki shape preserve rakhna chahte ho aur har element par ek if-else branch lagana chahte ho?

Iske liye NumPy ka sabse powerful function hai np.where():

np.where(condition, value_if_true, value_if_false)
Figure 12.4: Boolean indexing elements extract karke shape choti karta hai; np.where() original shape barkarar rakhte hue if-else swap karta hai.

Example 1: Pass or Fail Classification

pass_fail_where.pyPython
import numpy as np

marks = np.array([25, 40, 55, 32, 80])

# If marks >= 40 -> 'Pass', else -> 'Fail'
status = np.where(marks >= 40, "Pass", "Fail")

print("Student Marks:", marks)
print("Student Status:", status)
Terminal Output
Student Marks: [25 40 55 32 80] Student Status: ['Fail' 'Pass' 'Pass' 'Fail' 'Pass']

Example 2: 10% Discount on Expensive Products

conditional_discount.pyPython
import numpy as np

prices = np.array([100, 250, 500, 800])

# Products >= 500 get 10% off (multiply by 0.9), others stay unchanged
final_prices = np.where(prices >= 500, prices * 0.9, prices)

print("Original Prices:", prices)
print("Discounted Prices:", final_prices)
Terminal Output
Original Prices: [100 250 500 800] Discounted Prices: [100. 250. 450. 720.]

np.where() with 1 Argument: Finding Indices of True Elements

Agar tum np.where(condition) ko sirf condition ke saath call karte ho (bina x aur y ke), toh ye un saare elements ke indices ka tuple return karta hai jo condition satisfy karte hain:

06. Section E — Multi-Condition Categorization with np.select()

Jab do se zyada outcomes hote hain (jaise if-elif-elif-else ladder), toh np.where() ko nest karna messy aur unreadable ho jata hai. Iske liye NumPy ka standard tool hai np.select():

np.select(condition_list, choice_list, default=fallback_value)
Figure 12.5: np.select() waterfall logic follow karta hai: Pehli matching condition ka choice assign hota hai.

Example 1: Academic Grading System (A, B, C, D, F)

Notice karo conditions ka order hamesha highest se lowest arrange kiya jata hai:

grading_system.pyPython
import numpy as np

marks = np.array([95, 82, 68, 45, 30])

conditions = [
    marks >= 90,  # Grade A
    marks >= 75,  # Grade B
    marks >= 50,  # Grade C
    marks >= 35   # Grade D
]

choices = ["A", "B", "C", "D"]

grades = np.select(conditions, choices, default="F")

print("Marks :", marks)
print("Grades:", grades)
Terminal Output
Marks : [95 82 68 45 30] Grades: ['A' 'B' 'C' 'D' 'F']

Example 2: Retail Sales Tier Classification

sales_tiers.pyPython
import numpy as np

sales = np.array([12000, 45000, 28000, 60000, 15000])

s_cond = [
    sales >= 50000,
    sales >= 25000
]
s_choices = ["High", "Medium"]

tier_labels = np.select(s_cond, s_choices, default="Low")

print("Sales Amount:", sales)
print("Tier Labels :", tier_labels)
Terminal Output
Sales Amount: [12000 45000 28000 60000 15000] Tier Labels : ['Low' 'Medium' 'Medium' 'High' 'Low']
Why Order Matters in np.select()
Agar tum marks >= 50 ko marks >= 90 se pehle likh doge, toh 95 score karne wale student ko bhi Grade C mil jayega! Kyunki NumPy pehli condition True hote hi us row ko lock kar deta hai. Hamesha specific/strict conditions ko pehle rakhein.

07. Section F — Counting & Validating Conditions

Data analysis mein aksar hume filtered elements dekhne se pehle ye check karna hota hai: "Kitne elements match karte hain?" ya "Kya koi dangerous abnormal reading aayi hai?"

  • np.count_nonzero(mask): Mask mein kitne True elements hain unka exact count karta hai (fastest C-implementation).
  • np.sum(mask): Boolean array par sum lene par True ko 1 aur False ko 0 treat karke total count deta hai.
  • np.any(condition): Returns True agar kam se kam ek (at least one) element True ho. (Disaster / Alarm monitoring ke liye ideal).
  • np.all(condition): Returns True sirf tab jab saare ke saare (every single) elements True hon. (Quality control certification ke liye ideal).
Figure 12.6: np.count_nonzero exact frequency deta hai, jabki np.any aur np.all binary verification checkpoints hain.

Example 1: Student Pass Rate & Universal Success Validation

cohort_validation.pyPython
import numpy as np

marks = np.array([35, 60, 75, 28, 90, 50])
passed = marks >= 40

print("Total Students:", len(marks))
print("Passed Students:", np.count_nonzero(passed))
print("Passing Percentage:", f"{(np.sum(passed)/len(marks))*100:.1f}%")
print("Did at least one pass? (any):", np.any(passed))
print("Did everyone pass? (all):", np.all(passed))
Terminal Output
Total Students: 6 Passed Students: 4 Passing Percentage: 66.7% Did at least one pass? (any): True Did everyone pass? (all): False

Example 2: Industrial Pressure Boiler Safety Check

boiler_safety.pyPython
import numpy as np

# Boiler pressure sensor readings (normal limit: 100 to 105 psi, critical: > 104 psi)
pressures = np.array([101.3, 102.5, 104.8, 101.9, 103.2])

danger_spikes = pressures > 104.0
within_safety_limits = (pressures >= 100.0) & (pressures <= 105.0)

    print("WARNING: Danger spike detected! Reading:", pressures[danger_spikes])

if np.all(within_safety_limits):
    print("STATUS: All readings within structural tolerance limits.")
Terminal Output

10. Section I — Conditional Selection & Missing Values

Topics 10 aur 11 mein humne dekha tha ki np.nan calculations ko contaminate kar deta hai. Boolean masking se hum directly valid measurements ko isolate kar sakte hain.

  • np.isnan(arr): Jo elements NaN hain wahan True return karta hai.
  • ~np.isnan(arr): NOT operator lagane se un saare valid elements par True milta hai jo NaN nahi hain.
Figure 12.9: ~np.isnan() mask NaN missing rows ko drop karke clean dataset generate karta hai.

Example 1: Extract Clean Valid Temperature Readings

clean_temperatures.pyPython
import numpy as np

temps = np.array([25.0, np.nan, 28.0, 30.0, np.nan])

valid_mask = ~np.isnan(temps)
clean_temps = temps[valid_mask]

print("Valid Mask:", valid_mask)
print("Sanitized Temps:", clean_temps)
print("Clean Mean:", np.mean(clean_temps))
Terminal Output
Valid Mask: [ True False True True False] Sanitized Temps: [25. 28. 30.] Clean Mean: 27.666666666666668

Example 2: Compound Filter — Valid Readings Above a Threshold

compound_valid_filter.pyPython
import numpy as np

temps = np.array([25.0, np.nan, 28.0, 30.0, np.nan])

# Check BOTH: Must be a valid reading AND > 26.0°C
hot_valid_mask = (~np.isnan(temps)) & (temps > 26.0)
hot_readings = temps[hot_valid_mask]

print("Hot Valid Readings:", hot_readings)
Terminal Output
Hot Valid Readings: [28. 30.]

12. Section K — Common Mistakes & Debugging Guide

NumPy Boolean masking aur conditional selection mein beginners aksar in 5 critical pitfalls mein phaste hain:

❌ Mistake 1: Using Python "and" / "or" Instead of "&" / "|"

Wrong Code:

import numpy as np
scores = np.array([30, 50, 70])
mask = (scores >= 40) and (scores <= 60)  # CRASH: ValueError!

Error: ValueError: The truth value of an array with more than one element is ambiguous. Use a.any() or a.all()

✔ Corrected Code:
mask = (scores >= 40) & (scores <= 60)  # Bitwise element-wise AND
❌ Mistake 2: Forgetting Parentheses around Conditions

Wrong Code:

mask = scores >= 40 & scores <= 60  # TypeError / Unexpected Precedence!

Why it happens: & has higher precedence than >=. Python evaluates 40 & scores first!

✔ Corrected Code:
mask = (scores >= 40) & (scores <= 60)  # Always wrap each clause in ()
❌ Mistake 3: Confusing Boolean Indexing with np.where()

Confusion: arr[arr >= 50] returns an array of matching elements (e.g. [50, 70]), whereas np.where(arr >= 50) returns a tuple of indices: (array([1, 2]),).

✔ Rule of Thumb:
  • Agar values filter karni hain → Use arr[mask].
  • Agar if-else replacements karni hain → Use np.where(cond, x, y).
  • Agar matching index positions chahiye → Use np.where(cond)[0].
❌ Mistake 4: Accidental In-Place Mutation of Raw Data

Wrong Code:

raw_sensor = np.array([10, 20, 30])
modified = raw_sensor
modified[modified > 15] = 99  # BUG: raw_sensor is also permanently changed!
✔ Corrected Code:
modified = raw_sensor.copy()  # Creates independent memory buffer
modified[modified > 15] = 99  # raw_sensor remains untouched
❌ Mistake 5: Wrong Condition Order in np.select()

Wrong Code:

# Putting lenient condition first
conds = [marks >= 50, marks >= 90]
choices = ["Pass", "Topper"]
res = np.select(conds, choices)  # A student with 98 gets "Pass" instead of "Topper"!
✔ Corrected Code:
conds = [marks >= 90, marks >= 50]  # Strict conditions first!
choices = ["Topper", "Pass"]

Part A: 10 Output Prediction Questions

Prediction 01 arr = np.array([10, 20, 30, 40]) • What is arr[arr > 25]?

Explanation: Elements strictly greater than 25 are 30 and 40.

Prediction 02 arr = np.array([5, 12, 18, 25]) • What is np.count_nonzero((arr >= 10) & (arr <= 20))?

# -------------------------------------------------------------------------
# MODULE 1: STUDENT PERFORMANCE & BONUS ENGINE
# -------------------------------------------------------------------------
marks = np.array([45, 82, 91, 58, 76, 88, 32, 95, 67, 73])

passed_mask = marks >= 40
honors_mask = marks >= 80

grades = np.select([marks >= 85, marks >= 70, marks >= 50], ["A", "B", "C"], default="F")

# Grace marks: Students in 65-69 band get +3 grace marks
boosted_marks = marks.copy()
grace_mask = (boosted_marks >= 65) & (boosted_marks < 70)
boosted_marks[grace_mask] += 3

print("\n>>> 1. Academic Performance Summary:")
print(f"   Total Students Analyzed : {len(marks)}")
print(f"   Students Passed (>= 40) : {np.count_nonzero(passed_mask)}")
print(f"   Honors Cohort   (>= 80) : {np.count_nonzero(honors_mask)}")

print("   Grace Boosted Marks     :", boosted_marks)

# -------------------------------------------------------------------------
# MODULE 2: RETAIL STORE DISCOUNT & PRICING ENGINE
# -------------------------------------------------------------------------
prices = np.array([150, 450, 800, 1200, 250, 3000, 600])

# High ticket items (>= 1000) get 15% off
final_prices = np.where(prices >= 1000, prices * 0.85, prices)
affordable_products = final_prices[final_prices <= 500]

print("\n>>> 2. Retail Pricing & Discount Engine:")
print("   Original Inventory Prices : ₹", prices)
print("   Discounted Final Prices   : ₹", final_prices)
print("   Affordable Items (≤ ₹500) : ₹", affordable_products)

# -------------------------------------------------------------------------
sensors = np.array([24.2, 25.1, np.nan, 29.8, 24.8, 31.5, np.nan])

sanitized_readings = sensors[valid_filter]
