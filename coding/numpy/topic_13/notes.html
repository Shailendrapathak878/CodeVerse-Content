02. Section A — Sorting Basics with np.sort()

Sorting ka matlab hota hai array ke elements ko kisi defined systematic sequence (chote se bada — Ascending, ya bade se chota — Descending) mein re-arrange karna.

NumPy ka primary sorting function hai np.sort(a). By default, ye array ko Ascending Order (increasing numerical value) mein sort karta hai aur humesha ek naya sorted array copy return karta hai.

Example 1: Sorting Student Marks

sort_student_marks.pyPython
import numpy as np

marks = np.array([72, 95, 61, 84, 78])

sorted_marks = np.sort(marks)

print("Original:", marks)
print("Ascending:", sorted_marks)
print("Descending:", np.sort(marks)[::-1])
Terminal Output
Original: [72 95 61 84 78] Ascending: [61 72 78 84 95] Descending: [95 84 78 72 61]

Descending order kaise mila? NumPy ke np.sort() mein koi direct reverse=True parameter nahi hota (jaise standard Python list mein hota hai). Lekin kyunki np.sort() ek 1D array return karta hai, hum Python ke negative step slicing [::-1] ka use karke sorted array ko instantly reverse kar lete hain!

Example 2: E-Commerce Product Price Sorting

E-commerce websites (jaise Amazon, Flipkart) par jab user "Sort by: Price - Low to High" ya "High to Low" click karta hai, toh backend par pricing array ko sort kiya jata hai:

ecommerce_prices.pyPython
import numpy as np

prices = np.array([499, 199, 999, 299, 699])

print("Lowest to highest:", np.sort(prices))
print("Highest to lowest:", np.sort(prices)[::-1])
Terminal Output
Lowest to highest: [199 299 499 699 999] Highest to lowest: [999 699 499 299 199]
Figure 13.2: Original price array ascending aur negative slice [::-1] ke through descending sequence mein sort hota hua.
Important Note: Values Change Nahi Hoti!
Sorting sirf elements ke positions / order ko rearrange karta hai. Underlying array ke values, unka data type (`dtype`), aur count bilkul same rehte hain.

03. Section B — np.sort() versus ndarray.sort()

NumPy mein sorting perform karne ke do methods hain jo dekhne mein similar lagte hain lekin unka memory behavior bilkul opposite hota hai:

  • np.sort(array) — Function method: Ek naya sorted copy banata hai. Original array jaisa tha waisa hi rehta hai.
  • array.sort() — In-place array method: Original array ke existing memory buffer ko modify kar deta hai aur None return karta hai!

Example 1: Preserving Original Data with np.sort()

sort_copy.pyPython
import numpy as np

data = np.array([40, 10, 30, 20])

result = np.sort(data)

print("Original:", data)
print("Result  :", result)
Terminal Output
Original: [40 10 30 20] Result : [10 20 30 40]

Example 2: In-Place Mutation with array.sort()

sort_inplace.pyPython
import numpy as np

data = np.array([40, 10, 30, 20])

result = data.sort()

print("Array after sorting:", data)
print("Return value       :", result)
Terminal Output
Array after sorting: [10 20 30 40] Return value : None
Figure 13.3: np.sort() new memory allocate karta hai jabki array.sort() existing buffer mutate karta hai.
Feature np.sort(arr) arr.sort()
Method Type Top-level NumPy function ndarray instance method
Memory Allocation New array memory allocated (Copy) Zero extra memory (In-Place)
Original Array Preserved untouched Overwritten & permanently changed
Return Value Sorted ndarray None
When to Use Jab original raw data baad mein chahiye Jab memory limit tight ho (massive arrays)
The #1 Beginner Trap: arr = arr.sort()
Kabhi bhi arr = arr.sort() mat likhna! Kyunki arr.sort() ka return value None hota hai, tumhara variable arr permanently None ban jayega aur tumhara code crash ho jayega: 
data = np.array([3, 1, 2])
data = data.sort()  # DANGER: data is now None!

04. Section C — Sorting Multidimensional Arrays & axis

Jab hum 2D matrix (jaise student marksheet table ya sales spreadsheet) ko sort karte hain, toh hume specify karna padta hai ki sorting kis direction mein karni hai. Iske liye axis parameter use hota hai:

  • axis=1 — Across Rows (Horizontally): Har row ke andar ke elements independently sort hote hain. Column 0 se Column n tak ascending order banta hai.
  • axis=0 — Down Columns (Vertically): Har column ke andar ke elements independently sort hote hain. Row 0 se Row n tak ascending order banta hai.

Example 1: Sorting Across Each Row (axis=1)

Suppose 3 students ke 3 subjects ke marks hain:

sort_2d_rowwise.pyPython
import numpy as np

marks = np.array([
    [78, 65, 90],  # Student 0
    [88, 72, 81],  # Student 1
    [60, 95, 70]   # Student 2
])

sorted_rows = np.sort(marks, axis=1)
print(sorted_rows)
Terminal Output
[[65 78 90] [72 81 88] [60 70 95]]

Notice karo ki Row 0 ke marks [78, 65, 90] sort ho kar [65, 78, 90] ban gaye. Har student ke personal scores low se high arrange ho gaye.

Example 2: Sorting Down Each Column (axis=0)

sort_2d_colwise.pyPython
import numpy as np

marks = np.array([
    [78, 65, 90],
    [88, 72, 81],
    [60, 95, 70]
])

sorted_cols = np.sort(marks, axis=0)
print(sorted_cols)
Terminal Output
[[60 65 70] [78 72 81] [88 95 90]]
Figure 13.4: axis=1 horizontally har row sort karta hai; axis=0 vertically har column sort karta hai.
Critical Data Science Warning: Broken Row Correlation!
np.sort(marks, axis=0) har column ko alag se sort karta hai. Iska matlab Column 0 ka sabse chota mark (60, jo Student 2 ka tha) ab Row 0 par aa gaya, jabki Column 1 ka mark Student 0 ka hi raha! Isse poori table ka record correlation destroy ho jata hai! Agar tumhe poore students ko kisi subject ke marks ke hisaab se rank karna hai, toh np.sort() nahi balki np.argsort() use karein!

05. Section D — Sorting Indices using np.argsort()

Real-life mein hum aksar direct values ko sort nahi karna chahte, balki ye jaanna chahte hain: "Kaunsa student 1st rank par hai aur kaunsa 2nd?"

np.argsort() array ki sorted values return nahi karta, balki un index positions ka array return karta hai jo array ko sort karne ke liye chahiye! Isse hum parallel arrays (jaise Names, IDs, Salaries) ko aapas mein synchronize karke rank kar sakte hain.

Example 1: Ranking Student Marks

student_argsort.pyPython
import numpy as np

marks = np.array([78, 92, 65, 85])

indices = np.argsort(marks)

print("Sorting indices:", indices)
print("Sorted marks   :", marks[indices])
Terminal Output
Sorting indices: [2 0 3 1] Sorted marks : [65 78 85 92]

Index mapping samajhte hain:

  • Sabse chota mark 65 hai, jo original array ke index 2 par tha.
  • Usse bada mark 78 hai, jo original index 0 par tha.
  • Usse bada mark 85 hai, jo original index 3 par tha.
  • Sabse bada mark 92 hai, jo original index 1 par tha.
  • Isliye resulting index array bana: [2, 0, 3, 1]!

Example 2: Ranking Products by Price While Keeping Product Names Paired

product_ranking.pyPython
import numpy as np

products = np.array(["Earbuds", "Laptop", "Mouse", "Keyboard"])
prices = np.array([1999, 54999, 499, 1499])

sort_idx = np.argsort(prices)

print("Cheapest to Most Expensive Products:")
print(products[sort_idx])
print("Corresponding Prices:")
print(prices[sort_idx])

# Descending Order (Most expensive first)
desc_idx = sort_idx[::-1]
print("\nMost Expensive to Cheapest:")
print(products[desc_idx])
Terminal Output
Cheapest to Most Expensive Products: ['Mouse' 'Keyboard' 'Earbuds' 'Laptop'] Corresponding Prices: [ 499 1499 1999 54999] Most Expensive to Cheapest: ['Laptop' 'Earbuds' 'Keyboard' 'Mouse']
Figure 13.5: argsort indices original parallel arrays ko bina unki correlation tode rank karte hain.
Ties & Stable Sorting
Jab array mein identical values hon (jaise do students ke 92 marks), default QuickSort algorithm unka relative order guarantee nahi karta. Agar tumhe original appearance order preserve rakhna hai, toh kind='stable' parameter pass karein: 
idx = np.argsort(marks, kind='stable')

06. Section E — Searching with Boolean Conditions & np.where()

Sorting answers "order kya hai", jabki Searching answers "kisi condition ko satisfy karne wale elements kahan baithe hain".

NumPy mein values dhoondhne ke liye sabse common pattern hai Boolean condition ko np.where(condition) ke andar pass karna. Ye matching elements ke indices ka tuple return karta hai.

Example 1: Find Marks Above 80

search_high_scores.pyPython
import numpy as np

marks = np.array([55, 82, 91, 67, 88])

indices = np.where(marks > 80)

print("Matching indices:", indices[0])
print("Matching marks  :", marks[indices])
Terminal Output
Matching indices: [1 2 4] Matching marks : [82 91 88]

Example 2: Find Exact Price Points with Duplicates

search_exact_price.pyPython
import numpy as np

prices = np.array([199, 499, 299, 499, 799])

indices = np.where(prices == 499)

print("Matching indices:", indices[0])
print("Matching prices :", prices[indices])
Terminal Output
Matching indices: [1 3] Matching prices : [499 499]
Figure 13.6: np.where(condition) matching elements ke exact index coordinates return karta hai.
np.nonzero() Connection
Python mein np.where(condition) internally np.nonzero(condition) ko call karta hai. Boolean condition par True ko non-zero (1) aur False ko zero (0) treat kiya jata hai. Isliye np.nonzero(marks > 80)[0] aur np.where(marks > 80)[0] identical indices return karte hain.

07. Section F — Find Minimum & Maximum Positions (argmax & argmin)

Data analysis mein hume do tarah ke sawaal milte hain:

  1. "Sabse bada score kya hai?" → Iska answer ek value hai (jaise 92 marks).
  2. "Sabse bada score kis student ka hai ya kis index par hai?" → Iska answer ek index coordinate hai (jaise index 1).

NumPy ke np.max() / np.min() actual values return karte hain, jabki np.argmax() / np.argmin() un extreme values ki index position return karte hain.

Example 1: Highest and Lowest Scoring Student Position

extremes_demo.pyPython
import numpy as np

marks = np.array([78, 92, 65, 85])

print("Highest marks        :", np.max(marks))
print("Index of highest marks:", np.argmax(marks))
print("Lowest marks         :", np.min(marks))
print("Index of lowest marks :", np.argmin(marks))
Terminal Output
Highest marks : 92 Index of highest marks: 1 Lowest marks : 65 Index of lowest marks : 2

Example 2: Peak Sales Day and Handling Tied Maximums

Suppose ek retail store ke 5 dino ki daily revenue recorded hai:

peak_sales_day.pyPython
import numpy as np

days = np.array(["Mon", "Tue", "Wed", "Thu", "Fri"])
sales = np.array([150, 300, 250, 300, 200])

peak_idx = np.argmax(sales)
print("argmax returned index:", peak_idx)
print("First peak day       :", days[peak_idx])

# Find ALL tied peak days using np.where
all_peaks = np.where(sales == np.max(sales))[0]
print("All tied peak indices:", all_peaks)
print("All peak sales days  :", days[all_peaks])
Terminal Output
argmax returned index: 1 First peak day : Tue All tied peak indices: [1 3] All peak sales days : ['Tue' 'Thu']
Figure 13.7: Value vs Index Position: np.max value deta hai, np.argmax index position locate karta hai.
Tied Maximum Gotcha
Dhyan rahe ki agar maximum value array mein ek se zyada baar repeat ho rahi ho (jaise ₹300 Tuesday aur Thursday dono din tha), toh np.argmax() humesha sirf pehla occurrence index (index 1) return karega! Agar tumhe saare tied toppers ya peaks nikalne hain, toh humesha np.where(arr == np.max(arr))[0] use karein!

08. Section G — Binary Search Insertion Positions with np.searchsorted()

Beginners aksar np.searchsorted() ko normal element search samajh lete hain, jabki iska purpose completely alag hai:

np.searchsorted ka exact meaning
"Agar mere paas pehle se ek sorted array hai, aur main usme ek naya number insert karna chahta hoon, toh main use kis index position par insert karoon taaki poora array abhi bhi sorted bana rahe?"

Prerequisite: Array MUST be Sorted!

np.searchsorted() internally fast $O(\log N)$ Binary Search algorithm use karta hai. Isliye input array ka strictly sorted hona compulsory hai. Agar array unsorted hoga, toh output completely wrong aur unpredictable aayega.

Example 1: Where Does a New Student's Score Belong?

searchsorted_simple.pyPython
import numpy as np

marks = np.array([50, 60, 70, 80, 90])  # Already sorted!

pos = np.searchsorted(marks, 75)
print("Insertion index for 75:", pos)
Terminal Output
Insertion index for 75: 3

Index 3 par element 80 hai. Agar hum 75 ko index 3 par daal dein, toh sequence ban jayegi: [50, 60, 70, 75, 80, 90] jo perfectly sorted hai!

Example 2: Handling Duplicates with side='left' and side='right'

Agar jo value hum dhoondh rahe hain wo pehle se array mein repeat ho rahi ho, toh insertion position side parameter par depend karti hai:

searchsorted_sides.pyPython
import numpy as np

values = np.array([10, 20, 20, 20, 30])

left_pos = np.searchsorted(values, 20, side="left")
right_pos = np.searchsorted(values, 20, side="right")

print("side='left'  insertion index:", left_pos)
print("side='right' insertion index:", right_pos)
Terminal Output
side='left' insertion index: 1 side='right' insertion index: 4

Notice karo:

  • side="left" (default): Naye 20 ko pehle se mojud 20s ke pehle insert karta hai (index 1).
  • side="right": Naye 20 ko pehle se mojud 20s ke baad insert karta hai (index 4).
Figure 13.8: searchsorted sorted array mein order maintain karte hue insertion index find karta hai.
Batch Searching with Arrays
Tum ek saath poora array of values bhi pass kar sakte ho: 
marks = np.array([50, 60, 70, 80, 90])
np.searchsorted(marks, [55, 85])  # Returns: array([1, 4])
Ye feature Data Science mein continuous numbers ko categorical bins (jaise Grade brackets ya Age groups) mein divide karne ke liye extremely popular hai!

11. Section J — return_index and return_inverse

np.unique() ke do advanced parameters hote hain jo intermediate aur advanced data manipulation mein frequently use hote hain:

1. return_index=True (First Occurrence Pointer)

Ye batata hai ki har unique value original array mein pehli baar kis index par aayi thi:

unique_first_index.pyPython
import numpy as np

data = np.array([30, 10, 30, 20, 10])

unique_vals, first_indices = np.unique(data, return_index=True)

print("Unique values          :", unique_vals)
print("First occurrence indices:", first_indices)
Terminal Output
Unique values : [10 20 30] First occurrence indices: [1 3 0]

Important nuance: Notice karo ki unique_vals sorted order ([10, 20, 30]) mein hain. Isliye first_indices ka pehla element 1 value 10 ke first occurrence (index 1) ko point kar raha hai!

2. return_inverse=True (Original Array Reconstruction)

Ye parameter ek aisa index array return karta hai jisse hum unique_vals ka use karke original array ko 100% reconstruct kar sakte hain:

unique_inverse_reconstruct.pyPython
import numpy as np

data = np.array([30, 10, 30, 20, 10])

unique_vals, inverse_indices = np.unique(data, return_inverse=True)

print("Unique values  :", unique_vals)
print("Inverse indices:", inverse_indices)

# Reconstruct original array
reconstructed = unique_vals[inverse_indices]
print("Reconstructed  :", reconstructed)
print("Match original ?:", np.array_equal(reconstructed, data))
Terminal Output
Unique values : [10 20 30] Inverse indices: [2 0 2 1 0] Reconstructed : [30 10 30 20 10] Match original ?: True
Figure 13.11: return_index pehli appearance map karta hai; return_inverse array reconstruction permit karta hai.
Label Encoding in Machine Learning
Data Science aur Machine Learning algorithms (jaise Decision Trees ya Neural Networks) string categories (jaise ['Cat', 'Dog', 'Cat']) ko directly accept nahi karte. np.unique(categories, return_inverse=True) text labels ko zero-based integers ([0, 1, 0]) mein encode karne ka sabse efficient NumPy method hai!

13. Section L — Sorting, Searching & Unique with NaN & Data Types

Real-world raw data clean nahi hota — usme missing measurements (NaN) aur mismatched data types hote hain. Inhe handle karte waqt kuch essential rules follow karne chahiye:

1. NaN Sorting Behavior

Floating-point arrays mein np.sort() saare NaN values ko array ke aakhri positions (end) par dhakel deta hai:

nan_sorting.pyPython
import numpy as np

temps = np.array([30.0, np.nan, 10.0, 20.0, np.nan])

print("Direct Sort:", np.sort(temps))

# Safe Pattern: Pre-filter NaNs before sorting
clean_temps = temps[~np.isnan(temps)]
print("Clean Sort :", np.sort(clean_temps))
Terminal Output
Direct Sort: [10. 20. 30. nan nan] Clean Sort : [10. 20. 30.]

2. Why NaN Fails in Searching

IEEE 754 floating-point standard ke anusaar, np.nan == np.nan humesha False evaluate hota hai! Isliye np.where(data == np.nan) se kabhi koi missing value nahi milegi: 

np.where(temps == np.nan)  # WRONG: returns empty array!

The Correct Way: Humesha np.where(np.isnan(temps)) use karein!

3. Numeric Strings vs Numbers in Sorting

Agar tumhare numbers string format mein store ho gaye hain (jaise ['100', '20', '35']), toh string sorting alphabetical (lexicographical) order follow karegi: 

str_arr = np.array(['100', '20', '35'])
np.sort(str_arr)  # Returns: array(['100', '20', '35']) because '1' < '2'!

Numerical sorting ke liye array ko pehle .astype(int) ya .astype(float) mein convert karein.

15. Section N — Common Beginner Mistakes & Debugging

Mistake 1: Confusing Sorted Values with Sorting Indices

mistake1_indices.pyPython (Misconception)
import numpy as np

marks = np.array([40, 10, 30, 20])

# Incorrect: Assuming argsort returns sorted values
res = np.argsort(marks)
print("Result:", res)
Terminal Output
Result: [1 3 2 0]

Why this happens: np.argsort() index positions return karta hai, numbers nahi! Agar sorted numbers chahiye toh np.sort(marks) ya marks[np.argsort(marks)] likhein.

Mistake 2: Overwriting Array with arr = arr.sort()

mistake2_none.pyPython (Fatal Trap)
import numpy as np

arr = np.array([5, 2, 8])
arr = arr.sort()  # DANGER: arr is now None!
print("arr:", arr)
Terminal Output
arr: None

The Fix: Either write arr.sort() (standalone statement without assignment), or use arr = np.sort(arr).

Mistake 3: Confusing np.argmax() with Maximum Value

mistake3_argmax.pyPython (Logic Bug)
import numpy as np

marks = np.array([40, 90, 20])
highest = np.argmax(marks)  # Returns 1 (index!), not 90!
print("Highest Marks:", highest)
Terminal Output
Highest Marks: 1

The Fix: Actual highest score ke liye np.max(marks) use karein, ya marks[np.argmax(marks)] evaluate karein.

Mistake 4: Running np.searchsorted() on an Unsorted Array

mistake4_unsorted.pyPython (Logic Bug)
import numpy as np

unsorted_arr = np.array([90, 10, 40, 20])
pos = np.searchsorted(unsorted_arr, 30)
print("Incorrect Position:", pos)
Terminal Output
Incorrect Position: 1

Why this happens: Binary search tabhi kaam karta hai jab array already sorted ho. Unsorted array par binary search arbitrary/invalid index return karega.

The Fix: Pehle array ko sort karein: np.searchsorted(np.sort(unsorted_arr), 30).

Mistake 5: Expecting np.where(cond) to Return Elements Directly

mistake5_where_tuple.pyPython
import numpy as np

arr = np.array([10, 20, 30])
res = np.where(arr > 15)
print("res type:", type(res))
print("res     :", res)
Terminal Output
res type: <class 'tuple'> res : (array([1, 2], dtype=int64),)

The Fix: np.where(cond) coordinates ka tuple return karta hai. Elements extract karne ke liye array indexing arr[res] ya index array res[0] use karein!

Mistake 6: Column Sorting Destroys Row Record Relationships

mistake6_2d_sort.pyPython
import numpy as np

# [RollNo, ScienceMarks]
data = np.array([
    [101, 90],  # Student 101 got 90
    [102, 40]   # Student 102 got 40
])

# WRONG: np.sort(data, axis=0) sorts RollNo and Marks independently!
bad_sort = np.sort(data, axis=0)
print("Corrupted Data:\n", bad_sort)
Terminal Output
Corrupted Data: [[101 40] [102 90]]

Student 101 ke marks 90 se badal kar 40 ban gaye! Humesha row integrity maintain karne ke liye np.argsort() se row indices nikal kar index karein: 

order = np.argsort(data[:, 1])  # Sort by Science marks
correct_data = data[order]       # Preserves row pairs!

Part C: 8 Multiple Choice Questions

MCQ 01 np.sort() aur ndarray.sort() mein primary difference kya hai?
Correct Option: np.sort() naya sorted copy banata hai; ndarray.sort() array ko in-place modify karta hai aur None return karta hai.
Explanation: In-place sorting original array ko change karti hai jabki top-level function original array ko safe rakhta hai.
MCQ 02 np.argsort() ka return value kya hota hai?
Correct Option: Sorted element values nahi, balki unke index coordinates.
Explanation: np.argsort() se mile indices ko parallel arrays par index karke records rank kiye jaate hain.
MCQ 03 2D array matrix par np.sort(matrix, axis=0) kis direction mein sort karta hai?
Correct Option: Down the columns (vertically row by row).
Explanation: axis=0 columns ke andar vertical sorting perform karta hai.
MCQ 04 np.argmax() array mein duplicate maximum values hone par kaunsa index return karta hai?
Correct Option: Sirf sabse pehla (first occurrence) index.
Explanation: Tied maximums ke saare indices paane ke liye np.where(arr == np.max(arr))[0] use kiya jata hai.
MCQ 05 np.searchsorted() use karne se pehle array ki mandatory prerequisite kya hai?
Correct Option: Array ka pehle se sorted hona compulsory hai.
Explanation: np.searchsorted() binary search use karta hai jo sirf sorted data par valid results produce karta hai.
MCQ 06 np.unique(data, return_counts=True) kya return karta hai?
Correct Option: Do arrays ka tuple: (unique_values, occurrence_counts).
Explanation: Isse category frequency distributions aur histograms direct C-speed par calculate ho jaate hain.
MCQ 07 np.unique() mein return_inverse=True ka main practical benefit kya hai?
Correct Option: Unique values se original array ko 100% reconstruct karna aur categorical data ko integer labels mein encode karna.
Explanation: unique_vals[inverse_indices] exactly original array generate karta hai.
MCQ 08 Agar array mein NaN mojud ho, toh np.sort() use kahan place karta hai?
Correct Option: Array ke bilkul aakhri positions (end) par.
Explanation: IEEE 754 float sorting convention ke hisaab se NaN values ko highest order index par end mein place kiya jata hai.
