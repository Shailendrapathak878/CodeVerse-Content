💡 Real-Life Scenario: Student Marks Processing
Suppose ek teacher ke paas 5 students ke exam marks ka array hai: [45, 60, 72, 81, 95]. Ab teacher ko teen alag-alag mathematical operations karne hain:

# Operation 3: Whole-array Summary / Reduction (Not a ufunc!)

Line-by-Line Breakdown: Ye Results Alag Kyun Hain?

  • np.sqrt(marks): Har element par floating-point square root calculate karta hai. Iska output bhi same size (5,) ka array hai: [6.71, 7.75, 8.49, 9.00, 9.75].
  • np.mean(marks): Pure array ke saare elements ko add karke unki count (5) se divide karta hai. Iska output koi naya array nahi, balki ek single scalar number 70.6 hai!
⚠️ The Key Conceptual Question
NumPy ka ek hi function poore array ke har element par itni rapidly math operation kaise execute kar pata hai bina Python for loop likhe? Iska answer hai: Universal Functions (ufuncs)!

🅰️ Section A: What are Universal Functions (ufuncs)?

NumPy mein Universal Function (ufunc) ek aisa function hota hai jo ndarray ke har ek element par fast, element-by-element operation perform karta hai. Ye functions standard C language mein compiled hote hain, isliye inme Python interpreter ka overhead nahi hota.

Key Characteristics of ufuncs

  • Element-Wise Execution: Ye array ke har element par parallel ya fast compiled loops mein run hote hain.
  • Broadcasting Support: Agar do arrays ke shapes alag hain (jaise ek matrix aur ek row vector), toh ufuncs automatically Broadcasting rules follow karte hain.
  • Type Casting & Buffering: Ufuncs automatic type conversion handle karte hain (e.g., integer array par np.sqrt() lene par floating-point output generate hota hai).
  • Optional Output Parameter (out=): Tum calculated results ko direct kisi pre-allocated array mein store kar sakte ho bina extra memory allocate kiye.
🛑 Crucial Distinction: ufunc vs Regular Function vs Reduction
Kya har NumPy function ek ufunc hota hai? Nahi!
• np.add, np.sin, np.sqrt: Ye true ufuncs hain (in ka type numpy.ufunc hota hai).
• np.mean, np.sum, np.median: Ye array reduction / summary functions hain jo multiple values ko reduce karke single scalar ya lower-dimension array banate hain.

Unary ufuncs vs Binary ufuncs

Operands (input arrays) ki sankhya ke aadhar par ufuncs ko do pramukh categories mein baanta gaya hai:

  1. Unary ufuncs: Ye sirf ek input array lete hain aur utne hi elements ka output array return karte hain. Examples: np.abs(), np.sqrt(), np.square(), np.sin(), np.exp().
  2. Binary ufuncs: Ye do input arrays (ya ek array aur ek scalar) lete hain aur corresponding elements par operation perform karte hain. Examples: np.add(), np.subtract(), np.multiply(), np.maximum().
Figure 10.1: Visual Comparison of Unary ufunc (1 Input → 1 Output) and Binary ufunc (2 Inputs → 1 Output).

⚠️ Vital Distinction: np.multiply vs @ Matrix Dot Product
Beginners aksar * aur @ mein confuse ho jaate hain:
• np.multiply(A, B) ya A * B: Element-wise multiplication karta hai (A[i,j] * B[i,j]).
• A @ B ya np.matmul(A, B): Linear algebra matrix dot product (row-by-column dot product) karta hai! Dono ke mathematical rules bilkul alag hain.

3. Negative Square Roots & Integer Reciprocal Caveats

⚠️ Domain Caution 1: Negative Square Root in Real Space
Agar real-number array mein negative number ka np.sqrt() nikala jaye, toh NumPy error throw karke crash nahi hota! Balki wo nan (Not a Number) return karta hai aur ek RuntimeWarning: invalid value encountered in sqrt raise karta hai. Complex numbers calculate karne ke liye complex input (e.g. np.array([-4+0j])) pass karna zaroori hai.
⚠️ Dtype Caution 2: Integer Reciprocal Truncation
Agar tum integer array par np.reciprocal(np.array([2, 4, 5])) call karoge, toh output [0, 0, 0] aayega! Kyunki integers mein 1 // 2 = 0 ho jata hai. Hamesha float array use karo: np.reciprocal(np.array([2.0, 4.0, 5.0])) → [0.5, 0.25, 0.2].

• np.log(0.0) calculate karne par NumPy -inf return karta hai aur divide by zero warning deta hai.

🅴 Section E: Rounding and Precision

Numerical data cleaning aur scientific measurements mein floating-point numbers ko neat decimals ya integers mein round karna padta hai. NumPy chaar alag-alag rounding ufuncs provide karta hai, aur in sabka mathematical behaviour different hota hai.

Figure 10.5: Comparative Behavior of np.round, np.floor, np.ceil, and np.trunc on Positive and Negative Values.

The 4 Core Rounding Functions

  1. np.round(a, decimals=0): Banker's Rounding (Round half to even) — Nearest integer par round karta hai. Agar value exact 0.5 par ho, toh nearest even integer choose karta hai (e.g. 2.5 → 2.0, lekin 3.5 → 4.0). Ye statistical bias reduce karta hai!
  2. np.floor(a): Round toward $-\infty$ — Value ko hamesha niche (downwards) round karta hai. 2.7 → 2.0, aur negative mein -2.3 → -3.0!
  3. np.ceil(a): Round toward $+\infty$ — Value ko hamesha upar (upwards) round karta hai. 2.3 → 3.0, aur negative mein -2.7 → -2.0!
  4. np.trunc(a): Round toward Zero — Simply decimal part ko cut kar deta hai bina direction shift kiye. 2.7 → 2.0 aur -2.7 → -2.0.
PYTHON 3rounding_comparison.py
import numpy as np

values = np.array([2.3, 2.7, 3.5, -2.3, -2.7])

print("Inputs:  ", values)
print("np.round:", np.round(values))
print("np.floor:", np.floor(values))
print("np.ceil: ", np.ceil(values))
print("np.trunc:", np.trunc(values))
[RUN RESULT]
Inputs: [ 2.3 2.7 3.5 -2.3 -2.7] np.round: [ 2. 3. 4. -2. -3.] np.floor: [ 2. 2. 3. -3. -3.] np.ceil: [ 3. 3. 4. -2. -2.] np.trunc: [ 2. 2. 3. -2. -2.]

🅵 Section F: Trigonometric Functions & Radians

NumPy pure mathematical trigonometric functions support karta hai: np.sin(), np.cos(), aur np.tan(). Lekin yahan sabse bada beginner trap hota hai Angle Units ka.

🅷 Section H: Aggregation and Mathematical Reductions (`axis`)

Element-wise ufuncs har input element ke liye ek output element produce karte hain. Lekin data analysis mein aksar hume data ko summarize karna hota hai: total revenue nikalna, class average find karna, ya standard deviation measure karna. NumPy inhe Reductions kehta hai.

Figure 10.8: Dimension Collapse in 2D Array Reductions: axis=0 (Column-wise) vs axis=1 (Row-wise).

Demystifying the `axis` Parameter

💡 The Golden Rule of Axis Reductions
Vague "rows vs columns" yaad rakhne ke bajay ye fundamental principle yaad rakho:
"Specified axis collapse (collapse/disappear) ho jati hai aur baaki dimensions bachti hain!"
  • axis=0 (Column-wise reduction): Rows collapse ho jati hain. Result array ka length number of columns ke barabar hota hai.
  • axis=1 (Row-wise reduction): Columns collapse ho jati hain. Result array ka length number of rows ke barabar hota hai.

Example: 3 Students × 3 Subjects Academic Matrix

PYTHON 3axis_demonstration.py
import numpy as np

# 3 Students (rows), 3 Subjects [Math, Physics, Chem] (columns)
marks_2d = np.array([
    [70, 80, 90],    # Student 1
    [60, 75, 85],    # Student 2
    [88, 92, 95]     # Student 3
])

# 1. Total marks scored by each student (axis=1 collapses columns)
student_totals = np.sum(marks_2d, axis=1)

# 2. Total marks scored across all students in each subject (axis=0 collapses rows)
subject_totals = np.sum(marks_2d, axis=0)

# 3. Overall Class Metrics
overall_mean = np.round(np.mean(marks_2d), 2)
overall_std = np.round(np.std(marks_2d), 2)
overall_var = np.round(np.var(marks_2d), 2)

print("Student Totals (axis=1):", student_totals)
print("Subject Totals (axis=0):", subject_totals)
print("Overall Class Mean:     ", overall_mean)
print("Overall Std Deviation:  ", overall_std)
print("Overall Variance:       ", overall_var)
[RUN RESULT]
Student Totals (axis=1): [240 220 275] Subject Totals (axis=0): [218 247 270] Overall Class Mean: 81.67 Overall Std Deviation: 10.84 Overall Variance: 117.56
⚠️ Statistical Note: Population vs Sample Standard Deviation
NumPy ka default np.std() population standard deviation calculate karta hai jahan denominator $N$ hota hai (ddof=0).
Agar tum sample statistics calculate kar rahe ho (jahan sample variance ka denominator $N-1$ hota hai), toh hamesha parameter pass karein: np.std(data, ddof=1).

🅸 Section I: Mathematical Operations with Broadcasting

NumPy universal functions ka sabse powerful feature ye hai ki wo automatically Broadcasting rules (Topic 8) follow karte hain. Iska matlab agar operands ka shape exact match nahi karta, lekin compatible hai, toh NumPy smaller array ko logically stretch karke element-wise math perform kar deta hai bina actual copy banaye!

🅺 Section K: Common Mistakes & Debugging Guide

NumPy mathematical operations use karte waqt beginners aksar 6 critical mistakes karte hain. Aao har mistake ka reason, actual error behavior, aur verified fix samjhein:

❌ Mistake 1: Passing Angles in Degrees to Trigonometric Functions

Misleading Code:

angle = 30
result = np.sin(angle)  # Expected 0.5, but gets -0.988031624!

Why it happens: NumPy's np.sin accepts radians, not degrees. 30 is interpreted as 30 radians (~1718 degrees)!

✅ Corrected Code:
result = np.sin(np.deg2rad(30))  # Returns exact 0.5
❌ Mistake 2: Taking Square Root of Negative Real Numbers

Misleading Code:

vals = np.array([-4.0, 9.0])
roots = np.sqrt(vals)
# Emits RuntimeWarning: invalid value encountered in sqrt
# Returns [nan, 3.]

Why it happens: In real-number arithmetic, square root of a negative number does not exist. NumPy returns NaN.

✅ Corrected Code:
# 1. Sanitize with np.maximum/np.clip OR convert to complex
safe_vals = np.maximum(vals, 0.0)
roots = np.sqrt(safe_vals)  # Returns [0., 3.]
❌ Mistake 3: Confusing np.maximum() with np.max()

Misleading Code:

a = np.array([10, 50, 30])
b = np.array([20, 40, 35])
highest = np.max(a, b)  # TypeError: cannot interpret 'b' as an axis integer!

Why it happens: np.max(a) is an aggregation function for a single array. To compare two arrays element-wise, you MUST use binary ufunc np.maximum(a, b).

✅ Corrected Code:
element_wise_max = np.maximum(a, b)  # Returns [20, 50, 35]
❌ Mistake 4: Confusing Natural Log np.log() with Base-10 Log

Misleading Code:

val = np.log(100)  # Beginner expects 2.0, but gets 4.60517!

Why it happens: In mathematics and computer science, log without suffix means Natural Logarithm (base $e$). For base 10, explicitly use np.log10().

✅ Corrected Code:
val = np.log10(100)  # Returns exact 2.0
❌ Mistake 5: Integer Reciprocal Truncation Caveat

Misleading Code:

int_arr = np.array([2, 4, 8])
recip = np.reciprocal(int_arr)  # Returns [0, 0, 0]!

Why it happens: Input dtype is integer, so 1/2 is floor-divided to 0 in integer space.

✅ Corrected Code:
float_arr = np.array([2.0, 4.0, 8.0])
recip = np.reciprocal(float_arr)  # Returns [0.5, 0.25, 0.125]
❌ Mistake 6: Forgetting axis in Multidimensional Aggregation

Misleading Code:

marks = np.array([[70, 80], [60, 90]])
student_averages = np.mean(marks)  # Returns 75.0 (scalar total average, NOT per-student!)

Why it happens: Without specifying axis, NumPy reduces the entire matrix into a single scalar value.

✅ Corrected Code:
student_averages = np.mean(marks, axis=1)  # Returns [75., 75.]

Part 3: Debugging Challenges (6 Questions)

Debug 1 Fix: TypeError: loop of ufunc does not support argument 0 of type list
Buggy Code: np.sqrt([4, 9, 16]) works, but custom list methods fail when passed directly into some functions expecting ndarray.

Debug 5 Fix: RuntimeWarning: divide by zero encountered in log
