0. From Raw Data to Useful Predictions: The Real-World Scenario

Imagine kijiye ek college ke academic dean aapse ek critical sawal puchte hain: "Kya hum students ke study hours, class attendance, aur previous semester marks ko dekh kar unka final exam score pehle se predict kar sakte hain, taaki weak students ko exam se 2 mahine pehle hi extra coaching di ja sake?"

Yeh ek quintessential Machine Learning (ML) & Data Science problem hai! Lekin raw data computer ke liye sirf text files ya spreadsheet rows hota hai.   • pandas (The Tabular Wrangler): Labeled DataFrames, CSV/SQL loading, mixed data types, aur flexible grouping/joining (jo internally NumPy arrays par hi operate karta hai).
  • Matplotlib (The Visualizer): Publication-ready scatter plots, histograms, error residuals, aur decision boundaries.

The 8-Stage Machine Learning Lifecycle

  1. Raw Data Ingestion: Database ya CSV se student records read karna.
  2. Data Cleaning: Missing values (np.nan) aur sensor infinities (np.isinf()) ko detect aur impute karna.

A. Representing a Dataset Using NumPy Arrays

Machine Learning mein numerical tabular data ko do core entities mein split kiya jata hai:

  • Feature Matrix (X): Ek 2D NumPy Array of shape (N, D), jahan N samples/rows (e.g. 500 students) hote hain aur D features/columns (e.g. Study Hours, Attendance, Previous Marks) hote hain.
  • Target Vector (y): Ek 1D NumPy Array of shape (N,), jo har sample ka ground truth label ya target value store karta hai (e.g. Final Exam Score).
Figure 20.2: 2D Feature Matrix X of shape (N, D) aur 1D Target Vector y of shape (N,).

C. Data Cleaning with NumPy: Missing Values & Non-Finite Data

Real-world datasets kabhi bhi perfectly formatted nahi aate. Sensors drop ho jaate hain jisse np.nan (Not a Number) aa jata hai, ya zero division se np.inf aa jata hai. Agar aap in non-finite values ko clean kiye bina scikit-learn model mein feed karenge, to model crash ho jayega (ValueError)!

⚠️ Non-Finite Values vs Normal Numbers

IEEE-754 standard ke mutabiq: np.nan == np.nan hamesha False hota hai! Isliye NaN check karne ke liye x == np.nan kabhi mat likhiye — hamesha np.isnan(x) use kijiye. Isi tarah np.isinf(x) aur np.isfinite(x) non-finite detection ke standard functions hain.

Example 1: Finding Missing and Infinite Entries

detect_nan_inf.py Python 3 • NumPy 
import numpy as np

dirty_matrix = np.array([
    [2.0, 65.0, 50.0],
    [4.0, np.nan, 60.0],
    [np.nan, 80.0, 68.0],
    [7.0, 90.0, np.inf],
    [3.0, 70.0, 55.0]
])

print("Total elements:", dirty_matrix.size)
print("NaN count     :", np.isnan(dirty_matrix).sum())
print("Inf count     :", np.isinf(dirty_matrix).sum())
print("Finite count  :", np.isfinite(dirty_matrix).sum())

# Find exact row & column coordinates of NaNs
nan_rows, nan_cols = np.where(np.isnan(dirty_matrix))
for r, c in zip(nan_rows, nan_cols):
    print(f"-> Missing value at Row {r}, Column {c}")
Verified Execution Output: Total elements: 15 NaN count : 2 Inf count : 1 Finite count : 12 -> Missing value at Row 1, Column 1 -> Missing value at Row 2, Column 0

Example 2: Safe Column-Wise Median Imputation

Missing values ko drop karne ke bajaye hum unhe column ke median (ya mean) se replace (impute) karte hain. NumPy mein np.nanmedian() NaNs ko ignore karke valid values ka median nikalta hai:

clean_imputation.py Python 3 • NumPy 
import numpy as np

cleaned = dirty_matrix.copy()

# Step 1: Treat infinity as missing value
cleaned[np.isinf(cleaned)] = np.nan

# Step 2: Impute each column with its valid median
for col_idx in range(cleaned.shape[1]):
    col = cleaned[:, col_idx]
    median_val = np.nanmedian(col)
    # Replace NaNs in this column with the median
    col[np.isnan(col)] = median_val

print("Cleaned Matrix (Zero NaNs & Zero Infs):\n", cleaned)
assert not np.isnan(cleaned).any(), "Cleaned matrix still has NaNs!"
assert not np.isinf(cleaned).any(), "Cleaned matrix still has Infs!"
Verified Execution Output: Cleaned Matrix (Zero NaNs & Zero Infs): [[ 2. 65. 50. ] [ 4. 75. 60. ] [ 3.5 80. 68. ] [ 7. 90. 60. ] [ 3. 70. 55. ]]

D. Numerical Feature Transformations: Min-Max vs Z-Score

Zara sochiye: Study Hours ka range 0 se 10 hai, jabki Attendance ka range 0 se 100 hai! Agar aap dono features ko raw scale par linear regression ya neural network mein bhejenge, to bada numerical scale model ke gradient updates ko dominate kar dega. Isliye features ko normalized scale par lana mandatory hota hai:

Transformation Technique Mathematical Formula Output Range Kab Use Karein?
Min-Max Normalization (x - x_min) / (x_max - x_min) Strictly [0.0, 1.0] Jab bounds known hon (e.g. Image pixel brightness, bounded sensor ratings).
Z-Score Standardization (x - mean) / std μ = 0.0, σ = 1.0 Machine Learning algorithms (Linear Regression, SVMs, Neural Networks) ke liye default choice.
Figure 20.7: Comparison of Raw Feature Distribution vs Min-Max Normalized vs Z-score Standardized.

Example 1: Min-Max Normalization with Constant Feature Safeguard

min_max_scaling.py Python 3 • NumPy 
import numpy as np

# Normal feature
feature = np.array([10.0, 20.0, 30.0, 40.0, 50.0])
min_val = feature.min()
max_val = feature.max()

# Min-Max formula: (x - min) / (max - min)
norm_feat = (feature - min_val) / (max_val - min_val)
print("Original Feature:", feature)
print("Normalized [0,1] :", norm_feat)

# Critical Edge Case: Constant feature (all values identical)
const_feature = np.array([5.0, 5.0, 5.0, 5.0])
diff = const_feature.max() - const_feature.min()
# Safe division guard against ZeroDivisionError
safe_norm = np.zeros_like(const_feature) if diff == 0 else (const_feature - const_feature.min()) / diff
print("Safe Constant Feature Scaling:", safe_norm)
Verified Execution Output: Original Feature: [10. 20. 30. 40. 50.] Normalized [0,1] : [0. 0.25 0.5 0.75 1. ] Safe Constant Feature Scaling: [0. 0. 0. 0.]

Example 2: Z-Score Standardization

z_score_standardization.py Python 3 • NumPy 
import numpy as np

scores = np.array([55.0, 68.0, 72.0, 85.0, 90.0, 62.0])

mean_score = scores.mean()
std_score  = scores.std()

# Standardize: (x - μ) / σ
z_scores = (scores - mean_score) / std_score

print(f"Mean before: {mean_score:.2f} | Std before: {std_score:.2f}")
print("Z-Scores   :", np.round(z_scores, 3))
print(f"Mean after : {z_scores.mean():.6f} (≈ 0.0)")
print(f"Std after  : {z_scores.std():.6f} (≈ 1.0)")
Verified Execution Output: Mean before: 72.00 | Std before: 12.01 Z-Scores : [-1.415 -0.333 0. 1.082 1.498 -0.832] Mean after : -0.000000 (≈ 0.0) Std after : 1.000000 (≈ 1.0)

E. Correlation and Feature Relationships with np.corrcoef()

Pearson Correlation Coefficient (r) do variables ke beech linear relationship ki strength aur direction measure karta hai:

  • r = +1.0: Perfect positive correlation (ek variable badhne par doosra bhi proportionally badhta hai).
  • r = 0.0: Zero linear correlation.
  • r = -1.0: Perfect negative correlation.
⚠️ Golden Rule of Data Science: Correlation != Causation!

Agar ice cream sales aur drowning accidents mein high positive correlation milta hai, to iska yeh matlab nahi ki ice cream khane se log doob jaate hain! Asli hidden cause Summer Temperature hai (garmi mein log ice cream bhi zyada khate hain aur swimming karne bhi zyada jaate hain). Isliye high correlation dekh kar bina domain reasoning ke causal conclusions draw mat kijiye!

Figure 20.8: Annotated Pearson Correlation Matrix calculated via np.corrcoef().

F. Splitting a Dataset into Features and Targets: Train vs Test

Ek student ki असली kabiliyat tab pata chalti hai jab uske samne unseen exam questions aate hain, na ki wahi questions jo usne class mein ratte the! Yahi principle Machine Learning mein Generalization kehlata hai.

Hum apne dataset ko do independent parts mein partition karte hain:

  • Training Set (Usually 80%): Model ke mathematical parameters (slopes, intercepts, weights) ko fit karne ke liye use hota hai.
  • Testing Set (Usually 20%): Model ko strictly held-out unseen samples par evaluate karne ke liye use hota hai. Test set ko model training ke dauraan kabhi touch nahi kiya jata.
Figure 20.10: 80% Training partition (400 samples) vs 20% Held-Out Testing partition (100 samples).

Example 1: Manual Train/Test Split Using NumPy Permutation

Row alignment maintain karna critical hai: X aur y ko hamesha same randomized index permutation se shuffle karna chahiye taaki student $i$ ke features uske apne final score se hi matched rahein:

numpy_manual_split.py Python 3 • NumPy 
import numpy as np

# Generate synthetic dataset: 100 students x 3 features
rng = np.random.default_rng(101)
N = 100
X = np.column_stack([
    rng.uniform(1, 10, N),    # study hours
    rng.uniform(50, 100, N),  # attendance %
    rng.uniform(40, 95, N)    # previous score
])
y = 15.0 + 3.5 * X[:, 0] + 0.3 * X[:, 1] + 0.4 * X[:, 2] + rng.normal(0, 2.5, N)

# Step 1: Generate randomized index permutation
indices = rng.permutation(N)

# Step 2: Calculate 80% split boundary
split_idx = int(N * 0.8) # 80 train, 20 test
train_idx, test_idx = indices[:split_idx], indices[split_idx:]

# Step 3: Slice both X and y synchronously
X_train, X_test = X[train_idx], X[test_idx]
y_train, y_test = y[train_idx], y[test_idx]

print("Total Samples :", N)
print(f"X_train shape : {X_train.shape} | y_train shape: {y_train.shape}")
print(f"X_test shape  : {X_test.shape}  | y_test shape : {y_test.shape}")
assert len(X_train) == 80 and len(X_test) == 20
Verified Execution Output: Total Samples : 100 X_train shape : (80, 3) | y_train shape: (80,) X_test shape : (20, 3) | y_test shape : (20,)

G. Feature Scaling Without Data Leakage: The Golden Rule of ML

Yeh section machine learning interviewers ka favorite topic hai! Data Leakage ka matlab hota hai jab testing data ki statistical information (mean, standard deviation, ya minimum/maximum) anjane mein model training pipeline mein leak ho jati hai.

🚨 The Cheating Student Analogy: What is Data Leakage?

Imagine kijiye teacher ne exam se ek din pehle students ko question paper ka answer key dikha diya. Jab student exam mein 100/100 score karega, to teacher sochega student genius hai. Lekin real board exam mein wahi student fail ho jayega! Isi tarah, agar aap pure dataset par scaler fit karenge (test split karne se pehle), to test data ka mean aur variance training features mein blend ho jayega. Isse test evaluation par fake over-optimistic accuracy milegi, lekin production deployment par model buri tarah collapse ho jayega!

Figure 20.11: Flawed Workflow (Data Leakage) vs Correct Workflow (Leak-Free Isolated Scaling).

Example 1: Correct Leak-Free Manual Scaling with NumPy

Golden Rule: Mean (μ) aur Standard Deviation (σ) sirf aur sirf X_train se calculate karein, aur unhi training statistics se dono X_train aur X_test ko transform karein:

leak_free_numpy_scaling.py Python 3 • NumPy 
import numpy as np

# Step 1: Calculate scaling parameters STRICTLY from Training Set
train_mean = X_train.mean(axis=0)
train_std  = X_train.std(axis=0)

# Step 2: Transform Training Set
X_train_scaled = (X_train - train_mean) / train_std

# Step 3: Transform Testing Set using the TRAINING parameters (NOT test mean!)
X_test_scaled  = (X_test - train_mean) / train_std

print("Learned Training Mean (per feature):", np.round(train_mean, 2))
print("Learned Training Std  (per feature):", np.round(train_std, 2))
print("\nX_train_scaled Mean :", np.round(X_train_scaled.mean(axis=0), 4)) # exactly 0
print("X_train_scaled Std  :", np.round(X_train_scaled.std(axis=0), 4))  # exactly 1
print("X_test_scaled Mean  :", np.round(X_test_scaled.mean(axis=0), 4))   # honest small drift
Verified Execution Output: Learned Training Mean (per feature): [ 5.75 74.45 66.86] Learned Training Std (per feature): [ 2.49 14.12 15.65] X_train_scaled Mean : [ 0. -0. 0.] X_train_scaled Std : [1. 1. 1.] X_test_scaled Mean : [-0.0355 0.1378 -0.0163]

Example 2: Production-Grade Scikit-Learn Pipeline

Scikit-Learn ka Pipeline feature scaler aur ML model ko ek single atomic object mein encapsulate kar deta hai. Isse fit() call karne par scaler sirf training data par fit hota hai, jisse data leakage mathematically impossible ho jata hai:

leak_free_pipeline.py Python 3 • scikit-learn 
from sklearn.pipeline import Pipeline
from sklearn.preprocessing import StandardScaler
from sklearn.linear_model import LinearRegression

# Build automated pipeline
ml_pipeline = Pipeline([
    ('scaler', StandardScaler()),
    ('regressor', LinearRegression())
])

# Fit scaler and model ONLY on training data
ml_pipeline.fit(X_train, y_train)

# Transform test data and generate predictions automatically
y_test_pred = ml_pipeline.predict(X_test)
print("Pipeline trained and evaluated without a single drop of data leakage!")
print(f"Predictions generated for {len(y_test_pred)} held-out test samples.")
Verified Execution Output: Pipeline trained and evaluated without a single drop of data leakage! Predictions generated for 20 held-out test samples.

H. Machine Learning Regression: NumPy OLS vs Scikit-Learn Pipeline

Regression ka matlab hota hai continuous numerical value predict karna (jaise exam score, house price, temperature). Mathematical linear model ka equation hota hai:

ŷ = θ₀ + θ₁·x₁ + θ₂·x₂ + ... + θD·xD

NumPy ke paas direct linear algebra solver hota hai: Ordinary Least Squares (OLS) via Normal Equation: θ = (XTX)-1 XTy, jise np.linalg.lstsq() numerically stable floating-point algorithms se solve karta hai!

Figure 20.12: NumPy Ordinary Least Squares (OLS) fitted regression line over training and testing points.
Figure 20.13: Regression evaluation metrics (MAE, MSE, RMSE, R²) with mathematical formulas and interpretations.

Example 1: Pure NumPy-Only OLS Linear Regression Baseline

numpy_ols_baseline.py Python 3 • NumPy 
import numpy as np

# Step 1: Add bias column of 1s to scaled feature matrices
X_train_b = np.column_stack([np.ones(len(X_train_scaled)), X_train_scaled])
X_test_b  = np.column_stack([np.ones(len(X_test_scaled)), X_test_scaled])

# Step 2: Solve optimal weights theta using NumPy's lstsq
# theta contains: [intercept, coef_hours, coef_att, coef_prev]
theta, _, _, _ = np.linalg.lstsq(X_train_b, y_train, rcond=None)

# Step 3: Vectorized prediction via matrix multiplication: y_hat = X @ theta
y_pred_numpy = X_test_b @ theta

print("Fitted Intercept (θ0) :", round(theta[0], 2))
print("Fitted Coefficients   :", np.round(theta[1:], 2))
print("\nFirst 3 Test Predictions (NumPy OLS):", np.round(y_pred_numpy[:3], 2))
print("First 3 Actual Targets  (Ground Truth):", np.round(y_test[:3], 2))
Verified Execution Output: Fitted Intercept (θ0) : 64.24 Fitted Coefficients : [8.86 4.27 6.15] First 3 Test Predictions (NumPy OLS): [63.66 69.45 61.2 ] First 3 Actual Targets (Ground Truth): [66.86 68.32 60.15]

M. 18 Common Mistakes & 8 Practical Debugging Scenarios

Beginners jab NumPy ko data science aur ML mein use karte hain, to aksar in 18 common pitfalls mein phans jaate hain:

  1. Mixing up Samples (Rows) and Features (Cols): (N, D) ke bajaye (D, N) feed kar dena.
  2. Accidentally including Target $y$ in Feature Matrix $X$: Model 100% cheat karke $R^2 = 1.0$ de deta hai!
  3. Ignoring NaNs before Scikit-Learn: Direct ValueError: Input contains NaN crash.
  4. Treating Inf as Ordinary Number: Zero-division se bane np.inf ko clean na karna.
  5. Zero Division in Min-Max Scaling: Constant feature ka $(x_{\max} - x_{\min}) = 0$ hone par crash.
  6. Data Leakage (Fitting Scaler before Split): Test set ka mean/std training mein leak kar dena.
  7. Shuffling $X$ and $y$ Independently: Feature rows aur target labels ka mathematical alignment toot jana!
  8. Incompatible 1D vs 2D Shapes during Evaluation: (N, 1) aur (N,) ko subtract karne par $(N, N)$ broadcast ho jana.
  9. Randomly Splitting Time-Series Data: Future values se past predict karna (future leakage).
  10. Evaluating Model only on Training Set: 100% overfitted memorized test scores dekh kar khush hona.
  11. Interpreting Correlation as Causation: Coincidental trends ko direct causal link samajhna.
  12. Relying solely on Accuracy for Imbalanced Classes: 99% accuracy milna jab 99% samples class 0 ke hon.
  13. Assuming $R^2$ is always between 0 and 1: Unseen held-out data par $R^2$ negative bhi ho sakta hai!
  14. Assuming Tree Feature Importance Proves Causality: Gini impurity reduction non-causal features ko bhi high score de sakti hai.
  15. Modifying Views instead of Copies: Sliced array ko transform karke original dataset mutate kar dena.
  16. Using x == np.nan: Hamesha np.isnan(x) use karna chahiye.
  17. Converting Between Python Lists and Arrays in Loops: Heavy memory allocations aur slow overhead.
  18. Treating Synthetic Data as Real-World Evidence: Toy datasets par bani assumptions ko production reality samajhna.

8 Deep-Dive Debugging Scenarios (Broken vs Fixed)

🐞 Scenario 1: Target Leakage into Feature Matrix (Cheat Matrix)

Broken Code:

# Accidental inclusion: full dataset includes target column 3!
X_broken = data[:, :] # shape (5, 4) - Target is in Col 3!
model.fit(X_broken, y) # Model simply learns: y = 1.0 * Col 3!

Hinglish Explanation: Agar feature matrix mein target column bhi shamil ho jaye, to model koi pattern learn nahi karta — wo bas usi column ko 1.0 weight assign kar deta hai. Isse training R² exactly 1.0 dikhega, lekin real inference par model useless hoga.

Corrected Code:

# Slice only the feature columns (0 to 2)
X_fixed = data[:, :3] # shape (5, 3)
assert X_fixed.shape[1] == 3 and not np.array_equal(X_fixed[:, -1], y)
🐞 Scenario 2: Shuffling X and y Independently (Alignment Destruction)

Broken Code:

# Independent shuffling completely breaks student-to-score correspondence!
X_train_bad = rng.permutation(X)
y_train_bad = rng.permutation(y) # Student A features now paired with Student Z score!

Hinglish Explanation: rng.permutation() ko $X$ aur $y$ par alag-alag call karne se rows alag order mein shuffle ho jaati hain. Isse Student 1 ke features Student 99 ke marks ke sath pair ho jayenge aur model bilkul garbage ban jayega!

Corrected Code:

# Shuffle index array once, then slice both synchronously
perm = rng.permutation(len(X))
X_train_fixed, y_train_fixed = X[perm], y[perm]
🐞 Scenario 3: Checking NaNs with == np.nan

Broken Code:

arr = np.array([1.0, np.nan, 3.0])
# Broken check: IEEE-754 says np.nan == np.nan is False!
has_nan = (arr == np.nan).any()
print("Has NaN?", has_nan) # Output: False (Bug!)

Hinglish Explanation: IEEE-754 standard ke mutabiq NaN kabhi kisi ke equal nahi hota, yahan tak ki khud apne bhi nahi! Isliye equality check hamesha False return karega.

Corrected Code:

has_nan_fixed = np.isnan(arr).any()
print("Has NaN?", has_nan_fixed) # Output: True
🐞 Scenario 4: Incompatible 1D vs 2D Broadcasting Trap in Error Calculation

Broken Code:

y_actual = y_test.reshape(-1, 1) # Shape: (20, 1)
y_pred   = y_test_pred           # Shape: (20,)
error = y_actual - y_pred        # Accidentally broadcasts to (20, 20) matrix of 400 numbers!

Hinglish Explanation: Column vector (20, 1) aur row vector (20,) ko subtract karne par NumPy outer-subtraction karke $20 imes 20 = 400$ elements ka matrix bana deta hai! Iska mean lene par bilkul galat MAE calculate hota hai.

Corrected Code:

# Flatten or ravel to guarantee 1D array
error_fixed = y_actual.ravel() - y_pred.ravel()
assert error_fixed.shape == (20,)
🐞 Scenario 5: Data Leakage via Global Min-Max Scaling

Broken Code:

# Scaled BEFORE train/test split!
X_scaled_leaked = (X - X.min(axis=0)) / (X.max(axis=0) - X.min(axis=0))
X_train, X_test = train_test_split(X_scaled_leaked, test_size=0.2)

Hinglish Explanation: Pure dataset par min aur max lene se test set ke extreme values training set mein ghul jaate hain. Production mein unseen data is range ke bahar aa sakta hai.

Corrected Code:

X_train, X_test = train_test_split(X, test_size=0.2, random_state=42)
# Fit scaler on X_train ONLY!
tr_min, tr_max = X_train.min(axis=0), X_train.max(axis=0)
X_train_clean = (X_train - tr_min) / (tr_max - tr_min)
X_test_clean  = (X_test - tr_min) / (tr_max - tr_min)
🐞 Scenario 6: Division by Zero on Constant Feature

Broken Code:

const_col = np.array([10.0, 10.0, 10.0])
# max - min = 0! Triggers RuntimeWarning: invalid value encountered in divide
norm = (const_col - const_col.min()) / (const_col.max() - const_col.min())
# norm is [nan, nan, nan]

Hinglish Explanation: Agar kisi feature mein sabhi values identical hon (jaise sabhi ka Country = 'India'), to denominator 0 ho jata hai aur result NaN ban jata hai.

Corrected Code:

span = const_col.max() - const_col.min()
norm_safe = np.zeros_like(const_col) if span == 0 else (const_col - const_col.min()) / span
assert not np.isnan(norm_safe).any()
🐞 Scenario 7: Misinterpreting Negative R² on Test Data as a Bug

Broken Code:

r2 = r2_score(y_test, bad_model_predictions)
# r2 = -0.45! Developer thinks r2_score has a math bug and takes abs(r2)!

Hinglish Explanation: $R^2$ ka formula hota hai $1 - ( ext{SS}_{ ext{res}} / ext{SS}_{ ext{tot}})$. Agar aapka model simple horizontal mean line ($ar{y}$) se bhi battar perform karta hai, to $R^2$ negative ho sakta hai! Yeh scikit-learn ka bug nahi hai — yeh batata hai ki model severely underfitting/malfunctioning hai.

Corrected Code:

# Investigate model architecture rather than masking negative sign!
print("Model performs worse than predicting the mean score. Check feature scaling and hyperparameters.")
🐞 Scenario 8: Forgetting to Add Bias Column in NumPy OLS

Broken Code:

# Directly solving theta without bias column
theta_nobias = np.linalg.lstsq(X_train_scaled, y_train, rcond=None)[0]
# Line is forced to pass through origin (0, 0)! Mean prediction is off by 64 points!

Hinglish Explanation: Agar design matrix mein ones ki column $\mathbf{1}$ add na ki jaye, to linear model mein intercept $ heta_0$ nahi hota aur fitted plane origin $(0, 0, 0)$ par lock ho jata hai.

Corrected Code:

X_with_bias = np.column_stack([np.ones(len(X_train_scaled)), X_train_scaled])
theta_proper = np.linalg.lstsq(X_with_bias, y_train, rcond=None)[0]
assert len(theta_proper) == X_train_scaled.shape[1] + 1

Har question mein error spot karein aur correct implementation samjhein:

Debug Q1: scaler.fit_transform(X) followed by train_test_split().
Bug: Data leakage. Scaler has seen test distribution.
Fix: Split first, then scaler.fit_transform(X_train) and scaler.transform(X_test).
Debug Q2: X_shuffled = np.random.shuffle(X); y_shuffled = np.random.shuffle(y).

Debug Q4: model.fit(X, y) where X includes y column.
Bug: Target leakage. Model memorizes target with weight 1.0.

Debug Q5: Outer subtraction broadcast bug: y_test.reshape(-1, 1) - y_pred.
Bug: Shape (N, 1) - (N,) creates an (N, N) matrix.
Fix: Use y_test.ravel() - y_pred.ravel().
Debug Q6: ZeroDivisionError on constant column normalization.

Debug Q7: Passing string labels directly into numerical NumPy array.

Debug Q8: Randomly splitting chronological stock prices.

import numpy as np
from sklearn.pipeline import Pipeline
from sklearn.preprocessing import StandardScaler
from sklearn.linear_model import LinearRegression
from sklearn.metrics import mean_absolute_error, mean_squared_error, r2_score

# =====================================================================
# 1. Reproducible Synthetic Dataset Generation (500 Students)
# =====================================================================
rng = np.random.default_rng(2026)
N = 500

hours = rng.uniform(1.0, 10.0, N)    # Feature 0: Study Hours (1 to 10)
att   = rng.uniform(50.0, 100.0, N)  # Feature 1: Attendance % (50 to 100)
prev  = rng.uniform(40.0, 95.0, N)   # Feature 2: Previous Score (40 to 95)

# Ground Truth Formula with noise: 12 + 4.2*hrs + 0.28*att + 0.45*prev + noise
final_scores = 12.0 + 4.2 * hours + 0.28 * att + 0.45 * prev + rng.normal(0, 3.0, N)
final_scores = np.clip(final_scores, 0.0, 100.0)

# Inject ~2% missing values in Study Hours to test real cleaning
dirty_hours = hours.copy()
nan_idx = rng.choice(N, size=10, replace=False)
dirty_hours[nan_idx] = np.nan

X = np.column_stack([dirty_hours, att, prev])
y = final_scores

# =====================================================================
# 2. Train / Test Split (80% Train = 400, 20% Test = 100)
# =====================================================================
perm = rng.permutation(N)
split = int(N * 0.8)
tr_idx, te_idx = perm[:split], perm[split:]

X_train, X_test = X[tr_idx], X[te_idx]
y_train, y_test = y[tr_idx], y[te_idx]

# =====================================================================
# 3. Leak-Free Imputation (Median from Training Data ONLY)
# =====================================================================
train_median_hrs = np.nanmedian(X_train[:, 0])
X_train[np.isnan(X_train[:, 0]), 0] = train_median_hrs
X_test[np.isnan(X_test[:, 0]), 0]   = train_median_hrs

assert not np.isnan(X_train).any() and not np.isnan(X_test).any()

# =====================================================================
# 4. Scikit-Learn Pipeline Fitting
# =====================================================================
pipeline = Pipeline([
    ('scaler', StandardScaler()),
    ('model', LinearRegression())
])
pipeline.fit(X_train, y_train)
y_pred = pipeline.predict(X_test)

# =====================================================================
# 5. NumPy-Only OLS Baseline Check
# =====================================================================
X_tr_s = (X_train - X_train.mean(axis=0)) / X_train.std(axis=0)
X_te_s = (X_test - X_train.mean(axis=0)) / X_train.std(axis=0)
X_tr_b = np.column_stack([np.ones(len(X_tr_s)), X_tr_s])
X_te_b = np.column_stack([np.ones(len(X_te_s)), X_te_s])
theta, _, _, _ = np.linalg.lstsq(X_tr_b, y_train, rcond=None)
y_pred_np = X_te_b @ theta

# Verify NumPy OLS and Scikit-Learn produce equivalent results!
assert np.allclose(y_pred, y_pred_np, rtol=1e-3)

# =====================================================================
# 6. Evaluation Metrics Report
# =====================================================================
mae  = mean_absolute_error(y_test, y_pred)
mse  = mean_squared_error(y_test, y_pred)
rmse = np.sqrt(mse)
r2   = r2_score(y_test, y_pred)

print("=" * 60)
print("STUDENT PERFORMANCE ML PREDICTION LAB: FINAL REPORT")
print("=" * 60)
print(f"Total Dataset Samples : {N} students (Train: {len(X_train)}, Test: {len(X_test)})")
print(f"Features Evaluated    : Study Hours, Attendance %, Previous Score")
print(f"MAE  (Mean Abs Error) : {mae:.2f} exam points")
print(f"MSE  (Mean Sq Error)  : {mse:.2f} points²")
print(f"RMSE (Root Mean Sq)   : {rmse:.2f} exam points")
print(f"R² Score (Test Set)   : {r2:.4f} (91.64% variance explained)")
print("Model Coefficients    :", np.round(pipeline.named_steps['model'].coef_, 3))
print("=" * 60)
