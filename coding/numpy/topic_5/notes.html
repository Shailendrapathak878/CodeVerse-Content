01 Opening Hook — Finding One Value in a Sea of Data

Imagine kijiye aapke paas ek massive school database hai jisme 5 students ke 3 alag-alag subjects ke marks store hain. Ek grocery shop owner ke paas pure month ki daily revenue ka record hai. Aur ek weather forecasting center ke paas pure hafte ke hourly temperatures hain.

Humein real-life data science me kabhi bhi pure dataset ki ek sath zaroorat nahi hoti:

  • Kayi baar humein sirf ek specific student ke marks dekhne hote hain.
  • Kayi baar humein sirf Science subject ka average nikalna hota hai.
  • Kayi baar humein sirf Monday se Wednesday tak ka temperature analyze karna hota hai.
  • Kayi baar shop owner ko sirf last 3 days ki sales check karni hoti hai.
The Fundamental Rule:
• Indexing (इंडेक्सिंग): Ek single specific element ko uski exact position se pick karta hai (jaise kisi book ka page number 42 kholna).
• Slicing (स्लाइसिंग): Elements ki ek range ya continuous section ko extract karta hai (jaise page number 10 se 20 tak padhna).

Aaiye ek simple array [12, 24, 36, 48, 60] ko dekhte hain jisme positive aur negative indexing ko visually map kiya gaya hai:

Element Value 12 24 36 48 60
Positive Index (Left to Right) 0 1 2 3 4
Negative Index (Right to Left) -5 -4 -3 -2 -1

02 Section A — Basic Array Indexing

NumPy me kisi bhi element ko access karne ke liye square brackets [] ka use hota hai. Python hamesha zero-based indexing follow karta hai: yani array ka sabse pehla item index 0 par baithta hai, second item index 1 par, aur n-th item index n-1 par.

Example 1 — Student Marks Retrieval Python 
import numpy as np

# 5 students ke test marks store karte hain
marks = np.array([78, 85, 92, 67, 88])

print(marks[0])  # Pehla student (Index 0)
print(marks[2])  # Teesra student (Index 2)
print(marks[4])  # Paanchva student (Index 4)
Verified Python Output
78 92 88

Line-by-line Breakdown:
• marks[0] → Index 0 par pehla number 78 hai, jo successfully return hua.
• marks[2] → Index 2 par teesra element 92 hai.
• marks[4] → Total 5 elements hain, isliye aakhri element ka index 5 - 1 = 4 hai, jo 88 deta hai.

Example 2 — Daily Store Sales Python 
import numpy as np

# 5 days ki store sales (in INR ₹)
sales = np.array([1200, 1500, 980, 1750, 2100])

print("First day:", sales[0])
print("Third day:", sales[2])
print("Last day:", sales[4])
Verified Python Output
First day: 1200 Third day: 980 Last day: 2100

Dekhiye kaise same indexing syntax alag-alag datasets me accurate values fetch karne ke liye kaam karta hai.

03 Section B — Negative Indexing

Jab humein array ka last element, second last element ya end se data chahiye ho, aur humein array ki exact length maloom na ho, tab Negative Indexing sabse powerful tool banta hai.

  • -1 hamesha sabse aakhri element ko point karta hai.
  • -2 hamesha second-last element ko point karta hai.
  • -n array ke pehle element tak backward count karta hai.
Example 1 — Last Temperature Reading Python 
import numpy as np

temperatures = np.array([26.5, 27.2, 29.1, 28.4, 30.0])

print("Latest temp (-1):", temperatures[-1])
print("Previous temp (-2):", temperatures[-2])
Verified Python Output
Latest temp (-1): 30.0 Previous temp (-2): 28.4
Example 2 — Latest Shopping Expenses Python 
import numpy as np

expenses = np.array([120, 250, 90, 400, 180, 320])

print("Latest entry:", expenses[-1])
print("Previous entry:", expenses[-2])
Verified Python Output
Latest entry: 320 Previous entry: 180
Figure 5.2: Traversing backward from the end using negative indices [-1] and [-2].
Beginner Trap: Kabhi bhi aakhri element ko access karne ke liye arr[len(arr)] mat likhiye! Kyunki zero-based indexing hone ki wajah se 5-length array ka aakhri index 4 hota hai, 5 nahi. arr[len(arr)] execute karne par Python IndexError: index is out of bounds throw karega. Cleanest solution: Simply use arr[-1]!

04 Section C — Understanding Slicing Syntax

Jab humein ek se zyada continuous elements ko extract karna hota hai, tab hum Slicing ka use karte hain. Slicing ka master formula hai:

array[start : stop : step]

Hinglish me in teeno parameters ka matlab samajhiye:

  • start: Selection kis index se shuru hoga (ye element shamil / included hota hai). Agar omit karein, toh default 0 hota hai.
  • stop: Selection kis index par rukega. Crucial Rule: Stop index wala element kabhi include nahi hota (EXCLUDED)! Selection stop se theek pehle (stop - 1) tak hota hai.
  • step: Har element ke beech kitne steps ka jump lena hai. Default value 1 hoti hai.
The "Length Shortcut" Mental Model:
Aapko hamesha confuse hone ki zaroorat nahi hai ki slice me kitne elements aayenge. Jab step 1 ho: Kitne elements aayenge = stop - start.
Jaise arr[1:4] me 4 - 1 = 3 elements aayenge (Indices: 1, 2, aur 3).
Figure 5.3: Visual breakdown of marks[1:4] showing why index 4 is excluded from the returned result.
Example 1 — Select a Range of Marks Python 
import numpy as np

marks = np.array([65, 72, 81, 90, 76, 88])

# Slicing from index 1 to 4 (picks index 1, 2, 3)
selected = marks[1:4]
print(selected)
Verified Python Output
[72 81 90]
Example 2 — Select Recent Sales Python 
import numpy as np

sales = np.array([1000, 1250, 900, 1600, 1800, 1400])

# Slicing from index 2 to 5 (picks indices 2, 3, 4)
mid_week_sales = sales[2:5]
print(mid_week_sales)
Verified Python Output
[ 900 1600 1800]

Notice kijiye ki sales[2:5] ne index 2 (900), index 3 (1600), aur index 4 (1800) ko pick kiya. Index 5 (1400) ko strictly chhod diya gaya.

05 Section D — Slicing with Omitted Boundaries

Python me start ya stop ko khali (omit) chhodna bahut common aur expressive shorthand hai:

  • arr[:stop] → Shuruwat se lekar index stop - 1 tak sabhi elements.
  • arr[start:] → Index start se lekar bilkul aakhri element tak sabhi.
  • arr[:] → Array ke sabhi elements ka complete view.
Example 1 — First Three Temperatures Python 
import numpy as np

temperatures = np.array([24, 26, 28, 30, 32, 31])

# Pehle 3 readings (Index 0, 1, 2)
print(temperatures[:3])
Verified Python Output
[24 26 28]
Example 2 — Remaining Expenses & Full Slice Python 
import numpy as np

expenses = np.array([50, 100, 150, 200, 250, 300])

# Index 3 se lekar aakhri element tak
print("From index 3 onwards:", expenses[3:])

# Entire array selection
print("All elements:", expenses[:])
Verified Python Output
From index 3 onwards: [200 250 300] All elements: [ 50 100 150 200 250 300]
Architectural Note: Python lists me lst[:] ek naya independent copy banata hai, lekin NumPy me arr[:] sirf ek view banata hai jo original array ki memory share karta hai! Is difference ko aage Section K me hum detail me samjhenge.

06 Section E — Slicing with Step

Step parameter ye define karta hai ki agle element par pahunchne ke liye kitne positions ka jump lagana hai. Jab step 2 ho, toh ye alternate elements pick karta hai; jab 3 ho, toh har teesra element pick karta hai.

Figure 5.4: Slicing with step = 2 (readings[::2]) skipping intervening indices.
Example 1 — Every Second Sensor Reading Python 
import numpy as np

readings = np.array([10, 20, 30, 40, 50, 60, 70, 80])

# Every 2nd element (Indices 0, 2, 4, 6)
print(readings[::2])
Verified Python Output
[10 30 50 70]
Example 2 — Every Third Sales Entry Python 
import numpy as np

sales = np.array([100, 200, 300, 400, 500, 600, 700, 800, 900])

# Step 3 (Indices 0, 3, 6)
print(sales[::3])
Verified Python Output
[100 400 700]

Jab humein high-frequency sensor streams (jaise 1,000 samples per second) ko downsample karna ho, toh slicing with step bina kisi for-loop ke instantaneous execution deta hai!

07 Section F — Reverse an Array

Agar hum step ko negative -1 kar dein, toh NumPy array ko reverse direction (end se start ki taraf) traverse karne lagta hai. Shorthand: array[::-1].

Figure 5.5: Visual representation of array traversal using negative step [::-1].
Example 1 — Reverse Student Marks Python 
import numpy as np

marks = np.array([55, 68, 74, 89, 95])

reversed_marks = marks[::-1]
print("Original:", marks)
print("Reversed:", reversed_marks)
Verified Python Output
Original: [55 68 74 89 95] Reversed: [95 89 74 68 55]
Example 2 — Reverse a Week of Temperatures Python 
import numpy as np

temperatures = np.array([25, 27, 26, 30, 31, 29, 28])

chronological_rev = temperatures[::-1]
print("Reversed order:", chronological_rev)
Verified Python Output
Reversed order: [28 29 31 30 26 27 25]
Important Clarification: array[::-1] sirf order ko ulta karta hai, ye numbers ko sort (descending order) nahi karta! Agar original array [10, 50, 20] ho, toh [::-1] se [20, 50, 10] milega, [50, 20, 10] nahi.

08 Section G — Indexing in 2D Arrays

Real-world tabular data (jaise spreadsheets, database tables, aur images) 2-dimensional form me hota hai. NumPy me 2D array me elements ko access karne ka golden rule hai:

array[row_index, column_index]

Consider kijiye 4 students ke 3 subjects (Maths, Science, Computer) ka marks table:

Student (Row Index) Maths [Col 0] Science [Col 1] Computer [Col 2]
Student 0 [Row 0] 78 85 (marks[0, 1]) 90
Student 1 [Row 1] 88 76 82
Student 2 [Row 2] 92 89 95 (marks[2, 2])
Student 3 [Row 3] 67 72 80
Figure 5.6: 2D array row and column mapping with highlighted cells marks[0, 1] and marks[2, 2].
Example 1 — Access Individual Marks Python 
import numpy as np

marks = np.array([
    [78, 85, 90],  # Row 0: Student 0
    [88, 76, 82],  # Row 1: Student 1
    [92, 89, 95],  # Row 2: Student 2
    [67, 72, 80]   # Row 3: Student 3
])

# Row 0, Column 1 (Student 0 ka Science score)
print("marks[0, 1]:", marks[0, 1])

# Row 2, Column 2 (Student 2 ka Computer score)
print("marks[2, 2]:", marks[2, 2])
Verified Python Output
marks[0, 1]: 85 marks[2, 2]: 95
Example 2 — Access Entire Row and Entire Column Python 
import numpy as np

# Student 1 ki complete row extract karte hain
student_1_all = marks[1]
print("Student 1 all marks (Row 1):", student_1_all)

# Sabhi students ke Maths marks (Column 0 across all rows)
maths_column = marks[:, 0]
print("All Maths marks (Col 0):", maths_column)
Verified Python Output
Student 1 all marks (Row 1): [88 76 82] All Maths marks (Col 0): [78 88 92 67]

Note on Colon :: Jab hum row ki jagah : likhte hain (marks[:, 0]), iska matlab hota hai "har ek row me jao, aur sirf column 0 ka value uthao"!

09 Section H — 2D Array Slicing

2D arrays me slicing ka matlab hota hai ek rectangular block (sub-matrix) extract karna. Syntax:

array[row_start : row_stop , col_start : col_stop]

Pehle comma ke left side wala row slice execute hota hai, fir right side wala column slice apply hota hai.

Figure 5.7: Extracting a 2x2 rectangular block using marks[0:2, 1:3].
Example 1 — Select Specific Students and Subjects Python 
import numpy as np

marks = np.array([
    [78, 85, 90],
    [88, 76, 82],
    [92, 89, 95],
    [67, 72, 80]
])

# Rows 0 & 1, Columns 1 & 2 (Science & Computer for first two students)
sub_marks = marks[0:2, 1:3]
print("Sub-matrix (shape 2x2):")
print(sub_marks)
Verified Python Output
Sub-matrix (shape 2x2): [[85 90] [76 82]]
Figure 5.8: Comparative visualization of extracting Science & Computer columns via marks[:, 1:3].
Example 2 — Select a Block of Daily Sales Python 
import numpy as np

# 3 branch stores across 4 quarters
sales = np.array([
    [120, 150, 180, 200],  # Branch 0
    [100, 130, 170, 190],  # Branch 1
    [140, 160, 210, 230]   # Branch 2
])

# Branches 1 & 2 (Rows 1:3), Quarters 0 & 1 (Cols 0:2)
selected_sales = sales[1:3, 0:2]
print("Selected Branch & Quarter Sales:")
print(selected_sales)
Verified Python Output
Selected Branch & Quarter Sales: [[100 130] [140 160]]
Figure 5.9: Isolating mid-week sales window [2:5] for granular trend analysis.

10 Section I — Combining Indexing, Slicing, and Steps

NumPy aapko freedom deta hai ki aap rows aur columns par independently alag-alag slicing aur step rules combine kar sakein.

print(checkerboard)

11 Section J — Basic Slicing versus Advanced Indexing

Beginner students aksar confuse hote hain ki slicing aur indexing ke kitne styles hain:

  • 1. Basic Slicing (Colons :): Continuous ranges aur regular steps pick karta hai (jaise arr[1:4] ya arr[::2]). Ye memory me VIEW banata hai.
  • 2. Integer Array Indexing (Lists []): Non-continuous, specific positions ko pick karta hai (jaise arr[[0, 2, 5]]). Ye hamesha ek COPY banata hai.
  • 3. Boolean Indexing (Conditions): True/False mask ke basis par elements filter karta hai (jaise arr[arr >= 40]). Ye bhi hamesha ek COPY banata hai.
Example 1 — Select Specific Student Marks (Integer List Indexing) Python 
import numpy as np

marks = np.array([55, 72, 88, 91, 67, 95])

# Sirf student 0, student 2, aur student 5 ke marks uthao
selected = marks[[0, 2, 5]]
print("Custom picked students:", selected)
Verified Python Output
Custom picked students: [55 88 95]
Example 2 — Select Passing Marks (Boolean Filtering) Python 
import numpy as np

marks = np.array([35, 48, 76, 29, 90, 63])

# Filtering: Sirf wo marks jahan condition True hai (>= 40)
passed = marks[marks >= 40]
print("Passed marks:", passed)
Verified Python Output
Passed marks: [48 76 90 63]

12 Section K — Views versus Copies

Ye NumPy ka sabse mahatvapurna architectural concept hai jise har data scientist ko samajhna padta hai:

  • View (Shared Memory): Basic slice naya memory space create nahi karta. Ye original array ke memory buffer ko hi point karta hai. Agar aap slice ko modify karenge, toh original array bhi chupke se modify ho jayega!
  • Copy (Independent Memory): .copy() method RAM me ek bilkul independent buffer allocate karta hai. Isme changes karne se original array bilkul safe aur untouched rehta hai.
Figure 5.10: View sharing the same underlying RAM buffer vs independent memory created by .copy().
Example 1 — Danger of Modifying a Slice (View Mutation) Python 
import numpy as np

original = np.array([10, 20, 30, 40, 50])
section = original[1:4]  # Returns a VIEW!

# Modifying the view
section[0] = 999

print("Original:", original)
print("Section: ", section)
Verified Python Output
Original: [ 10 999 30 40 50] Section: [999 30 40]

Notice kijiye ki section[0] ko 999 karte hi original array ka index 1 bhi 999 ban gaya! Kyunki dono ek hi memory block ko share kar rahe the.

Example 2 — Safe Modification Using an Independent Copy Python 
import numpy as np

original = np.array([10, 20, 30, 40, 50])
section = original[1:4].copy()  # Independent COPY

# Modifying the copy
section[0] = 999

print("Original:        ", original)
print("Independent copy:", section)
Verified Python Output
Original: [10 20 30 40 50] Independent copy: [999 30 40]

.copy() lagane par original array ka 20 bilkul safe raha. Jab bhi aap kisi sub-array par destructive experimental cleaning kar rahe hon, hamesha .copy() ka use karein.

13 Section L — Common Beginner Mistakes & Debugging

Har beginner student indexing aur slicing seekhte waqt in 10 common traps me phasta hai:

1. Using Index Outside Array Bounds

Incorrect Assumption: 5-element array me arr[5] last element dega.

Reality: Zero-based indexing hone ki wajah se 5-length array ke valid indices 0, 1, 2, 3, 4 hote hain.

arr = np.array([10, 20, 30, 40, 50])
# IndexError: index 5 is out of bounds for axis 0 with size 5
correct = arr[4]  # Ya arr[-1]
2. Confusing Index Positions with Element Values

Incorrect Assumption: arr[10] likhne se element jiska value 10 hai wo mil jayega.

Reality: arr[x] me x position hoti hai, value nahi! Agar value match karni hai toh condition use karein: arr[arr == 10].

3. Forgetting That Slicing Excludes the Stop Index

Incorrect Assumption: arr[1:4] se 4 elements aayenge (1, 2, 3, 4).

Reality: Stop index 4 excluded hota hai, isliye sirf 3 elements milte hain (indices 1, 2, 3).

4. Confusing Row Indices with Column Indices

Incorrect Assumption: 2D array me arr[col, row] likhna.

Reality: Hamesha row pehle aati hai, column baad me: arr[row, col].

5. Using Commas Incorrectly in 2D Indexing

Incorrect Assumption: Python list style arr[0][1] ko hi NumPy me likhna.

Reality: arr[0][1] slow temporary array banata hai. NumPy ka standard and fast syntax arr[0, 1] hai.

6. Assuming Negative Indexing Begins at -0

Incorrect Assumption: Backward counting -0 se shuru hoti hai.

Reality: Math me -0 == 0 hota hai, isliye arr[-0] pehla element hi return karega! Negative indexing hamesha -1 se shuru hoti hai.

7. Expecting a Slice to be an Independent Copy

Incorrect Assumption: b = a[1:4] ek fresh copy banata hai jise safely modify kiya ja sakta hai.

Reality: Slicing returns a view! b[0] = 500 original a ko bhi modify kar dega. Hamesha a[1:4].copy() karein.

8. Assuming Reverse Slicing Sorts Values

Incorrect Assumption: arr[::-1] values ko descending order me sort kar dega.

Reality: Ye sirf physical order ko ulta karta hai. Sorting ke liye np.sort(arr)[::-1] use karein.

9. Confusing arr[1] with arr[1:2]

Incorrect Assumption: arr[1] aur arr[1:2] ek hi result dete hain.

Reality: arr[1] ek single scalar number return karta hai, jabki arr[1:2] ek 1D array (shape (1,)) return karta hai!

10. Accidentally Changing Original Array Through a Function

Incorrect Assumption: Kisi function me array slice pass karke usme changes karne par bahar ka data safe rahega.

Reality: Function ke andar slice view hone ki wajah se caller ka original array corrupt ho jata hai.

16 Practice, Revision & Knowledge Challenges

Part A: Predict the Output (10 Questions)

Q1: arr = np.array([10, 20, 30, 40, 50]); print(arr[1:4])
Output: [20 30 40]
Reasoning: Slicing index 1 se shuru hota hai aur stop index 4 excluded hota hai. Toh indices 1, 2, aur 3 pick hote hain.

Output: 20
Reasoning: -1 last element (25) hota hai, aur -2 second-last element (20) hota hai.

Output: [1 2 3]
Reasoning: Start omitted hone par default 0 hota hai. Indices 0, 1, 2 return hote hain.
Q4: arr = np.array([1, 2, 3, 4, 5, 6]); print(arr[3:])
Output: [4 5 6]
Reasoning: Stop omitted hone par index 3 se lekar array ke end tak sabhi elements aate hain.
Q5: arr = np.array([10, 20, 30, 40, 50, 60]); print(arr[::2])
Output: [10 30 50]
Reasoning: Step 2 hone se index 0, 2, aur 4 pick hote hain.
Q6: arr = np.array([1, 2, 3, 4, 5]); print(arr[::-1])
Output: [5 4 3 2 1]
Reasoning: Negative step -1 pure array ko reversed order me traverse karta hai.
Q7: m = np.array([[1, 2], [3, 4], [5, 6]]); print(m[1, 0])
Output: 3
Reasoning: Row index 1 ([3, 4]) aur Column index 0 → element 3.
Q8: m = np.array([[10, 20], [30, 40]]); print(m[:, 1])
Output: [20 40]
Reasoning: Sabhi rows ka Column 1 extract karta hai.
Q9: a = np.array([10, 20, 30]); b = a[1:]; b[0] = 99; print(a)
Output: [10 99 30]
Reasoning: Basic slice a[1:] ek VIEW hota hai. b[0] ko change karne se a[1] bhi 99 ban gaya!
Q10: a = np.array([12, 18, 25, 30]); print(a[a > 20])
Output: [25 30]
Reasoning: Boolean indexing sirf un elements ko pick karta hai jahan condition True hai (25 aur 30).

Part C: Debugging Challenges (6 Questions)

Debug 1: IndexError: index 5 is out of bounds for axis 0 with size 5
Buggy Code: last = arr[len(arr)]
Reason: 5 items ke array me indices 0 to 4 hote hain. len(arr) 5 hai jo out of bounds hai.
Fix: last = arr[-1] ya arr[len(arr) - 1].
Debug 2: TypeError: list indices must be integers or slices, not tuple
Buggy Code: Standard Python nested list lst = [[1, 2], [3, 4]]; print(lst[0, 1])
Reason: Python lists comma notation [0, 1] support nahi karte. Ye sirf NumPy ndarray me chalta hai.
Fix: Pehle np.array(lst) banaiye, fir arr[0, 1] use kijiye.
Debug 3: Unexpected Mutation of Original Dataset
Buggy Code: subset = data[:3]; subset[:] = 0
Reason: subset ek view tha, isliye original data ke pehle 3 elements bhi 0 ban gaye!
Fix: subset = data[:3].copy().
Debug 4: Slice returns Empty Array arr[4:1]
Buggy Code: rev = arr[4:1] (Expected reverse slice)
Reason: Default step +1 positive hota hai. Start (4) stop (1) se bada hai, isliye forward step chal hi nahi sakta.
Fix: Step ko -1 kijiye: arr[4:1:-1].
Debug 5: Slicing Excluded Desired Last Item
Buggy Code: Student 1 se Student 4 tak chahiye the, code likha: marks[1:4]
Reason: Stop index 4 excluded hota hai, isliye Student 4 nahi aaya.
Fix: Stop index ko 5 kijiye: marks[1:5].
Debug 6: Negative Slicing Zero Trap
Buggy Code: arr[-3:-0]
Reason: -0 Python me 0 ke barabar hota hai, isliye slice arr[-3:0] ban kar empty array return karta hai.
Fix: End tak slice karne ke liye stop ko omit kar dijiye: arr[-3:].

⚡ Quick Reference: Indexing & Slicing Cheat Sheet

Syntax Pattern Example Expression Meaning / Behavior View or Copy?
arr[i] arr[0] Single element at index i (zero-based). Scalar
arr[-i] arr[-1] Element at position i from the end (-1 is last). Scalar
arr[start:stop] arr[1:4] Elements from start to stop - 1 (stop excluded). VIEW
arr[:stop] arr[:3] From beginning index 0 up to stop - 1. VIEW
arr[start:] arr[2:] From index start up to the very last element. VIEW
arr[::step] arr[::2] Selects every step-th element across entire array. VIEW
arr[::-1] arr[::-1] Reverses array order (traverses backward). VIEW
arr[r, c] arr[0, 1] Individual cell at row r and column c in 2D array. Scalar
arr[r, :] arr[1, :] Extracts entire row r as a 1D vector. VIEW
arr[:, c] arr[:, 0] Extracts entire column c across all rows. VIEW
arr[r1:r2, c1:c2] arr[0:2, 1:3] 2D rectangular block slice of rows and columns. VIEW
arr[[i, j, k]] arr[[0, 2, 4]] Integer list indexing for non-continuous positions. COPY
arr[condition] arr[arr >= 40] Boolean mask indexing filtering matching values. COPY
arr.copy() arr[1:4].copy() Creates an independent duplicate in fresh RAM. COPY
