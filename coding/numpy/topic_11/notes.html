02. What is Aggregation? (Condensing Data)

Simple Hinglish mein samjhein toh: Aggregation ka matlab hota hai multiple values ko summarize karke ek single value ya chote structured result mein convert karna.

Topics 9 aur 10 mein humne Element-wise operations seekhe the, jahan agar array mein 5 elements hain toh output mein bhi 5 elements aate hain (jaise arr * 2). Lekin Aggregation mein array ke multiple elements collate hokar ek scalar value ya reduced dimension banate hain.

Feature Element-Wise Operations (Topic 9 & 10) Aggregation Operations (Topic 11)
Input Array Size Array of shape (N,) Array of shape (N,) ya (M, N)
Output Size Same shape (N,) Single scalar value ya smaller shape (e.g. () ya (M,))
Core Goal Har individual element ko transform karna Saare elements ka statistical summary nikalna
Classic Examples arr + 10, np.sqrt(arr), np.sin(arr) np.sum(arr), np.mean(arr), np.std(arr)

03. Basic Summary Functions: Finding Extrema, Sums, & Positions

NumPy hume fast C-level aggregation functions provide karta hai jo standard Python built-in functions (jaise sum(), min(), max()) ke muqable 50x se 100x fast execute hote hain.

  • np.sum(a): Array ke saare elements ka grand addition.
  • np.prod(a): Array ke saare elements ka multiplication (product).
  • np.min(a): Array ki minimum value.
  • np.max(a): Array ki maximum value.
  • np.argmin(a): Minimum value kis index position par baithi hai.
  • np.argmax(a): Maximum value kis index position par baithi hai.
  • np.count_nonzero(a): Array mein kitne elements non-zero (ya True) hain.
Figure 11.2: np.min aur np.max value return karte hain, jabki np.argmin aur np.argmax unka zero-based index batate hain.

Terminal Output

Critical Concepts to Understand

  1. Value vs Index: np.max(stock) return karta hai 25 (asli quantity), jabki np.argmax(stock) return karta hai 2 (item number index).
  2. Zero-Based Indexing: NumPy indexing 0 se start hoti hai. Isliye 1st item index 0 par hai aur 2nd item index 1 par.
  3. Tie-Breaking Rule (Multiple Min/Max elements): Agar array mein do ya do se zyada elements same maximum share karte hain (jaise [10, 50, 30, 50, 20]), toh np.argmax() humesha first occurrence ka index (index 1) return karta hai.
  4. Zero vs Missing: Inventory mein 0 ek legitimate valid number hai jiska matlab hai "Out of Stock". Lekin data collection error ya missing value ko 0 nahi manna chahiye, uske liye np.nan use hota hai (Section 10).
Common Mistake
Kabhi bhi np.argmax(arr) ko highest value samajhkar calculations mein multiply ya divide mat karna! Ye sirf ek address / index hai. Highest value lene ke liye np.max(arr) ya arr[np.argmax(arr)] use karein.

04. Measures of Central Tendency — Mean, Median, and Mode

Jab hamare paas hazaron numbers hote hain, toh sabse pehla sawaal hota hai: "In saare numbers ka typical center point kahan hai?" Isi ko statistics mein Central Tendency kehte hain.

  • Mean (Arithmetic Average): Saare values ka sum divided by total number of values: $\mu = \frac{\sum x_i}{N}$. Ye distribution ka physical balance point hota hai.
  • Median (Middle Value): Data ko ascending order mein sort karne ke baad exact beech ka number. Agar values even number mein hain, toh middle do numbers ka average.
  • Mode (Most Frequent): Jo value data mein sabse zyada baar repeat hui ho.
Figure 11.3: Symmetric distribution mein Mean aur Median same hote hain, lekin skewed data mein Mean extreme side khinch jata hai.

Example 1: Balanced Student Marks

print("Mean:", np.mean(marks))
print("Median:", np.median(marks))
Terminal Output
Mean: 80.0 Median: 80.0

Mode NumPy mein kaise calculate karein?

NumPy ke standard namespace mein koi direct np.mode() function nahi hota. Iska pure NumPy tarika hai np.unique() ko return_counts=True ke saath use karna:

find_mode_numpy.pyPython
import numpy as np

# Customer product ratings (1 to 5 stars)
ratings = np.array([4, 5, 3, 4, 4, 5, 2, 4, 5])

values, counts = np.unique(ratings, return_counts=True)
mode_val = values[np.argmax(counts)]
max_freq = np.max(counts)

print("Unique values:", values)
print("Frequencies:", counts)
print(f"Mode: {mode_val} (appeared {max_freq} times)")
Terminal Output
Unique values: [2 3 4 5] Frequencies: [1 1 4 3] Mode: 4 (appeared 4 times)
Real-Life Connection: Mean vs Median in Society
Government reports aur Real Estate property prices mein humesha Median Income aur Median House Price bataya jata hai, kabhi Mean nahi. Kyunki agar shehar mein 2-3 arabpati (billionaires) rehte hain, toh unki income poore shehar ka Mean artificially high kar degi!

05. Measures of Spread — Variance & Standard Deviation

Socho do cricket players hain. Dono ka batting average 50 runs hai. Lekin Player A har match mein lagbhag [48, 52, 49, 51, 50] banata hai, jabki Player B [0, 110, 10, 95, 35] banata hai.

Dono ka Mean same hai (50.0), lekin dono ka consistency / risk factor zameen-aasmaan ka farq hai! Yahan par kaam aate hain Variance aur Standard Deviation.

Mathematical Formulation

Population Variance ($\sigma^2$): Har observation ka mean se faasla (deviation), uska square, aur unka average:

σ² = ∑(xᵢ - μ)² / N

Population Standard Deviation ($\sigma$): Variance ka square root:

σ = √(σ²)

Square root lene se unit wapas original data ki unit ban jaati hai (jaise agar marks ka variance 450 marks² tha, toh standard deviation 21.21 marks ban gaya).

Figure 11.5: Class A aur Class B dono ka mean 80.0 hai, lekin Class B ka spread (Std = 21.21) Class A (Std = 1.41) se bohot zyada hai.

Population Statistics vs Sample Statistics (ddof=0 vs ddof=1)

NumPy mein np.var() aur np.std() by default ddof=0 (Delta Degrees of Freedom = 0) use karte hain, jo ki Population Statistics (N se divide) hai.

Lekin jab tum kisi badi population ka ek chota sample inspect kar rahe ho, toh sample mean sample ke variance ko underestimate karta hai. Is bias ko theek karne ke liye hum Bessel's Correction use karte hain jisme denominator N - 1 hota hai (ddof=1):

variance_ddof_demo.pyPython
import numpy as np

class_a = np.array([78, 79, 80, 81, 82])
class_b = np.array([50, 65, 80, 95, 110])

print("--- Class A (Consistent) ---")
print("Mean:", np.mean(class_a))
print("Population Variance (ddof=0):", np.var(class_a))
print("Population Std (ddof=0):", np.std(class_a))
print("Sample Std (ddof=1):", np.std(class_a, ddof=1))

print("\n--- Class B (Dispersed) ---")
print("Mean:", np.mean(class_b))
print("Population Variance (ddof=0):", np.var(class_b))
print("Population Std (ddof=0):", np.std(class_b))
print("Sample Std (ddof=1):", np.std(class_b, ddof=1))
Terminal Output
--- Class A (Consistent) --- Mean: 80.0 Population Variance (ddof=0): 2.0 Population Std (ddof=0): 1.4142135623730951 Sample Std (ddof=1): 1.5811388300841898 --- Class B (Dispersed) --- Mean: 80.0 Population Variance (ddof=0): 450.0 Population Std (ddof=0): 21.213203435596427 Sample Std (ddof=1): 23.717082451262844
Important Scientific Distinction: Spread vs Accuracy
Kabhi bhi kisi sensor ko "zyada accurate" mat kehna sirf isliye ki uska standard deviation kam hai! Standard deviation sirf consistency / precision (values ka aapas mein kitna paas rehna) measure karta hai. Calibration ya true target ke paas hona (accuracy / trueness) ek alag concept hai.

06. Percentiles & Quantiles — Dividing Data into Slices

Agar tum competitive exams (jaise JEE, CAT, ya GATE) ke results dekho, toh wahan percentage se zyada percentile matter karti hai.

  • Percentile ($p \in [0, 100]$): Wo threshold value jisse neeche $p\%$ observations lie karti hain.
  • 25th Percentile ($Q_1$ - First Quartile): 25% data isse chota hai.
  • 50th Percentile ($Q_2$ - Median): 50% data isse chota hai, 50% bada hai.
  • 75th Percentile ($Q_3$ - Third Quartile): 75% data isse chota hai.
  • Quantile ($q \in [0.0, 1.0]$): Same concept, bas scale 0 se 1 ke beech hoti hai (e.g. 0.25 quantile = 25th percentile).
Figure 11.6: Boxplot mein Q1, Median (Q2), Q3, aur Interquartile Range (IQR) ka spatial layout.

Example 1: Student Marks Percentiles

percentile_calc.pyPython
import numpy as np

marks = np.array([35, 45, 55, 65, 75, 85, 95])

print("25th percentile (Q1):", np.percentile(marks, 25))
print("50th percentile (Median):", np.percentile(marks, 50))
print("75th percentile (Q3):", np.percentile(marks, 75))
Terminal Output
25th percentile (Q1): 50.0 50th percentile (Median): 65.0 75th percentile (Q3): 80.0

Example 2: Sales Quantiles

quantile_calc.pyPython
import numpy as np

sales = np.array([100, 120, 130, 150, 180, 220, 250])

print("25% quantile:", np.quantile(sales, 0.25))
print("50% quantile:", np.quantile(sales, 0.50))

Crucial Concept: Percentiles are Interpolated Numbers!
Notice karo marks array mein 50.0 ya 80.0 kahi bhi present nahi tha! NumPy by default method='linear' interpolation use karta hai pass-pass ke elements ke beech estimate nikalne ke liye. Isliye kabhi ye assume mat karna ki percentile value hamesha original dataset ka hi koi number hogi.

07. Cumulative Operations — Tracking Running Totals

Standard aggregation functions (jaise np.sum) poore array ko condense karke ek single final scalar bana dete hain. Lekin business dashboards aur financial tracking mein hume aksar ye dekhna hota hai ki day-by-day progress kaise ho rahi hai.

  • np.cumsum(a): Cumulative Sum — Har point par previous saare elements ka running sum calculate karta hai. Output ki shape original array ke barabar hoti hai.
  • np.cumprod(a): Cumulative Product — Har point par running product calculate karta hai (useful for compound interest, growth multipliers, and probability chains).
Figure 11.7: Bars daily sales show karti hain, jabki amber line np.cumsum se running cumulative revenue track karti hai.

Example 1: Weekly Retail Sales Running Total

cumulative_sales.pyPython
import numpy as np

daily_sales = np.array([100, 150, 120, 180, 200])

total_rev = np.sum(daily_sales)
running_total = np.cumsum(daily_sales)

print("Total sales:", total_rev)
print("Cumulative sales:", running_total)
Terminal Output
Total sales: 750 Cumulative sales: [100 250 370 550 750]

Example 2: Investment Growth Multipliers

Ek portfolio 3 successive quarters mein grow karta hai (10% growth = 1.10x, 20% growth = 1.20x, 5% growth = 1.05x):

cumulative_growth.pyPython
import numpy as np

multipliers = np.array([1.10, 1.20, 1.05])
running_growth = np.cumprod(multipliers)

print("Quarterly Multipliers:", multipliers)
print("Compounded Growth Factor:", np.round(running_growth, 4))
Terminal Output
Quarterly Multipliers: [1.1 1.2 1.05] Compounded Growth Factor: [1.1 1.32 1.386]
Remember This
np.sum(arr) hamesha 1 number deta hai. np.cumsum(arr) hamesha original length ka array return karta hai jiska aakhiri element np.sum(arr) ke barabar hota hai!

08. Mastering 2D Array Reductions — Axis 0 vs Axis 1

NumPy beginners ke liye sabse confusing concept hota hai: "axis=0 ka matlab column hota hai ya row?"

Is confusion ko permanently khatam karne ka golden rule ye hai:

The Golden Mental Model: "Jis axis ko tum specify karte ho, NumPy us axis ke dimension ko collapse (destroy / reduce) kar deta hai!"
  • axis=0 specified → Rows collapse (up-to-down add honge) → Output mein 1 value per column bachegi.
  • axis=1 specified → Columns collapse (left-to-right add honge) → Output mein 1 value per row bachegi.
Figure 11.8: Axis 0 rows ko collapse karke column summaries deta hai; Axis 1 columns ko collapse karke row summaries deta hai.

Example 1: 3x3 Student Marks Matrix

3 students (rows) aur 3 subjects (columns: Math, Science, English):

axis_marks_demo.pyPython
import numpy as np

marks = np.array([
    [70, 80, 90],  # Student 0
    [60, 75, 85],  # Student 1
    [88, 92, 95]   # Student 2
])

# axis=0: Collapse rows (Vertical sum -> Subject totals)
sub_totals = np.sum(marks, axis=0)
sub_means = np.mean(marks, axis=0)

# axis=1: Collapse cols (Horizontal sum -> Student totals)
stu_totals = np.sum(marks, axis=1)
stu_means = np.mean(marks, axis=1)

print("Subject Totals (axis=0):", sub_totals)
print("Subject Averages (axis=0):", np.round(sub_means, 2))
print("Student Totals (axis=1):", stu_totals)
print("Student Averages (axis=1):", np.round(stu_means, 2))
Terminal Output
Subject Totals (axis=0): [218 247 270] Subject Averages (axis=0): [72.67 82.33 90. ] Student Totals (axis=1): [240 220 275] Student Averages (axis=1): [80. 73.33 91.67]

Example 2: Shop Department Sales Across 4 Days

4 days (rows: Day 1 to 4) aur 3 departments (columns: Grocery, Apparel, Electronics):

09. Dimensional Integrity with keepdims=True

By default, jab NumPy kisi axis par aggregation perform karta hai, toh wo us axis ko completely drop kar deta hai. For example, ek (2, 3) matrix ka axis=1 mean lene par output shape (2,) (1D array) ban jaati hai.

Lekin agar hume Broadcasting (Topic 8) ke through original matrix se uske row-averages subtract karne ho, toh (2, 3) aur (2,) directly subtract hone mein alignment error ya column-wise broadcast trigger kar sakte hain!

Figure 11.9: keepdims=True reduced dimension ko size 1 ke roop mein barkarar rakhta hai, jisse broadcasting bina reshape ke directly kaam karti hai.

Example 1: Row-Wise Mean Centering (Deviation from Mean)

keepdims_centering.pyPython
import numpy as np

data = np.array([
    [10, 20, 30],
    [40, 50, 60]
])  # shape (2, 3)

# Without keepdims: shape becomes (2,)
mean_default = np.mean(data, axis=1)

# With keepdims=True: shape remains (2, 1)
mean_kd = np.mean(data, axis=1, keepdims=True)

print("Default Mean Shape:", mean_default.shape)
print("keepdims Mean Shape:", mean_kd.shape)
print("keepdims Mean values:\n", mean_kd)

# Direct broadcasting subtraction: (2, 3) - (2, 1) -> (2, 3)
deviations = data - mean_kd
print("\nDeviations from row mean:\n", deviations)
Terminal Output
Default Mean Shape: (2,) keepdims Mean Shape: (2, 1) keepdims Mean values: [[20.] [50.]] Deviations from row mean: [[-10. 0. 10.] [-10. 0. 10.]]

Example 2: Feature Standardization Across Columns

feature_standardization.pyPython
import numpy as np

scores = np.array([
    [70, 85],
    [80, 90],
    [90, 95]
])  # 3 students x 2 tests

col_means = np.mean(scores, axis=0, keepdims=True)  # shape (1, 2)
centered_scores = scores - col_means

print("Original Scores:\n", scores)
print("Column Means (1, 2):\n", col_means)
print("Centered Scores:\n", centered_scores)
Terminal Output
Original Scores: [[70 85] [80 90] [90 95]] Column Means (1, 2): [[80. 90.]] Centered Scores: [[-10. -5.] [ 0. 0.] [ 10. 5.]]

10. Handling Missing Data & NaN-Aware Statistics

Real-world data collection mein sensors disconnect ho sakte hain, survey form mein user blank chhod sakta hai, ya network packet drop ho sakta hai. In missing ya unrecorded values ko NumPy np.nan (Not a Number, IEEE 754 float representation) se denote karta hai.

Figure 11.10: Legitimate zero (0.0) ek valid reading hai jo mean ko kam karti hai; np.nan ek missing reading hai jise safely ignore kiya jaana chahiye.

NaN Contamination Problem

Agar tum regular np.mean() ya np.sum() kisi aise array par call karoge jisme ek bhi np.nan hai, toh standard floating-point rules ke tehat poora output nan ban jayega!

Is problem ko solve karne ke liye NumPy ke paas dedicated NaN-Aware statistical functions hain jo NaNs ko automatically filter karke baaki valid numbers par calculations karte hain:

Regular Function (Fails on NaN) NaN-Aware Function (Safe) Behavior
np.sum(a) np.nansum(a) NaNs ko skip karke valid numbers add karta hai
np.mean(a) np.nanmean(a) Sirf non-NaN count se divide karke average nikalta hai
np.median(a) np.nanmedian(a) NaNs ko discard karke true middle value nikalta hai
np.std(a) np.nanstd(a) Valid values ka standard deviation nikalta hai
np.min(a) / np.max(a) np.nanmin(a) / np.nanmax(a) Minimum aur Maximum valid number find karta hai

Example 1: Weather Station Temperature Sensor Reading

nan_temperature_demo.pyPython
import numpy as np

# Wednesday ko sensor disconnect ho gaya (np.nan)
temps = np.array([28.0, 30.0, np.nan, 32.0])

print("Missing Mask (np.isnan):", np.isnan(temps))
print("Regular mean (Contaminated):", np.mean(temps))
print("NaN-aware mean (np.nanmean):", np.nanmean(temps))
print("NaN-aware sum (np.nansum):", np.nansum(temps))
print("NaN-aware min (np.nanmin):", np.nanmin(temps))
print("NaN-aware max (np.nanmax):", np.nanmax(temps))
Terminal Output
Missing Mask (np.isnan): [False False True False] Regular mean (Contaminated): nan NaN-aware mean (np.nanmean): 30.0 NaN-aware sum (np.nansum): 90.0 NaN-aware min (np.nanmin): 28.0 NaN-aware max (np.nanmax): 32.0

Edge Case: What Happens When the ENTIRE Array is NaN?

Ye ek bohot subtle interview question aur production bug source hai:

all_nan_edgecase.pyPython
import numpy as np

all_missing = np.array([np.nan, np.nan])

# nansum of empty slice returns 0.0
print("nansum on all-NaN:", np.nansum(all_missing))

# nanmean on all-NaN emits RuntimeWarning and returns nan
print("nanmean on all-NaN:", np.nanmean(all_missing))
Terminal Output
nansum on all-NaN: 0.0 RuntimeWarning: Mean of empty slice nanmean on all-NaN: nan
Critical Data Science Warning
np.nansum([nan, nan]) ka 0.0 return karne ka matlab ye bilkul nahi hai ki dukan par 0 rupees ki sale hui thi! Iska matlab hai ki calculate karne ke liye koi valid data points hi available nahi the. Production code mein hamesha pehle check karein: np.isnan(arr).all().

11. Outliers & Robust Summaries (The IQR Method)

Outlier ek aisi observation hoti hai jo dataset ke baaki typical pattern se abnormally door ya alag hoti hai.

  • Mean aur Standard Deviation Non-Robust hote hain: Ek akela extreme number in dono ko drastically distort kar deta hai.
  • Median aur IQR Robust hote hain: Ye extreme boundary values se affect nahi hote aur true majority structure ko preserve karte hain.
Figure 11.11: Q1 aur Q3 ke beech 50% data rehta hai. 1.5×IQR se bahar girne wale points potential outliers flag hote hain.

Mathematical Formulation of IQR Fences

  1. Calculate Quartiles: $Q_1$ (25th percentile) aur $Q_3$ (75th percentile).
  2. Interquartile Range: $IQR = Q_3 - Q_1$.
  3. Lower Fence: $Q_1 - 1.5 \times IQR$.
  4. Upper Fence: $Q_3 + 1.5 \times IQR$.

Jo points lower fence se chote ya upper fence se bade hote hain, unhe potential outliers ke roop mein inspect kiya jata hai.

Example: Employee Salary Outlier Flagging

iqr_outlier_detection.pyPython
import numpy as np

salaries = np.array([25000, 28000, 30000, 32000, 35000, 
                     36000, 38000, 40000, 42000, 185000])

13. Common Mistakes & Debugging Guide

NumPy aggregation aur statistics mein beginners aksar in 4 deadly traps mein phaste hain. Inhe dhyan se samjho:

❌ Mistake 1: Treating np.argmax() as the Maximum Value

Wrong Code:

import numpy as np
scores = np.array([45, 92, 18, 77])
bonus = np.argmax(scores) * 0.10  # BUG: Multiplies index 1 instead of 92!

What Happens: argmax returns index 1. Bonus calculate hota hai 0.10 jabki expected tha 9.2!

✔ Corrected Code:
# Option A: Direct max value
max_score = np.max(scores)
bonus = max_score * 0.10  # Correct: 9.2

# Option B: Indexing via argmax
idx = np.argmax(scores)
bonus = scores[idx] * 0.10  # Correct: 9.2
❌ Mistake 2: Mixing up Axis 0 and Axis 1 in 2D Reductions

Wrong Code:

# Trying to get each student's total marks (across columns)
stu_totals = np.sum(marks_matrix, axis=0)  # WRONG! Gives subject totals instead!

Why it happens: Developer sochta hai "Students rows mein hain toh axis 0 hona chahiye". Lekin rule hai: jis axis par operate karoge wo collapse hogi! Agar students bachaane hain toh columns ko collapse karna hoga (axis=1).

✔ Corrected Code:
stu_totals = np.sum(marks_matrix, axis=1)  # Correct: 1 total per student row
❌ Mistake 3: Forgetting ddof=1 for Sample Statistics

Wrong Code:

# Survey sample of 10 people from a city of 1,000,000
sample_std = np.std(survey_data)  # Biased: Uses N instead of N-1

Why it happens: NumPy ka default ddof=0 hota hai jo poori population ke liye valid hai. Chote samples mein standard deviation artificially under-reported ho jata hai.

✔ Corrected Code:
sample_std = np.std(survey_data, ddof=1)  # Unbiased sample standard deviation
❌ Mistake 4: Running Standard Aggregation on Data Containing NaNs

Wrong Code:

sensor_readings = np.array([10.0, np.nan, 30.0])
avg = np.mean(sensor_readings)  # Returns nan! Entire pipeline fails downstream
✔ Corrected Code:
avg = np.nanmean(sensor_readings)  # Correct: 20.0 (Ignores NaN safely)
