1 Section 1: Introduction to Dart

Dart is a modern, open-source, object-oriented programming language created by Google. It is designed specifically for building fast, beautiful applications across mobile devices (iOS & Android), the web, desktop computers (Windows, macOS, Linux), and backend servers.

Who Created It?

Developed by Google engineers Lars Bak and Kasper Lund. First unveiled at the GOTO conference in 2011 and continuously maintained as open-source software.

Why Was It Created?

Created to solve front-end performance bottlenecks — giving developers rapid iteration speed while compiling directly into high-speed native machine code.

What Problems Does Dart Solve?

  • Multi-Platform Code Duplication: Before Dart and Flutter, companies had to write two separate apps (one in Swift/Objective-C for iOS, another in Java/Kotlin for Android). Dart enables one single codebase for all platforms.
  • Slow Developer Iteration: Dart provides Stateful Hot Reload — modify your code and see UI changes on your screen in under 1 second without restarting the app or losing current state.
  • Null Pointer Crashes: Dart features Sound Null Safety built directly into its type system, catching null dereference bugs at compile time before your users ever run into a crash.

2 Section 2: Understanding Dart: JIT & AOT Compilation

To understand why Dart is so fast, we need to understand how programming languages translate human-written code into machine instructions:

Interpreted Languages (e.g. Python)

An interpreter translates code line-by-line in real-time while running. Flexible, but can be slower at execution.

Compiled Languages (e.g. C++)

A compiler translates the entire program beforehand into binary machine code. Ultra-fast, but requires a full rebuild for every change.

Dart's Superpower: Dual-Mode Compilation (JIT + AOT)

Dart combines the best of both worlds with a revolutionary two-tier compilation strategy:

  • JIT (Just-In-Time) Mode during Development: When writing code on your computer, Dart uses the Dart VM to compile on the fly. This enables Hot Reload, letting you tweak UI layouts, fix bugs, and see updates instantly without restarting the app!
  • AOT (Ahead-Of-Time) Mode for Production Release: When building your final app for the App Store or Google Play, Dart compiles directly into native ARM or x64 machine code (or optimized JavaScript/WebAssembly for Web). This delivers blazing-fast app startup and fluid 60 to 120 frames-per-second animations!

3 Section 3: Dart Development Environment

Before writing code, developers prepare an organized work environment. This consists of the Dart SDK and an IDE (Editor).

Dart SDK vs Flutter SDK

Standalone Dart SDK

Contains the Dart compiler, Dart VM, core libraries, package manager (pub), and developer tools (dart analyze, dart format). Best for pure Dart command-line scripts or backend microservices.

Flutter SDK (All-In-One)

Includes the complete Dart SDK bundled inside it, plus Flutter's rich UI widget library, graphics engine, mobile emulators, and device deployment tools. If you install Flutter, you do not need to install Dart separately!

Choosing an IDE (Code Editor)

An IDE (Integrated Development Environment) is a specialized software application that combines a text editor, code auto-completion, syntax highlighting, and a built-in terminal.

  • Visual Studio Code (VS Code): Highly recommended for beginners! Lightweight, ultra-fast, and free. Simply install the official Dart and Flutter extensions from the VS Code Marketplace.
  • Android Studio: Full-featured IDE by Google with visual Android emulators, layout inspectors, and deep memory profilers.

4 Section 4: Installing Dart & PATH Configuration

Let's walk through the complete step-by-step setup on Windows (with tips for macOS and Linux):

Diagram 4.1: Step-by-Step Dart Installation Flowchart
Step 1 • Download the Dart SDK

Visit the official download portal: dart.dev/get-dart. Download the official Dart SDK Windows x64 zip archive (or install Flutter from flutter.dev, which automatically includes Dart).

Step 2 • Extract the SDK

Extract the downloaded ZIP file into a permanent, clean directory on your computer, such as C:\tools\dart-sdk (or C:\flutter if using Flutter).

Step 3 • Add Dart to the System PATH Variable

Windows needs to know where to find the dart command from any folder you open:

  1. Press Windows Key and search for "Environment Variables".
  2. Click "Edit the system environment variables".
  3. In the dialog, click the "Environment Variables..." button near the bottom.
  4. Under User variables (or System variables), select Path and click Edit.
  5. Click New and type the path to your Dart bin folder: C:\tools\dart-sdk\bin (or C:\flutter\bin).
  6. Click OK on all open windows to save.
Step 4 • Verify in Terminal

Open a brand new Command Prompt or PowerShell window and run:

TerminalVerification Command
DART Script
DART 
dart --version
Expected Output Dart SDK version: 3.x.x (stable) (on windows_x64)

6 Section 6: First Dart Program & Anatomy

Let's study the canonical introductory program that every software engineer writes when learning a new language:

Dart main.dart
DART Script
DART 
void main() {
  print('Hello, Dart!');
}
Expected Output Hello, Dart!

Line-by-Line Detailed Explanation

1. void

void is a return type keyword. It tells the compiler: "When this function finishes running, it does not send any data/value back."

2. main()

The entry gate of every Dart application! The Dart runtime specifically searches for a top-level function named main(). Program execution always starts here.

3. { ... } (Curly Braces)

Curly braces define the body (scope) of the function. Everything placed between { and } belongs to the main() function and executes in order.

4. print('Hello, Dart!');

print() is a built-in Dart function that displays whatever message you provide inside its parentheses onto the computer's console screen.

5. ; (Semicolon)

In Dart, the semicolon is mandatory at the end of every statement. It acts like a period at the end of an English sentence, telling the compiler that an instruction is complete.

7 Section 7: Basic Dart Syntax Fundamentals

Before moving deeper into variables in Topic 2, let's understand the core syntax rules that govern all Dart code:

1. Semicolons are Mandatory

Unlike Python or Kotlin, Dart strictly enforces semicolons ; at the end of each statement. Leaving out a semicolon triggers an immediate compile error: Error: Expected ';' after this.

2. Comments in Dart

Comments are notes written by developers for humans to read. The Dart compiler completely ignores comments when executing the program:

Dart comments_demo.dart
DART Script
DART 
// 1. Single-line comment starts with double slashes

/* 
   2. Multi-line comment (block comment)
   Spans across several lines. Useful for 
   long explanations or temporarily disabling code.
*/

/// 3. Documentation comment (three slashes)
/// Used by dartdoc to generate official HTML API documentation.

void main() {
  // Print welcoming message
  print('Comments make code readable!');
}
Expected Output Comments make code readable!

3. Case Sensitivity in Dart

Dart is case-sensitive. Uppercase and lowercase letters are treated as completely different symbols:

  • main is valid; Main or MAIN will NOT be recognized as the entry point!
  • print() is the valid function; Print() will cause an error: Method not found: 'Print'.

4. Basic Naming Conventions

  • camelCase: Used for variable and function names — e.g. userAge, calculateScore().
  • PascalCase: Used for class names and types — e.g. UserProfile, BankAccount.

Common Beginner Errors & How to Fix Them

Error Message Mistake Made Solution
Error: Expected ';' after this. Forgot the semicolon at the end of a line. Add ; to the end of the statement.

⚡ Section 9: Quick Revision: Key Takeaways

  1. Dart is a client-optimized, object-oriented programming language created by Google.
  2. Dart powers Flutter: Dart provides the logic and engine, while Flutter provides the visual UI widgets.
  3. Sound Null Safety guarantees that variables cannot be null unless explicitly marked with ?.
  4. Dual-Mode Compilation: JIT provides instant Hot Reload during development; AOT compiles to native ARM/x64 machine code for production.

  9. Curly braces { } enclose the function body (scope).
  10. print() displays text messages on the computer's console output.
  11. Semicolons (;) are mandatory at the end of every statement in Dart.
