Variables, Constants & Type Inference

Understand how Dart stores and manages data in memory using variables, explicit types, type inference, dynamic containers, and immutable constants.

1. Introduction to Variables

In programming, a variable is a named container in the computer's memory used to hold information that your program needs to read, manipulate, or display.

Real-Life Analogy: Think of a variable as a labeled storage box in your closet. The label on the outside is the variable name (e.g., studentName), while whatever item you place inside the box is the stored value (e.g., "Shailendra"). Whenever you want that item later, you simply look for the box with that label.

Visual 1: Variable as a Labeled Storage Box

First Variable Example

first_variable.dart Dart
DART Script
DART 
void main() {
  var name = 'Shailendra';
  print(name);
}
▶ Output Console
Shailendra

Line-by-line explanation:

  • var name = 'Shailendra'; : Dart creates a new variable named name and assigns it the initial string text 'Shailendra'.
  • print(name); : Passes the variable name to print(). Dart retrieves the stored value from memory and prints Shailendra. Notice that we do not put quotation marks around variable names!

2. Declaring Variables in Dart

Dart provides two primary ways to declare variables: using the keyword var (letting Dart infer the type) or explicitly naming the data type.

Explicit Type Declarations

When you want to be completely explicit about the kind of data a variable holds, you write the data type directly before the variable name:

explicit_types.dart Explicit Data Types
DART Script
DART 
void main() {
  String name = 'Rahul';      // Text data
  int age = 20;               // Whole integer number
  double height = 5.8;        // Decimal point number
  bool isStudent = true;      // Boolean true/false

  print(name);
  print(age);
  print(height);
  print(isStudent);
}
▶ Output Console
Rahul
20
5.8
true

Declaration vs. Initialization

  • Declaration: Introducing the variable's name and type to Dart without storing an initial value yet (e.g., int score;).
  • Initialization: Assigning a value to a variable for the very first time (e.g., score = 95;).
  • Combined: Most commonly, both happen in one statement (e.g., int score = 95;).
separate_init.dart Declare then Assign
DART Script
DART 
void main() {
  int points;       // Declaration
  points = 50;      // Initialization
  points = 85;      // Reassignment (value updated)
  print(points);    // Prints 85
}

3. Understanding var

The var keyword instructs Dart to automatically determine (infer) the variable's data type based on the value assigned to it at initialization.

ⓘ Important Rule About var
var does NOT mean "any type at any time." Once Dart infers the type from the initial value, that type is locked permanently! The value can change, but the data type cannot.

Valid: Updating the Value

var_reassign.dart Valid Reassignment
DART Script
DART 
void main() {
  var city = 'Lucknow';  // Dart infers type String
  city = 'Delhi';        // Valid: 'Delhi' is also a String
  print(city);           // Prints Delhi
}

Invalid: Attempting to Change Data Type

invalid_var_type.dart Compile Error
DART Script
DART 
void main() {
  var city = 'Lucknow';  // Locked as String
  city = 42;             // COMPILE ERROR: Cannot assign int to String!
}
✘ Exact Compiler Error
Error: A value of type 'int' can't be assigned to a variable of type 'String'.
Because city was initialized with a String, Dart permanently registered its type as String. It will never accept an integer or boolean later.

4. Understanding dynamic

If you explicitly want a variable that can hold any data type and change its type freely at runtime, Dart provides the keyword dynamic.

dynamic_demo.dart Dynamic Type Changing
DART Script
DART 
void main() {
  dynamic value = 'Hello';  // Holds a String
  print(value);

  value = 100;              // Now holds an int! (Valid for dynamic)
  print(value);

  value = true;             // Now holds a bool! (Valid for dynamic)
  print(value);
}
▶ Output Console
Hello
100
true
Visual 3: var (Locked Type) vs dynamic (Flexible Container)
Feature var dynamic
Type Safety Strictly type-safe (enforced at compile time). Disabled (type checks happen at runtime).
Can Value Change? Yes (as long as it matches the inferred type). Yes.
Can Type Change? No. Locked to initial value's type. Yes. Can change to any type freely.
When to Use? Default for local variables when type is obvious. Only for unpredictable data (e.g., complex JSON parsing).
⚠ Why Beginners Should Avoid dynamic
dynamic disables Dart's static compiler checks. If you accidentally write a typo or call a function that doesn't exist, the compiler won't warn you—your Flutter app will crash at runtime! Always prefer var or explicit types.

5. Understanding final

When you want a variable whose value must never change after it is assigned, use the keyword final.

  • Single Assignment: A final variable can be set once and only once.
  • Runtime Values Allowed: Its value does not need to be known at compile time—it can be computed when the program is actively running (e.g., user input, sensor readings, or the current time).
final_example.dart Immutable Final Variable
DART Script
DART 
void main() {
  final name = 'Shailendra';
  print(name);

  // Attempting to reassign causes a compile error:
  // name = 'Pathak'; // Error: The final variable 'name' can only be set once.
}
✘ Exact Compiler Error on Reassignment
Error: The final variable 'name' can only be set once. Try making 'name' non-final.

6. Understanding const

The const keyword represents a compile-time constant. This means the value must be fixed, hardcoded, and completely calculable before the program ever runs.

const_example.dart Compile-Time Constants
DART Script
DART 
void main() {
  const pi = 3.14159;
  const maxRetries = 3;

  print(pi);
  print(maxRetries);
}
▶ Output Console
3.14159
3

Because const values are frozen at compilation, Dart stores them once in a special canonical memory location. In Flutter, using const constructors for widgets drastically improves frame rates and saves memory.

7. final vs const: The Critical Difference

Both final and const prevent reassignment. The crucial difference lies in when the value is determined:

Visual 4: Runtime Evaluation (final) vs Compile-Time Known (const)
final_vs_const.dart Runtime vs Compile-Time
DART Script
DART 
void main() {
  // DateTime.now() checks the system clock at the exact second the program runs
  final currentTime = DateTime.now(); // VALID: runtime determination
  const pi = 3.14;                     // VALID: known beforehand

  print(currentTime);
  print(pi);

  // const invalidTime = DateTime.now();
  // COMPILE ERROR: Const variables must be initialized with a constant value!
}
Characteristic final const
Reassignable? No (assigned exactly once). No (assigned exactly once).
When value is determined At runtime OR compile time. Strictly at compile time.
Example values DateTime.now(), device screen width, API token. 3.14, 'https://api.com', 100.
Rule of Thumb "Every const is final, but not every final is const." Use const whenever the value is completely known in advance.

8. Type Inference in Dart

Type inference is Dart's ability to deduce the exact data type of a variable from the value you supply on the right side of the equals sign (=).

Visual 5: How Dart Performs Type Inference
type_inference.dart Automatic Type Deduction
DART Script
DART 
void main() {
  var name = 'Amit';    // Dart detects String
  var age = 21;         // Dart detects int
  var price = 99.50;    // Dart detects double

  print(name);
  print(age);
  print(price);
}
▶ Output Console
Amit
21
99.5

9. Variable Naming Rules & Conventions

In Dart, identifiers must follow specific syntactic rules:

Visual 6: Valid vs Invalid Variable Identifiers
  • Letters, Digits, Underscores, $: Can contain letters, numbers, underscores (_), and dollar signs ($).
  • No Leading Digits: player1 is valid; 1player is illegal.
  • Case-Sensitive: userScore and userscore are two separate variables.
  • lowerCamelCase: The official Dart style convention for variables is lowerCamelCase (e.g., userAccountBalance).

10. Common Beginner Mistakes & Fixes

✘ Mistake 1: Using a Variable Before Declaring It

Broken:

print(age); int age = 20;
Error: Undefined name 'age'. Dart reads top-to-bottom!
Fix: Declare the variable before reading it: int age = 20; print(age);
✘ Mistake 2: Reassigning a final or const Variable

Broken:

final double rate = 4.5; rate = 5.0;
Error: The final variable 'rate' can only be set once.
Fix: If a variable needs to change later, declare it with var or double instead of final.
✘ Mistake 3: Forgetting Quotes Around String Values

Broken:

var city = Lucknow;
Error: Undefined name 'Lucknow'. Dart thinks Lucknow is another variable!
Fix: Wrap text literals in quotes: var city = 'Lucknow';

12. Quick Revision Summary

  • Variables: Labeled memory locations used to hold data.
  • var: Automatically infers the type at initialization; the inferred type cannot change later.
  • Explicit Types: String (text), int (integers), double (decimals), bool (true/false).
  • dynamic: Allows the variable to hold values of any data type and switch types at runtime.
  • final: Can be set only once; value can be computed at runtime (e.g., DateTime.now()).
  • const: Compile-time constant; value must be frozen and known before execution.
  • Naming Rules: Must start with a letter or underscore, no spaces or hyphens, lowerCamelCase convention.

13. Knowledge Check & Practice Exercises

Part A: Multiple Choice Questions (MCQs)

1. What happens if you try to assign an integer to a variable declared as: var city = 'Pune'; ?
A) Dart converts the integer to a String automatically.
B) The code causes a compile-time error: A value of type 'int' can't be assigned to 'String'.
C) The variable becomes dynamic automatically.
D) The program runs but prints null.
View Correct Answer
Answer: B. var locks the variable's type to String upon initialization.
2. Which keyword allows a variable to hold different data types at different times during execution?
A) final
B) const
C) dynamic
D) var
View Correct Answer
Answer: C. dynamic bypasses compile-time type locking and permits type changing at runtime.
3. Why does: const time = DateTime.now(); result in a compile error in Dart?
A) DateTime is not supported in Dart.
B) const requires values known at compile time, but DateTime.now() is determined at runtime.
C) time is a reserved keyword in Dart.
D) const variables only accept numbers.
View Correct Answer
Answer: B. DateTime.now() queries the computer clock at runtime, so it cannot be a compile-time const (it should be final instead).
4. Which of the following is an INVALID variable name in Dart?
A) _userCount
B) $totalBill
C) 1stRank
D) score2026
View Correct Answer
Answer: C. Variable identifiers in Dart cannot begin with a number digit.
5. What is the key difference between final and const?
A) final can be reassigned 3 times, while const cannot.
B) final can be computed at runtime, while const must be known at compile time.
C) const is only for Flutter widgets, while final is for Dart.
D) There is no difference; they are 100% identical.
View Correct Answer
Answer: B. final variables can evaluate runtime expressions (like system time or HTTP responses), whereas const must be fully known during compilation.
