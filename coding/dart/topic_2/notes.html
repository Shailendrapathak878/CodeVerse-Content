1. Understanding Dart Syntax

In human languages, grammar defines the rules for how words form meaningful sentences. If you ignore punctuation or word order, people might misinterpret your meaning.

Similarly, in computer programming, Syntax is the set of precise grammar and punctuation rules that the Dart compiler enforces. If you break even a single rule—such as omitting a semicolon ; or writing a lowercase letter when uppercase is required—the Dart compiler cannot understand your instructions and raises a Compile Error.

Visual 1: High-Level Dart Program Anatomy
✔ Correct Dart Syntax
print('Hello World');
Proper function name in lowercase, single quotes around text, closed parenthesis, and ended with a semicolon.
✘ Invalid Dart Syntax
Print("Hello World")
Capitalized Print (Dart is case-sensitive) and missing the ending semicolon ;.

3. The main() Function: The Entry Point

Dart applications do not begin randomly at line 1. Instead, the Dart Virtual Machine searches specifically for a top-level function named main().

  • Entry Gate: If your project has 10,000 lines of code, execution always starts inside main().
  • Top-to-Bottom Execution: Statements placed inside main() run sequentially one after another in order.
  • Missing main(): If you try to run a Dart file without main(), the compiler aborts immediately with an error: "Error: Method not found: 'main'".

4. The print() Statement

The print() function is your window into what your program is thinking. It converts any data passed into it into readable text and appends a newline at the end.

Visual 3: How the print() Function Works

What Can You Print?

  • Plain Text: Enclosed in single or double quotes: print('Hello');
  • Numeric Literals: Numbers without quotes: print(42); or print(9.99);
  • Arithmetic Calculations: Math expressions are calculated before printing: print(10 * 4); prints 40.
  • Booleans: print(true); or print(false);

5. Statements & Mandatory Semicolons

In Dart, every standalone command is called a Statement. Unlike Python, Swift, or Kotlin, Dart requires a semicolon ; at the end of every statement.

Visual 4: The Semicolon Acts as an Instruction Delimiter
⚠ Why Semicolons Are Mandatory
Dart allows statements to span multiple lines for clean code formatting. Because newlines do not automatically end statements, the compiler needs ; to know precisely where an expression ends and the next one begins.
multiline_statement.dart Valid Multi-Line Formatting
DART Script
DART 
void main() {
  // This is ONE single statement split across three lines:
  print(
    100 + 200 + 300
  );
}

6. Comments in Dart

Comments are descriptive notes written for human programmers. The Dart compiler completely ignores comments during compilation—they take up zero memory and have zero impact on program speed.

Visual 5: Compiler Processing Code vs Comments

The Three Types of Comments

  • 1. Single-Line Comment (//): Everything from the double slash to the end of that specific line is ignored.
  • 2. Multi-Line Comment (/* ... */): Everything enclosed between the opening /* and closing */ is ignored, even across multiple lines.
  • 3. Documentation Comment (///): Used directly above classes, methods, and functions. Dart's doc-generator tool parses these to produce official API documentation.
comments_demo.dart Comment Types
DART Script
DART 
/// The entry point for the customer greeting system.
/// Used to demonstrate how doc comments format API guides.
void main() {
  // This prints an initial hello message
  print('Welcome to CodeVerse!');

  /*
    The lines below calculate discounts.
    Currently disabled for testing:
    print('Discount: 20%');
  */

  print('Total: \$50'); // Inline comment at line end
}

7. Strings and Basic Text Formatting

In Dart, a String is an ordered sequence of characters used to represent text. You can enclose strings in either single quotes '...' or double quotes "...". Both work identically in Dart.

Escape Characters (\)

Special characters like newlines or tabs are represented using a backslash escape sequence:

  • \n : Newline (jumps down to a new line).
  • \t : Tab (adds an indentation horizontal space).
  • \' : Single quote inside a single-quoted string.
  • \" : Double quote inside a double-quoted string.
  • \\ : Literal backslash character.
string_formatting.dart Quotes & Escape Codes
DART Script
DART 
void main() {

  print('Single quotes work great.');
  print("Double quotes also work great.");

  // Escape sequences: Newline and Tab

8. Case Sensitivity & Naming Basics

Dart is strictly case-sensitive. This means uppercase and lowercase letters are treated as completely different characters:

  • main is the valid entry function name; Main or MAIN will fail to compile.
  • print is the output function; Print does not exist in the Dart core library.
  • score, Score, and SCORE represent three distinct identifiers.
💡 Official Dart Naming Conventions
  • lowerCamelCase: Used for function names, method names, and variables (e.g., calculateTotalBill, printReport).
  • UpperCamelCase: Used for class names, enums, and type definitions (e.g., UserProfile, BankAccount).
  • lowercase_with_underscores: Used for filenames and library imports (e.g., main_screen.dart).

9. Common Beginner Syntax Errors

Mistakes are a natural part of learning to code. Let's study the most common syntax errors beginners encounter and how the compiler flags them.

Visual 6: Side-by-Side Error Diagnosis

Top 5 Beginner Mistakes

  1. Missing Semicolon:
    print('Hello') → Error: Expected ';' after this.
  2. Unterminated String:
    print('Hello); → Error: String pattern has no matching end quote.
  3. Unbalanced Braces { }:
    Opening void main() { without a closing } → Error: Expected '}' to match '{'.
  4. Casing Mistakes:
    Print('Hello'); → Error: Method not found: 'Print'.
  5. Misspelled main:
    void mian() { } → Error: Method not found: 'main'.

11. Quick Revision Summary

  • main() is Mandatory: Every standalone executable Dart application must have a top-level main() function.
  • Return Type: void indicates that the function performs instructions but returns no value.
  • Mandatory Semicolons: In Dart, every statement must terminate with a semicolon ;.
  • Case-Sensitive: void main() and print() must be all-lowercase.
  • The print() Function: Evaluates expressions, prints the string representation to the terminal, and moves down to a new line.
  • Comments: Single-line //, multi-line /* ... */, and documentation comments /// are completely ignored by the compiler at runtime.
  • Escape Codes: Use \n for line breaks and \t for tab spacing.

1. What happens if you execute a Dart file that does not contain a main() function?
A) It starts executing from the first line automatically.
B) The compiler throws a compile-time error: Method not found: 'main'.
C) It executes only comments.
D) It runs in background mode without printing.
View Correct Answer
Answer: B. Dart strictly requires an entry point named main() to begin execution.
2. Which punctuation mark is mandatory at the end of each Dart statement?
A) Colon (:)
B) Period (.)
C) Semicolon (;)
D) Comma (,)
View Correct Answer
Answer: C. A semicolon ; is required to terminate statements in Dart.
3. What does the keyword "void" before main() mean?
A) The function never stops running.
B) The function does not return any data value.
C) The file is empty.
D) The function accepts infinite arguments.
View Correct Answer
Answer: B. void signifies an absence of a return value.
4. Which of the following initiates a documentation comment in Dart?
A) //
B) /* */
C) ///
D) #
View Correct Answer
Answer: C. Three slashes /// designate doc comments recognized by the Dart documentation generator.
5. What does the escape character '\n' produce in a printed string?
A) A tab horizontal space
B) A new line break
C) An alert chime sound
D) A literal letter 'n'
View Correct Answer
Answer: B. \n inserts a newline break into the text output.
