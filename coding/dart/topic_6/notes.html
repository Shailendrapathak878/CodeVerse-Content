Conditional Statements

Empower your Dart code to make intelligent decisions using if, if-else, else-if ladders, nested conditions, logical operators, and switch statements.

1. Introduction to Conditional Statements

By default, computer programs execute statements sequentially from top to bottom. However, real-world applications need to make intelligent choices based on changing conditions: "Did the payment succeed? Is the user logged in? Is the inventory in stock?"

A conditional statement allows your program to evaluate an expression that produces a Boolean value (true or false) and choose which branch of code to execute.

Real-Life Analogy: Before leaving home in the morning, you check the weather: "If it is raining, take an umbrella. Otherwise, go without one." The condition is whether rain is falling, and your action depends entirely on the answer.

2. Understanding the if Statement

The if statement is the simplest decision structure. It executes a block of code only when its condition evaluates to true. If the condition is false, Dart skips the entire block.

Visual 2: if Statement Flowchart
if_statement.dart Dart
DART Script
DART 
void main() {
  int age = 20;

  if (age >= 18) {
    print('You are eligible to vote');
  }
}
▶ Output Console
You are eligible to vote

3. Understanding the if-else Statement

When your application has two mutually exclusive options, use if-else. Exactly one branch is executed: the if block if true, or the else block if false.

Visual 3: if-else Two-Way Fork Flowchart
if_else.dart Dart
DART Script
DART 
void main() {
  int age = 16;

  if (age >= 18) {
    print('Adult');
  } else {
    print('Minor');
  }
}
▶ Output Console
Minor

4. Understanding the else-if Ladder

When your application needs to test more than two outcomes, use an else-if ladder. Dart evaluates the conditions sequentially from top to bottom. As soon as the first condition evaluates to true, its block executes, and all remaining conditions in the ladder are skipped!

Visual 4: Cascading else-if Ladder Evaluation
else_if_ladder.dart Grade Calculator
DART Script
DART 
void main() {
  int marks = 75;

  if (marks >= 90) {
    print('Grade A');
  } else if (marks >= 75) {
    print('Grade B');
  } else if (marks >= 50) {
    print('Grade C');
  } else {
    print('Fail');
  }
}
▶ Output Console
Grade B

5. Nested if Statements

An if statement placed inside another if block is known as a nested if. The inner condition is evaluated only if the outer condition has already passed.

Visual 5: Two-Stage Nested Security Check
nested_if.dart Nested Security Check
DART Script
DART 
void main() {
  bool hasTicket = true;
  bool hasId = true;

  if (hasTicket) {
    if (hasId) {
      print('Entry allowed');
    } else {
      print('ID required');
    }
  } else {
    print('Ticket required');
  }
}
▶ Output Console
Entry allowed

7. Understanding the switch Statement

When you have a single variable whose value must be matched against several constant options (like days of the week, menu numbers, or user roles), a switch statement is often cleaner and faster than a lengthy else-if chain.

Visual 7: switch Multi-Case Matching Flow
switch_demo.dart Day Selector
DART Script
DART 
void main() {
  int day = 2;

  switch (day) {
    case 1:
      print('Monday');
      break;
    case 2:
      print('Tuesday');
      break;
    case 3:
      print('Wednesday');
      break;
    default:
      print('Invalid day');
  }
}
▶ Output Console
Tuesday

8. The Ternary Operator for Short Decisions

For brief two-option outcomes, the ternary operator (condition ? valueIfTrue : valueIfFalse) offers a clean inline alternative to four lines of if-else:

DART Script
DART 
void main() {
  int age = 20;
  String result = age >= 18 ? 'Adult' : 'Minor';
  print(result);
}
▶ Output Console
Adult

9. Comparison of Conditional Statements

Statement Best Use Case When to Choose
if Single optional check. When an action should only happen if true, and nothing if false.
if-else Two mutually exclusive paths. When you have an action for pass and an alternative action for fail.
else-if Multiple sequential conditions. Grading scales, tax brackets, tiered pricing.
Nested if Multi-stage hierarchical checks. When checking a secondary requirement only after the first passes.
switch Matching one variable against fixed constants. Menu selections, day/month choices, state flags.
Ternary Inline assignment of two values. Setting a variable or widget property in a single readable line.

10. Common Beginner Mistakes & Fixes

✘ Mistake 1: Using Assignment = Instead of Comparison ==
if (age = 18) { } // COMPILE ERROR: Conditions must have static type 'bool'!
Fix: Use double equals: if (age == 18) { }
✘ Mistake 2: Using Non-Boolean Values as Conditions
int count = 5; if (count) { } // ERROR: Dart is not JS or C!
Fix: Test explicitly: if (count > 0) { }
✘ Mistake 3: Out-of-Order Conditions in else-if Ladders
if (marks >= 50) { ... } else if (marks >= 90) { ... } // 95 gets caught by 50!
Fix: Arrange conditions from most specific / highest threshold to lowest: if (marks >= 90) ...

12. Quick Revision Summary

  • Conditions: In Dart, conditions inside if must evaluate strictly to a bool (true/false).
  • if: Executes a block if the condition evaluates to true.
  • if-else: Provides two alternative branches; exactly one executes.
  • else-if Ladder: Evaluates conditions top to bottom and terminates at the first true match.
  • Nested if: Places one decision inside another for multi-layered checks.
  • Logical Operators: Use && (AND) when both must pass, and || (OR) when at least one must pass.
  • switch: Matches an expression against constant values and uses break to prevent fallthrough.
  • Ternary: condition ? trueVal : falseVal provides concise inline decisions.

13. Knowledge Check & Practice Exercises

Part A: Multiple Choice Questions (MCQs)

1. What data type MUST the condition inside an if statement evaluate to in Dart?
A) int (0 or 1)
B) bool (true or false)
C) String
D) dynamic
View Correct Answer
Answer: B. Unlike C or JavaScript, Dart strictly enforces that if conditions must have a static type of bool.
2. In an else-if ladder, what happens once a condition evaluates to true?
A) Dart executes that block and ignores all subsequent else-if and else blocks.
B) Dart executes all remaining blocks in the ladder.
C) The program restarts from main().
D) It throws a compile-time warning.
View Correct Answer
Answer: A. Dart executes only the first matching branch and immediately exits the ladder.
3. What keyword is placed inside a traditional switch case to exit the switch block?
A) stop
B) exit
C) break
D) return
View Correct Answer
Answer: C. break terminates execution of the switch statement and jumps to the code following it.
4. Which conditional structure is best suited for matching a single variable against several constant integers?
A) switch
B) Nested if
C) While loop
D) Ternary operator
View Correct Answer
Answer: A. switch is specifically optimized for comparing one variable against multiple discrete constant options.
5. What is the output of: int score = 50; print(score > 40 ? 'Pass' : 'Fail'); ?
A) Pass
B) Fail
C) true
D) 50
View Correct Answer
Answer: A. Since 50 > 40 is true, the ternary operator evaluates the true branch ('Pass').
