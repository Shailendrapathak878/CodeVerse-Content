Operators & Expressions

Learn how Dart manipulates data using arithmetic, assignment, relational, logical, increment/decrement, type test, bitwise, ternary, and null-aware operators.

1. Introduction to Operators

An operator is a special character or symbol that tells the compiler to perform a specific mathematical, comparison, or logical operation. The values or variables that the operator works on are called operands. A combination of operands and operators that computes a value is called an expression.

Real-Life Analogy: A pocket calculator has symbol buttons like +, -, ×, and ÷. When you enter 10 + 5 and press equals, 10 and 5 are the operands, + is the operator, and 15 is the evaluated result!

Visual 1: Anatomy of an Expression
intro_operators.dart Dart
DART Script
DART 
void main() {
  int a = 10;
  int b = 5;

  print(a + b); // Prints 15
}
▶ Output Console
15

2. Arithmetic Operators

Arithmetic operators perform basic mathematical calculations on numeric operands (int and double).

Visual 2: Dart Arithmetic Calculator Overview
arithmetic.dart Dart Math
DART Script
DART 
void main() {
  int a = 10;
  int b = 3;

  print(a + b);   // Addition (13)
  print(a - b);   // Subtraction (7)
  print(a * b);   // Multiplication (30)
  print(a / b);   // Standard division (3.3333333333333335)
  print(a ~/ b);  // Integer division truncating toward zero (3)
  print(a % b);   // Modulo remainder (1)
}
▶ Output Console
13
7
30
3.3333333333333335
3
1
⚠ Crucial Dart Division Distinction: / vs ~/
  • / always returns a double, even if the numbers divide evenly! For instance, 10 / 2 evaluates to 5.0.
  • ~/ integer division chops off (truncates) the decimal part and returns an int. For example, 10 ~/ 3 returns 3.
  • % modulo yields the remainder after integer division. For example, 10 % 3 leaves 1.

3. Assignment Operators

The simple assignment operator = assigns a value to a variable. Compound assignment operators (like +=, -=, *=, ~/=, %=) combine an arithmetic operation with assignment to update the existing variable in place.

Visual 3: How Compound Assignment Updates Variable State

DART Script
DART 
void main() {
  int score = 10;

  score += 5;   // Same as score = score + 5 (15)
  print(score);

  score -= 3;   // Same as score = score - 3 (12)
  print(score);
}
▶ Output Console
15

4. Relational / Comparison Operators

Comparison operators test the relationship between two values and always return a boolean: true or false.

  int age = 20;

  print(age != 18); // Not equal to? (true)
  print(age > 18);  // Greater than? (true)
  print(age = 20); // Greater than or equal to? (true)

✘ Never Confuse = with ==
= is for assignment (storing a value in a variable).
== is for comparison (asking Dart: "Are these two values equal?").

5. Logical Operators

Logical operators combine or invert boolean values:

  • AND (&&): Returns true only if both operands are true.
  • OR (||): Returns true if at least one operand is true.
  • NOT (!): Inverts the boolean value (!true → false, !false → true).
Visual 5: Boolean Logic Truth Tables
logical_operators.dart AND, OR, NOT
DART Script
DART 
void main() {
  bool hasId = true;
  bool hasTicket = false;

  print(hasId && hasTicket); // false (both needed)
  print(hasId || hasTicket); // true (one is enough)
  print(!hasId);             // false (reverses true)
}
▶ Output Console
false
true
false

6. Increment and Decrement Operators

The increment operator (++) adds 1 to a variable, while decrement (--) subtracts 1. The placement of the operator relative to the operand determines when the value updates:

Visual 6: Prefix (++a) vs Postfix (a++) Execution Steps
increment_decrement.dart Prefix vs Postfix
DART Script
DART 
void main() {
  int a = 5;
  print(a++); // Prints 5 (uses current value, then increments)
  print(a);   // Prints 6

  int b = 5;
  print(++b); // Prints 6 (increments first, then uses)
  print(b);   // Prints 6
}
▶ Output Console
5
6
6
6

7. Type Test Operators

Type test operators check the runtime data type of an object:

  • is: Returns true if the object has the specified type.
  • is!: Returns true if the object does not have the specified type.

DART Script
DART 
void main() {
  var name = 'Dart';
  var age = 20;

  print(name is String);  // true
  print(age is int);      // true
  print(age is! String);  // true (age is NOT a String)
}

10. Null-Aware Operators — Introduction

In Dart, variables can be nullable. Dart provides null-aware operators to handle missing values safely without throwing exceptions:

Visual 9: Null-Coalescing Fallback (??)
  • ?? (If-Null): Returns the left expression if not null; otherwise returns the right fallback.
  • ??= (Null-Aware Assignment): Assigns a value to a variable only if the variable is currently null.
  • ?. (Null-Aware Access): Safely calls a method or property; returns null if the target object is null.
  • ! (Null Assertion): Forcefully asserts to the compiler that an expression is definitely not null (crashes if null!).
null_aware.dart Null Safety Operators
DART Script
DART 
void main() {
  String? name;

  print(name ?? 'Guest'); // Prints Guest (fallback)

  name ??= 'Shailendra';  // Assigns because name was null
  print(name);            // Prints Shailendra
}
▶ Output Console
Guest
Shailendra

11. Operator Precedence & Expressions

When an expression contains multiple operators, Dart evaluates them according to strict operator precedence rules. Multiplication and division take priority over addition and subtraction:

Visual 10: Parentheses Override Precedence
precedence.dart Order of Evaluation
DART Script
DART 
void main() {
  int result1 = 10 + 5 * 2;   // 5 * 2 = 10; 10 + 10 = 20
  int result2 = (10 + 5) * 2; // 15 * 2 = 30

  print(result1);
  print(result2);
}
▶ Output Console
20
30
💡 Best Practice
Whenever you are writing complex expressions, always use parentheses ( ... ). They make your intentions 100% unambiguous to both Dart and other programmers reading your code.

12. Common Beginner Mistakes & Fixes

✘ Mistake 1: Using / Instead of ~/ for Integer Division
int result = 10 / 2; // COMPILE ERROR: 10 / 2 returns double (5.0)!
Fix: Use integer division ~/: int result = 10 ~/ 2;
✘ Mistake 2: Confusing Assignment = with Equality ==
if (score = 100) { } // ERROR: Cannot assign inside condition!
Fix: Use double equals for comparison: if (score == 100) { }
✘ Mistake 3: Using Single & or | Instead of && and ||
bool canDrive = hasLicense & hasCar; // Bitwise operator instead of logical!
Fix: Use double ampersand for logical AND: bool canDrive = hasLicense && hasCar;

14. Quick Revision Summary

  • Operands & Operators: Operators perform actions on operands (values) to produce expression results.
  • Arithmetic: +, -, *, / (returns double), ~/ (integer division), % (modulo remainder).
  • Assignment: = assigns; +=, -=, *=, ~/=, %= update variables in place.
  • Relational: ==, !=, >, <, >=, <= return true or false.
  • Logical: && (AND: both true), || (OR: at least one true), ! (NOT: reverses boolean).
  • Increment/Decrement: Prefix ++a updates before use; postfix a++ uses current value then updates.
  • Type Test: is and is! verify object types at runtime.
  • Ternary: condition ? valueIfTrue : valueIfFalse provides concise inline decisions.
  • Null-Aware: ?? provides fallback defaults for null variables; ??= assigns only if null.
  • Precedence: Parentheses ( ... ) have the highest precedence and clarify evaluation order.

15. Knowledge Check & Practice Exercises

Part A: Multiple Choice Questions (MCQs)

1. What is the result of the division expression: 14 ~/ 4; in Dart?
A) 3.5
B) 3
C) 2
D) Compile error
View Correct Answer
Answer: B. ~/ is integer division, which truncates 3.5 to the integer 3.
2. Which operator in Dart returns true only if BOTH operands are true?
A) ||
B) !
C) &&
D) ==
View Correct Answer
Answer: C. The logical AND operator (&&) requires both conditions to be true.
3. What is the output of: int a = 5; print(a++); ?
A) 5
B) 6
C) 4
D) Compile error
View Correct Answer
Answer: A. Postfix a++ returns the current value (5) to the print statement before incrementing to 6 in memory.
4. What does the expression: String? user; print(user ?? 'Anonymous'); print?
A) null
B) Anonymous
C) user
D) Throws a NullPointerException
View Correct Answer
Answer: B. The null-coalescing operator ?? detects that user is null and substitutes the fallback 'Anonymous'.
5. What is the value of: 10 + 5 * 2; in Dart?
A) 30
B) 20
C) 100
D) 25
View Correct Answer
Answer: B. Multiplication has higher precedence than addition: 5 * 2 = 10, then 10 + 10 = 20.
