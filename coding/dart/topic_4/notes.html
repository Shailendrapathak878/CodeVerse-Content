Data Types & Type Conversion

Master Dart's core data types (int, double, num, String, bool, collections), understand how data is organized in memory, and learn safe, error-free type conversion techniques.

1. Introduction to Data Types

In programming, data is any raw information processed by your computer—such as a student's age, an item's price, or a welcome greeting. A data type tells Dart what kind of value a variable holds, how much memory to allocate, and what operations can legally be performed on it.

Real-Life Analogy: Think of a school backpack with distinct compartments. One pouch is designed specifically for flat textbooks, another holds water bottles, and a zippered pocket holds pens and pencils. You wouldn't pour loose water into your textbook sleeve! Similarly, Dart uses data types to keep text, numbers, and lists properly organized.

Visual 1: Dart Core Data Types Overview

2. Numeric Data Types — int, double, and num

In Dart, all numbers fall under the numeric category. There are two primary concrete number types, plus their common parent type num:

  • int: Represents whole numbers (integers without decimal points), such as 10, 100, or -5.
  • double: Represents 64-bit floating-point numbers containing fractional decimal points, such as 10.5, 99.99, or 3.14.
  • num: The direct superclass (parent) of both int and double. A variable declared as num can hold an integer at first and a double later!

DART Script

void main() {

  num temperature = 30;         // num holding integer initially

  print(age);
  print(price);
  print(temperature);

  // num can cleanly update to a double:
  temperature = 30.5;
  print(temperature);
}
▶ Output Console

5. Collection Data Types — Basic Introduction

While primitive variables hold a single value, collections group multiple items together under a single variable name:

Visual 4: Collection Types Architecture
  • List (Ordered): Like a grocery list. Items maintain their exact inserted order and duplicate entries are allowed: ['Apple', 'Mango', 'Banana'].
  • Set (Unique): Like student roll numbers. Automatically rejects duplicate values: {1, 2, 3}.
  • Map (Key-Value): Like a phonebook or dictionary. Stores data as paired labels and values: {'name': 'Rahul', 'city': 'Lucknow'}.

DART Script
DART

  List fruits = ['Apple', 'Mango', 'Banana'];
  Set numbers = {1, 2, 3};
  Map student = {
    'name': 'Rahul',
    'city': 'Lucknow',
  };

  print(fruits);
  print(numbers);
  print(student);
}
▶ Output Console
[Apple, Mango, Banana]
{1, 2, 3}
{name: Rahul, city: Lucknow}

6. Understanding dynamic and Object

Dart provides general-purpose types for scenarios where the exact type cannot be fixed:

  • Object: The root class of the entire Dart type system. Everything in Dart (except null) is an Object. An Object variable can hold any value, but the compiler only allows you to call methods defined on Object (like toString()).
  • dynamic: An escape hatch from static type checking. You can call any method on a dynamic variable without compile-time errors (though calling a nonexistent method will crash your app at runtime).
💡 Best Practice
Always declare specific types (int, String) whenever possible. Specific types catch typos at compile time before your users encounter a crash.

7. Type Conversion — Introduction

Type conversion is the process of taking a value of one data type (the source type) and transforming it into another data type (the target type).

Real-Life Analogy: Exchanging 10 US Dollars for 830 Indian Rupees at a currency counter. The monetary purchasing power is identical, but the currency representation has changed so local vendors can accept it.

Visual 5: Type Conversion Pipeline

Unlike JavaScript, Dart does not do implicit type coercion. If a function expects a double, passing an int directly without conversion is disallowed. You must convert explicitly!

8. Converting int to double

To convert an integer into a floating-point decimal number, call the built-in .toDouble() method:

int_to_double.dart toInt to toDouble
DART Script
DART 
void main() {
  int number = 10;
  double result = number.toDouble();

  print(result); // Prints 10.0
}
▶ Output Console
10.0

9. Converting double to int

To convert a floating-point number into an integer, call .toInt().

⚠ Truncation vs. Rounding
.toInt() does NOT round to the nearest integer! It simply truncates (chops off) all decimal digits toward zero. For example, 99.75.toInt() produces 99, not 100!
double_to_int.dart Truncating Decimals
DART Script
DART 
void main() {
  double price = 99.75;
  int truncatedPrice = price.toInt();

  print(truncatedPrice); // Prints 99

  double negativeVal = -5.9;
  print(negativeVal.toInt()); // Prints -5
}
▶ Output Console
99
-5

10. Converting String to int and double

When users type into a Flutter text field, the input always arrives as a String. To perform math on user input, you must parse the string into a numeric type using int.parse() or double.parse().

string_parsing.dart Parsing Numbers
DART Script
DART 
void main() {
  String ageText = '20';
  int age = int.parse(ageText);
  print(age + 5); // Math works! Prints 25

  String priceText = '99.50';
  double price = double.parse(priceText);
  print(price * 2); // Prints 199.0
}
▶ Output Console
25
199.0

11. Safe Conversion Using tryParse()

If a user types "abc" instead of a valid number, int.parse() will crash your app with a FormatException. To prevent crashes, Dart provides the safe alternative tryParse():

Visual 8: Unsafe parse() vs Safe tryParse()
safe_try_parse.dart tryParse with Nullable int?
DART Script
DART 
void main() {
  // Returns null on invalid input
  int? safeAge = int.tryParse('twenty');
  print(safeAge); // Prints null

  // Returns the parsed integer on valid input
  int? validAge = int.tryParse('25');
  print(validAge); // Prints 25
}
▶ Output Console
null
25

What is int?? The question mark (?) designates a nullable type. It indicates that the variable can hold an integer, but it can also hold null (representing the absence of a value when parsing fails).

13. Common Beginner Mistakes & Fixes

✘ Mistake 1: Assigning a String to an int Variable
int age = '20'; // ERROR: String cannot be assigned to int!
Fix: Parse it first: int age = int.parse('20');
✘ Mistake 2: Assigning a double to an int Without Conversion
int count = 10.5; // ERROR: double cannot be assigned to int!
Fix: Truncate with .toInt(): int count = 10.5.toInt();
✘ Mistake 3: Calling parse() on Unsanitized User Input
int age = int.parse('abc'); // CRASH: FormatException
Fix: Use safe tryParse(): int? age = int.tryParse('abc');
✘ Mistake 4: Assuming toInt() Performs Mathematical Rounding
double val = 4.9; int rounded = val.toInt(); // Produces 4, NOT 5!
Fix: .toInt() truncates. If you need rounding, use val.round().

15. Quick Revision Summary

  • int: Whole numbers without decimal points (e.g. 20).
  • double: Decimal numbers with fractions (e.g. 99.50).
  • num: The parent superclass of both int and double.
  • String: Text sequences enclosed in quotes (e.g. 'Hello').
  • bool: Logical true/false flag.
  • Collections: List (ordered), Set (unique values), Map (key-value pairs).
  • .toDouble() & .toInt(): Explicit numeric conversions. Note that .toInt() truncates decimals toward zero without rounding.
  • int.parse(): Converts numeric strings into integers, but throws FormatException on invalid text.
  • int.tryParse(): Safe conversion that returns null instead of crashing when given invalid text.
  • .toString(): Converts any data type into its String representation.
