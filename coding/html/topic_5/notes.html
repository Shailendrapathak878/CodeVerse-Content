🔊 1. The Core Philosophy: Visual vs. Semantic Formatting

In early HTML, tags like <b> (bold) and <i> (italic) were invented solely to change the visual look of font on a screen.

In modern HTML5, we design for accessibility. Web browsers are not only used by humans looking at screens; they are parsed by search engine crawlers, automated translation tools, and screen readers used by blind or visually impaired individuals.

Figure 5.1: Visual Tags vs Semantic Screen-Reader Accessible Tags
🎙️ How Screen Readers Announce <em> vs <i>
Consider this sentence:
"I did not take your laptop."
If you wrap <em> around the word did not, an accessibility screen reader modulates its synthesized speech voice with pitch emphasis and intensity, changing the meaning of the entire sentence!

📚 2. Complete Guide to Text Formatting Tags

Tag Name Semantic Purpose & Real-World Usage Live Visual Output
<strong> Strong Importance High urgency, critical warnings, or key document concepts. Warning: Toxic
<em> Stress Emphasis Vocal stress inflection that alters the sentence tone. Please arrive on time.
<mark> Marked / Highlighted Represents text highlighted for reference relevance (like search query hits). Found match: HTML5
<small> Fine Print Side comments, copyright notices, and legal disclaimers. © 2026 CodeVerse. All rights reserved.
<del> Deleted Text Content removed or replaced in an edit or discounted item price. $99.00
<ins> Inserted Text Content newly inserted into a document (often paired with <del>). $49.00
<sub> Subscript Renders below the baseline for chemical formulas and math indices. Water is H2O
<sup> Superscript Renders above the baseline for exponents, footnotes, and ordinals. Einstein's E = mc2 (1st Place)
<kbd> Keyboard Input Represents hardware keys or user keyboard combinations. Press Ctrl + C

💻 4. Practical Working Example: E-Commerce Product Flash Sale

Here is a production-grade component combining discounts, key specifications, and chemical battery components using semantic text tags:

📄 product-deal.html Semantic Formatting in Practice 
<!DOCTYPE html>
<html lang="en">
  <head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>Flash Sale Deal | CodeVerse Store</title>
  </head>
  <body>
    <h1>Smart Fitness Watch Pro</h1>
    
    <p>
      <mark>FLASH SALE TODAY ONLY</mark>: 
      Was <del>$249.99</del>, now only <ins><strong>$179.99</strong></ins>!
    </p>

    <p>
      Rated the <strong>1<sup>st</sup></strong> choice for athletes worldwide. 
      Powered by an ultra-durable LiFePO<sub>4</sub> lithium battery cell.
    </p>

    <p>
      To quickly toggle developer sync mode, press <kbd>Shift</kbd> + <kbd>D</kbd>.
    </p>

    <p>
      <small>*Discounts valid while supplies last. Standard warranty terms apply.</small>
    </p>
  </body>
</html>

⚠️ 5. Common Traps & Best Practices

❌ Using <b> for Critical Warnings
<p><b>WARNING:</b> Do not touch high voltage!</p>

Trap: Screen readers do not announce <b> with urgency, putting visually impaired users at risk!

✅ Using <strong> for Urgency
<p><strong>WARNING:</strong> Do not touch high voltage!</p>

Fix: <strong> signals strong semantic importance to both sighted humans and screen readers.
