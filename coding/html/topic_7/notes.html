Images, Paths & Alternative Text

Bring rich visual life to your websites. Master the <img> element, write accessible alt text that delights screen readers, eliminate Cumulative Layout Shift (CLS) with explicit dimensions, and speed up load times using native loading="lazy".

🖈️ 1. The Anatomy of an <img> Element

The <img> tag embeds an image into your HTML document.

Notice that <img> is a void (self-closing) element. Images cannot enclose child text or elements; all image source data is provided through attributes:

<img src="assets/images/mountains.webp" alt="Snow-capped Alpine mountain peak under sunrise" width="800" height="450" loading="lazy">
🖼️ The Picture Frame Analogy
The <img> tag in your HTML file is like hanging an empty wooden picture frame on your living room wall:
  • The src attribute is the delivery address: "Fetch the photograph from this local file or web URL."
  • The width and height are the physical dimensions of the wooden frame so your furniture doesn't rearrange when the photo arrives.
  • The alt text is the audio guide for museum visitors who cannot see the painting!

💡 What if an image is purely decorative?
If an image is purely decorative (such as an abstract wave banner, a subtle divider line, or a background floral swirl):
Use an empty alt attribute: alt=""!
An empty string explicitly instructs screen readers: "Skip this image completely; it contains no textual information."
Warning: If you omit the alt attribute entirely, screen readers will read the ugly raw file path aloud: "Image: slash assets slash uploads slash dsc underscore 9021 dot jpg"!

🖆️ 3. Preventing Cumulative Layout Shift (CLS)

Have you ever read an article on your phone, and suddenly the text jumped 300 pixels down because an image finished downloading above it?

This annoying jumping is called Cumulative Layout Shift (CLS). It frustrates users and lowers your Google search ranking.

Figure 7.2: How Explicit Dimensions Eliminate Annoying Content Jumping (CLS)

Modern Performance: loading="lazy"

By adding loading="lazy" to images below the fold (not immediately visible on screen when the page opens), the browser will delay downloading those heavy image files until the user actually scrolls near them! This drastically saves mobile cellular data and accelerates initial page load speed.

🖌️ 4. Semantic Image Grouping: <figure> and <figcaption>

When an image, diagram, or chart is accompanied by a caption that explains it, HTML5 provides two semantic elements:

  • <figure>: An independent, self-contained unit of content (photo, illustration, diagram).
  • <figcaption>: The human-readable caption or legend attached directly to that figure.
📄 figure-demo.html Semantic Figure Markup 
<figure>
  <img 
    src="solar-system.webp" 
    alt="Orbital diagram of the eight planets surrounding the Sun"
    width="800" 
    height="450"
    loading="lazy">
  <figcaption>
    Figure 1.1: Scaled orbital trajectory model of the inner and outer planets.
  </figcaption>
</figure>

Here is a complete, working HTML document applying images, local relative paths, alt text, dimensions, and semantic captions:

<!DOCTYPE html>
<html lang="en">
  <head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">

  </head>

    <figure>
      <img 
        src="https://images.unsplash.com/photo-1516426122078-c23e76319801" 
        alt="Adult African lion resting majestically on a rock kopje during sunset"
        width="600" 
        height="350"
        loading="lazy">
      <figcaption>

      </figcaption>
    </figure>
  </body>

⚠️ 6. Common Image Traps & Anti-Patterns

❌ Redundant "Image of..." in Alt Text
<img src="dog.jpg" alt="Picture of a golden retriever dog">

Trap: Screen readers already announce: "Image: Picture of a...", repeating the word redundantly.

✅ Direct Descriptive Subject
<img src="dog.jpg" alt="Golden retriever puppy playing fetch with a yellow tennis ball">

Fix: Describe the visual scene directly and vividly.
