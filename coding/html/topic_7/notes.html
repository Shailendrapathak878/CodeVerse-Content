01

The Image Element ()

The <img> element embeds graphic files into a webpage. It is a void element (no closing tag). The two mandatory attributes are src (path or URL to the image) and alt (alternative text description).

02

Alternative Text (alt) and Accessibility

The alt attribute serves three critical roles:

  • Accessibility: Read aloud by screen readers for visually impaired users.
  • Fallback: Displayed if the image file fails to load or the network drops.
  • SEO: Indexed by search engines to understand image subject matter.

Purely decorative images should have an empty alt attribute (alt=""), telling screen readers to silently skip them.

03

Performance: Dimensions and Lazy Loading

Always declare explicit width and height attributes. This allows the browser layout engine to allocate an aspect ratio box before the image downloads, preventing CLS (Cumulative Layout Shift).

Use loading="lazy" to defer image download until the user scrolls near it, drastically saving bandwidth on long pages.

WARN

Common Mistakes & Pro Tips

⚠️ Common Trap: Omitting the alt attribute entirely

Problem: Screen readers will announce the raw, cryptic image file URL (e.g., 'IMG_98234_final.jpg').

Fix: Always include alt. If decorative, set alt=""; if informational, describe its content accurately.

⚠️ Common Trap: Writing 'Image of...' or 'Photo of...' in alt

Problem: Screen readers already announce that an element is an image. Redundant text clutters the audio experience.

Fix: Directly describe the subject: alt="Student practicing Python syntax on laptop".
