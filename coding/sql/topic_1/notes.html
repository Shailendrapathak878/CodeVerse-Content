Introduction to SQL & Database

Learn what databases are, why modern applications rely on them, and how SQL lets you store, query, and manage relational data.

A Introduction to Database

Before writing queries, we must understand what data is and why databases exist.

  • What is Data? Data is raw facts, figures, or observations collected together, such as a student's roll number, name, or exam score. On its own, raw data lacks structure until it is organized.
  • What is a Database? A database is an organized collection of related data stored electronically on a computer system. It enables data to be quickly searched, inserted, updated, and secured.
  • Why Do We Need Databases? Storing critical records in text files or paper registers leads to duplicate entries, data loss, slow searching, and no safe way for multiple people to access records simultaneously. Databases solve this through structured storage, fast indexed searching, and secure multi-user access.

Real-World Example (College Records): A college manages thousands of students, fee payments, attendance, and semester marks. A centralized database ensures that when a student pays a fee, the finance office, exam cell, and student portal all see the updated record instantly without discrepancies.

B What Is SQL?

SQL stands for Structured Query Language (pronounced "S-Q-L" or "Sequel"). It is the standard computer language used to communicate with Relational Database Management Systems (RDBMS) such as MySQL, PostgreSQL, Oracle, and SQLite.

SQL provides a clean, declarative syntax to perform common data operations:

  • Retrieving Data (Read): Finding and extracting specific records that match your query.
  • Inserting Data (Create): Adding new rows of data into tables.
  • Updating Data (Modify): Changing or correcting existing table records.
  • Deleting Data (Remove): Deleting unwanted or outdated records safely.

Key Distinction: SQL is a language, whereas a database is the software container where data is organized and stored. You use SQL to give instructions to the database engine.

C Database, Table, Row, and Column

Relational databases organize information in tables. Let us examine each component using our Students table:

student_id name branch age
101 Rahul CSE 19
102 Priya AI 20
103 Aman IT 19
Table

The complete two-dimensional structure named Students, holding related data arranged in rows and columns.

Row (Record / Tuple)

A horizontal entry representing one student's complete record (e.g., 102 | Priya | AI | 20).

Column (Attribute / Field)

A vertical category that holds a specific type of data across all rows, such as name or branch.

Cell (Individual Value)

The single data point at the intersection of a specific row and column (e.g., "Rahul" or 19).

D Your First SQL Queries

Let us write our first SQL query to retrieve data from the Students table.

Query 1: Retrieve All Records & All Columns SQL 
SELECT * FROM Students;

Query Breakdown:

  • SELECT is the SQL command used to retrieve data.
  • * is an asterisk wildcard meaning "select all columns".
  • FROM Students specifies the target table.
  • ; (semicolon) terminates the SQL statement.
✔ Expected Output (All 4 Columns)
student_id name branch age
101 Rahul CSE 19
102 Priya AI 20
103 Aman IT 19

To retrieve only specific columns, list their names separated by commas:

Query 2: Select Specific Columns SQL 
SELECT name, branch
FROM Students;

Explanation: Here, only name and branch are retrieved. The other columns (student_id, age) are omitted, making queries faster and cleaner.

✔ Expected Output (Only Requested Columns)
name branch
Rahul CSE
Priya AI
Aman IT

E SQL vs. Database

While often mentioned together, SQL and databases serve distinct roles:

SQL (Structured Query Language) Database (Data Storage System)
A language used to work with data. An organized collection of data.
Used to query, insert, update, and modify records. Stores, manages, and secures data files.
You write statements (e.g., SELECT * FROM Students;). The database executes statements and holds the tables.
Examples: ANSI SQL, MySQL dialect, PostgreSQL SQL. Examples: MySQL, PostgreSQL, Oracle, SQLite.

F Where Is SQL Used?

SQL powers data storage and retrieval across modern software applications:

Banking Systems

Banks use SQL to track account balances, process customer deposits, and record daily transactions securely.

College Management Systems

Universities use SQL to store student enrollment records, manage semester grades, and schedule classes.

E-Commerce Websites

Online stores use SQL to manage product catalogs, update inventory levels, and process shopping orders.

Hospital Management Systems

Hospitals use SQL to maintain patient treatment histories, schedule doctor appointments, and manage billing records.

G Quick Revision & Key Takeaways

  • Data vs. Database: Data is raw facts; a database is an organized system that stores and manages data electronically.
  • SQL Definition: SQL is the standard language used to communicate with relational databases.
  • Relational Structure: Databases contain tables made of vertical columns (fields) and horizontal rows (records).
  • Basic Query: SELECT * FROM Students; fetches all columns and all rows from the table.
  • Filtering Columns: Specifying column names (e.g., SELECT name, branch FROM Students;) retrieves only the necessary data.
★ Remember This

SQL is case-insensitive for keywords: select * from Students; works the same as SELECT * FROM Students;. However, writing SQL keywords in UPPERCASE is the universal industry standard because it keeps queries easy to read!
