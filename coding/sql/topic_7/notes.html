ORDER BY, DISTINCT & LIMIT

Organize and refine query results using sorting, deduplication, and row limits to present clean, structured, and focused relational data.

A ORDER BY — Sort Records

By default, relational databases do not guarantee any specific display order when retrieving rows. The ORDER BY clause sorts query results in ascending or descending order using one or more columns.

Throughout this lesson, we use our college Students table containing five learner records:

student_id name age branch city

College Example (Youngest to Oldest): The administrator wants student records listed in ascending order by age:

Sort by Age Ascending ORDER BY 
SELECT name, age
FROM Students
ORDER BY age ASC;

Understanding Sort Directions:

  • ASC sorts from smallest to largest (or A to Z). In standard SQL, ASC is the default if no direction is specified.
  • DESC sorts from largest to smallest (or Z to A).
Sort by Age Descending ORDER BY

FROM Students

★ Tied Values in SQL

Rahul and Aman both have age 19, while Priya and Arjun both have age 20. When rows share identical values, their relative order is not guaranteed unless a secondary sort column (such as name ASC) is specified.

B DISTINCT — Show Unique Values

When querying data, repeated values often clutter result sets. The DISTINCT keyword eliminates duplicate combinations from the selected columns, returning only unique values.

College Example: The administration needs a clean list of all engineering branches represented among enrolled students:

Retrieve Unique Branches DISTINCT 
SELECT DISTINCT branch
FROM Students
ORDER BY branch ASC;

The Students table contains five student records with branches CSE, AI, IT, CSE, and AI. DISTINCT collapses the two duplicates, and ORDER BY branch ASC displays the unique branch names alphabetically.

C LIMIT — Show Only a Few Records

The LIMIT clause restricts how many rows are returned by a query. It is widely supported across modern SQL engines including MySQL, PostgreSQL, and SQLite.

College Example: Show the first two students arranged alphabetically by name:

First Two Students Alphabetically LIMIT 
SELECT name, branch
FROM Students
ORDER BY name ASC
LIMIT 2;
name branch

ORDER BY name ASC arranges all five students alphabetically. LIMIT 2 then returns only the top two rows (Aman and Arjun), discarding the rest.

Database System Note: While LIMIT is standard in MySQL, PostgreSQL, and SQLite, Microsoft SQL Server uses TOP or OFFSET ... FETCH to restrict row counts.

3 Concise Takeaways:

  • Default Sort is ASC: If you omit ASC or DESC, SQL sorts ascending by default.
  • DISTINCT Evaluates Selected Columns: Duplicates are evaluated across all columns specified in your SELECT list.
  • Pair LIMIT with ORDER BY: Always use ORDER BY with LIMIT to ensure predictable, consistent results.
★ Remember This

Sort, Unique, Trim: ORDER BY sets the direction, DISTINCT removes duplicates, and LIMIT sets the ceiling. Together, they create clean and structured SQL reports!
