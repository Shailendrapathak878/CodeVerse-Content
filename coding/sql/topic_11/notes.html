Subqueries & Nested Queries

Harness the power of queries inside queries to answer multi-step data questions dynamically without hardcoded values.

A What Is a Subquery?

A subquery (or nested query) is an SQL query placed inside another query, enclosed within parentheses. It allows you to use the result of an inner query as the search condition or comparison value for an outer query.

Throughout this lesson, we use our college Students table:

Real-Life Question: Which students scored more than the average marks of the class?

B Example 1 — Subquery with AVG()

To find students scoring higher than the class average, an inner subquery calculates the mean, and the outer query filters students exceeding that score:

Find Students Above Average SUBQUERY 
SELECT name, marks
FROM Students
WHERE marks > (
    SELECT AVG(marks)
    FROM Students
);
name marks
Priya 90
Neha 85
◆ Visual 1: Nested Query Execution Flow
1. Inner Query (Runs First)
SELECT AVG(marks) FROM Students → Computes and returns single value: 80
2. Outer Query (Uses Returned Value)
SELECT name, marks WHERE marks > 80 → Filters students scoring strictly above 80
3. Final Output
Returns qualifying students: Priya (90) and Neha (85)
◆ Visual 2: Marks vs. Class Average (400 ÷ 5 = 80)
Student Marks Comparison: marks > 80 Status
Rahul 80 80 > 80 → False (= 80) ✘ Excluded
Priya 90 90 > 80 → True ✔ Above Avg
Aman 70 70 > 80 → False (< 80) ✘ Excluded
Neha 85 85 > 80 → True ✔ Above Avg
Arjun 75 75 > 80 → False (< 80) ✘ Excluded

Execution Details:

  • The inner query calculates the class average: 80.
  • The outer query filters students whose marks are greater than 80.
  • Rahul scored exactly 80, but is excluded because the condition uses strictly greater than (>).

C Example 2 — Subquery with MAX()

Real-Life Question: Who scored the highest marks in the class?

Find Highest Scorer SUBQUERY 
SELECT name, marks
FROM Students
WHERE marks = (
    SELECT MAX(marks)
    FROM Students
);
name marks
Priya 90

The inner query determines the maximum score (90). The outer query then retrieves the student or students who achieved that score (Priya). If multiple students tied for first place, all toppers would be returned.

★ Quick Revision & Takeaways

1. Parentheses Required: Always enclose subqueries in parentheses.
2. Dynamic Values: Subqueries update automatically when new records are added.
3. Inside-Out Execution: Inner query runs first → Outer query uses its output.
