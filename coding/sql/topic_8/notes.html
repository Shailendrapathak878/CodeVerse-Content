Aggregate Functions & GROUP BY

Summarize and categorize data using SQL mathematical functions and grouping to generate meaningful branch-wise reports.

A What Are Aggregate Functions?

An aggregate function performs a mathematical calculation across multiple rows of a table and returns a single summary value. Instead of inspecting each record individually, aggregate functions compute totals, averages, and extremes across entire datasets.

Throughout this lesson, we use our college Students table recording student exam marks:

student_id name branch marks
101 Rahul CSE 80
102 Priya AI 90
103 Aman CSE 70
104 Neha AI 85
105 Arjun IT 75

The Five Core Aggregate Functions:

Function Purpose
COUNT() Counts rows or non-NULL values, depending on the expression
SUM() Adds numeric values together into a total
AVG() Calculates the mathematical average of numeric values
MAX() Returns the highest value in the column
MIN() Returns the lowest value in the column

Row Count vs. Value Count: COUNT(*) counts all rows in the table. In contrast, COUNT(column_name) counts only rows where that specific column contains a non-NULL value.

B Practical Aggregate Queries

Let us execute three essential aggregation queries on our college dataset:

1. Count All Students:

Count Total Rows COUNT 
SELECT COUNT(*) AS total_students
FROM Students;
total_students
5

The COUNT(*) function counts all five student rows in the table, and AS assigns a clear alias to the output column.

2. Calculate Average Marks:

Calculate Marks Mean AVG 
SELECT AVG(marks) AS average_marks
FROM Students;
average_marks
80

The AVG() function adds all student scores (80 + 90 + 70 + 85 + 75 = 400) and divides by 5, producing an average score of 80.

3. Find Highest and Lowest Marks:

Find Extremes MAX / MIN 
SELECT
    MAX(marks) AS highest_marks,
    MIN(marks) AS lowest_marks
FROM Students;
highest_marks lowest_marks
90 70

You can combine multiple aggregate functions in a single query: MAX finds Priya's top score of 90, while MIN identifies Aman's score of 70.

C What Is GROUP BY?

While aggregate functions normally collapse an entire table into a single number, real-world reporting often requires summaries for different categories.

The GROUP BY clause groups rows sharing the same value so aggregate functions can calculate a separate summary for each group.

College Example: The college dean wants to see the total number of students and their average marks for each branch:

Branch-Wise Summary GROUP BY 
SELECT
    branch,
    COUNT(*) AS total_students,
    AVG(marks) AS average_marks
FROM Students
GROUP BY branch
ORDER BY branch;
branch total_students average_marks
AI 2 87.5
CSE 2 75
IT 1 75

Branch Group Aggregation Calculation Summary Result

Query Execution Breakdown:

  • GROUP BY branch creates one group per branch.
  • COUNT(*) counts students within each branch group.
  • AVG(marks) computes the average score within each branch group.
  • ORDER BY branch sorts the resulting rows alphabetically.

D Important Rule & Quick Revision

When writing grouped queries, SQL enforces a fundamental structural rule:

⚠ The GROUP BY Rule

Every column listed in your SELECT clause must either appear in the GROUP BY clause or be enclosed inside an aggregate function (such as COUNT() or AVG()).

Common Beginner Mistake:

Invalid Grouped Query (Causes SQL Error) ERROR 
SELECT branch, name, AVG(marks)
FROM Students
GROUP BY branch;

This query fails because the AI branch contains two students (Priya and Neha). Since you grouped by branch, SQL cannot choose which individual student name to display on the single summary row! To fix it, remove name from the SELECT list.

◆ Visual 4: Grouped Query Execution Flow
Step 1 • FROM Load Students table on storage (5 rows).
Step 2 • GROUP BY Partition rows into branch buckets (AI, CSE, IT).
Step 3 • AGGREGATE Compute COUNT(*) and AVG(marks) for each bucket.
Step 4 • SELECT Produce clean 3-row branch summary output table.

3 Concise Takeaways:

  • Aggregates Summarize Rows: Functions like COUNT, AVG, MAX, and MIN collapse multiple records into a single result.
  • GROUP BY Partitions Data: It creates subsets of rows so calculations happen independently per category.
  • Match Non-Aggregated Columns: Any unaggregated column in SELECT must be included in your GROUP BY list.
★ Remember This

Aggregate = Math on Rows, GROUP BY = Categories. Together, they transform raw student lists into executive summary reports!
