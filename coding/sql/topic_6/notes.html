SELECT & WHERE

Learn how to retrieve specific columns using SELECT and filter precise records using WHERE to query exact student data from relational tables.

A SELECT — Choose the Columns You Need

The SELECT statement retrieves data from a database table. In real-world applications, tables often contain dozens of columns, but you only need a few fields for a report or mobile screen.

Throughout this lesson, we query our college Students table containing four registered learners:

student_id name age branch city
101 Rahul 19 CSE Lucknow
102 Priya 20 AI Kanpur
103 Aman 19 IT Lucknow
104 Neha 21 CSE Delhi

1. Retrieving All Columns: Use an asterisk (*) to fetch every column:

Retrieve All Columns SQL 
SELECT *
FROM Students;

The asterisk tells the database engine to extract all five attributes (student_id, name, age, branch, city) across all rows.

2. Retrieving Specific Columns: List the exact column names separated by commas:

Retrieve Specific Columns SQL 
SELECT name, branch
FROM Students;

B WHERE — Filter the Records

The WHERE clause acts as a filter on table rows. When attached to a SELECT statement, the database evaluates the condition for every record and returns only rows where the condition evaluates to true.

College Example: The college administrator wants to find all enrolled students who reside in Lucknow:

Filter Students from Lucknow FILTER 
SELECT *
FROM Students
WHERE city = 'Lucknow';
student_id name age branch city

103 Aman 19 IT Lucknow

Only the two rows for Rahul and Aman satisfy city = 'Lucknow'. Priya and Neha fail the check and are excluded from the output.

★ The AND Rule

With AND, both conditions must be true for a row to appear in the output. If either condition fails, the row is discarded.

D Quick Revision & Common Mistake

Mastering SQL queries requires understanding how column projection and row filtering combine:

◆ Visual 5: Query-to-Output Execution Flow
Step 1 • FROM Load Students table on storage (4 rows, 5 columns).
Step 2 • WHERE Filter records by condition (e.g., city = 'Lucknow' keeps 2 rows).
Step 3 • SELECT Extract only requested columns (e.g., name, branch).
Step 4 • RESULT Deliver clean 2-row × 2-column result table to client.

Core Distinction:

  • SELECT decides which columns to display horizontally.
  • WHERE decides which rows to include vertically.
  • Both clauses operate together to shape the exact output table.
⚠ Common Beginner Mistake: Forgetting WHERE

If you run SELECT name FROM Students;, the query will return the names of every single student in the entire table. Beginners often omit WHERE and unintentionally retrieve thousands of unwanted rows!

3 Concise Takeaways:

  • Projection vs. Filtering: SELECT narrows column width (projection); WHERE narrows row count (filtering).
  • Quotes for Text, None for Numbers: Text literals require single quotes (e.g., 'CSE'), while numeric criteria do not (e.g., 20).
  • Precise Queries Save Bandwidth: Requesting only required columns with a targeted WHERE filter maximizes database performance.
★ Remember This

Think in Grids: SELECT chops columns left-to-right. WHERE chops rows top-to-bottom. Together, they isolate the precise cell data you need!
