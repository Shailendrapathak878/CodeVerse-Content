Common Table Expressions (CTEs)

Write cleaner, modular SQL by creating temporary named result sets using the WITH clause.

A What Is a CTE?

A CTE (Common Table Expression) is a temporary named result set defined using the WITH keyword. It exists only for the single SQL statement that follows it (such as SELECT, INSERT, UPDATE, or DELETE).

CTEs make complex queries easier to read and maintain by breaking them into simple, logical steps instead of deeply nested subqueries.

Real-Life Analogy: First prepare a list of students who scored at least 80, then use that list to display the final results.

We use our college Students table throughout this lesson:

B Example 1 — Create and Use a CTE

Here we create a CTE named HighScorers to find students with marks ≥ 80, then sort them by marks descending:

Define and Query a CTE WITH CLAUSE 
WITH HighScorers AS (
    SELECT name, branch, marks
    FROM Students
    WHERE marks >= 80
)
SELECT name, branch, marks
FROM HighScorers
ORDER BY marks DESC;

◆ Visual 1: CTE Execution Workflow
1. WITH Defines Named Result
WITH HighScorers AS (...) defines the temporary named result set.
2. Temporary Result Held
Stores query result temporarily in memory for the single statement that follows.
3. Outer Query Reads CTE
SELECT ... FROM HighScorers reads the named set like a table and sorts it.
4. Final Output
Returns final student results (Priya 90, Neha 85, Rahul 80). CTE is released.

Explanation:

  • WITH HighScorers AS (...) defines the CTE.
  • The inner query selects students with marks of at least 80.
  • The outer query reads from HighScorers and sorts the results.
  • The CTE is not a permanent table.

C Example 2 — CTE with Aggregate Results

A CTE can also simplify multi-step aggregate queries:

Branch Averages CTE WITH CLAUSE 
WITH BranchAverage AS (
    SELECT branch, AVG(marks) AS avg_marks
    FROM Students
    GROUP BY branch
)
SELECT branch, avg_marks
FROM BranchAverage
WHERE avg_marks >= 80
ORDER BY branch;
branch avg_marks
AI 87.5

The CTE calculates each branch's average marks first (AI: 87.5, CSE: 75.0, IT: 75.0). The outer query then keeps only branches whose average is at least 80.

★ Quick Revision & Takeaways

1. Single-Query Scope: The CTE exists only for the immediate query that follows it.
2. Clean Readability: Replaces hard-to-read nested subqueries with linear steps.
3. Non-Persistent: No table or storage overhead is stored in the database.
