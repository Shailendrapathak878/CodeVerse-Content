Set Operations

Combine, compare, and filter records from multiple queries using UNION, UNION ALL, INTERSECT, and EXCEPT.

A College Clubs & Set Operations

Set operations combine or compare rows returned by two separate SELECT queries. While JOINs combine columns horizontally from related tables, set operations compare or combine rows vertically between query result sets.

In this lesson, we examine students registered for two college activity clubs: CodingClub and RoboticsClub. Some students belong to both clubs, while others belong to only one:

The Golden Rule: Both queries in a set operation must return the same number of columns with compatible data types, listed in the exact same column order.

B UNION & UNION ALL

1. UNION — Combine, Remove Duplicates

Lists students registered in either club, automatically removing duplicate rows. Priya and Aman belong to both clubs, but each appears only once in the final result:

UNION Query UNION 
SELECT student_id, name FROM CodingClub
UNION
SELECT student_id, name FROM RoboticsClub
ORDER BY student_id;
◆ Visual 1: UNION (Both Circles Highlighted • Unique Rows)
Both clubs combined; shared students (Priya, Aman) appear once.

2. UNION ALL — Combine, Keep Duplicates

Combines records without filtering out duplicates. It retains all six rows: Rahul once, Priya twice, Aman twice, and Neha once. Because it avoids sorting to eliminate duplicate entries, UNION ALL executes faster. Do not rely on a particular row order unless ORDER BY is used:

UNION ALL Query UNION ALL 
SELECT student_id, name FROM CodingClub
UNION ALL
SELECT student_id, name FROM RoboticsClub;
◆ Visual 2: UNION ALL (All Rows Included • Duplicates Retained)
Combines both clubs and retains duplicate rows (6 total rows).

C INTERSECT & EXCEPT

3. INTERSECT — Common Rows

Finds students registered in both clubs (the shared overlapping records):

INTERSECT Query INTERSECT 
SELECT student_id, name FROM CodingClub
INTERSECT
SELECT student_id, name FROM RoboticsClub;
◆ Visual 3: INTERSECT (Only Overlapping Region Highlighted)
Only students enrolled in BOTH clubs (Priya, Aman).

4. EXCEPT — Rows in First Result Only

Finds students who belong to CodingClub who are not in RoboticsClub. Here, Priya and Aman are excluded because they joined robotics, leaving only Rahul:

EXCEPT Query EXCEPT 
SELECT student_id, name FROM CodingClub
EXCEPT
SELECT student_id, name FROM RoboticsClub;

⚙ Database Syntax Note

Set-operation support and syntax vary by database system. In particular, EXCEPT is called MINUS in Oracle. Availability of INTERSECT and EXCEPT can also vary across specific database products and versions.
