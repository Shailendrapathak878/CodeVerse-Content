Loops & Iterations in R

Master automated repetition in R: exploring for, while, and repeat loops, control commands (break, next), nested iterations, vector processing, the functional apply family, and AI batch scoring pipelines.

1. What Are Loops?

A loop is a programming structure that repeats a block of instructions automatically. In programming, performing one single cycle of repetition is called an iteration.

Imagine your teacher asks you to write "Good Morning" 100 times on a chalkboard:

  • Without a loop: You must write out 100 separate print lines manually. This is exhausting, clutter-filled, and prone to copy-paste typos.
  • With a loop: You give R one single instruction: "Repeat this print statement 100 times", and R executes it instantly.

Your First Basic Loop

first_loop.RR
R Script
R 
# Loop 5 times over the sequence 1 to 5
for (i in 1:5) {
  print("Good Morning")
}
Console Output
R Script
R 
[1] "Good Morning"
[1] "Good Morning"
[1] "Good Morning"
[1] "Good Morning"
[1] "Good Morning"

Code breakdown:

  • for: Keyword that initiates a counted sequence loop.
  • i: The loop variable (iterator) that temporarily holds the current item.
  • 1:5: The sequence of numbers (1, 2, 3, 4, 5) providing 5 distinct iterations.
  • { print("Good Morning") }: The loop body executed during each cycle.
  • Termination: After processing 5, the sequence ends and the loop terminates automatically.

2. Important Loop Terminology

Before diving deeper, let's establish key terms in clear language:

  • Loop: A code structure that repeats instructions until a specific goal or boundary is reached.
  • Iteration: A single complete pass through the loop's code body.
  • Loop Variable: The placeholder variable (like i or item) that stores the value for the active iteration.
  • Sequence: An ordered collection of items (such as numbers 1:5 or names vector) that the loop steps through.
  • Condition: A logical test (e.g. i <= 5) evaluated to determine whether the loop should continue or stop.
  • Loop Body: The instructions enclosed inside curly braces { ... } that execute on each pass.
  • Infinite Loop: A bug where a loop never encounters a stopping condition, running endlessly and freezing the session.
  • Loop Termination: The moment when repetition ceases and control moves to the following lines of code.

4. The while Loop

A while loop repeats as long as a test condition remains TRUE. It is used when you do not know in advance exactly how many iterations are needed, but you know the condition under which repetition should stop.

Formal Syntax:

  # Body instructions to repeat
  # Crucial: update loop variable to avoid infinite loop!
}

5. The repeat Loop

A repeat loop continuously executes its body unconditionally. It does NOT check a condition at the start or end; instead, the programmer must supply an explicit break statement inside the loop.

CRITICAL SAFETY WARNING: A repeat loop without a reachable break will run infinitely until the R process crashes or is forcefully terminated!

6. The break Statement

The break statement immediately exits the nearest enclosing loop. It terminates the entire loop instantly, ignoring all remaining iterations.

break_demo.RR
R Script
R 
for (i in 1:10) {
  if (i == 5) {
    break  # Halts immediately when i hits 5
  }
  print(i)
}
Console Output
R Script
R 
[1] 1
[1] 2
[1] 3
[1] 4

Why 5 is not printed: As soon as i == 5, the break executes, exiting before reaching print(i). The sequence values 6, 7, 8, 9, 10 are completely skipped.

7. The next Statement

The next statement skips the remaining instructions in the current iteration and advances directly to the next iteration. Unlike break, next does NOT terminate the loop.

next_demo.RR
R Script
R 
for (i in 1:5) {

    next  # Skip only 3!
  }
  print(i)
}
Console Output

R 
[1] 1
[1] 2
[1] 4
[1] 5

8. Nested Loops

A nested loop is a loop placed inside another loop. Think of an analog clock: the minute hand (inner loop) must tick through all 60 minutes before the hour hand (outer loop) moves ahead by one hour.

nested_grid.RR
R Script
R 
for (i in 1:3) {
  for (j in 1:2) {
    print(paste("Row:", i, "Column:", j))
  }
}
Console Output
R Script
R 
[1] "Row: 1 Column: 1"
[1] "Row: 1 Column: 2"
[1] "Row: 2 Column: 1"
[1] "Row: 2 Column: 2"
[1] "Row: 3 Column: 1"
[1] "Row: 3 Column: 2"
Performance Caution: If an outer loop runs 1,000 times and an inner loop runs 1,000 times, the inner body runs 1,000,000 times. For large datasets, use vectorized matrix operations instead of nested loops.

11. Comparing Loop Types: for vs while vs repeat

Feature for Loop while Loop repeat Loop
Main Use Case Iterating over a known sequence or vector. Repetition while an external condition holds TRUE. Unconditional loop needing explicit internal breaks.
Condition Check Implicit: checks if sequence has more elements. Evaluated before each iteration (pre-test). No automatic check; must use if (c) break.
Counter Update Automatic (managed by R interpreter). Manual: you must write i <- i + 1. Manual: you must update state inside body.
Stop Behavior Stops when sequence is exhausted. Stops when test condition returns FALSE. Requires manual break statement.
Beginner Example for (i in 1:5) while (count > 0) repeat { ... break }

14. 10 Common Beginner Mistakes & Traps

Trap 1: Forgetting to Update Counter in a while Loop

Symptom: The program hangs and runs forever because i never reaches the exit boundary. Always include i <- i + 1.

Trap 2: Creating an Infinite while Loop

Incorrect (Infinite)R
R Script
R 
x  0) {
  print(x)
  x <- x + 1  # Increases! Never drops to 0!
}

Trap 3: Using repeat Without a Reachable break

Every repeat block must contain an if (condition) break statement to allow the interpreter to exit.

Trap 4: Placing break Outside a Loop

Calling break in top-level code outside any loop throws: Error: no loop for break/next, jumping to top level.

Trap 5: Confusing break with next

break cancels the entire loop permanently. next only skips the current pass and continues with the next value.

Trap 6: Unexpected Sequence Boundaries (1:0 Trap)

Sequence HazardR
R Script
R 
n <- 0
for (i in 1:n) { print(i) }  # In R, 1:0 generates c(1, 0)! Runs twice unexpectedly!
Fix: Use seq_len(n) which safely generates an empty sequence when n = 0.

Trap 7: Overwriting Accumulator Variable

Writing total <- i inside the loop replaces the total on every pass instead of adding to it. Always write total <- total + i.

Trap 8: Confusing Outer and Inner Nested Variables

Using the outer variable i inside the inner loop header (e.g. for (i in 1:3) { for (i in 1:2) ... }) corrupts the outer loop index! Always use distinct identifiers (like i and j).

Trap 9: Using the Wrong Margin in apply()

Remember: MARGIN = 1 computes across ROWS, while MARGIN = 2 computes down COLUMNS. Swapping them transposes your aggregated summary!

Trap 10: Assuming sapply() Always Returns a Vector

If the function applied returns outputs of varying lengths, sapply() cannot simplify and silently falls back to returning a list. Check with is.vector() or use vapply() for strict safety.

16. Quick Revision & Key Takeaways

Construct Primary Syntax When to Choose Termination Mechanism
for for (var in seq) { ... } Known count or vector traversal. Sequence exhausts all items.
while while (condition) { ... } Repetition depends on condition state. Condition evaluates to FALSE.
repeat repeat { ... if (c) break } Custom internal stopping logic. Requires explicit break statement.
break if (condition) break Emergency loop exit. Terminates entire enclosing loop immediately.
next if (condition) next Filter out invalid or unwanted values. Skips current pass; loop remains active.
apply() apply(mat, margin, fun) Row/column operations on 2D arrays. Built-in functional iteration.
lapply() / sapply() lapply(list, fun) Applying operations to list/vector items. Returns list (lapply) or vector (sapply).
