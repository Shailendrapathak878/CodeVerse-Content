Data Types & Special Values in R

A comprehensive beginner's guide to atomic data types (Numeric, Integer, Character, Logical, Complex), type conversion, coercion, and special values (NA, NULL, NaN, Inf, -Inf) for Data Science & AI.

1. Introduction to Data Types

In the real world, human beings instantly recognize different kinds of information. When you see 21, you think of an age or a count. When you see "Sophia", you recognize a person's name. When you see a checkbox marked with a checkmark, you understand it as a "Yes" or "No" decision. When a thermometer reads 36.5°C, you understand it as a continuous physical measurement.

A computer, however, only sees raw electrical pulses (zeros and ones) in its silicon chips. To perform meaningful calculations, the R language must assign a data type to every value stored in memory. A data type tells R three critical facts:

  1. Memory Representation: How many bytes to allocate in RAM to store the item.
  2. Interpretation: How to translate the binary bits into numbers, text, or flags.
  3. Allowed Operations: What operations are valid (e.g., you can multiply numbers, but you cannot multiply someone's name!).
💡 Real-Life Categorization Analogy

Think of data types as organized kitchen containers:

  • Measuring jug for milk: Holds fluid volume with fractions (Numeric decimals like 1.75 liters).
  • Egg carton: Holds whole, indivisible items (Integers like 6L eggs).
  • Spice label tag: Holds textual words and names (Character strings like "Cinnamon").
  • Stove light on/off: A binary boolean state (Logical TRUE or FALSE).

2. The 5 Core Atomic Data Types in R

In R, individual values are called atomic values because they cannot be broken down into simpler fundamental data types. Base R provides five primary atomic types used daily in statistics and machine learning.

A. Numeric (Double-Precision Real Numbers)

The numeric type represents all standard real numbers, including positive numbers, negative numbers, and numbers with decimal fractions. In R, any number written without special suffixes defaults to numeric.

R Script — Numeric Examples R
R Script
R 
price       <- 99.50
temperature <- 36.5
height      <- 5.8

print(price)
print(temperature)
print(height)

typeof(price)
class(price)
Console Output
R Script
R 
[1] 99.5
[1] 36.5
[1] 5.8
[1] "double"
[1] "numeric"

Notice that typeof(price) returns "double". This is because R stores numeric values using 64-bit double-precision floating-point format (conforming to the international IEEE 754 standard). This allows R to handle prices, laboratory measurements, percentages, and scientific constants with extreme precision.

B. Integer (Discrete Whole Numbers)

While numeric values can contain fractions, integers represent discrete, whole numbers without any fractional part (e.g., count of students, days of the week, hospital patient IDs). To tell R to store a number as an integer in memory, you append a capital L to the literal number.

R Script — Integer Examples R
R Script
R 
age      <- 20L
students <- 50L

print(age)
print(students)

typeof(age)
class(age)
Console Output
R Script
R 
[1] 20
[1] 50
[1] "integer"
[1] "integer"
🔍 Why Append 'L' for Integers?

In R, writing x <- 20 stores 20 as an 8-byte double (numeric). Writing y <- 20L stores 20 as a 4-byte integer. The capital 'L' historically stands for Long integer (borrowed from C). When working with massive datasets with tens of millions of rows, using integers can cut memory usage in half!

C. Character (Text Strings & Labels)

The character type stores text strings, letters, words, and sentences. To define a character literal, you wrap the text in double quotes ("...") or single quotes ('...').

[1] "Lucknow"

A crucial rule in R is understanding the difference between numeric 100 and character "100". To humans they look similar, but in R:

  • 100 + 50 evaluates cleanly to 150.
  • "100" + 50 throws an error: non-numeric argument to binary operator.

D. Logical (Boolean TRUE & FALSE)

The logical data type stores boolean truth values: either TRUE or FALSE. Logical values are the bedrock of computer decision-making, conditional loops, and dataset row filtering.

R Script — Logical Decisions R

💡 Shorthand T and F Note

R allows the single-letter abbreviations T and F as shortcuts for TRUE and FALSE. However, best practice is to always write TRUE and FALSE in full, because T and F can be accidentally overwritten by user variables (e.g., T <- 0), creating nasty bugs!

E. Complex Numbers (Real + Imaginary)

A complex number represents a value containing both a real part and an imaginary part, expressed in the standard mathematical form: a + bi, where i represents the imaginary unit √(-1).

Complex numbers are widely utilized by electrical engineers (alternating current circuit analysis), physicists (quantum mechanics), and signal processing researchers (Fourier transforms). Beginners will rarely need complex numbers in ordinary business data analysis, but knowing they exist completes your understanding of R's core atomic types.

4. Understanding typeof() and class()

Two essential inspection functions in R are typeof() and class(). While they may return the same string for some simple values, they answer fundamentally different questions.

R Script — Comparing typeof() and class() R
R Script
R 
a <- 25
b <- 25L
c <- "25"
d <- TRUE
e <- 3 + 2i

cat("typeof(a):", typeof(a), "| class(a):", class(a), "
")
cat("typeof(b):", typeof(b), "| class(b):", class(b), "
")
cat("typeof(c):", typeof(c), "| class(c):", class(c), "
")
cat("typeof(d):", typeof(d), "| class(d):", class(d), "
")
cat("typeof(e):", typeof(e), "| class(e):", class(e), "
")
Console Output
R Script
R 
typeof(a): double | class(a): numeric 
typeof(b): integer | class(b): integer 
typeof(c): character | class(c): character 
typeof(d): logical | class(d): logical 
typeof(e): complex | class(e): complex
📖 Summary of the Difference

For a <- 25, typeof(a) is "double" (the internal C-level representation), while class(a) is "numeric" (the object class seen by R functions). For advanced objects like Dates or Data Frames, typeof() might be "double" or "list", while class() is "Date" or "data.frame".

5. Type Conversion & Automatic Coercion

In real-world data analysis, datasets imported from CSV files or web APIs often arrive with incorrect types (e.g., telephone numbers or currency amounts parsed as character text). R allows you to convert types explicitly, and also performs automatic conversion under certain rules.

Explicit Type Conversion Functions

Base R provides dedicated functions starting with as. to convert objects to specific data types:

  • as.numeric(x): Converts to double-precision numeric.
  • as.integer(x): Converts to integer (truncating decimals).
  • as.character(x): Converts any value into a text string.
  • as.logical(x): Converts numbers (0 → FALSE, non-zero → TRUE) and strings ("TRUE" → TRUE).
  • as.complex(x): Converts numbers to complex format (e.g., 5 → 5+0i).
R Script — Explicit Conversion Examples R
R Script
R 
# 1. Converting valid character string to numeric
x      <- "100"
number <- as.numeric(x)
cat("number:", number, "| type:", typeof(number), "
")

# 2. Converting decimal to integer (Truncation demonstration)
value  <- 25.8
result <- as.integer(value)
cat("as.integer(25.8) evaluates to:", result, "(Notice it dropped .8, did NOT round to 26)
")

# 3. Failed conversion (Non-numeric text to number)
text_val   <- "Hello"
failed_num <- as.numeric(text_val)
cat("as.numeric('Hello'):", failed_num, "
")
Console Output
R Script
R 
number: 100 | type: double 
as.integer(25.8) evaluates to: 25 (Notice it dropped .8, did NOT round to 26)
as.numeric('Hello'): NA 
Warning message:
NAs introduced by coercion

Automatic Coercion in Atomic Vectors

A fundamental rule in R is that an atomic vector can only hold elements of one single data type. When you combine elements of different types into a vector using c(), R automatically converts all elements to the least restrictive (most flexible) type according to this hierarchy:

logical → integer → double (numeric) → complex → character

R Script — Automatic Coercion R
R Script
R 
mixed_values <- c(10, 20, "Hello")
print(mixed_values)
typeof(mixed_values)
Console Output
R Script
R 
[1] "10"    "20"    "Hello"
[1] "character"

Because the character type is at the top of the hierarchy, the numbers 10 and 20 are automatically coerced into the strings "10" and "20".

6. Understanding Special Values in R

In Data Science and Artificial Intelligence, data is rarely pristine. Sensors disconnect, survey participants skip questions, mathematical divisions by zero occur, and models receive null parameters. R features a rich set of special values to handle these real-world anomalies cleanly.

A. NA (Not Available — Missing Data)

NA represents missing, unobserved, or unknown information in a dataset. It is not an error; it simply signifies that an observation could not be recorded.

R Script — Missing Values (NA) R
R Script
R 
marks <- c(80, 90, NA, 70)

print(marks)
is.na(marks)
is.na(NA)
is.na(100)
Console Output
R Script
R 
[1] 80 90 NA 70
[1] FALSE FALSE  TRUE FALSE
[1] TRUE
[1] FALSE
⚠ What NA is NOT

NA is NOT zero (0), NOT an empty string (""), and NOT FALSE. Zero is an actual measured quantity (e.g., 0 degrees Celsius or 0 dollars). An empty string is a valid text token of length zero. NA means "the measurement does not exist."

B. NULL (Absence of an Object or Value)

While NA is a placeholder inside an existing vector, NULL represents the complete absence of an object or an empty container. Its length is always 0.

R Script — NULL Object R
R Script
R

print(x)
is.null(x)
length(x)

R Script
R

[1] TRUE
[1] 0

C. NaN (Not a Number)

NaN stands for Not a Number. It occurs when a mathematical calculation produces an indeterminate or undefined numerical result (e.g., dividing zero by zero).

R Script — Undefined Math (NaN) R
R Script
R 
result <- 0 / 0

print(result)
is.nan(result)
is.na(result)
Console Output
R Script
R 
[1] NaN
[1] TRUE
[1] TRUE
🔍 Crucial R Fact: NaN is a Subset of NA

In R, is.na(NaN) returns TRUE! Why? Because for all statistical purposes, an undefined mathematical result cannot provide valid data. Thus, R treats NaN as a specialized kind of missing numeric value. However, is.nan(NA) returns FALSE.

D & E. Inf & -Inf (Positive & Negative Infinity)

When you divide a positive non-zero number by zero, R does not crash with a fatal exception. Instead, adhering to IEEE floating-point arithmetic standards, it produces Inf (positive infinity). Dividing a negative number by zero produces -Inf (negative infinity).

R Script — Infinities R
R Script
R

neg_inf <- -10 / 0

print(pos_inf)
print(neg_inf)
is.infinite(pos_inf)
is.infinite(neg_inf)
is.finite(pos_inf)

[1] TRUE

[1] FALSE

8. Handling Missing Values in R

Missing data is the single most common data quality challenge in modern Data Science. In R, any arithmetic calculation performed on a vector containing NA will propagate and return NA by default. This is an intentional safeguard: R refuses to guess your missing values without your consent!

R Script — Missing Value Handling R
R Script
R 
marks <- c(80, 90, NA, 70)

# 1. Count total missing observations
missing_count <- sum(is.na(marks))
cat("Total missing marks:", missing_count, "
")

# 2. Default calculation propagates NA
cat("Default mean(marks):", mean(marks), "
")

# 3. Explicitly removing NA from calculation using na.rm = TRUE
valid_mean <- mean(marks, na.rm = TRUE)
cat("Clean average (na.rm = TRUE):", valid_mean, "
")

# 4. Extracting only clean, non-missing observations
clean_marks <- marks[!is.na(marks)]
cat("Cleaned subset:", clean_marks, "
")
Console Output
R Script
R 
Total missing marks: 1 
Default mean(marks): NA 
Clean average (na.rm = TRUE): 80 
Cleaned subset: 80 90 70
⚠ Golden Rule of Data Science & AI: Never Replace NA with 0 Blindly!

If a student was absent for an exam (NA), replacing their score with 0 distorts the class average, standard deviation, and statistical models. In professional AI projects, data scientists carefully decide between removing missing records, imputing via mean/median, or applying specialized machine learning imputation models (e.g., MICE or KNN).

12. Common Beginner Mistakes & Traps

Trap 1: Assuming 25 is an Integer

Writing x <- 25 stores a double in memory. If you require integer storage, always write 25L.

Trap 2: Math on Text Strings

Strings like "100" cannot be added or multiplied. Cast them first using as.numeric("100").

Trap 3: Assuming as.integer() Rounds

as.integer(25.9) returns 25, not 26! Use round() if you require mathematical rounding.

Trap 4: Confusing NA with NULL

NA is a missing measurement inside data; NULL represents complete void/non-existence.
