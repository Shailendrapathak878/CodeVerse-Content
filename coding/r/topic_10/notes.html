2. What Is a Vector?

A vector is the primary basic data structure in R that stores multiple values of the same fundamental data type in an ordered one-dimensional container.

🎓 Real-Life Analogy: The Student Report Card

Imagine a student has marks across 5 subjects: Maths (85), English (78), Science (90), Computer (95), and Hindi (80). Instead of creating 5 disconnected scalar variables (m1, m2, m3, m4, m5), R bundles all 5 exam scores into one unified vector named marks.

Your First Vector in R

R Script • first_vector.R R 4.x
R Script
R 
# Combine 5 subject scores into a single vector
marks <- c(85, 78, 90, 95, 80)

# Print the vector to the console
print(marks)

# Confirm its length and fundamental data type
cat("Number of subjects:", length(marks), "\n")
cat("Storage type:", typeof(marks), "\n")
Console Output
[1] 85 78 90 95 80
Number of subjects: 5
Storage type: double

3. Why Do We Need Vectors?

Without vectors, managing 10,000 customer ages or sensor readings would require 10,000 individual variable names. Vectors provide:

  • Consolidated Storage: Store hundreds or millions of observations in a single named object.
  • Instant Math without Loops: Add sales tax to 1,000 prices in one step: prices * 1.08.
  • Data Filtering: Instantly isolate passing grades: marks[marks >= 60].
  • Machine Learning Features: Every column in a machine learning training matrix is fundamentally a vector!
🛒 E-Commerce Shopping Cart

A checkout system holds product prices c(19.99, 45.00, 12.50) and quantities c(2, 1, 4). By storing them as vectors, total line items are computed in a single vectorized multiplication: prices * quantities.

4. Characteristics of Vectors

Every standard atomic vector in R adheres to 7 fundamental rules:

  1. Multi-Element Storage: Can hold 0 (empty), 1 (scalar), or millions of elements.
  2. Type Homogeneity: All elements in an atomic vector must share the exact same basic data type. (Lists can be heterogeneous).
  3. Ordered Sequence: Elements maintain a strict, persistent left-to-right order.
  4. 1-Based Indexing: The first element is always accessed at position 1 (v[1]), not 0.
  5. One-Dimensional: A vector has a length, but its dim() attribute is NULL (no rows/columns).
  6. Vectorized Operations: Mathematical operators naturally apply element-by-element across the vector.
  7. Dynamic Sizing: Vectors can be expanded by concatenating new items using c().

5. Creating Vectors in R

R provides four primary mechanisms to construct vectors: c(), seq(), rep(), and the colon operator :.

1. The c() Combine Function

The workhorse function c() concatenates arbitrary values into a vector.

R Script • create_vectors.R
R Script
R 
# Numeric vector (doubles)
weights <- c(65.5, 72.0, 81.4)

# Character vector
cities <- c("Tokyo", "Bengaluru", "Berlin")

# Logical vector
active_flags <- c(TRUE, FALSE, TRUE, TRUE)

# Integer vector (using 'L' suffix to prevent double conversion)
counts <- c(10L, 25L, 40L)

# Empty vector
empty_nums <- numeric(0)

cat("Empty vector length:", length(empty_nums), "\n")
Console Output
Empty vector length: 0
Empty Vector vs. Zero: numeric(0) represents a completely empty container with length = 0. In contrast, c(0) is a valid vector of length = 1 containing the number zero.

2. The seq() Progression Function

When you need structured sequences with custom step sizes or specific point counts, use seq().

Indexing is the mechanism used to inspect, filter, or retrieve specific elements from a vector. R supports four distinct indexing styles: 1-based positional, multiple, negative exclusion, logical mask, and named indexing.

1. Basic Positional Indexing (1-Based)

Last score (index length): 80

3. Negative Indexing (Exclusion)

A negative integer tells R to drop or exclude elements at those positions.

R Script • negative_indexing.R
R Script
R 
v <- c(10, 20, 30, 40, 50)

# Drop the second element
without_second <- v[-2]
cat("Dropped index 2:", without_second, "\n")

# Drop first and last
without_extremes <- v[c(-1, -5)]
cat("Dropped indices 1 and 5:", without_extremes, "\n")
Console Output
Dropped index 2: 10 30 40 50
Dropped indices 1 and 5: 20 30 40
Never Mix Positive and Negative Indices: Writing v[c(1, -2)] will crash R with: Error in v[c(1, -2)] : only 0's may be mixed with negative subscripts. You must either select what to keep or select what to drop!

Sorting vs Ordering vs Deduplication

  • sort(v): Returns the values rearranged in ascending (or descending) order.
  • order(v): Returns the integer index positions that sort the vector.
  • unique(v): Returns the distinct values with duplicate occurrences stripped.
  • duplicated(v): Returns a logical vector flagging elements that have appeared previously.

cat("order(items):", order(items), "\n") # Position 2 (val 10), pos 4 (val 10)...
cat("unique(items):", unique(items), "\n")
cat("duplicated(items):", duplicated(items), "\n")
Console Output

order(items): 2 4 3 5 1
unique(items): 40 10 20 30
duplicated(items): FALSE FALSE FALSE TRUE FALSE

8. Vector Operations & The Recycling Rule

R was designed specifically for mathematics and statistics, so arithmetic operators execute in parallel across vector items.

cat("a + b :", a + b, "\n")
cat("a - b :", a - b, "\n")
cat("a * b :", a * b, "\n")
cat("a / b :", a / b, "\n")
cat("a ^ 2 :", a ^ 2, "\n")
cat("a %% 3 (Modulus):", a %% 3, "\n")
cat("a %/% 3 (Integer division):", a %/% 3, "\n")
Console Output
a + b : 11 22 33
a - b : 9 18 27
a * b : 10 40 90
a / b : 10 10 10
a ^ 2 : 100 400 900
a %% 3 (Modulus): 1 2 0
a %/% 3 (Integer division): 3 6 10

The Vector Recycling Rule

When arithmetic involves two vectors of unequal length, R automatically recycles (repeats) the shorter vector until its length matches the longer one.

R Script • recycling_rule.R
R Script
R 
long_v  <- c(10, 20, 30, 40)
short_v <- c(1, 2) # Length 2 is an exact submultiple of 4

# short_v is recycled to c(1, 2, 1, 2)
result <- long_v + short_v
cat("Clean recycling (10+1, 20+2, 30+1, 40+2):", result, "\n")

# What happens if lengths are NOT clean multiples?
# c(10, 20, 30) + c(1, 2)
# Produces: [1] 11 22 31
# Warning message: longer object length is not a multiple of shorter object length
Console Output
Clean recycling (10+1, 20+2, 30+1, 40+2): 11 22 31 42
Recycling Best Practice: While recycling by scalar (length 1) is standard idiom (e.g. v * 2), recycling multi-element vectors of unequal lengths should be avoided in production scripts unless explicitly intended, as it frequently masks alignment bugs!

9. Modifying Vectors

R atomic vectors are immutable in memory at a micro level, but can be updated, expanded, and trimmed via assignment statements.

R Script • modifying_vectors.R
R Script
R 
# 1. Update element by position
scores <- c(80, 75, 90)
scores[2] <- 85
cat("Updated score at index 2:", scores, "\n")

# 2. Append new elements
scores <- c(scores, 95)
cat("Appended 95 to end:", scores, "\n")

# 3. Prepend elements to front
scores <- c(100, scores)
cat("Prepended 100 to front:", scores, "\n")

# 4. Remove elements by re-assigning negative index
scores <- scores[-1]
cat("Removed front element:", scores, "\n")
Console Output
Updated score at index 2: 80 85 90
Appended 95 to end: 80 85 90 95
Prepended 100 to front: 100 80 85 90 95
Removed front element: 80 85 90 95

10. Type Coercion in Vectors

Because atomic vectors must remain homogeneous, combining different basic data types forces R to automatically convert all elements to a common denominator.

Implicit Coercion Hierarchy

R coerces toward greater flexibility to prevent information loss:

Combination Coerced Type Example Code Resulting Vector
Logical + Integer Integer c(TRUE, 5L, FALSE) c(1L, 5L, 0L)
Integer + Double Double (Numeric) c(10L, 25.5) c(10.0, 25.5)
Numeric + Character Character c(42, "CodeVerse", 99) c("42", "CodeVerse", "99")
Logical + Character Character c(TRUE, "Hello") c("TRUE", "Hello")

Explicit Type Conversion

Convert types intentionally using explicit casting functions:

R Script • explicit_casting.R
R Script
R 
str_nums <- c("10", "20", "30.5")
real_nums <- as.numeric(str_nums)
cat("Explicitly converted to numeric:", real_nums * 2, "\n")

int_vals <- as.integer(c(1.1, 2.9, 3.5)) # Truncates decimal part!
cat("as.integer():", int_vals, "\n")

log_vals <- as.logical(c(0, 1, 5, 0)) # 0 becomes FALSE; non-zero becomes TRUE
cat("as.logical():", log_vals, "\n")
Console Output
Explicitly converted to numeric: 20 40 61
as.integer(): 1 2 3
as.logical(): FALSE TRUE TRUE FALSE

11. Missing Values (NA) in Vectors

Real-world datasets are littered with missing, corrupted, or uncollected measurements. R reserves the special constant NA (Not Available) to represent missing data.

R Script • missing_values.R
R Script
R 
readings <- c(85, 90, NA, 75, NA, 92)

# 1. Detection
cat("is.na() mask:", is.na(readings), "\n")
cat("Are there any NAs?", anyNA(readings), "\n")
cat("Count of missing values:", sum(is.na(readings)), "\n")

# 2. Arithmetic Propagation
cat("mean(readings) default:", mean(readings), "\n") # Returns NA!

# 3. Calculation with na.rm = TRUE
cat("mean(readings, na.rm = TRUE):", mean(readings, na.rm = TRUE), "\n")

# 4. Filtering out missing entries
clean_readings <- readings[!is.na(readings)]
cat("Clean vector:", clean_readings, "\n")
Console Output
is.na() mask: FALSE FALSE TRUE FALSE TRUE FALSE
Are there any NAs? TRUE
Count of missing values: 2
mean(readings) default: NA
mean(readings, na.rm = TRUE): 85.5
Clean vector: 85 90 75 92

15. 15 Common Beginner Mistakes & Traps

Watch out for these 15 frequent misconceptions and syntax traps:

# Mistake / Trap Flawed Code Correct Solution Why It Matters
1 Assuming 0-Based Indexing v[0] expecting the first element v[1] R is 1-based; v[0] returns an empty vector of the same type.
2 Forgetting c() to Combine x <- (10, 20, 30) x <- c(10, 20, 30) Parentheses alone cannot combine items; c() is mandatory.
3 Unintended String Coercion c(1, 2, "3") → all become text Keep numbers separate: c(1, 2, 3) Atomic vectors are homogeneous; text coerces all numbers into strings.
4 Confusing Length with Highest Value Assuming length(v) returns max(v) Use length(v) for count and max(v) for highest value Length measures count of items, not their numerical magnitude.
5 Mixing Positive & Negative Indices v[c(1, -2)] Use either v[c(1, 3)] or v[-2] R forbids mixing inclusion and exclusion in a single subscript.
6 Testing Missing Data with x == NA if (x == NA) ... if (is.na(x)) ... Comparison with unknown data yields NA, never TRUE.
7 Forgetting na.rm = TRUE mean(c(1, 2, NA)) → returns NA mean(c(1, 2, NA), na.rm = TRUE) Missing values propagate through arithmetic unless explicitly ignored.
8 Expecting sort() to Modify In-Place sort(v) without assignment v <- sort(v) R does not alter variables in place; you must assign the return value back.
9 Confusing which() with Logical Mask v[which(v > 5)] vs v[v > 5] Both work, but v > 5 is simpler unless managing NAs which() converts booleans to integer index positions.
10 Confusing which.max() with max() m <- which.max(v) expecting largest value Use max(v) for value; which.max(v) returns index position which.max() returns the index, not the actual maximum number.
11 Misunderstanding rep(times=) vs rep(each=) rep(c(1, 2), 2) expecting c(1, 1, 2, 2) Use each = 2 for element duplication Default second argument is times, repeating the full block.
12 Unintended Vector Recycling Adding length 3 to length 4 vector Verify vector lengths match before arithmetic Silently repeats short vector and emits an uneven multiple warning.
13 Using Scalar && Instead of Vector & marks > 50 && marks < 90 marks > 50 & marks < 90 Double && only evaluates element 1, ignoring the rest of the vector.
14 Assuming Index Out-of-Bounds Always Crashes v[10] when length(v) == 3 Inspect length(v) first R quietly returns NA instead of throwing an out-of-bounds error!
15 Neglecting Integer 'L' Suffix c(1, 2, 3) expecting integers c(1L, 2L, 3L) Bare numbers default to 64-bit floating-point doubles in R.

16. Quick Revision & Key Takeaways

Operation Function / Syntax Primary Purpose Key Memory Rule
Create Vector c(...) Combine individual elements into 1D array Homogeneous atomic type only
Sequence seq(from, to, by) Generate structured numeric progression Supports negative steps & length.out
Repeat rep(x, times, each) Replicate vector patterns times = whole block; each = element-wise
Unit Sequence from:to Fast integer sequence Auto-detects ascending & descending
Length length(v) Count total elements Last element is v[length(v)]
Indexing v[index] Extract elements by position, name, or mask 1-based indexing; negative drops item
Sort sort(v, decreasing) Rearrange elements Returns values; not in-place
Unique unique(v) Strip duplicate entries Preserves first appearance order
Missing Check is.na(v) Identify missing NA cells Never use v == NA
Index Search which(cond) Find index positions where TRUE Converts boolean mask to integers
