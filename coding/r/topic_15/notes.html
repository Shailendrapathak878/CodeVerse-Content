1. Topic Introduction

In real-world data science and artificial intelligence workflows, data rarely originates inside R. Instead, data lives in external files—spreadsheets maintained by marketing teams, CSV telemetry streams generated by IoT devices, multi-sheet Excel reports from finance departments, or JSON payloads delivered by cloud REST APIs.

Data Import is the process of bringing these external files into R's active memory (RAM) as structured data frames or tibbles. Data Export is the process of writing processed, cleaned, and modeled data back to permanent storage so it can be shared with colleagues, deployed to dashboards, or ingested by machine learning production servers.

2. Learning Objectives

  • Master the complete lifecycle of data ingestion and persistence in R.
  • Navigate the operating system with getwd(), setwd(), file.exists(), and list.files().
  • Understand the critical distinction between brittle absolute paths and portable relative paths.
  • Import and export Comma-Separated Values (CSV) using Base R read.csv() and write.csv() with customized arguments.
  • Parse plain text tables and Tab-Separated Values (TSV) using read.table(), read.delim(), and write.table().
  • Read multi-worksheet Excel workbooks with readxl::read_excel() and write clean spreadsheets using writexl::write_xlsx().
  • Preserve pure R objects and factor levels losslessly with binary serialization via saveRDS() and readRDS().
  • Exchange hierarchical web and API data using jsonlite::fromJSON() and jsonlite::toJSON().
  • Leverage the high-performance tidyverse readr package (read_csv(), problems()) for modern data wrangling.
  • Diagnose character encoding pitfalls (UTF-8 vs Mojibake) and common file connection errors.
  • Construct production-ready training and testing dataset export splits for machine learning without data leakage.

3. What Is Data Import?

Data import is the operation of reading structured bytes from a storage medium (hard drive, solid-state drive, network share, or URL) and loading them into R's memory as a first-class tabular object (typically a data.frame or tbl_df).

External Storage (Disk)

Data is stored in bytes as plain text, binary tables, or compressed archives (e.g. .csv, .xlsx, .rds, .json). It is non-volatile but cannot be queried directly with R functions.

Import Engine

A specialized parser (like read.csv() or readxl::read_excel()) scans delimiters, infers column types, handles missing values, and allocates RAM.

In-Memory R Object (RAM)

The resulting 2D tabular object is assigned to an R variable, immediately available for visualization, statistical modeling, or machine learning.

4. What Is Data Export?

Data export is the reverse operation: serializing an in-memory R object (data frame, matrix, list, or trained predictive model) into an external file format on disk for permanent archiving, stakeholder reporting, or downstream application consumption.

5. File Paths and Working Directory

Before R can read or write a file, it must know exactly where the file resides in the operating system's file tree. This is governed by file paths and the active working directory.

Windows File Path Rule: In R string literals, the backslash \ is an escape operator (e.g. \n for newline). Always use forward slashes / (e.g., "C:/Users/Student/data.csv") or escaped double backslashes "C:\\Users\\Student\\data.csv". Forward slashes are portable across Windows, macOS, and Linux!
R Script
R 
# Inspecting and managing directories
current_dir <- getwd()
cat("Current Working Directory:", current_dir, "\n")

# Check if a target data file exists before reading
if (file.exists("data/customers.csv")) {
  message("File found! Ready for ingestion.")
} else {
  warning("File not found! Verify your working directory.")
}

# List all CSV files in the working directory
csv_files <- list.files(pattern = "\\.csv$")
print(csv_files)
Current Working Directory: D:/CodeVerse-Content File found! Ready for ingestion. [1] "customers.csv" "sales_2026.csv" "students.csv"

6. CSV Import and Export with Base R

Comma-Separated Values (CSV) is the universal tabular format in computing. Base R provides read.csv() for ingestion and write.csv() for persistence.

R Script
R 
# 1. Exporting data to CSV cleanly
students <- data.frame(
  name  = c("Rahul", "Priya", "Aman"),
  age   = c(20, 21, 19),
  marks = c(85, 91, 78)
)
# CRITICAL: Always specify row.names = FALSE to avoid creating an extra index column!
write.csv(students, "students.csv", row.names = FALSE)

# 2. Ingesting CSV with custom parameters
imported_data <- read.csv(
  file = "students.csv",
  header = TRUE,
  sep = ",",
  stringsAsFactors = FALSE,
  na.strings = c("", "NA", "NULL", "-99")
)
print(imported_data)
str(imported_data)
name age marks 1 Rahul 20 85 2 Priya 21 91 3 Aman 19 78 'data.frame': 3 obs. of 3 variables: $ name : chr "Rahul" "Priya" "Aman" $ age : int 20 21 19 $ marks: int 85 91 78

Excel files (.xlsx, .xls) are complex container workbooks containing multiple named sheets, formulas, and formatting.

Package Division of Labor: readxl is strictly for reading Excel files without requiring Java. writexl is used for writing clean Excel spreadsheets. Remember: readxl does NOT write Excel files!

9. Pure R Data Formats: RDS and RData

When continuing an analysis in R, saving data to CSV is sub-optimal because CSV strips custom factor levels, class tags, and timezone attributes. Base R provides native binary serialization via saveRDS() and readRDS().

R Script
R 
# 1. saveRDS() saves a single object with gzip compression
ordered_df <- data.frame(
  tier = factor(c("Bronze", "Gold"), levels = c("Bronze", "Silver", "Gold"), ordered = TRUE)
)
saveRDS(ordered_df, "customer_tiers.rds")

# 2. readRDS() restores the object losslessly into any chosen variable name
restored_df <- readRDS("customer_tiers.rds")
levels(restored_df$tier) # Factor levels and ordering are 100% preserved!

# 3. save() and load() for multi-object workspace snapshots (.RData)
v1 <- 1:10
v2 <- "CodeVerse"
save(v1, v2, file = "workspace_snapshot.RData")
rm(v1, v2)
load("workspace_snapshot.RData") # Injects v1 and v2 back into environment
[1] "Bronze" "Silver" "Gold"

10. JSON Import and Export (jsonlite)

JavaScript Object Notation (JSON) is the dominant data standard for web APIs, microservices, cloud databases (MongoDB), and LLM response payloads. In R, the jsonlite package provides complete bidirectional translation.

R Script
R 
library(jsonlite)

# 1. Ingesting JSON from file, text string, or live REST URL
json_data <- fromJSON('{"user":"Rahul", "scores":[85, 91, 78], "active":true}')
print(json_data$user)
print(json_data$scores)

# 2. Serializing an R data frame to pretty formatted JSON
students_json <- toJSON(students, pretty = TRUE)
cat(students_json)

# 3. Writing JSON to an external file
write(students_json, "students.json")

11. Fast Ingestion with the readr Package

The tidyverse readr package re-engineers rectangular text reading. It is significantly faster on large datasets, outputs modern tibbles, and provides detailed column parsing audits.

R Script
R 
library(readr)

# 1. High-speed CSV parsing
fast_tbl <- read_csv("students.csv", col_types = cols(
  name  = col_character(),
  age   = col_double(),
  marks = col_double()
))
print(fast_tbl)

# 2. Inspect parsing warnings and problems
parsing_issues <- problems(fast_tbl)
print(parsing_issues) # Empty tibble means zero errors!

# 3. Exporting with write_csv() (Never outputs row numbers by default!)
write_csv(fast_tbl, "fast_clean_students.csv")
# A tibble: 3 x 3 name age marks <chr> <dbl> <dbl> 1 Rahul 20 85 2 Priya 21 91 3 Aman 19 78 # A tibble: 0 x 5 # ... with 5 variables: row, col, expected, actual, file

12. File Encoding & Character Sets

A character encoding scheme maps binary bit sequences to human letters. If an external file encoded in UTF-8 is read using an ANSI/Latin-1 assumption, accented and non-English text corrupts into unreadable symbols (known as mojibake).

R Script
R 
# Multi-lingual international text handling
intl_df <- data.frame(
  lang = c("Hindi", "French", "Japanese"),
  greeting = c("नमस्ते", "Bonjour", "こんにちは")
)
# Save explicitly with UTF-8 encoding
write.csv(intl_df, "intl_data.csv", fileEncoding = "UTF-8", row.names = FALSE)

# Ingest explicitly specifying fileEncoding
imported_intl <- read.csv("intl_data.csv", fileEncoding = "UTF-8")
print(imported_intl)
lang greeting 1 Hindi नमस्ते 2 French Bonjour 3 Japanese こんにちは

13. Common Import Errors & Diagnostic Fixes

Understanding and diagnosing import failures is an essential debugging skill for data scientists.

Error: cannot open connection / No such file or directory

Diagnosis: The target path does not exist or your active working directory is different from what you expect.

Fix: Run getwd() to check where R is looking. Run file.exists("file.csv"). Use relative paths matching your project root.

Symptom: Table has 1 giant column instead of 10

Diagnosis: Delimiter mismatch! The file is separated by semicolons (;) or tabs (\t), but you used comma separation.

Fix: Inspect the first row in a text editor or use read.csv2() / read.delim().

Symptom: First row of data missing, column headers look like data

Diagnosis: The raw file did not have a header line, but read.csv() assumed header = TRUE by default.

Fix: Specify header = FALSE when importing.

Symptom: Numeric column imported as character type

Diagnosis: A cell contains a character placeholder like "NULL", "N/A", or a stray typo.

Fix: Add the placeholder token to na.strings = c("NA", "NULL", "N/A").

14. Complete Practical Import/Export Workflow

Below is a production-grade 6-step workflow that verifies file presence, ingests raw data, audits quality, cleans invalid values, and exports dual CSV/RDS deliverables.

R Script
R 
# Step 1: Pre-flight existence check
target_file <- "data/raw_customers.csv"
if (!file.exists(target_file)) {
  # Generate sample dataset if absent
  dir.create("data", showWarnings = FALSE)
  write.csv(data.frame(id = 1:3, spend = c(100, NA, 300)), target_file, row.names = FALSE)
}

# Step 2: Ingest with missing value rules
raw_data <- read.csv(target_file, na.strings = c("", "NA"))

# Step 3: Audit dimensions and missingness
cat("Raw shape:", nrow(raw_data), "x", ncol(raw_data), "\n")
cat("Missing spend count:", sum(is.na(raw_data$spend)), "\n")

# Step 4: Impute missing spend with median
clean_data <- raw_data
clean_data$spend[is.na(clean_data$spend)] <- median(clean_data$spend, na.rm = TRUE)

# Step 5: Dual Export (CSV for external consumers, RDS for internal R pipelines)
dir.create("output", showWarnings = FALSE)
write.csv(clean_data, "output/clean_customers.csv", row.names = FALSE)
saveRDS(clean_data, "output/clean_customers.rds")

# Step 6: Reload and validate integrity
validated_data <- readRDS("output/clean_customers.rds")
stopifnot(sum(is.na(validated_data$spend)) == 0)
message("Pipeline successfully completed with zero missingness!")
Raw shape: 3 x 2 Missing spend count: 1 Pipeline successfully completed with zero missingness!

17. 22 Common Beginner Mistakes & Fixes

1. Backslash Path Collisions

Mistake: read.csv("C:\data\file.csv")

Fix: Use forward slashes: read.csv("C:/data/file.csv").

2. Unwanted Row Number Column in CSV

Mistake: Calling write.csv(df, "file.csv") without row.names.

Fix: Always specify write.csv(df, "file.csv", row.names = FALSE).

3. Assuming readxl Can Write Excel

Mistake: Calling readxl::write_excel() → Fails!

Fix: Use writexl::write_xlsx() to export Excel files.

4. Wrong Delimiter Ingestion

Mistake: Reading a semicolon file with read.csv().

Fix: Use read.csv2() or read.table(..., sep = ";").

5. Missing Header Omission

Mistake: Reading headerless file with default header=TRUE.

Fix: Pass header = FALSE to preserve the first data row.

6. Silently Overwriting Raw Data

Mistake: Saving cleaned data over raw_data.csv.

Fix: Maintain immutable raw files; export to clean_data.csv.

7. Assuming RDS Opens in Excel

Mistake: Trying to open model.rds in Microsoft Excel.

Fix: RDS is pure binary for R; export to CSV for Excel users.

8. Missing Values Parsed as Characters

Mistake: Cells containing "NULL" causing numeric column to become char.

Fix: Add na.strings = c("NA", "NULL").

9. Corrupted Characters (Mojibake)

Mistake: Non-English text reading as strange symbols.

Fix: Specify fileEncoding = "UTF-8".

10. Hardcoded Collaborator Paths

Mistake: read.csv("C:/Users/Rahul/data.csv") crashing on other PCs.

Fix: Use relative paths: read.csv("data/data.csv").

11. Forgetting to Load Library

Mistake: Calling fromJSON() without library(jsonlite).

Fix: Explicitly load required packages at top of script.

12. Data Leakage across Splits

Mistake: Calculating imputation mean before train/test splitting.

Fix: Split first, learn parameters on train set, apply to test set.

13. Misinterpreting load() vs readRDS()

Mistake: Writing x <- load("file.RData").

Fix: load() restores original names directly; readRDS() returns the object.

14. Incomplete File Extensions

Mistake: Writing read.csv("customers") without .csv.

Fix: Always specify complete file extension "customers.csv".

15. Ignoring readr Parsing Problems

Mistake: Ignoring warnings in read_csv().

Fix: Inspect row and column mismatches using problems().

16. Trailing Whitespace in Files

Mistake: Space after commas creating unintended categories ("Yes ").

Fix: Use strip.white = TRUE in read.csv().

17. Blind na.omit() Row Purging

Mistake: Purging 80% of rows because 1 unimportant column had NAs.

Fix: Select relevant features first or impute selectively.

18. Attempting to Parse Huge JSON without Streaming

Mistake: 10GB JSON loaded all at once in RAM.

Fix: Use chunked/streamed JSON readers or convert to Parquet.

19. Mismatched Excel Sheet Indices

Mistake: Reading sheet = 1 when data is on "Summary".

Fix: Discover sheet names first with excel_sheets().

20. Confusing RData with RDS

Mistake: Calling readRDS() on an .RData workspace.

Fix: Use readRDS() for .rds and load() for .RData.
