1. Introduction to R Syntax

In computer programming, syntax refers to the set of grammatical rules, symbols, and conventions that govern how code must be structured so that the interpreter can understand and execute it.

Just as human languages follow grammar rules (such as subject-verb-object order in English), R demands adherence to its specific grammatical framework. If you forget a quotation mark, misspell a function name, or leave a parenthesis open, R cannot guess your intent and will halt with a syntax error.

Grammar Analogy: Human Language vs R Syntax

If you say "Book the read I", a human might piece together your meaning through intuition. But a programming language interpreter is literal. If you write print("Hello" without closing the parenthesis, R pauses and refuses to execute until the grammatical syntax is satisfied.

2. Structure of an R Program

A well-structured R program is composed of five foundational building blocks:

  • Comments (#): Explanatory notes that the interpreter ignores.
  • Statements: Complete instructions that tell R to take action (e.g. printing or creating variables).
  • Assignment Operator (<-): Stores data values into memory variables.
  • Expressions: Mathematical or logical combinations that evaluate to a value (e.g. x + y).
  • Function Calls: Reusable routines that perform actions when passed arguments inside parentheses (e.g. print(...)).

# Step 4: Display the final result to the console
print(result)

4. Understanding Statements and Expressions

In R terminology:

  • An Expression is a snippet of code that R evaluates to produce a value (e.g. 10 + 20, sqrt(16)). Expressions do not necessarily save their result into memory unless assigned.
  • A Statement is a complete instruction that carries out an action, such as variable assignment (total <- 50) or displaying text to the screen (print("Done")).

5. Understanding Comments in R

Comments are non-executable text annotations written to explain why code was written in a certain way. In R, any line or portion of a line preceded by the hash character # is a comment.

Poor Comment: x <- 10 # set x to 10 (stating the obvious syntax).
Great Comment: x <- 10 # Baseline minimum patient cohort size (explaining the business context).

6. Understanding Code Execution Order

R executes instructions sequentially from top to bottom. A statement cannot reference a variable that has not yet been created in an earlier line:

R Script

[1] "Step 3: Train statistical model"
Order Dependency Trap

If you write total <- price * qty before defining price <- 50, R halts with an error: object 'price' not found. Always define variables before consuming them!

9. Understanding Basic R Code Formatting

Writing clean, readable code is a prerequisite for professional data analysis. While the R interpreter ignores spaces and blank lines, human colleagues depend on clean formatting for reproducibility and bug detection:

  • Spaces around Operators: Write x <- 10 + 20 rather than the cramped x<-10+20.
  • Spaces after Commas: Write round(12.567, 2) instead of round(12.567,2).
  • Consistent Naming: Use snake_case for variable names (e.g. student_marks, total_sales).
  • Section Breaks: Group related calculations with blank lines to create logical paragraphs.

10. Understanding Basic R Errors

Encountering syntax errors is a natural part of programming. When an error occurs, R prints a diagnostic message indicating what went wrong. Here are the 4 most frequent beginner syntax mistakes and how to fix them:

1. Missing Closing Parenthesis

Incorrect: print("Hello World"
Symptom: The console switches from > to the + continuation prompt waiting for closure.
Fix: Supply the closing parenthesis: print("Hello World") or hit Esc.

2. Case Sensitivity Mistake

Incorrect: Print("Welcome")
Error Message: Error in Print("Welcome") : could not find function "Print"
Fix: Built-in R functions are lowercase: print("Welcome").

3. Missing Quotation Mark

Incorrect: print("Hello)
Fix: Ensure all opening quotes have matching closing quotes: print("Hello").

4. Missing Binary Operator

Incorrect: x <- 5(10) (trying to multiply without *)
Fix: Explicitly specify the arithmetic operator: x <- 5 * 10.

11. Writing and Running R Scripts

In real data science, interactive console commands are temporary. Production data pipelines, machine learning experiments, and executive charts are stored inside R Script files (with the .R extension).

The standard professional development lifecycle follows 5 clean steps:

  1. Create: In RStudio, press Ctrl + Shift + N to open a fresh script editor tab.
  2. Write: Type comments, data assignments, and calculations.
  3. Save: Press Ctrl + S to save the script (e.g. pipeline.R).
  4. Run: Highlight code lines and hit Ctrl + Enter to execute incrementally.
  5. Batch Run: Run the complete script from the operating system command line using Rscript pipeline.R.

Output Prediction Challenges

Challenge 1: Sequential Assignment Override

What will the following code output to the R console?

R Script
R 
x <- 15
x <- x + 5
print(x)
View Output & Explanation
Output: [1] 20
Explanation: In line 1, x is allocated the value 15. In line 2, R evaluates the right side x + 5 (which is 15 + 5 = 20) and reassigns 20 into x. Line 3 prints the updated value 20.
Challenge 2: Semicolon Compact Evaluation

What will be displayed by this statement?

R Script
R 
a <- 4; b <- sqrt(a); print(b * 10)
View Output & Explanation
Output: [1] 20
Explanation: a is assigned 4. sqrt(4) evaluates to 2 and is stored in b. Finally, b * 10 (2 * 10) evaluates to 20 and is printed.
Challenge 3: print() vs cat() Behavior

What is the difference in output between these two lines?

R Script
R 
print("Data Science")
cat("Data Science\n")
View Output & Explanation
Output:
[1] "Data Science" (from print)
Data Science (from cat)
Explanation: print() adds vector indexing brackets [1] and quotes, while cat() streams clean raw characters without quotation marks or vector metadata.
Challenge 4: Built-in Summary Vector Functions

What is the output of the following statistical statement?

R Script
R 
vals <- c(10, 20, 30, 40)
print(sum(vals) / length(vals))
View Output & Explanation
Output: [1] 25
Explanation: sum(vals) = 100. length(vals) = 4. 100 / 4 = 25. This demonstrates manual implementation of the arithmetic mean!
Challenge 5: Case Sensitivity Verification

What happens when you run Round(12.345, 1)?

View Output & Explanation
Output: Error in Round(12.345, 1) : could not find function "Round"
Explanation: R is case-sensitive. The standard function is round() with a lowercase 'r'.
