3. Tabular Data: Rows, Columns, and Cells

Tabular data is information arranged in a 2-dimensional grid of rows and columns, exactly like a spreadsheet or SQL relational database table.

Row (Observation / Record)

A horizontal slice representing a single entity. For example, Row 2 contains all measurements for "Priya" (Age: 21, Course: BCA, Marks: 91). Indexed as df[2, ].

Column (Variable / Feature)

A vertical slice representing an individual measured attribute across all entities. For example, the age column holds c(20, 21, 19). Indexed as df$age or df[, 2].

Cell (Single Value)

The intersection of one row and one column. Cell [2, 3] holds the string value "BCA". Indexed as df[2, 3].

4. What Is a Data Frame in R?

In R, a data frame is a two-dimensional tabular data structure where columns are stored as a named list of equal-length vectors. While a matrix requires every single cell to share the exact same atomic type, a data frame is heterogeneous across columns: Column 1 can be character, Column 2 numeric, Column 3 logical, and Column 4 a factor.

Internal R Architecture: Under the hood, typeof(df) returns "list", while class(df) returns "data.frame". This proves a data frame is a list of equal-length column vectors bound with 2D attributes!

5. Creating Data Frames with data.frame()

Data frames are initialized using the data.frame(...) constructor function. Column names are assigned via named arguments.

R Script
R 
# Creating a simple student data frame
students <- data.frame(
  name  = c("Rahul", "Priya", "Aman"),
  age   = c(20, 21, 19),
  marks = c(85, 91, 78)
)
print(students)
name age marks 1 Rahul 20 85 2 Priya 21 91 3 Aman 19 78

Recycling & Length Rules: All columns passed into data.frame() must either have the exact same length, or length 1 (which R will recycle to fill all rows). If you pass vectors of differing lengths (e.g., 3 and 4), R halts with an error: arguments imply differing number of rows.

8. Accessing Rows and Columns ($, [[ ]], [ ], drop = FALSE)

R provides three primary operators to extract information from data frames: the dollar sign $, double brackets [[ ]], and single brackets [ ].

R Script
R 
# Accessing data frame elements
students <- data.frame(name = c("Rahul", "Priya"), marks = c(85, 91))

# 1. Dollar sign ($): Returns vector
students$marks         # [1] 85 91

# 2. Double brackets ([[ ]]): Returns vector (supports variables)
col <- "marks"
students[[col]]        # [1] 85 91

# 3. Single bracket ([ ]): Preserves 1-column data frame!
students["marks"]      # class: "data.frame"

# 4. Matrix-style 2D indexing [row, col]
students[1, 2]         # [1] 85 (Single cell)
students[1, ]          # Row 1 (all columns)
students[, 2, drop = FALSE] # Column 2 preserved as data frame!
[1] 85 91 [1] 85 91 marks 1 85 2 91 [1] 85 name marks 1 Rahul 85 marks 1 85 2 91

9. Modifying Data Frames: Adding, Updating & Deleting

Data frames in R are mutable via reassignment. You can add new columns, modify existing values, append rows with rbind(), and delete columns by assigning NULL.

R Script
R 
# Data frame manipulation demonstration
df <- data.frame(name = c("Rahul", "Priya"), marks = c(85, 91))

# Add a new column
df$city <- c("Delhi", "Mumbai")

# Update a value
df$marks[1] <- 95

# Add a row using rbind()
new_row <- data.frame(name = "Aman", marks = 78, city = "Lucknow")
df <- rbind(df, new_row)

# Delete a column
df$city <- NULL

# Delete row 2 using negative indexing
df <- df[-2, ]

# Rename column 1
names(df)[1] <- "student_name"
print(df)
student_name marks 1 Rahul 95 3 Aman 78

11. Missing Values (NA) and Data Cleaning

Real-world datasets frequently contain missing values (NA). Unhandled missing values propagate through calculations and produce NA in sums, means, and machine learning algorithms.

R Script
R 
# Missing value detection and treatment
customers <- data.frame(
  name     = c("A", "B", "C", "D"),
  age      = c(22, NA, 25, 30),
  spending = c(500, 700, NA, 900)
)

# 1. Audit missingness per column
colSums(is.na(customers))

# 2. Complete cases removal with na.omit()
clean_rows <- na.omit(customers)

# 3. Simple mean imputation for age
customers$age[is.na(customers$age)] <- mean(customers$age, na.rm = TRUE)
print(customers)
name age spending 1 A 22.00000 500 2 B 25.66667 700 3 C 25.00000 NA 4 D 30.00000 900
Data Science Notice on Imputation: Mean imputation across the entire dataset is demonstrated here for basic educational mechanics. In real Machine Learning pipelines, imputation parameters must be learned exclusively from the training split to prevent data leakage!

12. Introduction to Tibbles: The Modern Data Frame

A tibble (class tbl_df) is a modern evolution of the classic data frame, introduced by Hadley Wickham and the Tidyverse core team. Tibbles preserve everything that makes data frames great while redesigning legacy behaviors that cause frustration in production.

1. Polite Screen Printing

Printing a 1-million-row base data frame crashes your console terminal. A tibble politely prints only the first 10 rows and fits columns to your screen width.

2. Column Type Previews

Every column header displays its data type directly beneath the name (e.g., <chr>, <dbl>, <int>, <fct>), eliminating constant calls to str().

3. Predictable Subsetting

Subsetting a tibble with tbl[, 1] always returns a 1-column tibble. It never silently simplifies to an atomic vector!

13. Creating and Converting Tibbles (tibble(), as_tibble())

Tibbles are constructed using the tibble(...) function from library(tibble) or converted from existing data frames using as_tibble().

R Script
R 
# Creating and converting tibbles
library(tibble)

# 1. Sequential column creation (x can be referenced immediately by y!)
t <- tibble(
  x = 1:3,
  y = x * 10,
  label = c("Low", "Med", "Hi")
)
print(t)

# 2. Conversion between formats
df <- as.data.frame(t)  # Convert tibble to classic data frame
tbl <- as_tibble(df)    # Convert data frame to modern tibble
# A tibble: 3 x 3 x y label <int> <dbl> <chr> 1 1 10 Low 2 2 20 Med 3 3 30 Hi

14. Data Frame vs. Tibble: Key Architectural Differences

The table below provides a comprehensive comparison between Base R data frames and Tidyverse tibbles.

Feature Base R data.frame Tidyverse tibble (tbl_df)
Inheritance class: "data.frame" Inherits: c("tbl_df", "tbl", "data.frame")
Default Terminal Print Dumps all rows (floods terminal) Politely prints 10 rows and column data types
Subsetting df[, 1] Simplifies to atomic vector unless drop=FALSE Never simplifies; always returns a 1-column tibble
Partial Matching with $ Allowed (df$m matches marks) → dangerous! Disabled (returns NULL and throws warning)
Row Names Supported via rownames() Deprecated in favor of explicit ID columns
Sequential Column Creation Fails (cannot refer to earlier columns) Supported natively (e.g. tibble(x=1:3, y=x*2))

15. Introduction to dplyr: The Grammar of Data Manipulation

The dplyr package (part of the Tidyverse) provides a standardized, fast, and human-readable grammar for tabular data manipulation. Rather than wrestling with nested brackets and commas, dplyr provides dedicated action verbs.

Core Golden Rule: select() operates vertically on COLUMNS (variables). filter() operates horizontally on ROWS (observations). Never confuse the two!

17. Grouped Summaries: group_by() and summarise()

The Split-Apply-Combine strategy is implemented in R via group_by() and summarise(). First, the table is virtually partitioned into groups by a categorical column; then, summary statistics (means, counts, totals) are calculated per group.

R Script
R 
# Grouped aggregation pipeline
sales 
  group_by(category) |>
  summarise(
    total_sales = sum(amount),
    avg_sale    = mean(amount),
    count       = n(),
    .groups     = "drop"
  )
print(result)
# A tibble: 2 x 4 category total_sales avg_sale count <chr> <dbl> <dbl> <int> 1 Clothing 1200 600 2 2 Electronics 2500 1250 2

18. The Native Pipe Operator (|>)

Introduced natively in R 4.1.0, the pipe operator |> passes the result of the left-hand expression as the first argument to the right-hand function call. This transforms deeply nested, unreadable code into a clean, left-to-right processing assembly line.

R Script
R 
# Native pipe workflow (|>)
cleaned_report 
  filter(marks >= 80) |>
  mutate(status = "Honors") |>
  arrange(desc(marks)) |>
  select(name, marks, status)

print(cleaned_report)
# A tibble: 3 x 3 name marks status <chr> <dbl> <chr> 1 Priya 91 Honors 2 Neha 88 Honors 3 Rahul 85 Honors

21. Data Frame and Tibble Best Practices

  • 1. Meaningful Snake_Case Headers: Use descriptive column names like customer_id or monthly_revenue. Avoid spaces or cryptic abbreviations.
  • 2. Single Variable per Column: Ensure each column represents exactly one measurable concept with a uniform unit of measurement.
  • 3. Enforce Strict Data Types: Convert discrete categories to factors (as.factor()) and whole numbers to integers (as.integer()) to save memory.
  • 4. Use glimpse() for Rapid Audits: In the tidyverse, glimpse(df) provides a transposed overview of all column types and values.
  • 5. Check Dimensions Before Transformation: Always run dim(df) before and after filtering or joining to verify row counts.
  • 6. Audit Missingness First: Run colSums(is.na(df)) before running statistical models to avoid silent row omissions.
  • 7. Prevent Data Leakage: When preparing ML datasets, calculate imputation statistics (e.g. mean) exclusively from the training split.
  • 8. Prefer Dedicated ID Columns: Avoid relying on row names; store entity identifiers in explicit columns (e.g., patient_id).
  • 9. Immutable Raw Backups: Never overwrite your original imported dataset; assign cleaned results to new variables.
  • 10. Pipe for Readability: Use the native pipe operator |> to create clean, debuggable data processing pipelines.

22. 24 Common Beginner Mistakes & Fixes

1. Unequal Column Lengths in data.frame()

Mistake: data.frame(x=1:3, y=1:4)

Fix: Ensure all input vectors have identical lengths or length 1.

2. Forgetting the Comma in [row, col]

Mistake: df[df$marks > 80] (treated as column index!)

Fix: df[df$marks > 80, ] (always include row comma).

3. Unexpected Vector Simplification

Mistake: Assuming df[, 1] stays a data frame in Base R.

Fix: Use df[, 1, drop = FALSE] or use tibbles.

4. Confusing select() and filter()

Mistake: filter(df, name, marks) → Error!

Fix: select() for columns; filter() for rows.

5. Partial Matching Trap with $

Mistake: df$m accidentally matches marks in Base R.

Fix: Use tibble which blocks partial matching, or use df[["marks"]].

6. Confusing NA with NULL

Mistake: df$col <- NA when intending to delete column.

Fix: df$col <- NULL deletes; NA merely fills with missing.

7. Using na.omit() Blindly

Mistake: Dropping 80% of rows because 1 unimportant column had NAs.

Fix: Filter NAs on specific target columns or impute carefully.

8. Calculating Mean without na.rm = TRUE

Mistake: mean(df$age) returning NA.

Fix: mean(df$age, na.rm = TRUE).

9. Mismatched Columns in rbind()

Mistake: Appending row with different column names.

Fix: Harmonize column names and types before calling rbind().

10. Confusing Base Pipe with Logical OR

Mistake: Thinking |> is a conditional boolean OR.

Fix: | is logical OR; |> is the forward pipe operator.

11. Assuming Tibble is NOT a Data Frame

Mistake: is.data.frame(tbl) assumed FALSE.

Fix: A tibble inherits from data.frame; it returns TRUE!

12. Forgetting to Load Packages

Mistake: Calling filter() without library(dplyr).

Fix: Always call library(dplyr) or library(tibble).

13. Overwriting Existing Column Accidentally

Mistake: Assigning to df$name instead of df$new_name.

Fix: Audit existing column names with names(df) first.

14. Filtering with Assignment Instead of ==

Mistake: df[df$dept = "IT", ] → Syntax Error!

Fix: Use double equals: df[df$dept == "IT", ].

15. Global Imputation Data Leakage

Mistake: Calculating median on combined train+test data.

Fix: Compute median on train set only and apply to test set.

16. Confusing Single and Double Brackets

Mistake: Passing df["marks"] into a function expecting a vector.

Fix: Use df$marks or df[["marks"]] to extract pure vector.

17. Modifying Filtered Subset in Place

Mistake: sub_df <- df[1, ]; sub_df$x <- 9 expecting original df to change.

Fix: R uses copy-on-modify semantics; explicitly update df[1, "x"].

18. Incompatible Types in Vector Assignment

Mistake: Assigning character into an integer column.

Fix: R coerces the entire column vector to character type.

19. Ghost Factor Levels After Filtering

Mistake: Filtered data frame keeps unused factor levels in plots.

Fix: Call droplevels(filtered_df) to prune phantom categories.

20. Forgetting to Ungroup after group_by()

Mistake: Subsequent operations remain unintentionally grouped.

Fix: Add .groups = "drop" or call ungroup(df).
