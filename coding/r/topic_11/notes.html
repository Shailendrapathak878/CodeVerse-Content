3. What Is a Matrix?

A matrix is a two-dimensional rectangular data structure in R that stores values organized into horizontal rows and vertical columns.

Imagine tracking marks scored by three students across three subjects:

StudentMathsScienceEnglish
Rahul859078
Aman758882
Priya929589

Here, each horizontal row represents a student, each vertical column represents a subject, and each cell stores an atomic score. In R, this grid is represented directly as a numeric matrix.

Key Matrix Terminology

  • Row: A horizontal line of elements running left-to-right (Index 1: Rahul, Index 2: Aman, Index 3: Priya).
  • Column: A vertical line of elements running top-to-bottom (Index 1: Maths, Index 2: Science, Index 3: English).
  • Cell / Element: The single value located at the intersection of a specific row and column.
  • Dimensions: The size expressed as nrow × ncol (e.g., $3 imes 3$ has 9 total elements).

4. Why Do We Need Matrices?

Why not just store data in separate vectors? Vectors can only represent single lists. Storing related multi-variable data in matrices provides massive advantages:

  • Relational Structure: Automatically maintains row-and-column alignments (e.g., user profiles, monthly sales across branch stores, multi-city daily temperatures).
  • High-Speed Vectorized Math: Matrix operations in R are written in compiled C and Fortran (BLAS/LAPACK), running orders of magnitude faster than loops.
  • Computer Vision & Image Pixels: Digital grayscale images are literally 2D matrices of pixel luminance values.
  • Machine Learning Feature Matrices: The standard input for regression, PCA, and neural networks is a feature matrix $X$ where rows are observations and columns are feature measurements.

7. Matrix Indexing & Subsetting

In R, matrix subsetting uses square brackets with a comma separating row and column indices: M[row_index, col_index]. R uses 1-based indexing.

Access Patterns

1. Single Cell Access

Specify both row and column:

R Script
R 
marks[1, 2]  # Rahul's Science mark &rarr; 90

2. Extract Entire Row

Leave column index blank:

R Script
R 
marks[1, ]   # All marks for Rahul &rarr; c(85, 90, 78)

3. Extract Entire Column

Leave row index blank:

R Script
R 
marks[, "Science"] # All Science marks &rarr; c(90, 88)

4. Sub-Matrix Selection

Provide vectors of indices:

R Script
R 
marks[1:2, c(1, 3)] # Rows 1&2, Cols 1&3

Preserving Dimensions with drop = FALSE

The Dimension Dropping Trap: By default, when you extract a single row or column, R silently drops the 2D matrix structure and returns a 1D atomic vector (drop = TRUE). To keep the result as a 2D matrix, always specify drop = FALSE!

print(is.matrix(col_mat))  # TRUE! 2x1 Matrix
print(col_mat)

8. Matrix Operations & Linear Algebra

One of R's greatest strengths is numerical matrix computation. Beginners must carefully distinguish between element-wise math and matrix algebra.

1. Element-Wise Arithmetic

Standard arithmetic operators (+, -, *, /, ^) operate element-by-element on matching cells:

R ScriptElement-wise operations
R Script
R

B <- matrix(c(5, 6, 7, 8), nrow = 2, byrow = TRUE)

print(A + B)  # Element-wise addition
print(A * B)  # Element-wise multiplication (Hadamard product)
Output
R Script
R 
[,1] [,2]
[1,]    6    8
[2,]   10   12

     [,1] [,2]
[1,]    5   12
[2,]   21   32

2. Algebraic Matrix Multiplication (%*%)

In linear algebra, matrix multiplication computes row-by-column dot products. In R, this is executed using the %*% operator:

R ScriptMatrix dot-product multiplication
R Script
R 
C <- A %*% B
print(C)
Output
R Script
R 
[,1] [,2]
[1,]   19   22
[2,]   43   50
The Inner Dimension Rule: For A %*% B to be mathematically valid, ncol(A) must equal nrow(B). If matrix $A$ is $m imes n$ and matrix $B$ is $n imes p$, the resulting matrix will have dimensions $m imes p$. If inner dimensions differ, R throws Error in A %*% B: non-conformable arguments.

3. Matrix Transpose: t()

The transpose operator t(M) flips a matrix over its diagonal, turning rows into columns and columns into rows:

9. Important Matrix Functions

Base R provides powerful built-in analytical routines for linear algebra and summary statistics:

1. Diagonal Functions with diag()

  • diag(M): Extracts the main diagonal elements as a vector.
  • diag(c(a, b, c)): Creates a diagonal matrix with the specified vector on the diagonal.
  • diag(n): Creates an $n imes n$ Identity Matrix $I$.

2. Determinant: det() & Inverse: solve()

For a square $2 imes 2$ matrix $M = egin{pmatrix} a & b \ c & d end{pmatrix}$, the determinant is $det(M) = ad - bc$. If $det(M) eq 0$, the matrix is invertible, and solve(M) returns its mathematical inverse $M^{-1}$ such that $M imes M^{-1} = I$:

R Scriptdet and solve
R Script
R 
sq <- matrix(c(4, 7, 2, 6), nrow = 2, byrow = TRUE)
d <- det(sq)
inv <- solve(sq)

print(d)
print(inv)
print(round(sq %*% inv))  # Verifying Identity matrix
Output
R Script
R 
[1] 10

     [,1] [,2]
[1,]  0.6 -0.7
[2,] -0.2  0.4

     [,1] [,2]
[1,]    1    0
[2,]    0    1
Singular Matrix Trap: If $det(M) = 0$ (e.g., one row is an exact multiple of another), the matrix is singular and has no inverse. Running solve(M) throws Error: Lapack routine dgesv: system is exactly singular.

10. What Is an Array?

An array is a generalized multi-dimensional data structure in R that can store homogeneous atomic elements in 1, 2, 3, 4, or more dimensions.

  • Vector: 1 Dimension (Length: $N$).
  • Matrix: 2 Dimensions ($N$ Rows $ imes$ $P$ Columns).
  • Array: $N$ Dimensions ($D_1 imes D_2 imes D_3 imes dots imes D_k$).

Real-Life Analogy: Imagine measuring temperature across 4 cities, recorded 3 times a day, across 7 days a week. Storing this requires a 3D grid: dim = c(4 cities, 3 times, 7 days). In R, this is represented as a 3D array.

11. Creating Arrays with array()

Syntax: array(data = NA, dim = length(data), dimnames = NULL)

The dim parameter takes an integer vector defining the size of each dimension in order: c(rows, columns, layers, ...).

R ScriptCreating a 3D array
R Script
R 
# Creating a 3D array: 2 rows, 3 columns, 2 layers (slices)
arr_3d <- array(1:12, dim = c(2, 3, 2))
print(arr_3d)
Output
R Script
R

[2,]    2    4    6

[1,]    7    9   11

Notice how R prints 3D arrays: each layer is displayed as an independent 2D matrix indexed by ,,1 and ,,2.

12. Array Dimensions and Indexing

Accessing elements in an array follows the general bracket syntax with a coordinate for each dimension: array[dim1, dim2, dim3, ...].

3D Indexing Patterns

  • arr[row, col, layer]: Accesses a single scalar element.
  • arr[1, , 2]: Extracts the entire 1st row of layer 2.
  • arr[, 3, 1]: Extracts the entire 3rd column of layer 1.
  • arr[, , 1]: Extracts the entire 2D matrix slice representing layer 1.
R ScriptArray slicing
R Script
R 
# Access element at row 1, col 2, layer 2
val <- arr_3d[1, 2, 2]
print(val)  # 9

# Extract full layer 1 as 2D matrix
layer1 <- arr_3d[, , 1]
print(layer1)
Output
R Script
R 
[1] 9

     [,1] [,2] [,3]
[1,]    1    3    5
[2,]    2    4    6

14. apply() With Matrices and Arrays

The apply() function provides functional iteration across specified dimensions (margins) without manual nested loops:

  • apply(M, 1, FUN): Applies FUN across rows (MARGIN = 1).
  • apply(M, 2, FUN): Applies FUN across columns (MARGIN = 2).
  • apply(arr, 3, FUN): Applies FUN across layers / slices (MARGIN = 3).
  • apply(arr, c(1, 2), FUN): Collapses the 3rd dimension across each row-column pair.
R Scriptapply() demonstration
R Script
R 
mat <- matrix(1:12, nrow = 3, ncol = 4)

# Calculate sum of each row
row_totals <- apply(mat, 1, sum)

# Calculate standard deviation of each column
col_sds <- apply(mat, 2, sd)

print(row_totals)
print(col_sds)
Output
R Script
R 
[1] 22 26 30
[1] 1 1 1 1

18. Common Beginner Mistakes & How to Avoid Them

1. Confusing * and %*%

A * B multiplies element-by-element, not matrix dot product!

Fix: Use A %*% B for algebraic linear matrix multiplication.

2. Incompatible Multiplication Dimensions

Multiplying matrices when ncol(A) != nrow(B) throws error.

Fix: Always verify dim(A)[2] == dim(B)[1] before %*%.

3. Forgetting the Comma in Subsetting

M[1] flattens the matrix and returns the 1st vector element!

Fix: Always include the comma: M[1, ] for row 1, M[, 1] for column 1.

4. Silent Dimension Dropping

M[, 1] returns a 1D vector, breaking subsequent matrix code.

Fix: Use M[, 1, drop = FALSE] to preserve 2D matrix structure.

5. Assuming byrow = TRUE is Default

Assuming matrix(1:4, 2, 2) fills row-wise.

Fix: R fills column-wise by default. Explicitly pass byrow = TRUE.

6. Inverting a Singular Matrix

Running solve(M) when det(M) == 0 crashes.

Fix: Check if (det(M) != 0) solve(M) before inverting.

7. Zero-Based Indexing

Writing M[0, 1] returns an empty matrix slice in R.

Fix: R uses 1-based indexing: start rows and columns at 1.

8. Confusing MARGIN in apply()

Using apply(M, 2, sum) when row sums were needed.

Fix: Remember: MARGIN = 1 → Rows; MARGIN = 2 → Columns.

9. Type Coercion Trap

Adding a single string cell coerces the entire numeric matrix to character.

Fix: Matrices must be homogeneous. Use Data Frames for mixed data types.

10. Confusing length() and dim()

Expecting length(M) to return row count.

Fix: length(M) returns total cells ($nrow imes ncol$). Use nrow(M) for row count.

11. Mismatched Vector Lengths in rbind/cbind

Binding vectors of unequal lengths causes silent recycling bugs.

Fix: Verify vector lengths match matrix dimensions before binding.

12. Missing na.rm in Summaries

colMeans(M) returns NA if any element is missing.

Fix: Always pass na.rm = TRUE when datasets contain missing entries.

13. Misinterpreting 3D Array Dimensions

Assuming dim = c(2, 3, 4) means 4 rows.

Fix: Dimension order is strictly c(rows, columns, layers, ...).

14. Vector Recycling in matrix()

matrix(1:5, nrow = 2, ncol = 3) warns and recycles 1.

Fix: Ensure data vector length divides evenly into $nrow imes ncol$.

15. Modifying Matrix Names Incorrectly

Assigning wrong length vector to rownames(M) causes error.

Fix: Ensure length(rownames(M)) == nrow(M).

Q1: What does dim(matrix(1:6, nrow = 2))[2] return?

Reveal Answer

[1] 3. The matrix has 2 rows and 3 columns. dim() returns c(2, 3), so index 2 is 3.

Q2: What is the output of matrix(1:4, 2, 2, byrow = TRUE)[2, 1]?

Reveal Answer

[1] 3. Row 1 is [1, 2] and Row 2 is [3, 4]. Row 2, Col 1 is 3.

Q3: What is dim(rbind(1:3, 4:6))?

Reveal Answer

[1] 2 3. rbind() stacks 2 vectors of length 3, creating 2 rows and 3 columns.

Q4: What does class(matrix(1:4, 2)[, 1]) return?

Reveal Answer

[1] "integer". By default, drop = TRUE simplifies the column slice to an atomic vector.

Q5: What does matrix(1:4, 2) * matrix(1:4, 2) yield at cell [2, 2]?

Reveal Answer

[1] 16. * is element-wise multiplication: $4 imes 4 = 16$.

Q6: What does matrix(c(1, 0, 0, 1), 2) %*% c(3, 4) compute?

Reveal Answer

[1] 3 4. Multiplying by the $2 imes 2$ Identity matrix preserves the input vector.

Q7: What is t(matrix(1:6, 2, 3))[3, 1]?

Reveal Answer

[1] 5. Original cell [1, 3] had value 5; transposing places it at row 3, col 1.

Q8: What does diag(diag(3)) return?

Reveal Answer

[1] 1 1 1. diag(3) creates a 3x3 identity matrix; applying diag() again extracts its diagonal vector.

Q9: What is det(matrix(c(2, 0, 0, 3), 2))?

Reveal Answer

[1] 6. Determinant of a diagonal matrix is the product of diagonal elements ($2 imes 3 = 6$).

Q10: In arr <- array(1:12, dim = c(2, 3, 2)), what is arr[2, 3, 2]?

Reveal Answer

[1] 12. It is the very last element of the 12-element array.

Q11: What is apply(matrix(1:6, 2, 3), 1, sum)[1]?

Reveal Answer

[1] 9. Row 1 has elements 1, 3, 5 (filled column-wise). Their sum is $1 + 3 + 5 = 9$.

Q12: What is the result of which(matrix(c(10, 20, 30, 40), 2) == 30, arr.ind = TRUE)?

Reveal Answer

Row 1, Column 2. In column-major filling, column 1 has 10 and 20; column 2 has 30 at row 1.
