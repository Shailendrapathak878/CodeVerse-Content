1. Introduction to Data Visualization & The Grammar of Graphics

Data Visualization is the graphical representation of data and information. By turning numerical matrices and categorical features into visual elements (points, lines, bars, colors, and coordinates), we empower human cognition to instantly spot patterns, anomalies, correlations, and clusters.

The Grammar of Graphics was pioneered by statistician Leland Wilkinson (1999) and brought to life in R by Hadley Wickham via ggplot2. Rather than viewing charts as isolated "types" (pie, bar, line), ggplot2 decomposes every graphic into a formal grammar composed of 7 independent structural layers.

The 7 Core Layers:
  • Data: The tidy rectangular dataset containing observations (rows) and variables (columns).
  • Aesthetics (aes): Mappings from data variables to visual channels (x, y, color, fill, shape, size).
  • Geometries (geoms): Visual shapes representing data points (geom_point, geom_line, geom_col).
  • Facets: Small multiples splitting data across categorical variables into subpanels.
  • Statistics (stats): Algorithmic transformations (binning, counting, smoothing, density estimation).
  • Coordinates (coord): Coordinate system projecting data (Cartesian, polar, flipped, map projection).
  • Theme: Non-data visual styling (fonts, backgrounds, grids, legend positioning).
2. ggplot2 Architecture & The Addition (+) Operator

In ggplot2, you initialize a plot object with ggplot(data, aes(...)) and append visual layers sequentially using the addition + operator. Note that + must always remain at the end of the line, never at the beginning of the next line.

3. Aesthetic Mappings: aes() vs Fixed Attributes

A crucial conceptual hurdle for beginners is distinguishing between mapping a variable inside aes() versus setting a constant aesthetic outside aes().

Aesthetic Mapping: inside aes()
geom_point(aes(color = class))
Maps values of the column class to distinct colors via an automatic color scale and legend.
Static Aesthetic Setting: outside aes()
geom_point(color = "#276DC3", size = 3)
Sets every point to the constant hex color #276DC3 with size 3. No legend is drawn.
4. Foundational Geometric Layers

Geometric layers dictate how data rows are materialized visually on the Cartesian plane. Choose geoms matching data variable types (continuous vs categorical).

Scatter & Line:
  • geom_point(): 2 continuous variables (x, y).
  • geom_line(): Continuous ordered trend over time/steps.
Bar Charts:
  • geom_bar(): Auto-counts frequencies (stat = 'count').
  • geom_col(): Plots pre-aggregated y values directly.
Distributions:
  • geom_histogram(): Bins continuous x data.
  • geom_boxplot(): Median, IQR, whiskers, outliers.
5. Advanced & Distributional Geometric Layers

When dataset complexity increases, basic geoms can suffer from severe overplotting or conceal multi-modal distributions. Advanced geoms reveal dense point clusters and density distributions.

geom_violin() & geom_jitter(): Violins mirror kernel density estimates, exposing bimodal clusters invisible in boxplots. Jitter adds small noise to eliminate point overlaps.

geom_density() & geom_tile(): Continuous probability density smooths histograms. geom_tile() converts 2D grid matrices into correlation or confusion heatmaps.

6. Small Multiples & Faceting (facet_wrap & facet_grid)

Faceting splits a plot into multiple subpanels, with each panel presenting a slice of data corresponding to a categorical conditioning factor. This avoids cluttered visual legends and enables clean comparisons.

facet_wrap(~ group, ncol = 3):
Takes a 1D sequence of panels and wraps them across rows/columns. Ideal for a single categorical variable with many levels.
facet_grid(rows ~ cols):
Forms a 2D matrix of subplots mapped strictly to row factors and column factors. Every intersection is visually evaluated.
7. Statistical Transformations & Coordinate Systems

Every geom has an underlying statistical transformation (stat). You can alter coordinates (flipping axes, transforming to polar rings, or fixing aspect ratios).

coord_flip():
Swaps horizontal and vertical axes. Extremely useful for reading long horizontal bar labels.
coord_polar(theta = 'y'):
Bends Cartesian space into polar coordinates. Turns stacked bars into pie or donut charts.
coord_fixed(ratio = 1):
Forces 1 unit on x to equal 1 unit on y. Essential for ROC curves, PCA, and maps.
8. Scales, Color Palettes & Customization

Scales control how data values translate into visual dimensions: axis tick increments, numerical formatting (currency, percent, log), and color gradients.

Accessibility & Perceptual Uniformity: Always prefer scale_fill_viridis_c() or scale_color_viridis_d() over rainbow palettes. Viridis scales maintain monotonic luminance ramps that remain clear when printed in greyscale or viewed by colorblind users.
9. Themes, Styling & Annotations

Themes manage non-data visual properties. ggplot2 includes standard themes (theme_minimal, theme_classic, theme_void) which can be customized via theme(...) and element functions (element_text, element_line, element_rect, element_blank).

14. 28 Beginner Pitfalls & Common Mistakes

1. Static color inside aes(): geom_point(aes(color = "blue")) maps string "blue" to a single-level categorical color (red). geom_point(color = "blue").

2. Starting a line with +: In R script execution, placing + on the new line breaks execution. Always keep + at the end of the previous line.

3. Using %>% instead of +: ggplot2 uses + to combine layers, not the magrittr pipe %>%.

4. geom_bar with raw heights: Using geom_bar() on raw numbers fails because its default stat is 'count'. Use geom_col() or geom_bar(stat = "identity").

5. Overwriting theme settings: Calling theme_minimal() AFTER custom theme(...) wipes out custom modifications. Always declare standard themes first.

6. Forgetting group aesthetic in lines: Drawing lines on multi-group data without group = id creates a messy zigzag. Map group or color.

7. Overplotting dense points: Thousands of points render as an opaque blob. Use geom_jitter(), alpha = 0.2, or geom_bin2d().

8. Alphabetical factor ordering: Categories sort alphabetically by default. Use reorder(cat, val) or factor(levels = ...).

9. Inverting coord_polar parameters: Forgetting theta = "y" draws bullseye concentric rings instead of pie wedges.

10. Truncating data with scale limits: scale_y_continuous(limits = c(0, 10)) drops out-of-bound rows. Use coord_cartesian(ylim = c(0, 10)) to zoom without dropping data.

11. Confusing fill and color: Setting color = "blue" on bars colors the border lines, not the interior. Use fill for 2D areas.

12. Missing aes() mapping quotes: Writing aes(x = "mpg") creates a single constant category "mpg", rather than reading the column mpg.

13. Non-tidy wide data: ggplot requires long format. Convert wide tables with tidyr::pivot_longer() first.

14. Legend label confusion: Setting labs(color = "Category") when points use fill splits the legend into two. Match aesthetic labels.

15. Misinterpreting histogram binwidth: Too few bins over-smooth trends; too many bins introduce excessive noise. Test multiple binwidth values.

16. Pie charts with > 5 categories: Slices become impossible to distinguish. Use a sorted horizontal bar chart instead.

17. Unbounded facet scales: Default fixed scales can compress smaller subgroups. Enable scales = "free_y" where appropriate.

18. Rainbow color maps: Rainbow palettes have non-monotonic luminance ramps that mislead perception. Use viridis.

19. ggsave default overwrite: Calling ggsave() without passing plot = p saves last_plot(), which might be an unintended plot.

20. Forgetting print() in loops: In for-loops or functions, ggplots do not display automatically without an explicit print(p).

21. Hardcoded aspect ratios: Warped aspect ratios distort slope perceptions. Use coord_fixed() for 1:1 comparisons.

22. Double dodging without position_dodge: Combining points and error bars requires matching position_dodge(width = 0.8).

23. Missing scale library for formatting: scales::percent requires install.packages("scales").

24. Hardcoded pixel dimensions in ggsave: Passing width = 800 without setting units = "px" assumes inches, resulting in an enormous file.

25. Outlier duplication in boxplot + jitter: geom_boxplot() plots outliers by default. Set outlier.shape = NA when overlaying jitter.

26. Cluttered x-axis labels: Overlapping date or category names. Rotate them with theme(axis.text.x = element_text(angle = 45, hjust = 1)).

27. Omitting baseline zero on bar charts: Truncating the y-axis on bar charts exaggerates relative differences, misleading readers.

28. Misunderstanding layer ordering: Layers render sequentially. Drawing points before regression lines hides points beneath the shaded ribbon.
