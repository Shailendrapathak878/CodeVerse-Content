What is File Handling?

FILE
A named place on your disk where data is stored permanently. It stays even after the program stops.
Example: notes.txt, marks.csv, data.json
FILE HANDLING
Using code to open, read, write and close files.
💡 Real-life analogy

A variable is like a sticky note. It is thrown away when you leave. A file is like a notebook. You can close it and open it again tomorrow.

The 3 steps of working with a file

Two kinds of files

📄 Text files

Hold readable text. Examples: .txt, .csv, .json, .py. These notes focus on them.

🖼 Binary files

Hold raw bytes, not readable text. Examples: .jpg, .pdf, .mp3. You open them with "rb" or "wb".

04

Opening a File with open()

Concept

The built-in open() function opens a file and gives you a file object. You use that object to read or write.

Syntax
file = open("filename", "mode")
# ... work with the file ...
file.close()
Example
Python
f = open("hello.txt", "w")
f.write("Hello, file!")
f.close()
print("File created")
Output
File created
Easy Explanation
  • "w" is the mode. It means "write".
  • The file hello.txt did not exist, so Python created it.
  • f.write(...) put the text inside.
  • f.close() finished the job and saved the file.

File modes

The mode tells Python what you want to do with the file.

r
Read (the default)Error if the file is missing
w
WriteCreates the file, erases old content
a
AppendAdds at the end, keeps old content
x
CreateMakes a new file, error if it exists
r+
Read and writeThe file must already exist
b
Binary (add to a mode)rb, wb (images, PDFs)
⚠️ "w" erases the file

If the file already exists, mode "w" deletes everything inside it first. Use "a" if you want to keep the old content.

📌 Tip: set the encoding

Write open("notes.txt", "r", encoding="utf-8") so that special letters and symbols work the same on every computer.

06

Writing and Appending

Concept

write() puts text into a file. In mode "w" the file starts empty. In mode "a" the new text goes at the end.

Example
Python
f = open("todo.txt", "w")
f.write("Buy milk\n")
f.write("Call mom\n")
f.close()
File content
Buy milk
Call mom
Easy Explanation
  • write() does not add a new line by itself.
  • We add \n to start a new line.

Append mode

Python
f = open("todo.txt", "a")
f.write("Study Python\n")
f.close()
todo.txt now
Buy milk
Call mom
Study Python

"w" → Write

Erases the old content, then writes. Old lines are lost.

"a" → Append

Keeps the old content and adds new text at the end.

writelines() writes a list

Python
items = ["Rice\n", "Dal\n", "Tea\n"]
f = open("shopping.txt", "w")
f.writelines(items)
f.close()
shopping.txt
Rice
Dal
Tea
  • writelines() also does not add new lines.
  • Put \n inside each item yourself.
⚠️ Only strings can be written

To write a number, change it first: f.write(str(25)). Otherwise Python raises a TypeError.

07

The with Statement

Concept

If you forget close(), data may not be saved. And if an error happens in the middle, close() may never run.

The with statement fixes this. It closes the file automatically, even when an error happens.

Syntax
with open("filename", "mode") as f:
    # work with f here (indented)
Example
Python
with open("todo.txt", "r") as f:
    data = f.read()

print(data.splitlines())
print(f.closed)
Output
['Buy milk', 'Call mom', 'Study Python']
True
Easy Explanation
  • The file is open only inside the indented block.
  • When the block ends, Python closes the file for you.
  • f.closed is True, which proves it is closed.
  • splitlines() cuts text into a list of lines without the \n.
Python
with open("log.txt", "w") as f:
    f.write("Program started\n")
    f.write("Program finished\n")

with open("log.txt") as f:
    for line in f:
        print(line.strip())
Output
Program started
Program finished
🧠 Remember this

From now on, always use with open(...). It is the standard, safe way. You never have to remember close().

08

The File Cursor: tell() and seek()

When a file is open, Python keeps a cursor (a position marker), like your finger moving along a line of text.

  • Reading moves the cursor forward.
  • tell() tells you the current position.
  • seek(n) jumps to position n.
The cursor after reading 5 characters
Example
Python
with open("demo.txt", "w") as f:
    f.write("Hello World")

with open("demo.txt", "r") as f:
    print(f.read(5))
    print(f.tell())
    print(f.read())
    print(repr(f.read()))
    f.seek(0)
    print(f.read())
Output
Hello
5
 World
''
Hello World
Easy Explanation
  • read(5) reads only the first 5 characters.
  • tell() says the cursor is now at position 5.
  • read() reads the rest, including the space.
  • The next read() gives an empty string ''. repr() shows the quotes so we can see it.
  • seek(0) moves back to the start, so we can read again.
⚠️ Reading twice

After a full read(), the cursor is at the end. A second read() returns nothing. Use seek(0) to go back to the start.

09

File Paths

A path tells Python where a file lives. There are two types.

📍 Relative path

Starts from the current folder of your program. Example: "notes.txt" or "data/notes.txt".

🌍 Absolute path

The full address from the top of the drive. Example: "C:/Users/Riya/notes.txt" or "/home/riya/notes.txt".

⚠️ Backslashes on Windows

In normal strings, \n means a new line and \t means a tab. So a path like "C:\new\test.txt" breaks. Use forward slashes / or a raw string like r"C:\new\test.txt".

Easy paths with pathlib

The pathlib module builds paths that work on every operating system.

Python
from pathlib import Path

p = Path("data") / "notes.txt"
print(p)
print(p.name)
print(p.suffix)
print(p.exists())
Output (on Windows the first line shows data\notes.txt)
data/notes.txt
notes.txt
.txt
False
  • The / joins the folder and the file name.
  • p.name is the file name, and p.suffix is the extension.
  • p.exists() is False here because this file was never created.
10

Handling File Errors

Files can go wrong. The file may be missing, or you may not have permission. If you do not handle the error, the program stops.

with open("missing.txt") as f:
    print(f.read())
Error
FileNotFoundError: [Errno 2] No such file or directory: 'missing.txt'

Use try and except to handle it politely.

Python
try:
    with open("missing.txt") as f:
        print(f.read())
except FileNotFoundError:
    print("Sorry, that file does not exist.")

print("Program continues")
Output
Sorry, that file does not exist.
Program continues

Common file errors

  • FileNotFoundError → the file or folder is missing.
  • PermissionError → you are not allowed to open it.
  • FileExistsError → mode "x" was used on a file that already exists.
  • IsADirectoryError → you tried to open a folder as a file.

Or check first

Python
from pathlib import Path

if Path("settings.txt").exists():
    print("Found it")
else:
    print("No settings file yet")
Output
No settings file yet
🧠 Remember this

try/except is usually the better choice. A file can disappear between your check and your open().

import os

  • exist_ok=True means "no error if the folder is already there".

Real Example: Word Counter

Let us use what we learned. This program reads notes.txt and counts lines and words.

Python
with open("notes.txt") as f:
    text = f.read()

words = text.split()

print("Lines:", len(text.splitlines()))
print("Words:", len(words))
print("Longest word:", max(words, key=len))
Output
Lines: 3
Words: 6
Longest word: three
  • split() cuts the text into words.
  • splitlines() cuts the text into lines.
  • max(words, key=len) picks the word with the most letters.

What are Data Formats?

DATA FORMAT
An agreed way of arranging data inside a file, so that different programs can understand it.
Example: CSV for tables, JSON for structured data.
💡 Real-life analogy

A data format is like a language. If both people speak the same language, they understand each other. In the same way, if two programs use JSON, they can share data easily.

  • CSV → rows and columns, like a spreadsheet.
  • JSON → nested data with lists and key-value pairs.
  • Others you may meet later: XML, YAML, Excel files.

Python gives you two ready-made modules, csv and json. They are part of the standard library, so you only need to import them (see Chapter 12).

Reading CSV Files

CSV
Comma-Separated Values. A text file where each line is a row and commas separate the columns.

Create a file students.csv with this content:

students.csv
name,marks,city
Riya,85,Delhi
Aman,72,Pune
Sara,91,Jaipur
Syntax
import csv

with open("file.csv", "r", newline="") as f:
    reader = csv.reader(f)
    for row in reader:
        # row is a list
Example
Python
import csv

with open("students.csv", "r", newline="") as f:
    reader = csv.reader(f)
    for row in reader:
        print(row)
Output
['name', 'marks', 'city']
['Riya', '85', 'Delhi']
['Aman', '72', 'Pune']
['Sara', '91', 'Jaipur']
Easy Explanation
  • Each row comes as a list of strings.
  • The first row is the header (column names).
  • 85 looks like a number but it is the string '85'.
  • newline="" is a small safety setting the csv module needs.

Skip the header

Python
import csv

with open("students.csv", newline="") as f:
    reader = csv.reader(f)
    header = next(reader)
    for row in reader:
        print(row[0], int(row[1]) + 5)
Output
Riya 90
Aman 77
Sara 96
  • next(reader) takes one row, the header, out of the way.
  • int(row[1]) changes the text into a number so we can add 5.

Writing CSV Files

Syntax
writer = csv.writer(f)
writer.writerow(one_row_list)
writer.writerows(list_of_rows)
Example
Python
import csv

rows = [
    ["Riya", 85, "Delhi"],
    ["Aman", 72, "Pune"],
]

with open("students.csv", "w", newline="") as f:
    writer = csv.writer(f)
    writer.writerow(["name", "marks", "city"])
    writer.writerows(rows)

print("Saved")
Output
Saved
students.csv now
name,marks,city
Riya,85,Delhi
Aman,72,Pune
Easy Explanation
  • writerow() writes one row.
  • writerows() writes many rows at once.
  • Numbers like 85 are turned into text for you.

If a value contains a comma, the writer adds quotes so the file stays correct.

Python
import csv

with open("places.csv", "w", newline="") as f:
    csv.writer(f).writerow(["Riya", "Delhi, India"])
places.csv
Riya,"Delhi, India"
⚠️ Always use newline=""

Without newline="", files on Windows may get blank lines between rows. Add it every time you open a CSV file.

DictReader and DictWriter

Rows as lists make you remember positions like row[1]. Dictionaries let you use column names instead.

Concept

csv.DictReader gives each row as a dictionary. The header row becomes the keys.

Example
Python
import csv

with open("students.csv", newline="") as f:
    reader = csv.DictReader(f)
    for row in reader:
        print(row["name"], "scored", row["marks"])
        print(row)
Output
Riya scored 85
{'name': 'Riya', 'marks': '85', 'city': 'Delhi'}
Aman scored 72
{'name': 'Aman', 'marks': '72', 'city': 'Pune'}
Easy Explanation
  • row["name"] is much clearer than row[0].
  • Values are still strings, so use int() for numbers.

DictWriter

Python
import csv

people = [
    {"name": "Tina", "age": 20},
    {"name": "Raj", "age": 22},
]

with open("people.csv", "w", newline="") as f:
    writer = csv.DictWriter(f, fieldnames=["name", "age"])
    writer.writeheader()
    writer.writerows(people)
people.csv
name,age
Tina,20
Raj,22
  • fieldnames is the list of column names, in order.
  • writeheader() writes the first row of names.

What is JSON?

JSON
JavaScript Object Notation. A text format for storing data using key-value pairs and lists. It looks a lot like a Python dictionary.
Used by websites, apps and APIs to send data to each other.
student.json
{
  "name": "Riya",
  "age": 21,
  "skills": ["Python", "SQL"],
  "is_student": true,
  "address": null
}

JSON rules

  • Keys and text must use double quotes ". Single quotes are not allowed.
  • Booleans are lowercase: true and false.
  • Empty value is null.
  • No comments and no extra comma at the end.

JSON type → Python type

object
becomes a Python dict{"a": 1}
array
becomes a Python list[1, 2, 3]
string
becomes a Python str"hello"
number
becomes int or float21 or 3.5
true
becomes Python Truefalse → False
null
becomes Python Nonenull → None

json.dumps() and json.loads()

These two work with strings. The letter s in the name stands for string.

Python ⇄ JSON
Concept
  • json.dumps(obj) → Python object to a JSON string.
  • json.loads(text) → JSON string to a Python object.
Example
Python
import json

student = {
    "name": "Riya",
    "age": 21,
    "skills": ["Python", "SQL"],
    "is_student": True,
    "address": None,
}

text = json.dumps(student)
print(text)
print(type(text))

data = json.loads(text)
print(data["name"])
print(data["skills"][0])
print(type(data))
Output
{"name": "Riya", "age": 21, "skills": ["Python", "SQL"], "is_student": true, "address": null}
<class 'str'>
Riya
Python
<class 'dict'>
Easy Explanation
  • True became true, and None became null.
  • dumps gave a string. loads turned it back into a dict.

Pretty printing with indent

Python
print(json.dumps(student, indent=4))
Output
{
    "name": "Riya",
    "age": 21,
    "skills": [
        "Python",
        "SQL"
    ],
    "is_student": true,
    "address": null
}
  • indent=4 makes the text neat and easy to read.
  • sort_keys=True sorts the keys A to Z.

json.dump() and json.load()

These two work with files. There is no s in the name.

Concept
  • json.dump(obj, f) → writes the object into a file.
  • json.load(f) → reads a file and gives back the object.
Example
Python
import json

student = {"name": "Riya", "age": 21, "skills": ["Python", "SQL"]}

with open("student.json", "w") as f:
    json.dump(student, f, indent=4)

with open("student.json", "r") as f:
    loaded = json.load(f)

print(loaded["age"])
print(loaded == student)
Output
21
True
student.json
{
    "name": "Riya",
    "age": 21,
    "skills": [
        "Python",
        "SQL"
    ]
}
Easy Explanation
  • dump saved the dictionary to disk.
  • load brought it back, and it is equal to the original.
dumps
object → strings = json.dumps(obj)
loads
string → objectobj = json.loads(s)

⚠️ Not everything fits in JSON

A tuple is saved as a list. Dictionary keys become strings. A set cannot be saved at all. It gives TypeError: Object of type set is not JSON serializable. Change it with list(my_set) first.

21

CSV vs JSON

📊 CSV

Best for flat tables with rows and columns. Opens in Excel. Small and simple. Every value is plain text.

🧩 JSON

Best for nested data like lists inside dictionaries. Remembers numbers, true/false and null. Used by most web APIs and settings files.

How to choose

  • Data looks like a spreadsheet? Use CSV.
  • Data has levels (a student with many skills)? Use JSON.
  • Sending data to or from a website? Use JSON.
  • Need to open it in Excel? Use CSV.
🧠 Remember this

CSV gives you strings only. JSON keeps real numbers and booleans, so you need less converting.

Real Example: CSV to JSON

Read students.csv, calculate a small report, and save it as JSON.

students.csv
name,marks,city
Riya,85,Delhi
Aman,72,Pune
Sara,91,Jaipur
Python
import csv
import json

students = []
with open("students.csv", newline="") as f:
    for row in csv.DictReader(f):
        row["marks"] = int(row["marks"])
        students.append(row)

total = sum(s["marks"] for s in students)
toppers = [s["name"] for s in students if s["marks"] >= 80]

report = {
    "count": len(students),
    "average": round(total / len(students), 1),
    "toppers": toppers,
}

with open("report.json", "w") as f:
    json.dump(report, f, indent=4)

print(report)
Output
{'count': 3, 'average': 82.7, 'toppers': ['Riya', 'Sara']}
report.json
{
    "count": 3,
    "average": 82.7,
    "toppers": [
        "Riya",
        "Sara"
    ]
}
  • DictReader reads each student as a dictionary.
  • int() changes marks from text to numbers.
  • A comprehension picks the toppers (Chapter 11).
  • json.dump() saves the final report.

Common Beginner Mistakes

❌ Wrong: Opening without with, and forgetting close()
f = open("a.txt", "w")
f.write("Hello")
# no f.close()
✅ Correct: use with open("a.txt", "w") as f:

Without closing, the text may never be saved to the disk.

❌ Wrong: Using "w" when you wanted to add lines
f = open("todo.txt", "w")
f.write("New task\n")
✅ Correct: use mode "a" to keep the old lines

Mode "w" erased everything that was in the file.

❌ Wrong: Forgetting \n when writing
with open("t.txt", "w") as f:
    f.write("Buy milk")
    f.write("Call mom")
✅ Correct: write "Buy milk\n"

The file would contain Buy milkCall mom on a single line.

❌ Wrong: Writing a number directly
with open("n.txt", "w") as f:
    f.write(25)
Error
TypeError: write() argument must be str, not int
✅ Correct: f.write(str(25))
❌ Wrong: Using CSV values as numbers
import csv
with open("students.csv", newline="") as f:
    rows = list(csv.reader(f))
print(rows[1][1] + 10)
Error
TypeError: can only concatenate str (not "int") to str
✅ Correct: int(rows[1][1]) + 10

CSV values are always strings. Convert them first.

❌ Wrong: Mixing up load and loads
import json
data = json.load('{"a": 1}')
Error
AttributeError: 'str' object has no attribute 'read'
✅ Correct: json.loads(...) for strings, json.load(f) for files

Quick Revision

File→A named place on disk that stores data permanently
open()→Opens a file and returns a file object
"r"→Read (default). Error if file is missing
"w"→Write. Creates the file or erases old content
"a"→Append. Adds to the end
"x"→Create new. Error if file exists
read()→Whole file as one string
readline()→One line at a time
readlines()→List of all lines
write()→Writes a string. No automatic new line
with→Opens a file and closes it automatically
tell() / seek()→Get / move the cursor position
FileNotFoundError→Raised when the file does not exist
os / pathlib→Manage files, folders and paths
CSV→Comma-separated rows of a table
csv.reader / writer→Read / write CSV rows as lists
DictReader / DictWriter→Read / write CSV rows as dictionaries
JSON→Text format of key-value pairs and lists
dumps / loads→Object ⇄ JSON string
dump / load→Object ⇄ JSON file
indent→Makes JSON output neat
newline=""→Always use it when opening CSV files
25

Key Points to Remember

  • Files store data permanently. Variables do not.
  • The steps are: open → read or write → close.
  • Always use with open(...) so the file closes by itself.
  • "w" erases the file. "a" adds to the end.
  • write() needs a string and does not add \n for you.
  • Use a for loop to read big files line by line.
  • Handle missing files with try and except FileNotFoundError.
  • CSV values always come back as strings. Use int() or float().
  • Open CSV files with newline="".
  • JSON uses s for strings (dumps, loads) and no s for files (dump, load).
  • indent=4 makes saved JSON easy to read.
