Topic Introduction

📊 Figure 3.6: Object Identity (is) vs. Value Equality (==)
The equality operator `==` checks whether two objects have equivalent content. The identity operator `is` verifies whether both variables refer to the exact same physical memory address (`id(a) == id(b)`).
Visual Summary & Trace:
Comparison Rules: a == b checks content equality (True if data matches), whereas a is b checks memory address identity (True only if pointing to the identical object).
📊 Figure 3.5: Floating-Point Representation and IEEE-754 Precision
Python floats use 64-bit IEEE-754 double precision representation. Fractions that are finite in base 10 (such as 0.1 and 0.2) repeat infinitely in binary, producing minor arithmetic rounding artifacts.
Visual Summary & Trace:
IEEE-754 Architecture: 1 sign bit + 11 exponent bits + 52 mantissa bits. Inexact decimal fractions should be compared using math.isclose() or the decimal module.
📊 Figure 3.4: Python Data Types Taxonomy and Hierarchy
All data values in Python are objects. They divide into scalar atomic types representing individual measurements (int, float, bool, NoneType) and compound collection containers holding multiple items (str, list, tuple, dict, set).
Visual Summary & Trace:
Taxonomy: Python Objects divide into Scalar (int, float, bool, None) and Collections (str, list, tuple, dict, set).
📊 Figure 3.1: Python Reference Model (Name Tags) vs. Traditional Box Model
In Python, variables do not store values directly inside rigid memory cells. Instead, variables are lightweight names (references) bound to independent objects residing in heap memory.
Visual Summary & Trace:
Reference Model: A variable 'age' acts as a label pointing to an int object (value: 100, type: int, refcount: 1) on the Python heap.
Why Programs Need Variables

Programs exist to process information — user names, product prices, high scores, and account balances. A variable allows a program to hold and label a piece of data in memory so it can be retrieved and modified later.

Real-Life Analogy: The Labeled Storage Box

Imagine organizing a workshop with labeled storage boxes. One box is labeled shoes, another is labeled tools. In Python, a variable name is like the label on the box, and the value is whatever you place inside. A data type defines what kind of item the box holds.

What Is a Variable?

In Python, you create a variable the exact moment you assign a value to it using the assignment operator =:

Python 
1name = "Riya"2age = 20
Variable Name name
➔ = ➔
Object in Memory "Riya" (str)
Under the Hood: Names Refer to Objects

While the labeled-box analogy is great for beginners, under the hood Python creates an object in memory (like "Riya") and attaches the label name as a reference (pointer) to that object.

03

Creating and Updating Variables

📊 Figure 3.2: Dynamic Rebinding and Reference Counting in Python
Reassigning a variable does not overwrite existing object memory; it simply updates the variable's pointer. When an object's reference count falls to zero, Python's automatic garbage collector deallocates it.
Visual Summary & Trace:
Rebinding Flow: x originally points to int 10. When x = 'Python' is executed, x references the new string object, leaving 10 with ref count 0 ready for garbage collection.

Variables are called variable because their values can vary (change) as your program runs. When you assign a new value to an existing variable, Python updates the reference:

Python 
1score = 102print(score)34score = 255print(score)
>_ Output
10 25
🛒 Real-Life Calculation: Shopping Bill
Python 
1price = 1002quantity = 33total = price * quantity45print(total)
>_ Output
300

Rules for Naming Variables

📊 Figure 3.3: PEP 8 Python Identifier and Variable Naming Rules
Python identifiers must start with a letter (a-z, A-Z) or underscore (_), followed by letters, digits, or underscores. They are case-sensitive and must never collide with reserved keywords or contain hyphens.
Visual Summary & Trace:
Identifier Rules: Valid (user_age, _cache, MAX_LIMIT) vs Invalid (2user, user-name, for, my score).

Python has specific rules and best practices for creating variable names:

🔤
Allowed Characters

Variable names can only contain letters (a-z, A-Z), digits (0-9), and underscores (_).

1️⃣
Cannot Start With a Digit

age2 is valid, but 2age is invalid and causes an immediate SyntaxError.

🔠
Case-Sensitive

total, Total, and TOTAL are three completely different variables.

🚫
No Reserved Keywords

You cannot name variables after Python keywords like class, if, for, or while.

Variable Name Validity Explanation
student_name Valid Uses clean snake_case with letters and an underscore.
age2 Valid Digits are allowed as long as they are not the first character.
_total Valid An underscore is a valid starting character in Python.
2age Invalid Variable names cannot start with a numerical digit.
student-name Invalid Contains a hyphen, which Python interprets as a subtraction minus operator.
class Invalid class is a reserved Python language keyword.
05

What Are Data Types?

Definition: Data Type

A data type tells Python what kind of value a variable represents and determines which operations are allowed on it. You can multiply numbers, but you cannot subtract text!

Python automatically detects the data type based on the value you assign. Let's explore Python's built-in fundamental types:

06

Integer (int)

An integer is a whole number without any decimal point. It can be positive, negative, or zero:

Python 
1age = 202students = 4534print(age)5print(type(age))
>_ Output
20 <class 'int'>

Real-world uses: Counting objects, ages, page numbers, item quantities in a shopping cart.

07

Floating-Point (float)

A floating-point number represents a real number with a decimal fraction:

Python 
1price = 99.502temperature = 36.634print(price)5print(type(price))
>_ Output
99.5 <class 'float'>

Real-world uses: Prices, weights, body temperatures, GPA scores, sensor readings.

08

String (str)

A string is a sequence of characters used to store text. Strings are always enclosed in matching single or double quotation marks:

Python 
1name = "Aman"2city = "Lucknow"34print("Name:", name)5print("City:", city)6print(type(name))
>_ Output
Name: Aman City: Lucknow <class 'str'>
09

Boolean (bool)

A Boolean represents one of two logical states: True or False. Notice that in Python, both must be capitalized!

Python 
1is_student = True2is_logged_in = False34print(is_student)5print(type(is_student))
>_ Output
True <class 'bool'>

Real-world uses: Tracking login state, verification flags, toggling settings.

10

Additional Essential Types

📊 Figure 3.7: Mutable vs. Immutable Objects in Python Memory
Immutable objects cannot have their internal payload altered once instantiated; operations that seem to modify them allocate fresh objects. Mutable objects allow direct modifications to their internal elements without changing their identity.
Visual Summary & Trace:
Mutability Matrix: Immutable (int, float, str, tuple) reallocates upon modification; Mutable (list, dict, set) alters items in place at the same memory address.

As your programs grow, you will store groups of values using Python's built-in collection types:

⚪
NoneType (None)

Represents the intentional absence of a value. data = None

📋
List [ ]

An ordered, mutable (changeable) list of items. fruits = ["apple", "banana"]

🔒
Tuple ( )

An ordered, immutable (unchangeable) sequence. coordinates = (10, 20)

📖
Dictionary { }

A key-value mapping of data. user = {"name": "Riya", "age": 20}

🎯
Set { }

An unordered collection of unique elements with no duplicates. colors = {"red", "blue"}

Type Conversion (Type Casting)

📊 Figure 3.8: Explicit Type Casting Pipeline and Conversion Limits
Type casting functions convert values between scalar data types. Floating-point strings cannot be parsed directly by `int()`, and casting floats to integers truncates decimal digits rather than rounding.
Visual Summary & Trace:
Type Casting: int('42') → 42; float('3.14') → 3.14; int(9.99) → 9 (truncation); int('3.14') raises ValueError (must parse via float first).

Sometimes you receive data in one format (such as text from a web form) and need to convert it into a number to perform calculations. This process is called type casting:

🔢 Converting String to Integer
Python 
1age_text = "20"2age_number = int(age_text)34print(age_number + 5)
>_ Output
25
🔡 Converting Number to String
Python 
1price = 492price_text = str(price)34print("Price: " + price_text)
>_ Output
Price: 49
Caution: Invalid Conversion Error

You can only convert text containing actual digits. Attempting to convert word characters like int("hello") causes Python to crash with a ValueError: invalid literal for int()!

14

Difference Between a Number and Numeric Text

One of the most frequent beginner bugs comes from confusing numeric text with actual numbers:

Numeric Integer: age = 20

An actual number. Python performs mathematical addition:

print(20 + 5) # Output: 25
String Text: age_text = "20"

A sequence of characters. Python concatenates (joins) the strings:

print("20" + "5") # Output: "205"

Common Beginner Mistakes & Fixes

Common Mistake Broken Code Correct Fix Why It Matters
Unquoted Strings name = Aman name = "Aman" Without quotes, Python looks for a variable called Aman instead of text.
Lowercase Booleans is_valid = true is_valid = True Python requires capitalized True and False.
Adding String + Number print("Score: " + 95) print("Score: " + str(95)) Python cannot concatenate strings with integers directly.
Confusing = and == if score = 100: if score == 100: = assigns a value; == compares two values.
Invalid Variable Name 1st_place = "Riya" first_place = "Riya" Variable names cannot begin with a number.

Quick Revision & Key Takeaways

✅ Five Golden Rules to Remember
  • ✓ Variables are references pointing to objects in memory; created upon assignment with =.
  • ✓ Core types: int (whole numbers), float (decimals), str (text in quotes), bool (True/False).
  • ✓ Use type() to inspect what data type any variable holds.
  • ✓ Type casting converts data between compatible formats (e.g. int("20") produces 20).
  • ✓ Variables are case-sensitive: age, Age, and AGE are three distinct variables.
Concept / Question Quick Answer
What is a variable? A named reference to an object stored in memory.
How do you assign a variable? Using the = operator (e.g., score = 100).
What function checks data types? type(variable)
How do you convert text to integer? int("25")
What is the difference between 20 and "20"? 20 is an int (math enabled); "20" is a str (text literal).
