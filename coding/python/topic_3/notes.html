Topic Introduction

So far you've learned what Python is and how to write your first line of code. Now it's time to learn how Python actually stores information — using variables — and the different types of information it can store.

💡 What you'll walk away with

You'll be able to create variables, name them correctly, understand Python's core data types, convert between them, and know the difference between things that can and can't be changed.

02

What is a Variable?

VARIABLE
A named container that stores a piece of information (data) so your program can use it later.
Example: a box labeled "age" that holds the number 20.
A variable is just a labeled box

In Python, a variable holds a value, and you refer to that value using the variable's name.

03

Why Do We Need Variables?

Without variables, you'd have to retype the same value everywhere, and you'd have no way to change it as your program runs. Variables let you:

  • Store information so it isn't lost.
  • Reuse that information many times without retyping it.
  • Update the value whenever needed.
  • Give data a meaningful name, making code easier to read.
💡 Simple Analogy

Think of a variable like a labeled jar in your kitchen. You can look inside anytime, use what's in it, or replace its contents — the jar's label stays the same even if what's inside it changes.

04

How Variables Work in Python

In Python, you don't need to announce a variable's type in advance. You simply give it a name and a value using the equals sign =, and Python takes care of the rest.

Creating and using a variable
05

Creating a Variable

Concept

To create a variable, write its name, then =, then the value you want to store.

Syntax 
variable_name = value
Example
Python
name = "Shailendra"
age = 20
Output

(No output yet — we haven't asked Python to display anything. We'll add print() next.)

Easy Explanation

name is a variable that now stores the text "Shailendra". age is a variable that now stores the number 20. Python figured out the type of each one automatically.

Python
name = "Shailendra"
age = 20
print(name)
print(age)
Output
Shailendra
20
06

Variable Naming Rules

  • A name cannot start with a number.
  • Spaces are not allowed — use an underscore instead.
  • Only letters, numbers, and underscores _ are allowed.
  • Names are case-sensitive (age and Age are different).
  • You cannot use a Python keyword (like if, for, class) as a variable name.
🧠 Good Habit

Use names that describe what the variable holds — student_name is much clearer than x.

07

Valid vs Invalid Names

✅ Valid

student_name, age2, _marks, totalPrice

❌ Invalid

2name (starts with a number), student-name (hyphen not allowed), student name (space not allowed), class (reserved keyword)

08

Multiple Variable Assignment

Concept

Python lets you assign the same value to several variables at once, in a single line.

Syntax 
a = b = c = value
Example
Python
x = y = z = 10
print(x, y, z)
Output 
10 10 10
Easy Explanation

All three names — x, y, and z — now point to the same value, 10.

09

Assigning Multiple Values

Concept

Python also lets you assign different values to multiple variables in just one line.

Syntax 
a, b, c = value1, value2, value3
Example
Python
name, age, city = "Riya", 21, "Delhi"
print(name, age, city)
Output 
Riya 21 Delhi
Easy Explanation

The first value goes to the first variable, the second to the second, and so on — matched left to right, in order.

10

Swapping Variables

Concept

Python makes it very easy to swap the values of two variables — no extra "helper" variable needed.

Example
Python
a = 5
b = 10
a, b = b, a
print(a, b)
Output 
10 5
Easy Explanation

Python calculates both new values first, then assigns them together — so a gets what b used to have, and b gets what a used to have, all in one clean step.

11

Constants in Python

CONSTANT
A value that is meant to stay the same throughout the program.
Example: PI = 3.14
Python
PI = 3.14
GRAVITY = 9.8
⚠️ Good to know

Python doesn't have a built-in, enforced way to stop a constant from changing — it's purely a naming convention. Writing a name in ALL_CAPS is a signal to other programmers: "please don't change this value."

12

What is a Data Type?

DATA TYPE
A category that tells Python what kind of value something is, and what you can do with it.
Example: numbers, text, and true/false values are all different data types.

Knowing a value's data type matters because different types support different operations — you can add two numbers, but "adding" two pieces of text works differently (it joins them together).

14

Numeric Types: int, float, complex

int (integer)

Concept

A whole number, with no decimal point — positive, negative, or zero.

Example
Python
marks = 90
print(marks)
Output
90
Easy Explanation

90 has no decimal point, so Python treats it as an int.

float (floating-point number)

Concept

A number that has a decimal point.

Example
Python
price = 99.50
print(price)
Output
99.5
Easy Explanation

The decimal point tells Python this is a float, used for values that need more precision than a whole number.

complex (complex number)

Concept

A number that has a "real" part and an "imaginary" part, written with a j. This is mostly used in specialized math and engineering work.

Example
Python
value = 2 + 3j
print(value)
Output
(2+3j)
Easy Explanation

You won't need this often as a beginner — just know it exists as one of Python's built-in numeric types.

15

Boolean (bool)

Concept

A value that can only be True or False. Booleans are used to represent yes/no, on/off type decisions.

Syntax 
variable = True
Example
Python
is_active = True
is_admin = False
print(is_active)
Output
True
Easy Explanation

Notice True and False start with a capital letter in Python — this matters, because Python is case-sensitive.

16

String (str)

Concept

A sequence of characters (letters, numbers, symbols) treated as text, written inside quotes.

Syntax 
variable = "text here"
Example
Python
message = "Welcome to CodeVerse"
print(message)
Output
Welcome to CodeVerse
Easy Explanation

Anything inside single ' ' or double " " quotes is treated as a string in Python.

17

List

Concept

An ordered collection of items that can be changed after creation. Written using square brackets.

Syntax 
variable = [item1, item2, item3]
Example
Python
fruits = ["apple", "banana", "mango"]
print(fruits)
Output
['apple', 'banana', 'mango']
Easy Explanation

A list is like a shopping list — items are kept in order, and you can add, remove, or change items later.

18

Tuple

Concept

An ordered collection of items that cannot be changed after creation. Written using round brackets.

Syntax 
variable = (item1, item2, item3)
Example
Python
coordinates = (10, 20)
print(coordinates)
Output
(10, 20)
Easy Explanation

Use a tuple when you want to store values that should stay fixed and not be accidentally modified later.

19

Set

Concept

An unordered collection that automatically removes duplicate values. Written using curly brackets.

Syntax 
variable = {item1, item2, item3}
Example
Python
numbers = {1, 2, 2, 3}
print(numbers)
Output
{1, 2, 3}
Easy Explanation

Notice the repeated 2 disappeared — a set automatically keeps only one copy of each value, and doesn't preserve a fixed order.

20

Dictionary

Concept

A collection of key–value pairs — each value is accessed using its own unique key, instead of a position number.

Syntax 
variable = {key1: value1, key2: value2}
Example
Python
student = {"name": "Riya", "age": 21}
print(student)
Output
{'name': 'Riya', 'age': 21}
Easy Explanation

Think of it like a real dictionary — you look up a "word" (the key, like "name") to find its "meaning" (the value, like "Riya").

21

NoneType

Concept

None is a special value that represents "nothing" or "no value assigned yet."

Example
Python
result = None
print(result)
Output
None
Easy Explanation

None is not the same as 0 or an empty string — it specifically means "there is no value here."

22

Checking Type with type()

Concept

The built-in type() function tells you the data type of any value or variable.

Example
Python
age = 20
print(type(age))
Output
<class 'int'>
Easy Explanation

type() looked at the value stored in age and reported that it's an int.

23

Type Conversion / Type Casting

TYPE CASTING
Converting a value from one data type into another, on purpose.
Example: turning the text "10" into the number 10.
int()
value = int("10")
print(value)
10
float()
value = float("9.5")
print(value)
9.5
str()
value = str(25)
print(value)
25
bool()
value = bool(1)
print(value)
True
list()
value = list((1, 2, 3))
print(value)
[1, 2, 3]
tuple()
value = tuple([1, 2, 3])
print(value)
(1, 2, 3)
set()
value = set([1, 1, 2])
print(value)
{1, 2}
dict()
value = dict(name="Riya", age=21)
print(value)
{'name': 'Riya', 'age': 21}
⚠️ Watch out

Not every conversion makes sense. int("hello") will cause an error, because the text "hello" isn't a number Python can understand.

24

Mutable vs Immutable

MUTABLE
Can be changed after it's created.
Example: a list — you can add or remove items.
IMMUTABLE
Cannot be changed after it's created — any "change" actually creates a brand-new value.
Example: a string or a tuple.

🔓 Mutable examples

list, dict, set

🔒 Immutable examples

int, float, bool, str, tuple

Python
fruits = ["apple", "banana"]
fruits[0] = "mango"
print(fruits)
Output
['mango', 'banana']

The list changed in place — this is only possible because lists are mutable.

25

Dynamic Typing

DYNAMIC TYPING
A variable's type is decided automatically, based on the value it currently holds — and it can change if you assign a new, different kind of value.
Python
x = 10
print(type(x))

x = "Hello"
print(type(x))
Output
<class 'int'>
<class 'str'>

The same variable x first held a number, then held text — Python adjusted automatically both times, without you needing to declare anything.

26

Common Beginner Mistakes

❌ Wrong: Starting a variable name with a number
2name = "Riya"
✅ Correct: name2 = "Riya"
❌ Wrong: Using spaces in a variable name
student name = "Riya"
✅ Correct: student_name = "Riya"
❌ Wrong: Mixing up quotes and numbers
age = "20"
print(age + 5)
✅ Correct: age = 20 then print(age + 5)

Here "20" is text, not a number — Python cannot add text and a number directly, so this causes an error.

❌ Wrong: Using a Python keyword as a variable name
class = "10th"
✅ Correct: student_class = "10th"

28

Key Points to Remember

  • A variable is created the moment you assign it a value with =.
  • You never have to declare a variable's type in Python — it's automatic.
  • Variable names cannot start with a number or contain spaces.
  • Python has 4 main numeric-and-basic types: int, float, complex, and bool.
  • str stores text; collections (list, tuple, set, dict) store multiple values.
  • type() tells you exactly what data type a value is.
  • Type casting functions like int(), str(), and float() convert between types.
  • Lists, sets, and dictionaries are mutable; numbers, strings, and tuples are immutable.
  • Python is dynamically typed — the same variable can hold different types at different times.
