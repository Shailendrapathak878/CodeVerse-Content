Topic Introduction

02

What is Input in Python?

INPUT
Information the user types in while the program is running, which the program can then use.
Example: asking someone to type their name.
Input → Program → Output

Input is what makes a program feel alive — instead of always doing the exact same thing, it can react to whatever the user provides.

03

The input() Function

Concept

input() is a built-in function that pauses your program, waits for the user to type something and press Enter, and gives that text back to your code.

Syntax 
variable = input("Message to show the user: ")
Example
Python
name = input("Enter your name: ")
print("Hello,", name)
Output 
Enter your name: Riya
Hello, Riya
Easy Explanation

The text inside input("...") is just a message (called a prompt) shown to the user. Whatever the user types after that gets stored inside the variable name. (Here, "Riya" is what the user typed.)

04

Taking Input from the User

You can ask for as many separate pieces of input as your program needs — one input() call per piece of information.

Python
name = input("Enter your name: ")
city = input("Enter your city: ")
print(name, "is from", city)
Output (user typed Aman and Pune)
Enter your name: Aman
Enter your city: Pune
Aman is from Pune
05

input() Always Returns a String

⚠️ Important rule

No matter what the user types — even if it looks like a number — input() always gives it back as a string (text).

Python
age = input("Enter your age: ")
print(type(age))
Output (user typed 20)
Enter your age: 20
<class 'str'>

Even though the user typed 20, Python treats it as the text "20", not the number 20 — until you convert it.

06

Converting Input Data Types

Concept

If you need the input as a number, wrap input() with int() or float() to convert it.

Example
Python
age = int(input("Enter your age: "))
print(age + 5)
Output 
Enter your age: 20
25
Easy Explanation

input() gives back "20" (text), and int() immediately converts it to 20 (a number) — so it can now be used in maths like age + 5.

🧠 Remember this

Text input for a number → always convert it first with int() or float() before doing any calculation.

07

What is Output in Python?

OUTPUT
Whatever your program displays back to the user, usually on the screen.
Example: showing a calculated total, a greeting, or a result.

You've already been using output since Chapter 2 — every time you use print(), you're producing output.

08

The print() Function Recap

Python
print("CodeVerse makes learning easy")
Output
CodeVerse makes learning easy

print() can display text, numbers, variables, or several values together — it's the main way Python programs communicate with the user.

09

print() with sep and end

Concept

print() has two handy optional settings: sep controls what goes between multiple values, and end controls what's added after the whole line (a new line, by default).

Example
Python
print("Python", "is", "fun", sep="-")
print("Loading", end="...")
print("Done")
Output 
Python-is-fun
Loading...Done
Easy Explanation

sep="-" joined the words with a dash instead of a space. end="..." replaced the normal new-line after "Loading" with three dots, so "Done" continued on the same line.

10

Formatting Output with f-strings

Concept

An f-string lets you insert variables directly inside a piece of text, by placing them in curly braces { } and putting an f right before the opening quote.

Syntax 
f"some text {variable} more text"
Example
Python
name = "Riya"
age = 21
print(f"My name is {name} and I am {age} years old.")
Output 
My name is Riya and I am 21 years old.
Easy Explanation

Python replaces {name} and {age} with the actual values stored in those variables — this is the cleanest, most beginner-friendly way to build a sentence out of variables.

11

Concatenation vs f-strings

Before f-strings, people joined text and variables using the + symbol — this is called concatenation.

🔧 Concatenation (older style)

age = 21
print("Age: " + str(age))

✅ f-string (recommended)

age = 21
print(f"Age: {age}")
Both print
Age: 21
⚠️ Watch out with concatenation

With +, you can only join strings with other strings. A number must be wrapped in str() first, or Python will raise an error. f-strings don't have this problem — they convert values for you automatically.

Assignment Operators

Used to assign values to variables — including "update and assign in one step" shortcuts.

=
Assignx = 5
+=
Add and assignx += 3 → same as x = x + 3
-=
Subtract and assignx -= 3 → same as x = x - 3
*=
Multiply and assignx *= 3 → same as x = x * 3
/=
Divide and assignx /= 3 → same as x = x / 3
Python

x += 5
print(x)
Output
15
15

Comparison Operators

Used to compare two values — the result is always True or False.

==
Equal to5 == 5 → True
!=
Not equal to5 != 3 → True
>
Greater than5 > 3 → True
<
Less than5 < 3 → False
>=
Greater than or equal to5 >= 5 → True
<=
Less than or equal to5 <= 3 → False
⚠️ Common confusion

= assigns a value to a variable. == checks if two values are equal. Mixing them up is one of the most common beginner mistakes.

16

Logical Operators

Used to combine multiple True/False conditions.

and
True only if both sides are True(5 > 2) and (3 > 1) → True
or
True if at least one side is True(5 > 2) or (3 < 1) → True
not
Flips True to False, and vice versanot (5 > 2) → False
Python
age = 20
has_id = True
print(age >= 18 and has_id)
Output
True
17

Bitwise Operators

These work on the actual binary (0s and 1s) representation of numbers. They're less common for beginners, but good to recognize.

&
Bitwise AND5 & 3 → 1
|
Bitwise OR5 | 3 → 7
^
Bitwise XOR5 ^ 3 → 6
~
Bitwise NOT~5 → -6
<<
Left Shift5 << 1 → 10
>>
Right Shift5 >> 1 → 2
📌 For now

As a beginner, you don't need to master bitwise operators yet — just know they exist and work on individual bits, not whole numbers the way arithmetic operators do.

18

Identity Operators

Used to check whether two variables point to the exact same object in memory — not just whether their values look equal.

is
True if both are the same object
is not
True if they are not the same object
Python
a = [1, 2, 3]
b = [1, 2, 3]
print(a == b)
print(a is b)
Output
True
False

a == b is True because both lists contain the same values. a is b is False because they are two separate lists stored in different places in memory, even though they look the same.

19

Membership Operators

Used to check if a value exists inside a collection, like a list or a string.

in
True if the value is found inside
not in
True if the value is NOT found inside
Python
fruits = ["apple", "banana", "mango"]
print("banana" in fruits)
print("grape" not in fruits)
Output
True
True
20

Operator Precedence

OPERATOR PRECEDENCE
The order in which Python evaluates operators when a line has more than one of them — just like "multiplication before addition" in normal maths.
Python
print(10 + 2 * 3)
Output
16

Python multiplies 2 * 3 first (giving 6), and only then adds 10 — the same order you'd use by hand. When in doubt, use brackets ( ) to make the order crystal clear.

Python
print((10 + 2) * 3)
Output
36

Common Beginner Mistakes

❌ Wrong: Doing maths on raw input() without converting it
age = input("Enter age: ")
print(age + 5)
✅ Correct: age = int(input("Enter age: "))

Without conversion, age is text, and Python cannot add text and a number together.

❌ Wrong: Confusing = with ==
if x = 5:
✅ Correct: if x == 5:
❌ Wrong: Expecting / to give a whole number
print(7 / 2)  # gives 3.5, not 3
✅ Correct: use // for floor division: print(7 // 2) → 3
❌ Wrong: Forgetting f before an f-string
name = "Riya"
print("Hello {name}")
✅ Correct: print(f"Hello {name}")

Without the f, Python treats {name} as plain text, not a placeholder to fill in.

Key Points to Remember

  • input() always returns a string, even for numbers — convert it with int() or float() when needed.
  • print() can take multiple values, plus optional sep and end settings.
  • f-strings (f"{variable}") are the cleanest way to combine text and variables.
  • Arithmetic operators handle maths: + - * / // % **.
  • / always gives a float; // gives a whole number (floor division).
  • Comparison operators return True or False — don't confuse = with ==.
  • Logical operators (and, or, not) combine multiple conditions.
  • is checks identity (same object); == checks equal value.
  • in and not in check membership inside a collection.
  • Use brackets ( ) to make the order of operations clear when a line has multiple operators.
