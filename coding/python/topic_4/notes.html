Taking Input in Python

Definition: Input

Input is any information provided to the program from the outside world — whether typed on a keyboard, selected from a form, or read from a sensor.

Syntax of input()
variable_name = input("Optional prompt message to user: ")
⏸️
Execution Pauses

When Python encounters input(), it halts execution and waits patiently until the user types something and presses Enter.

🔤
Always Returns a String

Even if the user types 25 or 100.5, Python receives it as text: "25" or "100.5". It is always of type str.

⚙️ Example: Interactive Name Greeting
Python 
1name = input("Enter your name: ")2print("Hello,", name)
>_ Output (User typed "Riya")
Enter your name: Riya Hello, Riya
Step-by-Step Explanation
  • 1 input("Enter your name: ") shows the prompt text on screen and waits for user keystrokes.
  • 2 The user types Riya and hits Enter. Python captures "Riya" and assigns it to name.
  • 3 print("Hello,", name) prints the greeting, automatically inserting a space before the variable value.
03

Converting Input Types

The "String Number" Trap

If you ask for an age and the user types 18, input() gives you "18" (text). If you write age + 1, Python crashes with a TypeError: can only concatenate str (not "int") to str!

To perform mathematical operations, you must wrap input() inside a conversion function like int() or float():

🔢 Example: Converting to Integer
Python 
1age = int(input("Enter your age: "))2print("Next year, you will be", age + 1)
>_ Output (User typed "19")
Enter your age: 19 Next year, you will be 20
💵 Example: Converting to Decimal Float
Python 
1price = float(input("Enter product price: "))2print("Price with ₹10 discount:", price - 10)
>_ Output (User typed "99.50")
Enter product price: 99.50 Price with ₹10 discount: 89.5
Why int("12.5") Fails while float("12.5") Works

The function int() strictly expects integer digits in text strings. int("12.5") causes a ValueError because of the decimal point. However, float("12.5") works cleanly. If you need a whole number from decimal input text, convert to float first: int(float("12.5")) ➔ 12.

Taking Multiple Inputs

You can take multiple inputs either across separate lines or in a single line using .split():

Method 1: Multiple input() Calls (Separate Lines)
Python 
1name = input("Enter your name: ")2city = input("Enter your city: ")3print(name, "lives in", city)
Method 2: Space-Separated Single Line with .split()
Python 
1first, last = input("Enter first and last name: ").split()2print("First:", first)3print("Last :", last)
>_ Output (User typed "Riya Sharma")
Enter first and last name: Riya Sharma First: Riya Last : Sharma
Method 3: Multiple Numbers in One Line with map()
Python 
1a, b = map(int, input("Enter two numbers: ").split())2print("Sum:", a + b)
>_ Output (User typed "10 25")
Enter two numbers: 10 25 Sum: 35
Unpacking Mismatch Warning

If you write a, b = input().split(), Python expects exactly two items. If the user enters only one word, Python raises ValueError: not enough values to unpack. If the user enters three words, it raises ValueError: too many values to unpack.

Displaying Output in Python

The print() function is Python's standard tool for displaying text, numbers, calculations, and variables on screen.

Syntax & Parameters of print()
print(value1, value2, ..., sep=" ", end="\n")
↔️
sep (Separator)

Controls what goes between multiple items printed in the same call. Default is a single space " ".

🔚
end (Ending Character)

Controls what gets printed at the very end of the line. Default is a newline "\n".

⚙️ Example: Customizing sep and end
Python 
1# Custom separator2print("Python", "is", "easy", sep="-")34# Custom end (keeps next print on the same line)5print("Hello", end=" ")6print("World!")
>_ Output
Python-is-easy Hello World!
✨ Modern Formatting with f-strings

Prefixing a string with f allows you to insert variables directly inside curly braces { }:

Python 
1name = "Aman"2age = 203print(f"{name} is {age} years old.")
>_ Output
Aman is 20 years old.

What Are Operators?

Definition: Operators & Operands

Operators are special symbols that carry out operations on values and variables. The values the operator acts upon are called operands.

In 5 + 3: 5 and 3 are operands, and + is the operator.

Category Symbols Primary Purpose Quick Example
Arithmetic + - * / // % ** Perform basic mathematics 10 + 5 ➔ 15
Comparison == != > < >= <= Compare two values (gives True/False) 10 > 5 ➔ True
Logical and or not Combine conditional expressions True and False ➔ False
Assignment = += -= *= /= Assign and update variable values x += 5 (adds 5 to x)
Membership in not in Check if an item exists inside a collection 'a' in 'cat' ➔ True
Identity is is not Check if two variables reference the same object a is b
Bitwise & | ^ ~ << >> Operate on individual binary bits 5 & 3 ➔ 1

Arithmetic Operators in Detail

Arithmetic operators handle standard mathematical calculations:

Operator Name Description Example Result
+ Addition Adds two numbers 10 + 3 13
- Subtraction Subtracts second number from first 10 - 3 7
* Multiplication Multiplies two numbers 10 * 3 30
/ Float Division Divides first by second (always a float) 10 / 2 5.0
// Floor Division Divides and rounds DOWN to nearest integer 10 // 3 3
% Modulus Returns the division remainder 10 % 3 1
** Exponentiation Raises first number to the power of second 2 ** 3 8
/ vs // (Floor Division)

7 / 2 gives 3.5 (float).
7 // 2 chops off the decimal and gives 3 (integer).

% (Modulus: The Remainder)

If you divide 14 candies among 4 kids: 14 // 4 = 3 candies each. The leftover candy is 14 % 4 = 2!

08

Comparison Operators

Comparison operators test relationships between values and always evaluate to a Boolean: True or False.

Operator Meaning Example Result
== Equal to 5 == 5 True
!= Not equal to 5 != 3 True
> Greater than 10 > 20 False
< Less than 10 < 20 True
>= Greater than or equal to 18 >= 18 True
<= Less than or equal to 15 <= 10 False
Crucial Rule: = vs ==

A single equals sign = is the assignment operator (stores a value: x = 5).
A double equals sign == is the comparison operator (checks equality: x == 5).

Logical Operators

Logical operators allow you to combine multiple conditions together:

🔗
and (Both Must Be True)

Returns True only if both conditions evaluate to True. Example: age >= 18 and marks >= 75

🔀
or (Either Can Be True)

Returns True if at least one condition is True. Example: has_coupon or is_member

🔄
not (Reverses Truth)

Flips the truth value. If a condition is True, not makes it False.

A B A and B A or B not A
True True True True False
True False False True False
False True False True True
False False False False True

11

Membership and Identity Operators

Membership (in, not in)

Checks whether a value is present inside a sequence like a string or list:

print("a" in "apple") # True
print(5 not in [1, 2, 3]) # True
Identity (is, is not)

Checks whether two variables refer to the exact same memory location:

a = [1, 2]
b = [1, 2]
print(a == b) # True (same values)
print(a is b) # False (separate lists)
Equality (==) vs Identity (is)

== compares whether two objects hold the same value.
is checks whether both variables point to the exact same object in RAM. They are not interchangeable!

Bitwise Operators (Introductory)

Bitwise operators perform calculations directly on the individual binary bits (0s and 1s) of integer numbers:

Operator Name Binary Operation Example (5 & 3)
& AND 1 if both bits are 1 5 (0101) & 3 (0011) = 1 (0001)
| OR 1 if either bit is 1 5 (0101) | 3 (0011) = 7 (0111)
^ XOR 1 if bits are different 5 (0101) ^ 3 (0011) = 6 (0110)
~ NOT Inverts all bits (formula: -x - 1) ~5 = -6
<< Zero-fill Left Shift Shifts bits left (multiplies by 2) 5 << 1 = 10
>> Signed Right Shift Shifts bits right (divides by 2) 5 >> 1 = 2

Operator Precedence

When multiple operators appear in a single expression, Python evaluates them following strict precedence rules (similar to PEMDAS in mathematics):

Python 
1result1 = 2 + 3 * 42result2 = (2 + 3) * 434print("Without parentheses:", result1)5print("With parentheses   :", result2)
>_ Output
Without parentheses: 14 With parentheses : 20
Precedence Rank Operators Description
1 (Highest) ( ) Parentheses (always evaluated first)
2 ** Exponentiation
3 +x, -x, ~x Unary positive, negative, bitwise NOT
4 *, /, //, % Multiplication, division, remainder
5 +, - Addition and subtraction
6 ==, !=, >, <, >=, <=, is, in Comparison, identity, membership
7 not, and, or Logical operators
8 (Lowest) =, +=, -=, *=, /= Assignments

Quick Revision & Summary

Feature input() print()
Direction Inward (from user to computer) Outward (from computer to screen)
Return Type Always returns a str Returns None
Execution Halt Pauses program until Enter is pressed Executes immediately and moves to next line
Key Arguments Prompt message string sep (separator), end (terminal char)
✅ Six Golden Rules to Remember
  • ✓ input() always returns a string; wrap in int() or float() for numbers.
  • ✓ .split() breaks multi-value single-line text into a list of strings by whitespace.
  • ✓ In print(), sep controls gaps between items, while end controls the ending character.
  • ✓ Floor division // rounds down to an integer quotient; modulus % gives the division remainder.
  • ✓ == tests value equality; is tests object identity in memory.
  • ✓ Always use parentheses ( ) to make multi-operator math expressions crystal clear.
Viva / Interview Question Concise Technical Answer
What does input() return if user enters 45? It returns the string "45", not an integer.
What is the difference between / and //? / is true division (gives float 2.5); // is floor division (gives integer 2).
How do you take 2 integers in one line? a, b = map(int, input().split())
What is the difference between == and is? == checks if values are equal; is checks if both variables reference the exact same memory address.
How do you print without a newline at the end? Set end=" " or end="" inside print().
