01

Topic Introduction

Imagine you need to greet 100 people. Would you copy the same lines 100 times?

No way. You write the lines once, give them a name, and use that name whenever you need them. That is a function.

💡 What you'll learn
  • Create your own functions with def
  • Send data in and get results back
  • Use default and keyword arguments
  • Understand local and global variables
02

What is a Function?

FUNCTION
A named block of code that does one job. You can run it as many times as you want.
Example: print() and len() are functions.
💡 Real-life analogy

Think of a juice machine. You put fruit in, it does the work, and juice comes out. You do not care how it works inside.

A function is like a machine
03

Why Use Functions?

  • Reuse — write once, use many times.
  • Less repetition — no copy-pasting code.
  • Easy to fix — change it in one place, and it is fixed everywhere.
  • Easy to read — a good name explains what the code does.
  • Teamwork — big programs are split into small, simple parts.
🧠 Remember this

Programmers love the rule "Don't Repeat Yourself". Functions are how you follow it.

04

Defining and Calling a Function

Concept

You use def to define (create) a function. Then you call (run) it by writing its name with brackets.

Syntax 
def function_name():
    # code inside the function (indented)

function_name()   # call it
Example
Python
def greet():
    print("Hello!")

greet()
greet()
Output 
Hello!
Hello!
Easy Explanation
  • def greet(): creates the function. Nothing runs yet.
  • Each greet() call runs the code inside it.
  • Two calls means two "Hello!" lines.

The 4 parts of a function

  1. The keyword def
  2. A name you choose
  3. Brackets ( ) and a colon :
  4. An indented body
What happens when you call a function
⚠️ Define before you call

A function must be defined above the line that calls it. Otherwise Python says it does not know that name.

05

Parameters and Arguments

Functions can take input. Two words describe this, and beginners mix them up.

📥 Parameter

The variable name inside the function's brackets. It is a placeholder.

📤 Argument

The real value you send when you call the function.

Example
Python
def greet(name):
    print("Hello,", name)

greet("Riya")
greet("Aman")

def add(a, b):
    print(a + b)

add(3, 4)
Output 
Hello, Riya
Hello, Aman
7
Easy Explanation
  • name, a and b are parameters.
  • "Riya", 3 and 4 are arguments.
  • Arguments go to parameters in order: 3 goes to a, 4 goes to b.
06

Return Values

Concept

return sends a result back to the place that called the function. You can then store it or use it in a calculation.

Syntax 
def function_name(parameters):
    return value
Example
Python
def add(a, b):
    return a + b

result = add(3, 4)
print(result)
print(add(10, 5) * 2)
Output 
7
30
Easy Explanation
  • add(3, 4) gives back 7, which is stored in result.
  • add(10, 5) gives 15, and then we multiply by 2.
📌 return also stops the function

The moment Python reaches return, the function ends. Lines after it do not run.

Python
def check(n):
    if n > 0:
        return "Positive"
    return "Not positive"

print(check(5))
print(check(-2))
Output
Positive
Not positive
07

print vs return

This is the #1 confusion for beginners. They look similar, but they do different jobs.

  • print() shows something on the screen.
  • return gives a value back so you can use it.
Python
def show(a):
    print(a)

x = show(5)
print(x)
Output
5
None
  • The function printed 5 on the screen.
  • But it returned nothing, so x is None.
🧠 Remember this

If a function has no return, Python quietly gives back None ("nothing").

08

Default Parameters

Concept

You can give a parameter a default value. If the caller skips it, Python uses the default.

Syntax 
def function_name(parameter=default_value):
Example
Python
def greet(name="friend"):
    print("Hello,", name)

greet()
greet("Riya")

def power(base, exp=2):
    return base ** exp

print(power(5))
print(power(2, 3))
Output 
Hello, friend
Hello, Riya
25
8
Easy Explanation
  • greet() used the default "friend".
  • power(5) used exp=2, so 5 squared is 25.
  • power(2, 3) replaced the default, so 2 cubed is 8.
⚠️ Defaults go last

Parameters with defaults must come after the ones without. Write def f(a, b=2), not def f(a=1, b).

09

Keyword Arguments

You can name each argument when you call a function. Then the order does not matter.

Python
def intro(name, age):
    print(name, "is", age, "years old")

intro("Riya", 21)
intro(age=21, name="Riya")
Output
Riya is 21 years old
Riya is 21 years old
  • The first call uses position.
  • The second call uses names, so the order is free.
  • Names make calls easier to read.
10

Returning Many Values

A function can return more than one value. Python packs them into a tuple. You can unpack them right away.

Python
def min_max(nums):
    return min(nums), max(nums)

low, high = min_max([4, 9, 1, 7])
print(low, high)
print(min_max([4, 9, 1, 7]))
Output
1 9
(1, 9)
  • The function returned (1, 9), a tuple.
  • low, high = ... unpacks it, like in Chapter 9.
11

Any Number of Arguments (*args)

Concept

Put a * before a parameter name to accept any number of arguments. Python collects them into a tuple.

Example
Python
def total(*numbers):
    s = 0
    for n in numbers:
        s += n
    return s

print(total(1, 2, 3))
print(total(5, 10))
print(total())
Output 
6
15
0
Easy Explanation
  • Inside the function, numbers is a tuple of everything you sent.
  • With no arguments, the tuple is empty, so the total is 0.
  • The name args is a habit. Any name after * works.
12

Docstrings

DOCSTRING
A short note in triple quotes, placed right under def, that explains what the function does.
Python
def square(n):
    """Return the square of n."""
    return n * n

print(square(6))
print(square.__doc__)
Output
36
Return the square of n.

Docstrings help other people (and future you) understand your code quickly.

13

Scope: Local and Global

SCOPE
The area of your code where a variable can be used.
  • Local variable — created inside a function. Only that function can see it.
  • Global variable — created outside all functions. The whole program can read it.
Who can see which variable?
Python
x = 10

def show():
    y = 5
    print(x, y)

show()
Output
10 5

Now try to use y outside the function:

Python (error)
print(y)
Error
NameError: name 'y' is not defined

Once the function finishes, its local variables disappear.

A sneaky surprise

Assigning to a name inside a function makes a new local variable. It does not change the global one.

Python
count = 0

def add_one():
    count = 1

add_one()
print(count)
Output
0

The best habit is to pass data in with parameters and get results out with return.

14

Functions Calling Functions

A function can call another function. This lets you build big things from small parts.

Python
def square(n):
    return n * n

def sum_of_squares(a, b):
    return square(a) + square(b)

print(sum_of_squares(3, 4))
Output
25

3 squared is 9, 4 squared is 16, and 9 + 16 = 25.

16

Real Examples

Is a number even?

Python
def is_even(n):
    return n % 2 == 0

print(is_even(4))
print(is_even(7))
Output
True
False

Grade from marks

Python
def grade(marks):
    if marks >= 90:
        return "A"
    elif marks >= 75:
        return "B"
    elif marks >= 50:
        return "C"
    else:
        return "Fail"

print(grade(82))
Output
B

Count vowels

Python
def count_vowels(word):
    count = 0
    for ch in word.lower():
        if ch in "aeiou":
            count += 1
    return count

print(count_vowels("Education"))
Output
5

The vowels in "Education" are E, u, a, i, o. That is 5.

17

Bonus: Lambda Functions

LAMBDA
A tiny one-line function with no name. It is handy for very short jobs.
lambda parameters: expression
Python
double = lambda x: x * 2
add = lambda a, b: a + b

print(double(5))
print(add(2, 3))
Output
10
5
  • It works like a normal function, but is written in one line.
  • The result is returned automatically. No return needed.
📌 Optional topic

If lambda feels confusing, use a normal def for now. Both do the same job.

18

Bonus: Recursion

RECURSION
When a function calls itself to solve a smaller version of the same problem.
Python
def factorial(n):
    if n == 1:
        return 1
    return n * factorial(n - 1)

print(factorial(5))
Output
120
  • factorial(5) = 5 × factorial(4)
  • …and so on, down to factorial(1), which returns 1.
  • 5 × 4 × 3 × 2 × 1 = 120.
⚠️ Always have a stopping point

The if n == 1 line is the stopping point. Without it, the function calls itself forever and Python raises an error.

19

Common Beginner Mistakes

❌ Wrong: Forgetting return, then using the result
def add(a, b):
    print(a + b)

result = add(3, 4)
print(result + 1)
Error (after printing 7)
TypeError: unsupported operand type(s) for +: 'NoneType' and 'int'
✅ Correct: use return a + b

Without return, result is None, and you cannot add 1 to None.

❌ Wrong: Forgetting the brackets when calling
greet   # nothing happens
✅ Correct: greet()

The brackets are what actually run the function.

❌ Wrong: Sending the wrong number of arguments
def add(a, b):
    return a + b

add(1)
Error
TypeError: add() missing 1 required positional argument: 'b'
✅ Correct: add(1, 2)
❌ Wrong: Calling a function before defining it
hello()

def hello():
    print("Hi")
Error
NameError: name 'hello' is not defined
✅ Correct: put the def above the call
❌ Wrong: Using a local variable outside its function
def f():
    secret = 42

f()
print(secret)
✅ Correct: return the value and store it

Local variables vanish when the function ends.

21

Key Points to Remember

  • A function is written once and used many times.
  • Use def, a name, brackets, a colon and an indented body.
  • Defining a function does not run it. You must call it.
  • Parameters are placeholders. Arguments are real values.
  • print shows a value. return gives a value back.
  • No return means the function gives back None.
  • Default values make parameters optional.
  • Variables made inside a function are local to it.
  • Pass data in with parameters. Get results out with return.
