What Is a String?

Python compares strings character-by-character based on their numeric Unicode code points (`ord()`). Because uppercase ASCII letters (65–90) precede lowercase letters (97–122), `'apple' > 'Banana'` evaluates to `True`.

In computer programming, human language is represented as text. Whether it is your username on Instagram, an email address, an SMS alert, or a product description on an e-commerce website, computers store and handle text using a data type called a string (abbreviated as str in Python).

Definition: String

A string in Python is an ordered sequence of characters enclosed inside quotation marks. A character can be an alphabet letter (A-Z, a-z), a digit (0-9), punctuation marks (!, ,, .), spaces, or even symbols and emojis.

Everyday Examples of Strings

Whenever you enclose anything inside quotes, Python treats it as literal text:

"Hello, Python!" • "user_aman99" • "contact@codeverse.in" • "₹499.00"
Python 
1name = "Aman"
2message = "Hello, World!"
3city = "Lucknow"
4
5print("Name:", name)
6print("Message:", message)
7print("City:", city)
Terminal Output
Name: Aman Message: Hello, World! City: Lucknow
🔍 Line-by-Line Breakdown
  • 1name = "Aman": Stores the 4-character text "Aman" in variable name.
  • 2message = "Hello, World!": Stores letters, a comma, a space, and an exclamation mark. All characters inside the quotes belong to the string.
  • 3city = "Lucknow": Stores the text representing a city name.
  • 5-7print(...) displays each stored string to the console.
⚖️ Numeric Value vs. Numeric String

Beginners often ask: "What is the difference between 25 and "25"?" Notice how quotation marks completely alter how Python treats data:

Value Written Data Type What Python Sees Can We Do Math?
"25" str Text containing two digit symbols: '2' and '5' ❌ No (Cannot do "25" - 5)
25 int Mathematical whole number twenty-five ✅ Yes (25 + 5 = 30)
"3.14" str Text containing four characters: '3', '.', '1', '4' ❌ No (Treated purely as text)
3.14 float Mathematical decimal number ✅ Yes (3.14 * 2 = 6.28)
"True" str A 4-letter word: 'T', 'r', 'u', 'e' ❌ No boolean logic applied
True bool Boolean truth state (logic flag) ✅ Yes (Used for conditions)
Golden Rule: Quotes Define Strings

Any piece of data wrapped inside quotation marks—whether it is letters, numbers, spaces, or symbols—is treated by Python as a string. Without quotes, Python interprets the characters as variable names, numbers, or keywords.

Common Mistake: Quote Mismatch

You cannot start a string with a single quote and close it with a double quote (e.g., 'Hello"). Both quotes must match. Furthermore, using a single quote inside single-quoted text prematurely terminates the string: 'It's raining' raises a SyntaxError. Either switch to double quotes ("It's raining") or escape it with a backslash ('It\'s raining').

String Indexing (Accessing Characters)

Think of a string as a row of numbered post boxes. Each box holds exactly one character. In Python, every character in a string has an assigned address called an index.

Two Indexing Systems in Python

Python gives you two ways to locate any character:

  • Positive Indexing (Left to Right): Begins at 0 for the first character, 1 for the second, up to length - 1.
  • Negative Indexing (Right to Left): Begins at -1 for the last character, -2 for the second-to-last, down to -length for the first.

Error Watch: IndexError (Index Out of Range)

Remember: For any string of length N, the highest positive index is always N - 1, because indexing starts at 0!

String Slicing (Extracting Substrings)

Indexing extracts a single character. But what if you want a chunk of characters, such as the first name from a full name, or the domain from an email? That is where slicing comes in.

Slicing Syntax Formula
string[start : stop : step]

• start: Starting index (included in result)
• stop: Stopping boundary index (excluded from result)
• step: Interval / jump count (defaults to 1; negative steps reverse direction)

Python 
1text = "Python Programming"
2
3# 1. Slice from index 0 up to 6 (index 6 excluded)
4print("text[0:6]:  ", text[0:6])
5
6# 2. Omitting start defaults to 0
7print("text[:6]:   ", text[:6])
8
9# 3. Omitting stop slices to the very end
10print("text[7:]:   ", text[7:])
11
12# 4. Slicing with negative index
13print("text[-11:]: ", text[-11:])
14
15# 5. Using step=2 (every second character)
16print("text[::2]:  ", text[::2])
17
18# 6. Reversing a string with step=-1
19print("text[::-1]: ", text[::-1])
Terminal Output
text[0:6]: Python text[:6]: Python text[7:]: Programming text[-11:]: Programming text[::2]: Pto rgamn text[::-1]: gnimmargorP nohtyP
Crucial Difference: Slicing Never Raises IndexError!

While indexing out of range (like text[99]) crashes your program with an IndexError, slicing handles out-of-bound indices gracefully. If you write text[0:100], Python simply returns the available string without error!

05

Strings Are Immutable (Cannot Be Changed in Place)

One of the most important concepts in Python is immutability. In plain English, immutable means "incapable of being modified after creation."

Why Python Enforces Immutability

Once Python creates a string object in memory, its characters are permanently locked. You cannot add, remove, or swap individual characters inside that existing string. If you want a modified version of text, you must create a new string and assign it.

Incorrect: Attempting Direct In-Place Character Assignment 
word = "Python"
word[0] = "J"   # ❌ CRASHES: TypeError!
Python Error Traceback
TypeError: 'str' object does not support item assignment
✅ How to Correctly "Modify" Strings in Python

To change text, either slice and concatenate, or use the replace() method to produce a brand new string:

Python 
1# Method 1: Slicing + Concatenation
2word = "Python"
3new_word = "J" + word[1:]
4print("Via Slicing:", new_word)      # Jython
5
6# Method 2: Using the replace() method
7original = "Python"
8replaced = original.replace("P", "J")
9print("Via replace():", replaced)   # Jython
10print("Original remains:", original) # Python (Untouched!)
Terminal Output
Via Slicing: Jython Via replace(): Jython Original remains: Python

Notice that original is completely unchanged. The replace() method returns a fresh string with the modifications; it does not alter the source text.

Combining and Repeating Strings

*

Finding String Length with len()

The built-in len() function counts the total number of characters in a string. It is one of the most frequently used functions in all of programming.

What Does len() Actually Count?

len() counts every single character between the quotes—including lowercase and uppercase letters, numbers, punctuation marks, and invisible whitespace characters like spaces, tabs, and newlines!

Python 
1text1 = "Hello Python"     # 11 letters + 1 space = 12
2text2 = "CodeVerse"        # 9 letters
3empty = ""                 # 0 characters (empty string)
4
5print("len('Hello Python'):", len(text1))
6print("len('CodeVerse'):   ", len(text2))
7print("len(''):            ", len(empty))
8
9# Accessing the last character using len() vs negative index
10last_char_v1 = text1[len(text1) - 1]  # text1[11] = 'n'
11last_char_v2 = text1[-1]              # idiomatic Python
12print("Last character is:", last_char_v2)
Terminal Output
len('Hello Python'): 12 len('CodeVerse'): 9 len(''): 0 Last character is: n
Note: Spaces Count as Characters!

In "Hello Python", there are 5 letters in "Hello", 1 space character, and 6 letters in "Python". Total = 5 + 1 + 6 = 12. Never forget that space is a real, measurable character in programming.

If your list contains numbers, such as [1, 2, 3], calling "-".join([1, 2, 3]) raises TypeError: sequence item 0: expected str instance, int found. You must convert numbers to strings first: "-".join(map(str, [1, 2, 3])).

String Formatting in Python

String formatting allows you to dynamically inject variables and expressions into text. Python has evolved three distinct ways to format strings over time.

f""
f-strings (Modern Standard)

Introduced in Python 3.6. Cleanest, fastest, and most readable. Prefix string with f and embed variables in {curly_braces}.

{}
str.format() (Python 3)

Uses empty curly braces as placeholders: "Hello {}".format(name). Good for templates read from files.

%
% Operator (Legacy / C-style)

Old C-style specifiers like %s (string) and %d (integer). Found in older legacy codebases.

The 3 Formatting Styles Compared 
1name = "Aman"
2age = 20
3
4# Approach A: Modern f-string (RECOMMENDED)
5print(f"My name is {name} and I am {age} years old.")
6
7# Approach B: format() method
8print("My name is {} and I am {} years old.".format(name, age))
9
10# Approach C: Legacy percent % formatting
11print("My name is %s and I am %d years old." % (name, age))
Terminal Output (All 3 Produce Identical Text)
My name is Aman and I am 20 years old. My name is Aman and I am 20 years old. My name is Aman and I am 20 years old.

Escape Sequences and Raw Strings

📊 Figure 5.6: Standard Escape Sequences vs. Raw String Literals
In standard Python strings, the backslash introduces escape sequences like \\n (newline) and \\t (tab). Prepending r creates a raw string literal where backslashes are preserved verbatim.
Visual Summary & Trace:
Raw Strings: Prefixing with 'r' (e.g. r'C:\\new\\test') disables escape interpretation, ensuring file paths and regex patterns render accurately.

Sometimes you need to include characters inside text that would otherwise confuse Python—such as a newline, a tab space, or quotation marks. You do this using escape sequences starting with a backslash (\).

Escape Code Name & Meaning Sample Usage Rendered Output
\n Newline (moves text to the next line) "Hello\nWorld" Hello
World

\' Single quote inside single-quoted string 'It\'s Python' It's Python

Checking Substrings with in and not in

Python makes searching inside text as natural as speaking English using the membership operators in and not in. These operators return a boolean True or False.

Python 
1message = "Welcome to Python Programming"
2
3print("'Python' in message:   ", "Python" in message)     # True
4print("'Java' in message:     ", "Java" in message)       # False
5print("'Java' not in message: ", "Java" not in message)   # True
6
7# Case sensitivity trap:
8print("'python' in message:   ", "python" in message)     # False! (Lowercase 'p')
9
10# Solution: Case-insensitive search via lower()
11search_term = "python"
12is_found = search_term.lower() in message.lower()
13print("Case-insensitive match:", is_found)                # True!
Terminal Output
'Python' in message: True 'Java' in message: False 'Java' not in message: True 'python' in message: False Case-insensitive match: True
Pro Tip: Always Normalize Case for Search

Users might type "Python", "python", or "PYTHON". To prevent search misses, always convert both the text and query to lowercase using .lower() before checking with in.

Comparing Strings (==, !=, <, >)

Python allows you to compare strings using standard comparison operators. It does this by evaluating the underlying Unicode (ASCII) character codes of each letter sequentially.

Python 
1# 1. Equality check (== and !=)
2print("'apple' == 'apple':", "apple" == "apple")   # True
3print("'Apple' == 'apple':", "Apple" == "apple")   # False (Case matters!)
4
5# 2. Lexicographical (Dictionary order) comparison
6print("'apple' < 'banana':", "apple" < "banana")   # True ('a' comes before 'b')
7
8# 3. Uppercase letters come BEFORE lowercase in ASCII!
9# 'Z' has code 90, while 'a' has code 97
10print("'Z' < 'a':         ", "Z" < "a")           # True!
Terminal Output
'apple' == 'apple': True 'Apple' == 'apple': False 'apple' < 'banana': True 'Z' < 'a': True
Reminder: == (Value Equality) vs. is (Object Identity)

Always use == when checking whether two strings contain the same text. The is operator tests whether two variables point to the exact same physical memory address. Do not use is for text comparisons!

Common Errors and Debugging

Every programmer runs into errors. Understanding the most common string traps will save you hours of debugging.

Error 1: Missing or Mismatched Quotes

Incorrect: message = "Hello world' or title = Welcome

What Happens: Raises SyntaxError: unterminated string literal or NameError: name 'Welcome' is not defined.

Fix: Enclose strings in matching pairs of quotes: message = "Hello world".

Error 2: TypeError When Concatenating Number to String

Incorrect: print("Roll No: " + 45)

What Happens: TypeError: can only concatenate str (not "int") to str.

Fix: Convert the number to text: print("Roll No: " + str(45)) or use f-string: print(f"Roll No: {45}").

Error 3: IndexError on String Indexing

Incorrect: word = "Cat"; print(word[3])

What Happens: IndexError: string index out of range (Length is 3, so valid indexes are only 0, 1, 2).

Fix: The highest index is always len(word) - 1, which is word[2].

Error 4: Attempting In-Place String Mutation

Incorrect: s = "hello"; s[0] = "H"

What Happens: TypeError: 'str' object does not support item assignment.

Fix: Reassign a new string: s = "H" + s[1:] or s = s.capitalize().

Error 5: Forgetting That String Methods Return a NEW String

Incorrect:

name = "aman"
name.upper() # ❌ Return value ignored!
print(name) # Still prints "aman"

Fix: You must store the returned string: name = name.upper().

Error 6: Confusing find() and index()

Gotcha: "apple".find("z") returns -1, but "apple".index("z") crashes with ValueError: substring not found.

Fix: Use find() when you are uncertain if the substring exists, or check with if "z" in text: first.

Error 7: Calling a Method Without Parentheses

Incorrect: name = "aman"; print(name.upper)

What Happens: Prints <built-in method upper of str object at 0x...> instead of executing the method.

Fix: Always include parentheses to execute the function: print(name.upper()).

Quick Revision, Interview QA & Practice Drills

📌 Key Rules to Remember

  • ✓Strings are Immutable: Character reassignment (s[0] = 'x') is forbidden. Methods return fresh strings.
  • ✓Indexing Starts at 0: Positive indexes go from 0 to len - 1. Negative indexing starts at -1 from the end.
  • ✓Slicing [start:stop:step]: The start index is included; the stop boundary is excluded. Slicing never raises an IndexError.
  • ✓find() vs index(): find() returns -1 when missing; index() raises a fatal ValueError.
  • ✓f-strings: Modern Python code prefers f"Hello, {name}" for readable and fast text interpolation.
  • ✓join() vs split(): split() turns a string into a list of strings. join() glues a list of strings into one single string.
📋 Quick Comparison Cheat Sheet
Comparison First Option Second Option When to Use Which
find() vs index() Returns -1 if not found Raises ValueError Use find() when you want to handle missing substrings safely without crash.
split() vs join() String ➔ List List ➔ String Use split() to parse text words; use join() to assemble them back.
== vs is Checks character value equality Checks exact memory address identity Always use == to compare text content!
strip() vs replace() Removes outer edge spaces Replaces characters anywhere inside text Use strip() for user input; replace() to substitute words.
💼 Common Interview & Viva Questions
Q1 What does it mean that strings are immutable in Python?
It means once a string object is created in memory, its contents cannot be altered in place. Any operation (like replace(), upper(), or concatenation) produces a brand new string object rather than modifying the existing one.
Q2 How do you reverse a string in Python without using a loop?
Using the step slicing syntax: reversed_str = original_str[::-1]. The step of -1 directs Python to traverse from the end of the string to the beginning.
Q3 What is the difference between single, double, and triple quotes?
Single (' ') and double (" ") quotes behave identically for single-line strings and allow embedding the opposite quote without escape backslashes. Triple quotes (''' ''' or """ """) permit multiline text and docstrings while preserving line breaks.
Q4 Why does "Age: " + 25 produce an error in Python?
Python is strongly typed and does not automatically convert numbers to strings when using the + operator. You must either write "Age: " + str(25) or use an f-string: f"Age: {25}".
Q5 How does Python compare strings like "apple" < "banana"?
It performs lexicographical comparison by evaluating the ASCII/Unicode numerical values of characters sequentially from left to right. Since 'a' has code 97 and 'b' has code 98, "apple" < "banana" evaluates to True.
