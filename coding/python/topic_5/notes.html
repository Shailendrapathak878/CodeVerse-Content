Topic Introduction

Almost every program works with text — names, messages, passwords, search words. In Python, text is stored as a string. In this chapter you'll learn how to create strings, pick out parts of them, and use Python's built-in tools to change and check them.

💡 What you'll walk away with

You'll be able to create strings, use indexing and slicing, apply the most useful string methods, and format text neatly in your output.

02

What is a String?

STRING (str)
A sequence of characters — letters, digits, spaces and symbols — written inside quotes.
Example: "Hello", "CodeVerse 2026", "@riya_21"

Think of a string like a row of boxes, where each box holds exactly one character. Python numbers these boxes so you can pick any one of them.

🧠 Remember this

Anything inside quotes is a string — even "25". It looks like a number, but Python treats it as text.

03

Creating Strings

Concept

You can create a string using single quotes or double quotes. Both work exactly the same.

Syntax 
variable = "text"
variable = 'text'
Example
Python
first = "Hello"
second = 'World'
print(first, second)
Output 
Hello World
Easy Explanation

first uses double quotes and second uses single quotes — Python treats both as strings. Just remember to close a string with the same type of quote you opened it with.

📌 Handy trick

If your text contains an apostrophe, wrap it in double quotes: "It's a nice day". If it contains double quotes, wrap it in single quotes: 'She said "Hi"'.

04

Multi-line Strings

Concept

To write text across several lines, use triple quotes (""" or '''). Line breaks inside them are kept as part of the string.

Example
Python
message = """Welcome to CodeVerse.
Happy learning!"""
print(message)
Output 
Welcome to CodeVerse.
Happy learning!
Easy Explanation

The text was typed on two lines, and Python printed it on two lines — triple quotes keep the layout exactly as you wrote it.

05

Escape Characters

ESCAPE CHARACTER
A backslash \ followed by a letter or symbol, which gives that character a special meaning inside a string.
Example: \n means "start a new line".
\n
New line"Hi\nBye" → two lines
\t
Tab space"A\tB" → A B
\\
A real backslash"C:\\Users" → C:\Users
\"
A double quote inside a string"Say \"Hi\"" → Say "Hi"
\'
A single quote inside a string'It\'s fine' → It's fine
Python
print("Hello\nWorld")
print("She said \"Hi\"")
Output
Hello
World
She said "Hi"
06

String Length with len()

Concept

len() tells you how many characters a string contains — including spaces and symbols.

Example
Python
word = "CodeVerse"
print(len(word))
print(len("Hi there"))
Output 
9
8
Easy Explanation

"CodeVerse" has 9 characters. "Hi there" has 8 because the space between the words counts as a character too.

07

String Indexing

INDEX
The position number of a character in a string. Python starts counting from 0, not 1.
Example: in "PYTHON", the letter P is at index 0.
Positive and negative index of "PYTHON"
Syntax 
string[index]
Example
Python
word = "PYTHON"
print(word[0])
print(word[2])
print(word[-1])
Output 
P
T
N
Easy Explanation

word[0] is the first letter, word[2] is the third letter (because counting starts at 0), and word[-1] is the last letter.

⚠️ Out of range

Asking for an index that doesn't exist, like word[10] for a 6-letter word, causes an IndexError.

08

String Slicing

Concept

Slicing lets you take a piece of a string. You give a start position and an end position, separated by a colon. The start is included, but the end is not.

Syntax 
string[start:end]
word[1:4] on "PYTHON"
Python
text = "CodeVerse"
print(text[0:4])
print(text[4:])
print(text[:4])
print(text[-5:])
Output
Code
Verse
Code
Verse

Easy explanation: text[0:4] takes characters at index 0, 1, 2, 3. If you leave out the start (text[:4]), Python starts from the beginning. If you leave out the end (text[4:]), it goes all the way to the end. text[-5:] means "the last 5 characters".

09

Slicing with Step and Reversing

Concept

A slice can have a third number, the step, which says how many positions to jump each time. A step of -1 walks backwards, which reverses the string.

Syntax 
string[start:end:step]
Example
Python
text = "CodeVerse"
print(text[::2])
print(text[::-1])
Output 
CdVre
esreVedoC
Easy Explanation

text[::2] takes every second character (indexes 0, 2, 4, 6, 8 → C, d, V, r, e). text[::-1] reads the whole string from the end to the start — the quickest way to reverse a string in Python.

10

Strings are Immutable

Remember from Chapter 3: strings are immutable. That means you cannot change a single character inside an existing string.

Python (this causes an error)
word = "hello"
word[0] = "H"
Error
TypeError: 'str' object does not support item assignment

The fix is to build a new string and store it in the variable:

Python
word = "hello"
word = "H" + word[1:]
print(word)
Output
Hello

Here word[1:] is "ello", and joining it with "H" gives a brand-new string "Hello".

11

Concatenation and Repetition

Concept

Use + to join strings together (concatenation) and * to repeat a string a number of times.

Example
Python
first = "Code"
second = "Verse"
print(first + second)
print(first + " " + second)
print("Ha" * 3)
print("-" * 10)
Output 
CodeVerse
Code Verse
HaHaHa
----------
Easy Explanation

+ glues strings end to end with nothing in between, so add " " if you want a space. "Ha" * 3 repeats the text three times.

⚠️ Strings and numbers don't mix with +

"Age: " + 20 causes an error. Convert the number first with str(20), or use an f-string.

12

Checking Text with in / not in

The membership operators from Chapter 4 also work on strings, to check whether some text appears inside another string.

Python
text = "CodeVerse"
print("Code" in text)
print("x" not in text)
print("code" in text)
Output
True
True
False

The last line is False because Python is case-sensitive — "code" (small c) is not the same as "Code".

13

Changing Case Methods

METHOD
A ready-made tool that belongs to a value. You use it by writing a dot after the value, then the method name with brackets.
Example: "hello".upper()
upper()
All letters in capitals"hello".upper() → HELLO
lower()
All letters in small letters"HELLO".lower() → hello
title()
First letter of every word in capital"hello world".title() → Hello World
capitalize()
Only the first letter of the string in capital"hello world".capitalize() → Hello world
Python
name = "riya sharma"
print(name.upper())
print(name.title())
print(name.capitalize())
Output
RIYA SHARMA
Riya Sharma
Riya sharma
🧠 Remember this

String methods never change the original string (strings are immutable). They return a new string, so store it in a variable if you want to keep it.

14

Cleaning and Replacing Text

strip()
Removes spaces from both ends" hi ".strip() → "hi"
replace(old, new)
Swaps every old piece with a new piece"I like Java".replace("Java", "Python")
Python
raw = "   Hello Python   "
print(raw.strip())

sentence = "I like Java"
print(sentence.replace("Java", "Python"))
Output
Hello Python
I like Python

strip() is very useful for cleaning text typed by a user, because people often add extra spaces by accident.

15

Searching and Counting

find(x)
Index of the first match, or -1 if not found"hello".find("l") → 2
count(x)
How many times x appears"banana".count("a") → 3
Python
word = "banana"
print(word.find("n"))
print(word.find("z"))
print(word.count("a"))
Output
2
-1
3

"n" first appears at index 2 in "banana". "z" is not there, so find() returns -1. The letter "a" appears 3 times.

16

split() and join()

Concept

split() breaks a string into a list of smaller strings. join() does the opposite — it glues a list of strings into one string.

Syntax 
string.split(separator)
separator.join(list_of_strings)
Example
Python
sentence = "red,green,blue"
colors = sentence.split(",")
print(colors)

words = ["Learn", "Python", "daily"]
print(" ".join(words))
print("hello world".split())
Output 
['red', 'green', 'blue']
Learn Python daily
['hello', 'world']
Easy Explanation

split(",") cut the text at every comma. " ".join(words) put a space between each word of the list. If you call split() with nothing inside the brackets, it splits at spaces.

17

Checking Methods

These methods answer a yes/no question about a string, so they return True or False.

startswith(x)
Does it begin with x?"python".startswith("py") → True
endswith(x)
Does it end with x?"main.py".endswith(".py") → True
isdigit()
Are all characters digits?"123".isdigit() → True
isalpha()
Are all characters letters?"abc".isalpha() → True
Python
print("python".startswith("py"))
print("main.py".endswith(".py"))
print("123".isdigit())
print("abc123".isalpha())
Output
True
True
True
False

The last line is False because "abc123" contains digits as well as letters.

18

Formatting Strings

You already know f-strings from the last chapter. Python also has the format() method, which fills {} placeholders in order.

Python
name = "Riya"
age = 21
print(f"My name is {name} and I am {age}.")
print("My name is {} and I am {}.".format(name, age))
Output
My name is Riya and I am 21.
My name is Riya and I am 21.

Both lines give the same result. f-strings are shorter and easier to read, so prefer them in new code. You'll still see format() in older programs, so it's good to recognise it.

19

Comparing Strings

Strings can be compared with the same comparison operators you learned earlier. Comparison is case-sensitive, and < / > compare alphabetical order.

Python
print("apple" == "apple")
print("apple" == "Apple")
print("apple".lower() == "Apple".lower())
print("a" < "b")
Output
True
False
True
True
📌 Useful habit

To compare text without worrying about capital letters, convert both sides with .lower() first, like the third line above.

Common Beginner Mistakes

❌ Wrong: Expecting a method to change the original string
text = "hello"
text.upper()
print(text)   # prints hello
✅ Correct: text = text.upper()

The method returned a new string, but the result was thrown away because it wasn't stored.

❌ Wrong: Starting the index from 1
word = "Python"
print(word[1])   # prints y, not P
✅ Correct: the first character is word[0]
❌ Wrong: Joining text and a number with +
age = 20
print("Age: " + age)
✅ Correct: print("Age: " + str(age)) or print(f"Age: {age}")
❌ Wrong: Forgetting the end of a slice is not included
word = "Python"
print(word[0:2])   # prints Py, not Pyt
✅ Correct: use word[0:3] to get Pyt
❌ Wrong: Mixing up quote types
message = 'It's a good day'
✅ Correct: message = "It's a good day"

The apostrophe in It's closes the string too early. Wrap the text in double quotes, or write \'.

22

Key Points to Remember

  • A string is a sequence of characters inside single, double or triple quotes.
  • Indexing starts at 0, and negative indexes count from the end (-1 is the last character).
  • In a slice [start:end], the start is included and the end is not.
  • [::-1] reverses a string.
  • Strings are immutable — you create a new string instead of editing the old one.
  • String methods return a new string; store the result if you want to keep it.
  • + joins strings and * repeats them, but you cannot add a string and a number directly.
  • split() turns a string into a list, and join() turns a list back into a string.
  • String comparison is case-sensitive, so use .lower() when case should not matter.
  • f-strings are the cleanest way to put variables inside text.
