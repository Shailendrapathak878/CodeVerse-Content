Introduction to Lists

📊 Figure 8.6: In-Place list.sort() vs. Built-In sorted(iterable)
The list method `.sort()` mutates the list directly in memory and returns `None` (assigning `x = nums.sort()` is a common bug setting `x` to None). The built-in function `sorted(iterable)` leaves the original data unchanged and returns a new sorted list.
Visual Summary & Trace:
Sorting Rules: list.sort() modifies list in place returning None; sorted(list) preserves original data and returns a fresh sorted list.
📊 Figure 8.3: Mutability in Action: In-Place Modification vs. Reassignment
Lists are mutable sequences. Performing index assignment `nums[0] = 99` rebinds slot 0 to the integer 99 within the existing list structure, keeping the list object's memory address (`id`) completely intact.
Visual Summary & Trace:
In-Place Mutation: nums[0] = 99 updates slot 0 in place; id(nums) remains identical before and after modification.
📊 Figure 8.2: Python List Dual-Indexing Matrix
Lists support bi-directional indexing. Positive indices provide left-to-right indexing starting from 0, while negative indices count from the tail starting at -1, providing immediate access to end elements without calculating length.
Visual Summary & Trace:
Coordinate Access: items[0] and items[-4] refer to 'Python'; items[3] and items[-1] refer to 'Rust'.
📊 Figure 8.1: Python List Dynamic Pointer Array Architecture
A Python list does not store raw values inline. Instead, it maintains a contiguous array of 64-bit pointers referencing independent heap objects, allowing lists to store heterogeneous data types while supporting O(1) random index access.
Visual Summary & Trace:
Internal Architecture: PyListObject tracks length and pre-allocated capacity, pointing to a contiguous array of references to heap objects (int, str, float).

Imagine you manage a classroom of 40 students. Without lists, you would have to invent 40 separate variable names: student1 = "Aarav", student2 = "Diya", student3 = "Rohan"... all the way to student40. Calculating marks or printing their names would require 40 separate lines of repetitive code!

What is a List in Python?

A List is a built-in Python data structure that holds an ordered, mutable (changeable), and dynamic sequence of elements enclosed inside square brackets [ ] and separated by commas.

🛒
Shopping Cart

You add apples, milk, and bread. You can remove items, add new items, or swap brands anytime.

🎵
Spotify Playlist

Songs are stored in a fixed track order (Track 0, Track 1). You can rearrange or delete songs at will.

📊
Student Scorecard

Store multiple marks [95, 88, 76, 92] in a single variable and easily compute sums or averages.

5 Core Characteristics of Python Lists
  • Ordered: Elements maintain a predictable, sequential index order. Item 0 remains item 0 unless you modify the list.
  • Mutable: You can modify, add, replace, and delete elements after the list is created without creating a new object.
  • Heterogeneous: A single list can contain mixed data types: integers, strings, floats, booleans, and other lists.
  • Allows Duplicates: Multiple identical items can exist at different positions (e.g., [10, 20, 10, 30]).
  • Dynamic: Python automatically handles memory resizing as you add or remove items.

Slicing Lists

Slicing extracts a sublist of elements without modifying the original list. Slicing uses the colon : operator inside square brackets.

List Slicing Syntax: list[start : stop : step]
  • start: The starting index (included). Defaults to 0.
  • stop: The boundary index (excluded). Slicing stops just before this index.
  • step: The stride / increment between items. Defaults to 1.
Visualizing numbers[1:4]

For numbers = [10, 20, 30, 40, 50, 60]:
Index 1 is 20, Index 2 is 30, Index 3 is 40. Index 4 (50) is excluded!

Copying Lists and Aliasing

📊 Figure 8.7: Variable Aliasing vs. Shallow Copy vs. Deep Copy
Direct assignment `b = a` creates an alias to the same list. Shallow copies (`a.copy()`) clone the outer pointer array but share references to nested objects. Deep copies (`copy.deepcopy(a)`) recursively duplicate all nested structures.
Visual Summary & Trace:
Copying Mechanics: b = a (shares list); b = a.copy() (new outer list, shared nested items); b = copy.deepcopy(a) (completely independent clone).

One of the most frequent sources of unexpected bugs for beginners is aliasing: assuming that assigning a list to a new variable (b = a) creates a copy. In Python, assignment never copies; it only creates another name referencing the exact same memory address!

The Aliasing Trap (b = a)

When you write b = a, both a and b point to the same list object in memory. Modifying b will instantly modify a!

Aliasing vs Proper Shallow Copying 
1# --- ALIASING (NOT A COPY) ---
2a = [10, 20, 30]
3b = a          # b is merely an alias for a!
4b[0] = 99
5print("a after changing b:", a)  # a was modified!
6
7# --- PROPER SHALLOW COPY (3 Ways) ---
8original = [10, 20, 30]
9copy1 = original.copy()  # Method 1: .copy()
10copy2 = original[:]       # Method 2: Slicing [:]
11copy3 = list(original)   # Method 3: list() constructor
12
13copy1[0] = 555
14print("Original stays safe:", original)
15print("copy1 updated only :", copy1)
Terminal Output
a after changing b: [99, 20, 30] Original stays safe: [10, 20, 30] copy1 updated only : [555, 20, 30]
Nested Lists: When to Use copy.deepcopy()

A shallow copy clones only the outer container. If the list contains inner lists, both the copy and the original still share references to those inner lists! For complete recursive independence, use Python's built-in copy.deepcopy():

Shallow Copy vs deepcopy on Nested Lists 
1import copy
2
3matrix = [[1, 2], [3, 4]]
4deep = copy.deepcopy(matrix)
5
6deep[0][0] = 999
7print("Original matrix:", matrix)
8print("Deep copy       :", deep)
Terminal Output
Original matrix: [[1, 2], [3, 4]] Deep copy : [[999, 2], [3, 4]]

Severe Pitfall: [[0] * 3] * 2 Creates Duplicate References!

Writing grid = [[0] * 3] * 2 repeats the exact same list reference twice! Changing grid[0][0] = 7 will unexpectedly change grid[1][0] = 7 as well!

Lists vs Tuples

Both lists and tuples store ordered sequences of items, but their design goals and mutability rules are fundamentally different.

Feature List (list) Tuple (tuple)
Syntax Square brackets: [1, 2, 3] Parentheses: (1, 2, 3)
Mutability Mutable (can add, remove, update) Immutable (cannot modify after creation)
Memory & Speed More memory (over-allocated for growth) Less memory, faster to allocate & iterate
Available Methods 11 methods (append, pop, sort...) Only 2 methods (count, index)
Dictionary Key ❌ Cannot be used as dict keys (unhashable) ✅ Can be used as dict keys (hashable)
Primary Use Case Dynamic, changing collections of items Fixed records, coordinates (x, y), RGB colors
Important Clarification on Tuple Immutability

Making a tuple immutable does not make mutable items inside it immutable! If a tuple holds a list: t = ([1, 2], 3), you can still mutate the inner list: t[0].append(99) ➔ ([1, 2, 99], 3). The tuple merely protects its own references from being reassigned.

Common Beginner Errors & Best Practices

Avoid these classic beginner list mistakes to write clean, bug-free Python code:

Mistake 1: Off-by-One IndexError

❌ Incorrect: nums = [10, 20, 30]; print(nums[3]) (Causes IndexError because max index is 2)
✅ Correct: print(nums[len(nums) - 1]) or simply print(nums[-1])

Mistake 2: nums = nums.sort() or nums = nums.append(40)

❌ Incorrect: nums = nums.sort() (Since sort() returns None, nums becomes None!)
✅ Correct: Simply call nums.sort() on its own line, or use nums = sorted(nums).

Mistake 3: Removing Elements During for Loop Iteration

❌ Incorrect: for x in nums: nums.remove(x) (As indices shift, Python skips every second element!)
✅ Correct: Iterate over a shallow copy: for x in nums.copy(): ... or use a comprehension.

Quick Revision

📌
Indexing & Slicing

Indices start at 0 from left, -1 from right. Slicing formula: list[start : stop : step] where stop is always excluded.

➕
Adding Items

append(x) adds single item to end; extend(iter) unpacks iterable items; insert(i, x) injects at index i.

➖
Removing Items

remove(val) deletes by value; pop(idx) deletes and returns by index; clear() empties the entire list.

🛡️
Aliasing vs Copying

b = a does NOT copy; it shares the same memory reference. Use b = a.copy() or b = a[:] for an independent shallow copy.

List Methods Cheat Sheet

• Mutate & return None: .append(), .extend(), .insert(), .remove(), .clear(), .sort(), .reverse()
• Return values: .pop() (returns removed item), .index() (returns index), .count() (returns tally), .copy() (returns new list).
