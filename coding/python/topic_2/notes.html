01

What Is Syntax?

Definition: Syntax

Syntax is the set of grammatical rules that define how a Python program must be written and structured for the computer to understand it.

Real-Life Analogy: Human Grammar

In English, we say "The sun rises in the east." If you write "Rises east sun the in", a person might guess what you mean, but the grammar is broken. Computers cannot guess — if your syntax violates Python's rules, the interpreter halts immediately and raises a SyntaxError.

🎯
Why Rules Exist

Computers execute instructions literally. Clear grammatical rules eliminate ambiguity so Python knows exactly what operation to perform.

✨
Python's Philosophy

Python syntax was specifically engineered to be readable and uncluttered, reading almost like plain written English pseudo-code.

Basic Structure of a Python Program

Let's examine the anatomy of the classic one-line program:

Python 
1print("Hello, World!")
>_ Output
Hello, World!
print Built-in output function
( ) Calls the function
" " String quotes
Hello, World! Text characters
! and , Punctuation inside text
Punctuation Inside Quotes vs Outside

Notice that the comma , and exclamation mark ! are enclosed inside the quotes. In this context, they are simply ordinary characters printed to the screen, not Python syntax operators.

04

Python Statements and Expressions

Understanding the difference between a statement and an expression helps you think like a programmer:

Python 
1age = 182total = 10 + 203print(total)
>_ Output
30
An Expression (Produces a Value)

Any snippet of code that evaluates to a value.

  • 10 + 20 (evaluates to 30)
  • "Hello" (evaluates to the string)
  • age >= 18 (evaluates to True)
A Statement (Performs an Action)

A complete instruction that Python executes.

  • age = 18 (stores 18)
  • total = 10 + 20 (assigns calculation)
  • print(total) (outputs to screen)

Indentation in Python

Unlike C, C++, or Java that use curly brackets { } to group lines together, Python uses indentation (whitespace) to define blocks of code.

✅ Correct Indentation Example
Python 
1age = 2023if age >= 18:4    print("You can vote.")
>_ Output
You can vote.
if age >= 18:
4 spaces print("You can vote.") ← Belongs inside the if-block
❌ Error Demonstration: Missing Indentation

The code below will fail because the statement inside the if block is not indented: 

if age >= 18:
print("You can vote.")  # ❌ IndentationError!
⚠️ Error Raised
IndentationError: expected an indented block after 'if' statement on line 1

Standard rule: Always use 4 spaces for each level of indentation. Avoid mixing tabs and spaces.

06

Comments in Python

Definition: Comments

Comments are human notes written directly in your source code. The Python interpreter completely ignores comments when executing the program.

Python 
1# Display a welcome message to our new user2print("Welcome to CodeVerse!")
>_ Output
Welcome to CodeVerse!
📝
Single-Line Comments (#)

Starts with a hash symbol #. Everything following # on that line is ignored by Python.

🤝
Why Comments Matter

They explain why code was written, help teammates understand your logic, and remind your future self how your program functions.

Note on Multi-line Docstrings

Triple quotes ("""...""" or '''...''') are called Docstrings. While often used by developers to write multi-line notes, Python technically preserves docstrings as documentation objects for functions and modules, unlike # comments which are completely stripped.

07

Case Sensitivity

Python treats lowercase and uppercase letters as completely distinct characters. name, Name, and NAME are three entirely separate identifiers!

Python 
1name = "Aman"2Name = "Riya"34print(name)5print(Name)
>_ Output
Aman Riya
Watch Out for Built-In Function Names

Because of case sensitivity, typing Print("Hello") instead of print("Hello") causes Python to report NameError: name 'Print' is not defined. Always use lowercase for built-in keywords and functions.

08

Strings, Quotes, and Basic Syntax Rules

Follow these essential syntax rules to keep your programs clean and error-free:

💬
Single vs Double Quotes

Both 'Hello' and "Hello" are valid. Use double quotes if your text contains an apostrophe: "It's sunny".

🔒
Matching Pairs

Quotes, parentheses (), and brackets [] must always be closed with their matching pair.

🚫
No Semicolons Needed

Unlike C or JavaScript, Python does not require a semicolon ; at the end of each line.

📏
One Statement Per Line

Write each statement on its own line. This ensures readability and clean error reporting.

Key Takeaways & Quick Revision

Walkthrough: Can You Explain This Code? 
# Calculate total score
bonus = 5
final_score = 90 + bonus
print("Final Score:", final_score)
  • Line 1 is a comment (ignored by Python).
  • Line 2 stores 5 in bonus.
  • Line 3 evaluates the expression 90 + bonus (which is 95) and assigns it to final_score.
  • Line 4 prints Final Score: 95 to the terminal.
✅ Core Rules to Remember
  • ✓ Syntax is the grammar of Python; computers require strict adherence to rules.
  • ✓ print() outputs values to the screen; text strings must be wrapped in quotes.
  • ✓ Indentation matters: Use 4 spaces to define code blocks (e.g. inside if statements).
  • ✓ Case-sensitive: name and Name are different variables; print must be lowercase.
  • ✓ Comments start with #: They help humans understand the purpose of your code.
  • ✓ Statements perform actions; expressions produce values.
Concept / Rule Quick Answer
What is Syntax? The rules and structure of code in a programming language.
How do you display text? print("Hello")
How do you write a comment? Using the # symbol at the beginning of the note.
What defines code blocks? Indentation (standard 4 spaces per block level).
Is Python case-sensitive? Yes. score and Score are two distinct variables.
What error occurs for missing quotes? SyntaxError: unterminated string literal
