02

What is Python Syntax?

Just like a spoken language has grammar rules, Python has syntax rules — the exact way code must be written so that Python can understand it.

DIAGRAM 1 · Human Language vs Python Syntax

Here's a correct Python line:

Python
print("Hello")

And here's the same line, broken — notice the missing closing bracket:

Python (incorrect)
print("Hello"
⚠️ Why this is wrong

Every opening bracket ( needs a matching closing bracket ). Python reads the whole line looking for that closing bracket — when it never finds one, it doesn't know where your instruction ends, so it cannot run the code.

03

Why Syntax Is Important

Computers don't "guess" what you mean. Unlike a human friend who can understand a sentence even with a small typo, Python needs the structure to be exactly right.

💡 Simple Way to Remember

No syntax errors → Python understands your instructions → Python runs them. Even one small mistake → Python stops and reports an error instead of guessing.

06

Indentation

This is one of the most important ideas in Python. Indentation means the blank spaces at the start of a line — and in Python, those spaces actually control how the code is structured.

Python
if condition:
    print("Hello")

The 4 spaces before print(...) tell Python: "this line belongs inside the if."

DIAGRAM 4 · Indentation Structure
🧠 Remember this

Python commonly uses 4 spaces for one level of indentation. Most code editors do this automatically when you press Tab.

07

Comments

A comment is a note in your code that Python completely ignores when running the program. Comments exist purely to help humans understand the code.

Python
# This is a comment
print("Hello")
Output
Hello
What happens to a comment

Python also supports triple-quoted text blocks:

Python
"""
This looks like a comment block
"""
⚠️ Important clarification

A triple-quoted block like this is actually a string (a piece of text) — not a true "comment" in the technical sense. It's often used the way a comment is used (as a note that isn't printed if left alone), but under the hood, Python treats it as text data. For real comments, the # symbol is the correct tool.

08

Case Sensitivity

Python is case-sensitive, which means uppercase and lowercase letters are treated as completely different things.

CASE-SENSITIVE
Uppercase and lowercase versions of a word are treated as different.
Example: name, Name, and NAME are three different identifiers to Python.

✅ Correct

Python
print("Hello")

❌ Incorrect

Python
PRINT("Hello")

print is a built-in function Python recognizes. PRINT is not — as far as Python is concerned, it's a completely different, unknown word.

09

Naming Rules

When you name something in Python (like a variable), a few simple rules apply.

✅ Valid names

name, student_name, age2, _marks

❌ Invalid names

2name, student-name, student name

  • A name cannot start with a number (e.g. 2name is invalid).
  • Spaces are not allowed inside a single name (e.g. student name is invalid).
  • Special characters like -, @, ! generally cannot be used.
  • The underscore ( _ ) is allowed and commonly used.
  • Python keywords (reserved words like if, print's special cases, for) cannot be used as ordinary names.

Understanding print()

print() is a built-in function whose only job is to display something on the screen. Let's look at a few small examples.

15

Common Beginner Mistakes

❌ Wrong: Missing quotation marks
print(Hello)
✅ Correct: print("Hello")

Without quotes, Python thinks Hello is the name of something it should already know — and it doesn't.

❌ Wrong: Incorrect capitalization
PRINT("Hello")
✅ Correct: print("Hello")

Python is case-sensitive — only lowercase print is the real function.

❌ Wrong: Missing closing bracket
print("Hello"
✅ Correct: print("Hello")

Every opening bracket needs a matching closing one.

❌ Wrong: Incorrect indentation
if True:
print("Hello")
✅ Correct: indent the line inside the if with 4 spaces

Without indentation, Python doesn't know this line belongs inside the if.

16

Syntax Error Basics

SYNTAXERROR
A mistake in the structure or rules of your code — Python cannot understand what you meant to write.
Example: print("Hello" (missing closing bracket) causes a SyntaxError.
What a SyntaxError means
⚠️ Keep in mind

A SyntaxError is purely about the structure being wrong — brackets, quotes, indentation, spelling of keywords. It's different from other kinds of errors you'll meet later on, once the code is structurally valid but something else goes wrong while it runs.

Key Takeaways

  • Python syntax is the set of rules that decides whether your code is understandable to Python.
  • A program is simply a sequence of statements the interpreter reads and runs in order.
  • Indentation is not just style in Python — it defines which lines belong together.
  • Comments (using #) are ignored by Python and exist purely to help humans.
  • Python is case-sensitive: print and PRINT are not the same thing.
  • Variable names follow simple rules: no starting with a number, no spaces, underscores are fine.
  • print("Hello, World!") is the classic first program every learner writes.
  • print() can display text, numbers, results of arithmetic, and multiple values at once.
  • Python checks your code's syntax before running it — a SyntaxError means the structure is broken.
  • Reading and predicting simple code is one of the fastest ways to build real understanding.
