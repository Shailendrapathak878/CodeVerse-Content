Module, Package, Library and Framework

These four words are often mixed up. Here is the simple version.

MODULE
A single Python file (.py) containing code you can reuse.
math is a module.
PACKAGE
A folder of related modules, so big projects stay organised.
numpy and pandas are packages (folders of many modules).
LIBRARY
A collection of modules/packages you call to do a job. A casual word; people use it for any reusable code collection.
NumPy is a library for numerical computing.
FRAMEWORK
A structure that calls your code. It decides the overall flow and you fill in the parts.
Django, Flask, FastAPI.
Module
One file of codeimport math
Package
Folder of modulesimport numpy
Library
Tools you callpandas, requests
Framework
Structure that calls youFlask, Django, FastAPI
💡 Library vs framework: who is in control?

With a library, you are in control: you call its function when you need it. With a framework, the framework is in control: you hand it your functions and it calls them at the right time.

Ways to import

Three import styles
Python
import math                        # import the whole module
print(math.sqrt(16))

from math import pi, ceil          # import only specific names
print(pi, ceil(2.1))

import statistics as st            # import with an alias (short name)
print(st.mean([1, 2, 3, 4]))
Output
Output
4.0
3.141592653589793 3
2.5
How It Works
  • import math → you must write math.sqrt.
  • from math import pi → use pi directly. Convenient, but be careful of name clashes.
  • as creates an alias (nickname) for a shorter name.
🏷️ Standard aliases

The community uses fixed aliases: import numpy as np, import pandas as pd, import matplotlib.pyplot as plt. Using the same ones everywhere means anyone can read your code instantly (and all tutorials match yours).

❌ Wrong: Importing a name that does not exist
Python
from math import sqroot
Problem (error)
ImportError: cannot import name 'sqroot' from 'math' (unknown location). Did you mean: 'sqrt'?
✅ Better: check the exact name in the documentation (sqrt)
Python
from math import sqrt
print(sqrt(25))
Output
5.0
⚠️ Avoid from module import *

It dumps every name into your file, hides where things come from and can silently overwrite your own names. Import what you need.

Standard Library vs Third-Party Libraries

📦 Standard library

Installed with Python. Nothing to download. Examples: math, os, json, pathlib, datetime, random, collections.

🌍 Third-party libraries

Written by the community and hosted on PyPI (the Python Package Index). You must install them first. Examples: numpy, pandas, requests.

💡 Why must third-party packages be installed?

Python only ships with the standard library. Anything else is a separate download from PyPI. Until you run pip install ..., Python has no idea the package exists, and import fails.

Telling them apart
Python
import sys
from importlib.metadata import version
from pathlib import Path
import json, os

print("json in standard library:", "json" in sys.stdlib_module_names)
print("numpy in standard library:", "numpy" in sys.stdlib_module_names)
print("numpy installed version:", version("numpy"))

print(json.dumps({"name": "Aman", "age": 21}))
print(os.path.join("data", "students.csv"))
p = Path("data") / "students.csv"
print(p.name, p.stem, p.suffix)
Output
Output
json in standard library: True
numpy in standard library: False
numpy installed version: 2.5.3
{"name": "Aman", "age": 21}
data/students.csv
students.csv students .csv
How It Works
  • sys.stdlib_module_names lists every standard-library module name (Python 3.10+).
  • importlib.metadata.version tells you the installed version of a package.
  • pathlib.Path handles file paths cleanly: the / operator joins parts, and .name, .stem, .suffix split them.
🌍 Real-World Use

Automation scripts often need only the standard library (os, pathlib, json, csv), which keeps them easy to share. Reach for a third-party package when it clearly saves effort.

How to Learn Any New Library

A professional developer meets a new library every few weeks. Nobody memorises them all. They follow a process.

  1. Identify the problem ("I need to read a CSV and average a column").
  2. Search for the right library ("python read csv analyze" → Pandas).
  3. Open the official documentation.
  4. Install it (inside your virtual environment).
  5. Import it with the standard alias.
  6. Find the function or class you need.
  7. Read the parameters (what goes in, what comes out).
  8. Try a tiny example with made-up data.
  9. Check the output: is it what you expected?
  10. Integrate it into your project.

Reading docs from inside Python

Docs without leaving Python
Python
import numpy as np
import inspect

print(np.linspace.__doc__.strip().splitlines()[0])   # first line of the docstring
print(inspect.signature(np.linspace))                # parameters and defaults
print([n for n in dir(np) if n.startswith("lin")])   # what names exist?
Output
Output
Return evenly spaced numbers over a specified interval.
(start, stop, num=50, endpoint=True, retstep=False, dtype=None, axis=0, *, device=None)
['linalg', 'linspace']
How It Works
  • __doc__ is the function's built-in documentation. help(np.linspace) prints all of it.
  • inspect.signature shows each parameter and its default value: this is how you learn what you can customise.
  • dir(module) lists names inside a module. Handy for exploring.
🧭 Developer Mindset
  • Do not memorise; know where to look.
  • Read the official docs first, then examples and Q&A sites.
  • Always try a small example before using a function on your real data.
  • Check the version: old blog posts may use deprecated syntax.
  • When stuck, inspect the data you actually have (type, shape, columns) before guessing.

NumPy: Numerical Computing

NUMPY
A library for fast numerical computing. Its core object is the ndarray: a grid of values that all share one type.
Name = Numerical Python.
💡 Problem → Tool → Solution
Problem: add 10 to a million marks, or compute their average.
Tool: NumPy arrays.
Solution: one expression operates on all values at once, in fast compiled code.
  • Data Science: Pandas is built on top of NumPy ideas.
  • Machine Learning / AI: images, text and model weights become NumPy-style arrays (tensors).
  • Scientific computing: simulations, signals, statistics.

Start with a simple comparison

List vs NumPy array
Python
numbers = [1, 2, 3, 4, 5]
print([x + 10 for x in numbers])        # list: needs a loop/comprehension

import numpy as np
arr = np.array([1, 2, 3, 4, 5])
print(arr + 10)                         # array: one expression
print(type(numbers), type(arr))
Output
Output
[11, 12, 13, 14, 15]
[11 12 13 14 15]
<class 'list'> <class 'numpy.ndarray'>
How It Works
  • With a list you must loop to add 10 to every item.
  • With a NumPy array arr + 10 applies to every element. This is called vectorization (explained soon).
❌ Wrong: Treating a list like an array
Python
numbers = [1, 2, 3]
print(numbers + 10)
Problem (error)
TypeError: can only concatenate list (not "int") to list
✅ Better: convert to a NumPy array (or use a comprehension)
Python
import numpy as np
print(np.array([1, 2, 3]) + 10)
Output
[11 12 13]
Same operator, different behaviour
Python
import numpy as np
print([1, 2, 3] * 2)                    # list: repeats the list
print(np.array([1, 2, 3]) * 2)          # array: multiplies each value
Output
Output
[1, 2, 3, 1, 2, 3]
[2 4 6]
How It Works
  • Same symbol, different meaning. On a list * means repeat; on an array it means multiply. This is a classic beginner trap.

Python list

General-purpose. Can hold mixed types ([1, 'a', True]). Great for ordinary data and small collections.

NumPy array

Holds one type (all ints, or all floats). Built for numerical work: vectorised math, statistics, reshaping.

Slices are views, not copies

Views vs copies
Python
import numpy as np

arr = np.array([10, 20, 30, 40, 50])
s = arr[1:3]
s[0] = 999
print(arr)                  # the ORIGINAL changed too!

safe = arr[1:3].copy()
safe[0] = 0
print(arr)                  # unchanged by the copy
Output
Output
[ 10 999  30  40  50]
[ 10 999  30  40  50]
How It Works
  • A NumPy slice shares memory with the original (a "view"). Changing the slice changes the array.
  • Use .copy() when you need an independent array. This differs from list slicing, which makes a new list.
⚠️ Important

This view behaviour is a feature (it is fast and memory-friendly) but surprises beginners. If you modify a slice, ask: "Do I mean to change the original?"

axis: which direction?

When a function works on a 2D array, axis tells it which direction to collapse.

axis in a 2D array
              axis=1  →
            ┌────────────┐
   axis=0   │ 1   2   3  │
     ↓      │ 4   5   6  │
            └────────────┘

axis=0 → work DOWN the rows, one result per COLUMN
axis=1 → work ACROSS the columns, one result per ROW
Sum and mean by axis
Python
import numpy as np

scores = np.array([[70, 80, 90],     # student 1: three subjects
                   [60, 85, 75]])    # student 2

print("whole array :", scores.sum())
print("per subject :", scores.sum(axis=0))     # collapse rows -> one value per column
print("per student :", scores.sum(axis=1))     # collapse columns -> one value per row
print("avg/subject :", scores.mean(axis=0))
print("avg/student :", scores.mean(axis=1))
Output
Output
whole array : 460
per subject : [130 165 165]
per student : [240 220]
avg/subject : [65.  82.5 82.5]
avg/student : [80.         73.33333333]
How It Works
  • axis=0: go down the rows, combining them. You get one result per column (here: per subject).
  • axis=1: go across the columns. You get one result per row (here: per student).
  • Trick: the axis you name is the one that disappears. Shape (2, 3) summed over axis=0 becomes (3,).
🧠 Remember this
axis = the dimension that gets squashed away. You will meet axis again in Pandas (drop, concat).

Boolean Filtering in NumPy

Filtering means keeping only the values that meet a condition. NumPy does it in two steps you can see.

Condition → mask → filter

API Error Handling

Networks fail. Servers crash. APIs change. Code that assumes every request succeeds will eventually break. Here is everything that can go wrong:

⏱️

raise_for_status()
A response method that does nothing for success (below 400) and raises an HTTPError for 4xx/5xx statuses, so failures cannot slip by silently.

The standard pattern

How It Works
  • Everything that can fail sits inside try.
  • requests.RequestException is the base class for all requests errors, so one except catches timeouts, connection problems and HTTP errors.
  • Without raise_for_status() a 404 would look like a normal response and you would process an error message as if it were data.

fetch_json(): a function you can reuse
Python
import requests

def fetch_json(url, params=None, timeout=10):
    """Return parsed JSON, or None if anything goes wrong."""
    try:
        response = requests.get(url, params=params, timeout=timeout)
        response.raise_for_status()
        return response.json()
    except requests.exceptions.Timeout:
        print("  -> timed out")
    except requests.exceptions.ConnectionError:
        print("  -> could not connect")
    except requests.exceptions.HTTPError as e:
        print("  -> bad status:", e)
    except ValueError:
        print("  -> response was not valid JSON")
    return None

"""API-Powered Data Analyzer: fetch -> inspect -> clean -> analyse -> export."""
import sys

import numpy as np
import pandas as pd
import requests

API_URL = "https://api.example.com/v1/orders"   # placeholder: swap in a real API later
OUTPUT_FILE = "clean_orders.csv"


def fetch_orders(url, timeout=10):
    """Download the orders as a list of dictionaries."""
    try:
        response = requests.get(url, params={"limit": 50}, timeout=timeout)
        response.raise_for_status()
        data = response.json()
    except requests.RequestException as e:
        sys.exit(f"Could not fetch data: {e}")
    except ValueError:
        sys.exit("The API did not return valid JSON.")
    if not isinstance(data, list) or not data:
        sys.exit("Unexpected or empty response.")
    return data


def inspect(df):
    print("Rows, columns :", df.shape)
    print("Missing values:", df.isnull().sum()[lambda s: s > 0].to_dict())
    print("Duplicate rows:", int(df.duplicated().sum()))


def clean(df):
    df = df.drop_duplicates().copy()
    df["city"] = df["city"].str.strip().str.title()
    df["created"] = pd.to_datetime(df["created"])
    df = df.dropna(subset=["amount"])        # an order without an amount cannot be analysed
    return df.reset_index(drop=True)


def analyse(df):
    done = df[df["status"] == "completed"]
    amounts = done["amount"].to_numpy()      # hand the numbers to NumPy

    print(f"Completed orders : {len(done)}")
    print(f"Total revenue    : Rs. {amounts.sum():,.2f}")
    print(f"Average order    : Rs. {amounts.mean():,.2f}")
    print(f"Median order     : Rs. {np.median(amounts):,.2f}")
    print(f"90th percentile  : Rs. {np.percentile(amounts, 90):,.2f}")
    print(f"Std deviation    : Rs. {amounts.std():,.2f}")

    by_city = done.groupby("city")["amount"].sum().sort_values(ascending=False)
    print("\nRevenue by city:")
    print(by_city.to_string())

    print("\nOrders by status:")
    print(df["status"].value_counts().to_string())

    best_day = done.groupby(done["created"].dt.day_name())["amount"].sum().idxmax()
    print("\nBest sales day:", best_day)


def main():
    records = fetch_orders(API_URL)
    df = pd.DataFrame(records)
    inspect(df)
    df = clean(df)
    print("\nAfter cleaning:", df.shape)
    analyse(df)
    df.to_csv(OUTPUT_FILE, index=False)
    print(f"\nSaved {len(df)} rows to {OUTPUT_FILE}")


if __name__ == "__main__":
    main()

Interview Connection

Tap a question to see a short, interview-ready answer. Try answering aloud first.

Libraries and environment

Q1 What is a virtual environment?

An isolated Python environment for one project with its own installed packages, so projects with different dependency versions do not clash. Create: python -m venv venv.

Q2 What is requirements.txt?

A text file listing a project's dependencies (and versions). Create it with pip freeze > requirements.txt; rebuild with pip install -r requirements.txt.

Q3 Difference between a library and a framework?

You call a library when you need it. A framework controls the flow and calls your code (inversion of control). Example: Requests is a library; Django/Flask are frameworks.

NumPy

Q4 What is NumPy?

A library for fast numerical computing built around the ndarray: a fixed-type, N-dimensional array with vectorised operations, statistics and reshaping.

Q5 Why use NumPy instead of Python lists?

Arrays hold one type compactly and support vectorised element-wise operations executed in optimised compiled code, so large numerical work is usually much faster and shorter to write. Lists remain better for small, mixed or non-numeric data.

Q6 What does axis mean in NumPy?

The dimension along which an operation works. axis=0 goes down the rows (result per column); axis=1 goes across columns (result per row). That axis is the one that disappears.

Q7 Are NumPy slices copies?

No. Basic slices are views sharing memory with the original; modifying one changes the other. Use .copy() for an independent array.

Pandas

Q8 What is a Pandas Series?

A one-dimensional labelled array (values + index), like a single column.

Q9 What is a DataFrame?

A two-dimensional labelled table of columns, where each column is a Series and can have a different type.

Q10 Difference between loc and iloc?

loc selects by label (slice end included); iloc selects by integer position (slice end excluded).

Q11 What does groupby() do?

Split-apply-combine: it splits rows into groups by a key, applies an aggregation (mean, sum, count...) per group and combines the results. Example: df.groupby("Dept")["Salary"].mean().

Q12 How do you handle missing values?

First inspect (isnull().sum()). Then decide based on the data: dropna() if rows are unusable or few, fillna() with a justified value (mean/median/constant) if you must keep rows. There is no universal answer; document the choice.

Q13 concat vs merge?

concat stacks tables (rows or columns) with matching structure; merge joins tables on key columns like a SQL join.

Q14 Why do you need & instead of "and" when filtering a DataFrame?

Conditions produce boolean Series (many values). and/or need a single truth value and raise an error; &/| work element-wise. Each condition also needs parentheses because of operator precedence.

APIs

Q15 What is an API?

A defined interface that lets one program request data or actions from another, usually over HTTP, commonly returning JSON.

Q16 What is JSON?

A text format for structured data (objects, arrays, strings, numbers, booleans, null) that maps naturally to Python dicts and lists.

Q17 GET vs POST?

GET reads data, with parameters in the URL, and should not change server state. POST sends data in the body to create something or trigger an action; repeating it may have side effects.

Q18 What does HTTP status 200 mean? And 404, 500?

200 OK (success). 404 not found (client asked for something that does not exist). 500 internal server error (server problem). 4xx = client-side problem, 5xx = server-side.

Q19 What is response.json()?

It parses the response body as JSON and returns Python objects (dict/list). It raises an error if the body is not valid JSON.

Q20 Why should API requests use timeouts?

Without a timeout, a slow or hung server can block your program indefinitely. A timeout turns that into a catchable requests.Timeout error.

Q21 How do you keep API keys safe?

Never hard-code them. Load from environment variables or a .env file excluded from version control; never print or commit them; revoke and replace any that leak.
