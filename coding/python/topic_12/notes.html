Topic Introduction

Do you think the Python team wrote square-root code for every programmer? No. They wrote it once and put it in a module.

You just import it and use it. In this chapter you will learn to use other people's code, and to organize your own.

💡 What you'll learn

  • Four ways to write an import

02

What is a Module?

MODULE
A Python file (ending in .py) that holds ready-to-use code: functions, variables and more.
Example: math.py holds maths tools.
💡 Real-life analogy

Think of a toolbox. One box has maths tools, another has date tools. You open only the box you need.

How importing works
03

Why Use Modules?

  • Reuse — do not rewrite code that already exists.
  • Save time — thousands of tools are ready for you.
  • Stay organized — split a big program into small files.
  • Fewer bugs — popular modules are tested by millions of people.
  • Teamwork — each person can work on a different file.
🧠 Remember this

Python is famous for the saying "batteries included". It comes with hundreds of useful modules built in.

04

Three Kinds of Modules

📦 1. Built-in (Standard Library)

Comes with Python. Nothing to install. Examples: math, random, datetime.

✍️ 2. User-defined

Files you write yourself. Example: your own mymath.py.

🌍 3. Third-party

Made by other people. You install them with pip. Examples: numpy, pandas, requests.

05

The import Statement

Concept

import brings a module into your program. Then you use its tools with a dot: module.tool.

Syntax 
import module_name
module_name.function_name()
Example
Python
import math

print(math.sqrt(16))
print(math.pi)
Output 
4.0
3.141592653589793
Easy Explanation
  • import math opens the maths toolbox.
  • math.sqrt(16) uses the square-root tool. It returns 4.0.
  • math.pi is a ready-made value of π.
📌 Good habit

Put all your import lines at the top of the file.

06

import ... as (Nicknames)

Long module names get tiring to type. Give them a short nickname using as.

Python
import math as m

print(m.floor(7.9))
print(m.ceil(7.1))
Output
7
8
  • m is now another name for math.
  • After this, writing math.floor(...) will not work. Use m.
  • Data science people often write import numpy as np.
07

from ... import

Concept

Use from to pick only the tools you need. Then you use them without the module name.

Syntax 
from module_name import tool1, tool2
Example
Python
from math import sqrt, pi

print(sqrt(25))
print(round(pi, 2))
Output 
5.0
3.14
Easy Explanation
  • We took only sqrt and pi out of the box.
  • We wrote sqrt(25), not math.sqrt(25).
  • The rest of the math tools were not brought in.

You can add a nickname here too

Python
from math import factorial as fact

print(fact(5))
Output
120
08

Which Import Style to Use?

import math
Whole module. Use math.sqrt(). Clear and safe.
import math as m
Whole module with a short nickname.
from math import sqrt
Only what you need. Use sqrt() directly.
from math import *
Everything at once. Usually a bad idea.
⚠️ Avoid import *
  • You cannot tell where a name came from.
  • Names from different modules can clash and overwrite each other.
🧠 Simple rule

Not sure? Use import module. It is the clearest style for beginners.

The math Module

A toolbox for maths jobs. Here are the favourites.

sqrt(x)
Square root
pi
The value of π
ceil(x)
Round up to a whole number
floor(x)
Round down to a whole number
factorial(n)
n × (n-1) × ... × 1
pow(a, b)
a to the power b
Python
import math

print(math.ceil(4.2))
print(math.floor(4.8))
print(math.factorial(5))
print(math.pow(2, 3))
Output
5
4
120
8.0
  • ceil(4.2) goes up to 5.
  • floor(4.8) goes down to 4.
  • pow always gives a decimal number, so 2³ shows as 8.0.
10

The random Module

Need a dice roll, a lucky draw or a shuffled list? Use random.

randint(a, b)
Random whole number from a to b (both included)
choice(list)
Picks one random item
shuffle(list)
Mixes up a list in place
random()
Random decimal between 0 and 1
Python
import random

print(random.randint(1, 6))
print(random.choice(["red", "green", "blue"]))

cards = [1, 2, 3, 4]
random.shuffle(cards)
print(cards)
Possible output (changes every run)
4
green
[3, 1, 4, 2]
📌 Do not expect the same answer

Random means the result changes each time you run the program. Your output will be different from the one above.

11

The datetime Module

Works with dates and times. It has a class called date for calendar dates.

Python
from datetime import date

d = date(2026, 5, 17)

print(d)
print(d.year)
print(d.month)
print(d.strftime("%d-%m-%Y"))
print(d.strftime("%A"))
Output
2026-05-17
2026
5
17-05-2026
Sunday
  • d.year and d.month pick out parts of the date.
  • strftime() formats the date as text.
  • %d = day, %m = month, %Y = year, %A = weekday name.

To get today's date, use date.today(). The answer depends on the day you run it.

12

Exploring a Module

How do you find out what is inside a module? Python gives you two helpers.

  • dir(module) — lists every name inside it.
  • help(module.tool) — shows how a tool works.
Python
import math

print("sqrt" in dir(math))
print("banana" in dir(math))
Output
True
False

The full dir(math) list is long, so we only checked if two names are inside. Try printing dir(math) yourself.

13

Creating Your Own Module

Any .py file you write is already a module. It is that simple.

Step 1: Create mymath.py

mymath.py
PI = 3.14159

def add(a, b):
    return a + b

def area_circle(r):
    return PI * r * r

Step 2: Create main.py in the same folder

main.py
import mymath

print(mymath.add(2, 3))
print(mymath.PI)
print(round(mymath.area_circle(2), 2))

from mymath import add
print(add(10, 20))
Output when you run main.py
5
3.14159
12.57
30
  • The file name mymath.py becomes the module name mymath.
  • Leave out the .py when you import.
  • Both files must be in the same folder for now.
14

Where Python Looks for Modules

When you write import something, Python searches in this order:

  1. The current folder (where your program is).
  2. The standard library that came with Python.
  3. Folders where installed packages live (like pip downloads).

If it finds nothing, you get a ModuleNotFoundError.

⚠️ Careful with file names

Never name your own file the same as a built-in module. A file called random.py will hide the real random module and cause confusing errors.

15

The __name__ == "__main__" Trick

Every Python file has a hidden variable called __name__. Its value depends on how the file is used.

  • Run the file directly → __name__ is "__main__".
  • Import the file from another → __name__ is the module's name.
demo.py
print("My name is:", __name__)
Run demo.py directly
My name is: __main__
Import demo from another file
My name is: demo

Why is this useful?

It lets one file act as both a module and a program. Code under the check runs only when the file is run directly.

greet.py
def hello(name):
    print("Hello,", name)

if __name__ == "__main__":
    hello("Riya")
Run greet.py directly
Hello, Riya

If another file does import greet, the hello("Riya") line does not run. Only the function becomes available.

16

What is a Package?

PACKAGE
A folder that holds several related modules. It groups them under one name.
Example: a shapes folder with circle.py and square.py.
💡 Real-life analogy

A module is a single book. A package is a whole bookshelf of related books.

A package is a folder of modules
  • __init__.py marks the folder as a package. It can be empty.
  • Modern Python can often work without it, but keeping it is the clear, safe habit.
17

Creating Your Own Package

Step 1: Make the files

shapes/circle.py
def area(r):
    return round(3.14159 * r * r, 2)
shapes/square.py
def area(s):
    return s * s

Also add an empty file named shapes/__init__.py.

Step 2: Use it from main.py

main.py
from shapes import circle, square

print(circle.area(2))
print(square.area(4))

from shapes.square import area
print(area(5))

import shapes.circle as c
print(c.area(1))
Output
12.57
16
25
3.14
  • Use a dot to go inside a package: shapes.square.
  • circle.area and square.area have the same name, but live in different modules, so they never clash.
18

Third-Party Packages and pip

Millions of free packages made by other developers are available online. You get them with pip, Python's package installer.

⚠️ pip runs in the terminal

Type pip commands in your terminal or command prompt, not inside a Python file.

pip install name
Download and install a package
pip list
Show installed packages
pip uninstall name
Remove a package
Terminal (not Python code)
pip install requests
pip list
pip uninstall requests

After installing, you import it like any other module:

Python
import requests

Popular packages

  • numpy — fast number crunching.
  • pandas — tables and data analysis.
  • matplotlib — charts and graphs.
  • requests — talk to websites.
  • flask / django — build websites.
📌 Pro tip: virtual environments

Professionals keep each project's packages separate using a virtual environment (python -m venv). You will meet it when you build bigger projects.

Module vs Package vs Library

📄 Module

A single .py file. Example: math.

📦 Package

A folder of modules. Example: shapes/.

📚 Library

A general word for a collection of reusable code. People say "the NumPy library" or "the standard library".

Common Beginner Mistakes

❌ Wrong: Forgetting to import
print(math.sqrt(4))
Error
NameError: name 'math' is not defined
✅ Correct: add import math at the top

Newer Python versions add a friendly hint: "Did you forget to import 'math'?"

❌ Wrong: A typo in the module name
import maths
Error
ModuleNotFoundError: No module named 'maths'
✅ Correct: import math
❌ Wrong: Using the module name after from-import
from math import sqrt
print(math.sqrt(4))
Error
NameError: name 'math' is not defined
✅ Correct: print(sqrt(4))

With from, only sqrt came in. The name math did not.

❌ Wrong: Naming your file like a built-in module
# inside a file called random.py
import random
print(random.randint(1, 6))
Error
AttributeError: partially initialized module 'random' has no attribute 'randint'
✅ Correct: rename your file, for example dice_game.py

Python imported your own file instead of the real random.

❌ Wrong: Typing pip install inside a Python file
pip install requests
Error
SyntaxError: invalid syntax
✅ Correct: run it in the terminal, then use import requests in Python

Quick Revision

Module→A .py file with reusable code
Package→A folder of modules
Library→A collection of reusable code
import m→Bring in the whole module; use m.tool
import m as x→Give the module a nickname
from m import t→Bring in only t; use t directly
import *→Brings everything; usually avoid
math / random / datetime→Built-in modules for maths, chance, dates
dir() / help()→Explore what a module contains
__name__ == "__main__"→True only when the file is run directly
__init__.py→Marks a folder as a package
pip→Installs third-party packages (in the terminal)
22

Key Points to Remember

  • A module is just a Python file. A package is a folder of modules.
  • Python has built-in, your-own, and third-party modules.
  • Use import module and call tools with module.tool().
  • Use as for a short nickname. Use from to pick specific tools.
  • Put all imports at the top of your file.
  • Never name your file the same as a built-in module.
  • Random results change every run.
  • if __name__ == "__main__": runs code only when the file is run directly.
  • Install third-party packages with pip in the terminal.
