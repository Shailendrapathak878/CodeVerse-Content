01

Topic Introduction

Until now, your programs ran every line from top to bottom, every time. Real programs need to decide: "Is the user old enough?", "Did the password match?", "Is the number even?". Conditional statements give Python that power.

💡 What you'll walk away with

You'll be able to write if, elif and else blocks, combine conditions, nest decisions inside each other, and avoid the most common beginner mistakes.

02

What are Conditional Statements?

CONDITIONAL STATEMENT
A statement that runs a block of code only if a condition is true.
Example: "If it is raining, take an umbrella."
💡 Real-life analogy

You make decisions all day: if it is raining, you take an umbrella, otherwise you wear sunglasses. Python code works the same way — it checks a condition and chooses what to do.

Python has three keywords for decisions: if, elif (short for "else if") and else.

03

Conditions Are True or False

A condition is any expression that Python can answer with True or False. You made these in Chapter 4 using comparison operators.

Python
age = 20
print(age >= 18)
print(age == 25)
Output
True
False

An if statement looks at this True/False answer. If it is True, the code inside runs. If it is False, Python skips it.

==
Equal to
!=
Not equal to
> <
Greater than, less than
>= <=
Greater or equal, less or equal
04

The if Statement

Concept

The if statement runs a block of code only when its condition is True. If the condition is False, the block is skipped.

Syntax 
if condition:
    # code that runs when condition is True
Example
Python
age = 20
if age >= 18:
    print("You can vote")
print("Program finished")
Output 
You can vote
Program finished
Easy Explanation

Python checks age >= 18. It is True, so the indented line runs. The last print is not indented, so it belongs to the main program and always runs. If age were 15, only "Program finished" would appear.

FLOWCHART · if statement

If the answer is NO, Python jumps past the block and carries on.

05

Indentation Inside if

You met indentation in Chapter 2. Here it matters even more: the colon : at the end of the if line, plus the 4 spaces in front of the next lines, tell Python which code belongs inside the if.

Python
score = 80
if score >= 50:
    print("You passed")
    print("Well done!")
print("Result checked")
Output
You passed
Well done!
Result checked

Both indented lines belong to the if block. They run together, or are skipped together. The last line has no indentation, so it is outside the block.

⚠️ Two things beginners forget

1) The colon : at the end of the if line. 2) The indentation of the lines inside. Missing either one causes an error.

06

The if-else Statement

Concept

Use else to say what should happen when the condition is not true. Exactly one of the two blocks will run.

Syntax 
if condition:
    # runs if True
else:
    # runs if False
Example
Python
num = 7
if num % 2 == 0:
    print("Even")
else:
    print("Odd")
Output 
Odd
Easy Explanation

7 % 2 gives remainder 1, so num % 2 == 0 is False. Python skips the if block and runs the else block instead.

FLOWCHART · if-else statement

Exactly one path is taken: either the if block or the else block.

07

The if-elif-else Statement

Concept

When there are more than two choices, add elif (else if) in the middle. Python checks the conditions from top to bottom and runs the block of the first True one, then skips the rest.

Syntax 
if condition1:
    # block 1
elif condition2:
    # block 2
else:
    # runs if nothing above was True
Example
Python
marks = 82
if marks >= 90:
    print("Grade A")
elif marks >= 75:
    print("Grade B")
elif marks >= 50:
    print("Grade C")
else:
    print("Fail")
Output 
Grade B
Easy Explanation

82 is not >= 90, so Python moves on. 82 is >= 75, so it prints "Grade B" and stops checking. The remaining elif and else are skipped, even though 82 is also >= 50.

FLOWCHART · if-elif-else ladder
🧠 Remember this

You can have as many elif blocks as you need, but only one if at the start and at most one else at the end. The else never has a condition.

08

Combining Conditions (and, or, not)

Use the logical operators from Chapter 4 to check more than one thing in a single condition.

and
Both conditions must be True
or
At least one condition must be True
not
Reverses True and False
Python
age = 20
has_id = True

if age >= 18 and has_id:
    print("Entry allowed")
else:
    print("Entry denied")

day = "Sunday"
if day == "Saturday" or day == "Sunday":
    print("Weekend")

is_raining = False
if not is_raining:
    print("No umbrella needed")
Output
Entry allowed
Weekend
No umbrella needed
⚠️ Write each full condition

Write day == "Saturday" or day == "Sunday". Beginners often write day == "Saturday" or "Sunday", which does not mean what it looks like and is always treated as True.

09

Chained Comparisons

Python lets you check whether a value lies between two numbers in one neat expression, just like in maths class.

Python
age = 30
if 18 <= age <= 60:
    print("Working age")
Output
Working age

18 <= age <= 60 means the same as age >= 18 and age <= 60, but it is shorter and easier to read.

10

Nested if Statements

Concept

A nested if is an if placed inside another if. The inner decision is only reached if the outer condition is True. Each level gets 4 more spaces of indentation.

Example
Python
age = 25
has_id = True

if age >= 18:
    if has_id:
        print("Entry allowed")
    else:
        print("ID required")
else:
    print("Too young")
Output 
Entry allowed
Easy Explanation

First Python checks the age. It is 18 or more, so it goes inside and checks has_id. That is True, so it prints "Entry allowed". If the age were 15, Python would jump straight to the outer else.

📌 Tip

Nested blocks work, but too many levels get hard to read. When you can, combine conditions with and instead (like in Section 8).

11

Short-hand if-else (One Line)

Concept

When you only need to pick between two values, Python lets you write the whole if-else in a single line. It is called a conditional expression.

Syntax 
value_if_true if condition else value_if_false
Example
Python
age = 20
status = "Adult" if age >= 18 else "Minor"
print(status)
Output 
Adult
Easy Explanation

Read it like English: "status is Adult if age is 18 or more, else Minor." It does the same job as a 4-line if-else, but in one line.

12

Truthy and Falsy Values

An if does not only work with True and False. Python can treat any value as a condition. Some values count as falsy (act like False), and almost everything else counts as truthy (acts like True).

Falsy values

False, None, 0, 0.0, "" (empty string), [] (empty list)

Truthy values

Everything else, such as 5, -3, "hi", [1, 2]

Python
print(bool(0), bool(""), bool("hi"), bool(5))

name = ""
if name:
    print("Hello,", name)
else:
    print("Name is empty")
Output
False False True True
Name is empty

An empty string is falsy, so if name: is False and the else block runs. This is a handy way to check "did the user type anything?".

13

Conditions with input()

Decisions become powerful when they depend on what the user types. Remember: input() returns a string, so convert it to a number first when you need to compare it.

Python
age = int(input("Enter your age: "))

if age >= 18:
    print("You are an adult")
else:
    print("You are a minor")
Output (user typed 16)
Enter your age: 16
You are a minor

Comparing text works too. Use == and remember that text comparison is case-sensitive:

Python
password = input("Enter password: ")

if password == "python123":
    print("Access granted")
else:
    print("Wrong password")
Output (user typed Python123)
Enter password: Python123
Wrong password

The user typed a capital P, so the text is not equal to "python123".

14

The pass Statement

pass
A statement that does nothing. It is a placeholder for a block that you plan to fill in later.

Python does not allow an empty if block, so write pass when you have nothing to put there yet.

Python
x = 3
if x > 5:
    pass
else:
    print("Small")
Output
Small

Real Examples

Positive, negative or zero

Python
n = -5
if n > 0:
    print("Positive")
elif n < 0:
    print("Negative")
else:
    print("Zero")
Output
Negative

Largest of three numbers

Python
a = 10
b = 25
c = 15

if a >= b and a >= c:
    print(a, "is the largest")
elif b >= a and b >= c:
    print(b, "is the largest")
else:
    print(c, "is the largest")
Output
25 is the largest

Leap year check

Python
year = 2024
if (year % 4 == 0 and year % 100 != 0) or year % 400 == 0:
    print(year, "is a leap year")
else:
    print(year, "is not a leap year")
Output
2024 is a leap year

A year is a leap year if it divides by 4 but not by 100, or if it divides by 400. 2024 divides by 4 and not by 100, so it qualifies.

16

Common Beginner Mistakes

❌ Wrong: Using = instead of == in a condition
if x = 5:
    print("Five")
✅ Correct: if x == 5:

= stores a value. == compares two values. A condition needs the comparison.

❌ Wrong: Forgetting the colon
if age >= 18
    print("Adult")
✅ Correct: if age >= 18:

This causes a SyntaxError. Every if, elif and else line must end with a colon.

❌ Wrong: Forgetting to indent the block
if age >= 18:
print("Adult")
✅ Correct: put 4 spaces before print("Adult")

Without indentation Python raises an IndentationError.

❌ Wrong: Using separate ifs when you meant elif
marks = 95
if marks >= 90:
    print("A")
if marks >= 75:
    print("B")
Output (surprise!)
A
B
✅ Correct: make the second one elif marks >= 75: to get only A

Each separate if is checked on its own, so both ran. elif links the checks together so only one block runs.

❌ Wrong: Comparing input() text with a number
age = input("Enter age: ")
if age >= 18:
    print("Adult")
Error
TypeError: '>=' not supported between instances of 'str' and 'int'
✅ Correct: age = int(input("Enter age: "))
17

Quick Revision

Conditional statement→Runs code only when a condition is True
if→Runs its block when the condition is True
else→Runs when no earlier condition was True
elif→Another condition to check; the first True one wins
Colon and indentation→Needed after every if / elif / else line
and / or / not→Combine or reverse conditions
Chained comparison→18 <= age <= 60 checks a range
Nested if→An if placed inside another if
Short-hand if→a if condition else b, on one line
Falsy values→False, None, 0, 0.0, "", [] act as False
pass→Does nothing; a placeholder for an empty block
18

Key Points to Remember

  • A condition is any expression that works out to True or False.
  • Every if, elif and else line ends with a colon, and its block is indented.
  • In an if-elif-else chain, Python runs only the first block whose condition is True.
  • else has no condition and always comes last.
  • Use == to compare, not =.
  • Use and, or and not to build bigger conditions from smaller ones.
  • Convert input() to int() or float() before comparing it with numbers.
  • Separate if statements are all checked; elif links them into one decision.
  • Empty values like "", 0 and [] are falsy, so if value: is a quick check.
  • Keep nesting shallow — combine conditions with and when possible.
