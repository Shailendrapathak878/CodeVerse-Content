01

What Are Conditional Statements?

In everyday life, we make decisions constantly based on circumstances around us. If it is raining outside, you carry an umbrella; if your phone battery drops below 15%, you plug in the charger; if traffic light is green, you proceed.

Definition: Conditional Statement

A conditional statement is a programming structure that directs Python to execute a specific block of instructions only if a designated test condition evaluates to True. If the condition evaluates to False, Python skips that code block entirely or takes an alternative path.

⚖️ Normal Sequential Statement vs. Conditional Statement
⬇️
Sequential Flow (Topics 1–5)

Every line runs unconditionally from top to bottom, one after another, no matter what happens.

🔀
Conditional Flow (Topic 6)

Python inspects a condition first. Code executes dynamically depending on whether the answer is True or False.

First Conditional Example 
1is_raining = True
2
3if is_raining:
4    print("Take an umbrella with you!")
5
6print("Have a wonderful day!")
Terminal Output
Take an umbrella with you! Have a wonderful day!
What Happens if is_raining = False?

If is_raining were set to False, line 4 would be completely skipped! Line 6 would still run because it is written on the outer level without indentation. That is the core power of conditional execution.

How Conditional Statements Work

Under the hood, decision-making follows a simple fork in the road: evaluate the test question, determine if the answer is True or False, and branch accordingly.

Decision Flowchart: Age Voting Eligibility Check
▶ Start Program (Enter Age)
⬇
Condition: Is Age >= 18?
⬇
✔ If TRUE
Print: "Eligible to vote!"
✖ If FALSE
Print: "Too young to vote."
⬇
⏹ End (Continue Program)

Note: While 18 years is the standard legal voting age in most democratic nations (including India, the US, and the UK), the exact threshold depends on country-specific laws. We use 18 throughout our examples for illustration.

03

The if Statement (Single Decision)

The simplest decision tool is the standalone if statement. It acts like a one-way security gate: if the key fits (condition is True), the door opens and the inner block runs. Otherwise, nothing happens and execution moves forward.

Syntax of an if Statement
if condition:
    # indented code block (runs only if condition is True)
    statement_1
    statement_2
📐 Indentation Visualizer (4 Spaces Rule)

In Python, indentation is not cosmetic—it tells the interpreter where a code block begins and ends:

if score >= 50: # Notice the trailing colon!
· · · · 4 SPACES print("Congratulations, you passed!")
· · · · 4 SPACES print("Certificate issued.")
print("End of report.") # Unindented: Always runs
Python if Demo 
1balance = 1500
2withdrawal_amount = 500
3
4if withdrawal_amount <= balance:
5    balance -= withdrawal_amount
6    print(f"Withdrawal successful! Remaining balance: ₹{balance}")
7
8print("Thank you for using CodeVerse ATM.")
Terminal Output
Withdrawal successful! Remaining balance: ₹1000 Thank you for using CodeVerse ATM.
🔍 Line-by-Line Breakdown
  • 1-2Stores bank account balance (1500) and requested cash amount (500).
  • 4Evaluates 500 <= 1500. Since 500 is less than 1500, this evaluates to True.
  • 5-6Because the condition is True, Python steps inside the indented block, deducts ₹500, and prints the confirmation.
  • 8Written at root level (no indent), so it executes unconditionally after the decision finishes.
04

The if-else Statement (Two Alternatives)

Real-life choices often come in pairs: pass or fail, heads or tails, eligible or ineligible. The if-else statement ensures that exactly one of two actions will always execute.

Syntax of an if-else Statement
if condition:
    # Runs when condition is TRUE
    action_true
else:
    # Runs when condition is FALSE
    action_false
Pass / Fail Evaluation 
1marks = 72
2
3if marks >= 40:
4    print("Result: PASS")
5    print("Congratulations, keep up the great effort!")
6else:
7    print("Result: FAIL")
8    print("Do not be discouraged. Revise and try again!")
Terminal Output (with marks = 72)
Result: PASS Congratulations, keep up the great effort!
Important: else Takes No Condition

Notice that else never has a condition written next to it! Writing else marks < 40: is a fatal SyntaxError. else: simply catches everything that did not meet the preceding if condition.

05

The if-elif-else Ladder (Multi-Way Decisions)

What if a problem has more than two possible outcomes? For example, school grading (A, B, C, D, or Fail), traffic lights (Red, Yellow, or Green), or customer reward tiers. That is where elif (short for "else if") is needed.

Syntax of an if-elif-else Ladder
if condition_1:
    block_1
elif condition_2:
    block_2
elif condition_3:
    block_3
else:
    fallback_block # Runs only if none of the above matched
How Python Evaluates the Ladder

Python checks conditions from top to bottom, one by one. The moment it finds a condition that evaluates to True, it executes that branch's block and immediately exits the entire ladder. Even if later conditions are also true, they are never evaluated!

📊 Illustrative Academic Grading Scale
Score Range Grade Evaluation Logic
90% and above Grade A marks >= 90
75% to 89% Grade B marks >= 75 (only reached if < 90)
60% to 74% Grade C marks >= 60 (only reached if < 75)
40% to 59% Grade D marks >= 40 (only reached if < 60)
Below 40% Fail else (catches anything under 40)
Academic Grading System Program 
1marks = 82
2

4    grade = "A"
5elif marks >= 75:
6    grade = "B"
7elif marks >= 60:
8    grade = "C"
9elif marks >= 40:
10    grade = "D"

  • Run 2 (marks = 35): Checks line 3 (False) ➔ line 5 (False) ➔ line 7 (False) ➔ line 9 (False) ➔ enters line 11 else. Sets grade = "Fail". Output: Grade: Fail.
06

Nested if Statements (Decisions Inside Decisions)

Sometimes a secondary question only makes sense if an initial requirement is already satisfied. For example, before verifying whether a citizen is registered to vote, you must first confirm whether they are 18 or older. Placing an if statement inside another if block is known as nesting.

Syntax of Nested if
if outer_condition:
    # First level indent (4 spaces)
    if inner_condition:
        # Second level indent (8 spaces)
        action_both_true
    else:
        action_outer_true_inner_false
else:
    action_outer_false
Voter Eligibility & Registration Check 
1age = 20
2has_voter_id = True
3
4if age >= 18:
5    print("Age check passed: You are old enough to vote.")
6    
7    # Nested check inside the outer block
8    if has_voter_id:
9        print("Registration check passed: Please proceed to the ballot!")
10    else:
11        print("You are old enough, but must register for a Voter ID first.")
12else:
13    print("You are not eligible to vote yet. Please wait until you are 18.")
Terminal Output
Age check passed: You are old enough to vote. Registration check passed: Please proceed to the ballot!
Caution: Avoid Deep Nesting ("Arrow Anti-Pattern")

Nesting 2 levels deep is standard and clean. However, nesting 4, 5, or 6 levels deep makes code unreadable (often called the "pyramid of doom"). When testing multiple conditions together, prefer using logical operators like and (covered in Section 8) to flatten your code.

07

Comparison Operators in Conditions

Conditions are built using comparison operators. They compare two values and always produce a boolean result: either True or False.

Operator Name & Meaning Example Evaluates To
== Equal to (checks value equality) 10 == 10 True
!= Not equal to (checks difference) 10 != 5 True
> Strictly greater than 15 > 20 False
< Strictly less than 15 < 20 True
>= Greater than or equal to 18 >= 18 True
<= Less than or equal to 25 <= 20 False
Critical Beginner Trap: = vs. ==

Never confuse the assignment operator (=) with the equality comparison operator (==):

  • x = 10 ➔ Stores value 10 into variable x.
  • x == 10 ➔ Asks a question: "Does variable x currently equal 10?" (Returns True or False).

Writing if x = 10: in Python immediately halts with a SyntaxError: invalid syntax because assignment is forbidden inside condition headers.

08

Logical Operators (and, or, not)

When decisions depend on multiple factors simultaneously—such as having both good marks and minimum attendance—we connect conditions using logical operators.

and
and (Both Must Be True)

Returns True only when every condition is satisfied.

True and True ➔ True
True and False ➔ False
False and True ➔ False
False and False ➔ False
or
or (At Least One True)

Returns True if any one of the conditions is satisfied.

True or True ➔ True
True or False ➔ True
False or True ➔ True
False or False ➔ False
not
not (Reverses State)

Inverts truth: flips True to False, and False to True.

not True ➔ False
not False ➔ True
Logical Operators Demo 
1age = 21
2has_license = True
3
4# Example 1: 'and' (Both criteria required to rent a vehicle)
5if age >= 18 and has_license:
6    print("Rental approved: You may drive the rental car.")
7
8# Example 2: 'or' (Discount if VIP member OR purchase > ₹1000)
9is_vip = False
10bill_amount = 1250
11if is_vip or bill_amount > 1000:
12    print("Discount applied: 10% off your total bill!")
13
14# Example 3: 'not' (Checking for incomplete state)
15is_logged_in = False
16if not is_logged_in:
17    print("Please log in to CodeVerse to access your profile.")
Terminal Output
Rental approved: You may drive the rental car. Discount applied: 10% off your total bill! Please log in to CodeVerse to access your profile.
Performance Concept: Short-Circuit Evaluation

Python is smart and lazy. In an and expression, if the first condition is False, the overall expression can never be true, so Python skips checking the second condition. Similarly, in an or expression, if the first condition is True, the overall expression is guaranteed to be true, so Python stops right there!

Truthy and Falsy Values in Python

In Python, conditions do not strictly need to be boolean expressions like x > 5. Every single data value in Python has an inherent truth value when placed in a condition.

❌ Inherently FALSY Values

These evaluate to False when tested in an if header:

  • Number zero: 0, 0.0
  • Empty string: ""
  • Empty collections: [], (), {}
  • The null constant: None
  • Explicit boolean: False
✅ Inherently TRUTHY Values

Virtually everything else evaluates to True:

  • Any non-zero number: 1, -5, 3.14
  • Any non-empty string: "Python", " " (even space!)
  • Any non-empty list: [10, 20]
  • Explicit boolean: True
Truthy & Falsy in Action 
1user_input = "Aman"
2
3# Idiomatic Python: Checking if a string is non-empty
4if user_input:
5    print(f"Welcome, {user_input}!")
6else:
7    print("Error: Name cannot be blank.")
8
9# Checking items in an empty list
10cart = []
11if cart:
12    print("Proceeding to checkout...")
13else:
14    print("Your cart is empty. Add products to buy!")
Terminal Output
Welcome, Aman! Your cart is empty. Add products to buy!

Conditional Expressions (Ternary Operator)

When you simply want to choose between two values to assign to a variable, writing a 4-line if-else block can feel verbose. Python provides a sleek, one-line shortcut known as a conditional expression.

One-Line Ternary Formula
variable = value_if_true if condition else value_if_false
Traditional if-else vs. Conditional Expression 
1age = 20
2
3# Traditional 4-line form
4if age >= 18:
5    status = "Adult"
6else:
7    status = "Minor"
8
9# Sleek One-Line Ternary Equivalent
10quick_status = "Adult" if age >= 18 else "Minor"
11
12print(f"Status: {quick_status}")
Terminal Output
Status: Adult
Best Practice: Readability First!

Use ternary expressions only for simple, short assignments. If your logic involves multiple calculations or side-effects (like printing), stick to traditional if-else blocks so your code remains easy to read and maintain.

Voting Eligibility with Years Remaining

Problem Statement: Tell underage users exactly how many years remain before they become eligible to vote.

age = 15
voting_threshold = 18

if age >= voting_threshold:

Program 06 · Logic Mastery

Accurate Leap Year Calculator

Problem Statement: Correctly check if a calendar year is a leap year using the astronomical Gregorian calendar rule.

The Leap Year Rule: A year is a leap year if it is divisible by 400, OR if it is divisible by 4 while NOT being divisible by 100. (For example, 2000 was a leap year, but 1900 and 2100 are NOT!). 

year = 2024

if (year % 400 == 0) or (year % 4 == 0 and year % 100 != 0):
    print(f"{year} is a Leap Year! (366 days)")
else:
    print(f"{year} is a Normal Year (365 days)")
2024 is a Leap Year! (366 days)
Dry Run for 2024: 2024 % 400 == 0 is False. Next checks: 2024 % 4 == 0 (True) and 2024 % 100 != 0 (True). Since both are True, the or statement succeeds!

Common Beginner Mistakes & Fixes

Here are the 7 most common mistakes beginners make with conditional statements in Python and exactly how to fix them.

Mistake 1: Forgetting the Trailing Colon (:)

Incorrect: if age >= 18

What Happens: SyntaxError: expected ':'

Fix: Every if, elif, and else header must strictly end with a colon: if age >= 18:

Mistake 2: IndentationError (Inconsistent or Missing Indents)

Incorrect:

if marks >= 40:
print("Pass") # ❌ IndentationError: expected an indented block

Fix: Indent every line inside the block by 4 spaces.

Mistake 3: Using = Instead of ==

Incorrect: if color = "red":

What Happens: SyntaxError: invalid syntax. Maybe you meant '==' or ':='?

Fix: Always use double equals for comparison: if color == "red":

Mistake 4: Incorrect Ordering of Conditions in an elif Ladder

Incorrect:

if marks >= 40:
    print("Pass")
elif marks >= 90: # ❌ NEVER REACHED! Anyone with 95 gets caught by >= 40 first!
    print("Grade A")

Fix: Always order conditions from the most specific / highest threshold down to the lowest threshold.

Mistake 5: Writing Separate if Statements Instead of elif

Incorrect: Writing multiple independent if blocks means Python evaluates ALL of them, potentially printing contradictory messages (e.g., both "Grade B" and "Pass"). Use elif so only one branch executes.

Mistake 6: Comparing Incompatible Types (String vs Number)

Incorrect: age = input("Age: "); if age >= 18:

What Happens: TypeError: '>=' not supported between instances of 'str' and 'int' (Remember: input() always returns a string!).

Fix: Wrap input() in int(): age = int(input("Age: ")).

Quick Revision Summary

Structure Primary Purpose Syntax Blueprint
if Single decision; runs block only if true if cond:
    code
if-else Dual choice; exactly one branch always runs if cond:
    code1
else:
    code2
if-elif-else Multi-way choice; evaluates top to bottom until first match if c1:
    b1
elif c2:
    b2
else:
    b3
Nested if Decision inside a decision; checks second requirement if c1:
    if c2:
        code
Ternary Compact one-line assignment x = v1 if cond else v2
Logical and True only when BOTH sides are True cond1 and cond2
Logical or True when AT LEAST ONE side is True cond1 or cond2
Logical not Inverts boolean state (True ➔ False) not cond

📌 Golden Rules to Remember

  • ✓Always end if, elif, and else lines with a colon (:).
  • ✓Indent block contents strictly by 4 spaces.
  • ✓Use == for comparison and = for variable assignment.
  • ✓In an if-elif-else chain, only the first true branch executes.
