Topic Introduction

You already know the list. Python has three more containers for storing groups of values.

Each one is built for a different job. Pick the right one and your code becomes shorter and safer.

💡 What you'll learn
  • Tuple — a list that cannot be changed
  • Set — a bag of unique items
  • Dictionary — labeled data, like a contact book
  • How to choose between them
02

The Four Containers at a Glance

Python's four collection types
Part A · Tuples
03

Tuple: What is it?

TUPLE
An ordered collection that cannot be changed after it is created. It is written inside round brackets ( ).
Example: (10, 20)
💡 Real-life analogy

Think of your date of birth. Once it is written, it should never change. A tuple is perfect for data like that.

04

Creating a Tuple

Concept

Put items inside ( ), separated by commas.

Syntax 
tuple_name = (item1, item2, item3)
Example
Python
point = (10, 20)
colors = ("red", "green", "blue")
no_brackets = 1, 2, 3

print(point)
print(colors)
print(no_brackets)
print(type(point))
Output 
(10, 20)
('red', 'green', 'blue')
(1, 2, 3)
<class 'tuple'>
Easy Explanation
  • Brackets are optional. The commas are what make a tuple.
  • type() confirms it is a tuple.

The one-item trap

A tuple with one item needs a comma after it. Without the comma, Python sees plain brackets.

Python
single = (5,)
not_tuple = (5)
print(type(single))
print(type(not_tuple))
Output
<class 'tuple'>
<class 'int'>
05

Accessing and Slicing Tuples

Tuples use indexes and slices exactly like lists and strings.

  • Counting starts at 0.
  • -1 is the last item.
  • In a slice, the end is not included.
Python
colors = ("red", "green", "blue")
print(colors[0])
print(colors[-1])
print(colors[0:2])
Output
red
blue
('red', 'green')
06

Tuples are Immutable

Immutable means "cannot be changed". You cannot replace, add or remove tuple items.

Python (error)
colors = ("red", "green", "blue")
colors[0] = "pink"
Error
TypeError: 'tuple' object does not support item assignment

The workaround

If you really need a change, make a new tuple. Convert to a list, edit it, then convert back.

Python
t = (1, 2, 3)
temp = list(t)
temp.append(4)
t = tuple(temp)
print(t)
Output
(1, 2, 3, 4)
07

Tuple Tools

Since tuples cannot change, they have only two methods.

count(x)
How many times x appears
index(x)
Position of the first x
len(t)
Number of items
+ and *
Join or repeat (makes a new tuple)
in
Check if an item is inside
Python
nums = (4, 2, 7, 2)
print(nums.count(2))
print(nums.index(7))
print(len(nums))
print((1, 2) + (3,))
print((0,) * 3)
print(7 in nums)
Output
2
2
4
(1, 2, 3)
(0, 0, 0)
True
08

Tuple Unpacking

Concept

Unpacking means pulling the items of a tuple into separate variables, in one line.

Example
Python
student = ("Riya", 21, "Delhi")
name, age, city = student

print(name)
print(age)
print(city)
Output 
Riya
21
Delhi
Easy Explanation
  • The first item goes to the first variable, and so on.
  • The number of variables must match the number of items.
  • This is the same trick you used to swap variables in Chapter 3.
📌 Why use tuples at all?
  • Safe — nobody can change the data by mistake.
  • Fast — slightly quicker than lists.
  • Good for fixed data — coordinates, dates, RGB colors.
Part B · Sets
09

Set: What is it?

SET
A collection of unique items with no fixed order. It is written inside curly brackets { }.
Example: {1, 2, 3}
💡 Real-life analogy

Think of a bag of unique stickers. Getting the same sticker twice does not add a new one, and the stickers have no order inside the bag.

10

Creating a Set

Concept

Put items inside { }. Python automatically removes duplicates.

Example
Python
s = {1, 2, 3, 3, 2}
print(s)
print(len(s))
Output 
{1, 2, 3}
3
Easy Explanation

We typed five numbers, but only three are unique. The set kept one copy of each.

The empty-set trap

Empty curly brackets {} make a dictionary, not a set. To make an empty set, use set().

Python
print(type({}))
print(type(set()))
Output
<class 'dict'>
<class 'set'>
11

No Order, No Index

  • A set has no order, so the items may print in a different order.
  • Because of that, a set has no index. You cannot write s[0].
  • Set items must be unchangeable types (numbers, strings, tuples). A list inside a set is not allowed.
Python (error)
s = {10, 20, 30}
print(s[0])
Error
TypeError: 'set' object is not subscriptable

"Not subscriptable" is Python's way of saying: you cannot use [ ] on this.

12

Adding and Removing Set Items

add(x)
Adds one item
update(list)
Adds many items
remove(x)
Removes x (error if missing)
discard(x)
Removes x (no error if missing)
clear()
Removes everything
Python
s = {1, 2}
s.add(3)
s.add(2)
print(s)

s.update([4, 5])
print(s)

s.remove(5)
s.discard(10)
print(s)
Output
{1, 2, 3}
{1, 2, 3, 4, 5}
{1, 2, 3, 4}
  • Adding 2 again changed nothing, because it was already there.
  • discard(10) did nothing and gave no error.
⚠️ remove() vs discard()

remove(10) on a missing item causes KeyError: 10. Use discard() when you are not sure the item exists.

13

Set Operations

Sets work just like circles in maths class. You can combine them, find what they share, or find the differences.

A = {1, 2, 3} and B = {3, 4}
A | B
Union — everything from both
A & B
Intersection — only what both share
A - B
Difference — in A but not in B
A ^ B
Symmetric difference — in one, but not both
Python
A = {1, 2, 3}
B = {3, 4}

print(A | B)
print(A & B)
print(A - B)
print(A ^ B)
Output
{1, 2, 3, 4}
{3}
{1, 2}
{1, 2, 4}

These also have word versions: union(), intersection(), difference() and symmetric_difference().

📌 Real-life use

Two classes have student lists. The intersection finds students who are in both classes.

14

Removing Duplicates

The most popular use of a set: remove repeated items from a list.

Python
nums = [1, 2, 2, 3, 3, 3]
unique = list(set(nums))
print(unique)
Output
[1, 2, 3]
  • set(nums) drops the duplicates.
  • list(...) turns it back into a list.
  • The original order may change, because sets have no order.

Checking membership with in is also very fast in a set, which makes sets great for big collections.

Part C · Dictionaries
15

Dictionary: What is it?

DICTIONARY (dict)
A collection of key : value pairs. You look up a value using its key, not a position number.
Example: {"name": "Riya", "age": 21}
💡 Real-life analogy

Think of the contacts on your phone. You search by name (the key) to get the number (the value). You never search by position.

Keys point to values
16

Creating a Dictionary

Concept

Write pairs as key: value, separated by commas, inside { }.

Syntax 
dict_name = {key1: value1, key2: value2}
Example
Python
student = {"name": "Riya", "age": 21, "city": "Delhi"}
print(student)
print(type(student))
print(len(student))
Output 
{'name': 'Riya', 'age': 21, 'city': 'Delhi'}
<class 'dict'>
3
Easy Explanation
  • Each pair is key : value.
  • len() counts the number of pairs.
  • Dictionaries keep the order you added items in.
17

Accessing Values

There are two ways to read a value.

  • dict[key] — gives an error if the key is missing.
  • dict.get(key) — gives None (or your own default) if the key is missing.
Python
student = {"name": "Riya", "age": 21}

print(student["name"])
print(student.get("age"))
print(student.get("phone"))
print(student.get("phone", "Not found"))
Output
Riya
21
None
Not found
⚠️ Missing key error

Writing student["phone"] when there is no such key causes:

KeyError: 'phone'

18

Adding and Changing Items

Use the same line for both. Python decides what to do:

  • Key exists → the value is changed.
  • Key is new → a new pair is added.
Python
student = {"name": "Riya", "age": 21}

student["age"] = 22
print(student)

student["city"] = "Delhi"
print(student)

student.update({"age": 23, "country": "India"})
print(student)
Output
{'name': 'Riya', 'age': 22}
{'name': 'Riya', 'age': 22, 'city': 'Delhi'}
{'name': 'Riya', 'age': 23, 'city': 'Delhi', 'country': 'India'}

update() lets you add or change many pairs at once.

19

Removing Items

pop(key)
Removes the key and gives back its value
del d[key]
Deletes that pair
clear()
Removes everything
Python
d = {"a": 1, "b": 2, "c": 3, "d": 4}

removed = d.pop("b")
print(removed)
print(d)

del d["a"]
print(d)

d.clear()
print(d)
Output
2
{'a': 1, 'c': 3, 'd': 4}
{'c': 3, 'd': 4}
{}
20

Looping Through a Dictionary

You learned loops in Chapter 7. There are three ways to loop over a dictionary.

for k in d
Gives each key
d.values()
Gives each value
d.items()
Gives key and value together
Python
marks = {"math": 90, "science": 85}

for subject in marks:
    print(subject)

for score in marks.values():
    print(score)

for subject, score in marks.items():
    print(subject, ":", score)
Output
math
science
90
85
math : 90
science : 85

The items() loop is the most useful. It unpacks each pair into two variables, just like tuple unpacking.

21

Handy Dictionary Tools

Python
student = {"name": "Riya", "age": 21}

print(list(student.keys()))
print(list(student.values()))
print(list(student.items()))
print("name" in student)
print("Riya" in student)
Output
['name', 'age']
['Riya', 21]
[('name', 'Riya'), ('age', 21)]
True
False
  • keys() → all keys.
  • values() → all values.
  • items() → all (key, value) tuples.
  • in checks the keys only. That is why "Riya" in student is False.

Real example: counting words

Python
words = ["apple", "banana", "apple"]
counts = {}

for w in words:
    counts[w] = counts.get(w, 0) + 1

print(counts)
Output
{'apple': 2, 'banana': 1}
  • counts.get(w, 0) gives the old count, or 0 for a new word.
  • We add 1 and store it back.
22

Nested Dictionaries

NESTED DICTIONARY
A dictionary that has other dictionaries as its values.
Python
students = {
    "s1": {"name": "Riya", "marks": 90},
    "s2": {"name": "Aman", "marks": 75}
}

print(students["s1"]["name"])
print(students["s2"]["marks"])
Output
Riya
75

Use one pair of brackets for each level. First pick "s1", then pick "name" inside it.

23

Dictionary Rules

  1. Keys must be unique. A repeated key keeps only the last value.
  2. Keys must be unchangeable types: strings, numbers or tuples.
  3. Values can be anything, even lists or other dictionaries.
Python
d = {"a": 1, "a": 2}
print(d)
Output
{'a': 2}

Using a list as a key causes TypeError: unhashable type: 'list'. A tuple works fine instead.

24

Which One Should I Use?

📋 List

Ordered items that will change. Example: a shopping list.

🔒 Tuple

Ordered items that should stay fixed. Example: map coordinates.

🎒 Set

Only unique items, or fast "is it inside?" checks. Example: unique visitors.

📒 Dictionary

Data with labels. Example: a student record.

25

Common Beginner Mistakes

❌ Wrong: Forgetting the comma in a one-item tuple
t = (5)   # this is just the number 5
✅ Correct: t = (5,)
❌ Wrong: Using {} to make an empty set
s = {}   # this is a dictionary!
✅ Correct: s = set()
❌ Wrong: Trying to change a tuple
t = (1, 2, 3)
t[0] = 10
✅ Correct: use a list if you need changes, or build a new tuple
❌ Wrong: Using [ ] on a key that might not exist
d = {"name": "Riya"}
print(d["age"])
✅ Correct: d.get("age") or d.get("age", 0)

The first way raises KeyError. The second is safe.

❌ Wrong: Expecting a set to have an order or index
s = {3, 1, 2}
print(s[0])
✅ Correct: convert to a list first, or loop through the set

Quick Revision

Tuple ( )→Ordered, cannot be changed
(5,)→A one-item tuple needs a comma
Unpacking→a, b = (1, 2) splits a tuple into variables
Set { }→Unique items, no order, no index
set()→The only way to make an empty set
add / update→Add one item / add many items
remove / discard→Error if missing / no error if missing
| & - ^→Union, intersection, difference, symmetric difference
Dictionary { k: v }→Key → value pairs
d[key] / d.get(key)→Read a value (get() is error-safe)
keys / values / items→Keys / values / both together
pop / del / clear→Remove a pair / delete a pair / empty it
27

Key Points to Remember

  • A tuple is an unchangeable list. Use it for fixed data.
  • A one-item tuple needs a comma: (5,).
  • A set keeps only unique items and has no order or index.
  • {} is an empty dictionary. Use set() for an empty set.
  • Sets are great for removing duplicates and finding shared items.
  • A dictionary stores key → value pairs.
  • Use get() to read a key safely.
  • in on a dictionary checks the keys, not the values.
  • Choose the container that matches the job: list, tuple, set or dict.
