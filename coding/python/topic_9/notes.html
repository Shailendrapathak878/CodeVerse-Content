Introduction to Tuples

In Topic 8, we explored Lists: dynamic sequences where you can add, remove, and alter elements freely. But what if you are recording data that must never change once created, such as GPS coordinates, RGB color values, or birthday dates?

What is a Tuple?

A Tuple is a built-in Python sequence that holds an ordered, immutable (unchangeable) collection of items enclosed in parentheses ( ) and separated by commas.

📍
GPS Coordinates

point = (28.6139, 77.2090) representing Latitude and Longitude. A location should not be accidentally modified.

🎨
RGB Color Codes

white = (255, 255, 255). Color channels have a fixed length of 3 and fixed definitions.

🗂️
Database Records

A row from an SQL query: ("Aman", 101, "A+"). The record identity remains intact.

Creating and Inspecting a Tuple 
1# Creating a tuple representing a student record
2student = ("Aman", 20, "CSE")
3
4print(student)
5print(type(student))
Terminal Output
('Aman', 20, 'CSE') <class 'tuple'>

Creating Tuples

Tuples can be created using parentheses (), comma-separated values (tuple packing), or the built-in tuple() constructor function.

The Single-Element Trap: The Trailing Comma Rule

Parentheses alone do not create a tuple — the comma creates the tuple!
a = (10) ➔ Python treats this as mathematical grouping; a is an int.
b = (10,) ➔ The trailing comma informs Python that this is a tuple of length 1.

Tuple Creation Patterns

6not_tuple = (10)  # Just an integer
7print("type((10,)):", type(single))
8print("type((10)) :", type(not_tuple))
9
10# 3. Tuple packing without parentheses
11coords = 10, 20, 30
12print("Packed coords:", coords, type(coords))
13
14# 4. Converting a list to a tuple with tuple()
15my_list = [1, 2, 3]
16my_tuple = tuple(my_list)

Tuple Immutability

Tuples cannot be altered after creation. Trying to assign a value to an index raises a TypeError.

TypeError: 'tuple' object does not support item assignment 
numbers = (10, 20, 30)
numbers[1] = 99  # ❌ TypeError!
How to Modify a Tuple (The Convert-Modify-Convert Pattern)

To alter a tuple, convert it to a mutable list, perform changes, and convert back with tuple():

Updating a Tuple via List Conversion 
1tup = (10, 20, 30)
2
3# 1. Convert to list
4temp = list(tup)
5# 2. Modify list element
6temp[1] = 99
7# 3. Convert back to tuple
8tup = tuple(temp)
9
10print("Modified tuple:", tup)
Terminal Output
Modified tuple: (10, 99, 30)
Critical Rule: Mutable Objects Inside an Immutable Tuple

A tuple protects its own references from reassignment, but if it contains an inner mutable object (like a list), that inner list can be altered! 

t = ([1, 2], 3)
t[0].append(99)  # ✅ Allowed! Inner list is modified
print(t)         # Output: ([1, 2, 99], 3)

Tuple Packing & Unpacking

Packing places multiple values into a single tuple. Unpacking distributes those values back into distinct variables in a single elegant step.

Unpacking and Extended Unpacking (*) 
1# Basic Unpacking (Variables count must match tuple length)
2student = ("Riya", 19, "AI")
3name, age, branch = student
4print(f"{name} is {age} years old studying {branch}.")
5
6# Variable Swapping (Python's iconic idiom)
7x, y = 10, 20
8x, y = y, x
9print(f"Swapped: x={x}, y={y}")
10
11# Extended Unpacking with * (absorbs remaining items into a list)
12numbers = (1, 2, 3, 4, 5)
13first, *middle, last = numbers
14print(f"First: {first} | Middle: {middle} | Last: {last}")
Terminal Output
Riya is 19 years old studying AI. Swapped: x=20, y=10 First: 1 | Middle: [2, 3, 4] | Last: 5

Introduction to Sets

A Set mirrors mathematical sets: an unordered, mutable collection of unique elements enclosed in curly braces { }. Duplicate items are instantly and automatically eliminated!

Core Characteristics of Python Sets
  • Unique Only: Duplicate values are rejected silently.
  • Unordered: Elements do not possess a permanent index. You cannot access set[0].
  • Fast Lookup: Membership testing (x in my_set) runs in lightning-fast O(1) constant time using hash tables!
Automatic Deduplication in Sets 
1# Creating a set with duplicate values
2numbers = {10, 20, 10, 30, 20}
3
4# Duplicates are automatically removed
5print("Deduplicated set:", numbers)
6print("Total unique items:", len(numbers))
Terminal Output
Deduplicated set: {10, 20, 30} Total unique items: 3
08

Creating Sets & Hashability Rules

To create an empty set, you must call set(). Using empty braces {} creates an empty dictionary!

Trap: {} is a Dict, NOT a Set!

d = {} ➔ type(d) is <class 'dict'>.
s = set() ➔ type(s) is <class 'set'>.

The Hashability Rule: What Can Be Inside a Set?

Set elements must be immutable and hashable: integers, floats, strings, and tuples are allowed. Mutable objects like lists, dicts, or other sets are forbidden and will crash with TypeError: unhashable type: 'list'.

Creating Sets from Iterables 
1# Empty set vs empty dict
2s_empty = set()
3print("type(set()):", type(s_empty))
4
5# Converting a list to quickly remove duplicates
6raw_list = [1, 2, 2, 3, 4, 4, 4]
7unique_vals = set(raw_list)
8print("set(raw_list):", unique_vals)
9
10# Sets cannot be indexed (s[0] raises TypeError)
11# Membership check with 'in' is lightning fast:
12print("Is 3 in unique_vals?:", 3 in unique_vals)
Terminal Output
type(set()): <class 'set'> set(raw_list): {1, 2, 3, 4} Is 3 in unique_vals?: True

Creating Dictionaries & Key Rules

Dictionaries can be initialized as literals, via dict(), or by combining parallel sequences with zip().

2 Non-Negotiable Rules for Dictionary Keys
  • Keys Must Be Unique: Duplicate keys are not allowed. If defined twice in a literal, the later value overwrites the earlier one.
  • Keys Must Be Hashable: Strings, numbers, and tuples can be keys. Mutable objects like lists or dictionaries cannot.
Creating Dictionaries via dict() and zip()

4employee = dict(zip(keys, vals))
5print("From zip():", employee)
6
7# 2. Duplicate key overwrite behavior (Last Write Wins)
8dup_dict = {"a": 1, "b": 2, "a": 99}
9print("Overwritten dict:", dup_dict)

Choosing the Right Data Structure

📋
Choose List When:

You need an ordered sequence of items that will change (add/remove), and duplicates are permissible (e.g. Shopping cart).

🔒
Choose Tuple When:

You need a fixed record of items that must never be altered (e.g. RGB color code, GPS coordinate (lat, lon)).

🎯
Choose Set When:

You need unique values with zero duplicates, rapid membership lookups, or Venn set math (e.g. Unique visitor IP addresses).

📖
Choose Dict When:

You need to associate structured keys to values for fast lookups (e.g. User account profiles, configuration settings).

Common Beginner Mistakes & Best Practices

Mistake 1: Forgetting Comma in Single-Element Tuple

❌ x = (5) ➔ Evaluates to integer 5.
✅ x = (5,) ➔ Creates a single-element tuple.

Mistake 2: Empty Set with {}

❌ s = {} ➔ Creates an empty dict.
✅ s = set() ➔ Creates an empty set.

Mistake 3: Unhandled KeyError on Missing Dictionary Key

❌ val = user["address"] ➔ Crashes with KeyError if missing.
✅ val = user.get("address", "N/A") ➔ Safe fallback value.

Quick Revision Cheat Sheets

Tuples ()

Ordered, immutable. Single item requires comma: (10,). Methods: only count() and index().

2

Unordered, unique only. Empty set is set(). Fast O(1) lookups. Math ops: |, &, -, ^.

Answer: set()
Explanation: Using {} creates an empty dictionary, not an empty set.

Intermediate Q6: Tuple with Inner List Mutation

Does t = ([1, 2], 3); t[0].append(4) cause an error?

Reveal Answer & Explanation

Answer: No error! t becomes ([1, 2, 4], 3).
Explanation: The tuple preserves its reference to the list; the list itself is mutated in place.

Intermediate Q7: remove() vs discard() on Missing Items

What happens if you run s = {1, 2}; s.discard(3) vs s.remove(3)?

Reveal Answer & Explanation

Answer: s.discard(3) does nothing safely; s.remove(3) raises a KeyError.

Intermediate Q8: Set Symmetric Difference

What is {1, 2, 3} ^ {2, 3, 4}?

Reveal Answer & Explanation

Output: {1, 4}
Explanation: Symmetric difference retains elements present in either set, but excludes elements in both.

Intermediate Q9: Duplicate Keys in Dict Literal

What is the final value of d["x"] if d = {"x": 10, "y": 20, "x": 30}?

Reveal Answer & Explanation

Output: 30
Explanation: Later assignments overwrite earlier values for identical keys.

Intermediate Q10: Unhashable Set Item

Why does s = {[1, 2], 3} fail?

Reveal Answer & Explanation

Answer: Raises TypeError: unhashable type: 'list' because list objects are mutable and have no fixed hash.

Intermediate Q11: Dict Comprehension Output

What does {x: x % 2 == 0 for x in range(1, 4)} evaluate to?

Reveal Answer & Explanation

Output: {1: False, 2: True, 3: False}

Challenge Q12: Extended Unpacking with Rest

What are the values of a and b in a, *b = (10, 20, 30)?

Reveal Answer & Explanation

Output: a = 10, b = [20, 30] (Notice that b is a list!).

Challenge Q13: Inverting a Dictionary

Write a comprehension to invert d = {"a": 1, "b": 2} into {1: "a", 2: "b"}.

Reveal Answer & Explanation

Answer: {v: k for k, v in d.items()}

Challenge Q14: Mutable Tuple Hashability

Can the tuple t = (1, [2, 3]) be used as a dictionary key or set item?

Reveal Answer & Explanation

Answer: No! Even though the outer container is a tuple, it contains an unhashable list, making the entire tuple unhashable.

Challenge Q15: Nested Dict Safe Extraction

Given users = {"u1": {}}, how do you safely extract users["u1"]["email"] without crashing if "email" is missing?

Reveal Answer & Explanation

Answer: users.get("u1", {}).get("email", "No Email")
