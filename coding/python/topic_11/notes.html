Introduction to Comprehensions

📌 What is a Comprehension?

A comprehension is an elegant, concise Python syntax for constructing a new collection (list, set, or dictionary) by transforming and filtering elements from an existing iterable in a single line.

In traditional programming, creating a modified list requires initializing an empty list, writing a multi-line for loop, and calling .append() on each iteration:

👀 Traditional for Loop (3 lines)
squares = []

for number in range(1, 6):
    squares.append(number * number)

print(squares)
⚡ List Comprehension (1 line)
squares = [number * number for number in range(1, 6)]
print(squares)
► TERMINAL OUTPUT (BOTH PRODUCE THE EXACT SAME RESULT)
[1, 4, 9, 16, 25]
The Comprehension Processing Pipeline
1. Input Iterable
range(1, 6)
→
2. Loop Variable
for number in ...
→
3. Transform Expression
number * number
→
4. Output List
[1, 4, 9, 16, 25]
💡 Balance Readability & Brevity

Comprehensions are optimized internally in CPython and run slightly faster than repeated append() calls. However, readability counts. If a comprehension becomes long, deeply nested, or complicated with multiple clauses, an explicit loop is preferred.

02

Anatomy of the Basic Syntax

Every basic comprehension consists of three essential components enclosed inside collection brackets:

📝 List Comprehension Blueprint
[ expression for item in iterable ]
  • expression: The value or computation placed into the resulting collection (e.g. x * 2, word.upper()).
  • item: The temporary iteration variable representing each item pulled from the source.
  • iterable: Any sequence you can loop over (e.g. range(), list, string, tuple).
  • Brackets: Square brackets [...] denote a List comprehension.
Collection Type Enclosing Delimiters Syntax Template Result Type
List Comprehension [ ... ] [x * 2 for x in data] list
Set Comprehension { ... } {x * 2 for x in data} set (unique values)
Dictionary Comprehension { ... : ... } {x: x * 2 for x in data} dict (key:value pairs)

List Comprehensions in Action

List comprehensions produce a fresh list without altering the original input data. You can perform arithmetic, string transformations, or invoke methods:

PYTHON • TRANSFORMING SEQUENCES 
numbers = list(range(1, 6))
print("Original numbers:", numbers)

# 1. Square every number
squares = [x ** 2 for x in numbers]
print("Squares         :", squares)

# 2. Double every number
doubles = [x * 2 for x in numbers]
print("Doubles         :", doubles)

# 3. String transformations
fruits = ["apple", "banana", "cherry"]
uppercase_fruits = [f.upper() for f in fruits]
print("Uppercase fruits:", uppercase_fruits)
► TERMINAL OUTPUT
Original numbers: [1, 2, 3, 4, 5] Squares : [1, 4, 9, 16, 25] Doubles : [2, 4, 6, 8, 10] Uppercase fruits: ['APPLE', 'BANANA', 'CHERRY']

Filtering Elements with if

🔍 Filtering Syntax

To selectively include only elements that satisfy a condition, append an if clause at the end of the comprehension: 

[ expression for item in iterable if condition ]
Filtering Decision Flow
Input Element
→
Condition Check?
if x % 2 == 0
→
✅ True: Compute & Include
❌ False: Skip Element
PYTHON • FILTERING EXAMPLES 
numbers = range(1, 11)

# Filter even numbers
evens = [x for x in numbers if x % 2 == 0]
print("Even numbers    :", evens)

# Filter words with length >= 5
words = ["code", "python", "dev", "antigravity", "git"]
long_words = [w for w in words if len(w) >= 5]
print("Words >= 5 chars:", long_words)
► TERMINAL OUTPUT
Even numbers : [2, 4, 6, 8, 10] Words >= 5 chars: ['python', 'antigravity']
05

Conditional Expressions (if-else) Inside Comprehensions

Beginners often confuse filtering (discarding items) with transforming (choosing between two alternative values). Notice the syntax placement:

Pattern Syntax Position Behavior Result Length
Filtering (if only) At the end: [expr for x in data if condition] Excludes items failing the test. ≤ source list length
Choosing Value (if-else) At the start: [val1 if cond else val2 for x in data] Keeps every item, but selects transformation. = source list length
PYTHON • IF-ELSE TRANSFORMATION 
numbers = [1, 2, 3, 4, 5]

# Assign a label to EVERY element
labels = ["Even" if x % 2 == 0 else "Odd" for x in numbers]
print("Numbers:", numbers)
print("Labels :", labels)

# Classify grades
scores = [85, 42, 76, 33, 91]
status = ["Pass" if s >= 50 else "Fail" for s in scores]
print("Status :", status)
► TERMINAL OUTPUT
Numbers: [1, 2, 3, 4, 5] Labels : ['Odd', 'Even', 'Odd', 'Even', 'Odd'] Status : ['Pass', 'Fail', 'Pass', 'Fail', 'Pass']
06

Nested List Comprehensions

Comprehensions can contain multiple for clauses. The iteration order in a comprehension mirrors standard nested loops: the leftmost for represents the outer loop, and each subsequent for represents an inner loop.

PYTHON • FLATTENING A 2D MATRIX 
matrix = [
    [1, 2, 3],
    [4, 5, 6]
]

# Nested comprehension: for row in matrix -> for item in row
flattened = [item for row in matrix for item in row]
print("Flattened:", flattened)

# Coordinate pairs
coords = [(x, y) for x in [1, 2] for y in [10, 20]]
print("Pairs    :", coords)
► TERMINAL OUTPUT
Flattened: [1, 2, 3, 4, 5, 6] Pairs : [(1, 10), (1, 20), (2, 10), (2, 20)]
💡 Equivalent Traditional Loop for Matrix Flattening
flattened = []
for row in matrix:         # Outer loop
    for item in row:       # Inner loop
        flattened.append(item)

Set Comprehensions

📌 Set Comprehension Syntax

Enclosing the comprehension in curly braces {expression for item in iterable} creates a Set. Duplicates generated during transformation are automatically discarded, leaving only unique members.

PYTHON • SET COMPREHENSION & DEDUPLICATION 
numbers = [1, 2, 2, 3, 4, 4, 5]

# Duplicate inputs produce a clean set of unique squares
unique_squares = {x ** 2 for x in numbers}
print("Unique squares:", sorted(list(unique_squares)))

# Extract unique word lengths
sentence = "the quick brown fox jumps over the lazy dog"
lengths = {len(word) for word in sentence.split()}
print("Unique lengths:", sorted(list(lengths)))
► TERMINAL OUTPUT
Unique squares: [1, 4, 9, 16, 25] Unique lengths: [3, 4, 5]
08

Dictionary Comprehensions

📚 Dictionary Comprehension Syntax

Enclosing a key: value mapping inside curly braces constructs a fresh Dictionary: 

{ key_expr: value_expr for item in iterable }
PYTHON • DICTIONARY COMPREHENSION EXAMPLES 
# 1. Number to Square mapping
squares_map = {x: x ** 2 for x in range(1, 6)}
print("Squares map:", squares_map)

# 2. Filtered even squares
even_squares = {x: x ** 2 for x in range(1, 7) if x % 2 == 0}
print("Even squares:", even_squares)

# 3. Inverting a dictionary (swap keys and values)
original = {"a": 1, "b": 2, "c": 3}
inverted = {v: k for k, v in original.items()}
print("Inverted   :", inverted)
► TERMINAL OUTPUT
Squares map: {1: 1, 2: 4, 3: 9, 4: 16, 5: 25} Even squares: {2: 4, 4: 16, 6: 36} Inverted : {1: 'a', 2: 'b', 3: 'c'}
⚠️ Warning: Duplicate Keys Overwrite Earlier Values

If the key_expr produces duplicate keys, subsequent occurrences quietly overwrite earlier ones:

words = ["apple", "banana", "apricot"]
first_char_map = {w[0]: w for w in words}
print(first_char_map)  # {'a': 'apricot', 'b': 'banana'} -> 'apple' was overwritten!

Evaluation Factor List Comprehension Traditional for Loop
Brevity 1 compact, declarative line. 3 to 6 imperative lines.
Execution Speed Faster (optimized in C bytecode). Slightly slower (repeated .append() lookups).

Generator Expressions: Brief Introduction

⚙️ What is a Generator Expression?

Enclosing a comprehension in standard round parentheses (expression for item in iterable) creates a Generator Expression. Rather than constructing the entire list in RAM immediately, a generator calculates each value lazily on-demand as you ask for it.

PYTHON • LIST COMPREHENSION VS GENERATOR EXPRESSION 
numbers = [1, 2, 3, 4, 5]

# List comprehension: All 5 elements allocated immediately
squares_list = [x * x for x in numbers]
print("List in memory    :", squares_list)

# Generator expression: Evaluated lazily via next()
squares_gen = (x * x for x in numbers)
print("Generator object  :", squares_gen)
print("First item        :", next(squares_gen))
print("Second item       :", next(squares_gen))
► TERMINAL OUTPUT
List in memory : [1, 4, 9, 16, 25] Generator object : <generator object <genexpr> at 0x...> First item : 1 Second item : 4

Introduction to Lambda Functions

⚡ What is a Lambda Function?

A lambda function is a small, anonymous (unnamed) function created inline using the lambda keyword. Unlike functions defined with def, a lambda can only contain a single expression whose computed value is automatically returned.

PYTHON • DEF VS LAMBDA COMPARISON 
# Standard named function
def square_number(x):
    return x * x

# Equivalent anonymous lambda
square = lambda x: x * x

print("def version   :", square_number(5))
print("lambda version:", square(5))
► TERMINAL OUTPUT
def version : 25 lambda version: 25
13

Lambda Syntax and Arguments

Lambdas support any standard parameter configuration: zero arguments, multiple arguments, and default parameters:

PYTHON • PARAMETER VARIATIONS IN LAMBDAS 
# 1. Zero arguments
greet = lambda: "Hello, Python!"
print(greet())

# 2. Multiple arguments
add = lambda a, b: a + b
print("Add 10 + 20:", add(10, 20))

# 3. Default argument
power = lambda base, exponent=2: base ** exponent
print("3 squared   :", power(3))
print("2 cubed     :", power(2, 3))
► TERMINAL OUTPUT
Hello, Python! Add 10 + 20: 30 3 squared : 9 2 cubed : 8

Lambda with Conditional Expressions

Because lambdas cannot contain statement blocks (like if: ... else: ...), you use Python's ternary conditional expression (val1 if condition else val2):

PYTHON • CONDITIONAL LAMBDAS 
# Even or odd checker
check_number = lambda x: "Even" if x % 2 == 0 else "Odd"
print("4 is:", check_number(4))
print("7 is:", check_number(7))

# Sign classifier
classify = lambda n: "Positive" if n > 0 else ("Zero" if n == 0 else "Negative")
print("15 is:", classify(15))
print("-8 is:", classify(-8))
► TERMINAL OUTPUT
4 is: Even 7 is: Odd 15 is: Positive -8 is: Negative

Lambda with map()

🗺️ What is map()?

The built-in map(function, iterable) applies a function to every item of an iterable and returns a lazy map iterator. In Python 3, wrap the result with list() to display or inspect the contents.

PYTHON • USING MAP WITH LAMBDA 
numbers = [1, 2, 3, 4, 5]

# Map with lambda
squares_map = list(map(lambda x: x * x, numbers))
print("map() result        :", squares_map)

# Equivalent list comprehension (often considered more Pythonic)
squares_comp = [x * x for x in numbers]
print("comprehension result:", squares_comp)
► TERMINAL OUTPUT
map() result : [1, 4, 9, 16, 25] comprehension result: [1, 4, 9, 16, 25]

Lambda with filter()

🚪 What is filter()?

The built-in filter(function, iterable) constructs an iterator from elements of iterable for which function returns True.

PYTHON • USING FILTER WITH LAMBDA 
numbers = [1, 2, 3, 4, 5, 6]

# Filter even numbers
evens_filter = list(filter(lambda x: x % 2 == 0, numbers))
print("filter() result     :", evens_filter)

# Equivalent list comprehension
evens_comp = [x for x in numbers if x % 2 == 0]
print("comprehension result:", evens_comp)
► TERMINAL OUTPUT
filter() result : [2, 4, 6] comprehension result: [2, 4, 6]

Lambda with reduce()

🔄 What is reduce()?

Available from the functools module, reduce(function, iterable[, initializer]) applies a two-argument function cumulatively to the sequence items, reducing the entire collection down to a single scalar value.

PYTHON • ACCUMULATING WITH REDUCE 
from functools import reduce

numbers = [1, 2, 3, 4, 5]

# Sum all elements: ((((1 + 2) + 3) + 4) + 5)
total = reduce(lambda acc, val: acc + val, numbers, 0)
print("Total sum:", total)

# Calculate product: 1 * 2 * 3 * 4 * 5 = 120
product = reduce(lambda acc, val: acc * val, numbers, 1)
print("Product  :", product)
► TERMINAL OUTPUT
Total sum: 15 Product : 120
💡 Good Practice Note

For ordinary addition, always prefer Python's built-in sum(numbers) over reduce(). Use reduce() when custom cumulative operations (such as products, matrix dot products, or cascading dictionaries) are needed.

Sorting with Lambda Keys

The most widespread production use of lambda in Python is providing a lightweight key= extraction function to sorted() or list.sort():

PYTHON • SORTING TUPLES & DICTIONARIES 
students = [
    ("Aman", 85),
    ("Riya", 92),
    ("Neha", 78)
]

# 1. Sort ascending by score (index 1)
by_score = sorted(students, key=lambda s: s[1])
print("Ascending score :", by_score)

# 2. Sort descending by score
top_down = sorted(students, key=lambda s: s[1], reverse=True)
print("Descending score:", top_down)

# 3. Sort words by character length
words = ["elephant", "ant", "cat", "hippopotamus"]
by_length = sorted(words, key=lambda w: len(w))
print("Sorted by length:", by_length)
► TERMINAL OUTPUT
Ascending score : [('Neha', 78), ('Aman', 85), ('Riya', 92)] Descending score: [('Riya', 92), ('Aman', 85), ('Neha', 78)] Sorted by length: ['ant', 'cat', 'elephant', 'hippopotamus']

Common Mistakes & Best Practices

❌ SyntaxError: if Clause in Wrong Position

When filtering (excluding items), the if must go at the end. Putting if at the start without an else raises a SyntaxError:

Incorrect (SyntaxError): 
# BROKEN: if without else at start
[if x % 2 == 0 x for x in data]
Correct (Filter at End): 
# CORRECT: filter goes at end
[x for x in data if x % 2 == 0]
❌ Writing Statements Inside Lambdas

A lambda expression cannot contain statements like return, pass, raise, or assignments:

# BROKEN: SyntaxError
bad_lambda = lambda x: return x * 2

# CORRECT: Expressions return automatically
good_lambda = lambda x: x * 2
❌ Forgetting to Materialize map() or filter() Iterators

Printing a map() or filter() object without wrapping it in list() merely prints the generator memory reference:

res = map(lambda x: x * 2, [1, 2, 3])
print(res)        # <map object at 0x...>
print(list(res))  # [2, 4, 6] (Correct!)

Quick Revision & Cheat Sheets

📝 Master Syntax Cheat Sheet
Pattern Syntax Format Example
List Comprehension [expr for item in iter] [x*2 for x in nums]
Filtered List [expr for item in iter if cond] [x for x in nums if x > 0]
Ternary if-else [v1 if cond else v2 for item in iter] ["A" if x>5 else "B" for x in nums]
Set Comprehension {expr for item in iter} {len(w) for w in words}
Dict Comprehension {k_expr: v_expr for item in iter} {x: x**2 for x in nums}
Generator Expression (expr for item in iter) (x*2 for x in nums)
Lambda Function lambda p1, p2: expr lambda a, b: a + b
map() map(func, iter) list(map(lambda x: x*2, nums))
filter() filter(func, iter) list(filter(lambda x: x>0, nums))
reduce() reduce(func, iter, init) reduce(lambda a,b: a*b, nums, 1)
☝ Remember These Core Rules
  1. Filtering if goes at the end; conditional if-else goes at the start.
  2. Set comprehensions eliminate duplicates automatically, with no guaranteed display order.
  3. A lambda expression can only evaluate and return a single expression, not statement blocks.
  4. Always import reduce from the functools module.
  5. Never sacrifice code readability just to fit complex logic into a single comprehension line.

evens = [x for x in nums if x % 2 == 0]

Q12 (Challenge): Use reduce() to find the maximum value in [14, 72, 38, 95, 41] 
from functools import reduce

maximum = reduce(lambda a, b: a if a > b else b, data)

Q14 (Challenge): Sort a list of student dictionaries by grade descending, then by name ascending:
