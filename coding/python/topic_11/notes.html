Part A · Comprehensions
02

What is a Comprehension?

COMPREHENSION
A short, one-line way to build a new collection from an existing one, using a loop.
Example: [n * n for n in range(1, 6)]
💡 Real-life analogy

Imagine telling a helper: "Take every number from 1 to 5 and square it." You say it in one sentence. A comprehension is that one sentence, in Python.

Python has four kinds:

  • List comprehension [ ]
  • Set comprehension { }
  • Dictionary comprehension {k: v}
  • Round brackets ( ) make a generator, not a tuple (more on this later)
03

List Comprehension

Concept

A list comprehension creates a new list by running an expression for every item in a sequence.

Syntax 
[expression for item in sequence]
Example
Python
squares = [n * n for n in range(1, 6)]
print(squares)
Output 
[1, 4, 9, 16, 25]
Easy Explanation
  • The loop picks n from 1, 2, 3, 4, 5.
  • For each n, Python works out n * n.
  • All the answers are collected into a new list.
The 3 parts of a list comprehension
04

Loop vs Comprehension

Both ways below give the same result. Compare the length.

The loop way (4 lines)

Python
squares = []
for n in range(1, 6):
    squares.append(n * n)
print(squares)

The comprehension way (1 line)

Python
squares = [n * n for n in range(1, 6)]
print(squares)
Output (same for both)
[1, 4, 9, 16, 25]
📌 Easy way to convert
  1. Write the loop first.
  2. Move the thing you append to the front.
  3. Put it all inside [ ].
05

Filtering with if

Concept

Add an if at the end to keep only the items that pass a test.

Syntax 
[expression for item in sequence if condition]
Example
Python
evens = [n for n in range(1, 11) if n % 2 == 0]
print(evens)

names = ["Aman", "Riya", "Anil", "Neha"]
a_names = [n for n in names if n.startswith("A")]
print(a_names)
Output 
[2, 4, 6, 8, 10]
['Aman', 'Anil']
Easy Explanation
  • The first line keeps only the even numbers.
  • The second line keeps only names that start with "A".
  • Items that fail the test are simply left out.
06

Changing Values with if-else

What if you want to change each item instead of dropping some? Use if-else at the front.

Python
labels = ["even" if n % 2 == 0 else "odd" for n in range(1, 6)]
print(labels)
Output
['odd', 'even', 'odd', 'even', 'odd']
🧠 Remember the position
  • Filter (drop items) → if goes at the end.
  • Choose a value (keep all items) → if-else goes at the front.
07

Comprehensions with Strings

Comprehensions work on any sequence, including strings and the results of split().

Python
words = ["python", "is", "fun"]

print([w.upper() for w in words])
print([len(w) for w in words])
print([ch for ch in "code"])
print([int(x) for x in "1 2 3".split()])
Output
['PYTHON', 'IS', 'FUN']
[6, 2, 3]
['c', 'o', 'd', 'e']
[1, 2, 3]
  • Line 1 turns every word into capitals.
  • Line 2 finds the length of every word.
  • Line 3 splits a string into letters.
  • Line 4 turns text numbers into real numbers. This is very handy with input().
08

Two Loops in One Comprehension

You can add a second for. It works like a nested loop. The first for is the outer loop.

Python
pairs = [(x, y) for x in [1, 2] for y in ["a", "b"]]
print(pairs)

matrix = [[1, 2], [3, 4]]
flat = [n for row in matrix for n in row]
print(flat)
Output
[(1, 'a'), (1, 'b'), (2, 'a'), (2, 'b')]
[1, 2, 3, 4]
  • The first example pairs every number with every letter.
  • The second flattens a list of lists into one simple list.
📌 Tip

Read it left to right, like nested loops written in one line. If it gets hard to read, use normal loops instead.

09

Set Comprehension

Use curly brackets { } to build a set. Remember, sets keep only unique items.

Python
remainders = {n % 3 for n in range(10)}
print(remainders)

lengths = {len(w) for w in ["hi", "yo", "hey"]}
print(lengths)
Output
{0, 1, 2}
{2, 3}
  • Ten numbers gave only three different remainders: 0, 1 and 2.
  • The words had only two different lengths: 2 and 3.
10

Dictionary Comprehension

Concept

Use {key: value for ...} to build a dictionary in one line.

Syntax 
{key: value for item in sequence}
Example
Python
squares = {n: n * n for n in range(1, 5)}
print(squares)

words = ["python", "is", "fun"]
print({w: len(w) for w in words})
Output 
{1: 1, 2: 4, 3: 9, 4: 16}
{'python': 6, 'is': 2, 'fun': 3}
Easy Explanation
  • The first builds a number → square table.
  • The second maps each word to its length.

Swap keys and values

Python
d = {"a": 1, "b": 2}
print({v: k for k, v in d.items()})
Output
{1: 'a', 2: 'b'}

Filter a dictionary

Python
marks = {"Riya": 90, "Aman": 45, "Neha": 72}
passed = {k: v for k, v in marks.items() if v >= 50}
print(passed)
Output
{'Riya': 90, 'Neha': 72}

Only students with 50 or more marks were kept.

11

When Not to Use Comprehensions

Short code is only good if it is easy to read.

✅ Use a comprehension when…

  • The job is simple: transform or filter.
  • It fits comfortably on one line.
  • You are building a new list, set or dictionary.

❌ Use a normal loop when…

  • The logic needs many steps.
  • You need break or continue.
  • Other people (or you) will struggle to read it.
⚠️ Round brackets are different

(n * n for n in range(3)) does not make a tuple. It makes a generator, a lazy "one at a time" producer. To get a tuple, write tuple(n * n for n in range(3)), which gives (0, 1, 4).

Part B · Lambda Functions
12

What is a Lambda Function?

LAMBDA
A small one-line function that has no name. It is also called an anonymous function.
Example: lambda x: x * 2
💡 Real-life analogy

A normal function is like a saved contact with a name. A lambda is like a sticky note. You jot it down, use it once, and throw it away.

  • It can take any number of inputs.
  • It has only one expression.
  • The result is returned automatically.
13

Lambda Syntax

Syntax 
lambda parameters: expression
Anatomy of a lambda
Example
Python
def square_def(x):
    return x * x

square_lambda = lambda x: x * x

print(square_def(5))
print(square_lambda(5))
print((lambda x: x + 1)(5))
Output 
25
25
6
Easy Explanation
  • The def version and the lambda do exactly the same job.
  • We saved the lambda in a variable, then called it like a function.
  • The last line uses a lambda without any name. We wrapped it in brackets and called it straight away.
14

Lambda with Many Inputs and Conditions

Python
add = lambda a, b: a + b
greet = lambda: "Hello!"
sign = lambda n: "Positive" if n > 0 else "Not positive"

print(add(2, 3))
print(greet())
print(sign(3))
print(sign(-1))
Output
5
Hello!
Positive
Not positive
  • add takes two inputs.
  • greet takes none.
  • sign uses the one-line if-else from Chapter 6, so a lambda can still make a choice.
📌 Style tip

If you plan to reuse a function many times, a normal def with a proper name is clearer. Lambdas are best for quick, throw-away jobs.

15

Lambda with sorted(), max() and min()

Here is where lambdas really shine. These functions have a key setting that decides what to compare.

Example
Python
words = ["banana", "kiwi", "apple"]
print(sorted(words, key=lambda w: len(w)))

students = [("Riya", 90), ("Aman", 75), ("Neha", 82)]
print(sorted(students, key=lambda s: s[1]))
print(sorted(students, key=lambda s: s[1], reverse=True))
print(max(students, key=lambda s: s[1]))
print(min(words, key=lambda w: len(w)))
Output 
['kiwi', 'apple', 'banana']
[('Aman', 75), ('Neha', 82), ('Riya', 90)]
[('Riya', 90), ('Neha', 82), ('Aman', 75)]
('Riya', 90)
kiwi
Easy Explanation
  • key=lambda w: len(w) sorts words by length, not by alphabet.
  • key=lambda s: s[1] sorts students by their marks (the second item).
  • reverse=True flips the order, biggest first.
  • max and min use the same key to pick the winner.
16

Lambda with map()

Concept

map() applies a function to every item of a list and collects the results.

Syntax 
map(function, sequence)
Example
Python
nums = [1, 2, 3, 4]
doubled = list(map(lambda x: x * 2, nums))
print(doubled)
Output 
[2, 4, 6, 8]
Easy Explanation
  • The lambda doubles one number.
  • map() repeats it for every item.
  • list(...) turns the result into a normal list so you can see it.
17

Lambda with filter()

Concept

filter() keeps only the items for which the function says True.

Syntax 
filter(function, sequence)
Example
Python
nums = [1, 2, 3, 4]
evens = list(filter(lambda x: x % 2 == 0, nums))
print(evens)
Output 
[2, 4]
Easy Explanation
  • The lambda asks: "Is this number even?"
  • filter() keeps only the numbers where the answer is True.
map() changes items · filter() keeps items
18

map/filter vs Comprehensions

Both tools can do the same job. Compare:

Python
nums = [1, 2, 3, 4]

# map + lambda
print(list(map(lambda x: x * 2, nums)))
# comprehension
print([x * 2 for x in nums])

# filter + lambda
print(list(filter(lambda x: x % 2 == 0, nums)))
# comprehension
print([x for x in nums if x % 2 == 0])
Output
[2, 4, 6, 8]
[2, 4, 6, 8]
[2, 4]
[2, 4]
  • The results are identical.
  • Most Python programmers find the comprehension easier to read.
  • Lambdas are still the best choice for the key= setting in sorted(), max() and min().
19

Limits of Lambda

  • Only one expression. No multiple lines.
  • No return keyword. The result is returned for you.
  • No statements like for, while or assignment (=) inside.
  • Hard to read when long. Switch to def in that case.
🧠 Remember this

Lambda = a short, simple, one-job function. If you need more than that, write a normal function.

20

Common Beginner Mistakes

❌ Wrong: Putting if-else at the end of a comprehension
[n for n in range(5) if n % 2 == 0 else 0]
Error
SyntaxError: invalid syntax
✅ Correct: [n if n % 2 == 0 else 0 for n in range(5)]
Output
[0, 0, 2, 0, 4]

With else, the whole choice moves to the front.

❌ Wrong: Printing map() or filter() directly
print(map(lambda x: x * 2, [1, 2]))
Output (the address will differ)
<map object at 0x7f...>
✅ Correct: wrap it with list(...)

map() and filter() give a lazy object, not a ready list.

❌ Wrong: Using return inside a lambda
f = lambda x: return x * 2
Error
SyntaxError: invalid syntax
✅ Correct: f = lambda x: x * 2
❌ Wrong: Expecting round brackets to make a tuple
t = (n for n in range(3))
✅ Correct: t = tuple(n for n in range(3))

Round brackets make a generator, not a tuple.

❌ Wrong: Cramming too much into one line
[(x, y) for x in a if x > 0 for y in b if y != x]
✅ Correct: use a normal loop when it gets this long

It runs, but it is hard to read. Clear code beats short code.

Quick Revision

Comprehension→A one-line way to build a collection
[x for x in seq]→List comprehension
... if condition→Filter: at the END, keeps some items
a if c else b→Choose a value: at the FRONT
{x for x in seq}→Set comprehension (unique items)
{k: v for ...}→Dictionary comprehension
( ... for ...)→A generator, not a tuple
lambda x: expr→One-line function with no name
key=lambda ...→Tells sorted/max/min what to compare
map(f, seq)→Apply f to every item
filter(f, seq)→Keep items where f is True
list(...)→Needed to see map/filter results
22

Key Points to Remember

  • A comprehension builds a new collection in one readable line.
  • Pattern: [expression for item in sequence if condition].
  • A filter if goes at the end. An if-else choice goes at the front.
  • Use { } for set and dictionary comprehensions.
  • A lambda is a small, nameless, one-expression function.
  • Lambdas return their result automatically, with no return.
  • Lambdas shine with key= in sorted(), max() and min().
  • map() changes every item. filter() keeps some items.
  • If a one-liner is hard to read, use a normal loop or def.
