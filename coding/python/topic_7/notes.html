What Is a Loop? (Repetition in Code)

Imagine having to print numbers from 1 to 100. Writing 100 separate print() lines by hand would be exhausting, error-prone, and painful to modify. Computers excel precisely at doing repetitive tasks at lightning speed without boredom or fatigue. That mechanism is called a loop.

Definition: Loop, Iteration & Loop Body

A loop is a control flow structure that repeatedly executes a block of statements as long as items remain in a sequence or a condition remains True.

  • Iteration: A single complete pass through the loop's instructions.
  • Loop Body: The indented block of code that runs on each iteration.
  • Termination Condition: The criteria that halts the loop to prevent it running forever.
⚖️ The Three Fundamental Pillars of Programming
1️⃣
Sequential (Topics 1–5)

Statements execute strictly in sequence from top to bottom, one after another.

2️⃣
Selection / Decision (Topic 6)

Statements branch dynamically based on conditions: if-elif-else.

3️⃣
Repetition / Loops (Topic 7)

Statements execute repeatedly in a cycle: for and while.

The for Loop (Iterating Sequences)

In Python, a for loop is designed to iterate through an ordered sequence or collection (such as a list, string, tuple, or range). It automatically retrieves each item one at a time from beginning to end.

Syntax of a for Loop
for variable in sequence:
    # 4 spaces indentation
    statement_1
    statement_2
Iterating a List of Fruits 
1fruits = ["Apple", "Banana", "Mango"]
2
3for fruit in fruits:
4    print(f"Fresh Fruit: {fruit}")
Terminal Output
Fresh Fruit: Apple Fresh Fruit: Banana Fresh Fruit: Mango

Iteration 2 "Banana" Prints: Fresh Fruit: Banana Yes ("Mango")
Iteration 3 "Mango" Prints: Fresh Fruit: Mango No (End of list reached)
03

Understanding range()

The built-in range() function produces an arithmetic progression of integers on demand without consuming memory for all values at once. It supports three flexible forms:

1. range(stop)

Starts at 0, increments by 1, stops before stop. range(5) ➔ 0, 1, 2, 3, 4.

2. range(start, stop)

Starts at start, increments by 1, stops before stop. range(2, 7) ➔ 2, 3, 4, 5, 6.

3. range(start, stop, step)

Increments by custom step. Can count backwards if step is negative! range(10, 0, -2) ➔ 10, 8, 6, 4, 2.

The Three Forms of range() 
1# Form 1: 0 up to 5 (5 is excluded!)
2print("range(5):")
3for i in range(5):
4    print(i, end=" ")
5
6# Form 2: 2 up to 7 (7 is excluded)
7print("\n\nrange(2, 7):")
8for i in range(2, 7):
9    print(i, end=" ")
10
11# Form 3: Counting backwards by -2
12print("\n\nrange(10, 0, -2):")
13for i in range(10, 0, -2):
14    print(i, end=" ")
15print()
Terminal Output
range(5): 0 1 2 3 4 range(2, 7): 2 3 4 5 6 range(10, 0, -2): 10 8 6 4 2
Error Watch: Step of Zero Raises ValueError

Passing a step of 0 like range(1, 10, 0) raises a fatal ValueError: range() arg 3 must not be zero. A step must always be a non-zero positive or negative integer.

The while Loop (Condition-Based Repetition)

Unlike a for loop which traverses an existing sequence of known length, a while loop continues repeating as long as a specific condition remains True. The moment the condition becomes False, the loop stops.

Syntax of a while Loop
initial_setup
while condition:
    loop_body_statements
    update_variable # CRITICAL: Without updating, loop never ends!
while Loop Counting 1 to 5 
1count = 1
2
3while count <= 5:
4    print(f"Count is: {count}")
5    count += 1  # Increment count by 1
6
7print("Loop finished!")
Terminal Output
Count is: 1 Count is: 2 Count is: 3 Count is: 4 Count is: 5 Loop finished!
🔍 Detailed while Loop Dry Run Trace
Iteration count at start Condition: count <= 5 Terminal Output count += 1 (After update)
1 1 1 <= 5 ➔ True Count is: 1 2
2 2 2 <= 5 ➔ True Count is: 2 3
3 3 3 <= 5 ➔ True Count is: 3 4
4 4 4 <= 5 ➔ True Count is: 4 5
5 5 5 <= 5 ➔ True Count is: 5 6
6 (Exit) 6 6 <= 5 ➔ False (None, loop terminates) 6

for Loop vs. while Loop Comparison

Both loops achieve repetition, but each shines in different circumstances. Here is how to choose between them:

Feature for Loop while Loop
Primary Use Case Iterating over sequences (lists, strings, ranges) Repeating until an event or condition changes
Iteration Count Known in advance (finite sequence length) Often unknown in advance (user input, game loop)
Variable Increment Handled automatically by Python Must be explicitly managed inside loop body
Risk of Infinite Loop Very low (finite collections) High if condition never becomes False
Typical Example for student in classroom: while battery_level > 10:
Same Task (Count 1 to 3) in Both Styles 
1# With for loop (Cleaner when range is known)
2for i in range(1, 4):
3    print("For loop:", i)
4
5# With while loop (Requires manual counter & increment)
6j = 1
7while j <= 3:
8    print("While loop:", j)
9    j += 1
Terminal Output
For loop: 1 For loop: 2 For loop: 3 While loop: 1 While loop: 2 While loop: 3

Loop Counters and Accumulators

Two of the most universal programming patterns are counting occurrences and accumulating running totals.

➕1

Increments by a fixed amount (usually +1) each time something happens: count += 1.

7print(f"Final Sum: {total}")

Nested Loops (Loops Inside Loops)

A loop placed inside another loop is called a nested loop. For every single turn of the outer loop, the inner loop runs completely through all its iterations from start to finish!

The Matrix Rule of Nested Loops

Think of a 2D spreadsheet: the outer loop controls the Rows, and the inner loop controls the Columns.

3x3 Star Matrix Using Nested Loops 
1for row in range(1, 4):          # Outer loop: runs 3 times (rows)
2    for col in range(1, 4):      # Inner loop: runs 3 times per row (columns)
3        print("*", end=" ")
4    print()                     # Print newline when a row completes
Terminal Output
* * * * * * * * *

The break Statement (Immediate Loop Exit)

The break statement provides an emergency exit. When Python encounters break, it immediately terminates the nearest enclosing loop and jumps to the code outside the loop block.

Stopping Search at Number 5 
1for number in range(1, 10):
2    if number == 5:
3        print("Found 5! Breaking out of loop...")
4        break
5    print(f"Checking number: {number}")
6
7print("Loop has ended.")
Terminal Output
Checking number: 1 Checking number: 2 Checking number: 3 Checking number: 4 Found 5! Breaking out of loop... Loop has ended.
Important: break Only Exits the Current Inner Loop

If you are inside a nested loop and hit break, it only escapes the inner loop. The outer loop continues running on its next turn.

The continue Statement (Skip Current Iteration)

Unlike break which shuts down the entire loop, continue simply skips the rest of the current iteration and immediately advances to the next turn of the loop.

Skipping Number 3 with continue 
1for number in range(1, 6):
2    if number == 3:
3        print("Skipping 3!")
4        continue
5    print(f"Processing: {number}")
Terminal Output
Processing: 1 Processing: 2 Skipping 3! Processing: 4 Processing: 5

The pass Statement (Empty Placeholder)

In Python, empty code blocks are syntactically illegal. If you write an if header or loop and leave the body blank, Python raises an IndentationError. The pass statement acts as a dummy placeholder that does nothing.

pass Statement Demonstration 
1for number in range(1, 4):
2    if number == 2:
3        pass  # Placeholder: do nothing (will write logic later)
4    print(f"Number: {number}")
Terminal Output
Number: 1 Number: 2 Number: 3
⚖️ Comparison: break vs. continue vs. pass
Statement What Happens to Current Iteration? What Happens to the Entire Loop?
break Aborted immediately Terminated completely (loop exits)
continue Skips remaining code in iteration Advances to next iteration turn
pass Executes normally (no effect) Continues running normally

The else Clause with Loops (Unique Python Feature)

Python has a rare feature: you can append an else block to a for or while loop! The else block executes only when the loop completes all its iterations normally without being interrupted by a break statement.

Normal Completion vs. break Interruption 
1# Case 1: Normal finish (else runs)
2for n in range(1, 4):
3    print("Item:", n)
4else:
5    print("Result 1: Loop completed without break!")
6
7# Case 2: break encountered (else is skipped!)
8for n in range(1, 4):
9    if n == 2:
10        print("Breaking at 2")
11        break
12else:
13    print("Result 2: This will NEVER print!")
Terminal Output
Item: 1 Item: 2 Item: 3 Result 1: Loop completed without break! Breaking at 2

Infinite Loops and Safe Termination

An infinite loop occurs when a loop's condition never becomes False. The computer repeats the body endlessly, causing the program to freeze or consume 100% CPU.

Danger Pattern: The Forgotten Increment 
i = 1
while i <= 5:
    print(i)
    # ❌ BUG: Forgot i += 1! 'i' stays 1 forever!
✅ Safe Intentional Loop Pattern: while True + break

When you want to repeat until a valid condition is met, write an intentional while True: loop with an explicit, guaranteed break:

Safe Controlled Loop Pattern 
1attempts = 0
2
3while True:
4    attempts += 1
5    print(f"Attempt #{attempts}: verifying security credentials...")
6    
7    # Guaranteed exit condition to prevent freeze
8    if attempts >= 3:
9        print("Connection established successfully!")
10        break
Terminal Output
Attempt #1: verifying security credentials... Attempt #2: verifying security credentials... Attempt #3: verifying security credentials... Connection established successfully!

Common Beginner Mistakes & Fixes

Mistake 1: Off-by-One Error in range()

Incorrect: for i in range(1, 10): to print numbers 1 to 10.

What Goes Wrong: Stop value 10 is excluded, so it only counts up to 9!

Fix: Use range(1, 11).

Mistake 2: continue Placed BEFORE while Counter Update

Incorrect:

while i <= 5:
    if i == 3:
        continue # ❌ INFINITE LOOP! Skips i += 1 below!
    print(i)
    i += 1

Fix: Always update the counter before calling continue inside a while loop!

Mistake 3: Re-initializing Accumulator Inside the Loop

Incorrect: Placing total = 0 inside the loop resets the sum back to zero on every turn! Always place accumulators above the loop.

💼 Viva & Technical Interview Questions
Q1 What is the difference between break and continue?
break completely terminates the loop and jumps outside. continue skips only the remaining statements of the current iteration and begins the next iteration.
Q2 Under what conditions does a loop's else block execute?
The else clause executes when the loop completes all its scheduled iterations normally. If the loop terminates prematurely via a break statement, the else block is skipped.
