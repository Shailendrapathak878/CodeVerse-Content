How to Build a Python Project

Beginners often open an editor and start typing. Professionals think first. Follow this workflow every time.

The project workflow

Turning a real problem into a project

Example problem: "I forget where my money goes each month."

  1. Problem: no record of spending.
  2. Requirements: add an expense, see a total, see spending by category, keep data after closing the app.
  3. Plan: store expenses as a list of dictionaries, save them in a file.
  4. Functions: add_expense(), view_expenses(), show_summary(), save_expenses(), load_expenses().
  5. Code → Test → Debug → Improve.
💡 The 5 Think-Before-You-Code questions
  1. What is the problem?
  2. What data do we need?
  3. Which functions or classes do we need?
  4. How will the data flow?
  5. What can go wrong?

You will see these questions before every project below.

03

Real-World Development Practices

Small habits that make your projects look professional.

1. Write modular code

  • One function = one job.
  • Use classes when data and actions belong together (Chapter 15).
  • Split big files into modules (Chapter 12).
  • Put the starting code under if __name__ == "__main__":.

2. Validate input and handle errors

  • Never trust what the user types.
  • Use try / except around risky steps: files, numbers, networks.
  • Print clear messages, not scary tracebacks.

3. Organize your files

Folder structure
my_project/
├── main.py              # starts the app
├── helpers.py           # reusable functions
├── data/
│   └── students.csv     # input data
├── requirements.txt     # libraries needed
├── README.md            # how to use the project
└── .gitignore           # files Git should skip

4. requirements.txt

Lists the libraries your project needs, so anyone can install them.

Terminal
python -m venv venv                 # make a clean environment
pip install pandas numpy requests   # install what you need
pip freeze > requirements.txt       # save the list
pip install -r requirements.txt     # someone else installs it

5. README.md

The front page of your project. Keep it short:

  • What the project does (1-2 lines)
  • How to install it
  • How to run it
  • A sample output or screenshot

6. Basic Git and GitHub

Git saves versions of your code. GitHub stores them online.

Terminal
git init
git add .
git commit -m "Add expense tracker"
git remote add origin https://github.com/you/expense-tracker.git
git push -u origin main
  • Commit small and often, with clear messages.
  • Add venv/, __pycache__/ and .env to .gitignore.

7. Keep secrets out of your code

API keys and passwords must never be typed into your code or pushed to GitHub. Read them from environment variables.

Python
import os

API_KEY = os.environ.get("WEATHER_API_KEY")
if API_KEY is None:
    raise SystemExit("Set the WEATHER_API_KEY environment variable first.")

8. Test and debug

  • Test small functions with assert:
Python
def test_total_spent():
    data = [{"amount": 100}, {"amount": 50}]
    assert total_spent(data) == 150
  • Read a traceback from the bottom up. The last line names the error.
  • Use print() to check values. Use breakpoint() to pause and look around.

Project 1: Student Management System

🟢 Level: Beginner

Console app with a menu, saved to a file.

1. Project Overview

A menu-driven program to add, view, search and delete student records. It also shows class statistics.

2. Problem Statement

A teacher keeps marks on paper. Finding one student or the class average takes too long. We need a quick digital record that is not lost when the program closes.

3. Features

  • Add a student (roll number, name, marks)
  • View all students
  • Search by roll number
  • Delete a student
  • Statistics: count, average, highest, lowest
  • Auto-save to a file

4. Concepts Used

  • Variables, dictionaries
  • Conditions and loops (menu)
  • Functions
  • File handling with JSON
  • Input validation with try / except

5. Project Structure

Folder structure

├── student_manager.py
└── students.json        # created automatically
💡 Think Before You Code
  • Problem: store and look up student marks.
  • Data: a dictionary. Roll number is the key, name and marks are the value.
  • Functions: load, save, add, view, search, delete, stats, main.

6. Implementation

Step 1: the data shape. A dictionary keyed by roll number gives instant lookup.

Python
students = {
    "101": {"name": "Riya Sharma", "marks": 88.0},
    "102": {"name": "Aman Verma", "marks": 75.5},
}

Step 2: save and load. JSON turns the dictionary into a text file and back.

Python
def load_students():
    """Read students from the file (or start empty)."""
    if os.path.exists(FILE_NAME):
        with open(FILE_NAME, "r") as f:
            return json.load(f)
    return {}


def save_students(students):
    """Write students to the file."""
    with open(FILE_NAME, "w") as f:
        json.dump(students, f, indent=2)
  • If the file does not exist yet, we return an empty dictionary.
  • with open(...) closes the file for us.

Step 3: add a student, safely.

Python
def add_student(students):
    roll = input("Roll number: ").strip()
    if roll in students:
        print("That roll number already exists.")
        return
    name = input("Name: ").strip().title()
    try:
        marks = float(input("Marks (0-100): "))
    except ValueError:
        print("Marks must be a number.")
        return
    if not 0 <= marks <= 100:
        print("Marks must be between 0 and 100.")
        return
    students[roll] = {"name": name, "marks": marks}
    save_students(students)
    print("Student added.")
  • Duplicate roll number? Stop early with return.
  • float(...) inside try catches text like "abc".
  • We save right after each change, so nothing is lost.

Step 4: statistics.

Python
def show_stats(students):
    if not students:
        print("No data for statistics.")
        return
    marks = [info["marks"] for info in students.values()]
    topper = max(students.values(), key=lambda s: s["marks"])
    print("Students:", len(marks))
    print("Average:", round(sum(marks) / len(marks), 2))
    print("Highest:", max(marks), "-", topper["name"])
    print("Lowest:", min(marks))
  • A list comprehension collects all marks.
  • max(..., key=lambda ...) finds the topper by marks.

Step 5: the menu loop ties every function together, using a while True loop and break to exit (see the complete code).

7. Complete Code

Show complete code (student_manager.py)
student_manager.py
import json
import os

FILE_NAME = "students.json"


def load_students():
    """Read students from the file (or start empty)."""
    if os.path.exists(FILE_NAME):
        with open(FILE_NAME, "r") as f:
            return json.load(f)
    return {}


def save_students(students):
    """Write students to the file."""
    with open(FILE_NAME, "w") as f:
        json.dump(students, f, indent=2)


def add_student(students):
    roll = input("Roll number: ").strip()
    if roll in students:
        print("That roll number already exists.")
        return
    name = input("Name: ").strip().title()
    try:
        marks = float(input("Marks (0-100): "))
    except ValueError:
        print("Marks must be a number.")
        return
    if not 0 <= marks <= 100:
        print("Marks must be between 0 and 100.")
        return
    students[roll] = {"name": name, "marks": marks}
    save_students(students)
    print("Student added.")


def view_students(students):
    if not students:
        print("No students yet.")
        return
    for roll, info in sorted(students.items()):
        print(f"{roll}: {info['name']} - {info['marks']}")


def search_student(students):
    roll = input("Roll number to search: ").strip()
    if roll in students:
        info = students[roll]
        print(f"Found: {info['name']} with {info['marks']} marks")
    else:
        print("Student not found.")


def delete_student(students):
    roll = input("Roll number to delete: ").strip()
    if roll in students:
        del students[roll]
        save_students(students)
        print("Student deleted.")
    else:
        print("Student not found.")


def show_stats(students):
    if not students:
        print("No data for statistics.")
        return
    marks = [info["marks"] for info in students.values()]
    topper = max(students.values(), key=lambda s: s["marks"])
    print("Students:", len(marks))
    print("Average:", round(sum(marks) / len(marks), 2))
    print("Highest:", max(marks), "-", topper["name"])
    print("Lowest:", min(marks))


def main():
    students = load_students()
    while True:
        print("\n1. Add  2. View  3. Search  4. Delete  5. Stats  6. Exit")
        choice = input("Choose: ").strip()
        if choice == "1":
            add_student(students)
        elif choice == "2":
            view_students(students)
        elif choice == "3":
            search_student(students)
        elif choice == "4":
            delete_student(students)
        elif choice == "5":
            show_stats(students)
        elif choice == "6":
            print("Goodbye!")
            break
        else:
            print("Invalid choice. Try again.")


if __name__ == "__main__":
    main()

  1. main() loads the file into a dictionary.
  2. The loop shows the menu and reads a choice.

10. Common Mistakes

❌ Wrong: Opening a file with "w" to read it
with open("students.json", "w") as f:
    data = json.load(f)
✅ Correct: use "r" to read

Mode "w" erases the file first. You lose all saved data.

❌ Wrong: Using marks straight from input()
marks = input("Marks: ")       # still text!
✅ Correct: marks = float(input("Marks: "))

Text cannot be averaged. Convert first.

❌ Wrong: Reading a key that may not exist
print(students["999"])      # KeyError
✅ Correct: check with if roll in students: first

  • Create a Student class (OOP).

  • Add several subjects per student.

6. Implementation

Step 1: load safely. Two different problems, two different messages.

Python
def load_expenses():
    try:
        with open(FILE_NAME, "r") as f:
            return json.load(f)
    except FileNotFoundError:
        return []
    except json.JSONDecodeError:
        print("Data file is damaged. Starting with an empty list.")
        return []
  • No file yet → return an empty list. That is normal on the first run.
  • Broken file → warn the user, but do not crash.

Step 2: ask until the input is valid.

Python
def read_amount():
    while True:
        try:
            amount = float(input("Amount: "))
            if amount <= 0:
                print("Amount must be greater than 0.")
                continue
            return amount
        except ValueError:
            print("Please enter a number.")


def read_date():
    text = input("Date (YYYY-MM-DD, Enter for today): ").strip()
    if text == "":
        return date.today().isoformat()
    try:
        return datetime.strptime(text, "%Y-%m-%d").date().isoformat()
    except ValueError:
        print("Invalid date. Using today's date.")
        return date.today().isoformat()
  • while True keeps asking until we return a good value.
  • strptime checks the date format. A bad date raises ValueError.
  • Pressing Enter uses today's date.

Step 3: the summary logic. Add up money per category with a dictionary.

Python
def total_spent(expenses):
    return sum(e["amount"] for e in expenses)


def category_totals(expenses):
    totals = {}
    for e in expenses:
        totals[e["category"]] = totals.get(e["category"], 0) + e["amount"]
    return totals
  • totals.get(category, 0) starts a new category at 0.
  • Same idea as counting words in Chapter 9.

7. Complete Code

Show complete code (expense_tracker.py)
expense_tracker.py
import json
from datetime import date, datetime

FILE_NAME = "expenses.json"


def load_expenses():
    try:
        with open(FILE_NAME, "r") as f:
            return json.load(f)
    except FileNotFoundError:
        return []
    except json.JSONDecodeError:
        print("Data file is damaged. Starting with an empty list.")
        return []


def save_expenses(expenses):
    with open(FILE_NAME, "w") as f:
        json.dump(expenses, f, indent=2)


def read_amount():
    while True:
        try:
            amount = float(input("Amount: "))
            if amount <= 0:
                print("Amount must be greater than 0.")
                continue
            return amount
        except ValueError:
            print("Please enter a number.")


def read_date():
    text = input("Date (YYYY-MM-DD, Enter for today): ").strip()
    if text == "":
        return date.today().isoformat()
    try:
        return datetime.strptime(text, "%Y-%m-%d").date().isoformat()
    except ValueError:
        print("Invalid date. Using today's date.")
        return date.today().isoformat()


def add_expense(expenses):
    amount = read_amount()
    category = input("Category (food/travel/...): ").strip().lower() or "other"
    when = read_date()
    expenses.append({"amount": amount, "category": category, "date": when})
    save_expenses(expenses)
    print("Expense saved.")


def view_expenses(expenses):
    if not expenses:
        print("No expenses yet.")
        return
    for i, e in enumerate(expenses, start=1):
        print(f"{i}. {e['date']}  {e['category']:<8} Rs. {e['amount']:.2f}")


def total_spent(expenses):
    return sum(e["amount"] for e in expenses)


def category_totals(expenses):
    totals = {}
    for e in expenses:
        totals[e["category"]] = totals.get(e["category"], 0) + e["amount"]
    return totals


def show_summary(expenses):
    if not expenses:
        print("No expenses yet.")
        return
    print(f"Total spent: Rs. {total_spent(expenses):.2f}")
    print("By category:")
    totals = category_totals(expenses)
    for cat, amount in sorted(totals.items(), key=lambda x: x[1], reverse=True):
        print(f"  {cat:<8} Rs. {amount:.2f}")


def main():
    expenses = load_expenses()
    while True:
        print("\n1. Add  2. View  3. Summary  4. Exit")
        choice = input("Choose: ").strip()
        if choice == "1":
            add_expense(expenses)
        elif choice == "2":
            view_expenses(expenses)
        elif choice == "3":
            show_summary(expenses)
        elif choice == "4":
            print("Goodbye!")
            break
        else:
            print("Invalid choice.")


if __name__ == "__main__":
    main()

10. Common Mistakes

❌ Wrong: Catching every error silently
try:
    amount = float(input("Amount: "))
except:
    pass
✅ Correct: catch ValueError and tell the user

A silent except hides bugs and leaves amount undefined.

❌ Wrong: Saving dates as random text
date = "5th May"
✅ Correct: use YYYY-MM-DD

This format sorts correctly and is easy to convert to a real date.

❌ Wrong: Forgetting to save after a change
expenses.append(item)   # no save_expenses() call
✅ Correct: call save_expenses(expenses) right after

7. Complete Code

Show complete code (analyzer.py)
analyzer.py
import pandas as pd
import numpy as np

SUBJECTS = ["maths", "science", "english"]

# 1. Load
df = pd.read_csv("students.csv")
print("Rows, columns:", df.shape)
print("Missing values:")
print(df.isna().sum())

# 2. Clean
df["name"] = df["name"].str.strip()
df = df.drop_duplicates()
df[SUBJECTS] = df[SUBJECTS].fillna(df[SUBJECTS].mean().round(1))
print("\nAfter cleaning:", df.shape)

def get_json(url, params):
    """Call an API and return its JSON, or raise a clear error."""
    response = requests.get(url, params=params, timeout=10)
    response.raise_for_status()          # turns 404/500 into an error

def find_city(name):
    data = get_json(GEO_URL, {"name": name, "count": 1})

class TaskError(Exception):
    """Raised when a task operation is invalid."""


class Task:
    PRIORITIES = {"high": 1, "medium": 2, "low": 3}

    def __init__(self, title, priority="medium", due=None, done=False):
        if priority not in Task.PRIORITIES:
            raise TaskError(f"Invalid priority: {priority}")
        self.title = title
        self.priority = priority
        self.due = due              # "YYYY-MM-DD" or None
        self.done = done

    def to_dict(self):
        return {"title": self.title, "priority": self.priority,
                "due": self.due, "done": self.done}

    def __str__(self):
        mark = "x" if self.done else " "
        return f"[{mark}] {self.title} ({self.priority}, due {self.due})"
  • TaskError is our own exception. It gives clear, specific errors.
  • PRIORITIES is a class variable. Every task shares it.
  • to_dict() prepares the task for saving to JSON.
  • __str__ controls how print(task) looks.

Step 3: DSA, picking the next task with a heap.

Python
class TaskManager:
    def next_task(self):
        """Pick the most urgent pending task using a priority queue."""
        heap = [(Task.PRIORITIES[t.priority], t.due or "9999-12-31", t.title)
                for t in self.tasks if not t.done]
        if not heap:
            return None
        heapq.heapify(heap)
        return heapq.heappop(heap)[2]
  • Each pending task becomes a tuple: (priority number, due date, title).
  • A tuple compares left to right. Smaller priority number wins. A tie goes to the earlier due date.
  • "9999-12-31" pushes tasks with no due date to the back of their priority group.

task_manager.py
import json
import heapq
import numpy as np
import pandas as pd


class TaskError(Exception):
    """Raised when a task operation is invalid."""


class Task:
    PRIORITIES = {"high": 1, "medium": 2, "low": 3}

    def __init__(self, title, priority="medium", due=None, done=False):
        if priority not in Task.PRIORITIES:
            raise TaskError(f"Invalid priority: {priority}")
        self.title = title
        self.priority = priority
        self.due = due              # "YYYY-MM-DD" or None
        self.done = done

    def to_dict(self):
        return {"title": self.title, "priority": self.priority,
                "due": self.due, "done": self.done}

    def __str__(self):
        mark = "x" if self.done else " "
        return f"[{mark}] {self.title} ({self.priority}, due {self.due})"


class TaskManager:
    def __init__(self, filename="tasks.json"):
        self.filename = filename
        self.tasks = []
        self.load()

    def add(self, title, priority="medium", due=None):
        task = Task(title, priority, due)
        self.tasks.append(task)
        self.save()
        return task

    def complete(self, title):
        for task in self.tasks:
            if task.title == title:
                task.done = True
                self.save()
                return
        raise TaskError(f"Task not found: {title}")

    def next_task(self):
        """Pick the most urgent pending task using a priority queue."""
        heap = [(Task.PRIORITIES[t.priority], t.due or "9999-12-31", t.title)
                for t in self.tasks if not t.done]
        if not heap:
            return None
        heapq.heapify(heap)
        return heapq.heappop(heap)[2]

    def completion_rate(self):
        if not self.tasks:
            return 0.0
        return round(float(np.mean([t.done for t in self.tasks])) * 100, 1)

    def report(self):
        df = pd.DataFrame([t.to_dict() for t in self.tasks])
        status = df["done"].map({True: "Done", False: "Pending"})
        return pd.crosstab(df["priority"], status)

    def save(self):
        with open(self.filename, "w") as f:
            json.dump([t.to_dict() for t in self.tasks], f, indent=2)

    def load(self):
        try:
            with open(self.filename, "r") as f:
                self.tasks = [Task(**item) for item in json.load(f)]
        except FileNotFoundError:
            self.tasks = []


if __name__ == "__main__":
    manager = TaskManager()

    manager.add("Finish Python notes", "high", "2026-06-01")
    manager.add("Buy groceries", "low", "2026-05-30")
    manager.add("Prepare project demo", "high", "2026-05-28")
    manager.add("Read one article", "medium")

    for task in manager.tasks:
        print(task)

    print("\nNext task:", manager.next_task())

    manager.complete("Prepare project demo")
    print("Next task:", manager.next_task())

    try:
        manager.complete("Dance class")
    except TaskError as error:
        print("Error:", error)

    try:
        manager.add("Sleep", "urgent")
    except TaskError as error:
        print("Error:", error)

    print("\nCompletion rate:", manager.completion_rate(), "%")
    print("\nReport:")
    print(manager.report())
