Variables, Constants & Data Types

Learn how data is stored in memory, how to choose appropriate C++ data types, and when to enforce fixed values with constants.

A Variables: Storage & Naming

A variable is a named storage location in memory that holds a value your program can read and change. Working with variables involves three stages: declaration reserves memory and assigns a type, initialization provides a starting value, and assignment updates the value later.

Variables act like labeled storage boxes. When declaring a variable, choosing a specific data type ensures the compiler allocates just the right amount of memory to hold that category of information.

Variable names must begin with a letter or underscore, cannot contain spaces, are strictly case-sensitive, and cannot match reserved C++ keywords. Choosing descriptive identifiers like studentAge makes code clear and self-documenting.

Student Score Example C++ 
int marks = 85; // Declaration & Initialization
marks = 92;     // Value Reassignment

When Rahul improves his score, assigning 92 to marks replaces 85. The original value is overwritten in memory, while the variable name and storage address remain unchanged.

B C++ Data Types

C++ is a statically typed language, meaning every variable requires a declared data type that informs the compiler how much memory to allocate and what operations are valid. Selecting the correct type optimizes memory and guards against arithmetic inaccuracies.

Key beginner types include int for whole numbers, double for high-precision decimals, char for single characters in single quotes, bool for true or false flags, and std::string for text.

C Constants

Constants represent values that must not change after initialization. Adding const turns a variable into a read-only entity, protecting critical limits from accidental modification. Using constants replaces mysterious literal numbers with named identifiers, dramatically improving code readability.

Constants Example C++ 
const int MAX_MARKS = 100; // Read-only constant
int marks = 85;            // Mutable variable

While variables can be reassigned anytime, reassigning an initialized constant triggers a compiler error. By convention, constant names are often written in uppercase like MAX_MARKS. C++ also provides constexpr to enforce compile-time constant evaluation.

D Type Conversion & Casting

Type conversion changes a value from one data type to another. C++ automatically performs implicit conversions when safe, while explicit casting gives you direct control and prevents unintended data loss. In mixed-type arithmetic, explicit casting clearly signals your intent and avoids mathematical truncation bugs.

Explicit Cast Example C++ 
int total = 5;
int students = 2;

double average = static_cast<double>(total) / students;

Without static_cast, dividing two integers performs integer division, discarding the fractional remainder and yielding 2. Casting total to double forces floating-point division, calculating the accurate result of 2.5.

E Practical Program

This runnable program combines variables of different data types and a fixed constant to model a complete student record.

Complete Student Record (main.cpp) C++ 
#include <iostream>
#include <string>

int main() {
    std::string name = "Rahul";
    int marks = 85;
    double attendance = 92.5;
    char grade = 'A';
    bool passed = true;
    const int MAX_MARKS = 100;

    std::cout << "Student: " << name << '\n';
    std::cout << "Marks: " << marks << '/' << MAX_MARKS << '\n';
    std::cout << "Attendance: " << attendance << "%\n";
    std::cout << "Grade: " << grade << '\n';
    std::cout << "Passed: " << std::boolalpha << passed << '\n';

    return 0;
}
✔ Program Output
Student: Rahul
Marks: 85/100
Attendance: 92.5%
Grade: A
Passed: true

Notice std::boolalpha, which instructs the output stream to print boolean values as true or false instead of numeric 1 or 0.
