Loops & Iterations

Master C++ loops to repeat tasks efficiently, control iteration flow, and choose the right loop construct for any programming challenge.

A What Are Loops?

In programming, loops automate repetitive actions, saving you from writing duplicate code. Instead of copying an output statement twenty times to log student attendance or scan inventory items, a loop runs a single block of instructions repeatedly until a stopping condition is reached.

B The for Loop

The for loop is ideal when you know in advance how many times an operation should repeat. It packages three critical control elements into a single header: initialization runs once before execution, condition is tested before each cycle, and update modifies the counter after every iteration.

Standard for Loop C++ 
for (int i = 1; i <= 5; i++) {
    std::cout << i << ' ';
}
✔ Program Output
1 2 3 4 5

When i reaches 6, the condition 6 <= 5 evaluates to false, immediately terminating the loop and continuing with the rest of your program.

C The while Loop

The while loop is an entry-controlled loop that tests its condition before executing the loop body. It is especially useful when the exact number of iterations is unpredictable, such as waiting for user input, reading sensor signals, or processing data streams until a sentinel value arrives.

Entry-Controlled while Loop C++ 
int count = 1;

while (count <= 3) {
    std::cout << count << ' ';
    count++;
}
✔ Program Output
1 2 3

Always ensure the loop body updates the variable governing the condition, otherwise the loop will repeat endlessly as an infinite loop.

D The do-while Loop

The do-while loop is an exit-controlled loop that checks its condition after the body executes. Because the test occurs at the end, the code block is guaranteed to execute at least once, regardless of whether the initial condition is true or false.

Exit-Controlled do-while Loop C++ 
int choice = 1;

do {
    std::cout << "Menu shown\n";
    choice++;
} while (choice <= 1);
✔ Program Output
Menu shown

Notice the mandatory semicolon (;) after while(condition);, which is a unique syntax requirement of the do-while loop.

◆ Visual 3: while vs. do-while Comparison
Entry-Controlled: while
Evaluates condition before entering. If initially false, the loop body runs 0 times.
Exit-Controlled: do-while
Executes body first, then evaluates condition. Always guaranteed to run at least 1 time.

E Nested Loops

A nested loop is simply a loop located inside another loop. The outer loop controls the overall cycles—like table rows—while the inner loop completes all its iterations for every single cycle of the outer loop, such as filling columns or seats across each row.

Row & Column Star Pattern C++ 
for (int row = 1; row <= 2; row++) {
    for (int col = 1; col <= 3; col++) {
        std::cout << "* ";
    }
    std::cout << '\n';
}
✔ Program Output
* * *
* * *

F Loop Control: break & continue

C++ provides two powerful statements to alter standard iteration flow: break and continue.

The break statement immediately terminates the innermost loop, jumping past its closing brace. The continue statement skips any remaining instructions in the current iteration and jumps directly to the loop's update step.

break & continue in Action C++ 
for (int i = 1; i <= 5; i++) {
    if (i == 3) continue; // Skips number 3
    if (i == 5) break;    // Terminates before 5
    std::cout << i << ' ';
}
✔ Program Output
1 2 4
◆ Visual 5: break vs. continue Control Flow
❌ break (Abort & Exit)
Instantly aborts the loop. Execution jumps outside the closing brace immediately.
⟲ continue (Skip & Next)
Bypasses remaining statements in the current iteration and jumps directly to next update.

G Loop Comparison & Pitfalls

Watch out for forgetting to update the loop counter, writing inverted conditions that create infinite loops, using a single equal sign (=) instead of double equals (==), and omitting the trailing semicolon in do-while.

Loop Type Best Use Key Behavior
for Known repetition count Combines init, condition, and update in one header
while Repetition depends on a condition Evaluates condition before executing body
do-while Body must run at least once Evaluates condition after executing body
⚠ Common Loop Bugs
  • Missing update (e.g., omitting i++ in a while loop) triggers an infinite loop.
  • Forgetting the semicolon in do { ... } while(cond); causes a compiler syntax error.

H Practical Mini Program: Sum Calculation

Sum of Numbers 1 to 5 (main.cpp) C++ 
#include <iostream>

int main() {
    int total = 0;

    for (int i = 1; i <= 5; i++) {
        total += i;
    }

    std::cout << "Total: " << total << '\n';
    return 0;
}
✔ Program Output
Total: 15

During each iteration, total accumulates the current value of i: 0 becomes 1, then 3, 6, 10, and finally 15 when i reaches 5.
