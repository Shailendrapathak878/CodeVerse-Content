Templates in C++

Master C++ templates to write type-independent, reusable code. Explore function templates, class templates, multi-type parameters, and compile-time specialization.

A What Are Templates?

Templates enable generic programming by allowing you to write a single blueprint that works with multiple data types without duplicating code. Instead of copying functions for every type, you define the logic once.

Think of a universal calculator: whether calculating with whole integers, decimal measurements, or scientific numbers, the addition or comparison logic remains identical. The machine applies the same rules regardless of input format.

Templates operate at compile time. When your program calls a template with a specific type, the compiler generates a dedicated specialization tailored to that exact type, delivering maximum runtime performance with full type safety.

B Function Templates

A function template defines a family of functions. The prefix template <typename T> declares T as a generic type placeholder substituted by the compiler during compilation.

In this example, getLarger() accepts integers, floating-point decimals, and strings. The compiler deduces T automatically from the passed arguments. Both arguments must deduce a consistent type and support the > operator. If arguments have different types like int and double, you can resolve the ambiguity explicitly with getLarger<double>(10, 2.5).

Function Template Example (main.cpp) C++ 
#include <iostream>
#include <string>
using namespace std;

template <typename T>
T getLarger(T a, T b) {
    return (a > b) ? a : b;
}

int main() {
    cout << getLarger(10, 20) << '\n';
    cout << getLarger(3.5, 2.1) << '\n';
    cout << getLarger(string("Apple"), string("Mango")) << '\n';

    return 0;
}

C Class Templates

Class templates extend generic programming to object definitions, enabling a single class blueprint to store and manipulate different data types. This separation of class mechanics from stored data types forms the foundation of container libraries like std::vector.

Think of a standardized shipping box: the box structure, handles, and lid stay identical whether holding books, shoes, or electronics. You specify the intended contents upon creation.

Unlike functions, class templates require explicit type arguments (such as Box<int> or Box<string>), enabling the compiler to allocate appropriate storage for each specialization.

Class Template Example (main.cpp) C++ 
#include <iostream>
#include <string>
using namespace std;

template <typename T>
class Box {
private:
    T item;

public:
    Box(T value) : item(value) {}

    void show() const {
        cout << item << '\n';
    }
};

int main() {
    Box<int> numberBox(100);
    Box<string> textBox("CodeVerse");

    numberBox.show();
    textBox.show();

    return 0;
}

D Multiple Template Parameters

Templates can accept multiple type parameters, allowing functions and classes to combine distinct data types seamlessly.

Here, displayPair() binds T and U to different types independently, printing combinations like an integer student ID with a string name.

Multiple Parameters Example (main.cpp) C++ 
#include <iostream>
#include <string>
using namespace std;

template <typename T, typename U>
void displayPair(T first, U second) {
    cout << first << " - " << second << '\n';
}

int main() {
    displayPair(101, string("Student"));
    displayPair(string("Marks"), 95.5);

    return 0;
}
✓ Program Output
101 - Student
Marks - 95.5

E Template Advantages and Limitations

Key benefits and practical considerations when using generic templates:

  • Code Reuse: Eliminates repetitive boilerplate functions while preserving native type checking.
  • Zero Runtime Overhead: Specializations compile into optimized native machine code with no virtual dispatch penalty.
  • Supported Operations: Passed types must support all operators used within the template (such as > or <<).
  • Compiler Errors: Type mismatches inside templates can generate lengthy compiler diagnostic messages.
  • Template Visibility: Definitions must be visible at compile time where instantiated, usually placed in header files or before main().
