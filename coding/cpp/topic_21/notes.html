Standard Template Library (STL) in C++

Master the C++ Standard Template Library to write powerful, production-ready code using pre-built containers, smart iterators, fast algorithms, and custom function objects.

A What Is STL?

The Standard Template Library (STL) is a foundational collection of generic C++ templates providing battle-tested data structures and algorithms. Instead of manually engineering dynamic arrays, linked lists, or sorting routines from scratch, STL delivers optimized, reusable components ready for production.

Think of a modern public library: sturdy bookshelves store and organize books, librarians navigate through catalog numbers, standard checkout rules govern organization, and specialized filters locate specific genres. STL organizes software in the exact same structured way.

The STL architecture rests on four coordinated building blocks:

  • Containers: Data structures that store, manage, and organize collections of elements in memory.
  • Iterators: Pointer-like objects that navigate through container elements, serving as the bridge between containers and algorithms.
  • Algorithms: Standardized functions that perform common processing tasks like searching, sorting, counting, and transforming.
  • Function Objects (Functors): Objects that behave like functions, enabling custom logic and flexible comparator rules.

B Containers — The Main Types

STL containers offer specialized trade-offs between memory layout and access speed to suit various algorithmic needs:

  • vector: Dynamic contiguous array that resizes automatically, like an expandable shopping list.
  • array: Fixed-size sequential container with compile-time capacity, delivering zero allocation overhead.
  • list: Doubly-linked sequence optimized for constant-time element insertion and deletion anywhere.
  • set: Associative container storing unique keys in sorted order using balanced binary search trees.
  • map: Collection of key-value pairs sorted by unique keys, like a phone directory.
  • stack: Container adapter providing Last-In, First-Out (LIFO) access, like a stack of plates.
  • queue: Container adapter providing First-In, First-Out (FIFO) access, like a grocery checkout line.
  • unordered_map: Hash-table collection of key-value pairs providing average constant-time lookup without sorting keys.

C Vector — A Practical Example

std::vector is the standard workhorse container in C++. Because it maintains elements in contiguous memory, it provides fast indexed access and dynamically allocates additional capacity as elements are inserted.

Here, push_back() appends elements to the end, range-based for iterates cleanly through the elements, and size() tracks the dynamic element count.

Vector Dynamic Operations (main.cpp) C++ 
#include <iostream>
#include <vector>
using namespace std;

int main() {
    vector<int> marks = {70, 85, 90};

    marks.push_back(95);

    for (int mark : marks) {
        cout << mark << ' ';
    }

    cout << "\nSize: " << marks.size() << '\n';

    return 0;
}

D Iterators

Iterators act as generalized pointers that let you traverse any STL container without needing to know its internal storage mechanics.

Crucially, begin() points to the first stored element, whereas end() represents a past-the-end sentinel position right after the final element. Dereferencing *it retrieves the actual value, while auto lets the compiler deduce the complex iterator type.

Iterator Traversal Snippet C++ 
vector<int> nums = {10, 20, 30};

for (auto it = nums.begin(); it != nums.end(); ++it) {
    cout << *it << ' ';
}
✓ Program Output
10 20 30

E Algorithms — Sorting and Searching

STL algorithms are decoupled from containers, operating flexibly across half-open iterator ranges [begin, end).

In this example, std::sort() organizes integers in ascending order, while std::find() performs a linear scan. If an item is absent, find()` safely returns the end() iterator.

Sorting and Searching Example (main.cpp) C++ 
#include <iostream>
#include <vector>
#include <algorithm>
using namespace std;

int main() {
    vector<int> nums = {40, 10, 30, 20};

    sort(nums.begin(), nums.end());

    for (int n : nums) {
        cout << n << ' ';
    }
    cout << '\n';

    auto it = find(nums.begin(), nums.end(), 30);

    if (it != nums.end()) {
        cout << "Found: " << *it << '\n';
    }

    return 0;
}

F Function Objects & Common Mistakes

A function object (functor) is an instance of a class that overloads operator(), allowing it to be invoked like a function. For example, passing greater<int>() from the <functional> header to sort() reverses the ordering to descending:

Descending Sort with Functor C++ 
sort(nums.begin(), nums.end(), greater<int>());
♦ Visual 8: Default Ascending vs. Functor Descending Sort
Default Ascending Sort
sort(nums.begin(), nums.end());
→ 10 20 30 40
Descending with greater<int>()
sort(..., greater<int>());
→ 40 30 20 10

Avoid these common STL beginner pitfalls:

  • Dereferencing end(): The end() iterator marks the past-the-end boundary; dereferencing it causes undefined behavior.
  • Duplicate Assumption: A set automatically ignores duplicate values; use multiset if duplicates must be preserved.
  • Map Ordering: std::map sorts items automatically by key, not by insertion order; use unordered_map for hash tables.
  • Missing Headers: Remember to include dedicated headers like <vector>, <algorithm>, and <functional>.
