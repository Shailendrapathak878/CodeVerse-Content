Arrays & Multidimensional Arrays

Learn how to store, traverse, and manipulate structured collections of data in contiguous memory using single-dimensional and multidimensional arrays.

A What Is an Array?

An array is a contiguous collection of variables of the exact same data type grouped under a single identifier. Instead of declaring separate variables for five students' marks or seven daily temperatures, you store all related readings inside one structured array.

The number inside square brackets during declaration defines the fixed capacity. When declaring int marks[5], C++ reserves an unbroken block in memory holding five integers back-to-back:

Array Declaration & Initialization C++ 
int marks[5] = {85, 90, 78, 92, 88};

In C++, indexing is strictly zero-based: the first element is at marks[0], and the last of five elements is at marks[4]. You can read or update an item by index, such as marks[2] = 80;.

Value (The Stored Data)

The actual data stored inside that slot. For marks[2], value is 78.

B Traversing an Array with Loops

Traversal means visiting every element sequentially. Because array indices form an unbroken sequence from 0 to size - 1, loops and arrays work together naturally. A standard for loop counter matches the array index:

Array Traversal (main.cpp) C++ 
#include <iostream>

int main() {
    int marks[5] = {85, 90, 78, 92, 88};

    for (int i = 0; i < 5; i++) {
        std::cout << marks[i] << ' ';
    }

    return 0;
}
✓ Program Output
85 90 78 92 88

The loop starts at i = 0 to access marks[0]. On each iteration, the counter increments until i becomes 5, where the condition i < 5 stops traversal before reading out of bounds.

C Common Array Operations & Linear Search

Real-world applications perform several fundamental operations on arrays:

  • Accessing & Updating: Read with marks[i] or overwrite with marks[i] = val in constant time.
  • Sum & Average: Accumulate elements into a total variable and divide by array size.
  • Finding Extremes: Track the maximum or minimum value while traversing.
  • Linear Search: Inspect items from index 0 onward until a target is found.
◆ Visual 4: Accumulating Sum Step by Step

Linear search is a foundational searching technique. It scans each element sequentially from index 0, checking whether the current value equals the target. When found, it captures the index and immediately halts execution with break to conserve CPU cycles.

Linear Search Example C++ 
int target = 92;
int foundIndex = -1;

for (int i = 0; i < 5; i++) {
    if (marks[i] == target) {
        foundIndex = i;
        break;
    }
}
✓ Search Result
Target 92 found at index 3
⚠ Bounds Safety Warning
Fixed-size C++ arrays do not perform bounds checking. Accessing marks[5] or negative indices reads outside allocated memory, leading to unpredictable crashes or undefined behavior.

D Multidimensional Arrays (2D & 3D)

A two-dimensional (2D) array arranges elements into rows and columns, like a spreadsheet or classroom seating grid. In our marks[2][3] example, the two rows represent two distinct students, while the three columns represent their individual test scores across three subjects:

2D Array Initialization & Printing C++ 
#include <iostream>

int main() {
    int marks[2][3] = {
        {80, 85, 90},
        {75, 88, 92}
    };

    for (int r = 0; r < 2; r++) {
        for (int c = 0; c < 3; c++) {
            std::cout << marks[r][c] << ' ';
        }
        std::cout << '\n';
    }
    return 0;
}

A 3D array extends this concept by adding a third dimension of layers: int cube[2][3][4]; stores 2 separate 2D tables, each containing 3 rows and 4 columns. In real-world software, a 3D array might track test scores across multiple school classrooms, grade levels, and individual subjects.

F Common Mistakes & Best Practices

Avoid these classic beginner array pitfalls:

  • Off-by-One Access: A 5-element array has indices 0 to 4. Accessing marks[5] is an out-of-bounds bug.
  • Confusing Index and Value: i is the position, whereas marks[i] is the data stored at that position.
  • Inverted 2D Coordinates: In C++, write array[row][column], not [col][row].
  • Fixed-Size Constraint: Traditional C++ arrays cannot grow or shrink during runtime. When dynamic resizing is required, use std::vector from the Standard Library.

Always double-check loop boundary conditions: writing i <= 5 instead of i < 5 is the most common cause of off-by-one memory corruption in beginner C++ programs.

G Practical Mini Program: Grade Analytics

The following complete, runnable program calculates the total, average, and highest score across five student marks:

Student Grade Analytics (main.cpp) C++ 
#include <iostream>

int main() {
    int marks[5] = {85, 90, 78, 92, 88};
    int total = 0;
    int highest = marks[0];

    for (int i = 0; i < 5; i++) {
        total += marks[i];

        if (marks[i] > highest) {
            highest = marks[i];
        }
    }

    double average = static_cast<double>(total) / 5;

    std::cout << "Total: " << total << '\n';
    std::cout << "Average: " << average << '\n';
    std::cout << "Highest: " << highest << '\n';

    return 0;
}
✓ Program Output
Total: 433
Average: 86.6
Highest: 92

The variable highest starts initialized to marks[0], providing an authentic baseline rather than guessing an arbitrary zero. During traversal, total accumulates each score, and highest updates whenever a larger number is encountered. We cast total to double using static_cast<double> to prevent integer division truncation, yielding the exact decimal average 86.6.
