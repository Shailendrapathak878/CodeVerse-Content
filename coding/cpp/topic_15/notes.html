Classes and Objects in C++

Master object-oriented programming fundamentals: class blueprints, object instances, member functions, access specifiers, constructors, and encapsulation.

A What Is a Class and an Object?

In Object-Oriented Programming (OOP), programs are structured around real-world entities rather than isolated functions and loose variables. A class is a user-defined blueprint specifying the data attributes and actions an entity possesses. An object is a concrete, individual instance created from that class.

Think of car manufacturing: an architectural blueprint specifies that a car has a brand, color, and engine, and can accelerate or brake. The blueprint itself is the class; each physical car manufactured from it is an independent object with its own distinct color and vehicle identification number.

Inside a class, variables that hold an object's state are called data members, while functions defining what the object can do are called member functions. Together, they form a cohesive, self-contained unit.

B Creating a Class and an Object

You declare a class using the class keyword followed by a class name, body enclosed in curly braces, and a mandatory terminating semicolon (;):

First Class and Object (main.cpp) C++ 
#include <iostream>
#include <string>

class Student {
public:
    std::string name;
    int marks;

    void display() {
        std::cout << name << " scored " << marks << '\n';
    }
};

int main() {
    Student s1;            // Instantiates object s1
    s1.name = "Aarav";     // Dot operator sets member
    s1.marks = 90;

    s1.display();          // Invokes member function

    return 0;
}
✓ Program Output
Aarav scored 90

The public: specifier allows members to be accessed from outside the class. The dot operator (.) accesses data members and executes member functions on object s1. When s1.display() is called, the function automatically operates on the data members stored within s1.

C Creating Multiple Objects

A single class can instantiate multiple independent objects. Each object maintains its own private memory slots for data members:

Multiple Student Objects (main.cpp) C++ 
int main() {
    Student s1;
    Student s2;

    s1.name = "Aarav";
    s1.marks = 90;

    s2.name = "Meera";
    s2.marks = 95;

    s1.display();
    s2.display();

    return 0;
}
✓ Program Output
Aarav scored 90
Meera scored 95

Modifying s1.marks changes only s1's internal memory; s2.marks remains completely unaffected.

D Access Specifiers (public, private, protected)

Access specifiers control member visibility from outside the class:

Specifier Accessibility Scope Common Usage
public Accessible from anywhere the object is visible Constructors, methods, interface
private Accessible only within member functions of this class Sensitive data attributes, helpers
protected Accessible within this class and derived (child) classes Inheritance hierarchies

In C++, members of a class are private by default. Attempting to access private members directly from main() produces a compile-time error. The protected specifier behaves like private, but allows derived child classes to inherit access during class inheritance.

⚠ Private Member Protection
If marks is private, writing s1.marks = 90; in main() fails with: "error: 'int Student::marks' is private within this context".

E Constructors (Object Initialization)

A constructor is a special member function invoked automatically upon object creation. It shares the class name and returns no value. A parameterized constructor initializes an object's data members directly with provided arguments, guaranteeing an object starts in a valid initial state:

Parameterized Constructor (main.cpp) C++ 
#include <iostream>
#include <string>

class Student {
public:
    std::string name;
    int marks;

    // Parameterized Constructor
    Student(std::string studentName, int studentMarks) {
        name = studentName;
        marks = studentMarks;
    }

    void display() {
        std::cout << name << ": " << marks << '\n';
    }
};

int main() {
    Student s1("Aarav", 90);
    Student s2("Meera", 95);

    s1.display();
    s2.display();

    return 0;
}
✓ Program Output
Aarav: 90
Meera: 95

Constructors ensure objects are never left uninitialized with random memory garbage. If no constructor is defined, C++ automatically creates a default constructor with empty parameters. When you define a custom constructor, you can initialize all members cleanly in one step.

F Encapsulation — Beginner Introduction

Encapsulation bundles data and the functions operating on that data into a unified class while restricting direct external tampering.

By declaring data members private and providing public methods, the class controls how data is read and updated. For example, a bank account keeps its balance private so callers cannot arbitrarily alter funds without passing through validation checks like verifying sufficient balance.

G Common Pitfalls & Best Practices

  • Missing Semicolon: Forgetting the semicolon after a class closing brace (};) causes compile errors.
  • Accessing Private Members: Direct access to private members outside the class is forbidden; use public methods.
  • Confusing Types and Instances: Student is the class blueprint; s1 is the actual object instance.
  • Calling Methods Without Objects: In standard OOP, call member functions through an object (e.g., s1.display()).
  • Shared Data Assumption: Each object has independent memory; modifying s1 never alters s2.

H Practical Project: Student Result Card

The following complete program demonstrates encapsulation, private members, a constructor, and a public display function:

Student Result Card (main.cpp) C++ 
#include <iostream>
#include <string>

class StudentResult {
private:
    std::string name;
    int score;

public:
    StudentResult(std::string studentName, int studentScore) {
        name = studentName;
        score = studentScore;
    }

    void displayResult() {
        std::cout << "Student: " << name
                  << " | Score: " << score
                  << " | Result: " << (score >= 50 ? "Pass" : "Fail") << '\n';
    }
};

int main() {
    StudentResult student1("Aarav", 92);
    student1.displayResult();

    return 0;
}
✓ Program Output
Student: Aarav | Score: 92 | Result: Pass

The StudentResult class encapsulates private attributes while offering a clean public interface via displayResult().
