Conditional Statements

Learn how C++ programs make decisions, branch execution paths using if, if-else, else-if ladders, nested checks, and switch statements.

A Why Conditional Statements?

By default, programs execute instructions in strict sequential order from top to bottom. Conditional statements introduce decision-making, allowing your application to choose different actions depending on whether a specific condition evaluates to true or false.

Think of an exam portal: if a student's score meets the passing threshold, the system displays a congratulations message; otherwise, it advises them to re-attempt the test.

B The if Statement

The if statement is the simplest decision structure. It executes an enclosed block of code only when its test condition evaluates to true. If the condition is false, the compiler skips the entire block. Because marks is 85, the check 85 >= 40 evaluates to true, so Pass is printed.

Single if Check C++ 
int marks = 85;

if (marks >= 40) {
    std::cout << "Pass";
}
✔ Program Output
Pass

C The if-else Statement

When your logic requires choosing between two mutually exclusive alternatives, use if-else. If the condition evaluates to true, the if block executes; otherwise, control diverts to the else block. This guarantees that exactly one of the two code paths will run.

Two-Way Selection C++ 
int marks = 35;

if (marks >= 40) {
    std::cout << "Pass";
} else {
    std::cout << "Fail";
}
✔ Program Output
Fail
◆ Visual 2: if vs. if-else Comparison
Single-Branch: if
Only executes when condition == true. If false, code execution bypasses the block completely with no alternative action.
Dual-Branch: if-else
Guarantees one outcome: executes True block if true, or False block if false. Never leaves the decision unhandled.

D The else-if Ladder

When evaluating multiple non-overlapping ranges, an else-if ladder tests conditions sequentially from top to bottom. As soon as one condition evaluates to true, C++ executes that specific block and exits the entire ladder. Carefully ordering checks from highest to lowest ensures accurate classification.

◆ Visual 3: Ordered Grade Cascade
marks >= 90 Grade A (90+)
marks >= 75 Grade B (75 – 89)
marks >= 40 Grade C (40 – 74)
else (default) Fail (< 40)

E Nested if Statements

A nested if places one conditional check inside another. The inner condition is evaluated only after the outer condition succeeds, which is ideal for hierarchical prerequisites like confirming a student passed before checking their scholarship eligibility.

Nested Eligibility Check C++ 
bool passed = true;
int marks = 92;

if (passed) {
    if (marks >= 90) {
        std::cout << "Scholarship Awarded!";
    }
}
◆ Visual 4: Nested Decision Tree
Gate 1: Has Student Passed? (passed == true)
Gate 2: Marks >= 90?
✔ True: Scholarship Awarded!
✖ False: Regular Pass (No Scholarship)

F The switch Statement

The switch statement selects one branch among multiple discrete, constant values. It matches an integer or character expression against case labels.

Always include break statements to exit the switch block upon matching a case; omitting break causes execution to fall through to subsequent cases. The default label acts as a fallback for unmatched choices. Use switch for discrete menu options and if-else for continuous numeric ranges.

Menu Selection Example C++ 
int choice = 2;

switch (choice) {
    case 1:
        std::cout << "Start Game\n";
        break;
    case 2:
        std::cout << "Load Game\n";
        break;
    case 3:
        std::cout << "Exit\n";
        break;
    default:
        std::cout << "Invalid Choice\n";
        break;
}
✔ Program Output
Load Game
◆ Visual 5: switch Menu Flow
case 1: "Start Game" Skipped
case 2: "Load Game" ✔ Matched • break exits switch
case 3: "Exit" Skipped
default: Fallback Skipped

G Common Mistakes to Avoid

Watch out for typing a single equal sign (=) instead of double equals (==) in comparisons, forgetting curly braces for multi-line blocks, omitting break in switch cases, and ordering ladder conditions incorrectly.

⚠ Critical Beginner Pitfalls
  • if (x = 5) assigns 5 instead of checking equality. Always write if (x == 5).
  • Forgetting break; in a switch causes fall-through into unwanted lower cases.
  • Ordering else if (marks >= 40) before marks >= 90 traps top scores in the lower grade.

H Practical Program: Student Grade Determination

Grade Determination (main.cpp) C++ 
#include <iostream>

int main() {
    int marks = 82;

    if (marks >= 90) {
        std::cout << "Grade A";
    } else if (marks >= 75) {
        std::cout << "Grade B";
    } else if (marks >= 40) {
        std::cout << "Grade C";
    } else {
        std::cout << "Fail";
    }

    return 0;
}
✔ Program Output
Grade B

Because marks is 82, the first check (marks >= 90) fails. The program then tests the next condition (marks >= 75), which evaluates to true. It prints Grade B and skips all remaining branches.
