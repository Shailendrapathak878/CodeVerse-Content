STL Algorithms & Lambda Expressions

Master C++ STL algorithms to process collections efficiently, and use modern inline lambda expressions with custom capture clauses to supercharge data manipulation.

A Understanding STL Algorithms

STL algorithms are pre-built, highly optimized generic functions that operate on element ranges via iterators. Rather than manually writing nested loops to search or reorder data, STL algorithms deliver standardized operations ready for immediate use. Because algorithms accept iterators rather than specific container types, one algorithm like sort() works uniformly across `vector`, `array`, and custom buffers.

Think of a teacher grading exams: the teacher sorts test scores in rank order, searches for an individual student's paper, counts how many students passed, or curves all grades by adding bonus points. The teacher applies standard administrative operations without reinventing how counting or sorting works.

Key algorithms from the <algorithm> header include:

  • sort(): Reorders elements into ascending order.
  • find(): Scans a range for a matching target value.
  • count_if(): Tallies how many elements satisfy a condition.
  • for_each(): Applies a function across every element.
  • transform(): Maps an operation across elements to generate new values.
  • remove_if(): Rearranges elements satisfying a condition toward the end.

Practical Example: Sort, Search, and Count

In this example, sort() organizes student marks, find() locates a target score, and count_if() uses an inline lambda condition to count scores at or above 75.

Sort, Find, and Count_if in Action (main.cpp) C++ 
#include <iostream>
#include <vector>
#include <algorithm>
using namespace std;

int main() {
    vector<int> marks = {75, 40, 90, 60, 90};

    sort(marks.begin(), marks.end());

    for (int mark : marks) {
        cout << mark << ' ';
    }
    cout << '\n';

    auto it = find(marks.begin(), marks.end(), 75);
    if (it != marks.end()) {
        cout << "Found: " << *it << '\n';
    }

    int highScores = count_if(
        marks.begin(), marks.end(),
        [](int mark) { return mark >= 75; }
    );

    cout << "High scores: " << highScores << '\n';

    return 0;
}

B Lambda Expressions

A lambda expression is an anonymous, inline callable function defined directly where it is invoked. Instead of declaring a separate named function elsewhere, a lambda supplies customized logic on the spot.

Think of a quick sticky note on a document: instead of drafting a formal memo, you write a brief instruction right where the action occurs.

♦ Visual 5: Anatomy of a C++ Lambda Expression
[capture] (parameters) { body; }
[capture]
Accesses outer local variables.
(parameters)
Input parameters supplied to lambda.
{ body }
Instructions to execute.
Basic Lambda Assignment C++ 
auto square = [](int n) {
    return n * n;
};

cout << square(5) << '\n';
✓ Program Output
25

The auto keyword lets the compiler deduce the lambda's internal closure type automatically.

Lambda with STL Algorithms

Lambdas shine when paired with STL algorithms as custom predicates. Here, isPassed acts as a dynamic rule passed into count_if() to evaluate whether each mark meets the passing threshold.

Lambda as Algorithm Predicate (main.cpp) C++ 
#include <iostream>
#include <vector>
#include <algorithm>
using namespace std;

int main() {
    vector<int> marks = {45, 80, 30, 90, 65};

    auto isPassed = [](int mark) {
        return mark >= 40;
    };

    int passed = count_if(
        marks.begin(), marks.end(), isPassed
    );

    cout << "Passed: " << passed << '\n';

    return 0;
}
✓ Program Output
Passed: 4

Capture Clauses

The capture clause [] controls how a lambda accesses local variables from its enclosing scope:

  • []: Captures nothing from the outer scope.
  • [x]: Captures x by value (read-only copy).
  • [&x]: Captures x by reference, allowing modifications to affect the original variable.
  • [=]: Captures all referenced outer local variables by value.
  • [&]: Captures all referenced outer local variables by reference.
♦ Visual 6: Lambda Capture Modes Comparison
[] No Capture Isolated function; uses arguments only.
[x] By Value Copy snapshot; immune to outer changes.
[&x] By Reference Direct link; reflects and edits original state.
Value Capture Example C++ 
int bonus = 5;

auto addBonus = [bonus](int marks) {
    return marks + bonus;
};

cout << addBonus(80) << '\n';
✓ Program Output
85

Capturing by value provides an isolated snapshot, while reference capture links directly to the original variable in memory. Variables captured by value are treated as constant copies inside the lambda unless you mark the lambda with the mutable specifier.

C Transform & Remove If

std::transform() maps an operation over an input range and writes results to a destination range. The output container must be pre-sized to accommodate the incoming values.

transform() Example C++ 
vector<int> nums = {1, 2, 3};
vector<int> doubled(nums.size());

transform(nums.begin(), nums.end(), doubled.begin(),
          [](int n) { return n * 2; });

std::remove_if() shifts matching elements to the tail and returns a new logical end iterator. Crucially, it does not shrink the container itself. To actually remove elements and reduce .size(), combine it with .erase() in the standard erase-remove idiom.

Erase-Remove Idiom Snippet C++ 
nums.erase(
    remove_if(nums.begin(), nums.end(),
              [](int n) { return n < 3; }),
    nums.end()
);
♦ Visual 8: The Erase-Remove Idiom Step-by-Step
1. Initial State: [1, 2, 3, 4, 5] (size: 5)
2. remove_if(< 3): [3, 4, 5 | ? ?] (returns iterator pointing after 5)
3. nums.erase(it, end): [3, 4, 5] (unwanted tail deleted, size: 3)
