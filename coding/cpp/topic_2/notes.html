C++ Setup & First Program

Configure your C++ development environment, write your first source file, understand compilation, and run your executable.

A What Do You Need?

To write, build, and execute C++ programs on your computer, you need three foundational components:

  • C++ Compiler: Translates your human-readable C++ code into machine instructions (such as GCC/G++, Clang, or MSVC).
  • Code Editor or IDE: An application to write and organize code (such as VS Code, Visual Studio, or CLion).
  • Terminal or Command Line: An interface to execute compiler commands and inspect program output.
Important Clarification: Visual Studio Code is a code editor, not a compiler. It requires a separately installed compiler toolchain to build and run C++ programs.
◆ Visual 1: C++ Development Workflow
1. Code Editor / IDE
Write and format your C++ statements inside a source file.
2. C++ Source File (.cpp)
Save plain text instructions (e.g., main.cpp) on disk.
3. C++ Compiler (g++ / clang)
Checks syntax rules, resolves headers, and emits machine code.
4. Executable Program
Creates a standalone binary (main on Linux/macOS, main.exe on Windows).
5. Console Output
Operating system runs the binary, and terminal prints results.
Setup Options

You can choose between zero-install online compilers and full local installations:

◆ Visual 2: Platform Setup Options
🌐 Option 1: Online Compiler
Start coding instantly in your web browser (e.g., Godbolt, OnlineGDB) without local installation. Great for quick practice.
💻 Option 2A: Windows Setup
Install MinGW-w64 (GCC toolchain) or Visual Studio Community with the "Desktop development with C++" workload.
🐧 Option 2B: Linux Setup
Install GCC via your terminal package manager: sudo apt install g++ (Ubuntu/Debian) or sudo dnf install gcc-c++ (Fedora).
🍎 Option 2C: macOS Setup
Open Terminal and run xcode-select --install to install Apple Command Line Developer Tools with the Clang compiler.

B Create and Run Your First Program

Follow these steps to create, compile, and execute your first C++ program:

Step 1: Write and Save Source Code

Create a file named main.cpp and enter the following code:

Source Code (main.cpp) C++ 
#include <iostream>

int main() {
    std::cout << "Hello, CodeVerse!" << '\n';
    return 0;
}
✔ Expected Program Output
Hello, CodeVerse!
Step 2: Compile the Source Code

Open your terminal in the directory containing main.cpp and run the compiler:

Terminal Compilation Command BASH / CLI 
g++ main.cpp -o main

The -o main flag instructs the compiler to name the output executable main (or main.exe on Windows).

Step 3: Run the Compiled Executable

Execute the generated binary directly from your terminal:

Terminal Execution Command BASH / CLI 
./main

On Windows Command Prompt or PowerShell, run main.exe or .\main.exe to view the output.

◆ Visual 3: Compiling vs. Running
⚙ Compilation Phase (g++ main.cpp -o main)
The compiler checks syntax, enforces type safety, and translates C++ code into machine language. Produces the binary executable.
▶ Execution Phase (./main)
The operating system loads the compiled executable into RAM, and the CPU processes instructions to produce output.

C Troubleshooting Common Errors

If your program does not compile or run as expected, check these common issues:

⚠ 'g++' is not recognized / command not found
The compiler is either not installed or its installation directory (e.g., bin) has not been added to your system's PATH environment variable.
⚠ fatal error: No such file or directory
Verify that your terminal's current working directory matches the folder where main.cpp is saved, and verify the filename spelling.
⚠ Compilation Syntax Errors
Check for missing semicolons (;), unmatched curly braces ({}), typos in header names, or unclosed quotation marks.
