A Arithmetic Operators

Arithmetic operators perform fundamental mathematical calculations. C++ provides standard addition (+), subtraction (-), multiplication (*), division (/), and modulus (%). In everyday calculations like shopping bills, multiplying quantity by unit price determines the gross cost.

Remember that dividing two integers truncates any fractional portion. The modulus operator calculates the integer remainder: 14 % 4 yields 2 because 4 fits into 14 three times with 2 remaining. Modulus strictly requires integer operands.

B Assignment Operators

Assignment operators store values into variables. The basic assignment operator (=) copies the right-hand value into the left-hand variable. Compound assignment operators combine arithmetic with assignment to write concise code.

For instance, x += 5 adds 5 to x, while x *= 2 doubles its current value. Compound assignment is not only cleaner to read but also avoids repetitive code when variable names are long, such as studentBalance -= tuitionFee;.

C Relational Operators

Relational operators compare two values and produce a boolean result—either true or false. They include equality (==), inequality (!=), less than (<), greater than (>), less than or equal (<=), and greater than or equal (>=).

In C++, relational expressions evaluate to 1 for true and 0 for false when printed normally, or textual true and false when using std::boolalpha. A common beginner bug is typing a single equal sign (=) instead of double equal signs (==) when testing equality.

D Logical Operators

Logical operators combine or invert boolean expressions. Logical AND (&&) requires both conditions to be true, logical OR (||) requires at least one condition to be true, and logical NOT (!) reverses truth value.

For example, a student qualifies for academic honors only if their marks reach 85 and attendance exceeds 90: marks >= 85 && attendance >= 90.

E Increment & Decrement Operators

The increment (++) and decrement (--) operators adjust an integer variable by 1. When used inside larger expressions, their placement matters significantly.

Postfix (x++) evaluates using the current value before incrementing. Prefix (++x) increments the variable first before using the new value in the expression.

Prefix vs. Postfix Example C++ 
int x = 5;
std::cout << x++ << '\n'; // Prints 5, then x becomes 6
std::cout << x   << '\n'; // Prints 6

x = 5;
std::cout << ++x << '\n'; // Increments first: prints 6

F Other Operators & Precedence

The conditional ternary operator (?:) provides a compact inline if-else structure. Bitwise operators (&, |, ^, ~, <<, >>) manipulate individual binary bits. The sizeof operator measures the memory footprint of a type or variable in bytes.

Never confuse bitwise & and | with logical && and ||. Logical operators evaluate conditions with short-circuit evaluation, whereas bitwise operators perform binary bit masking. Operator precedence governs execution order, where multiplication precedes addition. Always use parentheses to guarantee evaluation order and make code self-explanatory.

G Practical Program: Shopping Discount

This runnable program combines arithmetic multiplication, relational comparison, and the ternary conditional operator to calculate an order discount.

Shopping Bill Calculation (main.cpp) C++ 
#include <iostream>

int main() {
    double price = 500.0;
    int quantity = 2;
    double total = price * quantity;

    bool hasDiscount = total >= 1000.0;
    double finalTotal = hasDiscount ? total * 0.90 : total;

    std::cout << "Total: " << total << '\n';
    std::cout << "Discount eligible: "
              << std::boolalpha << hasDiscount << '\n';
    std::cout << "Final total: " << finalTotal << '\n';

    return 0;
}
✔ Program Output
Total: 1000
Discount eligible: true
Final total: 900

Because total reaches 1000, hasDiscount evaluates to true, applying the 10% discount and reducing the final bill from 1000 to 900.
