Inheritance in C++

Learn how inheritance enables code reuse, models real-world is-a relationships, organizes class hierarchies, and coordinates constructors.

A What Is Inheritance?

Inheritance is a core mechanism of Object-Oriented Programming that allows a new class to acquire accessible attributes and behaviors from an existing class. This establishes an is-a relationship between classes, promoting code reuse and eliminating redundant definitions across your software.

Think of vehicles in transportation: a general Vehicle defines foundational properties like speed and brand, with a behavior to move. Specific vehicles such as Car and Bike are specialized vehicles. Rather than reprogramming basic vehicle logic for each, Car and Bike inherit from Vehicle and add their own specialized features.

  • Base Class (Parent): The existing class whose properties and member functions are inherited.
  • Derived Class (Child): The new class that inherits from the base class.

In C++, you define inheritance by placing a colon (:) and an access mode after the derived class name:

Inheritance Declaration Syntax C++ 
class DerivedClass : public BaseClass {
    // Adds specialized attributes and methods
};

B Basic Inheritance Example

When a derived class publicly inherits from a base class, public base methods become callable directly on the derived object:

Animal and Dog Inheritance (main.cpp) C++ 
#include <iostream>
using namespace std;

class Animal {
public:
    void eat() {
        cout << "Animal is eating" << '\n';
    }
};

class Dog : public Animal {
public:
    void bark() {
        cout << "Dog is barking" << '\n';
    }
};

int main() {
    Dog d;
    d.eat();  // Inherited from Animal base class
    d.bark(); // Defined directly in Dog derived class

    return 0;
}
✓ Program Output
Animal is eating
Dog is barking

The Dog object d seamlessly executes the inherited eat() method without writing any duplicate code inside the Dog class.

d.bark();
→ resolves to → ↓ resolves to ↓
Execution Targets
eat() → Dispatched to Animal
bark() → Dispatched to Dog

C The Five Types of Inheritance

C++ supports five distinct inheritance architectures to organize class hierarchies:

◆ Visual 4: Single vs. Multilevel Inheritance
1. Single Inheritance

One derived class inherits directly from one base class.

Animal → Dog
2. Multilevel Inheritance

Inheritance forms a linear multi-generational chain.

Animal → Mammal → Dog
◆ Visual 5: Multiple vs. Hierarchical Inheritance
3. Multiple Inheritance

One child inherits from multiple parent classes.

Camera + Phone → SmartPhone
4. Hierarchical Inheritance

Multiple derived classes share one common base class.

Vehicle → Car, Bike
◆ Visual 6: Hybrid Inheritance & The Diamond Pattern

5. Hybrid Inheritance combines two or more inheritance styles. A classic example is the diamond pattern, which combines hierarchical and multiple inheritance:

Device (Base)
↙                 ↘
Printer : Device
Scanner : Device
↘                 ↙
Copier : Printer, Scanner

In hybrid diamond hierarchies, member ambiguity can arise because Copier inherits two separate copies of Device. Advanced C++ resolves this via virtual inheritance.

D Public, Protected, and Private Inheritance

The inheritance access specifier determines how inherited members from the base class transition into the derived class:

Inheritance Mode Base Public Members Become Base Protected Members Become
public public in derived class protected in derived class
protected protected in derived class protected in derived class
private private in derived class private in derived class

Base-class private members are never directly accessible inside derived classes, regardless of the inheritance mode used. They can only be accessed indirectly through accessible base member functions.

Standard C++ programs almost always use public inheritance, which preserves the base class public interface and establishes an authentic is-a relationship.

◆ Visual 7: Inheritance Access Mode Scope
: public Base

Standard is-a modeling. Public interface stays public to callers.

: protected Base

Restricts public members to protected inside derived hierarchy.

: private Base

Default for classes. All inherited members become private.

E Constructors in Inheritance

When an object of a derived class is created, the base class constructor executes first to initialize parent properties before the derived class constructor body runs:

Constructor Order (main.cpp) C++ 
#include <iostream>
using namespace std;

class Person {
public:
    Person() {
        cout << "Person constructor" << '\n';
    }
};

class Student : public Person {
public:
    Student() {
        cout << "Student constructor" << '\n';
    }
};

int main() {
    Student s; // Instantiates derived object
    return 0;
}
✓ Program Output
Person constructor
Student constructor
◆ Visual 8: Constructor Execution Sequence
1. Base Constructor
Person() runs first
→ ↓
2. Derived Constructor
Student() runs second

This construction sequence ensures that parent data attributes are always fully constructed before child initialization logic runs.

F Benefits & Common Pitfalls

Inheritance streamlines software design by reducing duplication, modeling realistic domain hierarchies, and supporting modular expansion.

  • Direct Private Access: Derived classes cannot directly read private base members; use getters or protected.
  • Multiple vs. Multilevel: Multiple inheritance inherits from two parents simultaneously; multilevel forms a chain across generations.
  • Default Private Inheritance: Omitting the access specifier (e.g., class B : A) defaults to private in classes.
  • Overusing Inheritance: Favor composition ("has-a") over inheritance when an entity merely contains another rather than being a subtype.
