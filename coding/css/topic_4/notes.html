01

CSS Combinators

Combinators define the structural relationship between multiple selectors:

  • Descendant Combinator (space): Matches all matching elements nested anywhere inside the ancestor (e.g., nav a matches all links inside nav, even deeply nested).
  • Child Combinator (>): Matches only direct children (e.g., ul > li).
  • Adjacent Sibling Combinator (+): Matches the immediately following sibling (e.g., h2 + p matches the first paragraph immediately after an h2).
  • General Sibling Combinator (~): Matches all subsequent siblings sharing the same parent.
02

Dynamic Pseudo-classes

Pseudo-classes select elements based on their state or user interaction:

  • :hover: Active when the user points with a mouse cursor.
  • :focus: Active when an element receives keyboard or input focus.
  • :active: Active while an element is being clicked/pressed down.
  • :visited: Active for links the user has already visited.
03

Structural Pseudo-classes

Select elements based on their position in the DOM tree:

  • :first-child / :last-child: First or last child element of its parent.
  • :nth-child(2n): Selects even elements (great for zebra-striped tables).
  • :not(.active): Negation pseudo-class selecting elements without the class.

/* Direct child list items */

  font-size: 1.15rem;

  background-color: #2563eb;
  color: white;
  transition: background-color 0.2s ease;

.btn:hover {
  background-color: #1d4ed8;
}
.btn:active {
  transform: scale(0.98);
}

Common Mistakes & Pro Tips

⚠️ Common Trap: Confusing descendant (space) with multi-class (.class1.class2)

Problem: .btn .active looks for an element with class .active inside .btn, whereas .btn.active targets an element with both classes simultaneously.

Fix: No space (.a.b) means both classes on the same element; space (.a .b) means parent-child descendant.

⚠️ Common Trap: Applying :hover styles without considering mobile touch devices

Problem: Mobile devices do not have true hover states, causing sticky hover effects on tap.

Fix: Combine hover with :focus-visible and use @media (hover: hover) when appropriate.
