01

Understanding z-index

While X and Y coordinate axes control horizontal and vertical placement, the Z-axis controls the 3D stacking depth of elements towards the viewer. The z-index property accepts positive or negative integers (e.g. z-index: 10, z-index: -1).

Crucial Prerequisite: z-index only works on positioned elements (elements with position set to relative, absolute, fixed, or sticky) or direct flex/grid children.

02

What is a Stacking Context?

A Stacking Context is a three-dimensional conceptual grouping of elements. Elements within the same stacking context are layered against each other.

The Golden Trap of z-index: A child element cannot escape its parent's stacking context. If Parent A has z-index: 1 and Parent B has z-index: 2, a child inside Parent A with z-index: 999999 will still render underneath Parent B!

03

Stacking Context Triggers

Stacking contexts are formed by more than just z-index:

  • Root <html> element.
  • Positioned element with z-index != auto.
  • opacity < 1.
  • transform, filter, backdrop-filter, or perspective not equal to none.
  • isolation: isolate; (Clean modern method to create a stacking context safely).

Interactive Code & Live Examples

Example

Modal Overlay Layering with Isolated Stacking Context:

CSS 
/* Component with isolated stacking context */
.card-isolated {
  isolation: isolate; /* Safe boundary */
  position: relative;
}

/* Fullscreen dimmed backdrop */
.modal-backdrop {
  position: fixed;
  inset: 0;
  background-color: rgba(0, 0, 0, 0.7);
  z-index: 900;
}

/* Modal dialog box floating on top */
.modal-dialog {
  position: fixed;
  top: 50%;
  left: 50%;
  transform: translate(-50%, -50%);
  z-index: 1000;
  background: white;
  border-radius: 16px;
  padding: 32px;
}
Browser / Console Result
[Backdrop sits at z-index 900; dialog box sits firmly on top at z-index 1000]

WARN

Common Mistakes & Pro Tips

⚠️ Common Trap: Applying z-index to position: static elements

Problem: Writing z-index: 99 on an element without declaring position: relative has zero effect.

Fix: Always add position: relative (or absolute/fixed/sticky) when using z-index.

⚠️ Common Trap: Setting extreme arbitrary numbers like z-index: 9999999

Problem: Leads to unmaintainable z-index wars where developers keep adding 9s.

Fix: Use a systematic scale: dropdowns (100), sticky header (200), modals (500), toasts (1000).
