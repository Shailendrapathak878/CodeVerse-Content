01

The 2-Dimensional Grid Powerhouse

While Flexbox is designed for 1-dimensional layouts (rows OR columns), CSS Grid is the first native CSS layout system built for 2 dimensions simultaneously (rows AND columns).

Turn any element into a grid container with display: grid;. Columns and rows are defined along virtual grid lines.

02

Defining Columns, repeat(), and the fr Unit

Grid introduces the fractional fr unit, representing a fraction of available free space:

  • grid-template-columns: 200px 1fr 2fr; (1st column 200px, remaining space split 1:2).
  • grid-template-columns: repeat(3, 1fr); (Creates 3 equal columns).
  • Responsive Auto-Fitting Grid without Media Queries:
    grid-template-columns: repeat(auto-fit, minmax(280px, 1fr));
    Automatically drops columns onto new rows as the screen narrows!
03

Spanning Items and Grid Template Areas

Items can span multiple columns or rows:

  • grid-column: span 2;: Spans across two columns.
  • grid-template-areas: Allows you to visually sketch the entire page layout in ASCII-like art:
    grid-template-areas:
  "header header"
  "sidebar main"
  "footer footer";
EX

Interactive Code & Live Examples

Example

Modern Auto-Responsive Grid Card Layout:

CSS 
/* Auto-responsive card grid: No media queries needed! */
.card-grid {
  display: grid;
  grid-template-columns: repeat(auto-fit, minmax(280px, 1fr));
  gap: 24px;
  padding: 24px;
}

.card {
  background: #1e293b;
  color: #f8fafc;
  border-radius: 12px;
  padding: 20px;
}

/* Featured card spans 2 columns on wide screens */
.card.featured {
  grid-column: span 2;
}

WARN

Common Mistakes & Pro Tips

⚠️ Common Trap: Using percentages instead of the fr unit

Problem: Setting grid-template-columns: 33.33% 33.33% 33.33% with a gap: 20px causes total width to exceed 100%, causing horizontal overflow.

Fix: Always use repeat(3, 1fr); the fr unit automatically accounts for gap gutters before dividing space.

⚠️ Common Trap: Choosing Grid when 1D Flexbox is simpler

Problem: Using complex grid lines for a simple linear button group or horizontal navbar.

Fix: Use Flexbox for 1D micro-components; use Grid for 2D page layouts and card matrices.
