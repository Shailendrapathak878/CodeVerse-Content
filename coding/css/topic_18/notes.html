What are CSS Custom Properties?

CSS Custom Properties (commonly referred to as CSS Variables) allow developers to store reusable values (colors, spacing, font sizes, shadows) and reference them throughout stylesheets.

Unlike preprocessor variables (Sass/Less) which compile down to static values, CSS custom properties are live in the browser runtime, participate in the cascade, and update dynamically in real time!

02

Declaration and the var() Function

Custom properties must begin with a double dash (--) and are case-sensitive. They are typically declared on :root for global scope:

:root {
  --primary: #2563eb;
  --radius: 12px;
  --spacing-md: 16px;
}

.btn {
  background-color: var(--primary);
  border-radius: var(--radius);
  padding: var(--spacing-md);
}

Fallback Values: You can provide a fallback if a variable is undefined: var(--brand-color, #000000).

03

Runtime Dark Mode and Theming

Because custom properties participate in the cascade, theming is effortless:

:root {
  --bg: #ffffff;
  --text: #1f2937;
}

[data-theme="dark"] {
  --bg: #0b0f17;
  --text: #e7ecf3;
}

body {
  background-color: var(--bg);
  color: var(--text);
}

Switching themes only requires toggling an attribute on <html> without rewriting component styles!

Example

Complete Design System Tokens with Dark Theme Switch:

CSS 
/* Design tokens defined in root */
:root {
  --primary: #3b82f6;
  --surface: #ffffff;
  --text-main: #0f172a;
  --border-subtle: #e2e8f0;
  --card-radius: 16px;
}

/* Dark theme overrides */
@media (prefers-color-scheme: dark) {
  :root {
    --surface: #141b2a;
    --text-main: #f8fafc;
    --border-subtle: #232c40;
  }
}

/* Component uses tokens cleanly */
.card {
  background-color: var(--surface);
  color: var(--text-main);
  border: 1px solid var(--border-subtle);
  border-radius: var(--card-radius);
  padding: 24px;
}

[Card automatically responds to system dark mode without duplicating CSS rules]

WARN

Common Mistakes & Pro Tips

⚠️ Common Trap: Declaring variables without the leading double hyphen

Problem: Writing primary-color: #3b82f6 instead of --primary-color: #3b82f6 causes the property to be ignored as invalid CSS.

Fix: Always prefix custom property names with two dashes: --variable-name.

⚠️ Common Trap: Assuming CSS variables are case-insensitive

Problem: --primaryColor and --primarycolor are two completely separate variables in CSS.

Fix: CSS variable names are case-sensitive. Use lowercase kebab-case consistently (--primary-color).
