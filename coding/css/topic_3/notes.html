Foundational CSS Selectors

Selectors allow CSS to target specific HTML elements for styling:

  • Universal Selector (*): Matches all elements on the entire page. Primarily used for global box-sizing resets.
  • Type Selector (Element Tag): Targets all elements of a given tag name (e.g., p, h2, button).
  • Class Selector (.className): Targets elements with a matching class attribute. Reusable across unlimited elements.
  • ID Selector (#idName): Targets a single unique element with a matching id. Highly specific.
02

Attribute Selectors

Attribute selectors target elements based on the presence or value of their HTML attributes:

  • [disabled]: Targets elements with the disabled attribute.
  • [type="text"]: Exact match for attribute value.
  • [href^="https"]: Attribute value begins with 'https' (secure links).
  • [href$=".pdf"]: Attribute value ends with '.pdf' (download links).
  • [class*="btn-"]: Attribute value contains the substring 'btn-'.
EX

Interactive Code & Live Examples

Example

Using Attribute and Class Selectors:

CSS 
/* Style external secure links with an icon */
a[href^="https://"][target="_blank"] {
  color: #2563eb;
  font-weight: 500;
}

/* Add PDF indicator after PDF links */
a[href$=".pdf"]::after {
  content: " (PDF)";
  font-size: 0.8em;
  color: #ef4444;
}

/* Disabled input styling */
input[disabled] {
  background-color: #f1f5f9;
  cursor: not-allowed;
}
Browser / Console Result
[PDF links display red (PDF) badges; disabled inputs show not-allowed cursor]

WARN

Common Mistakes & Pro Tips

⚠️ Common Trap: Overusing ID selectors for styling

Problem: IDs have very high specificity (0,1,0,0), making them almost impossible to override without !important or messy selector chains.

Fix: Always use class selectors (.btn) for styling. Keep IDs strictly for JavaScript hooks and anchor fragment links.

⚠️ Common Trap: Forgetting the dot prefix for class selectors

Problem: Writing button-primary instead of .button-primary treats it as a non-existent HTML tag.

Fix: Always prefix class selectors with a dot (.) and ID selectors with a hash (#).
