What is CSS?

CSS (Cascading Style Sheets) is the stylesheet language used to describe the visual presentation, typography, colors, animations, and responsive layout of an HTML document.

Invented by Håkon Wium Lie in 1994, CSS decoupled document structure from presentation, transforming the web from plain text documents into visually stunning digital experiences.

02

Three Methods of Applying CSS

CSS can be connected to HTML in three distinct ways:

  • 1. External Stylesheet (Recommended): Linked via <link rel="stylesheet" href="styles.css"> in <head>. Styles are cached by browsers across multiple pages, drastically improving performance and maintainability.
  • 2. Internal Stylesheet: Written inside a <style> tag inside <head>. Scoped to a single document; useful for critical above-the-fold CSS.
  • 3. Inline Styles (Anti-pattern): Written directly on elements via the style="..." attribute. Violates separation of concerns, causes high specificity clashes, and prevents caching.
03

The Browser Rendering Pipeline

Understanding how browsers turn code into pixels:

  1. DOM Construction: The browser parses HTML into the Document Object Model tree.
  2. CSSOM Construction: The browser parses CSS rules into the CSS Object Model tree.
  3. Render Tree: The DOM and CSSOM combine into the Render Tree (excluding hidden elements like display: none).
  4. Layout (Reflow): Calculates the exact geometry, position, and dimensions of each element.
  5. Paint: Fills in pixels (colors, borders, text, shadows).
  6. Composite: Layers are drawn to screen via the GPU.

Common Mistakes & Pro Tips

⚠️ Common Trap: Relying on inline styles for component styling

Problem: Inline styles bloat HTML, override stylesheet rules with high specificity, and cannot use media queries or pseudo-classes (:hover).

Fix: Always write styles in external stylesheets using reusable classes.

⚠️ Common Trap: Placing at the bottom of

Problem: Causes FOUC (Flash of Unstyled Content), where users see raw unstyled HTML before styles pop in.

Fix: Always place inside the element.
