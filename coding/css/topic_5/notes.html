CSS Pseudo-elements

Create virtual DOM elements and style sub-parts of text without touching your HTML markup. Master generated content with ::before and ::after, typographic styling with ::first-letter and ::first-line, and UI state customization with ::selection and ::placeholder.

1 Technical Definition & Single vs Double Colon Syntax

In CSS standards, a Pseudo-element is an abstraction that represents a "virtual" child element or an internal fragment of an element that does not exist as an independent node in the HTML Document Object Model (DOM) tree.

The Single Colon (:) vs Double Colon (::) Distinction

Beginners frequently ask why both :after and ::after exist in various codebases:

  • CSS2 Specification (1998): Used a single colon (:) for both pseudo-classes and pseudo-elements (e.g. :hover and :before).
  • CSS3 Selectors Specification (W3C Standard): Introduced the double colon (::) prefix specifically to create a clear syntactic distinction:
    • Single Colon (:): Reserved exclusively for Pseudo-classes describing states (e.g., :hover, :focus).
    • Double Colon (::): Reserved exclusively for Pseudo-elements describing virtual DOM nodes or sub-parts (e.g., ::before, ::after, ::first-letter).
💡 Modern Best Practice

Always use double colons (::before, ::after, ::marker) in modern CSS. All contemporary browsers support double colons while maintaining backward compatibility for single colons on the four original CSS2 pseudo-elements (:before, :after, :first-line, :first-letter).

2 Generated Content with ::before & ::after

The two most widely used pseudo-elements are ::before and ::after. They allow developers to insert cosmetic, stylistic, or supplementary visual content into the page purely from CSS, keeping the HTML semantic and clean.

Figure 5.1: Internal DOM insertion model of ::before (first child) and ::after (last child) within the parent's content box.

The Mandatory content Property

A pseudo-element will never render unless it has a content property defined! Even if you are creating a purely decorative graphic with width, height, and background-color, you MUST declare:

The Mandatory Content Rule CSS 
.card::before {
  content: "";               /* Mandatory! Empty string generates the box */
  display: block;
  width: 40px;
  height: 4px;
  background: #4f46e5;
}
🚨 The "Replaced Elements" Exception

You CANNOT attach ::before or ::after to replaced elements such as <img>, <input>, <br>, or <hr>! Because these elements have no document subtree or internal text box, the browser cannot insert virtual child elements inside them.

3 Typographic & Form Pseudo-elements

Pseudo-element Target Sub-part Primary Use Cases
::first-letter The very first character of the first formatted line of block content. Editorial drop caps, decorative leading letters in magazine layouts.
::first-line The complete first line of text as rendered on the screen. Newspaper lede styles, small-caps first sentences (resizes dynamically on reflow).
::selection Portion of document highlighted/selected by the user's cursor. Branded text highlighting colors (e.g. indigo background, white text).
::placeholder Placeholder helper text within <input> or <textarea>. Customizing input guidance color, font-weight, or italic style.
::marker The bullet symbol or number of a list item (<li>). Coloring list bullets, replacing bullets with emojis or custom counters.
::backdrop The background layer rendered beneath a native <dialog> or fullscreen modal. Darkening or blurring the page behind a modal dialog box.

4 Progressive Code Examples

Level 1: Editorial Drop Cap & Branded Selection

Level 1: Editorial Typography CSS 
/* Style the first letter as an editorial drop-cap */
.editorial-lead::first-letter {
  font-size: 3.5rem;
  font-weight: 800;
  float: left;
  line-height: 0.85;
  margin-right: 0.6rem;
  color: #4f46e5;
}

/* Custom text selection styling across the page */
::selection {
  background-color: #4f46e5;
  color: #ffffff;
}

Level 2: Custom List Markers with ::marker

Level 2: List Markers CSS 
/* Custom bullet color and size */
ul.feature-list li::marker {
  color: #10b981;
  font-size: 1.25em;
}

/* Custom emoji marker using content */
ul.checklist li::marker {
  content: "✓ ";
  color: #4f46e5;
  font-weight: bold;
}

Level 3: Pure CSS Tooltip with ::before & ::after

Using ::before for the tooltip bubble and ::after for the triangular arrow indicator:

Level 3: Pure CSS Tooltip HTML & CSS 
.has-tooltip {
  position: relative;
  cursor: pointer;
}

/* Tooltip bubble reads data-tip attribute */
.has-tooltip::before {
  content: attr(data-tip);
  position: absolute;
  bottom: 125%;
  left: 50%;
  transform: translateX(-50%);
  background: #0f172a;
  color: #ffffff;
  padding: 0.4rem 0.8rem;
  border-radius: 6px;
  font-size: 0.8rem;
  white-space: nowrap;
  opacity: 0;
  pointer-events: none;
  transition: opacity 0.2s ease, transform 0.2s ease;
}

/* Reveal on hover */
.has-tooltip:hover::before {
  opacity: 1;
  transform: translateX(-50%) translateY(-4px);
}

Level 4: Production Card with Decorative Gradient Top-Bar

A production card component featuring an accent border generated completely via ::before:

Level 4: Component Accent Border CSS 
.feature-box {
  position: relative;
  background: #ffffff;
  border: 1px solid #e2e8f0;
  border-radius: 12px;
  padding: 1.75rem;
  overflow: hidden;
}

/* Top decorative gradient line */
.feature-box::before {
  content: "";
  position: absolute;
  top: 0;
  left: 0;
  right: 0;
  height: 4px;
  background: linear-gradient(90deg, #4f46e5 0%, #06b6d4 100%);
}

5 Common Beginner Mistakes & Fixes

Mistake 1: Omitting the content Property

The number one reason ::before or ::after fails to appear is forgetting content: "". Without content, the rendering engine skips generating the box model entirely.

Mistake 2: Missing position: relative on the Parent

When positioning a pseudo-element with position: absolute; top: 0; left: 0;, if the parent container lacks position: relative, the pseudo-element will fly out and anchor itself to the <body> element!

How to Inspect Pseudo-elements in Chrome DevTools

  1. Inspect the target element in the DevTools Elements panel.
  2. Click the expand arrow (▶) next to the element in the DOM tree.
  3. Notice the gray ::before or ::after child nodes listed directly inside the element!
  4. Click on ::before to inspect and modify its computed styles in the right-hand panel just like any standard DOM node.

6 Knowledge Assessment & Exercises

1. Which property is strictly required for ::before and ::after to render on screen?
  • A) display: block
  • B) content
  • C) position: absolute
  • D) z-index
Answer: B) content — Without defining the content property (even as an empty string ""), the pseudo-element will not generate.
2. On which of the following HTML elements will ::before FAIL to work?
  • A) <button>
  • B) <div>
  • C) <img>
  • D) <blockquote>
Answer: C) <img> — Replaced elements lack an internal content box and cannot hold pseudo-element children.

7 Quick Reference Cheat Sheet

::before

Virtual first child of target. Requires content: "".

::after

Virtual last child of target. Requires content: "".

::marker

Controls list bullet / numbering styling directly.

::selection

Custom highlight colors for user-selected text.

::placeholder

Custom colors and styles for input placeholder text.

::first-letter

Drop-cap editorial styling on first character.
