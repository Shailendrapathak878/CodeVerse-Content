01

The 1-Dimensional Flexbox Model

Flexbox (Flexible Box Layout) is designed to lay out items in a single dimension (either as a row or as a column). It excels at distributing space, aligning content, and building responsive navigation bars and card rows.

Declare display: flex; on the parent to turn it into a flex container; all its immediate children instantly become flex items.

02

Main Axis vs Cross Axis

Flexbox operates on two perpendicular axes:

  • Main Axis: Defined by flex-direction: row (default, horizontal left-to-right) or flex-direction: column (vertical top-to-bottom).
  • Cross Axis: Runs perpendicular to the main axis.
  • justify-content: Aligns items along the Main Axis (flex-start, center, flex-end, space-between, space-around, space-evenly).
  • align-items: Aligns items along the Cross Axis (stretch, center, flex-start, flex-end, baseline).
  • gap: 16px;: Native spacing between items along both axes!
03

Flex Item Sizing: grow, shrink, and basis

Individual items can be controlled using the flex shorthand (flex: grow shrink basis):

  • flex-grow: 1;: Allows the item to expand and consume leftover empty space.
  • flex-shrink: 1;: Dictates how the item shrinks when container space is constrained.
  • flex-basis: 250px;: The starting ideal size before growing or shrinking.
  • flex: 1; (Shorthand for 1 1 0%): Causes items to share space equally!

Interactive Code & Live Examples

Example

Responsive Navigation Bar and Centered Hero with Flexbox:

CSS 
/* Navbar with logo on left, links on right */
.navbar {
  display: flex;
  justify-content: space-between;
  align-items: center;
  padding: 16px 24px;
  background-color: #0f172a;
}

.nav-links {
  display: flex;
  gap: 20px;
  list-style: none;
}

/* Perfect absolute vertical and horizontal centering */
.center-box {
  display: flex;
  justify-content: center;
  align-items: center;
  min-height: 300px;
}

WARN

Common Mistakes & Pro Tips

⚠️ Common Trap: Confusing justify-content with align-items when flex-direction is column

Problem: When flex-direction: column is active, the main axis becomes vertical. justify-content now controls vertical alignment!

Fix: Remember: justify-content ALWAYS controls the main axis, whichever direction it points.

⚠️ Common Trap: Using margin hacks instead of the native gap property

Problem: Adding margin-right to items requires ugly :last-child overrides to prevent layout shifts.

Fix: Use the modern gap property on the flex container (e.g. gap: 1rem).
