01

Mathematical Calculations with calc()

The calc() function performs mathematical calculations directly inside CSS properties, allowing you to mix units seamlessly:

width: calc(100% - 40px);
padding: calc(1rem + 4px);

Critical Syntax Rule: In addition and subtraction, operators (+ and -) must be surrounded by whitespace (e.g., calc(100% - 20px), NOT calc(100%-20px)), otherwise the minus sign is parsed as a negative number!

02

Boundary Constraints: min() and max()

Dynamic comparison functions choose the smallest or largest value from a comma-separated list:

  • min(50vw, 400px): Takes whichever value is smaller. (Acts like a max-width constraint!).
  • max(200px, 10vw): Takes whichever value is larger. (Acts like a min-width constraint!).
03

Fluid Responsive Design with clamp()

The clamp(min, preferred, max) function is the gold standard for fluid responsive typography and spacing without media queries:

font-size: clamp(1.25rem, 2.5vw + 1rem, 2.75rem);
  • Minimum: 1.25rem (never shrinks smaller on small phones).
  • Preferred: Scales smoothly with viewport width (2.5vw + 1rem).
  • Maximum: 2.75rem (never grows larger on massive desktop screens).

Example

Fluid Typography and Responsive Container using clamp() and calc():

CSS 
/* Fluid heading that scales smoothly across all devices */
h1.fluid-title {
  font-size: clamp(2rem, 4vw + 1rem, 4rem);
  line-height: 1.15;
  letter-spacing: -0.02em;
}

/* Sidebar with dynamic calculation */
.sidebar {
  width: calc(280px + 2vw);
}

/* Container constrained with min() */
.wrapper {
  width: min(90%, 1200px);
  margin-inline: auto;
}

WARN

Common Mistakes & Pro Tips

⚠️ Common Trap: Omitting spaces around + and - inside calc()

Problem: Writing calc(100%-20px) is invalid syntax in CSS and fails silently.

Fix: Always put spaces around addition and subtraction: calc(100% - 20px).

⚠️ Common Trap: Reversing the min and max arguments in clamp()

Problem: Writing clamp(3rem, 2vw, 1rem) where the minimum is larger than the maximum produces invalid behavior.

Fix: Ensure the first argument is strictly the minimum and the third is the maximum: clamp(1rem, 2vw, 3rem).
