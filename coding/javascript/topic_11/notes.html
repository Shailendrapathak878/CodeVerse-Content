Strings & String Methods

Master text representation in JavaScript. Learn character indexing, string immutability, interpolation with template literals, slicing, searching, trimming, text transformation, and practical parsing.

1 What Is a String?

How does JavaScript store and work with a person's name, an email address, a password, or a chat message?

In JavaScript, a String is a sequence of text characters used to represent information. While numbers like 20 are meant for arithmetic, strings like "20" represent literal written text.

You can create strings using three types of quotation marks:

  • Double quotes: "Hello"
  • Single quotes: 'Hello'
  • Template literals (backticks): `Hello` (introduced in ES6)
◆ String Anatomy: Quotes vs. Content
"Aarav"   →   Opening Quote + Text Characters + Closing Quote

Example 1: Creating Strings with Single and Double Quotes

Declaring Text Variables JS 
const firstName = "Aarav";
const city = 'Lucknow';

console.log(firstName);
console.log(city);
Expected Terminal Output
Aarav Lucknow

Step-by-Step Trace: firstName stores five characters enclosed in double quotes. city stores seven characters enclosed in single quotes. Both are identical string primitives in JavaScript.

Example 2: Handling Quotation Marks Inside Strings

Mixing Quotes or Using Escape Sequences (\) JS 
// 1. Use double quotes outside when single quotes are inside
const message1 = "It's a beautiful day!";

// 2. Use single quotes outside when double quotes are inside
const message2 = 'She said, "Hello!"';

// 3. Or escape matching quotes with backslash (\)
const escaped = 'It\'s JavaScript';

console.log(message1);
console.log(message2);
console.log(escaped);
Expected Terminal Output
It's a beautiful day! She said, "Hello!" It's JavaScript

2 Template Literals & String Interpolation

Traditional string concatenation with + can quickly become messy when building sentences with variables. ES6 introduced Template Literals using backticks (` `) and the interpolation syntax ${expression}.

Example 1: Embedding Variables Directly

Clean Variable Interpolation JS 
const name = "Priya";
const course = "JavaScript";

// Interpolates variables directly without manual concatenation
const message = `Hello ${name}, welcome to ${course}!`;

console.log(message);
Expected Terminal Output
Hello Priya, welcome to JavaScript!

Example 2: Evaluating Arithmetic Expressions Inside ${...}

In-Line Calculations JS 
const price = 500;
const quantity = 3;

// JavaScript calculates price * quantity and converts it to text
const bill = `Total amount: ₹${price * quantity}`;

console.log(bill);
Expected Terminal Output
Total amount: ₹1500

Example 3: Multiline Strings Without \n

Multi-line formatting JS 
const emailBody = `Dear Student,
Your assignment has been graded.
Keep coding!`;

console.log(emailBody);
Expected Terminal Output
Dear Student, Your assignment has been graded. Keep coding!

3 String Length & Character Indexing

Just like arrays, JavaScript strings use zero-based indexing. Each character occupies a numbered slot starting from index 0 up to length - 1.

◆ Character Index Ruler: "JavaScript"
[0]J
[1]a
[2]v
[3]a
[4]S
[5]c
[6]r
[7]i
[8]p
[9]t

Example 1: Reading Characters by Index and Finding Length

Reading by Bracket Notation JS 
const language = "JavaScript";

console.log("Length:", language.length);
console.log("First char [0]:", language[0]);
console.log("Fifth char [4]:", language[4]);
console.log("Last char [9]:", language[language.length - 1]);
Expected Terminal Output
Length: 10 First char [0]: J Fifth char [4]: S Last char [9]: t

Example 2: Accessing Missing or Out-of-Range Indexes

Out of Range Indexing JS 
const word = "Code";

console.log("Index 2:", word[2]);
console.log("Index 10:", word[10]);
console.log("Word length:", word.length);
Expected Terminal Output
Index 2: d Index 10: undefined Word length: 4
💡 Emojis and UTF-16 Code Units
JavaScript strings are indexed by UTF-16 code units. Most common characters (A-Z, digits) take 1 code unit. However, many emojis like "🚀" take 2 code units (known as a surrogate pair). Therefore, "🚀".length === 2, even though it appears visually as a single glyph!

4 String Immutability: Strings Cannot Be Modified in Place

In JavaScript, strings are immutable. Once a string value is created in memory, its individual characters can never be updated, replaced, or deleted in place.

Example 1: Attempting to Modify a Character In Place

Direct Index Assignment Fails Silently JS 
let word = "Code";

// Trying to overwrite 'C' with 'N'
word[0] = "N";

console.log(word);
Expected Terminal Output
Code

Notice that word is still "Code"! The assignment fails silently in standard JavaScript (or throws an error in strict mode).

Example 2: Constructing and Reassigning a New String

The Correct Approach to "Updating" Text JS 
let word = "Code";

// Combine new character with sliced remainder
word = "N" + word.slice(1);

console.log(word);
Expected Terminal Output
Node

Immutability Takeaway: All string methods (such as toUpperCase(), replace(), slice()) never mutate the original string. They always compute and return a brand new string!

5 Concatenation and Type Coercion

The plus operator + performs two completely different operations depending on the operand types:

  • Numeric addition: If both operands are numbers (e.g. 10 + 5 → 15).
  • String concatenation: If either operand is a string, JavaScript converts the other operand to text and joins them together (e.g. "10" + 5 → "105").

Example 1: Joining Text Variables with +

String Joining JS 
const firstName = "Aarav";
const lastName = "Sharma";

const fullName = firstName + " " + lastName;

console.log(fullName);
Expected Terminal Output
Aarav Sharma

Example 2: The Addition vs. Concatenation Pitfall

Comparing "10" + 5 vs 10 + 5 JS 
const age = 20;
console.log("Age: " + age);

// String coercion: joins text
console.log("10" + 5);

// Numeric math: adds values
console.log(10 + 5);
Expected Terminal Output
Age: 20 105 15

6 Changing Letter Case

The toUpperCase() and toLowerCase() methods return a new string with all alphabetic characters converted to capital or lowercase letters.

Example 1: Uppercase Conversion

Converting to All Capitals JS 
const name = "Aarav Sharma";

console.log(name.toUpperCase());
console.log(name); // Original remains unchanged!
Expected Terminal Output
AARAV SHARMA Aarav Sharma

Example 2: Normalizing User Email Input

Case Normalization for Reliable Comparison JS 
const emailInput = "STUDENT@EXAMPLE.COM";
const normalizedEmail = emailInput.toLowerCase();

console.log(normalizedEmail);
console.log(normalizedEmail === "student@example.com");
Expected Terminal Output
student@example.com true

7 Extracting Text: slice() vs. substring()

Both methods extract a section of a string without modifying the original. However, they handle negative arguments and argument ordering differently:

Feature slice(start, end) substring(start, end)
End Index Excluded (up to, but not including) Excluded (up to, but not including)
Negative Indexes Counts backwards from the end (e.g. -6) Treated as 0
If start > end Returns empty string "" Swaps the two arguments automatically
Recommendation Preferred in modern JavaScript Legacy compatibility

Example 1: Using slice() with Positive and Negative Indexes

Extracting Substrings with slice JS 
const language = "JavaScript";

console.log(language.slice(0, 4));  // Indexes 0,1,2,3 -> "Java"
console.log(language.slice(4));     // From index 4 to end -> "Script"
console.log(language.slice(-6));    // Last 6 characters -> "Script"
Expected Terminal Output
Java Script Script

Example 2: Using substring() and Argument Swapping

substring() Behavior JS 
const language = "JavaScript";

console.log(language.substring(0, 4));
console.log(language.substring(4));

// When start > end, substring swaps them: substring(0, 4)
console.log(language.substring(4, 0));
Expected Terminal Output
Java Script Java

JavaScript provides dedicated methods to check if a word or phrase exists inside a string:

Boolean Search JS

9 Replacing Text: replace() vs. replaceAll()

Beginners often assume that replace() swaps every instance in a string. In reality:

  • replace(target, replacement): Replaces only the first matching occurrence.
  • replaceAll(target, replacement): Replaces all matching occurrences across the string.

Example 1: Replacing the First Occurrence with replace()

First Match Only JS 
const message = "I like JavaScript. JavaScript is useful.";

const updated = message.replace("JavaScript", "Python");

console.log(updated);
Expected Terminal Output
I like Python. JavaScript is useful.

Example 2: Replacing All Occurrences with replaceAll()

Global Replacement JS 
const message = "red red blue red";

const updated = message.replaceAll("red", "green");

console.log(updated);
Expected Terminal Output
green green blue green

10 Cleaning Text with trim()

When users type text into input forms, they often introduce accidental spaces at the beginning or end. Trimming methods remove these extra whitespace characters:

◆ Whitespace Removal Visualization
···Priya Sharma···  →  "Priya Sharma" (Only internal space remains)

Example 1: Trimming Both Ends with trim()

Stripping Leading and Trailing Spaces JS 
const name = "   Priya Sharma   ";

console.log("Before trim:", `"${name}"`);
console.log("After trim:", `"${name.trim()}"`);
Expected Terminal Output
Before trim: " Priya Sharma " After trim: "Priya Sharma"

Example 2: Trimming One Side Only (trimStart() and trimEnd())

Directional Trimming JS 
const message = "   Hello CodeVerse   ";

console.log(`"${message.trimStart()}"`);
console.log(`"${message.trimEnd()}"`);
Expected Terminal Output
"Hello CodeVerse " " Hello CodeVerse"

11 Splitting Strings into Arrays: split()

The split(delimiter) method breaks a string apart wherever the specified delimiter appears, returning an ordered Array of Strings.

Example 1: Splitting a Sentence into Words

Splitting by Space (" ") JS 
const sentence = "Learn JavaScript every day";

const words = sentence.split(" ");

console.log(words);
console.log("Word count:", words.length);
Expected Terminal Output
[ 'Learn', 'JavaScript', 'every', 'day' ] Word count: 4

Example 2: Splitting Comma-Separated Values (CSV)

Parsing Delimited Data JS 
const data = "Aarav,20,Lucknow";

const values = data.split(",");

console.log(values);
console.log("Name:", values[0]);
console.log("City:", values[2]);
Expected Terminal Output
[ 'Aarav', '20', 'Lucknow' ] Name: Aarav City: Lucknow

14 Common String Mistakes and Debugging

Review these 10 classic string bugs and learn how to prevent them:

✕ 1. Using string.length as the Last Index (Off-by-One)
const str = "Code";
console.log(str[str.length]); // undefined! Valid indexes are 0 to 3
✓ Correct Fix: Subtract 1 or use str.at(-1): console.log(str[str.length - 1]); // "e"
✕ 2. Expecting In-Place Mutation
let city = "delhi";
city.toUpperCase();
console.log(city); // "delhi"! toUpperCase() returns a new string
✓ Correct Fix: Assign the returned string back: city = city.toUpperCase(); // "DELHI"
✕ 3. Confusing Addition with Concatenation
const a = "20";
const b = 10;
console.log(a + b); // "2010" instead of 30!
✓ Correct Fix: Convert text to number first: console.log(Number(a) + b); // 30
✕ 4. Forgetting that includes() and indexOf() are Case-Sensitive
const text = "JavaScript";
console.log(text.includes("javascript")); // false
✓ Correct Fix: Normalize both to lowercase: text.toLowerCase().includes("javascript")
✕ 5. Expecting replace() to Replace All Occurrences
const text = "cat and cat";
const res = text.replace("cat", "dog"); // "dog and cat"
✓ Correct Fix: Use replaceAll(): text.replaceAll("cat", "dog") // "dog and dog"
✕ 6. Negative Indexes in substring() Treated as 0
const str = "Hello";
console.log(str.substring(-2)); // "Hello" (treated as substring(0))
✓ Correct Fix: Use slice() for negative indexing: str.slice(-2) // "lo"
✕ 7. Forgetting to Trim User Form Input
const userInput = "   ";
if (userInput.length > 0) { /* Passes validation even though it's blank! */ }
✓ Correct Fix: Check trimmed length: if (userInput.trim().length > 0)
✕ 8. Confusing split() and join()
const str = "A-B-C";
str.join(","); // TypeError: str.join is not a function! join() is an Array method.
✓ Correct Fix: Use split() on strings, and join() on arrays: str.split("-").join(",")
✕ 9. Assuming Emojis Always Have Length 1
const smile = "😀";
console.log(smile.length); // 2! UTF-16 surrogate pair
✓ Correct Fix: For true Unicode glyph counts, spread into an array: [...smile].length // 1
✕ 10. Direct Character Assignment Fails Silently
const str = "Hello";
str[0] = "Y"; // str is still "Hello"
✓ Correct Fix: Construct a new string: "Y" + str.slice(1)

Part B: Beginner Coding Exercises

Exercise 1: Capitalize the First Letter of a Word

Task: Write a function capitalize(str) that turns "javascript" into "Javascript".

function capitalize(str) {
  if (!str) return "";
  return str[0].toUpperCase() + str.slice(1);
}

console.log(capitalize("javascript")); // "Javascript"
Exercise 2: Mask Credit Card Digits

Task: Given a 16-digit card number string, mask all but the last 4 digits with *.

function maskCard(card) {
  const lastFour = card.slice(-4);
  return lastFour.padStart(card.length, "*");
}

console.log(maskCard("1234567812345678")); // "************5678"
Exercise 3: Count Occurrences of a Word

Task: Count how many times the word "code" appears in a sentence (case-insensitive).

function countWord(sentence, target) {
  const words = sentence.toLowerCase().split(/\s+/);
  return words.filter(w => w === target.toLowerCase()).length;
}

console.log(countWord("Code more code every day", "code")); // 2
Exercise 4: Format a Full Name

Task: Given messy user input like " priya sharma ", clean extra spaces and format as "Priya Sharma".

function formatName(raw) {
  return raw
    .trim()
    .split(/\s+/)
    .map(w => w[0].toUpperCase() + w.slice(1).toLowerCase())
    .join(" ");
}

console.log(formatName("   priya   sharma   ")); // "Priya Sharma"
Exercise 5: Truncate Text with Ellipsis

Task: If a string exceeds maxLength, truncate it and append "...".

function truncate(text, max) {
  if (text.length <= max) return text;
  return text.slice(0, max) + "...";
}

console.log(truncate("JavaScript Strings are fun", 10)); // "JavaScript..."
Exercise 6: Check for Palindrome

Task: Check whether a string reads the same forwards and backwards.

function isPalindrome(str) {
  const clean = str.toLowerCase().replace(/[^a-z0-9]/g, "");
  const reversed = clean.split("").reverse().join("");
  return clean === reversed;
}

console.log(isPalindrome("Racecar")); // true
console.log(isPalindrome("Hello"));   // false
