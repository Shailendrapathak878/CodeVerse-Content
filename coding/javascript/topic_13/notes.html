JavaScript Foundations • Topic 13

Map, Set & Collections

Explore specialized modern JavaScript collections. Learn how to store key-value associations with Map, maintain unique values with Set, understand memory reference equality, and discover weak collections for garbage-collected metadata.

1 What Are Collections?

Consider three common programming tasks:

  • Recording student exam marks by subject name or student object.
  • Maintaining a list of active online user IDs where duplicate logins must never appear twice.
  • Attaching temporary metadata to HTML buttons without creating memory leaks when those buttons are deleted from the page.

In everyday coding, a collection is a data structure designed to group, organize, search, and manipulate multiple values together. While JavaScript has always provided ordered Array lists and keyed Object dictionaries, modern ECMAScript (ES6+) introduced specialized collection structures:

◆ The JavaScript Collection Family
Array
Ordered index list. Allows duplicate items.
Object
Keyed record. String & Symbol keys only.
Map
Key-value dictionary. Any key type allowed.
Set
Unique values list. Automatic deduplication.

Example 1: An Array Containing Duplicate Elements

Standard Array Allows Duplicate Entries JS 
const subjects = ["JavaScript", "Python", "JavaScript"];

console.log(subjects);
console.log("Count:", subjects.length);
Expected Terminal Output
[ 'JavaScript', 'Python', 'JavaScript' ] Count: 3

Example 2: A Set Preserving Only Unique Values

Set Silently Discards Duplicate Values JS 
const subjects = new Set([
  "JavaScript",
  "Python",
  "JavaScript"
]);

console.log(subjects);
console.log("Size:", subjects.size);
Expected Terminal Output
Set(2) { 'JavaScript', 'Python' } Size: 2

Step-by-Step Trace: In Example 2, when new Set() receives the array, it encounters "JavaScript", inserts it, accepts "Python", and then rejects the second "JavaScript" because it already exists. The resulting set contains exactly 2 unique items.

2 Introduction to Map

A Map is an ordered collection of key-value pairs where both the keys and the values can be of any data type.

Unlike ordinary objects where keys are automatically converted to strings (e.g. obj[1] becomes obj["1"]), a Map preserves the exact type and reference of every key:

◆ Conceptual Map Architecture
Key: "Aarav"
→
Value: 85
Key: "Priya"
→
Value: 92
Key: { id: 101 } (Object)
→
Value: "Admin"

Example 1: Creating a Map and Accessing Values

Map.set(), Map.get(), and Map.size JS 
const studentMarks = new Map();

studentMarks.set("Aarav", 85);
studentMarks.set("Priya", 92);
studentMarks.set("Rohan", 78);

console.log("Priya's Marks:", studentMarks.get("Priya"));
console.log("Total Students in Map:", studentMarks.size);
Expected Terminal Output
Priya's Marks: 92 Total Students in Map: 3

Example 2: Checking Existence with has() and Deleting Entries

Map.has() and Map.delete() JS 
const inventory = new Map();

inventory.set("Laptop", 5);
inventory.set("Mouse", 12);

console.log("Has Laptop?", inventory.has("Laptop"));

// Delete the "Mouse" entry
inventory.delete("Mouse");

console.log("Inventory Size:", inventory.size);
console.log("Has Mouse?", inventory.has("Mouse"));
Expected Terminal Output
Has Laptop? true Inventory Size: 1 Has Mouse? false

3 Adding, Updating, and Removing Map Entries

In a Map, every key is strictly unique. If you call map.set(key, newValue) with a key that already exists, it updates the existing value in place instead of creating a second duplicate entry:

Example 1: Updating an Existing Key

In-Place Key Update JS 
const marks = new Map();

marks.set("Aarav", 80);
marks.set("Priya", 90);

// Aarav retook the test - update score
marks.set("Aarav", 95);

console.log("Aarav's Score:", marks.get("Aarav"));
console.log("Total Students:", marks.size);
Expected Terminal Output
Aarav's Score: 95 Total Students: 2

Example 2: Initializing from 2D Array and Clearing Entries

2D Array Initialization & Map.clear() JS 
// Initialize a Map directly with [key, value] pairs
const stock = new Map([
  ["Laptop", 4],
  ["Keyboard", 10]
]);

stock.set("Mouse", 15);
stock.delete("Keyboard");

console.log("Has Keyboard?", stock.has("Keyboard"));
console.log("Stock Size:", stock.size);

// Remove all entries
stock.clear();
console.log("After clear(), size:", stock.size);
Expected Terminal Output
Has Keyboard? false Stock Size: 2 After clear(), size: 0

4 Iterating Through a Map

Maps maintain a strict insertion order. When you iterate through a map, its entries are processed in the exact order they were inserted.

Connecting directly with Topic 12 (Destructuring), a Map yields [key, value] pairs that can be unpacked cleanly in a for...of loop:

Example 1: Looping Through Entries with Destructuring

for (const [key, value] of map) JS 
const prices = new Map([
  ["Book", 250],
  ["Pen", 20],
  ["Bag", 900]
]);

for (const [item, price] of prices) {
  console.log(`${item}: ₹${price}`);
}
Expected Terminal Output
Book: ₹250 Pen: ₹20 Bag: ₹900

Example 2: Reading keys(), values(), and entries()

Converting Map Iterators via Spread Syntax JS 
const scores = new Map([
  ["Aarav", 85],
  ["Priya", 92]
]);

console.log("Keys:", [...scores.keys()]);
console.log("Values:", [...scores.values()]);
console.log("Entries:", [...scores.entries()]);
Expected Terminal Output
Keys: [ 'Aarav', 'Priya' ] Values: [ 85, 92 ] Entries: [ [ 'Aarav', 85 ], [ 'Priya', 92 ] ]

5 Map Keys and Key Equality

How does a Map know whether two keys are the same?

Maps use the SameValueZero equality algorithm:

  • The string "1" and the number 1 are treated as two completely different keys.
  • NaN is considered equal to NaN (unlike === where NaN !== NaN).
  • +0 and -0 are treated as equal.
  • Objects are compared by heap reference, never by shape!

Example 1: Distinguishing Different Key Types

Type-Preserving Keys in Map JS 
const data = new Map();

data.set("1", "String key");
data.set(1, "Number key");
data.set(true, "Boolean key");

console.log("Size:", data.size);
console.log('get("1"):', data.get("1"));
console.log('get(1):', data.get(1));
Expected Terminal Output
Size: 3 get("1"): String key get(1): Number key
◆ Memory Diagram: Object Key Identity
Variables in Scope
user→ Heap #Obj_101
{ id: 101 } (Literal)→ Heap #Obj_999 (New!)
Map Internal Hash Table
Key #Obj_101→ "Admin" ✓
Key #Obj_999→ undefined ✕

Example 2: Using Objects as Map Keys

Reference Equality with Object Keys JS 
const user = { id: 101 };
const permissions = new Map();

permissions.set(user, "Admin");

// 1. Lookup with the original object reference:
console.log("Lookup by reference:", permissions.get(user));

// 2. Lookup with a brand new object literal (different reference!):
console.log("Lookup by new literal:", permissions.get({ id: 101 }));
Expected Terminal Output
Lookup by reference: Admin Lookup by new literal: undefined

Why It Returns undefined: In JavaScript, { id: 101 } !== { id: 101 }. Even though the contents appear identical, the second literal creates a distinct object at a new memory address that was never registered in the map.

6 Map vs. Ordinary Object

Both objects and maps associate keys with values, but their design goals differ significantly:

Feature Ordinary Object {} ES6 Map
Key Types Strings and Symbols only (coerces others). Any type (numbers, objects, booleans, functions).
Key Count Manual: Object.keys(obj).length Direct: map.size
Iteration Requires helper (Object.entries()). Directly iterable with for...of.
Key Order Complex (integers first, then strings). Guaranteed exact insertion order.
JSON Support Native: JSON.stringify(obj). Requires conversion: Object.fromEntries(map).
Default Keys Has prototype chain keys (e.g. toString). Pure dictionary containing only set keys.

Example 1: Using an Ordinary Object as a Record

Plain Object Record JS 
const student = {
  name: "Aarav",
  course: "JavaScript"
};

console.log(student.name);
console.log("Key count:", Object.keys(student).length);
Expected Terminal Output
Aarav Key count: 2

Example 2: Using a Map for Dynamic Key-Value Collections

Map Collection & JSON Serialization JS 
const studentMap = new Map();
studentMap.set("name", "Aarav");
studentMap.set("course", "JavaScript");

console.log(studentMap.get("name"));
console.log("Map size:", studentMap.size);

// To convert a Map with string keys to JSON:
const json = JSON.stringify(Object.fromEntries(studentMap));
console.log("Serialized JSON:", json);
Expected Terminal Output
Aarav Map size: 2 Serialized JSON: {"name":"Aarav","course":"JavaScript"}

7 Introduction to Set

A Set is a collection of unique values. A value can appear in a Set at most once.

If you attempt to add an item that already exists in the Set, JavaScript quietly ignores the addition without throwing an error:

◆ Set Uniqueness Funnel
["JS", "Python", "JS"]
→ Set Filter →
Set(2) { "JS", "Python" }

Example 1: Creating a Set and Adding Values

Set.add() and Set.has() JS 
const languages = new Set();

languages.add("JavaScript");
languages.add("Python");
languages.add("JavaScript"); // Duplicate ignored!

console.log("Languages Size:", languages.size);
console.log("Has Python?", languages.has("Python"));
console.log("Has Ruby?", languages.has("Ruby"));
Expected Terminal Output
Languages Size: 2 Has Python? true Has Ruby? false

Example 2: Removing Values with Set.delete()

Set.delete() Returns Boolean Success JS 
const colors = new Set(["Red", "Green", "Blue"]);

const wasDeleted = colors.delete("Green");

console.log("Was 'Green' deleted?", wasDeleted);
console.log("Colors Size:", colors.size);
console.log("Has Green?", colors.has("Green"));
Expected Terminal Output
Was 'Green' deleted? true Colors Size: 2 Has Green? false

8 Removing Duplicates from an Array

The most famous and widely used idiom in modern JavaScript is combining Set with the array ... spread syntax (from Topic 12) to deduplicate arrays in one concise line:

◆ The Array Deduplication Pipeline
[1, 2, 2, 3, 4, 4, 5]
→ new Set() →
Set(5) { 1, 2, 3, 4, 5 }
→ [...set] →
[1, 2, 3, 4, 5]

Example 1: Deduplicating Numeric Arrays

Deduplicating Numbers via [...new Set(arr)] JS 
const numbers = [1, 2, 2, 3, 4, 4, 5];

const uniqueNumbers = [...new Set(numbers)];

console.log(uniqueNumbers);
Expected Terminal Output
[ 1, 2, 3, 4, 5 ]

Example 2: Deduplicating String Names

Deduplicating Names while Preserving Order JS 
const names = ["Aarav", "Priya", "Aarav", "Rohan", "Priya"];

const uniqueNames = [...new Set(names)];

console.log(uniqueNames);
Expected Terminal Output
[ 'Aarav', 'Priya', 'Rohan' ]
⚠ Object Reference Warning
A Set checks object equality by heap reference. If an array contains [{ id: 1 }, { id: 1 }], new Set() will not eliminate the duplicate because those two object literals point to distinct memory addresses.

9 Iterating Through a Set

Sets preserve the insertion order of their unique elements. You can traverse them using standard loops or unpack them into array indexes:

Example 1: Direct Iteration with for...of

for (const value of set) JS 
const skills = new Set(["Python", "JavaScript", "SQL"]);

for (const skill of skills) {
  console.log("Skill:", skill);
}
Expected Terminal Output
Skill: Python Skill: JavaScript Skill: SQL

Example 2: Converting Set to Array for Index Access

Array Conversion and Indexing JS 
const numbers = new Set([10, 20, 30]);

// Set has no index access (numbers[1] is undefined). Spread to array first:
const values = [...numbers];

console.log("Full Array:", values);
console.log("Second Element (index 1):", values[1]);
Expected Terminal Output
Full Array: [ 10, 20, 30 ] Second Element (index 1): 20

10 Set vs. Array

Choosing between an Array and a Set depends on whether duplicates and index positions are required:

Feature Array [] Set new Set()

12 Introduction to WeakMap

A WeakMap is a specialized collection designed to attach private metadata to objects without creating memory leaks:

  • Keys MUST be objects: Primitives (strings, numbers) are forbidden.
  • Weak References: If an object has no other active references in your program, the JavaScript garbage collector can automatically reclaim it and remove its entry from the WeakMap.
  • Non-Iterable: WeakMaps have no size property, no keys(), and cannot be looped over with for...of.

Example 1: Storing Private Metadata for an Object

WeakMap.set() and WeakMap.get() JS 
const user = { id: 101 };
const privateData = new WeakMap();

privateData.set(user, { lastLogin: "Today" });

console.log("Private Metadata:", privateData.get(user));
console.log("Has user key?", privateData.has(user));
Expected Terminal Output
Private Metadata: { lastLogin: 'Today' } Has user key? true

Example 2: Removing Metadata and Enforcing Key Constraints

WeakMap.delete() and Primitive Key Rejection JS 
const element = { name: "Submit Button" };
const meta = new WeakMap();

meta.set(element, "Primary action");
console.log("Before delete:", meta.get(element));

meta.delete(element);
console.log("After delete:", meta.has(element));
Expected Terminal Output
Before delete: Primary action After delete: false

13 Introduction to WeakSet

A WeakSet is to Set what WeakMap is to Map:

  • It stores only objects (no primitives).
  • Objects in a WeakSet are held weakly without blocking garbage collection.
  • It has no size and cannot be iterated.
  • Common use case: "Tagging" or marking objects as processed, visited, or authorized.

Example 1: Marking Objects as Processed

Tracking Processed Objects with WeakSet JS 
const processedItems = new WeakSet();

const item = { id: 1 };

processedItems.add(item);

console.log("Is item processed?", processedItems.has(item));
console.log("Is fresh literal processed?", processedItems.has({ id: 1 }));
Expected Terminal Output
Is item processed? true Is fresh literal processed? false

Example 2: Adding and Deleting from WeakSet

WeakSet.delete() JS 
const seen = new WeakSet();
const request = { id: 500 };

seen.add(request);
console.log("Has request?", seen.has(request));

seen.delete(request);
console.log("After delete, has request?", seen.has(request));
Expected Terminal Output
Has request? true After delete, has request? false

14 Map, Set, WeakMap, and WeakSet Comparison

Use this comprehensive decision matrix to select the right collection for any architectural requirement:

Collection Allowed Keys / Values Duplicates Size Property Iterable? Primary Real-World Use Case
Map Any key type → Any value type Unique keys, duplicate values allowed map.size Yes (for...of) Dynamic dictionary, caching by complex keys.
Set Any value type Strictly unique values set.size Yes (for...of) Deduplication, unique tag/ID tracking.
WeakMap Object keys only → Any value Unique object keys None (undefined) No DOM element metadata, memory-safe private fields.
WeakSet Objects only Unique objects None (undefined) No Marking objects visited/processed without leaks.
◆ Quick Decision Guide
  • Need key-value pairs with arbitrary types or frequent add/remove? → Map
  • Need unique items or deduplicating a list? → Set
  • Need private metadata attached to objects without blocking garbage collection? → WeakMap
  • Need to track whether an object has been processed without holding it in memory? → WeakSet
  • Need a fixed structure/record with predefined schema? → Plain Object {}
  • Need an ordered list where items are accessed by 0-based integer position? → Array []

16 Common Mistakes & Debugging

✕ 1. Using .length Instead of .size on Collections
const myMap = new Map([["a", 1]]);
console.log(myMap.length); // undefined!
✓ Correct Fix: Arrays have .length; Maps and Sets have .size. Use myMap.size.
✕ 2. Accessing Map Entries with Bracket Notation
const prices = new Map();
prices["apple"] = 50; // Sets a plain object property, NOT a Map key!
console.log(prices.size); // 0!
✓ Correct Fix: Always use the official methods: prices.set("apple", 50) and prices.get("apple").
✕ 3. Expecting Fresh Object Literals to Match Map Keys
const map = new Map();
map.set({ id: 1 }, "User Data");
console.log(map.get({ id: 1 })); // undefined!
✓ Correct Fix: Store the object reference in a variable first: const user = { id: 1 }; map.set(user, ...); map.get(user);
✕ 4. Expecting Set to Deduplicate Object Literals
const set = new Set([{ tag: "js" }, { tag: "js" }]);
console.log(set.size); // 2! Objects are compared by reference, not value
✓ Correct Fix: Deduplicate by a primitive property (e.g. item.tag) using a Set or Map index.
✕ 5. Forgetting that map.set() Returns the Map Itself
const m = new Map();
const val = m.set("score", 100);
console.log(val); // Map(1) { 'score' => 100 } - NOT 100!
✓ Correct Fix: map.set() returns the map to enable method chaining. Use m.get("score") to retrieve the value.
✕ 6. Attempting to Iterate or Check .size on WeakMap / WeakSet
const wm = new WeakMap();
console.log(wm.size); // undefined!
for (const entry of wm) {} // TypeError: wm is not iterable
✓ Correct Fix: Weak collections do not support iteration because keys are garbage-collected non-deterministically. Use standard Map or Set if iteration is needed.
✕ 7. Calling clear() on Weak Collections
const ws = new WeakSet();
ws.clear(); // TypeError: ws.clear is not a function
✓ Correct Fix: Neither WeakMap nor WeakSet implements .clear(). Delete entries individually with .delete(), or create a new instance.
✕ 8. Confusing map.get() === undefined with Key Absence
const m = new Map();
m.set("role", undefined);

if (m.get("role") === undefined) {
  // Misleading! The key "role" DOES exist in the map!
}
✓ Correct Fix: Always use m.has(key) to test key existence reliably: if (!m.has("role")) { ... }
✕ 9. Assuming Garbage Collection Occurs Immediately
let btn = { id: "submit" };
weakMap.set(btn, "metadata");
btn = null; // The memory is eligible for collection, but GC timing is unpredicted
✓ Correct Fix: Garbage collection runs at the JavaScript engine's discretion. Never write program logic that depends on immediate GC timing.
✕ 10. Assuming Native Set Methods are Universal Without Fallbacks
// setA.union(setB) is ES2025 - older browsers/environments throw TypeError!
setA.union(setB);
✓ Correct Fix: Use the universal spread pattern: new Set([...setA, ...setB]) for guaranteed cross-platform compatibility.

Part A: Output-Prediction Challenges

1. Set with Duplicate Integers 
const s = new Set([1, 1, 2, 3, 3, 4]);
console.log(s.size);

Predicted Output: 4

Explanation: The duplicate 1 and 3 are ignored. The set retains { 1, 2, 3, 4 }.

2. Map String vs Number Key 
const m = new Map();
m.set(5, "number");
m.set("5", "string");
console.log(m.size);

Predicted Output: 2

Explanation: Maps do not coerce keys. Number 5 and String "5" are distinct keys.

3. Map with Two Object Literals 
const m = new Map();
m.set({ id: 1 }, "User 1");
m.set({ id: 1 }, "User 2");
console.log(m.size);

Predicted Output: 2

Explanation: Each { id: 1 } is a separate object reference created in memory. Hence, two distinct keys.

4. Set.entries() Structure 
const s = new Set(["apple"]);
console.log([...s.entries()]);

Predicted Output: [ [ 'apple', 'apple' ] ]

Explanation: For consistency with Map, a Set's .entries() yields [value, value] pairs.

5. Map Method Chaining 
const m = new Map();
m.set("a", 1).set("b", 2).set("c", 3);
console.log(m.size);

Predicted Output: 3

Explanation: map.set() returns the map instance, allowing chained operations.

6. Array Deduplication via Spread 
const arr = ["x", "y", "x", "z"];
console.log([...new Set(arr)].join("-"));

Predicted Output: x-y-z

Explanation: The Set removes the second "x", and .join("-") connects the unique strings.

7. WeakMap with Primitive Key

try {
  wm.set("key", 100);
} catch (e) {
  console.log(e.name);

Explanation: WeakMap keys must be objects or non-registered symbols. Primitives throw a TypeError.

8. Checking Existence with has() vs get()

console.log(m.get("status"));
console.log(m.has("status"));

undefined

Explanation: The value stored is undefined, but .has() confirms the key is present.

Exercise 1: Word Frequency Counter

Problem: Write a function countWords(text) that returns a Map of word frequencies.

function countWords(text) {
  const map = new Map();
  const words = text.toLowerCase().split(/\s+/);
  for (const word of words) {
    if (!word) continue;
    map.set(word, (map.get(word) || 0) + 1);
  }
  return map;
}

Problem: Implement a function that returns elements in Set A or Set B, but not in both. 

function symmetricDifference(setA, setB) {
  const aMinusB = [...setA].filter(x => !setB.has(x));
  const bMinusA = [...setB].filter(x => !setA.has(x));
  return new Set([...aMinusB, ...bMinusA]);
}

Exercise 6: Two Sets Subset Check

Problem: Write a function isSubset(subset, superset) returning true if all elements of subset exist in superset.

function isSubset(subset, superset) {

  return true;
}
