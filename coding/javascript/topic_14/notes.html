DOM Manipulation

Learn how JavaScript interacts with the webpage. Select elements, update text and markup, modify CSS styles and classes, handle user clicks, listen to form events, understand event bubbling, and build dynamic applications without page reloads.

1 What Is the DOM?

When you click a button on a modern website, how does the page change its text, display a notification, or open a menu without reloading the entire window?

The answer is the DOM (Document Object Model). When a web browser loads an HTML document, it translates the raw text into a live, hierarchical tree of JavaScript objects. Every HTML tag, attribute, and text snippet becomes a node in this tree.

◆ The Document Tree Hierarchy
document
↓
<html>
↓
<head> (title, meta)
<body>
↓
<h1 id="title"> "Welcome"
<p> "Learn DOM"
<button> "Click Me"

Example 1: Initial HTML Structure

index.html — Raw Markup HTML 
<h1 id="title">Welcome to CodeVerse</h1>
<p>This is my first DOM lesson.</p>

Example 2: Selecting and Inspecting the Element with JavaScript

app.js — Accessing the DOM Tree JS 
// 1. Find the element in the document tree by its ID
const heading = document.getElementById("title");

// 2. Read the text node inside the element
console.log(heading.textContent);
console.log("Node name:", heading.nodeName);
Expected Terminal Output
Welcome to CodeVerse Node name: H1

Step-by-Step Trace: The browser parses the HTML and assigns the global document object. document.getElementById("title") traverses the tree, finds the matching <h1> node, and returns a live JavaScript DOM reference.

2 Selecting HTML Elements

Before you can read or change an element, you must select it. JavaScript provides several selector APIs:

Method Selector Syntax Return Type Behavior If Not Found
document.getElementById("id") Exact ID string without # Single Element null
document.querySelector("css") CSS selector (#id, .class, tag) First Matching Element null
document.querySelectorAll("css") CSS selector Static NodeList Empty NodeList []
document.getElementsByClassName("c") Class name without . Live HTMLCollection Empty HTMLCollection []

Example 1: Selecting by ID

document.getElementById() JS 
const title = document.getElementById("course-title");

if (title) {
  console.log("Found title:", title.textContent);
} else {
  console.log("Element with ID 'course-title' not found.");
}

Example 2: querySelector vs querySelectorAll

First Element vs. Collection of Elements JS 
// Returns ONLY the first element matching the CSS selector:
const firstMsg = document.querySelector(".message");

// Returns ALL elements matching the CSS selector as a NodeList:
const allMsgs = document.querySelectorAll(".message");

console.log("First message text:", firstMsg.textContent);
console.log("Total matching messages:", allMsgs.length);
Expected Terminal Output
First message text: First message Total matching messages: 2

4 innerHTML vs. textContent

The difference between innerHTML and textContent is critical for security:

Property How It Treats Markup Security Level Performance
textContent Inserts raw text. <b> is printed literally as characters. Safe — Prevents Cross-Site Scripting (XSS). Faster (no HTML parser needed).
innerHTML Parses strings as HTML, creating real DOM child nodes. Dangerous if combined with untrusted user input. Slower (triggers browser HTML parser).

Example 1: Safe Plain Text with textContent

Tags Render as Literal Text JS 
const output = document.querySelector("#output");
output.textContent = "<strong>Hello!</strong>";

// Rendered on screen: <strong>Hello!</strong>
console.log(output.textContent);

Example 2: Rendering Markup with innerHTML (Trusted Sources Only)

Tags Parse into Bold Node JS 
const output2 = document.querySelector("#output2");
output2.innerHTML = "<strong>Hello!</strong>";

// Rendered on screen: Hello! (in bold text)
console.log(output2.textContent);
⚠ Security Rule
Never assign user-submitted form data (like usernames, comments, or chat messages) to innerHTML. A malicious user could submit <img src="x" onerror="stealCookies()">, executing unauthorized scripts on your visitors' devices.

5 Changing CSS Styles

You can inspect or apply inline CSS styles using the element.style object.

Because JavaScript identifiers cannot contain hyphens, CSS properties written with dashes use camelCase in JavaScript:

  • background-color → style.backgroundColor
  • font-size → style.fontSize
  • border-radius → style.borderRadius

Example 1: Changing Text Color

element.style.color = "blue" JS 
const message = document.querySelector("#message");
message.style.color = "blue";

console.log("Inline color:", message.style.color);

Example 2: Modifying Multiple Styles on a Card

Applying Multiple Style Rules JS 
const card = document.querySelector("#card");

card.style.backgroundColor = "#E0F2FE";
card.style.padding = "16px";
card.style.borderRadius = "12px";

console.log("Card background:", card.style.backgroundColor);
Expected Terminal Output
Inline color: blue Card background: rgb(224, 242, 254)

6 Using classList

While element.style sets inline styles, best practices favor toggling CSS classes with classList. This separates styling rules (in CSS) from interaction logic (in JavaScript):

  • classList.add("class") — Adds one or more classes.
  • classList.remove("class") — Removes a class.
  • classList.toggle("class") — Adds the class if missing; removes it if present.
  • classList.contains("class") — Returns true if class is present, else false.

Example 1: Adding and Removing Classes

classList.add() & classList.contains() JS 
const notice = document.querySelector("#notice");

notice.classList.add("highlight");
console.log("Has highlight class?", notice.classList.contains("highlight"));

notice.classList.remove("highlight");
console.log("After removal, has class?", notice.classList.contains("highlight"));

Example 2: Toggling a Class on Click

classList.toggle() JS 
const button = document.querySelector("#toggle-button");
const target = document.querySelector("#target");

button.addEventListener("click", () => {
  target.classList.toggle("highlight");
});
Expected Terminal Output
Has highlight class? true After removal, has class? false

8 Creating and Inserting Elements

Building user interfaces dynamically requires creating new DOM elements and attaching them to the page:

  1. document.createElement("tagName") — Creates the element in memory.
  2. Set content or attributes (e.g. item.textContent = "text").
  3. parent.append(element) or parent.appendChild(element) — Mounts the element into the document tree.

Example 1: Creating a Single List Item

createElement & appendChild JS 
const list = document.querySelector("#skills");
const item = document.createElement("li");

item.textContent = "JavaScript";
list.appendChild(item);

console.log("List children count:", list.children.length);

Example 2: Generating Multiple Elements in a Loop

Iterative Element Insertion JS 
const list2 = document.querySelector("#skills2");
const skills = ["HTML", "CSS", "JavaScript"];

for (const skill of skills) {
  const li = document.createElement("li");
  li.textContent = skill;
  list2.append(li);
}

console.log("Total items added:", list2.children.length);
Expected Terminal Output
List children count: 1 Total items added: 3

9 Removing and Replacing Elements

Modern JavaScript makes cleaning up or swapping elements straightforward:

Example 1: Removing an Element with element.remove()

element.remove() JS 
const message = document.querySelector("#temporary");
const removeBtn = document.querySelector("#remove");

removeBtn.addEventListener("click", () => {
  if (message) {
    message.remove();
    console.log("Element removed from DOM.");
  }
});

Example 2: Replacing an Element with replaceWith()

element.replaceWith() JS 
const replaceBtn = document.querySelector("#replace");

replaceBtn.addEventListener("click", () => {
  const oldMsg = document.querySelector("#old-message");
  if (!oldMsg) return;

  const newMsg = document.createElement("p");
  newMsg.textContent = "New message loaded!";
  newMsg.id = "old-message";

  oldMsg.replaceWith(newMsg);
  console.log("Replaced old element with new element.");
});
Expected Terminal Output
Element removed from DOM. Replaced old element with new element.

11 The Event Object

When an event triggers, JavaScript automatically passes an Event Object (typically named event or e) into the handler function.

  • event.target — The exact innermost element that was clicked or activated.
  • event.currentTarget — The element that attached the event listener.
  • event.preventDefault() — Prevents the default browser behavior (e.g. stops form submit from reloading).

Example 1: event.target vs event.currentTarget

Target vs. CurrentTarget JS 
const actionBtn = document.querySelector("#action");

actionBtn.addEventListener("click", (event) => {
  // If user clicks the inner <span>, target is <span>
  console.log("event.target tag:", event.target.tagName);
  // currentTarget is always the <button> that owns the listener
  console.log("event.currentTarget tag:", event.currentTarget.tagName);
});

Example 2: Preventing Form Submission with preventDefault()

event.preventDefault() JS 
const searchForm = document.querySelector("#search-form");
const searchOutput = document.querySelector("#result");

searchForm.addEventListener("submit", (event) => {
  event.preventDefault(); // Stop page reload!

  const query = document.querySelector("#search").value.trim();
  searchOutput.textContent = query ? `Searching for: ${query}` : "Enter a search term.";
});
Expected Terminal Output
event.target tag: SPAN event.currentTarget tag: BUTTON Searching for: DOM Tutorials

13 Event Bubbling & Event Delegation

When an event occurs on a DOM element, it doesn't stop there. It bubbles up through all its ancestor elements to <body>, <html>, and document:

◆ Event Bubbling Phase
<button> (Target)
→ bubbles to →
<li> Parent
→ bubbles to →
<ul id="list"> (Delegated Listener)

Example 1: Observing Event Bubbling

Child to Parent Event Flow JS 
const parent = document.querySelector("#parent");
const child = document.querySelector("#child");

parent.addEventListener("click", () => {
  console.log("Parent listener executed");
});

child.addEventListener("click", () => {
  console.log("Child button clicked");
});

Example 2: Event Delegation on a Dynamic List with closest()

One Listener for Many Children JS 
const taskList = document.querySelector("#task-list");

// Attach ONE listener to the parent <ul> instead of each <button>
taskList.addEventListener("click", (event) => {
  const btn = event.target.closest("button[data-task]");
  if (!btn || !event.currentTarget.contains(btn)) return;

  console.log(`Selected task: ${btn.dataset.task}`);
});
Expected Terminal Output
Child button clicked Parent listener executed Selected task: 1

Why Event Delegation Is Powerful: If you add 50 new items to the list later with JavaScript, you do not need to attach 50 new event listeners. The single parent listener handles all clicks automatically!

14 DOM Ready & Script Placement

A frequent beginner bug is running JavaScript before the HTML elements have been created, causing document.querySelector() to return null.

Example 1: Placing Scripts at the End of the Body (Standard)

End of Body Script HTML 
<h1 id="title">CodeVerse</h1>

<!-- Placed after elements so DOM is parsed first -->
<script>
  const title = document.querySelector("#title");
  console.log(title.textContent);
</script>

Example 2: Using the DOMContentLoaded Event

DOMContentLoaded Event JS 
document.addEventListener("DOMContentLoaded", () => {
  // Safe to query elements even if script is in <head>
  const title = document.querySelector("#title");
  console.log("DOM Ready! Found:", title ? title.textContent : "Missing");
});
Expected Terminal Output
CodeVerse DOM Ready! Found: CodeVerse

16 Common Mistakes & Debugging

✕ 1. Missing the # or . in querySelector
const btn = document.querySelector("my-button"); // Looks for a <my-button> tag!
✓ Correct Fix: Use # for IDs: querySelector("#my-button") or . for classes: querySelector(".my-button").
✕ 2. Calling the Callback Immediately in addEventListener
function greet() { console.log("Hello"); }
btn.addEventListener("click", greet()); // Executes immediately on page load!
✓ Correct Fix: Pass the function reference without parentheses: btn.addEventListener("click", greet).
✕ 3. Forgetting querySelectorAll Returns a Collection, Not a Single Element
const cards = document.querySelectorAll(".card");
cards.style.color = "red"; // TypeError: Cannot set property 'color' of undefined!
✓ Correct Fix: Loop through the NodeList: cards.forEach(c => c.style.color = "red").
✕ 4. Using innerHTML with Untrusted User Input
const userInput = "<img src=x onerror=alert('hacked')>";
profile.innerHTML = userInput; // Security vulnerability!
✓ Correct Fix: Always use profile.textContent = userInput to neutralize markup.
✕ 5. Forgetting event.preventDefault() on Form Submits
form.addEventListener("submit", () => {
  // The browser refreshes the page and wipes out your JavaScript state!
});
✓ Correct Fix: Add (e) => { e.preventDefault(); ... } as the very first line.
✕ 6. Creating an Element but Forgetting to Append It
const p = document.createElement("p");
p.textContent = "Where am I?";
// The element exists in memory, but is completely invisible!
✓ Correct Fix: Attach it to a parent: document.body.append(p).
✕ 7. Reading input.value at Script Execution Instead of in Event Handler
const name = document.querySelector("#name-input").value; // Reads "" on page load!
btn.addEventListener("click", () => { console.log(name); });
✓ Correct Fix: Read input.value inside the click handler function when the user clicks.
✕ 8. Using class instead of className or classList
card.class = "active"; // Fails because 'class' is a reserved keyword in JS!
✓ Correct Fix: Use card.className = "active" or card.classList.add("active").
✕ 9. Assuming DOM Query Returns Element Without Null Check
const modal = document.querySelector("#nonexistent");
modal.style.display = "block"; // TypeError: Cannot read properties of null
✓ Correct Fix: Guard with an if check: if (modal) { modal.style.display = "block"; }
✕ 10. Forgetting to Clean Up State After Removing Elements
taskItem.remove();
// Bug: Forgot to decrement taskCounter! Display shows 5 tasks when only 4 exist
✓ Correct Fix: Update associated counter variables and empty-state displays whenever elements are removed.
