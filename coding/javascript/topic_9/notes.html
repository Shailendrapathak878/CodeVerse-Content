JavaScript Foundations • Topic 9

Arrays & Data Collections

Master ordered collections in JavaScript. Learn how to store, access, and mutate lists with zero-based indexing, navigate common methods like push, pop, slice, and splice, transform arrays with map and filter, and manage data references.

1 What Is an Array?

If you want to store the names of 50 students in your class, would you create 50 separate variables like student1, student2, ..., student50?

Writing 50 separate variables would be exhausting and impractical. An Array is an ordered, numbered collection of values stored inside a single variable container.

💡 Real-Life Analogy: The Numbered Locker Row
Think of an array like a row of school lockers side by side. Instead of scattering your belongings across the school, you have a single row called students, and each locker door has a specific number printed on it where a student's information lives.
◆ Conceptual Representation of an Array
Index 0 "Aarav"
Index 1 "Priya"
Index 2 "Rohan"

Example 1: Separate Variables vs. A Clean Array

Comparing Individual Bindings with an Array JS 
// Clunky: 3 separate variables
const student1 = "Aarav";
const student2 = "Priya";
const student3 = "Rohan";

// Clean: One single array holding all 3 values
const students = ["Aarav", "Priya", "Rohan"];

console.log(students);
Expected Terminal Output
[ 'Aarav', 'Priya', 'Rohan' ]

Step-by-Step Trace: Rather than declaring and tracking separate variable names, the array groups related items under students, allowing us to pass, loop, and sort the entire collection as a single unit.

Example 2: Arrays with Mixed Data Types

Flexibility of JavaScript Array Values JS 
// JavaScript arrays can hold strings, numbers, booleans, and more!
const studentInfo = ["Aarav", 20, true];

console.log("Name:", studentInfo[0]);
console.log("Age:", studentInfo[1]);
console.log("Enrolled:", studentInfo[2]);
Expected Terminal Output
Name: Aarav Age: 20 Enrolled: true

Step-by-Step Trace: Index 0 stores a string, index 1 stores a number, and index 2 stores a boolean. While grouping consistent types is standard practice, JavaScript gives you the flexibility to store any type.

2 Creating Arrays and Understanding Indexes

The most common way to create an array is with array literal syntax using square brackets [].

JavaScript uses zero-based indexing. This means the very first element is at index 0, the second element is at index 1, and the third is at index 2.

◆ Zero-Based Index Map
[ 0 ] First "Apple"
[ 1 ] Second "Banana"
[ 2 ] Third "Mango"

Example 1: Reading Array Elements by Index

Accessing Values with Square Brackets JS 
const fruits = ["Apple", "Banana", "Mango"];

console.log("fruits[0]:", fruits[0]);
console.log("fruits[1]:", fruits[1]);
console.log("fruits[2]:", fruits[2]);
Expected Terminal Output
fruits[0]: Apple fruits[1]: Banana fruits[2]: Mango

Example 2: Accessing an Out-of-Bounds Index

Missing Index Returns undefined JS 
const colors = ["Red", "Green", "Blue"];

// Valid index
console.log("colors[1]:", colors[1]);

// Index 5 does not exist!
console.log("colors[5]:", colors[5]);
Expected Terminal Output
colors[1]: Green colors[5]: undefined

Step-by-Step Trace: In JavaScript, accessing an index that doesn't exist does not crash your program or throw an error. It safely returns undefined.

3 The length Property

Every JavaScript array has a built-in property called .length that returns the total count of elements inside the array.

  • Count vs. Last Index: Because indexing starts at 0, the last valid index in a normal dense array is always length - 1.
  • Empty Array: An array with no elements has a length of 0.
  • Dynamic Updates: The length property automatically updates whenever elements are added or removed.
◆ Array Length vs Last Valid Index
Index 0 "Dog"
Index 1 "Cat"
Index 2 (length - 1) "Rabbit"

Total elements (length): 3 • Last accessible index: 2

Example 1: Reading Length and Accessing the Last Element

Using length - 1 for the Last Element JS 
const animals = ["Dog", "Cat", "Rabbit"];

console.log("Total animal count:", animals.length);
console.log("Last animal:", animals[animals.length - 1]);
Expected Terminal Output
Total animal count: 3 Last animal: Rabbit

Example 2: Empty Array and Changing Length

Dynamic Length Growth JS 
const numbers = [];
console.log("Initial length:", numbers.length);

numbers.push(10);
numbers.push(20);
console.log("Length after 2 pushes:", numbers.length);
Expected Terminal Output
Initial length: 0 Length after 2 pushes: 2

4 Reading and Updating Array Elements

Array elements can be replaced at any time using direct index assignment: array[index] = newValue.

🔒 const Arrays Can Still Be Modified!
Declaring an array with const prevents you from reassigning the variable (e.g., scores = [1, 2] is illegal). However, the contents inside the array are completely mutable! You can update, add, or delete elements freely.
◆ In-Place Element Update
Before
["Apple", "Banana", "Mango"]
→ fruits[1] = "Orange" →
After
["Apple", "Orange", "Mango"]

Example 1: Updating an Existing Element

Direct Index Assignment JS 
const fruits = ["Apple", "Banana", "Mango"];

// Replace "Banana" at index 1 with "Orange"
fruits[1] = "Orange";

console.log(fruits);
Expected Terminal Output
[ 'Apple', 'Orange', 'Mango' ]

Example 2: Updating an Element in a const Array

Mutating Array Contents Under const JS 
const scores = [70, 80, 90];

// Allowed: Modifying index 0
scores[0] = 95;
console.log("Updated scores:", scores);

// NOT allowed (reassigning the variable):
// scores = [100, 100]; // TypeError: Assignment to constant variable.
Expected Terminal Output
Updated scores: [ 95, 80, 90 ]

5 Adding and Removing Elements: push, pop, unshift, shift

JavaScript provides four foundational methods to add and remove items at either end of an array:

Method Operates On Action Return Value Mutates Original?
push(item) End Appends element(s) New length Yes
pop() End Removes last element Removed item Yes
unshift(item) Start Prepends element(s) New length Yes
shift() Start Removes first element Removed item Yes

Example 1: push() and pop() at the End

Adding and Removing at the End JS 
const cart = ["Book", "Pen"];

// 1. push() adds to the end
cart.push("Notebook");
console.log("After push:", cart);

// 2. pop() removes and returns the last item
const removedItem = cart.pop();
console.log("Popped:", removedItem);
console.log("Remaining in cart:", cart);
Expected Terminal Output
After push: [ 'Book', 'Pen', 'Notebook' ] Popped: Notebook Remaining in cart: [ 'Book', 'Pen' ]

Example 2: unshift() and shift() at the Beginning

Queue Operations with unshift and shift JS 
const queue = ["Priya", "Rohan"];

// 1. unshift() adds to the very front
queue.unshift("Aarav");
console.log("After unshift:", queue);

// 2. shift() removes the first person at index 0
const servedPerson = queue.shift();
console.log("Served:", servedPerson);
console.log("Queue remaining:", queue);
Expected Terminal Output
After unshift: [ 'Aarav', 'Priya', 'Rohan' ] Served: Aarav Queue remaining: [ 'Priya', 'Rohan' ]

6 Searching Arrays: includes and indexOf

To find out whether an array contains an item, JavaScript provides two straightforward methods:

  • includes(val): Returns true if the value exists in the array, otherwise false.
  • indexOf(val): Returns the index of the first matching element, or -1 if not found.

Example 1: Checking Membership with includes()

Testing if an Element Exists JS 
const languages = ["JavaScript", "Python", "Java"];

console.log("Has Python?", languages.includes("Python"));
console.log("Has C++?", languages.includes("C++"));
Expected Terminal Output
Has Python? true Has C++? false

Example 2: Finding Position with indexOf()

Locating Indices and Handling -1 JS 
const scores = [60, 75, 90, 75];

// Returns 1 (the FIRST occurrence)
console.log("Index of 75:", scores.indexOf(75));

// 100 is not in the array, returns -1
console.log("Index of 100:", scores.indexOf(100));
Expected Terminal Output
Index of 75: 1 Index of 100: -1

7 slice() vs splice(): Safe Extraction vs In-Place Mutation

Beginners often confuse slice() and splice() because of their similar names. However, they serve completely opposite purposes:

Feature slice(start, end) splice(start, deleteCount, ...items)
Purpose Extracts a portion into a new array Removes, inserts, or replaces elements in place
Mutates Original? NO (Safe shallow copy) YES (Mutates original array)
End Parameter End index (excluded) Number of elements to delete
Return Value Extracted slice Array of deleted elements

Example 1: slice() Extracts Safely Without Modifying the Original

Non-Destructive Slicing JS 
const numbers = [10, 20, 30, 40, 50];

// Extracts from index 1 up to (but not including) index 4
const selected = numbers.slice(1, 4);

console.log("Selected slice:", selected);
console.log("Original remains unchanged:", numbers);
Expected Terminal Output
Selected slice: [ 20, 30, 40 ] Original remains unchanged: [ 10, 20, 30, 40, 50 ]

Example 2: splice() Deletes Elements and Mutates the Original

Destructive Mutation with splice JS 
const numbers = [10, 20, 30, 40, 50];

// At index 1, remove 2 elements (20 and 30)
const removed = numbers.splice(1, 2);

console.log("Removed elements:", removed);
console.log("Original numbers mutated:", numbers);
Expected Terminal Output
Removed elements: [ 20, 30 ] Original numbers mutated: [ 10, 40, 50 ]

Example 3: Inserting Elements Without Deleting Using splice()

Inserting In-Place JS 
const items = ["A", "D"];

// At index 1, delete 0 elements, insert "B" and "C"
items.splice(1, 0, "B", "C");
console.log("Items after insertion:", items);
Expected Terminal Output
Items after insertion: [ 'A', 'B', 'C', 'D' ]

9 Transforming Arrays with map()

The map() method creates a brand-new array populated with the results of calling a provided function on every element in the calling array.

map() does not change the original array. Whatever you return inside the callback becomes the new value for that position.

◆ map() Transformation Pipeline
Input Array
[ 1, 2, 3, 4 ]
→ n => n * 2 →
New Mapped Array
[ 2, 4, 6, 8 ]

Example 1: Doubling Numbers

Transforming Numeric Elements JS 
const numbers = [1, 2, 3, 4];
const doubled = numbers.map(number => number * 2);

console.log("Doubled:", doubled);
console.log("Original intact:", numbers);
Expected Terminal Output
Doubled: [ 2, 4, 6, 8 ] Original intact: [ 1, 2, 3, 4 ]

Example 2: Capitalizing Names

String Formatting with map JS 
const names = ["aarav", "priya", "rohan"];
const capitalized = names.map(name => name[0].toUpperCase() + name.slice(1));

console.log("Capitalized:", capitalized);
Expected Terminal Output
Capitalized: [ 'Aarav', 'Priya', 'Rohan' ]

10 Selecting Elements with filter()

The filter() method evaluates every element against a condition function. If the callback returns true (or truthy), that element is kept in the new array. If it returns false, it is filtered out.

Example 1: Filtering Even Numbers

Condition-Based Extraction JS 
const numbers = [1, 2, 3, 4, 5, 6];
const evenNumbers = numbers.filter(num => num % 2 === 0);

console.log("Even numbers:", evenNumbers);
Expected Terminal Output
Even numbers: [ 2, 4, 6 ]

Example 2: Filtering Passing Exam Marks

Filtering with Threshold Values JS 
const marks = [35, 72, 48, 90, 65];
const passingMarks = marks.filter(m => m >= 40);

console.log("Passing scores:", passingMarks);
Expected Terminal Output
Passing scores: [ 72, 48, 90, 65 ]

11 Finding One Element with find()

While filter() collects all matching elements into an array, find() stops searching immediately after encountering the first element that satisfies the condition and returns that single item directly.

If no element matches, find() returns undefined.

Feature filter() find()
Matches Returned All matches First match only
Return Type Array [ ... ] Single value / object (or undefined)
When Nothing Matches Returns empty array [] Returns undefined

Example 1: Finding the First Number Greater Than 15

Stopping at the First Match JS 
const numbers = [5, 12, 18, 25];
const firstBig = numbers.find(n => n > 15);

console.log("First match:", firstBig);
Expected Terminal Output
First match: 18

Example 2: Finding an Object in an Array

Finding Student with Top Score JS 
const students = [
  { name: "Aarav", marks: 72 },
  { name: "Priya", marks: 91 },
  { name: "Rohan", marks: 84 }
];

const topper = students.find(s => s.marks > 90);
console.log("Topper found:", topper);
Expected Terminal Output
Topper found: { name: 'Priya', marks: 91 }

12 Array References and Copying

In JavaScript, primitive values (like numbers and strings) are copied by value. Arrays, however, are Reference Types.

When you assign an array variable to another variable (e.g. const second = first), you do not create a new array. Both variables hold a memory address pointing to the exact same array in memory!

Example 1: Accidental Shared Mutation

Both Variables Point to Same Array JS 
const first = [10, 20, 30];
const second = first; // Copies reference address, NOT array contents

second.push(40);

// Mutating 'second' also mutated 'first'!
console.log("first:", first);
console.log("second:", second);
Expected Terminal Output
first: [ 10, 20, 30, 40 ] second: [ 10, 20, 30, 40 ]

Example 2: Creating a Real Shallow Copy with the Spread Operator

Independent Array Copy JS 
const original = [10, 20, 30];
// Spread syntax [...original] creates an independent clone
const copy = [...original];

copy.push(40);

console.log("original:", original);
console.log("copy:", copy);
Expected Terminal Output
original: [ 10, 20, 30 ] copy: [ 10, 20, 30, 40 ]

14 Common Array Mistakes and Debugging

Here are 10 common mistakes beginners make with arrays, along with clear fixes and actual outputs:

✖ 1. Using array.length as the Last Index (Off-by-One)
const items = ["A", "B", "C"];
console.log(items[items.length]); // undefined!
✔ Correct Fix: Use items.length - 1
console.log(items[items.length - 1]); // "C"
✖ 2. Accidental Mutation Using splice() Instead of slice()
const nums = [1, 2, 3];
const sub = nums.splice(0, 2); // Mutates nums in place!
✔ Correct Fix: Use slice() for safe non-destructive extraction
const sub = nums.slice(0, 2); // nums remains [1, 2, 3]
✖ 3. Expecting map() to Mutate in Place
const nums = [1, 2, 3];
nums.map(n => n * 2);
console.log(nums); // Still [1, 2, 3]!
✔ Correct Fix: Assign the returned new array to a variable
const doubled = nums.map(n => n * 2); // [2, 4, 6]
✖ 4. Forgetting return in a Curly-Brace map() Callback
const result = nums.map(n => { n * 2; }); // [undefined, undefined, undefined]
✔ Correct Fix: Add return, or use concise body without braces
const result = nums.map(n => n * 2);
✖ 5. Confusing find() and filter() Return Types
const firstEven = nums.filter(n => n % 2 === 0); // Returns array [2], not a single number!
✔ Correct Fix: Use find() when you want just the single item
const firstEven = nums.find(n => n % 2 === 0); // 2
✖ 6. Assuming Variable Assignment Creates a Copy
const b = a; b.push(99); // Mutates both a and b because they share one reference!
✔ Correct Fix: Clone using spread operator [...a]
const b = [...a]; b.push(99); // 'a' remains untouched
✖ 7. Checking Array Equality with ===
console.log([1, 2] === [1, 2]); // false! Compares memory references, not values!
✔ Correct Fix: Compare elements individually or check lengths and values
const isEqual = a.length === b.length && a.every((val, i) => val === b[i]);
✖ 8. Expecting break to Work in forEach()
nums.forEach(n => { if (n === 2) break; }); // SyntaxError: Illegal break statement
✔ Correct Fix: Use a standard for or for...of loop if you need early termination
for (const n of nums) { if (n === 2) break; }
✖ 9. Thinking const Prevents Element Modification
const arr = [1]; arr.push(2); // Works! const only locks the variable binding, not items.
✔ Correct Fix: Use Object.freeze(arr) if you need true element immutability
✖ 10. Modifying an Array While Iterating With Index
for (let i = 0; i < arr.length; i++) { arr.shift(); } // Skips items due to shifting indices!
✔ Correct Fix: Iterate over a shallow copy or iterate backwards

Exercise 6: Flatten a 2D Matrix ▾ View Solution

Goal: Convert a 2D array of rows into a single flat array using nested loops.

function flattenGrid(grid) {
  const flat = [];
  for (const row of grid) {
    for (const item of row) {
      flat.push(item);
    }
  }
  return flat;
}
console.log(flattenGrid([[1, 2], [3, 4], [5, 6]])); // [ 1, 2, 3, 4, 5, 6 ]

Challenge 1: Fix the Mutation Bug in High Score Tracker ▾ View Solution

Broken Code:

function saveScore(allScores, newScore) {
  const updated = allScores;
  updated.push(newScore);
  return updated;
}
// Bug: allScores is accidentally modified outside!

function saveScore(allScores, newScore) {
  return [...allScores, newScore];

console.log(scores);                // [ 80, 90 ] (Untouched!)
