JavaScript Foundations • Topic 6

Loops and Iterations

Master programmatic repetition in JavaScript. Discover how loops eliminate duplicate code, explore the complete lifecycle of for, while, and do...while, control execution with break and continue, traverse arrays and objects, and avoid common infinite-loop pitfalls.

1 The Repetition Problem

Imagine your manager asks you to print "I love JavaScript" exactly 100 times to the developer console. Would you sit down and handwrite 100 separate console.log() statements?

Writing statements manually is exhausting, prone to copy-paste mistakes, and impossible to adjust when requirements change. If your team decides to change the text to "I love CodeVerse", you would have to edit 100 lines by hand.

The Tedious Approach vs The Loop JS 
// ❌ Repetitive, hard to maintain, and prone to typing errors
console.log("I love JavaScript");
console.log("I love JavaScript");
console.log("I love JavaScript");
// ... 97 more manual lines!

// ✔ The Elegant Loop Approach (3 lines of clean code)
for (let count = 1; count <= 100; count++) {
  console.log("I love JavaScript");
}

In computer programming, repetition refers to performing the same block of instructions multiple times. A loop is a control structure designed to automate this repetition until a specific exit condition is fulfilled.

Each single pass through the body of a loop is termed an iteration. Loops dramatically compress code volume, eradicate copy-paste defects, and allow software to process dynamically sized data collections effortlessly.

◆ Real-Life Analogy: Completing 5 Push-Ups
Start
Initialize push-up counter to 1 → Goal: complete 5 repetitions.
Rep 1-4
Perform push-up → Check: Reached 5? No → Count up and repeat motion!
Rep 5
Perform 5th push-up → Check: Reached 5? Yes → Workout set complete!

2 How a Loop Works (The Lifecycle)

Every standard loop in JavaScript follows a dependable 4-phase lifecycle: Initialize → Check Condition → Execute Body → Update → Check Again.

Understanding this order is critical. The initialization runs once at the very start. The condition is tested before every single pass. The body only executes if the condition is true. The update happens right after the body finishes, preparing the variable for the next evaluation.

◆ The Universal Loop Lifecycle
1. Init
Initialization: Set up your loop counter variable (e.g., let i = 1). Runs strictly once at the start.
2. Test
Condition Check: Test if the condition evaluates to true (e.g., i <= 5). If false, stop immediately.
3. Run
Execute Body: Execute statements enclosed within curly braces { ... }.
4. Update
Update Expression: Modify the counter (e.g., i++), then jump directly back to Step 2.
Fundamental Loop Example JS 
for (let i = 1; i <= 5; i++) {
  console.log(i);
}
Expected Terminal Output
1
2
3
4
5

Notice how the variable progresses through each iteration in this precise execution trace:

Iteration Counter (i) Condition (i <= 5) Action / Output Next Step
1 1 1 <= 5 → true Prints 1 i++ becomes 2
2 2 2 <= 5 → true Prints 2 i++ becomes 3
3 3 3 <= 5 → true Prints 3 i++ becomes 4
4 4 4 <= 5 → true Prints 4 i++ becomes 5
5 5 5 <= 5 → true Prints 5 i++ becomes 6
Stop check 6 6 <= 5 → false No output Loop terminates immediately

3 The for Loop

The for loop is the most widely used loop when you know in advance how many times an operation should occur. Its header neatly bundles the three control expressions separated by semicolons:

🔍 Anatomy of a For Statement
for ([initialization]; [condition]; [update]) { ... }
  • Initialization: Declares and sets starting state (runs once).
  • Condition: Evaluated before every iteration. If true, the body runs.
  • Update: Executes after every iteration body to advance the counter.

Pattern 1: Counting from 1 to 10

This classic pattern initializes a counter at 1 and continues incrementing by 1 until it exceeds 10:

Counting 1 to 10 JS 
for (let i = 1; i <= 10; i++) {
  console.log(i);
}

Pattern 2: Counting Backwards

To count down, start at your upper value, check that the counter remains greater than or equal to the minimum, and decrement using i--:

Countdown 5 to 1 JS 
for (let i = 5; i >= 1; i--) {
  console.log(i);
}
Expected Output
5
4
3
2
1

Pattern 3: Stepping by 2 (Even Numbers)

You are not limited to i++. You can step by any interval using compound assignment such as i += 2:

Even Numbers 2 to 10 JS 
for (let i = 2; i <= 10; i += 2) {
  console.log(i);
}

Pattern 4: Accumulating a Sum (1 to 10)

The accumulator pattern initializes a running total variable outside the loop and adds each counter value during every pass:

Sum Accumulator JS 
let sum = 0;
for (let i = 1; i <= 10; i++) {
  sum += i;
}
console.log("Total sum:", sum);
Expected Output
Total sum: 55

Pattern 5: Generating a Multiplication Table

Table of 5 JS 
const multiplier = 5;
for (let i = 1; i <= 5; i++) {
  console.log(`${multiplier} x ${i} = ${multiplier * i}`);
}
Expected Output
5 x 1 = 5
5 x 2 = 10
5 x 3 = 15
5 x 4 = 20
5 x 5 = 25

4 The while Loop

Use a while loop when you want to repeat an action while a condition remains true, but the number of required iterations is not known beforehand (such as reading user inputs, listening for network packets, or waiting for a game event).

Basic While Loop JS 
let count = 1;

while (count <= 5) {
  console.log(count);
  count++; // Crucial: update state to avoid infinite loop!
}
Expected Output
1
2
3
4
5

Notice how the while loop checks its test expression before each pass. If count began at 10, the condition 10 <= 5 would be false immediately, and the loop body would never execute.

⚠ Caution: The Infinite Loop Danger
In a while loop, if you forget to increment your counter (count++), the condition 1 <= 5 will permanently stay true. The browser or terminal will freeze, consuming 100% CPU until forcefully closed.

5 The do...while Loop

The key distinction of do...while is that the loop body always executes at least once before the condition is ever checked. This is called a post-test loop, making it ideal for menu prompts, interactive CLI questions, and dice rolls.

Condition Initially True JS 
let num = 1;
do {
  console.log("Num:", num);
  num++;
} while (num <= 3);
Expected Output
Num: 1
Num: 2
Num: 3

Now observe what happens when the condition is initially false:

Condition Initially False (Runs Once!) JS 
let x = 10;
do {
  console.log("Runs once even though condition is false: " + x);
  x++;
} while (x < 5);
Expected Output
Runs once even though condition is false: 10
Feature for Loop while Loop do...while Loop
Condition Check Before body Before body After body
Minimum Runs 0 times 0 times At least 1 time
Best Used For Known count / arrays Unknown count / flags User input / menus

6 Loop Control: break & continue

JavaScript provides two special control flow statements to alter loop progression on demand:

  • break: Abruptly and completely terminates the loop, jumping to the first line following the closing brace. Think of it like pulling the emergency brake on a train.
  • continue: Skips the remaining lines in the current iteration and proceeds directly to the next iteration. Think of it like skipping one unwanted song in a music playlist.
Using break to Stop at 5 JS 
for (let i = 1; i <= 10; i++) {
  if (i === 5) {
    break; // Exits immediately when i is 5
  }
  console.log(i);
}
Expected Output (Stops before printing 5)
1
2
3
4
Using continue to Skip 3 JS 
for (let i = 1; i <= 5; i++) {
  if (i === 3) {
    continue; // Skips printing 3, advances to i = 4
  }
  console.log(i);
}
Expected Output (Notice 3 is omitted)
1
2
4
5
💡 Critical While Loop Difference
When using continue inside a while loop, make sure you manually increment your counter variable before calling continue! Otherwise, the counter will never advance, causing an infinite loop.

7 Looping Through Collections

In modern JavaScript, loops are constantly used to read and process arrays and objects:

Arrays are ordered lists with zero-indexed positions. Objects are collections of named key-value pairs. Selecting the right loop structure ensures clean, readable, and bug-free traversal.

Method 1: Traditional Indexed for Loop

Array with Index JS 
const fruits = ["Apple", "Banana", "Cherry"];
for (let i = 0; i < fruits.length; i++) {
  console.log(`${i}: ${fruits[i]}`);
}
Expected Output
0: Apple
1: Banana
2: Cherry

Method 2: for...of (For Iterable Values)

Direct Values with for...of JS 
for (const fruit of fruits) {
  console.log(fruit);
}

Method 3: for...in (For Object Keys)

Object Properties with for...in JS 
const user = { name: "Priya", role: "Engineer", city: "Bengaluru" };
for (const key in user) {
  console.log(`${key}: ${user[key]}`);
}
Expected Output
name: Priya
role: Engineer
city: Bengaluru
Loop Type Iterates Over Typical Target Caution
for Numerical indices Arrays, Strings Off-by-one boundary bugs
for...of Element values Arrays, Strings, Sets Does not work directly on plain objects
for...in Enumerable keys Plain Objects Avoid for arrays (keys are strings, includes prototypes)

8 Nested Loops and Patterns

A nested loop is simply a loop located inside another loop. For every single iteration of the outer loop, the inner loop executes its full cycle from start to finish.

Think of a clock: the hour hand represents the outer loop, while the minute hand represents the inner loop. The minute hand must complete 60 full ticks before the hour hand advances by just one step.

3x3 Star Grid Pattern JS 
for (let row = 1; row <= 3; row++) {
  let line = "";
  for (let col = 1; col <= 3; col++) {
    line += "* ";
  }
  console.log(line.trim());
}
Expected Output
* * *
* * *
* * *
◆ Inner vs Outer Progression
Row 1
Outer row = 1 → Inner runs col = 1, 2, 3 → Prints * * *
Row 2
Outer row = 2 → Inner resets & runs col = 1, 2, 3 → Prints * * *
Row 3
Outer row = 3 → Inner resets & runs col = 1, 2, 3 → Prints * * *

9 Common Bugs & Debugging

Writing loops is straightforward, but subtle boundary and variable bugs are common for beginners. Review these classic pitfalls to debug your code like an experienced developer:

❌ Bug 1: Missing Counter Update (Infinite Loop)
let i = 1; while (i <= 5) { console.log(i); } never increments i.
✔ Fix: Always update state in the body: i++;.
❌ Bug 2: Off-By-One Boundary Error
Writing for (let i = 0; i <= arr.length; i++) visits an undefined index at the end.
✔ Fix: Use strict less-than: i < arr.length.
❌ Bug 3: Inverted Condition Never Executing
Writing for (let i = 1; i > 5; i++) starts with 1 > 5 (false), so body never runs.
✔ Fix: Check condition direction: i <= 5.
❌ Bug 4: continue Before Increment in While
Calling continue before incrementing keeps the counter stuck on the same number forever.
✔ Fix: Increment the counter variable prior to invoking continue.
❌ Bug 5: Re-Declaring Counter with var
Using var i inside nested loops shares the same variable across both loops, causing early exit.
✔ Fix: Always use block-scoped let for loop variables.
❌ Bug 6: Confusion Between i++ and ++i in Expressions
Writing let val = i++; assigns the old value before incrementing, leading to off-by-one results.
✔ Fix: Keep the increment on its own line or use ++i if immediate update is required.
❌ Bug 7: Accidentally Skipping Values With Duplicate Increments
Placing i++ in the loop body while also incrementing in the header steps forward twice per pass.
✔ Fix: Increment in only one place: either in the header or in the body.

11 Mini Project: Number Pattern & Calculator

This practical mini project combines loops with conditional filters to print a range, calculate the sum, extract even numbers, and generate multiplication tables:

Range Calculator & Table Generator JS 
const start = 1;
const end = 5;
const factor = 7;

// 1. Range & Sum Calculation
let totalSum = 0;
const evens = [];

for (let i = start; i <= end; i++) {
  totalSum += i;
  if (i % 2 === 0) {
    evens.push(i);
  }
}

console.log("Total Sum:", totalSum);
console.log("Even Numbers:", evens.join(", "));

// 2. Multiplication Table
console.log(`--- Table of ${factor} ---`);
for (let i = 1; i <= 5; i++) {
  console.log(`${factor} x ${i} = ${factor * i}`);
}
Verified Console Output
Total Sum: 15
Even Numbers: 2, 4
--- Table of 7 ---
7 x 1 = 7
7 x 2 = 14
7 x 3 = 21
7 x 4 = 28
7 x 5 = 35

Part D: Quick Revision Summary

1. for vs while Use for when count is predetermined. Use while when repeating until a dynamic condition shifts.
2. Guaranteed do...while A do...while body executes at least once even if the condition is false from the start.
3. break vs continue break exits the loop completely; continue jumps directly to the next iteration.
4. for...of vs for...in Use for...of for array values; use for...in for object keys.
