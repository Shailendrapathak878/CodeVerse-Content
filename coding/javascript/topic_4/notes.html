Discover how JavaScript manipulates data, performs calculations, evaluates logical conditions, and controls program flow. Master arithmetic, assignment, comparison, truth tables, and short-circuit evaluation.

1 Welcome to Operators & Expressions

Every interactive software application relies on computing new information from existing data. An e-commerce store calculates the subtotal by multiplying item prices by quantities. A fitness tracker measures daily step progress toward a target. A video game computes character health after taking damage.

In JavaScript, these actions are performed using three fundamental building blocks:

  • Operator: A specialized language symbol (such as +, -, or *) that instructs the engine to perform a specific mathematical, comparison, or logical operation.
  • Operand: The values, literals, or variables on which an operator acts. In the calculation 100 * 3, both 100 and 3 are operands.
  • Expression: Any combination of literals, variables, and operators that evaluates down to a single resulting value. In modern JavaScript, expressions can be simple (5 + 2) or complex nested formulas.

Operator: *

Shopping Cart Calculation JS

console.log(total);

💡 Remainder (%) is Not a Percentage
The modulo operator % gives the integer remainder after division. For example, 10 % 3 is 1 because 3 goes into 10 three times with 1 left over. Programmers frequently use num % 2 to test if a number is even (remainder 0) or odd (remainder 1).

4 Increment & Decrement: Postfix vs Prefix

The increment (++) and decrement (--) operators add or subtract exactly 1 from a variable. While straightforward on their own, their placement matters when used inside expressions:

Basic Increment and Decrement JS 
let count = 5;

count++; // Adds 1 -> count is 6
console.log(count);

count--; // Subtracts 1 -> count is 5
console.log(count);
Expected Output
6
5
◆ Visual 3: Postfix vs Prefix Timeline
Postfix (a++)

1. Returns the current value to the expression first (5).
2. Updates the variable in memory to 6 afterward.

Prefix (++b)

1. Updates the variable in memory to 6 first.
2. Returns the newly updated value (6) to the expression.

Postfix vs Prefix Code Execution JS 
// Postfix Example
let a = 5;
console.log(a++); // Prints 5 (evaluates first, then increments)
console.log(a);   // Prints 6

// Prefix Example
let b = 5;
console.log(++b); // Prints 6 (increments first, then evaluates)
console.log(b);   // Prints 6
Expected Output
5
6
6
6

5 Comparison Operators: Strict vs Loose

Comparison operators test two values and evaluate to a Boolean: true or false.

Relational Comparisons JS 
console.log(10 > 5);   // true
console.log(10 < 5);   // false
console.log(10 >= 10); // true
console.log(5 <= 3);   // false
console.log(5 === 5);  // true
console.log(5 !== 3);  // true
Expected Output
true
false
true
false

⚠ Strict (===) vs Loose (==) Equality

Always prefer strict equality (=== and !==).

  • === checks both value AND data type without converting operands.
  • == performs automatic type coercion before comparing, which can trigger unexpected bugs.
Strict vs Loose Equality Comparison JS 
console.log(5 === "5"); // false (Number !== String)
console.log(5 == "5");  // true (Loose: "5" coerced to 5)
Expected Output
false
true

6 Logical Operators: AND, OR, and NOT

Logical operators combine or invert Boolean conditions to create powerful decision rules:

Student Eligibility Check JS 
const marks = 85;
const submittedAssignment = true;

// AND (&&): Both conditions must be true
console.log(marks >= 40 && submittedAssignment);

// OR (||): At least one condition must be true
console.log(marks >= 90 || submittedAssignment);

// NOT (!): Inverts true to false or false to true
console.log(!submittedAssignment);

7 String Concatenation & Type Coercion

The + operator behaves differently depending on operand data types:

  • When both operands are numbers, + performs arithmetic addition.
  • When either operand is a string, + performs string concatenation.
  • Arithmetic operators like -, *, and / always coerce strings into numbers.
Concatenation vs Coercion JS 
console.log(5 + 3);                 // 8 (Addition)
console.log("Hello " + "CodeVerse"); // "Hello CodeVerse" (Concatenation)
console.log("5" + 2);               // "52" (Coerced to string)
console.log("5" - 2);               // 3 (Coerced to number)
Expected Output
8
Hello CodeVerse
52
3

8 The Ternary Operator: Inline Conditions

The ternary operator is a concise, inline shorthand for choosing between two values based on a single condition:

condition ? valueIfTrue : valueIfFalse
Ternary Expressions in Action JS 
const marks = 75;
const result = marks >= 40 ? "Pass" : "Fail";
console.log(result);

const age = 20;
const access = age >= 18 ? "Granted" : "Denied";
console.log(access);
Expected Output
Pass
Granted

Ternary expressions are best kept simple. If you find yourself nesting multiple ternary checks, an if...else block is much easier to read and maintain.

9 Operator Precedence & Parentheses

JavaScript evaluates operators according to established precedence rules, not simply left-to-right. Multiplication and division carry higher precedence than addition and subtraction:

Controlling Evaluation Order JS 
console.log(2 + 3 * 4);   // 14 (3 * 4 = 12, then 2 + 12 = 14)
console.log((2 + 3) * 4); // 20 (Parentheses evaluate first: 5 * 4 = 20)
Expected Output
14
20
💡 Best Practice: Use Parentheses for Clarity
Even when you know the precedence rules by heart, wrapping sub-expressions in parentheses makes your intention crystal clear to anyone reading your code.

10 Short-Circuit Evaluation with && and ||

In JavaScript, logical operators evaluate from left to right and short-circuit (stop early) as soon as the outcome is determined. They return the actual operand value, not just a Boolean:

  • && (AND): Stops at the first falsy value and returns it. If all are truthy, it returns the last operand.
  • || (OR): Stops at the first truthy value and returns it. If all are falsy, it returns the last operand.
Short-Circuit Code Examples JS 
console.log(false && "Hello");     // false (stops at first falsy)
console.log(true || "Hello");       // true (stops at first truthy)
console.log(true && "CodeVerse");   // "CodeVerse" (all truthy, returns last)
console.log(false || "CodeVerse");  // "CodeVerse" (first was falsy, returns second)
Expected Output
false
true

11 Common Beginner Mistakes & Fixes

❌ Mistake 1: Using = Instead of ===
Writing if (score = 100) accidentally overwrites the variable instead of checking equality.
✔ Fix: Use === for comparison and = only for assignment.
❌ Mistake 2: Confusing Loose (==) with Strict (===)
0 == "" evaluates to true due to unexpected coercion.
✔ Fix: Use strict equality 0 === "" which correctly yields false.
❌ Mistake 3: Assuming % Calculates Percentage
Writing 100 % 10 gives 0 (remainder), not 10.
✔ Fix: For percentage, multiply by the decimal: 100 * 0.10.
❌ Mistake 4: Accidental String Concatenation
Adding "10" + 5 produces "105" instead of 15.
✔ Fix: Convert strings to numbers first: Number("10") + 5.
❌ Mistake 5: Misunderstanding Postfix vs Prefix
Expecting let a = 5; let b = a++; to set b to 6.
✔ Fix: Use ++a if you need the incremented value immediately.
❌ Mistake 6: Neglecting Operator Precedence
Writing 10 + 20 / 2 gives 20 instead of 15.
✔ Fix: Use parentheses to enforce order: (10 + 20) / 2.
❌ Mistake 7: Expecting && and || to Always Return Booleans
"User" && "Admin" evaluates to "Admin", not true.
✔ Fix: Remember that logical operators return operand values.
❌ Mistake 8: Writing Deeply Nested Ternary Statements
Writing unreadable multi-level ternary expressions creates bugs and confusion.
✔ Fix: Use clear if...else structures for complex branching.

12 Hands-On Lab: Student Result Calculator

Apply all your operator skills in this hands-on project that computes totals, calculates averages, validates assignment completion, and assigns a readiness status:

★ Lab Instructions
  1. Define marks for math (80), science (70), and english (90).
  2. Calculate total using addition (+).
  3. Calculate average by dividing total by 3.
  4. Determine if the student passed (average at least 40).
  5. Use a logical AND (&&) with assignmentSubmitted in a ternary expression to set status.
✔ Complete Solution 
const math = 80;
const science = 70;
const english = 90;

const total = math + science + english;
const average = total / 3;

const assignmentSubmitted = true;
const passed = average >= 40;

const status =
  passed && assignmentSubmitted ? "Ready" : "Needs Review";

console.log("Total:", total);
console.log("Average:", average);
console.log("Passed:", passed);
console.log("Status:", status);

Status: Ready

13 Quick Recap & Self-Reflection

1. Strict Over Loose Always use === and !== to avoid automatic type coercion surprises.
2. Order Matters Multiplication and division precede addition. Use parentheses (...) to explicitly guarantee execution order.
3. Short-Circuit Logic && stops at the first falsy operand; || stops at the first truthy operand.
4. Ternary for Conciseness Use condition ? ifTrue : ifFalse for clean, single-line decisions.
