JavaScript Foundations • Topic 12

Destructuring & Spread Syntax

Master modern ES6 syntax for unpacking values, collecting leftovers with rest syntax, copying and combining collections with spread, and understanding shallow copies vs. references.

1 What Is Destructuring?

Suppose you have a student record containing a name, age, and city. In traditional JavaScript, do you always need to access and assign each property manually one by one?

Destructuring assignment is a convenient syntax that allows you to "unpack" values from arrays, or properties from objects, directly into distinct local variables using a clean, symmetrical syntax.

◆ Conceptual Extraction: Array to Variables
["Aarav", 20, "Lucknow"]
→ [name, age, city] →
name = "Aarav"
age = 20
city = "Lucknow"

Example 1: Without Destructuring (Traditional Manual Indexing)

Clunky Manual Extraction JS 
const student = ["Aarav", 20, "Lucknow"];

const name = student[0];
const age = student[1];
const city = student[2];

console.log(name);
console.log(age);
console.log(city);
Expected Terminal Output
Aarav 20 Lucknow

Example 2: With Modern Array Destructuring

Concise ES6 Array Unpacking JS 
const student = ["Aarav", 20, "Lucknow"];

// Extracts items by their index position in one single line
const [name, age, city] = student;

console.log(name);
console.log(age);
console.log(city);
Expected Terminal Output
Aarav 20 Lucknow

Step-by-Step Trace: In Example 2, the square brackets [name, age, city] on the left side of the = match the positions of the array on the right side: name receives index 0, age receives index 1, and city receives index 2.

2 Array Destructuring & Skipping Elements

Array destructuring is strictly position-based. The variable placed at position 0 receives the item at index 0, position 1 receives index 1, and so forth.

If you want to skip an element you don't need, simply leave a comma without a variable name!

Example 1: Unpacking All Array Values

Sequential Position Matching JS 
const colors = ["Red", "Green", "Blue"];

const [first, second, third] = colors;

console.log(first);
console.log(second);
console.log(third);
Expected Terminal Output
Red Green Blue

Example 2: Skipping Unwanted Elements with an Empty Comma Slot

Skipping Elements Using Extra Commas JS 
const numbers = [10, 20, 30, 40];

// Notice the blank comma slot skipping index 1 (20)
const [first, , third] = numbers;

console.log("first:", first);
console.log("third:", third);
Expected Terminal Output
first: 10 third: 30
💡 What Happens If Elements Run Out?
If you specify more variables than elements in the array (e.g. const [a, b, c] = [1, 2]), missing positions safely evaluate to undefined without throwing an error!

3 Default Values in Array Destructuring

To prevent variables from becoming undefined when an array has fewer elements than expected, you can supply fallback default values using =.

Example 1: Providing a Fallback Default

Safeguarding with Defaults JS 
const settings = ["dark"];

// language falls back to "English" because index 1 does not exist
const [theme, language = "English"] = settings;

console.log("Theme:", theme);
console.log("Language:", language);
Expected Terminal Output
Theme: dark Language: English

Example 2: The Critical Difference: undefined vs. null

Defaults only activate for undefined, NEVER for null! JS 
const values = [undefined, null];

const [first = 100, second = 200] = values;

console.log("first (from undefined):", first);
console.log("second (from null):", second);
Expected Terminal Output
first (from undefined): 100 second (from null): null

Key Concept: undefined means "no value was provided", so the default activates. null is an intentional, defined value, so JavaScript preserves it.

4 Swapping Variables Without a Temporary Variable

In older programming languages, swapping the values of two variables required creating an awkward temporary third variable: let temp = a; a = b; b = temp;.

With JavaScript array destructuring, you can swap variables in a single expressive line: [a, b] = [b, a].

Example 1: Swapping Numeric Variables

In-Place Numeric Swap JS 
let a = 10;
let b = 20;

[a, b] = [b, a];

console.log("a:", a);
console.log("b:", b);
Expected Terminal Output
a: 20 b: 10

Example 2: Swapping String Variables

String Variable Swap JS 
let firstName = "Aarav";
let secondName = "Priya";

[firstName, secondName] = [secondName, firstName];

console.log("firstName:", firstName);
console.log("secondName:", secondName);
Expected Terminal Output
firstName: Priya secondName: Aarav

Why It Works: The right-hand side [b, a] constructs a temporary array in memory containing the values [20, 10] before any assignments happen. Then the destructuring unpacks them into a and b safely.

5 Rest Syntax in Array Destructuring

When destructuring an array, you can use the three dots ... (known as Rest syntax) to collect all remaining unextracted elements into a brand new array.

  • Position rule: Rest syntax must be the last element in the destructuring pattern.
  • Result: It collects zero or more leftovers into a fresh array.

Example 1: Extracting First Element and Collecting the Rest

Collecting Trailing Elements JS 
const scores = [85, 90, 78, 92, 88];

const [firstScore, ...remainingScores] = scores;

console.log("First:", firstScore);
console.log("Remaining:", remainingScores);
Expected Terminal Output
First: 85 Remaining: [ 90, 78, 92, 88 ]

Example 2: Skipping Early Elements Before Collecting the Rest

Combining Commas and Rest Syntax JS 
const tasks = ["HTML", "CSS", "JavaScript", "React"];

// Skips index 0 and 1, then collects remaining into advancedTopics
const [, , ...advancedTopics] = tasks;

console.log(advancedTopics);
Expected Terminal Output
[ 'JavaScript', 'React' ]

6 Object Destructuring: Extracting by Property Name

While array destructuring relies on positions, Object Destructuring extracts properties by matching their key names.

  • Curly braces: { ... } on the left side of the assignment.
  • Name matching: The variable name must match the key name on the object.
  • Order does NOT matter: You can unpack properties in any order.

Example 1: Unpacking Object Properties

Matching Property Keys JS 
const student = {
  name: "Aarav",
  age: 20,
  city: "Lucknow"
};

// Extracts only 'name' and 'age' into variables of the same name
const { name, age } = student;

console.log(name);
console.log(age);
Expected Terminal Output
Aarav 20

Example 2: Property Order Independence

Unpacking in Arbitrary Order JS 
const product = {
  title: "Laptop",
  price: 65000,
  brand: "ExampleTech"
};

// Notice brand is listed first, but still unpacks correctly
const { brand, title } = product;

console.log(brand);
console.log(title);
Expected Terminal Output
ExampleTech Laptop

7 Renaming Variables in Object Destructuring

What if you want to store a property in a variable with a different name? The syntax keyName: newVariableName allows custom renaming.

Example 1: Renaming Properties to Avoid Collisions

Aliasing Object Keys JS 
const student = {
  name: "Priya",
  age: 19
};

// 'name' is stored in 'studentName', 'age' is stored in 'studentAge'
const { name: studentName, age: studentAge } = student;

console.log(studentName);
console.log(studentAge);
Expected Terminal Output
Priya 19

Example 2: Renaming While Simultaneously Setting a Default Value

Renaming and Fallbacks Together JS 
const user = {
  name: "Aarav"
};

// 'role' is absent, so userRole defaults to "Student"
const {
  name: displayName,
  role: userRole = "Student"
} = user;

console.log(displayName);
console.log(userRole);
Expected Terminal Output
Aarav Student

8 Default Values in Object Destructuring

Just like arrays, an object property that is missing or explicitly undefined triggers its default value.

Example 1: Supplying Defaults for Optional Configuration

Config Defaults JS 
const preferences = {
  theme: "dark"
};

const {
  theme,
  language = "English"
} = preferences;

console.log("Theme:", theme);
console.log("Language:", language);
Expected Terminal Output
Theme: dark Language: English

Example 2: null vs. undefined in Objects

Behavior with null and undefined JS 
const settings = {
  timeout: undefined,
  retries: null
};

const {
  timeout = 5000,
  retries = 3
} = settings;

console.log("timeout:", timeout); // 5000 (activated by undefined)
console.log("retries:", retries); // null (null is preserved!)
Expected Terminal Output
timeout: 5000 retries: null

9 Nested Destructuring

When an object contains child objects or arrays, you can nest destructuring patterns to reach deep properties in a single step.

Example 1: Unpacking Nested Objects

Navigating Object Trees JS 
const student = {
  name: "Aarav",
  address: {
    city: "Lucknow",
    state: "Uttar Pradesh"
  }
};

// Extracts city and state directly from the nested address
const {
  address: { city, state }
} = student;

console.log(city);
console.log(state);
Expected Terminal Output
Lucknow Uttar Pradesh

Example 2: Combining Nested Objects & Arrays

Hybrid Object and Array Pattern JS 
const course = {
  title: "JavaScript",
  topics: ["Variables", "Arrays", "Objects"]
};

const {
  title,
  topics: [firstTopic, secondTopic]
} = course;

console.log(title);
console.log(firstTopic);
console.log(secondTopic);
Expected Terminal Output
JavaScript Variables Arrays

10 Destructuring in Function Parameters

Instead of passing an object and writing user.name and user.course repeatedly inside the function, you can unpack properties directly inside the parameter list.

Example 1: Clean Function Signatures

Direct Parameter Destructuring JS 
function displayStudent({ name, course }) {
  console.log(`${name} is learning ${course}.`);
}

displayStudent({
  name: "Priya",
  course: "JavaScript"
});
Expected Terminal Output
Priya is learning JavaScript.

Example 2: Safe Function Parameter Defaults with = {}

Guarding Against Missing Arguments JS 
// The outer = {} guarantees the function doesn't crash if called with no arguments
function createProfile({
  name = "Guest",
  role = "Student"
} = {}) {
  console.log(`${name} - ${role}`);
}

createProfile();                           // No argument: Guest - Student
createProfile({ name: "Aarav" });          // Partial: Aarav - Student
Expected Terminal Output
Guest - Student Aarav - Student

11 What Is Spread Syntax?

The Spread Operator (...) expands an array or iterable into individual arguments/elements, or expands an object's properties into a new object literal.

💡 Mental Model: Packing vs. Unpacking
Rest (...) packs multiple individual values together into a single container.
Spread (...) unpacks a container's items out into a new destination!

Example 1: Expanding an Array into Function Arguments

Passing Array Elements to Math.max JS 
const numbers = [10, 20, 30];

// Math.max expects separate arguments, not an array
console.log(Math.max(...numbers)); // Evaluates as Math.max(10, 20, 30)
Expected Terminal Output
30

Example 2: Spreading into a Brand New Array

Array Expansion JS 
const first = [1, 2, 3];
const second = [...first];

console.log(second);
console.log(first === second); // false: distinct array in memory
Expected Terminal Output
[ 1, 2, 3 ] false

12 Copying Arrays with Spread

In JavaScript, writing const b = a does not duplicate the array; it only copies the memory reference (an alias). Spreading creates an independent outer array.

Example 1: Variable Assignment (Shared Reference Pitfall)

Accidental Mutation Through an Alias JS 
const original = [10, 20, 30];
const shared = original;

shared.push(40);

console.log("original:", original);
console.log("shared:", shared);
Expected Terminal Output
original: [ 10, 20, 30, 40 ] shared: [ 10, 20, 30, 40 ]

Example 2: Safe Copying with Spread ([...original])

Independent Outer Array JS 
const original = [10, 20, 30];
const copy = [...original];

copy.push(40);

console.log("original:", original);
console.log("copy:", copy);
Expected Terminal Output
original: [ 10, 20, 30 ] copy: [ 10, 20, 30, 40 ]

13 Combining Arrays with Spread

Spread syntax allows you to combine multiple arrays seamlessly without using older methods like concat().

Example 1: Merging Two Arrays

Joining Lists JS 
const frontend = ["HTML", "CSS"];
const javascript = ["JavaScript", "React"];

const skills = [...frontend, ...javascript];

console.log(skills);
Expected Terminal Output
[ 'HTML', 'CSS', 'JavaScript', 'React' ]

Example 2: Adding Elements In-Between Spreads

Arbitrary Element Insertion JS 
const start = [1, 2];
const end = [5, 6];

const result = [0, ...start, 3, 4, ...end, 7];

console.log(result);
Expected Terminal Output
[ 0, 1, 2, 3, 4, 5, 6, 7 ]

14 Spread Syntax with Objects

The object spread syntax { ...original } copies all enumerable own properties of an existing object into a fresh object.

Example 1: Shallow Copying an Object

Cloning an Object Literal JS 
const student = { name: "Aarav", course: "JavaScript" };
const copy = { ...student };

console.log(copy);
console.log("Same memory?", copy === student); // false
Expected Terminal Output
{ name: 'Aarav', course: 'JavaScript' } Same memory? false

Example 2: Adding or Overriding Properties with Spread

Non-Mutating Updates JS 
const defaults = { theme: "light", language: "English" };

// 'theme' defined after the spread overrides the default 'light'
const preferences = {
  ...defaults,
  theme: "dark"
};

console.log(preferences);
Expected Terminal Output
{ theme: 'dark', language: 'English' }

15 Merging Objects & Property Precedence

When merging multiple objects with spread, order determines the winner. If two objects contain the exact same property key, the one written later in the literal wins and overwrites the earlier value.

Example 1: User Settings Overriding Default Settings (Standard Pattern)

Defaults First, User Settings Second JS 
const defaults = { theme: "light", fontSize: 16, notifications: true };
const userSettings = { theme: "dark", fontSize: 18 };

const finalSettings = {
  ...defaults,
  ...userSettings
};

console.log(finalSettings);
Expected Terminal Output
{ theme: 'dark', fontSize: 18, notifications: true }

Example 2: Reversing the Order (Defaults Overwrite User Settings!)

Order Inversion Bug JS 
const finalReversed = {
  ...userSettings,
  ...defaults // defaults comes last, obliterating user settings!
};

console.log(finalReversed);
Expected Terminal Output
{ theme: 'light', fontSize: 16, notifications: true }

16 Rest vs. Spread: The Important Difference

Both Rest and Spread use three dots ..., but their roles are opposites depending on where they appear in your code:

Feature Rest Syntax (...) Spread Syntax (...)
Location Left side of = (or function parameters) Right side of = (or inside [], {}, function calls)
Core Purpose Collects multiple remaining items into one array/object Expands one collection into individual items/properties
Direction Many values → One array One array/object → Many individual values

Example 1: Rest Collecting

Rest Syntax JS 
const [first, ...others] = [10, 20, 30, 40];
console.log("others:", others);
Expected Terminal Output
others: [ 20, 30, 40 ]

Example 2: Spread Expanding

Spread Syntax JS 
const arr1 = [10, 20];
const arr2 = [30, 40];
const combined = [...arr1, ...arr2];
console.log("combined:", combined);
Expected Terminal Output
combined: [ 10, 20, 30, 40 ]

17 Shallow Copy, Nested Data, & References

The most common bug in modern JavaScript applications is assuming that spread creates a deep copy. Spread only copies one level deep.

◆ Memory Inspection: Shallow Copy with Nested Object
Variables
original→ Object #A
copy = {...original}→ Object #B
Nested Child Object
#A.address→ #Addr_01
#B.address→ #Addr_01 (Shared!)

Example 1: Nested Object Remains Shared in Shallow Copy

Unintended Shared Nested Mutation JS 
const original = {
  name: "Aarav",
  address: { city: "Lucknow" }
};

const copy = { ...original };
copy.address.city = "Kanpur";

console.log("original.address.city:", original.address.city);
console.log("copy.address.city:", copy.address.city);
Expected Terminal Output
original.address.city: Kanpur copy.address.city: Kanpur

Example 2: Explicitly Spreading the Nested Level

Spreading the Child Object JS 
const orig2 = {
  name: "Aarav",
  address: { city: "Lucknow" }
};

// Manually spread the address object to create a fresh child object
const copy2 = {
  ...orig2,
  address: { ...orig2.address }
};

copy2.address.city = "Kanpur";

console.log("orig2 city:", orig2.address.city);
console.log("copy2 city:", copy2.address.city);
Expected Terminal Output
orig2 city: Lucknow copy2 city: Kanpur

Modern Deep Clone: Modern environments support structuredClone(obj) for deep cloning structured data without functions.

19 Common Mistakes & Debugging

✕ 1. Using Square Brackets Instead of Curly Braces for Objects
const user = { name: "Aarav" };
const [name] = user; // TypeError: user is not iterable!
✓ Correct Fix: Use curly braces: const { name } = user;
✕ 2. Confusing Variable Renaming with Object Key Mutation
const student = { name: "Priya" };
const { name: studentName } = student;
console.log(name); // ReferenceError: name is not defined
✓ Correct Fix: Access the new variable name: console.log(studentName);
✕ 3. Expecting Defaults to Activate on null
const [count = 10] = [null];
console.log(count); // null! Not 10
✓ Correct Fix: Defaults only trigger for undefined. Check with nullish coalescing: (count ?? 10)
✕ 4. Placing Rest Syntax in Non-Final Position
const [...rest, last] = [1, 2, 3]; // SyntaxError: Rest element must be last
✓ Correct Fix: Always put rest at the end: const [first, ...rest] = [1, 2, 3];
✕ 5. Assuming Spread Deep Clones Nested Objects
const a = { sub: { x: 1 } };
const b = { ...a };
b.sub.x = 99; // a.sub.x is also 99!
✓ Correct Fix: Spread nested levels explicitly: const b = { ...a, sub: { ...a.sub } };
✕ 6. Reversing Merge Order
const userPref = { theme: "dark" };
const defaults = { theme: "light" };
const settings = { ...userPref, ...defaults }; // defaults overwrote userPref!
✓ Correct Fix: Put defaults first, overrides last: { ...defaults, ...userPref }
✕ 7. Calling Function with Destructured Parameter Without Guard
function greet({ name }) { console.log(name); }
greet(); // TypeError: Cannot destructure property 'name' of undefined
✓ Correct Fix: Add = {} default: function greet({ name = "Guest" } = {}) { ... }
✕ 8. Wrapping Spread in Array Unintentionally
const items = [1, 2];
const nested = [[...items]]; // [[1, 2]] - double array brackets!
✓ Correct Fix: Use single brackets: const copy = [...items];
✕ 9. Attempting to Destructure undefined or null
const response = null;
const { data } = response; // TypeError: Cannot destructure property 'data' of null
✓ Correct Fix: Guard with default empty object: const { data } = response || {};
✕ 10. Forgetting that Spread Only Copies Enumerable Own Properties
class User { hello() { return "Hi"; } }
const u = new User();
const plain = { ...u };
console.log(plain.hello); // undefined! Prototype methods are not copied
✓ Correct Fix: Remember spread is for plain data properties, not class prototype chains.

20 Practice and Revision

Part A: Output-Prediction Challenges

1. Array destructuring skipping 
const [, b, , d] = [10, 20, 30, 40];
console.log(b, d);

Predicted Output: 20 40

Explanation: Blank comma slots skip index 0 (10) and index 2 (30).

2. Destructuring variable swap 
let x = 1, y = 2;
[x, y] = [y, x];
console.log(x);

Predicted Output: 2

Explanation: The array destructuring pattern swaps the values in-place.

3. Object destructuring with renaming and default 
const { a: alpha = 99 } = {};
console.log(alpha);

Predicted Output: 99

Explanation: Property a is missing, so local variable alpha receives its default value 99.

4. Rest syntax in array 
const [first, ...rest] = [5];
console.log(rest);

Predicted Output: []

Explanation: first receives 5, and with no remaining items, rest collects an empty array [].

5. Object spread override precedence 
const a = { x: 1, y: 2 };
const b = { ...a, y: 10, y: 20 };
console.log(b.y);

Predicted Output: 20

Explanation: The last value specified for key y wins.

6. Shallow copy nested array mutation 
const original = [[1, 2]];
const copy = [...original];
copy[0].push(3);
console.log(original[0].length);

Predicted Output: 3

Explanation: Spread creates a shallow copy. The nested inner array [1, 2] remains shared in memory.

7. Function parameter default fallback 
function f({ count = 5 } = {}) {
  console.log(count);
}
f();
f({ count: 0 });

Predicted Output: 5 then 0

Explanation: When called with no argument, = {} triggers and count defaults to 5. When called with { count: 0 }, 0 is a defined value and is preserved.

8. Math.max with array spread 
const nums = [4, 18, 9];
console.log(Math.max(...nums));

Predicted Output: 18

Explanation: ...nums expands into separate arguments Math.max(4, 18, 9).

Part C: Debugging Challenges

Challenge 1: Fix Destructuring on null Response

Bug: const { items } = fetchResult; crashes when fetchResult is null.

Fix: const { items = [] } = fetchResult || {};

Challenge 2: Fix Nested Preference Spread

Bug: const updated = { ...user, preferences: { theme: "dark" } }; wipes out existing preferences!

Fix: const updated = { ...user, preferences: { ...user.preferences, theme: "dark" } };

Challenge 3: Fix Reversed Merge Order

Bug: const config = { ...userOverrides, ...baseDefaults }; ignores user overrides.

Fix: const config = { ...baseDefaults, ...userOverrides };

Challenge 4: Fix Invalid Rest Placement

Bug: const [first, ...middle, last] = arr; (SyntaxError)

Fix: Rest must be last: const [first, second, ...tail] = arr;
